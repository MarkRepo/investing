## 0. 主旨：两句话 + 一个行为顺序

射手定位（前期很难主动创造节奏、中后期要队友保护，非常被动但也非常重要）浓缩成两句话，**全片所有取舍都用它衡量**：

> **保证发育节奏，扩大推进节奏。**

以及一个作者断言「只要能掌握，就不可能低分」的行为顺序：

> **先看小地图 → 根据小地图的信息，调整自己在大地图上的行为。**

认知重构对照：

| 低分认知 | 教科书认知 |
|---|---|
| 射手 = 跟辅助连体、后期站桩输出 | 两句话模型：先保发育节奏，再扩大推进节奏 |
| 队友打进攻，我跟上去准没错 | 跟队进野区 = 没有节奏（三路线没人处理、只能捡小野怪）——射手常被队友的进攻「打炸」 |
| 掉点 = 劣势，复活后缩起来 | 复活后逻辑要重建：防守红区 / 清线，掉点≠什么都不做 |
| 射手被切死很正常（「老艺术家」言论） | 被切死多数是没提前规划安全区域和战场位置 |
| 抢线被 GANK 就骂队友不保我 | 放线进塔清，对方就难有 GANK 想法——节奏全在自己把控 |

视频结构：问答式推进（「我会以部分问题的形式来引导大家」）——守约局问出对线与中期逻辑 → 孙尚香局问出支援、动向与团战逻辑。每问的答案都先给**逻辑基点**、再给**小细节辅佐**（原话：逻辑决定思路，细节辅佐思路）。

## 1. 守约局（一）：劣势对线怎么苟

### Q1 开局看什么？

**看有没有辅助跟自己。** 没有辅助 → 线上一打二是绝对劣势 → 抢线会被打掉状态 → 没法补兵 → **第一波线劣势方不能上前摸兵，在塔下吃就可以**。本局一诺是百里守约：二技能补兵就可以了。

### Q2 中路队友掉点，发育路能把兵线推过去吗？

不能。对局经验丰富的玩家知道：守约前期比较弱，**哪怕发育路 2v2 也不好打，更别说中路掉点、对面中路能支援**——我们在泉水，这波线推过去什么都干不了，反而给对面机会抓自己一波 → 依旧属于劣势方，不上前摸兵，补兵就行。

由此总结**通用逻辑**（作者：这就是所谓的游戏认知，所有玩家都是在建立这一个逻辑框架，高分玩家的理解一定是成型的）：

> 发育路对位劣势 + 中路也是劣势 → 顶前没有意义 → 线放塔下接，用来过渡前期。

**小细节辅佐大思路**：对面会冲上前来压退守约 → 一诺在路中央放一只眼（一技能视野装置），让自己一直进入隐身状态（守约贴墙伪装），**永远掌握先手权** → 对方没办法消耗自己的状态 → 也就达成了「苟着补兵」的原有思路。

### Q3 苟到三分半，一诺开始推兵线，逻辑在哪？

| 条件 | 推论 |
|---|---|
| 队友在身后 | 不怕送线进塔 |
| 对面不来 | 有可能能越塔打 |
| 对方慢慢推线 | 哪怕（对面）有节奏也会变成没有 |
| 结论 | **这时候能速推兵线就速推** |

下一波为什么也在速推：①火舞上路漏了，自己这边半图的人比对方人多；②4 分钟龙要刷新 → 速推后**自己就能先动起来，帮队友打龙**。

### 速推兵线技巧（本片第一个可复用细节）

在能 A 到后排兵的时候**先 A 后排兵，并且用精准普攻，同时压低两只后排兵的血量**；前排兵会被自家兵压低血量 → 三只小兵同时来到残血 → **直接用能打穿透伤害的大招秒清兵线——比正常逐个清兵快两秒以上**。

### 发育路兵线处理通则

兵线怎么处理，要看对应的**发育路半图以及中路**：

- 半图靠发育路的那一半（发育路半图）**这边有队友 → 就可以往前压**；
- 中路队友是优势、能先动起来 → 也可以往前压——职业里面简称**中轴优势**。

## 2. 4 分钟：离开对线期（必须有的认知）

**逻辑基点**：4 分钟后野区保护机制消失、防御塔保护机制衰减 → 会有更激烈的野区对抗以及更快的推塔 → **这已经不是对线期，而是入侵和推进的阶段**。

- 协防红区打防守 → 可以**保证自己的发育节奏**。

### Q4 队友反进对方野区，要一起进攻野区吗？

**不进。** 进野区可以保证万无一失，但会让你自己没有任何节奏——射手两句话再记一次：**保证发育节奏、扩大推进节奏**。

正面算法：对方上路漏了人 → 队友进野区是能打得过的；**下路有一整波兵线可以用作推进** → 继续用速推技巧推过去 → 敌方哪怕做了换节奏行为（把对抗路半图的兵线处理好），对自己来说节奏完全顺畅——**推进加发育，足够射手玩家爽一天了**。

反面算法（如果跟去打野区入侵）：

1. 三条路的兵线都没人处理 → 根本不可能有兵线能用作推进；
2. 射手只能捡节点小野怪吃；
3. 推进和发育都没做成 → **这样的射手根本没有节奏**。

> 「大家这时候应该就明白，为什么有时候队友打进攻，会把自己这个射手打炸了吧。」

### 复活后的逻辑（拒绝「老艺术家」行为）

绝大部分玩家从泉水出来后逻辑是混乱的：掉点意味着劣势 → 劣势了就缩起来。正确画面（本局张飞掉点后）：

- 红区要刷新、下路兵线**还有一会**不会丢 → **优先和队友一起防守红区** → 保证发育节奏；
- 下路兵线收完后要去哪 → 进入中后期兵线处理逻辑（见下）。

## 3. 中后期：打三线 vs 打半图 + 速率差

两种模式（职业简称，作者：「学会了就又可以装 X」）：

| 模式 | 定义 | 前置条件 | 好处 |
|---|---|---|---|
| **打三线** | 同时带三路兵线 | **绝对优势**——三条路都打得过对方 | 同时拥有多条推进线；对方因绝对劣势打不过，没办法同时处理三条线 |
| **打半图** | 同时带一边半图的两条线（中线+上线 / 中线+下线） | **只要不是绝对优势，都是打半图** | 相互照应、集中站在一边，半图能随时和对方正面对抗或者拉扯 |

**应用（守约局）**：队友掉点，四打五 → 不可能打三线，只能打半图；达摩在蹲人找机会，不可能往我们这边半图靠 → **守约清完下路兵线一定是往中路靠——主动靠近队友所在的半图**。来中路的过程中发现对方在打三线（对方分散）→ 自己这边集中了战力打半图 → **对方中路顶多也就三个人可以抢中线 → 不可能会掉节奏 → 先到位就可以速推中路兵线**。

**兵线速率差（核心技巧）**：

> 敌方中路兵线来到地图中央，肯定比发育路兵线来到我们二塔前的速度快 → **利用这一点先吃中再吃下，就可以爽吃双线，而且全程没有掉节奏的机会。**

射手的锅，说透了：

> 大部分对局的射手「牢」确实牢（坐牢），但自己的节奏也是根本没有打出来；只是因为射手节奏不容易体现，所以背锅最多的反而是掉点，而不是节奏。

## 4. 孙尚香局（二）：优势对线怎么滚

### 速推的同款技巧

孙尚香一技能强化普攻是穿透 → **调整位置 + 精准普攻，同时收多只小兵**（与守约同思路）。

### Q5 对抗路打起架，我们能过去吗？

可以。**基点在于刚才这波兵线是速推的 → 速率领先很多 → 有足够的时间去「切图」**：

- **切半图** = 从下路到中路，走了一个半图；
- **切全图** = 从下路到上路，走了一个全图。

如果刚才兵线不是速推 → 自然不够时间切全图；且孙尚香有一技能，切图速度并不慢 → 才可以赶得上打仗的节奏。**这就是英雄选择 + 游戏理解。**

支援到位拿了助攻 → **顺便收掉上路的兵线 → 用传送阵回发育路吃双线**——这波支援还补回了队友的节奏。这是**射手在对线期可以做到的「补节奏」行为**。

### 对线期的反向问题：优势也放线？

对面中路打野不见、队友集中去打对抗路——我们对位优势，但这波发育的兵线能抢吗？很急着抢吗？**当然是放进来清**：这样对方就很难有 GANK 的想法；而不是出去抢线然后被抓，开始骂队友「为什么要打对抗路，不打发育路、去当一个太子爷」。

> 「这其实全都是自己就能把控的节奏。当你点进来教科书那一刻，就要摆脱这些低分行为。」

### 4 分钟节点：调站位（字幕作「挑战位」）的逻辑

队友正面顶了一波、前排血量被压得很低 → 对面会压过来、队友要退走；身后有敌方 all in → 不可能在这个地方停留 → **打满输出之后，立刻调身位到团队的后防** → 帮铠打小野怪回血量、顺便又可以发育。

> 一诺强的地方之一：**转换很快——团战不好接、接不好输出，能第一时间调整成发育。**

### 有顺序的行为（先看小地图）

拿到红 buff，发育路可以起推进，但**小地图对方的人没漏 → 兵线不急着抢**，和发育路下面的草丛保持距离；**小地图漏人了再抢线**；兵线抢完不急着进塔 → 用一技能探前面的草丛 → **小地图敌方全漏，再压塔**；敌方传送就再拉走。

> 「先看小地图，根据小地图的信息来调整自己在大地图的行为。**就这一个行为顺序，只要你能掌握，是不可能低分的。**」

同样的下步兵线：先看小地图信息，再速推兵线——线上优势射手的逻辑，不可能让自己前期掉节奏。

### 起推进：逼关键技能

让兵线推塔，**和太乙一起顶前 → 让敖隐被迫交出大招 → 为下一步争取一个关键技能**。

## 5. 中期动向：哪有钱往哪走 + 保底收益

### 塔下劣势线收完后往哪走？

比较简单的想法：**哪有钱往哪走**——有蓝区资源、没有红区就往蓝区那边靠，蹭点经济。蹭完留中还是回发育路？这条逻辑稍长：

- 如果打半图 → 当然是留中（对抗路那边夏洛特已经到位，对方在发育路这边的话夏洛特就可以把线带出去）；
- **但如果对方也打对抗路半图呢？** 现在的局势是小逆风，且对方有大乔可以传送 → 打同一边半图，正面肯定打不过大乔 → **必须保留另一种可能性**：对方打对抗路半图，我们就可以去打发育路半图，把一条边路的兵线带出去；
- 所以**动向必须是先往发育路那边靠**，看情况选择中或者发育路；
- **明确看到了敌方是打发育路半图了，就再靠回中路、选择打对抗路半图** → 把对抗路的兵线处理好后，再尝试阻断敌方的半图节奏；
- 哪怕最终的结果还是打不过对方，也会丢掉一整波对抗路的兵线经济——**这就是你的保底收益**。

（作者注：这属于更高端的运营，教科书里还是讲回个人节奏。）

**同类判断**：嫦娥掉点、对方想推下二塔 → 上一波的发育路兵线还在、连续的两波线拦不住 → 没必要留下路，赶紧把中路兵线处理好；这时候对抗路半图是安全区域，**进中左草就可以和队友相互照应，把这波节奏扯平**。

### 什么时候射手可以去带边路的兵线？

还是那两种模式：**打三线的时候当然可以；打半图的时候——看队友在哪半图**：

- 夏洛特往中路靠、打的是上半图 → 我们就可以把上路兵线带出去；
- **队友懂得来靠中 → 射手就有机会在边路打；队友不懂得配合打你这边的半图 → 射手就在中路打，让队友去带边线**——一点都不难；
- 这里轮到孙尚香靠中 → 夏洛特就又可以去带下路线——顶尖局才有的章法，「但你现在还不敢开麦指挥吗？只要打出一波半图节奏，对面就已经溃败了，**没有任何路人玩家能打得过半图节奏**」。

### 吃双线与标准节奏

敌方马超把上线带过来 → 对孙尚香又是一波吃双线的节点：**先吃中，然后切图到上路接劣势线**（转线的过程中谨慎一点）。

哪怕是小逆风，**标准节奏：10 分钟前做出破晓**。

## 6. 团战理解：安全区域 + 战场位置

一句话明白射手在团战到底要找什么位置：

> **安全区域** 和 **战场位置**。

### 常规团战

敌方视野全漏 → 安全区域是很大的保证 → **在队友的身后作战就可以了**。

小细节辅佐思路：

- **先 A 小野怪——不是刷新一技能，是先打出暴击、触发影刃的被动** → 更好地往后方拉扯；
- 敌方往前顶、一直往安全区域退不好 A 敌方 → **先摸红（野怪）刷新技能、续影刃被动以及吸血 → 边打团边发育**。

### 必死局面：往哪拉？

铠掉点了，但这波团不一定结束（敌方技能交了很多、强化炮车出击）→ 试探性绕回去 → 找到机会带走蒙恬 → **马超切进来，一技能穿墙也走不了，必死了**：

> 战场位置在哪？**队友最多的地方。既然必死，往左拉**——能打满输出，而且能让战场的位置不变 → 队友就能处理后续的团战。

反面：如果刚才穿墙走了 → **把整个战场的位置打破了** → 夏洛特不可能去追击马超。

> 「学起来比较难，一波团不够，大家理解透。后期一定要多看小地图，才能快速找到安全区域和战场位置。」

### 动态规划

敌方在中路接近视野全漏 → 安全区域：这一整片；战场位置在这一片。**这两个是会一直变的** → 只要瞄一眼、快速在脑子里规划一下 → 提前有了规划，就明白团战大概要怎么打。

### 打龙团（细节密集段）

- 打龙时马超绕过来 → 可直接上前赶走他——**这个位置依旧相对安全**（敌方大部队在另一边输出）；
- 蒙恬切进来 → 往下路安全的地方拉 → **换复活甲、A 兵线补状态**；
- 嬴政、敖隐大招跟过来 → **先二再闪**躲 → 继续A单位补状态、续影刃；
- 这波团没有后续了 → **把鞋子换成 CD 鞋，加快闪现 CD，提前准备下一波团战**。

> 「打团思路清晰，提前明确自己要往哪边跑——这样你的射手 KDA 不可能会很低。」
