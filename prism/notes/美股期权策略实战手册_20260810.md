# 第 0 章　5 分钟前置速查

## 0.1 一句话把期权说清楚

期权 = 一份**权利合约**。买方花钱（权利金 premium）买一个"**将来能不能按约定价（行权价 strike）买/卖 100 股标的**"的权利；卖方收钱，承担对应的**义务**。

- **认购期权 Call**：买方有权**以行权价买入**标的。看涨买 Call。
- **认沽期权 Put**：买方有权**以行权价卖出**标的。看跌买 Put。
- 一张（1 contract）美股期权 = **100 股**标的（乘数 100，除非公司行为调整过）。
- 权利金报价是"每股"，实际付出 = 报价 × 100。看到 `2.50`，一张就是 **$250**。

**内在价值 vs 时间价值**（贯穿全文的底层概念）：

```
权利金 = 内在价值(Intrinsic) + 时间价值(Extrinsic / Time value)

内在价值 = 立刻行权能赚多少（Call: 现价−行权价，最低为 0；Put: 行权价−现价，最低为 0）
时间价值 = 权利金里超出内在价值的部分 = 你为"还有时间 + 波动可能"付的钱
```

例：AAPL 现价 $255，250 Call 报价 $8。内在价值 = 255−250 = $5，时间价值 = 8−5 = **$3**。这 $3 会随时间和波动率**衰减到 0**（到期日归零）。**卖方赚的就是这 $3 的衰减，买方要靠标的涨得够快够多来盖过它。**

- **实值 ITM**（In The Money）：有内在价值。Call 现价>行权价；Put 现价<行权价。
- **平值 ATM**（At The Money）：现价 ≈ 行权价。**时间价值最厚**。
- **虚值 OTM**（Out of The Money）：无内在价值，全是时间价值。

## 0.2 期权代码解剖（OCC 标准格式）

看到 `AAPL 260918C00250000`，拆成 5 段：

| 段 | 例子 | 含义 |
|---|---|---|
| 标的代码 | `AAPL` | 根代码（root symbol） |
| 到期日 | `260918` | 2026-09-18（YYMMDD） |
| 类型 | `C` | C=Call，P=Put |
| 行权价 | `00250000` | $250.000（后 3 位是小数，即 ×1000 再补零） |

**几个必须认识的变体**：

- **周度 SPX 用 `SPXW`**：`SPX` = 传统月度（AM 现金结算，最后交易日周四）；`SPXW` = 周度/日度（PM 现金结算，当日收盘结算）。**两者结算规则不同，别买错**（第 2 章详解）。
- **调整后合约 `AAPL1` / `AAPL2`**：根代码后带数字，代表经历过拆股、特别股息、并购等**公司行为调整**，其乘数或交割物**不是标准 100 股**。看到带数字后缀的合约，先查 OCC 公告弄清交割物再交易，否则会踩坑。
- **迷你期权（已很少）**：乘数 10 而非 100，代码带 `7` 后缀，流动性差，尽量别碰。

## 0.3 T 型报价怎么读

打开任意合约链（option chain），一行长这样：

```
        CALLS                    STRIKE              PUTS
 Bid   Ask   IV   Vol   OI   |          |   Bid   Ask   IV   Vol   OI
 8.30  8.45  22%  1240  9800 |   250    |   3.10  3.25  24%   860  7300
```

初学者必须盯的 5 个字段：

1. **Bid / Ask（买价/卖价）**：你**卖出**成交价接近 Bid，**买入**成交价接近 Ask。中间价 Mid =(Bid+Ask)/2 是你挂单的锚。
2. **Bid-Ask 价差**：`8.30/8.45` 价差 $0.15 尚可；若是 `8.30/9.20` 价差近 $1，说明**流动性差**，一进一出先亏 10%，直接换标的或换行权价。
3. **IV（隐含波动率）**：市场对未来波动的定价。**卖方要在 IV 高时卖，买方要在 IV 低时买。**（怎么判断高低看 3.2 节 IV Rank）
4. **Volume（当日成交量）**：今天换手活跃度。
5. **Open Interest OI（未平仓量）**：市场上还没平掉的合约总数。**OI 越大越好平仓。** 初学者只做 **OI > 500、Vol > 100** 的合约。

> 记忆口诀：**买看 Ask、卖看 Bid、进出看价差、贵贱看 IV、能不能跑看 OI。**

## 0.4 券商期权权限等级（Options Approval Level）

美国券商按风险给你分级，决定你能做什么。各家名称略异，通用如下：

| Level | 能做 | 典型代表策略 |
|---|---|---|
| **Level 1** | 备兑开仓、保护性认沽（有持股/现金担保的保守操作） | 备兑 Call、保护 Put |
| **Level 2** | 买入 Call/Put、现金担保卖 Put | 买方全部 + 卖现金担保 Put |
| **Level 3** | 价差（垂直、日历、蝶、鹰等**有限风险多腿**） | 本文第 5、6 章绝大多数 |
| **Level 4** | **裸卖 Naked** Call/Put（无担保，无限/巨大风险） | 裸卖认购、卖跨式（保证金账户） |

**给初学者的路径**：先申请到 **Level 2**，把买方 + 现金担保卖 Put + 备兑跑熟；再升 **Level 3** 做价差（本文主战场，风险可控）。**Level 4 裸卖认购在你有 2 年以上实盘经验前，不要碰。**

另外两个必须知道的账户规则（第 9 章细讲）：
- **Reg T 保证金 vs 组合保证金（Portfolio Margin）**：决定你的保证金占用算法，PM 通常需 $12.5 万+ 净值。
- **PDT 规则（Pattern Day Trader）**：净值 < $2.5 万时，5 个交易日内日内平仓（当日开当日平）不能超过 3 次 —— 对做 0DTE 的人是硬约束。

# 第 1 章　四块积木：期权只有 4 种基本头寸

任何复杂策略，拆开都是这 4 块积木的组合。先把这 4 张损益图刻进脑子。

## 1.1 买入认购（Long Call）——「我看它要涨，且愿意付保费」

- 付出权利金（**借记 Debit**，钱出去）
- **最大亏损 = 权利金**（有限）；**最大盈利 = 无限**（理论上）
- 盈亏平衡 = 行权价 + 权利金
- 世界观：**方向坚定看涨 + 认为 IV 不贵 + 有明确时间催化**

```
损益
  +∞ ┤          ╱
     │        ╱
   0 ┼──────╱──────────  ← 盈亏平衡 = 行权价+权利金
     │     ╱
 -付出┤────╱ (无论跌多深，最多亏权利金)
     └────┴──────────► 到期标的价
        行权价
```

## 1.2 买入认沽（Long Put）——「我看它要跌，或给持仓买保险」

- 付出权利金（借记）
- **最大亏损 = 权利金**；**最大盈利 = 行权价−权利金**（标的跌到 0，巨大但有限）
- 盈亏平衡 = 行权价 − 权利金
- 世界观：**看跌**，或**持有股票想对冲下行**（保护性认沽，见 4.4）

## 1.3 卖出认购（Short Call）——「我赌它涨不上去 / 或我持股愿高位卖」

- 收取权利金（**信用 Credit**，钱进来）
- **裸卖**：最大盈利 = 权利金；**最大亏损 = 无限**（标的暴涨）← 全期权最危险头寸
- **备兑**（有持股）：见 4.3，风险被持股覆盖，是保守策略
- 世界观：中性偏空 / 认为 IV 高 / 标的上方有强阻力

```
损益 (裸卖认购 —— 注意右侧是无底深渊)
 +收 ┤──────────┐
   0 ┼──────────┴─╲──────  ← 平衡 = 行权价+权利金
     │            ╲
 -∞  ┤             ╲  (涨越多亏越多，无上限)
     └────┴─────────► 到期标的价
        行权价
```

## 1.4 卖出认沽（Short Put）——「跌不下去 / 或我愿低位接货」

- 收取权利金（信用）
- 最大盈利 = 权利金；**最大亏损 =(行权价−权利金)×100**（标的到 0，巨大但有限）
- 世界观：中性偏多 / IV 高 / 愿意在行权价接货（现金担保卖认沽，本文样例，见 4.2）

## 1.5 借记 vs 信用：一眼看穿你的风险长相

这是初学者最该建立的分类直觉：

| | **借记 Debit（钱出去）** | **信用 Credit（钱进来）** |
|---|---|---|
| 你是 | 净买方 | 净卖方 |
| 时间价值 Theta | **敌人**（每天流逝） | **朋友**（每天收租） |
| IV 变化 Vega | 涨 IV 对你有利 | 跌 IV 对你有利 |
| 盈利概率 | 通常 < 50%（要方向对 + 够快） | 通常 > 50%（横盘也能赢） |
| 盈亏形态 | **小亏大赚**（亏有限，赚可能很大） | **大概率小赚，小概率大亏** |
| 心理陷阱 | 温水煮青蛙式阴跌到归零 | 平时躺赚，一次尾部还回去几个月 |

> **没有免费午餐**：高胜率的代价是"亏起来大"，高赔率的代价是"经常亏小钱"。选策略本质是选你要哪一种痛苦。

## 1.6 【核心对照表】四类标的的期权规则差异

> ⚠️ 这张表是全文最重要的一张，第 2 章结算规则全部由它展开。

| | **个股期权**<br>AAPL/NVDA | **ETF 期权**<br>SPY/QQQ/IWM | **指数期权**<br>SPX/NDX/RUT | **VIX 期权** |
|---|---|---|---|---|
| 行权方式 | **美式**（到期前随时可行权） | **美式** | **欧式**（仅到期日行权） | **欧式** |
| 结算 | **实物**交割 100 股 | **实物**交割 100 份 | **现金**结算 | **现金**结算 |
| 提前被指派 | **有**（除息前尤甚） | **有**（ETF 也分红） | **无** | **无** |
| Pin Risk（钉住风险） | 有 | 有 | **无** | 无 |
| 乘数 / 名义 | 100×股价 | 100×价格 | 100×指数（SPX≈$60 万/张） | 100×VIX |
| 最后交易日 | 到期**周五** | 到期**周五** | 月度AM=**周四**；周度PM=当日 | 到期前一日（周二） |
| 结算价 | 周五收盘 | 周五收盘 | 月度=周五**开盘 SET**；周度=收盘 | **VRO**（特殊开盘价） |
| 标的实质 | 股票（可持有） | ETF 份额（可持有） | 指数（**不可持有**） | **VIX 期货**，非现货 VIX |
| 税务(美国) | 短期资本利得 | 短期资本利得 | **Section 1256 60/40** | **Section 1256** |
| 典型用途 | 个股表达观点、Wheel | 灵活、小资金、可实物 | 组合对冲、大资金、税优 | 尾部对冲、波动率交易 |
| 主要陷阱 | 财报跳空、被 call away | 除息日被指派 | **AM 结算隔夜缺口** | **贴水/升水，不跟踪现货 VIX** |

**三句话记住核心分野**：

1. **能拿在手里的东西（个股、ETF）→ 美式 + 实物 + 有提前指派风险。**
2. **拿不住的东西（指数）→ 欧式 + 现金 + 无提前指派、无 pin risk。**
3. **VIX 最特殊**：欧式现金结算，但**标的是 VIX 期货不是你看到的那个 VIX 数字**，且用特殊开盘价 VRO 结算 —— 是全场最容易亏冤枉钱的品种。

# 第 2 章　★ 行权、指派、平仓与结算（本文重点）

> 这一章是本文的核心差异化内容。**90% 的期权亏损事故不是方向看错，而是不懂到期那几天的机制。** 请逐字读完。

## 2.1 平仓 vs 行权 vs 到期作废：99% 的情况你该「平仓」

你了结一个期权头寸有三条路：

| 方式 | 怎么操作 | 何时用 |
|---|---|---|
| **平仓 Close** | 反向下单（买开的就卖平，卖开的就买平） | **默认方式，占 99%** |
| **行权 Exercise** | 主动履行权利，换成 100 股股票 | 极少数：你真想要股票、或做除息套利 |
| **到期作废 Expire** | 什么都不做，虚值到期归零 | 虚值合约、且你确认不会被自动行权 |

**为什么几乎永远该平仓而不是行权？—— 一个算术**：

AAPL 现价 $260，你持有 250 Call，还剩 5 天到期，报价 $11（内在 $10 + 时间价值 $1）。

- **若你行权**：以 $250 买入 100 股，立刻价值 $260，赚 $10/股 = **$1000**。那 $1 时间价值**白白扔掉**。
- **若你平仓**：直接卖出这张 Call，拿到 $11×100 = **$1100**。

**行权 = 主动放弃剩余时间价值。** 只要合约还有时间价值，平仓永远优于行权。真想长期持股，也应"平仓拿现金 + 市价买股"，通常更划算且省一笔行权指派费。

**唯一例外**：做**除息套利**（2.2 节），或时间价值已≈0 且你确实要股票。

## 2.2 美式提前指派全解（卖方必修）

只有**你是卖方（义务仓）**才会"被指派 assignment"。买方是权利方，永远不会被指派。

**美式期权买方理论上可以在到期前任意一天行权**，但理性买方几乎只在一种情况下会**提前**行权 —— 提前行权 = 放弃时间价值，除非放弃的时间价值 **小于** 立刻行权能拿到的东西（股息或利息）。

### 短认购（Short Call）被提前指派 —— 除息前的必修课

**判断法则**：若你卖的实值 Call，其**剩余外在价值（时间价值）< 即将派发的每股股息**，则**除息日前一天极可能被指派**。

**机制**：Call 买方为了拿到股息，会在**除息日前一天（last day to capture dividend）**行权，把 Call 换成股票以吃到股息。他放弃时间价值，但换来更多的股息，划算。

**实例**：

> KO（可口可乐）现价 $70，将于明天除息，每股股息 $0.50。
> 你卖了一张 65 Call（实值），当前时间价值只剩 $0.20。
> Call 买方一算：行权拿股票能吃 $0.50 股息，只损失 $0.20 时间价值 → **净赚 $0.30，果断行权**。
> 结果：**你今晚被指派**，手上凭空多出 −100 股（你要按 $65 卖出 100 股给对方），并且你**不再持有 Call**。若你原本是备兑（持有 100 股 KO），那就是被 call away，股票没了、也吃不到那 $0.50 股息。

**规避**：
- 卖备兑 Call 时，**除息日前**检查你的实值 Call 时间价值是否 < 股息，是则**提前平仓或向外/向上展期**。
- 或直接**避开除息周**卖近月实值 Call。
- 记住：**只有实值 Call 才有除息指派风险**（虚值 Call 行权不划算，没人会干）。

### 短认沽（Short Put）被提前指派 —— 深度实值 + 利率

**机制**：当认沽**深度实值**、时间价值≈0，且**利率较高**时，Put 买方提前行权把 Put 换成"卖出股票拿现金"，可以提前拿到现金去吃利息（carry）。高利率环境下这更常见。

**实例**：某股现价 $40，你卖了 55 Put（深度实值 $15），时间价值只剩 $0.05。对方提前行权，你被指派**买入 100 股 @ $55**（立刻浮亏 $15/股），并占用 $5500 现金。

**规避**：不要长期持有**深度实值**的短认沽，时间价值快归零就平掉或展期。

### OCC 随机分配：你无法预测谁被指派

被指派不是"先卖先中"。流程是：买方向 OCC 提交行权 → OCC **随机**分配给某家券商 → 券商再按自己规则（随机或 FIFO）分配到某个客户账户。**所以你完全无法预测自己会不会被选中**，只能按"时间价值 < 股息/利息"这个概率法则防御。

### 垂直价差的短腿被指派怎么办？—— 别慌，长腿保护着你

初学者最怕："我做的是牛市认沽价差（卖 50 Put + 买 45 Put），结果 50 Put 短腿被指派了，我账户里突然多了 100 股股票 + 一笔负现金，会不会爆仓？"

**冷静，你的最大风险早已被长腿锁定**。处理：

- 短腿被指派 → 你被迫**买入 100 股 @ $50**（花 $5000，可能显示为保证金负现金）。
- 你手上**仍持有 45 Put 长腿**（保护仍在）。
- **正确操作**：第二天开盘，**卖出这 100 股**平掉股票头寸，**同时卖出 45 Put 长腿**（或直接行权长腿以 $45 卖出这 100 股）。整个价差按最大亏损（翼宽−权利金）了结，**和你开仓时就知道的最坏情况一模一样**，没有额外风险。
- 唯一的坑：若被指派发生在**周五收盘后**，你要**扛一个周末的 100 股敞口**（周一开盘前的跳空风险），且可能触发保证金警告。**所以到期周不要持有实值短腿过夜**，提前平掉价差。

> **黄金法则**：**到期周，任何实值的短腿都提前平仓/展期**，就能一劳永逸避开 99% 的指派麻烦。

## 2.3 到期日时间线（精确到分钟，美东时间 ET）

到期日（通常周五）那天发生这些事，按时间顺序：

```
09:30  开盘。你还能自由平仓。
      ↓
15:00  券商风控开始盯实值短腿 —— 可能对保证金不足账户强制平仓（每家阈值不同）
      ↓
16:00  股票市场收盘。个股/ETF 期权以此刻收盘价定实值/虚值。
      ↓
16:00-16:15  期权停止交易（多数标的 16:00，部分 ETF/指数到 16:15）
      ↓
17:30  OCC「自动行权」判定 + 你向券商提交「反向指令」的截止时间
      （券商通常设更早的内部截止，如 16:30-17:00，务必查你券商的 cutoff）
      ↓
（周末 / 次日）实值合约被自动行权、指派，股票 T+1 交割到账
```

### OCC 例外行权（Exercise-by-Exception，"$0.01 规则"）

**OCC 会自动行权所有到期时实值 ≥ $0.01 的期权**（不管你想不想要）。

后果举例：
- 你买的 Put 到期时实值 $0.01 → 被自动行权 → 你**卖出了 100 股股票**（若你没有这些股票 → 变成 100 股空头！周一要被强制买回 + 可能借券费）。
- 你卖的 Call 到期时实值 $0.03 → 你被指派 → 交出 100 股。

**如果你不想要这个自动行权结果**（例如你没有对应股票、或没有足够现金买入），你必须在券商截止时间前提交 **"Do Not Exercise（DNE）"** 反向指令 —— 但很多券商已不接受散户 DNE 指令，所以**最稳妥的做法是：到期日收盘前，把任何可能变成实值的头寸平掉。**

### Pin Risk（钉住风险）：收盘正好卡在行权价

**场景**：你卖了 50 Call，标的周五收盘**正好 $50.00**（或 $49.99 / $50.01 反复横跳）。

- 这张 Call 到底算实值还是虚值？**你不知道，OCC 和对手方也在赌**。
- 你可能**周一才发现**自己被指派了（或没有），于是周末**裸扛一个方向不明的 100 股敞口**：以为虚值作废，结果被指派了 −100 股，周一跳空高开就直接爆亏。

**规避**：**收盘接近行权价（ATM）的实值/边缘短腿，到期日务必主动平仓，不要赌 pin。** 花几美元买回，换一个安稳周末。

## 2.4 现金结算的世界（SPX / NDX / RUT）—— 为什么专业对冲用它

指数期权（SPX 等）是**欧式 + 现金结算**，这消灭了上面所有麻烦：

- **无提前指派**（欧式，到期前没人能行权）。
- **无 pin risk、无实物交割**：到期直接按结算价**现金找差**，多退少补，你账户里永远不会凭空出现 100 股或空头。
- **无周末裸股敞口**。

**代价 / 陷阱：AM 结算 vs PM 结算，这条踩错要命。**

| | **传统月度 SPX**（第 3 个周五那一批） | **周度/日度 SPXW** |
|---|---|---|
| 结算类型 | **AM 结算** | **PM 结算** |
| 最后交易日 | **到期前一天（周四）** | 到期当日（收盘） |
| 结算价 | 到期日**周五开盘**特殊价 **SET**（各成分股开盘价算出，非任何一个实际可交易价） | 到期日**收盘价** |
| 隐藏风险 | 你周四收盘还持仓 → 结算价由**周五开盘**决定 → **裸扛周四夜到周五开盘的跳空**，且 SET 你无法交易到 | 与收盘一致，所见即所得 |

**血泪教训**：很多人以为 SPX 月度"周五到期"，周四没平仓，结果周四晚上出了大新闻，周五开盘 SET 大幅低于周四收盘，**结算价把你按在最差的价格上，而你根本没机会在那个价成交**。

**结论**：
- 做 SPX 月度对冲/交易，**周四（最后交易日）就要处理仓位**。
- 怕 AM 跳空，就用 **PM 结算的 SPXW 周度合约**。
- 这也是为什么组合对冲宁用 SPX 不用 SPY：**没有提前指派、没有 pin risk、税务还占优**（第 10 章），只需管好 AM/PM 这一个点。

## 2.5 结算细节杂项

- **现金 vs 保证金账户**：现金账户被指派买股票必须**全额现金**，否则可能违规（good faith violation）。保证金账户可用保证金买入。
- **交割日 T+1**：股票行权/指派后，2024 年 5 月起美股股票交割为 **T+1**（次一交易日到账）。
- **费用**：行权/指派通常**免佣金**（多数券商），但可能收少量 OCC/监管费；主动行权部分券商收 exercise fee，这也是"平仓优于行权"的又一理由。

## 2.6 公司行为：合约会被调整，别被吓到也别占便宜

标的发生**拆股、合股、特别股息、并购、分拆**时，OCC 会调整你的合约（Memo 公告），可能改变**行权价、乘数、交割物**：

- **整数拆股（如 2:1）**：行权价减半、合约数翻倍，乘数仍 100，代码通常不变。
- **非整数拆股 / 特别股息 / 并购换股**：常变成**调整后合约**（根代码带数字后缀，如 `AAPL1`），乘数可能非 100，或交割物变成"若干股 + 若干现金 + 别家股票"。
- **看到调整后合约**：先去 OCC 查那份 memo 弄清"1 张现在到底代表什么"，**流动性通常极差，别新开仓**。

## 2.7 一页决策树：「我的持仓明天到期，我该干什么？」

```
明天到期的持仓
   │
   ├─ 是【买方】(long)？
   │     ├─ 实值(ITM)？
   │     │     ├─ 想要股票 & 有钱/有券 → 可让其行权（或平仓拿现金再买，通常更优）
   │     │     └─ 不想要股票 → ★ 必须今天平仓（否则被自动行权成 100 股/空头）
   │     └─ 虚值(OTM)？ → 大概率归零；有反弹博一把可留，否则平掉收回残值
   │
   └─ 是【卖方】(short)？
         ├─ 实值(ITM)？
         │     ├─ 想接货/被 call away 也认了 → 可让其指派
         │     └─ 不想被指派 → ★ 必须今天平仓 或 展期到下周期(第7章)
         │           └─ 若是除息周的实值短 Call → 今天就处理，防除息前夜被指派
         └─ 平值(ATM，pin risk)？ → ★ 主动平仓，别赌，别扛周末
         └─ 深度虚值(OTM)？ → 大概率作废；剩值很小可直接放到期，或花几分钱买回求安心
```

> **一句话总纲**：**到期周，凡是"实值"或"卡在行权价"的头寸，主动了结；只有明确深度虚值、或你真心想接受行权结果的，才放着不管。**

## 2.8 交易时段与盘后跳空敞口 —— 期权几乎没有盘前盘后夜盘

> 这是初学者最容易踩、也最疼的制度差异：**股票有盘前盘后，它的期权却没有。** 上面讲的指派、pin risk、自动行权，之所以那么难缠，根子就在这条。

### 各品种的可交易时段（美东 ET）

| 品种 | 常规时段 | 盘前 / 盘后 / 夜盘 |
|---|---|---|
| **个股期权**（AAPL/NVDA…） | **9:30–16:00** | ❌ **完全没有** |
| **ETF 期权**（SPY/QQQ/IWM…） | 9:30–**16:15**（多数 ETF 期权晚收 15 分钟） | ❌ 无 |
| **多数指数期权**（NDX/RUT…） | 9:30–16:15 | ❌ 常规为主 |
| **SPX / VIX / XSP** | Cboe **全球交易时段 GTH**，接近 **24×5 夜盘**（含隔夜、欧亚时段） | ✅ **有**（唯一像样的例外） |

> ⚠️ 具体分钟数各券商/各年会调整，**以你券商与 Cboe 当前公告为准**；但"个股与普通 ETF 期权没有盘前盘后夜盘"这条是稳定的市场结构。

### 核心陷阱：标的在动，你的期权却「停牌」

- **股票**：盘前 4:00–9:30、盘后 16:00–20:00 都能交易（部分券商还有隔夜）。
- **它的期权**：16:00（ETF 16:15）一到就**冻结**，要等次日 9:30 才能动。

这条差异制造了三个具体风险，正好串起本章前面所有内容：

1. **财报跳空无法对冲**：公司盘后 16:05 出财报暴跌 20%，你手里的 Call 眼睁睁看标的在盘后崩，**期权盘口却关着，一动不能动，只能扛到次日开盘一次性承接全部跳空**。→ 这就是为什么"财报周别裸持单腿"、要用**有限风险结构**（价差/领口，见第 5 章）。
2. **到期日的 Pin Risk / 自动行权**（2.3、2.7）：16:00 收盘定实值虚值，之后标的盘后还在动，但期权已停牌，**你无法再平仓避险** → 只能被动接受行权/指派结果。
3. **周末与隔夜敞口**：被指派后扛周末跳空（2.2），期权市场同样帮不了你——它周末、盘后都不开门。

### 券商层面的补充与实操结论

- 部分券商（如 IBKR，及陆续推"隔夜/延长时段"的平台）对**部分指数或 ETF 期权**提供延长交易，但**覆盖标的窄、流动性差、买卖价差宽**，散户实操价值有限。
- 想要真正的"夜盘调仓能力"，现实答案基本只有 **SPX / VIX（Cboe GTH）** —— 这也是它们除了现金结算、税优之外，被专业资金偏好的又一理由：**全球有事的夜里也能对冲**。

**一句话结论**：**做个股/ETF 期权，就要接受"16:00 之后到次日 9:30 你是裸露的"这个前提。** 凡是横跨财报、事件、周末、到期日的头寸，要么提前用有限风险结构包好，要么改用能夜盘交易的 SPX —— 别指望盘后能补救。

# 第 3 章　够用就好的定价直觉

不推 Black-Scholes 公式，只建立**做单需要的四个直觉** + 一张贵贱表。

## 3.1 时间价值衰减曲线：为什么「开 30–45 天、21 天前离场」

时间价值（Theta）不是匀速流逝，而是**越接近到期衰减越快**，最后一两周陡降（近似平方根加速）：

```
时间价值
 100% ┤●
      │ ●●
      │   ●●●
  50% ┤      ●●●●
      │          ●●●●●
      │               ●●●●●●●●
   0% ┼────────────────────────●► 到期
     90天   60天   45天   30天  21天  7天  0
                    └─卖方甜蜜区─┘  └陡降/Gamma雷区┘
```

**给卖方的两条实操**：
- **开仓选 30–45 天到期（DTE）**：这段衰减速度与风险的性价比最佳，是绝大多数卖方策略的标准起手。
- **21 DTE 前了结或展期**：进入最后 3 周，Gamma 风险（见下）陡升，时间价值也没剩多少油水，**赚钱效率变差、风险变大**，不值得为最后一点权利金扛尾部。

**给买方的一条**：**别买近月虚值**（"彩票"），它每天被 Theta 抽血；要买就买**够远的期限（60+ DTE）+ 实值一点（Delta 0.7+）**，减少时间价值损耗（这是 PMCC 的思想，见 5.6）。

## 3.2 IV / HV / IV Rank：卖方唯一的「贵贱表」

- **HV（历史波动率 Historical Vol）**：标的过去实际的波动。
- **IV（隐含波动率 Implied Vol）**：期权价格反推出的市场预期波动。**IV 高 = 权利金贵。**
- **光看 IV 数字没用**（30% 对科技股算低、对公用事业算高）。要看**相对自己历史**的位置：

| 指标 | 定义 | 怎么用 |
|---|---|---|
| **IV Rank（IVR）** | 当前 IV 在过去一年 [最低,最高] 区间中的百分位 | **卖方要 IVR > 30~50**；买方喜欢 IVR 低 |
| **IV Percentile** | 过去一年有多少比例的交易日 IV 低于今天 | 同上，更抗极端值 |

**口诀**：
- **IV 高（IVR 高）→ 权利金贵 → 当卖方**（卖 Put、卖价差、铁鹰…）。
- **IV 低（IVR 低）→ 权利金便宜 → 当买方**（买 Call/Put、买日历、买价差…）。
- **哪里看**：多数券商合约链有 IV 列；tastytrade、Market Chameleon、barchart 等可看 IVR。

## 3.3 四个希腊字母：把抽象变成人话

| 希腊字母 | 人话 | 买方 | 卖方 | 实操含义 |
|---|---|---|---|---|
| **Delta** | 标的涨 $1，期权涨多少；**也可当"到期实值概率"** | Call +，Put − | 相反 | Delta 0.30 ≈ 30% 概率被行权；也是"这张相当于多少股"（0.30=30 股等效） |
| **Theta** | 每过一天，期权价值变化 | **负**（每天亏） | **正**（每天赚） | 卖方的收租速度 |
| **Vega** | IV 涨 1%，期权价值变化 | **正**（喜涨 IV） | **负**（喜跌 IV） | 为什么卖方要在高 IV 时卖 |
| **Gamma** | Delta 变化的加速度 | 正（有利） | **负**（有害） | 越近到期、越 ATM，Gamma 越大 → 卖方到期周的风险来源 |

**最该内化的两句**：
1. **Delta 当概率用**：卖 Delta 0.30 的 Put，约七成概率白赚权利金。选行权价就是选概率。
2. **卖方是「正 Theta、负 Vega、负 Gamma」的组合**：靠时间和 IV 下降赚钱，怕的是标的剧烈快速运动（Gamma 雷）。所以卖方要**高 IV 进场、21 天前离场、分散、控仓**。

## 3.4 波动率偏斜与期限结构：为什么认沽比认购贵

- **偏斜（Skew）**：同一到期，**低行权价（下方）Put 的 IV 通常高于上方 Call** —— 因为市场更怕暴跌，愿为下行保险多付钱。这叫"put skew"。
  - **应用**：卖 Put 收的 IV 溢价通常比卖 Call 高（下行险贵）；风险逆转（卖贵 Put 买便宜 Call）利用的就是它。
- **期限结构（Term Structure）**：正常情况远月 IV > 近月（时间越长越不确定）；但**财报/事件前，近月 IV 会异常高企**（事件集中在近月），形成"倒挂"。
  - **应用**：财报前近月 IV 暴涨 → 事件一过 IV 崩塌（IV Crush），这是日历/双日历策略和"别在财报前买跨式"的根本原因。

## 3.5 IV Crush 的数量级：为什么「买对方向仍然亏钱」

财报是初学者最大的绞肉机。看一个典型数字：

> 某股财报前 $100，近月 ATM 跨式（Call+Put）报价 $8（IV 60%，隐含 ±8% 波动）。
> 财报出来，股票涨 **+6%** 到 $106 —— **方向猜对了！**
> 但财报落地 IV 从 60% 崩到 25%（IV Crush），你的 105 Call 从 $4 只值 $2.5。
> **你方向对了却亏钱**，因为 6% 的实际波动 **小于** 市场之前定价的 8%。

**教训**：财报前**买单腿期权**，等于赌"实际波动 > 市场已定价的波动"，赔率天然不利。要玩事件，用**卖方**（收 IV 溢价）或**日历/双日历**（做多 IV crush 后的前月低价）等结构，见 6.6。

# 第 4 章　单腿策略

> 每个策略统一 **8 段式**：构造 / 场景 / 损益图 / 数字实例 / 希腊字母 / 管理规则 / 常见错误 / Checklist。

## 4.1 买入认购（Long Call）

**① 构造**：买入 1 张 Call，付权利金（借记）。方向：坚定看涨。

**② 场景**
- ✅ 强催化在前（新品、财报后趋势确立、突破关键位）、且 **IV 不高（IVR 低）**
- ✅ 想用**有限风险**博取大涨，替代直接买 100 股以减少占用资金
- ❌ IV 高企时（财报前）买 → 大概率 IV crush 挨刀
- ❌ 买深度虚值近月"彩票" → 大概率 Theta 归零
- ❌ 拿它当"我看不准所以买个 Call 试试" → 方向不明别用借记

**③ 损益图**：见 1.1（最大亏损=权利金，上不封顶）。

**④ 数字实例（个股，美式）**
> NVDA 现价 $180，看涨未来 2 个月。买 **185 Call，45 DTE**，Delta 0.42，权利金 **$7.00** → 付 **$700**。
> - 盈亏平衡 = 185 + 7 = **$192**（要涨 6.7% 才回本）
> - 涨到 $210：Call 至少值 210−185 = $25 内在 → 盈利约 **+$1800**（+257%）
> - 到期 ≤ $185：Call 归零，**亏光 $700**
> - 涨到 $192：打平

**⑤ 希腊字母**：+Delta（涨得利）、−Theta（每天流血）、+Vega（喜涨 IV）、+Gamma（加速有利）。

**⑥ 管理规则（照抄）**
1. **盈利 50~100% 分批止盈**，别做梦到期归零式满仓死拿。
2. **21 DTE 前**若没方向兑现 → 平仓换月，别让 Theta 加速吃你。
3. **止损**：跌破关键支撑或亏损达权利金 50% → 认错。
4. 想降成本 → 升级成**牛市认购价差**（5.1）或 **PMCC**（5.6）。

**⑦ 常见错误**：财报前买（IV 高）、买太近太虚（Theta+低概率）、方向不坚定却用借记、赚了不跑幻想翻十倍。

**⑧ Checklist**
- [ ] IVR 偏低（权利金不贵）？
- [ ] 有明确催化 + 时间窗匹配 DTE（留足 45+ 天）？
- [ ] Delta ≥ 0.40（别买纯彩票）？
- [ ] 已设 50~100% 止盈与 50% 止损？

## 4.2 现金担保卖出认沽（Cash-Secured Put）★ 全文样例策略

**① 构造**：卖出 1 张 Put（信用），账户预留**足额现金 = 行权价×100** 备接货。方向：中性偏多、愿低位接货。

**② 场景**
- ✅ 你**本来就想买**这只标的，觉得现价略贵，想更低接货 → 等待期白拿权利金
- ✅ 标的刚恐慌大跌、**IV 飙高**但你判断基本面没坏（IV 高=保费贵=卖方有利）
- ✅ 震荡市，ETF 在箱体下沿
- ❌ 根本不想持有的票（被指派就砸手里）
- ❌ 单边下跌趋势"接飞刀"（权利金盖不住 20% 下跌）
- ❌ 财报前卖近月（除非专门赌 IV crush）
- ❌ 现金不够去**裸卖** → 那是另一个风险等级

**③ 损益图**
```
 损益
  +收 ┤              ┌──────────  ← 到期≥行权价：赚满权利金
    0 ┼────────┬────╱ ─ ─ ─ ─
      │       ╱↑平衡=行权价−权利金
      │      ╱
      │    ╱   ← 跌破平衡后，等同持股 100 股同步亏损
      └──┴────┴──────► 到期标的价
        行权价
```

**④ 数字实例（ETF，美式，会分红→注意除息指派）**
> QQQ 现价 $480，你愿 $460 接货。卖 **460 Put，35 DTE**，Delta −0.28，权利金 **$6.50** → 收 **$650**。备现金 **$46,000**。
> - 盈亏平衡 = 460 − 6.5 = **$453.5**
> - 到期 ≥ $460：Put 作废，**+$650**（650/46000 ≈ 1.4%/月 ≈ 17% 年化）
> - 到期 $453.5：打平
> - 到期 $440：被指派买入 100 股 @ $460，实际成本 $453.5，浮亏 **−$1,350**（但比 $480 直接买少亏 $1,650）
> - ⚠️ QQQ 季度分红，**除息日前**若这张 Put 变实值且时间价值 < 股息，理论上有被提前指派风险（Put 的除息提前指派较少，但深度实值+高息要留意）。

**⑤ 希腊字母**：+Delta（涨得利）、+Theta（收租）、−Vega（喜 IV 降）、−Gamma（怕急跌）。

**⑥ 管理规则**
1. **止盈 50%**：权利金剩一半就买回（如收 $650，剩 $325 时平，落袋 $325），别死等到期。
2. **21 DTE 闸门**：没止盈就平仓/展期到下月。
3. **被指派** → 转**备兑 Call**（4.3），进入 **Wheel** 循环（8.1）。
4. **展期**：跌破行权价仍看多 → 买回本月、卖出下月更低行权价，力求**净收权利金**。
5. **仓位**：以"全部被指派我掏得出接货钱"倒推张数。

**⑦ 常见错误**：只看权利金高选合约（高往往因 Delta 大/要出事）、卖不想要的票、卖太远月（Theta 慢、占资久）、忘记财报/除息、用保证金裸卖而不自知。

**⑧ Checklist**
- [ ] 愿在行权价接货并长期持有？
- [ ] IVR > 30？
- [ ] 避开财报/除息？
- [ ] 张数×行权价×100 ≤ 可动用现金？
- [ ] Delta 在 0.15~0.35（保守区）？
- [ ] 设了 50% 止盈 + 21 天闸门？

## 4.3 备兑开仓（Covered Call）

**① 构造**：持有 ≥100 股标的，**每 100 股卖出 1 张 Call**（信用）。方向：中性/温和看涨，愿在行权价卖出（被 call away）。

**② 场景**
- ✅ 已长期持股、判断短期涨不动 → 卖 Call 收租增强收益
- ✅ 想在某高位"挂单卖出"股票，顺便先收一笔权利金（变相高位限价 + 补贴）
- ✅ 高 IV 时（权利金厚）
- ❌ 强烈看涨、舍不得被 call away 的核心票（上涨被封顶）
- ❌ 卖太低行权价（Delta 太大）→ 大概率被 call away 且封杀上涨
- ❌ **除息周卖实值 Call** → 除息前夜被指派、股票没了还吃不到股息（见 2.2）

**③ 损益图**
```
 损益
  +收 ┤        ┌───────────  ← 涨过行权价：股票被以行权价卖出，收益封顶=(行权价−成本)+权利金
      │       ╱
    0 ┼──────╱────────────
      │     ╱  ← 下跌时权利金只是薄垫子，股票继续亏
      │    ╱
      └───┴──────────────► 标的价
        成本
```

**④ 数字实例（个股，美式）**
> 你持 100 股 AAPL，成本 $240，现价 $255。卖 **270 Call，30 DTE**，Delta 0.30，权利金 **$4.00** → 收 **$400**。
> - 到期 ≤ $270：Call 作废，**白赚 $400**（继续持股，可再卖下月）
> - 到期 $280：被 call away，以 $270 卖出 → 股票赚 (270−240)=$3000 + 权利金 $400 = **+$3,400**，但**放弃了 280 以上的涨幅**
> - 下跌到 $240：股票浮亏 $1,500，权利金 $400 抵一部分 → 净 **−$1,100**
> - ⚠️ AAPL 除息周若这张 Call 变实值 → 检查时间价值 vs 股息，防提前指派。

**⑤ 希腊字母**：整体 +Delta（但比纯持股小，被 Call 压低）、+Theta、−Vega、−Gamma。

**⑥ 管理规则**
1. 卖 **Delta 0.20~0.30** 的 Call（被 call away 概率低、又有像样权利金）。
2. **止盈 50~80%** 买回，或到期作废后滚动再卖（这就是持续收租）。
3. 股价冲向行权价、又不想被 call away → **向上向外展期**（买回本月、卖下月更高行权价，7.4）。
4. **除息日历要标注**，除息前处理实值短 Call。
5. 接受"被 call away 是好结局"（本就想在那价卖），别在被 call away 后追高懊悔。

**⑦ 常见错误**：卖在成本价下方的行权价（一旦被 call 就锁定亏损）、核心成长股乱卖 Call 削上涨、忽略除息、把备兑当"稳赚"而忽视下跌里权利金只是薄垫。

**⑧ Checklist**
- [ ] 持有 ≥100 股整数倍？
- [ ] 行权价高于成本、且是我愿意卖出的价？
- [ ] Delta 0.20~0.30、避开除息/财报？
- [ ] IVR 偏高（权利金值得卖）？

## 4.4 保护性认沽（Protective Put）—— 给持仓买保险

**① 构造**：持有 100 股，**买入 1 张 Put**（借记）对冲下行。方向：长期看多但怕短期黑天鹅。

**② 场景**
- ✅ 有大额浮盈想锁定、又不想卖出（税务/看长）→ 买 Put 保底
- ✅ 财报/重大事件前，怕跳空但想留在场内
- ✅ 市场系统性风险升温，给核心持仓上保险
- ❌ 长期常态化买保险 → **保费拖累累积**，长期跑输（保险是应急，不是日常）
- ❌ IV 极高时买保护 → 保费太贵，可改用领口（4 章末/5.3）分摊成本

**③ 损益图**：持股的下方被 Put 托住，形同"股票 + 地板"。
```
 损益
      │        ╱ ← 上涨：跟随股票，只少赚了保费
    0 ┼──────╱────────
      │  ___╱  ← 下方被 Put 锁定：最大亏损 = (成本−行权价)+保费
      └──┴──────────► 标的价
       Put行权价
```

**④ 数字实例（个股，美式）**
> 持 100 股 TSLA，成本/现价 $300，财报在即怕跳空。买 **280 Put，30 DTE**，权利金 **$9.00** → 付 **$900**。
> - 无论跌多深，你可 $280 卖出 → **最大亏损锁定 = (300−280)+9 = $29/股 = $2,900**
> - 涨到 $350：股票赚 $5,000 − 保费 $900 = **+$4,100**（保险到期作废）
> - 相当于花 3%（900/30000）买 30 天"跌破 $280 就止损"的保险。

**⑤ 希腊字母**：整体仍 +Delta（比纯持股小）、−Theta（保费流逝）、+Vega、+Gamma（下行保护随波动增强）。

**⑥ 管理规则**
1. 行权价选在你**能承受的最大回撤位**（如 −7%~−10%），越接近现价越贵。
2. 事件结束、风险解除 → **卖出 Put 收回残值**，别让它白白 Theta 归零。
3. 觉得保费太贵 → 转 **领口 Collar**（卖个上方 Call 补贴保费，5.3），或用 **Put 价差**降本（放弃极端下行保护）。
4. 保护性 Put 是**成本**不是盈利来源，心态上当买车险。

**⑦ 常见错误**：常年买保险拖垮收益、行权价买太远（保护形同虚设）、事件过了忘卖回残值、IV 高位硬买贵保险。

**⑧ Checklist**
- [ ] 确有短期尾部风险值得花这笔保费？
- [ ] 行权价 = 我能承受的最大回撤？
- [ ] 事件后有卖回/转领口的计划？
- [ ] 保费占比可接受（一般 < 持仓的 2~4%/月）？

# 第 5 章　两腿方向性策略

从这章开始进入 **Level 3 价差世界**：用第二条腿把"无限风险"或"高昂成本"锁死，是个人投资者最该长期主用的区域。

## 5.1 牛市价差（Bull Call Spread / Bull Put Spread）—— 温和看涨的主力工具

**同一到期，一高一低两个行权价**，实现"有限成本、有限收益"的看涨。两种造法，风险收益等价，区别在借记还是信用：

| | **牛市认购价差（借记）** | **牛市认沽价差（信用）** |
|---|---|---|
| 造法 | 买低行权价 Call + 卖高行权价 Call | 卖高行权价 Put + 买低行权价 Put |
| 现金流 | 付出净权利金（Debit） | 收到净权利金（Credit） |
| 何时选 | **IV 低**时（买方视角，权利金便宜） | **IV 高**时（卖方视角，收 IV 溢价） |
| 最大盈利 | 翼宽−净借记 | 净信用 |
| 最大亏损 | 净借记 | 翼宽−净信用 |
| 到期最优 | 涨过高行权价 | 涨过高行权价（或维持在其上） |

**① 场景**
- ✅ 温和看涨（有目标位，不指望翻倍），想比裸买 Call **降本、抗 Theta、抗 IV crush**
- ✅ IV 高 → 优先用**信用版（Bull Put）**；IV 低 → 用**借记版（Bull Call）**
- ❌ 极度看涨博暴涨（价差封顶了收益，不如裸 Call）
- ❌ 方向不明（价差仍是方向性策略）

**② 损益图（牛市认购价差）**
```
 损益
 +最大┤        ┌────────  ← 涨过高行权价：锁定最大盈利
      │       ╱
    0 ┼────┬─╱────────
      │   ╱↑平衡
 -最大┤──┘  ← 跌破低行权价：亏光净借记（有限）
      └──┴──┴────────► 标的价
       低K  高K
```

**③ 数字实例（个股，美式，借记版）**
> AMD 现价 $170，看涨到 $185。**买 170 Call + 卖 185 Call，45 DTE**。170 Call 付 $8，185 Call 收 $3 → 净借记 **$5.00**（付 $500）。翼宽 $15。
> - 最大盈利 = 15 − 5 = **$1,000**（涨过 $185，+200%）
> - 最大亏损 = **$500**（跌破 $170）
> - 盈亏平衡 = 170 + 5 = **$175**
> - 对比裸买 170 Call（付 $800）：价差少赚极端涨幅，但成本从 $800 降到 $500，盈亏平衡从 $178 降到 $175，抗跌抗 Theta 都更好。

**④ 希腊字母**：+Delta、Theta/Vega 被两腿部分抵消（比单腿温和），风险被牢牢框定。

**⑤ 管理规则**
1. **信用版**：止盈 50% 买回；**借记版**：盈利 50~80% 了结。
2. **21 DTE** 前处理，别在到期周扛"一腿实值一腿虚值"的指派风险（见 2.2 价差被指派处理）。
3. 到期周若整个价差深度实值 → 直接平仓，别让两腿分别行权/指派产生手续费和周末敞口。
4. 方向走反 → 认净亏（有限），或视情况滚到下月/下移行权价。

**⑥ 常见错误**：翼宽选太宽变成接近裸买、到期周不平仓被单腿指派、IV 高还用借记（该用信用）、把最大盈利当"一定拿得到"（要涨过高行权价才满额）。

**⑦ Checklist**
- [ ] 有明确目标位（决定高行权价）？
- [ ] IV 高→信用版 / IV 低→借记版，选对了？
- [ ] 最大亏损（净借记 or 翼宽−信用）在可接受范围？
- [ ] 计划 21 DTE / 50% 止盈了结？

## 5.2 熊市价差（Bear Put / Bear Call Spread）—— 温和看跌

牛市价差的镜像。**温和看跌**用它替代裸买 Put 或裸卖 Call。

| | **熊市认沽价差（借记）** | **熊市认购价差（信用）** |
|---|---|---|
| 造法 | 买高行权价 Put + 卖低行权价 Put | 卖低行权价 Call + 买高行权价 Call |
| 现金流 | 付净借记 | 收净信用 |
| 何时选 | IV 低时看跌 | **IV 高时看跌/看不涨**（很常用） |
| 最大盈利 | 翼宽−借记 | 净信用 |
| 最大亏损 | 净借记 | 翼宽−净信用 |

**数字实例（信用版，个股）**
> SPY 现价 $600，你认为涨不过 $615。**卖 615 Call + 买 625 Call，40 DTE**，收净信用 **$3.00**（$300）。翼宽 $10。
> - 最大盈利 = **$300**（到期 ≤ $615，SPY 不涨过去就赢）
> - 最大亏损 = 10 − 3 = **$700**（涨过 $625）
> - 盈亏平衡 = 615 + 3 = $618
> - **信用版胜率结构**：只要 SPY 不涨过 $615 就全赢，横盘/下跌都赚 —— 这是"卖方 + 有限风险"的甜点。

**管理**：信用版止盈 50%；受测边（标的逼近卖出腿）→ 展期或认账；到期周实值短腿务必平仓防指派。

## 5.3 领口（Collar）—— 近乎零成本对冲大额持仓

**① 构造**：持有 100 股 + **买入下方保护 Put** + **卖出上方 Call**（用 Call 权利金补贴 Put 保费）。=（保护性 Put）+（备兑 Call）的合体。

**② 场景**
- ✅ 有**大额浮盈持仓**想锁定下行、又不想卖出（税务/长期）→ 领口几乎零成本上保险
- ✅ 财报/事件前对核心持仓做低成本护栏
- ❌ 强烈看涨的票（Call 封顶上涨）
- ❌ 想赚波动的场景（领口把股票锁成一个盒子）

**③ 损益图**：股票被**锁在 [Put行权价, Call行权价] 的盒子**里。
```
 损益
      │      ┌──────  ← 涨过 Call行权价：收益封顶
    0 ┼────┬─┘
      │ ___╱  ← 跌破 Put行权价：亏损封底
      └─┴──┴──────► 标的价
       Put  Call
```

**④ 数字实例（个股，美式）**
> 持 100 股 GOOGL，成本 $150，现价 $200（浮盈 $5,000），想保住利润过财报。
> **买 190 Put 付 $5 + 卖 215 Call 收 $4** → 净成本 **$1.00**（$100）。
> - 下方锁定：跌破 $190 也能 $190 卖出 → 最差仍锁 (190−150)−1 = **+$3,900** 利润
> - 上方封顶：涨过 $215 被 call away → (215−150)−1 = **+$6,400** 封顶
> - 盒子内（190~215）：随股价，利润在 3900~6400 间
> - 花 $100 把 $5,000 浮盈保护成"最少赚 3900、最多赚 6400"。

**⑤ 管理**：Call/Put 行权价按"能接受的顶和底"选；事件后可拆掉领口恢复纯持股；除息周注意上方实值 Call 的指派（可能被 call away 提前）。

**⑥ 常见错误**：Call 卖太近（轻易被 call away 削掉上涨）、把领口用在核心成长股、忘了这是"锁定"不是"赚更多"。

**⑦ Checklist**：大额浮盈 / 想低成本锁定 / 接受上涨封顶 / 行权价=可接受的顶和底。

## 5.4 合成多头与风险逆转（Synthetic Long / Risk Reversal）

**① 构造**：**买入 Call + 卖出 Put（同到期）**。
- 同行权价 = **合成多头**（损益几乎复制 100 股股票，占用保证金远小于买股）。
- Call 行权价 > Put 行权价 = **风险逆转**（利用 put skew，常可零成本甚至净收权利金地做多）。

**② 场景**
- ✅ 强烈看涨，想用**极小资金**获得接近持股的 Delta（资金效率）
- ✅ 认为下方 Put 太贵（skew 高）→ 卖 Put 收贵保费、买便宜 Call 博上涨
- ❌ 初学者慎用：**下方风险等同持股甚至更陡**（卖 Put 那腿=愿接货），需要 Level 3/4 与足额资金
- ❌ 高波动垃圾股（下行深不见底）

**③ 损益图**：几乎就是一条 45° 直线（像持股），下方随股票同步亏。

**④ 数字实例（个股，美式，风险逆转）**
> META 现价 $700，强烈看涨且认为下方 Put 贵。**卖 660 Put 收 $18 + 买 740 Call 付 $16**，45 DTE → **净收 $2.00**（倒收 $200）。
> - 涨过 $740：跟随股票上涨，几乎无限
> - $660~$740 之间：赚那 $200 净权利金
> - 跌破 $660：被指派买入 100 股 @ $660（等同 $660 接货），下方风险与持股相当
> - 用极小净成本获得"$740 以上全吃、$660 以下才接货"的看涨敞口。

**⑤ 希腊字母**：+Delta（接近 +1.0，像股票）、Theta/Vega 视行权价而定。

**⑥ 管理 / 错误**：把它当"便宜的股票"但记住**下行是实打实的持股风险**；仓位按"Put 被指派要接 100 股"倒算；别在你不愿持有的票上做。

**⑦ Checklist**：强看涨 / 愿在 Put 行权价接货 / 有足额资金或保证金 / 理解下行≈持股。

## 5.5 对角价差（Diagonal Spread）—— 方向 + 时间的组合

**① 构造**：**买入远月**期权 + **卖出近月**不同行权价期权（同为 Call 或同为 Put）。是"日历价差（同行权价）"的方向性版本，也是 **PMCC 的骨架**。

**② 直觉**：用**远月**长腿提供方向敞口（Theta 衰减慢），用**近月**短腿反复收租（Theta 衰减快）补贴长腿成本 —— **让别人的时间价值帮你付长腿的钱**。

**③ 场景**：温和看涨（Call 对角）/ 温和看跌（Put 对角）、想持续收租降本、IV 期限结构合适（近月相对贵）。

**④ 数字实例**：见下节 PMCC（Call 对角的典型形态）。

## 5.6 PMCC 穷人的备兑（Poor Man's Covered Call）★ 高频实战

**① 构造**：**买入远月深实值 Call（代替 100 股）** + **卖出近月虚值 Call（收租）**。用一张长 Call 冒充"100 股"，成本只有买股的零头。

**② 场景**
- ✅ 看好某股中长期、但**不想压上买 100 股的资金**（如 NVDA 100 股要 $18,000，PMCC 可能只要 $3,000）
- ✅ 想跑"备兑收租"逻辑但资金有限
- ❌ 高波动垃圾股（长 Call 时间价值损耗 + 方向崩了亏得比备兑还狠）
- ❌ 不懂管理"短腿被行权时长腿够不够覆盖"的人

**③ 关键构造纪律**
- 长腿：**Delta ≥ 0.80、90~180+ DTE**（越深实值、越远月，越像股票、时间价值损耗越小）。
- 短腿：**Delta 0.20~0.30、30~45 DTE**，反复卖。
- **翼宽纪律**：短 Call 行权价 − 长 Call 行权价 应 **> 你付的净借记**，否则短腿被行权时可能亏损（这是 PMCC 唯一的隐藏坑）。

**④ 数字实例（个股，美式）**
> NVDA 现价 $180。
> 长腿：买 **150 Call，120 DTE**，Delta 0.82，付 **$38**（$3,800，代替 $18,000 的 100 股）。
> 短腿：卖 **195 Call，35 DTE**，Delta 0.28，收 **$5**（$500）。
> - 净成本 $3,300；翼宽 195−150 = $45 > 净借记 $33 ✅（安全）
> - 短腿到期 ≤ $195：收 $500 白赚，继续卖下月（相当于每月给 $3,800 本金收 ~13% 月租的节奏）
> - 涨到 $200：短腿实值被要求交股，但你的长 150 Call 早已深度实值可覆盖 → 锁定 (195−150)+ 已收租 − 净借记的盈利
> - NVDA 跌到 $150：长腿大幅缩水（这是最大风险），短腿作废收租略作缓冲
> - ⚠️ 短 Call 除息周变实值 → 防提前指派（同备兑），必要时展期。

**⑤ 管理**：短腿滚动（作废/50% 止盈就再卖）；长腿到 45~60 DTE 或 Delta 掉太多时换更远月；方向崩了整体止损。

**⑥ 常见错误**：翼宽 < 净借记（被行权即亏）、长腿买太虚/太近（损耗大、不像股票）、在垃圾股上做、短腿卖太近行权价频繁被穿。

**⑦ Checklist**：长腿 Delta≥0.8 且远月 / 短腿 Delta 0.2~0.3 / 翼宽 > 净借记 / 中长期看好且愿滚动管理。

## 5.7 股票修复策略（Stock Repair）—— 套牢不加钱，回本点砍半

**① 构造**（针对已下跌的持仓）：持有 100 股（已浮亏）+ **买入 1 张 ATM Call + 卖出 2 张更高行权价 Call**（1×2 认购比例价差），通常**零成本或极小成本**建立。

**② 直觉**：不追加资金，用期权把"回本需要涨的幅度"**大约减半**。代价：涨过上方行权价后，收益被封顶（那两张卖出的 Call 覆盖了你的股票）。

**③ 场景**：温和反弹预期下的**解套工具**（你认为会涨回来一部分，但不会暴涨）；不适合"要么暴涨要么继续跌"的判断。

**④ 数字实例（个股，美式）**
> 你 $100 买了 100 股 XYZ，现跌到 $80（浮亏 $2,000）。判断能反弹到 $90 附近但难回 $100。
> **买 1 张 80 Call + 卖 2 张 90 Call，60 DTE**，构造成**净成本≈0**。
> - 涨回 $90：股票赚回 $1,000（80→90）+ 那张 80 Call 也赚 $1,000 → **合计 +$2,000，正好回本**（而纯持股只赚回 $1,000，还差 $1,000）。你把回本点从 $100 降到了约 **$90**。
> - 涨过 $90：两张短 Call 开始交股（一张被你长 Call 覆盖，另一张被 100 股覆盖）→ **收益封顶在回本附近**，不再多赚。
> - 继续跌破 $80：和纯持股一样继续亏（没额外成本，但也没保护下行）。

**⑤ 管理 / 错误**：只在"温和反弹"判断下用；封顶是代价（别指望暴涨）；下行无保护（不是对冲工具）；净成本尽量做到≤0。

**⑥ Checklist**：已套牢 / 判断温和反弹 / 接受回本即止盈封顶 / 构造净成本≈0。

# 第 6 章　中性与波动率策略

这章是"不赌方向、赌波动 / 赌区间"的世界。**大部分是卖方（收 Theta），少数是买方（做多波动）**。中性策略特别适合用**指数期权（SPX，欧式现金结算）**做，省掉指派与 pin risk 的所有麻烦（见 2.4）。

## 6.1 卖出跨式 / 宽跨式（Short Straddle / Strangle）—— 高胜率、亏起来要命

**① 构造**
- **跨式 Straddle**：同一行权价（ATM）**卖 Call + 卖 Put**。
- **宽跨式 Strangle**：卖**虚值 Call + 虚值 Put**（更宽区间、权利金少些、胜率更高）。
- 赌：标的在到期前**待在一个区间内**，两腿一起 Theta 衰减。

**② 场景**
- ✅ **高 IV（IVR > 50）** + 判断标的将横盘/波动收敛（如财报后 IV 高但事件已过）
- ✅ 用**指数（SPX）**做，无指派/无 pin risk，最干净
- ❌ **裸卖，风险巨大**：Call 端理论无限、Put 端到 0，**新手别单独裸做**，务必用铁鹰/铁蝶（下节）加保护腿
- ❌ 财报/事件**前**卖（除非你专门赌事件后收敛，且已用有限风险结构）
- ❌ 低 IV 时卖（收的权利金不够覆盖风险）

**③ 损益图（宽跨式）**
```
 损益
  +收┤   ┌────────┐   ← 待在区间内：赚两腿权利金
    0┼──╱┴────────┴╲──
     │ ╱            ╲
  -∞ ┤╱  (跌穿/涨穿都放大亏损，Call端无上限)
     └┴──┴────────┴┴─► 标的价
     下平衡 PutK  CallK 上平衡
```

**④ 数字实例（指数 SPX，欧式现金结算 —— 演示"无指派"的优雅）**
> SPX 现价 5,000，IVR 高，判断未来一月宽幅震荡。**卖 5,200 Call + 卖 4,800 Put，40 DTE（用 SPXW）**，两腿共收 **$60**（×100 = **$6,000**）。
> - 到期 4,800~5,200 之间：两腿作废，**+$6,000**（现金直接入账，无任何股票交割）
> - 上盈亏平衡 = 5,200 + 60 = 5,260；下 = 4,800 − 60 = 4,740
> - 到期 5,400：Call 端结算亏 (5,400−5,200)−60 = $140 ×100 = **−$14,000**（现金找差，无需交股）
> - **欧式优势**：全程无提前指派、无 pin risk，到期前想跑随时平仓，只有到期日按结算价现金清算。

**⑤ 希腊字母**：Delta≈0（中性）、**+Theta（核心利润源）**、**−Vega（怕 IV 涨）**、**−Gamma（怕大幅快速运动）**。

**⑥ 管理规则（卖波动率的生命线）**
1. **止盈 25~50%**：收 $6,000，赚到 $3,000 就跑（卖跨式尤其要早跑，别贪到期）。
2. **受测边调整**：一边被逼近 → 把没被测的那腿**向标的方向移近**收更多权利金，或整体展期。
3. **21 DTE / Gamma 雷区前离场**。
4. **务必控仓**：单个头寸名义敞口占净值比例要小到"最坏情况砸不垮账户"。
5. 新手：**永远加保护腿变成铁鹰/铁蝶**，不要裸卖。

**⑦ 常见错误**：裸卖不设保护、低 IV 卖、财报前卖近月、赚了不跑扛到尾部、仓位过重一次回撤打回原形（这是卖波动率爆仓的头号死因）。

**⑧ Checklist**：IVR>50 / 判断震荡 / 用指数或加保护腿 / 25~50% 止盈 / 仓位极度克制。

## 6.2 铁鹰式（Iron Condor）—— 震荡市的主力收租机

**① 构造**：**熊市认购价差 + 牛市认沽价差** 的组合 = **卖宽跨式 + 上下各买一腿保护**。四条腿、有限风险、收净信用。赌标的待在中间宽区间。

**② 场景**
- ✅ **高 IV + 判断区间震荡**，想要"卖跨式的收租 + 有限风险"
- ✅ 指数（SPX）上做最舒服（现金结算）
- ✅ 想要高胜率、可承受"偶尔大亏一次翼宽"的收益形态
- ❌ 强趋势市（不断被一边穿）、低 IV（信用太薄）、财报前近月（除非专门结构）

**③ 损益图**
```
 损益
 +收┤    ┌────────┐    ← 中间区间：赚净信用（最大盈利）
   0┼──┬─┘        └─┬──
    │  │            │
-最大┤──┴─          ─┴── ← 穿破任一外侧保护腿：亏损封顶=翼宽−净信用
    └┴─┴──────────┴─┴─► 标的价
   买P 卖P        卖C 买C
```

**④ 数字实例（指数 SPX，欧式）**
> SPX 5,000，IVR 高，判断月内 4,700~5,300 震荡。
> **买 4,650 Put / 卖 4,750 Put / 卖 5,250 Call / 买 5,350 Call，40 DTE**。翼宽各 $100。
> 净收信用 **$30**（×100 = **$3,000**）。
> - 最大盈利 = **$3,000**（到期 4,750~5,250 之间，四腿全作废）
> - 最大亏损 = (100−30)×100 = **$7,000**（穿破 4,650 或 5,350）
> - 胜率结构：只要 SPX 到期落在 4,750~5,250（±5%）就全赢，宽区间 → 高胜率
> - 典型盈亏比：赚 3000 概率高，亏 7000 概率低 —— **靠高胜率累积，怕的是一次趋势行情打穿一边**。

**⑤ 管理规则**
1. **止盈 50%**（收 3000，赚 1500 就走）。
2. 一边被测 → 把**未被测的价差向中间移**（roll in），多收权利金 / 或整体展期到下月。
3. **21 DTE 前**处理。
4. 用**指数**避免指派；若用个股/ETF，到期周实值短腿务必平仓（防 2.2 的指派）。

**⑥ 常见错误**：翼太窄（信用薄、频繁触及）、趋势市里硬做、低 IV 开仓、不止盈扛到打穿、一次亏损=好几个月利润却不控仓。

**⑦ Checklist**：IVR 高 / 判断区间 / 短腿 Delta 约 0.15~0.20（定区间宽度）/ 50% 止盈 / 用指数或管好指派。

## 6.3 铁蝶式（Iron Butterfly）—— 更集中的收租

**① 构造**：卖 **ATM Call + ATM Put**（同行权价，像卖跨式），上下各买一保护腿。相当于**收窄版铁鹰**：权利金更厚、但盈利区间更窄、胜率更低。

**② 场景**：判断标的会**紧紧钉在某个价位**附近（比铁鹰更笃定）、高 IV。适合有明确"磁吸位/大量 OI 钉住位"的判断。

**③ 数字实例（指数 SPX）**
> SPX 5,000，判断到期紧贴 5,000。**买 4,900 Put / 卖 5,000 Put / 卖 5,000 Call / 买 5,100 Call**。翼宽 $100。
> 净收信用 **$60**（$6,000，比铁鹰厚）。
> - 最大盈利 = **$6,000**（到期正好 5,000）
> - 最大亏损 = (100−60)×100 = **$4,000**（穿破 4,900 或 5,100）
> - 盈亏平衡 = 5,000 ± 60 → 4,940~5,060（窄）
> - 权利金厚、亏损小，但**要 SPX 精准落在窄区间才满额**，胜率低于铁鹰。

**④ 管理/错误/Checklist**：同铁鹰，但更强调"止盈可放宽到 25%"（因为满额要求苛刻）；别在趋势市用；适合区间中枢明确时。

## 6.4 长蝶式与破翼蝶（Long Butterfly / Broken Wing Butterfly）

### 长蝶式（借记版）—— 低成本押注"钉在某价位"

**① 构造**：**买 1 张低 K Call + 卖 2 张中 K Call + 买 1 张高 K Call**（等距）。付极小借记，赌到期钉在中 K。

**② 场景**：明确目标位 + 判断到期日标的会停在那附近（如钉在整数关口、最大痛点 max pain）。低成本、高赔率、低胜率的"精准狙击"。

**③ 数字实例（个股/指数）**
> 判断 SPY 一月后钉在 $600。**买 590 Call + 卖 2× 600 Call + 买 610 Call，30 DTE**，净借记 **$2.00**（$200）。翼宽 $10。
> - 到期正好 $600：最大盈利 = (10−2)×100 = **$800**（+300%）
> - 到期 ≤$590 或 ≥$610：亏光 **$200**
> - 盈亏平衡 = 592 与 608
> - 花 $200 博"钉在 600"，中了赚 $800，是低成本事件/到期狙击工具。

### 破翼蝶（Broken Wing Butterfly）—— 收权利金 + 单侧无风险

**① 构造**：不对称的蝶（一侧翼比另一侧宽），通常做成**净收信用**，使**一个方向完全无风险**。现今非常主流，比铁鹰资金效率高。

**② 直觉**：把长蝶的一条远翼往外挪，省下的权利金让整体变成"净收钱"，于是**无风险的那一侧就算完全猜错方向也不亏**（甚至小赚信用），风险全集中在另一侧。

**③ 数字实例（Put 破翼蝶，看不跌）**
> SPY $600，判断不会大跌。**买 1× 560 Put / 卖 2× 580 Put / 买 1× 590 Put**（近翼 10 宽、远翼 20 宽），做成**净收信用 $1.00**（$100）。
> - **上方无风险**：SPY 到期 ≥ $590，全部作废 → **净赚信用 $100**（涨、横、小跌都赢）
> - 最佳：到期钉 $580 → 赚翼差 + 信用
> - **风险在下方**：跌破某点后有限亏损（最大亏损 = 宽翼−窄翼−信用，仍有限）
> - 相比铁鹰：一侧彻底免风险，只需防单边，胜率与资金效率更好。

**④ 管理/Checklist**：明确"哪个方向我完全不怕"→ 把无风险侧对准它；止盈 25~50%；风险侧被测则展期或止损。

## 6.5 Jade Lizard —— 上方零风险的卖波动

**① 构造**：**卖 1 张虚值 Put + 卖 1 张虚值 Call 价差（卖低 Call + 买高 Call）**。诀窍：**收到的总权利金 ≥ Call 价差的翼宽 → 上方完全无风险**（涨破了也不亏）。

**② 场景**：中性偏多、高 IV、且**特别怕上方轧空**的卖方。是"卖宽跨式"的改良——牺牲一点上方收益，换来**上不封顶的风险被彻底消除**。

**③ 数字实例（个股，美式）**
> AMD $170，高 IV，中性偏多。**卖 155 Put 收 $4 + 卖 185 Call 收 $3 + 买 190 Call 付 $1**。
> - 总收信用 = 4 + 3 − 1 = **$6.00**（$600）；Call 价差翼宽 = 190−185 = $5。
> - **信用 $6 > 翼宽 $5 → 上方零风险**：AMD 无论涨多高，Call 价差最大亏 $5，被 $6 信用覆盖，**净赚至少 $100**。
> - 风险只在下方：跌破 155 后等同卖 Put（愿接货），最大亏损 = (155−6)×100。
> - 涨、横、小跌全赢，只有大跌才亏 → 适合"看不跌 + 怕踏空轧空"。

**④ 管理/错误/Checklist**：核心纪律是**总信用 ≥ Call 翼宽**（否则失去上方无风险性质）；下方按卖 Put 管理（愿接货、控仓）；高 IV 时开。

## 6.6 日历价差与双日历（Calendar / Double Calendar）—— 交易时间与 IV

**① 构造**：**卖近月 + 买远月，同行权价**（Call 或 Put 均可）。赚"近月 Theta 衰减快于远月"+"远月 Vega 受益于 IV 上升"。双日历 = 在两个行权价（上下各一）各做一个日历，覆盖更宽区间。

**② 场景**
- ✅ 判断标的**短期不动**（钉在行权价）→ 近月快速衰减，远月保值
- ✅ **财报事件**：财报前**近月 IV 远高于远月**（期限倒挂）→ 卖贵的近月、买相对便宜的远月，事件后近月 IV crush 归零、远月还在 → 获利（这是财报做多波动的正确姿势，胜过裸买跨式）
- ❌ 判断标的会大幅单边运动（日历怕标的跑离行权价）
- ❌ 远月 IV 也很高时（buy vega 买贵了）

**③ 损益图**：像一座"帐篷"，尖顶在行权价，标的钉在行权价附近时最赚，跑远两侧亏（有限）。

**④ 数字实例（财报双日历，个股）**
> NFLX $500，下周三财报，近月（本周五到期）IV 90%，次月 IV 45%（严重倒挂）。判断财报后大幅波动但方向不明，且会回到 500 附近区间。
> **双日历**：在 470 与 530 各做"卖本周 + 买次月"。净借记约 **$8**（$800）。
> - 财报后 IV crush：本周（近月）两腿几乎归零（你是卖方，赚了），次月两腿 IV 回落但仍保留时间价值（你是买方，回吐一部分）
> - 若股价落在 470~530 区间：近月赚满、远月留值 → **整体获利**
> - 若暴冲到 $560 或暴跌到 $440（跑出双日历覆盖区）→ 有限亏损（净借记附近）
> - 对比裸买跨式：裸买跨式财报后被 IV crush 双杀，双日历靠"卖近月"对冲了 crush，是**结构性更优的事件玩法**。

**⑤ 管理**：财报后**次日一早了结**（IV 已 crush，目标达成就走）；标的跑离 → 有限止损；别持有到近月到期后裸留远月（除非你想转成单腿）。

**⑥ 常见错误**：远月 IV 也高时做（买贵）、判断错方向让标的跑出区间、财报后不及时了结让远月继续 Theta 衰减、用了美式个股却在近月实值时被指派（可用指数规避）。

**⑦ Checklist**：近月 IV≫远月（倒挂）/ 判断区间震荡或事件后收敛 / 目标达成即走 / 覆盖区间够宽（双日历）。

## 6.7 比例价差与比例反向价差（Ratio Spread / Backspread）⚠️ 进阶

> **先看懂，别急着做**。这两个是"腿数不对称"的进阶结构，风险画像与前面都不同。

### 比例价差（Ratio Spread，卖得比买得多）
- **构造**：买 1 张近 + 卖 2 张更虚（如买 1× 100 Call + 卖 2× 110 Call）。常做成净收信用。
- **风险**：**净卖出一条裸腿**（卖 2 买 1，多卖的那张是裸的）→ 标的大幅冲过卖出腿方向时**风险很大/无限**。
- **场景**：温和看涨到某位置就停（到 110 最赚，冲过 110 反而因裸腿转亏）。**新手禁做裸腿版**。

### 比例反向价差（Backspread，买得比卖得多）⭐ 唯一"低成本做多波动 + 尾部凸性"
- **构造**：**卖 1 张近实 + 买 2 张更虚**（如卖 1× 100 Call + 买 2× 110 Call），常做成**净零成本或净收信用**。
- **风险画像**：**下方/横盘小亏或不亏（甚至小赚信用），大涨方向凸性爆发（多出来那张裸多 Call 无限获利）**。
- **场景**：判断"要么不动、要么暴涨"（如生物医药数据、并购传闻、突破放量）。是卖方策略的**尾部对冲补充**（卖方怕暴动，backspread 专吃暴动）。
- **数字实例**：
> 判断某生物股 $50 要么横要么暴涨。**卖 1× 50 Call 收 $5 + 买 2× 60 Call 付 $4（共 $8）** → 净借记 $3。
> - 横在 50~60：小亏（最多亏到 60 附近的谷底，约 −$1,300）
> - 暴涨到 $80：两张 60 Call 各赚 $20 = $4,000，减去 50 Call 亏 $3,000 与成本 → 大幅净赚且**上不封顶**
> - 微跌/大跌：只亏净借记 $300（甚至若做成信用则不亏）
> - 用极小成本获得"暴涨无限 + 平静小亏"的凸性。

**Checklist（backspread）**：判断"静止或暴动"/ 做成净成本≈0 / 接受中间区间小亏 / 有明确暴动催化。

## 6.8 盒式价差（Box Spread）—— 只讲认知，别当"无风险套利"乱做

**① 是什么**：牛市认购价差 + 熊市认沽价差（同两个行权价）组合，到期损益**固定 = 翼宽**，与标的无关 → 本质是一笔**合成借贷**（用期权融资或存钱套利率）。机构用它做低成本融资/资金管理。

**② 为什么散户要懂它却别乱做**：
- **欧式指数（SPX）盒子**才安全（无提前指派）；**用美式个股/ETF 做盒子 = 找死**：短腿会被提前指派，把"锁定的无风险"炸成巨亏。
- 著名的 **2019 年 "1R0NYMAN" 案例**：一散户在 Robinhood 用美式期权做盒式价差以为无风险套利放大杠杆，短腿被提前指派，**亏掉数万美元、穿仓**。
- **认知价值**：看到"无风险套利""box spread 稳赚"的说法，你要立刻警觉——**要么是欧式专业融资工具，要么是有人要爆仓的前奏**。散户不需要主动做盒子。

# 第 7 章　★ 展期与修复手册

> 前面每个策略都教了"怎么开仓"，但**真正决定长期盈亏的是"仓位走反后你怎么收拾"**。展期（Roll）是卖方的第二招，也是最容易被滥用的动作。

## 7.1 展期是什么、什么时候该展

**展期 = 平掉当前头寸 + 同时开一个新的（更晚到期 / 不同行权价）头寸**，通常一张组合单完成。

**展期的唯一正当理由**：新头寸的**概率结构比现在更好**，且你能**净收权利金（credit roll）**。

**展期的头号陷阱**：把它当"死不认错"的工具——一路向下展期一个卖飞的 Put，本质是**不断加大对一个错误方向的下注**，直到某天崩盘一次亏光。

**判断口诀**：
- ✅ **能净收权利金 + 你依然认可原判断** → 可以展期。
- ❌ **要倒贴权利金才能展** → 通常说明你在硬扛错误，**认账平仓往往更好**。
- ❌ 已经展了 2 次以上还在同方向加码 → 停手，接受结果。

## 7.2 短认沽走反 → 三条路

标的跌破你卖的 Put 行权价，看多逻辑还在：

| 选择 | 操作 | 何时选 |
|---|---|---|
| **认账接货** | 让其指派，买入 100 股，转 Wheel（8.1） | 你确实愿意持有这只票 |
| **向外展期（roll out）** | 买回本月 Put + 卖出下月同行权价 Put，净收权利金 | 想再给时间、且能收到 credit |
| **向外向下展期（roll out & down）** | 买回本月 + 卖下月**更低行权价**，力求仍净收权利金 | 想降低接货价，愿牺牲部分权利金 |

**纪律**：展到**净收权利金做不到**的那一刻，就该认账（接货或平仓止损）。

## 7.3 卖跨式/宽跨式受测 → 转铁蝶/铁鹰 或 调腿

- **一边被逼近**：把**没被测的那条腿向标的方向移近**（roll the untested side in），多收权利金、把盈亏中枢挪向现价。
- **裸卖变有限风险**：临时**买入外侧保护腿**，把裸的宽跨式改造成**铁鹰/铁蝶**，先把无限风险封住再从容处理。
- **整体展期**：平掉本月、开下月更宽的跨式，净收权利金 + 更宽区间。

## 7.4 备兑/短 Call 被逼空 → 向上向外展期

股价冲向你卖的 Call、不想被 call away：

- **roll up & out**：买回本月 Call + 卖出**下月更高行权价** Call，尽量**净收或成本中性**，既抬高被 call away 的价格、又继续收租。
- **除息周特别处理**：实值短 Call 在除息前，若时间价值 < 股息 → **今天就 roll**，否则今晚被指派、股票被 call away 还吃不到股息（见 2.2）。
- 若已远超行权价、roll 只能倒贴 → **接受被 call away**（本来就是愿意卖出的价），别硬扛。

## 7.5 垂直价差受测 → 展期还是认账

- **信用价差**被测：可**roll 到下月同结构**（净收权利金）或**向未受测方向平移**；若只能倒贴则认最大亏损（本就有限）。
- **到期周实值短腿**：无论如何**先平仓**，避免被指派 + 周末敞口（2.2）。
- **借记价差**走反：一般直接止损（成本有限），展期意义不大。

## 7.6 一张"展期决策"自检表

```
仓位走反了，我想展期 —— 先回答：
  1. 我还认可当初的方向/区间判断吗？   否 → 平仓认账
  2. 这次展期能【净收权利金】吗？        否 → 倾向平仓认账
  3. 展期后的新头寸概率更好吗？          否 → 平仓认账
  4. 这是我第几次展同一个方向？          ≥3 → 停，接受结果
  以上全过 → 可以展期（credit roll），并记录在交易日志里
```

# 第 8 章　组合应用与收益系统

把单个策略串成**可重复的系统**。

## 8.1 卖权轮 Wheel —— 完整 3 个月模拟账本

**逻辑闭环**：卖现金担保 Put 收租 →（被指派）接货 → 对持股卖备兑 Call 收租 →（被 call away）卖出 → 回到卖 Put。**一个愿意持有的好标的上，永远在收租。**

**三个月模拟（标的 XYZ ETF，起始现价 $100，账户备 $10,000）**：

| 月 | 动作 | 现金流 | 状态 |
|---|---|---|---|
| M1 | 卖 95 Put（30DTE）收 $2.0 | **+$200** | 到期 XYZ=$92 → **被指派**，$9,500 买入 100 股 |
| M1末 | 持有 100 股 XYZ @ 成本 95−2 = **$93** | — | 现价 $92，浮亏 $100 |
| M2 | 对持股卖 98 Call（30DTE）收 $1.8 | **+$180** | 到期 XYZ=$96 → Call 作废，继续持股 |
| M3 | 再卖 98 Call（30DTE）收 $1.7 | **+$170** | 到期 XYZ=$100 → **被 call away**，$9,800 卖出 100 股 |
| 结算 | 股票 (98−93)×100 = +$500 资本利得 | **+$500** | 回到全现金，重新开始卖 Put |

**三个月总收益** = 权利金 200+180+170 + 资本利得 500 = **$1,050**，对 $10,000 本金 ≈ **10.5%（3 个月）**。全程只做了"愿意持有的票 + 收租"，没预测方向。

**Wheel 的三条铁律**：
1. **只在你真心愿意长期持有的票上做**（被指派套牢也不慌）。
2. **接货成本 = 行权价 − 已收权利金**，被指派不是失败，是"打折买入 + 已收补贴"。
3. **除息日、财报日避开近月**，防提前指派与跳空。

## 8.2 用指数期权对冲股票组合 —— Beta 加权 Delta

**问题**：你有一篮子股票（总市值 $200,000），怕大盘回调，想用 SPX/SPY 认沽对冲。**买几张？**

**方法：Beta 加权 Delta（把组合换算成"等价多少 SPX Delta"）**

1. 估组合对 SPX 的 **Beta**（科技股为主约 1.2，均衡组合约 1.0）。设 Beta = 1.2。
2. **组合等价 SPX 名义敞口** = 组合市值 × Beta = 200,000 × 1.2 = **$240,000**。
3. SPX 现 5,000 → 1 张 SPX 名义 = 5,000 × 100 = **$500,000**；SPY 现 500 → 1 张 SPY 名义 = **$50,000**。
4. **完全对冲**需要的 Delta：$240,000。
   - 用 SPY：240,000 / 50,000 = **约 4.8 张 SPY 的 Delta**。若买 Delta −0.30 的 SPY Put，则需 4.8/0.30 ≈ **16 张** SPY Put 做部分对冲。
   - 用 SPX：240,000 / 500,000 = 0.48 张的 Delta，买 Delta −0.30 的 SPX Put 约需 **1~2 张**（大资金更省事、且现金结算 + 税优）。

**实操建议**：
- **不必 100% 对冲**（那等于清仓，还白付保费）。常见做**30~50% 部分对冲**（削峰）。
- 用**认沽价差**替代裸买认沽可**大幅降低对冲成本**（放弃极端下行保护，见 8.3）。
- 大组合（>$100k）用 **SPX**（无指派、现金结算、Section 1256 税优）；小组合用 SPY/QQQ。

## 8.3 尾部对冲成本对比 —— 四种做法

保护 $200,000 组合 3 个月，四种方式的性价比：

| 方式 | 构造 | 成本 | 保护效果 | 适合 |
|---|---|---|---|---|
| **裸买 SPX 认沽** | 买 5% 虚值 Put | 高（~2~3%/季） | 全额下行保护 | 极度担忧、要绝对保底 |
| **认沽价差** | 买近 Put + 卖更远 Put | **中（省 40~60%）** | 保护一段跌幅（如 −5%~−15%），超深不保 | **性价比首选** |
| **VIX 认购** | 买 VIX Call | 低名义、高波动 | 崩盘时爆发式对冲（VIX 暴涨） | 尾部凸性，但平时衰减、且标的是期货 |
| **持有现金** | 减仓 | 0 保费（机会成本） | 直接降敞口 | 最简单，但踏空风险 |

**给个人的组合拳**：**部分减仓 + 认沽价差**覆盖常规回调，**小额 VIX 认购或 SPX 深虚 Put** 博尾部凸性。避免长期全额裸买认沽（保费长期拖累）。

## 8.4 0DTE 卖方的真实盈亏分布 ⚠️ 高风险

**0DTE = 当日到期**期权，现已占 SPX 成交量近半。卖 0DTE = 收极快 Theta，但 Gamma 风险爆表。

**真实盈亏画像**：
```
日常（大多数交易日）：收一点点权利金，胜率看起来 80%+ → 账户平稳上涨
尾部日（偶发的大波动日）：Gamma 瞬间放大，一天亏掉几十天的累积
```

**三次尾部提醒**（卖波动率者的墓志铭）：**2018-02 "Volmageddon"**、**2024-08 日元套息平仓日**、**2025-04 关税冲击日** —— 这类日子里，卖 0DTE/卖波动率的账户可能**单日腰斩甚至穿仓**。

**若你坚持碰 0DTE**：
- **只用有限风险结构**（0DTE 铁鹰 / 破翼蝶），**永不裸卖**。
- **仓位极小**（单日最坏亏损 < 账户 2%）。
- **用 SPX**（现金结算、无指派、Section 1256 税优、无隔夜）。
- 记住"高胜率"是幻觉——**卖 Gamma 的本质是捡钢镚在压路机前，长期期望未必为正**。

## 8.5 事件驱动三例

1. **财报**：别裸买跨式（IV crush）。要玩 → **双日历/日历**（6.6）或**财报后卖 IV**（事件落地 IV 崩、卖宽跨式/铁鹰收残余高 IV）。
2. **并购套利**：现金收购案中，标的股钉在收购价附近 → 卖宽跨式/铁鹰收 Theta（但**注意交易破裂的跳空尾部**，务必有限风险）。
3. **除息前指派套利**（你作为卖方要防、作为进阶者可理解）：实值短 Call 时间价值 < 股息 → 除息前被指派。个人一般是**规避方**（备兑除息周展期），而非主动套利方。

## 8.6 期权在你研究流程里的位置

期权是**表达观点的工具**，不改变"观点从哪来"。把它接到你已有的研究结论后面：

```
研究结论（方向 + 时间窗 + 信心 + 催化）
        │
        ├─ 坚定看涨、有催化、IV 低      → 买 Call / 牛市认购价差 / PMCC
        ├─ 温和看涨、愿低接、IV 高      → 卖 Put / 牛市认沽价差 / Wheel
        ├─ 判断震荡、IV 高             → 铁鹰 / 铁蝶 / 卖宽跨式（有限风险）
        ├─ 判断静止或暴动（方向不明）    → backspread / 双日历
        ├─ 有大额浮盈想保住            → 领口 / 保护性 Put
        └─ 怕系统性回调               → SPX 认沽价差 / VIX 对冲
```

**核心原则**：**先有观点（方向/时间/IV 判断），再选工具**。不要因为"想做期权"而硬找观点——那是亏损的开始。

# 第 9 章　风控与执行细则

策略选对了，**仓位和执行决定你能不能活着复利**。这一章的每条都是用别人的爆仓换来的。

## 9.1 保证金：你的头寸到底占多少钱

| 头寸类型 | 保证金占用（Reg T 粗略） |
|---|---|
| 买方（long Call/Put） | 全额权利金，无额外保证金 |
| 现金担保卖 Put | 行权价×100（全额现金） |
| **裸卖 Call/Put** | 约 max(20%×标的−虚值额, 10%×行权价)×100 + 权利金，**且随标的移动追加** |
| **垂直价差** | **= 翼宽×100 − 净信用**（风险被锁死，占用小，最推荐） |
| 铁鹰/铁蝶 | = 单侧翼宽×100 − 净信用（两侧不会同时穿，只算一侧） |

**组合保证金（Portfolio Margin，PM）**：净值 ≥ $12.5 万可申请，按整体风险（-12%~+10% 压力测试）算保证金，对**对冲良好的组合**占用远小于 Reg T，但**对裸头寸更敏感**，用不好放大杠杆更危险。

## 9.2 头寸规模三条硬线

1. **单笔最大亏损 ≤ 账户净值的 1~3%**（有限风险策略按最大亏损算，卖方按"最坏情景"算，不是按保证金算）。
2. **名义敞口 ≠ 保证金占用**：卖 1 张 SPX Put 保证金可能只占几千，但**名义敞口 $50 万**——爆发时按名义亏。**永远按名义敞口的最坏情况倒推张数。**
3. **相关性集中度**：别同时卖 10 只科技股的 Put（它们一起跌），等于一个巨大的裸空波动率头寸。分散或用指数。

## 9.3 流动性筛选（多腿单尤其重要）

开仓前查：
- **OI > 500、当日 Volume > 100**（能进能出）。
- **Bid-Ask 价差**：单腿 < 权利金的 ~5~10%；多腿看**整体组合价差**。
- **只做高流动性标的**：个股（AAPL/NVDA/TSLA/AMD/META…大盘蓝筹）、ETF（SPY/QQQ/IWM/TLT/GLD）、指数（SPX/NDX/RUT）。**小盘冷门股期权价差能吃掉你所有利润。**

## 9.4 委托类型：永远别用市价单

- **限价单 + 中间价（Mid）起挂**：多腿组合单用 **Net Debit / Net Credit** 挂整体价格，从中价开始，向不利方向一格格让，别一步到 Bid/Ask。
- **绝不用市价单（Market Order）**：期权盘口薄，市价单会被打到极差价成交。
- **多腿务必用组合单（single order）**：别分腿逐条下（legging in），会有腿成交腿没成交的敞口风险。
- **到期日操作**：想平仓就早点挂，别等最后一分钟流动性枯竭。

## 9.5 PDT 与账户规则

- **PDT（Pattern Day Trader）**：净值 < $2.5 万时，滚动 5 交易日内**日内平仓（当日开当日平）不得超过 3 次**——做 0DTE 会瞬间触顶。
- **现金账户**：无 PDT 限制，但**卖方策略受限**（需全额担保），且资金交割 T+1 有"未交割资金不能再用"的限制。
- **被指派导致的保证金调用（margin call）**：到期周实值短腿被指派可能瞬间产生大额股票头寸 → 触发 margin call → 券商强平。**再次强调：到期周清理实值短腿。**

## 9.6 交易日志模板（每笔必记）

```
日期 | 标的 | 策略 | 到期/DTE | 行权价(各腿) | 开仓价(净) | IV/IVR
方向观点 | 催化 | 计划止盈% | 计划止损/展期条件 | 最坏情况亏损($)
——— 平仓后补 ———
平仓日 | 平仓价 | 盈亏$ | 盈亏% | 复盘：判断对错？执行有无失误？
```

**复盘重点不是"赚没赚"，而是"过程对不对"**：一个正确执行的策略偶尔亏钱是正常的；一个靠运气赚钱的坏习惯迟早还回去。

# 第 10 章　★ 税务（美股期权，实操影响巨大）

> **免责声明**：以下为一般性知识，**不是税务建议**。美国税法复杂且随年度变化，务必咨询你所在税辖区的持牌会计师（CPA）。非美国税务居民规则完全不同。

## 10.1 Section 1256 合约：SPX/NDX/RUT/VIX 的税务大优惠

**广基指数期权（SPX、NDX、RUT、VIX 等）属于 Section 1256 合约**，享受两大特殊待遇：

1. **60/40 规则**：无论持有多久，盈亏按 **60% 长期资本利得 + 40% 短期**征税。对高收入者，这比 100% 短期税率**显著省税**。
2. **年末按市值计税（mark-to-market）**：年底未平仓头寸按当年最后交易日市值视同已实现，跨年盈亏当年结算。

## 10.2 同样对冲，SPX vs SPY 的税后差异（算例）

> 假设你做指数对冲/交易，一年实现盈利 **$10,000**，你的短期税率 35%、长期税率 15%。

| | **用 SPY（普通短期）** | **用 SPX（Section 1256 60/40）** |
|---|---|---|
| 短期部分 | $10,000 × 35% = $3,500 | $4,000 × 35% = $1,400 |
| 长期部分 | — | $6,000 × 15% = $900 |
| **总税** | **$3,500** | **$2,300** |
| **税后到手** | $6,500 | **$7,700** |

**同样的交易，用 SPX 比 SPY 多留 $1,200（省 34% 的税）** —— 这就是专业资金做指数对冲宁用 SPX 的税务理由（叠加无指派、现金结算、无 pin risk）。

## 10.3 个股/ETF 期权的税务要点

- **一般规则**：个股与 ETF（SPY/QQQ 等**非** Section 1256）期权盈亏按**持有期**定短/长期，多数期权交易是**短期资本利得**。
- **洗售规则（Wash Sale）**：亏损平仓后 30 天内又买回"实质相同"证券（含期权），**亏损被递延**、不能当期抵扣。频繁交易同一标的期权极易踩中。
- **合格备兑认购（Qualified Covered Call）**：卖过深实值的备兑 Call 会**中断标的持股的长期持有期**，把本可享长期税率的股票打回短期。卖备兑别卖太深实值。
- **跨式（Straddle）规则**：持有对冲性的多空组合时，亏损那腿的抵扣可能被**递延**到盈利腿了结，规则复杂，量大者请咨询 CPA。

## 10.4 税务给策略选择的启示

- 大额、频繁的**指数对冲/波动率交易** → 优先 **SPX/NDX/RUT（1256 税优）**。
- **长期持有的核心股** → 卖备兑别卖深实值（保住长期持有期）。
- 频繁进出同一标的 → 警惕洗售，考虑用指数或拉开时间。
- **别让税务尾巴摇狗**：税优是加分项，不能为省税去做不该做的交易。

# 第 11 章　场景 → 策略速查矩阵

## 11.1 三维查表：方向 × IV × 是否持股

| 方向观点 | IV 低（买方友好） | IV 高（卖方友好） |
|---|---|---|
| **坚定看涨** | 买 Call、牛市认购价差、PMCC、backspread（若判断"暴涨"） | 卖 Put、牛市认沽价差、风险逆转、Jade Lizard |
| **温和看涨** | 牛市认购价差、对角 | 卖 Put、牛市认沽价差、Wheel |
| **中性/震荡** | 日历/双日历、长蝶（低成本狙击） | **铁鹰、铁蝶、卖宽跨式、破翼蝶** |
| **温和看跌** | 熊市认沽价差、买 Put | 熊市认购价差 |
| **坚定看跌** | 买 Put、熊市认沽价差 | 熊市认购价差、卖 Call 价差 |
| **静止或暴动(方向不明)** | **backspread、双日历** | 财报后卖 IV（宽跨/铁鹰） |
| **已持股·想增强** | — | 备兑 Call、备兑宽跨式 |
| **已持股·想保护** | 保护性 Put、**领口** | 领口（Call 腿更值钱，补贴更多） |
| **组合·怕回调** | SPX 认沽价差、VIX 认购 | SPX 认沽价差（部分对冲） |

## 11.2 一页决策树

```
我有一个观点 —— 
  ①方向？ 涨 / 跌 / 横 / 不定
  ②信心与幅度？ 温和 / 坚定 / 暴动
  ③IV 高不高？ 查 IVR：>50 卖方，<30 买方
  ④时间窗？ 事件驱动(近月) / 趋势(30-45DTE) / 长期(90+DTE)
  ⑤我持股吗 / 我愿接货吗？
        │
        ▼
  按 11.1 矩阵定"首选结构"
        │
        ▼
  检查：最坏亏损 ≤ 账户 1-3%？ 流动性够(OI>500)？ 避开财报/除息？
        │  否 → 调整行权价/翼宽/标的，或放弃
        ▼
  用限价组合单从中价挂 → 记交易日志(计划止盈/止损/展期条件)
        │
        ▼
  管理：50% 止盈 / 21DTE 闸门 / 受测则按第7章展期或认账
        │
        ▼
  到期周：清理所有"实值"或"卡行权价"的头寸（第2章）
```

## 11.3 品种选择速查

| 你的需求 | 首选品种 | 理由 |
|---|---|---|
| 个股观点表达 | 个股期权（大盘蓝筹） | 直接、流动性好 |
| 小资金练手 | ETF（SPY/QQQ/IWM） | 门槛低、可实物、流动性极佳 |
| 组合对冲 / 大资金中性策略 | **SPX/NDX/RUT** | 现金结算、无指派、无 pin、Section 1256 税优 |

## D. 打印版 Checklist 汇总

**开仓前（通用）**
- [ ] 我的观点：方向 / 幅度 / 时间窗 / 信心，写下来了？
- [ ] IVR 查了？（>50 倾向卖方，<30 倾向买方）
- [ ] 结构选对了？（对照 11.1 矩阵）
- [ ] 最坏亏损 ≤ 账户 1~3%？
- [ ] 流动性够？（OI>500、Vol>100、价差窄）
- [ ] 避开财报 / 除息（除非专门策略）？
- [ ] 用限价组合单、从中价挂？
- [ ] 写了交易日志（止盈/止损/展期条件）？

**持仓中**
- [ ] 到 50% 盈利了吗？（卖方尤其早止盈）
- [ ] 到 21 DTE 了吗？（处理或展期）
- [ ] 有腿被"测试"了吗？（按第 7 章展期/认账）

**到期周（第 2 章生命线）**
- [ ] 有"实值"短腿吗？→ 平仓或展期（防指派）
- [ ] 有"卡在行权价"的头寸吗？→ 主动平仓（防 pin risk）
- [ ] 除息周有实值短 Call 吗？→ 今天处理（防除息前指派）
- [ ] 买方实值又不想要股票？→ 今天平仓（防自动行权）
- [ ] 用的是欧式指数吗？→ 只需管到期日现金结算，其余无忧

> **结语**：期权不是让你暴富的彩票，而是**精确表达观点、管理风险、增强收益**的工具箱。初学者的正确路径是：
> **模拟盘 → 现金担保卖 Put / 备兑（Level 2）→ 垂直价差（Level 3）→ 铁鹰/日历等中性策略 → 组合对冲。**
> 全程守住三件事：**懂到期机制（第 2 章）、控好仓位（第 9 章）、先有观点再选工具（第 8.6）。** 活得久，才谈得上复利。
