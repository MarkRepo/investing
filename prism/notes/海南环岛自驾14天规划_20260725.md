# 海南环岛自驾 · 14天规划（深圳出发 · 纯电EV · 深度慢游）

> 制定日期：2026-07-25
> 参数：深圳往返 / 纯电动车 / 舒适型酒店（¥300–500/晚）/ 深度慢游 / 工作日每天处理工作 3 小时（时间灵活）
> ⚠️ 8月为**台风季 + 全年最热 + 暑期高峰**，本规划已按此优化（机动日、避正午户外、订可免费取消房型、轮渡提前抢票）。

---

## 0. 核心决策与假设

| 项 | 结论 | 说明 |
|---|---|---|
| 走向 | **顺时针环岛**：海口→东线下三亚→西线返海口 | 东线景点密、充电好，先玩精华；西线返程收尾 |
| 过海 | 徐闻港 ⇄ 海口新海港，客滚轮渡 | 航程约1.5h、班次最密 |
| 电量策略 | 单段控制在 250–350km，**上船电量压到 30%–50%** | 岛内东线/城市充电充足，西线偏稀疏需提前补 |
| 工作节奏 | 工作日**午间 11:00–14:00**（避高温、蹭空调WiFi）；驾驶日塞进轮渡/充电等待窗口 | 周末不工作，用于大交通与主玩 |
| 岛内高速 | **海南全岛高速免过路费**（含电车） | 只需付省外（粤境）过路费 |

**起止日期示例**：按 **2026-08-01（周六）出发、08-14（周五）返深** 排布（下表星期即据此）。
- 两个周末落在 **8/1–8/2** 和 **8/8–8/9**，正好承接「深圳→徐闻大交通+轮渡」与「三亚主玩」。
- 若希望**返程也落在周末**，把出发整体推迟1天（周日出发）即可，路线不变。

## 1. 每日时间表

> 图例：🚗驾驶 · 🔌充电 · 💼工作3h · 🏨住宿 · 🎒游玩

### 第1天（周六 8/1）深圳 → 徐闻｜大交通日·不工作
- 🚗 深圳 → 湛江徐闻，约 **500km / 净驾驶 5.5–6h**（G15沈海高速）
- 🔌 途中补能 2 次：**阳江**、**茂名/化州**服务区各约 40min（可顺带午餐）
- 🎒 傍晚抵徐闻，**吃湛江/徐闻海鲜**，早休息
- 🏨 **徐闻港附近酒店**（距港近，次日轮渡从容）
- ✅ 今日务必完成：① 小程序确认次日**新能源专道**船票；② 睡前把电量补到 **~50%** 以内备过海

### 第2天（周日 8/2）徐闻 → 海口｜过海日·不工作
- 🚢 上午轮渡 **徐闻港 → 海口新海港**，航程约1.5h + 候船，**提前1–2h到港**

### 第3天（周一 8/3）海口深度｜工作日

### 第4天（周二 8/4）海口 → 文昌 → 博鳌｜工作日

### 第5天（周三 8/5）博鳌深度｜工作日

## 4. EV 充电与轮渡要点

**充电**
- 岛内**东线高速服务区、各市县城区**充电充足；**西线（东方/昌江/儋州）以城区桩为主**，进城即充、别等到没电。
- 常用 App：国家电网、特来电、蔚来/小鹏/理想自营（海南覆盖较好）、海南本地充电平台。
- 单段控制 **250–350km**；离三亚进西线前**充满**；进港前**留 30%–50%** 即可（勿充满）。

**轮渡（出发前以「琼州海峡轮渡管家」小程序为准）**
- 渠道：微信小程序 **「琼州海峡轮渡管家」** / 公众号「徐闻港」。
- 航线：**徐闻港 → 海口新海港**（去程）、**海口新海港 → 徐闻港**（返程）。
- **新能源车必须选「新能源专道/专班」**，每船额度有限（约14–18辆），**暑期提前3–7天抢票**。
- 参考票价：车票(含司机) ~¥375–415，乘客 ~¥41.5/人；**提前1–2h到港**，全员带身份证原件（刷脸+实名）。
- 上船**电量30%–50%**、人车分离（停好车即上客舱，禁止留在车内）。

## 6. 8月专项提醒（台风季）

- **每日看台风**：关注中央气象台/海南气象 + 「琼州海峡轮渡管家」停复航通知；**台风来袭轮渡会停航**。
- **预留机动**：行程含缓冲弹性——若遇停航/暴雨，可在三亚或海口多留1天（把西线压缩为1天直穿东方→儋州→海口）。
- **订可免费取消房型**，别提前锁死不可退。
- **防暑**：正午户外风险高，户外集中在 07:00–10:00 与 16:30 之后；备防晒、电解质水。
- **环岛旅游公路**：陵水/万宁/文昌沿线的海景观景段建议专门留时间慢开，是慢游的精华。

## 7. 可选调整

- **想更慢**：砍掉西线（东方/昌江），三亚多住2晚，第11天起原路东线返海口——每日驾驶更短。
- **想更全**：加**中线雨林**（五指山/保亭·呀诺达/槟榔谷），从三亚上五指山再下海口，替换部分西线。
- **返程落周末**：出发整体推迟1天（周日出发），路线不变。
