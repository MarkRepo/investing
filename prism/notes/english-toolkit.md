# 英语资料与方法库（听说读写全表）

> 本篇是配套的**资料库 + 方法百科**。执行手册 [每天 30 分钟计划](english-plan) 告诉你**每天怎么练**；本篇告诉你**每项能力的方法细节和可选资料**，按 读 / 听 / 说 / 写 分章，每章给"方法 + 由易到难的资料表"。
>
> **适用对象**：CET-4 起点、实用导向（非应试）的学习者。

---

## 0. 怎么用这份资料库

一句话：**每类资料只选 1–2 个用到底，别来回换。** 下面每章先讲方法（怎么练最有效），再给资料表（从易到难，选与自己水平匹配的起点）。四项之中，**听和说**是你最该砸时间的（见 [计划篇的坐标](english-plan)）。

---

## 1. 阅读（目前最强，用它带动词汇和语感）

**方法**：两条线并行——
- **精读**：每天一篇短文，查生词、拆长句、复述大意。
- **泛读**：大量读，不查词，靠上下文猜意思，追求"读爽"。

**资料（由易到难）**：

| 资料 | 难度 | 说明 |
|------|------|------|
| 书虫 / **Oxford Bookworms** 分级读物 | ★★ | 从 Level 3–4 起步，一本本读完，建立"读完整本书"的成就感 |
| **Breaking News English** | ★★–★★★★ | 同一篇新闻 7 个难度版本 + 练习，最适合过渡（推荐主用） |
| BBC News / Reuters 短新闻 | ★★★★ | 目标级读物，先从 BBC 短讯起 |
| 原版小说《Charlotte's Web》《Wonder》《Harry Potter 1》 | ★★★ | 情节强，读得下去比读得难更重要 |
| The Economist | ★★★★★ | 后期挑战，别一开始就啃 |

---

## 2. 听力（重点投入，最易见效也最易放弃）

**方法**：精听 + 泛听结合——
- **精听**（每天核心）：2–3 分钟音频，反复听 → 听写 → 对照原文 → 找没听懂的**根因**（生词/连读/语速）。
- **泛听**（碎片时间）：通勤、走路、做家务磨耳朵，听懂大意即可。

**资料（由易到难）**：

| 资料 | 说明 |
|------|------|
| **BBC「6 Minute English」** | 语速适中、有文稿，起步首选（推荐主用） |
| **VOA Learning English** | 慢速英语，精听入门最友好 |
| 每日英语听力（App） | 海量带文稿音频，适合精听/听写 |
| 播客《All Ears English》《The English We Speak》 | 通勤泛听 |
| 进阶：ESLPod → TED-Ed / TED 短演讲 → Netflix 美剧 | 美剧推荐《Friends》《Modern Family》，生活对话多、语速真实 |

---

## 3. 口语（哑巴英语的解药，必须开口）

**方法**：光输入不开口永远不会说。三个核心练法——

1. **影子跟读（Shadowing）**：放一段有文稿的音频，晚半句跟读，模仿语音语调。每天 12–15 min，**性价比最高**。
2. **自言自语 / 每日一分钟独白**：给自己出题（"今天做了什么""你怎么看远程办公"），逼自己连续说 1 分钟，录音回听。
3. **找真人对练**：决定性一步，把练会的用出来。

**资料 / 平台**：

| 资源 | 说明 |
|------|------|
| 跟读素材：6 Minute English、TED | 有文稿的都行 |
| **AI 语音陪练**：ChatGPT 语音 / 豆包 / Speak App | 零社恐、随时练，先用它过渡 |
| **真人对练**：italki（一对一，菲教/欧美外教）、Cambly | 每周 1–2 次，几十元/节，最有效 |
| 发音专项：《American Accent Training》/ YouTube「Rachel's English」 | 系统纠正发音 |

---

## 4. 写作（有套路，投入产出比高）

**方法**：先仿写，再自由写，**一定要有人或 AI 批改**——
1. **背 + 仿**：积累好句型、连接词、地道搭配。
2. **每周 2 篇**：一篇议论/说明文，一篇自由日记或邮件。
3. **必须批改**：把作文发给 AI，让它按 **语法 / 用词 / 结构** 三点反馈并给地道改写。

**资料**：

| 资源 | 说明 |
|------|------|
| **《雅思写作 顾家北手把手教你写作文》** | 从句子到篇章，中国学生写作最实用的书（不考雅思也值得用） |
| **AI 批改**（发我 / ChatGPT） | 按"语法·用词·结构"三点反馈 + 地道化改写 + 解释 |
| **Grammarly** | 实时抓语法拼写错误 |
| Cambridge Dictionary / Longman | 查词看例句，学地道搭配 |

---

## 5. 通用原则（贴在显眼处）

1. **每类资料只选 1–2 个用到底**，别来回换。
2. **说 + 写才是真正卡你的地方**，别躲。
3. **精听 > 泛听，跟读 > 默听，仿写 > 空想**——主动加工才涨功力。
4. **量比难度重要**，能坚持的材料胜过硬啃高难度。
5. **闭环反馈**：口语找对练、写作找批改，否则错误固化。
6. **连续性 > 单次时长**：状态差也别断，缩短就行。
