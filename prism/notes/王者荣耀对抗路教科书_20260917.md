## 0. 主旨：掌线权者掌节奏

一句话模型：**对抗路拼的不是对线操作，是每一波兵线的处置权。**

- **前 4 分钟**：先分清强边 / 弱边（唯一标准：一级线好不好抢）——强边保每波线权都优 + 占进攻点位；弱边放线进塔保资源 + 半靠过渡蹭野补速率；
- **中期**：一切进退只看两个数——**支援距离**（打进攻方走得更远、支援更慢）与**人数差**（人少不进野区：假打野区、真打推进线）；
- **后期**：边路是推进发动机，两种模式二选一——**打三线**（绝对优势 + 全图快的英雄，如孙策）或**打半图**（四一分带且「一」与「四」同半图，如达摩：找夹位、推高防夹位）。

认知重构对照：

| 低分认知 | 教科书认知 |
|---|---|
| 对抗路 = 单人 solo，拼换血操作 | 兵线运营 + 野区联动，拼「每波线的处置」 |
| 线劣 = 被压制、没事干 | 弱边有完整动作链：放线进塔 → 保赤甲 → 半靠 → 蹭野补速率 |
| 强势 = 多杀人 | 强势 = 每波线权都优 + 占进攻点位 + 把对面堵在家里 |
| 见资源就抢 | 拼野怪拼斩杀线；抢不到就放给对面，不亏状态 |
| 后期跟团站桩 | 四一同一半图：一找夹位 / 护线运线，推高防夹位，被夹会拆火 |

视频自身结构：**前 15 分钟对线期**（梳理思路 + 弱边曹操、强边孙策两个第一视角 + 作者自带 8 条归纳）→ **中段约 5 分钟中期节奏**（龙点人数差、进野区速率判断）→ **后 19 分钟两种后期模式**（打三线、打半图各一整把素材）→ 收官总结。

## 1. 对线期：前 4 分钟

### 1.0 两个前置认知

- **克制关系**：需要大量经验积累（作者留了弹幕 / 评论区答疑入口）。但强边 / 弱边的区分只看一条：**一级线好不好抢**。狂铁毋庸置疑好抢 = 强边；曹操前期线权难抢 = 弱边（中后期发力的英雄，前期忍）。
- **草鞋出门**：必须学会的基本操作——更快 → 提前赶到点位（三个案例的第一步都是它）。

### 1.1 弱边怎么打：小罗曹操 vs 狂铁（第一视角一）

**开局阵容分析链（为什么弱边开局落位在野区）**：

| 环节 | 判断 |
|---|---|
| 自家打野 | 发育路野区开 → 对抗野区空 |
| 敌方中野 | 姜子牙 / 阿狸 / 空空儿可换线或三人同时走中 → 中路线权优 |
| 敌方对抗路 | 狂铁一级线权强 → 上路也优 |
| 结论 | 中上皆优 → **敌方打野有欲望进我方对抗野区** → 曹操必须**提前落位对抗野区**看视野 / 人员分布（比赛中出现的独特打法则「当无事发生」即可） |

**抢线细节（弱边摸兵的窗口）**：狂铁不交一技能时不好摸兵；**但凡交了一个一 → 就可以去摸对方前排兵**（摸后排兵来不及，摸着摸着会被锤）；上去 3A1 接平 A，被锤一下但不会被锤一路 → 立刻拉回来。

**放线**：把兵线放进塔 → **塔帮我们提速清兵 → 更快去摸赤甲**；期间注意补刀。

**对抗路三个点位**（红蓝方位略有不同）：

| 点位 | 位置 | 作用 |
|---|---|---|
| 防守点位 | 靠塔一侧草丛 | 弱边默认位；**留意对方动向**（有没有人提前钻草、狂铁会不会来摸赤甲） |
| 进攻点位 | 压前 | 强边 / 确认没人能威胁时占 |
| 保守进攻点位 | 取中间值 | 拿了线权但队友走开 / 敌方可能贴边时占（进可攻退可走） |

**视野换资源（信息联动）**：曹操占防守点位照出「狂铁回去拿美味烧鸡」→ 嫦娥（我方中路）知道我方赤甲没压力 → **不用过来帮打，掉头去帮打野提速摸野怪**；曹操等兵线进塔提速后自己摸赤甲也来得及。

**空间灵与放线补兵**：狂铁摸完美味烧鸡出来会拿空间灵（顶线在上路）→ 空间灵更抢不了，这波线只能放线；**放线时前排兵注意补**（放线时兵线互相磨损，曹操留二技能补前排兵）。姜子牙往前压 → 兵线就往后拉，补完就 OK。

**半靠（前期核心动作）**：

> 曹操站在河道中间，**随时靠得过去中路、也随时回得了对抗路**——这就叫半靠。

中路打起来 → 随时支援；中路无事 → 回线或「找点事情干」：帮夏侯惇（打野）补小野怪提速。原理：夏侯能到边路点位找机会，是因为**放了一片野怪 + 有嫦娥帮他提速** → 现在要补回丢失的野区速率 → 边路蹭小野是合理动作。

蹭野规则：低端局队友不给蹭就不蹭（分段打上去自然有队友给蹭）；**尽量不补打野的尾刀**（经济收益归打野）。

**后续节奏链**：嫦娥靠过来想抓机会 → 可以顶前配合（狂铁敢出来打 → GANK 狂铁；够谨慎就算了）；对面视野全漏 → 大胆抢这波线权（CD 鞋出来了）；4 级后曹操强度提上来 → 按经济情况分辨强势弱势 → 决定兵线处理。

### 1.2 强边怎么打：狼队归期孙策 vs 马超（第一视角二）

**开局观测链**：孙策对马超，前中期线上能优、抢线快；**风险 = 对面张良可能边路开 → 一级必须先观测**。队友把中路顶出去 → 提前看到对面视野 → 无野区防守压力。先落位边草，等「张良在哪」：中路没照出张良 → 这波线不能直接抢；**发育路把张良照出来了 → 这波线就可以抢**（点二技能直接刮三只兵）。

**野怪博弈（拼斩杀线）**：

- 过完线想的是：拿对面美味烧鸡，还是拿自家赤甲？拿烧鸡希望有队友帮（**进对面野区有减伤、拿得不够快、可能被马超一枪抢回**）；看中路没人靠过来帮 → **优先拿自家赤甲（更快）**。
- 拿完赤甲再看烧鸡好不好抢：**拼野怪拼的就是斩杀线**（孙策用 1A / 1A2 拼高斩杀线）。马超第一时间反应过来、不和孙策一起压低烧鸡血量 → 孙策交完技能再傻站着 A 烧鸡会被打很多状态 → **不好抢 → 放给马超，抢下一波线权**。这就是细节上的小博弈。

**卡线（要练成肌肉记忆）**：惯性 = 卡对面前排兵；队友靠我们这边 → 大胆上去卡线；马超敢上来摸前排兵 → 进入射程，顺带打他血量；对方卡好一个很细节的距离 → 摸不到就不硬接（空间灵不接就不接）。「平时的分段，只要注意好这些卡兵线的细节，一定能在线上对对方进行有效的血量置换。」

**强边行为链**：

| 条件 | 动作 |
|---|---|
| 拿到线权 + 中路没事干 + 没到 4 级 + 没野区资源 | **能提供的作用就是视野** → 站点位：强边占进攻点位（弱边才占防守点位） |
| 中路昭君交闪、梦奇交大（没人能威胁） | 尝试顶进进攻点位 + **保证每一波线权都是优** |
| 为什么不摸赤甲 | 摸赤甲被马超抢先 → 空间灵就得还给马超 → 违背强边定位（线优 → 空间灵一直是我们的；物抗叠满十层，马超压不动血线） |
| 队友点信号（对面视野漏完，张良可能贴边溜过来） | 进攻点位草只能看到从红区过来的人，**看不到贴边过来的** → 这波线不好抢 |
| 队友靠过来了 | 可以进去抢：对面 combo 连不起来（我方庄周在，张良摁一下摁不死，庄周可解昭君控制）→ 把张良 + 昭君一套破掉 |
| 队友又走开了 | 退占**保守进攻点位**：张良进 L 草也能第一时间退走 → 他一直没机会 GANK 这边 |

**支援细节**：孙策 4 级，这波线不做顶线清 → 意图是**腾出位置随时摇大招支援**（比较团队的行为，路人局不一定适用）。因为若顶线清，马超能及时开疾跑拦截、不好开船；拉到塔前点位再开船，**马超拦不住**（原话笑点：「马超像个无能为力的丈夫」）。

### 1.3 前 4 分钟知识点归纳（视频自带，口播原文）

1. 开局想好第一波线权的处理；
2. 每一波线都要分清楚线权强弱；
3. 部分英雄四级就会有强度的变化；
4. 根据不同情况能占三个草丛点位（红蓝方不太一样）；
5. 野区资源可以帮打野提速；
6. 野怪刷新时间要记住，墙边可以摸对方小野；
7. 弱边可以保护自家野区、通过蹭野怪过渡；
8. 前期半靠行为：保证不错过打架对抗的节奏以及回线发育的速度。

## 2. 中期：速率与人数差（继续孙策视角，对面张良 + 王昭君组合）

### 2.1 4 分钟龙点

对面没先摸龙（类似路人局节奏：4 分钟一到大家都还没动龙）→ **只要是还没开始摸龙，线强的边赶紧把线顶出去** → 对方边路必须上来对抗路接线 → 接线的时候你就**争取到了龙坑的人数差**（我们人多、对面人少）。孙策这类有大招全图游的英雄：先把打野还没来得及收的小野怪收掉，再开船打过去也来得及。

### 2.2 团战目标选择（第一波大碰撞）

团战大碰撞之前要想好：**手上这个英雄，打的是对面的哪个目标**。孙策大招用来**拆张良**（张良 + 昭君摁住队友之后可以拆）→ 目标应当很明确：**冲对方的后排**。梦奇不归孙策管；马超大招插过来，队友靠自己也能逃生。大招拆掉张良 → 大司命就能走开、继续帮队友拆火 → 闪现调位打马超。**拦截对方后排 + 帮队友拆火，一个梦奇打进来不足为惧。**

### 2.3 进野区判断（路人局打野狂点集合想进蓝区，怎么分辨好不好进）

| 判断项 | 本例 |
|---|---|
| 刚才团战 | 三换三，双方都从泉水出来 |
| 但方向 | **我们打进攻：队友拉过来的距离更远 → 对方支援速度一定比我们快** |
| 结论 | **对方才是人多打人少的一方 → 这个蓝区不好进** |
| 但可以 | 给点压力：身位半靠两边；趁大司命给蓝区压力，**赶紧把下线过了才是正节奏** |

> **给蓝区压力不是为了成功进这波蓝区（有人数差，不可能进）——是假打蓝区，真正为的是把这波推进线打过去。**

### 2.4 五零抱团与「看屁股」

队友想打红区：同理判断速率——对方 all in 刚在这个区域漏了、要管一波下路线 → 我们动起来速度比对面快；我们位置是**五零（什么叫五零？就是五人抱团）**。

这波劣势线（马超过的）来不及管：过去兵线也差不多没了，反而会被以多打少 → **第一时间跟队友抱一起，帮队友看屁股** → 马超漏了位置 → 打退马超 → 接队友摸完红 → 退 → 安稳过线。「这就是中期稍微复杂一点的节奏画面，但只要把自己的思路理清，其实还是不难的。」

### 2.5 帮打野提野区 + 不上头

- 帮大司命提速的原理：我们刚把对面野区进了一波 → **打野亏自家野区速率 → 帮他把整片野区都提完**。
- 开船后看队友走位：到这里已经能判断**没有什么后续、不可能直接越塔杀 → 不要上头 → 回头**，顺便扔一条船出去看马超位置。不怕马超：有被动 + 布甲鞋 + 做不祥征兆。

## 3. 两种后期兵线运营模式

模式选择一句话：**队伍绝对优势 + 英雄速度很快（如孙策大招开船全图切）→ 打三线；除此以外基本都是打半图。**

### 3.1 打三线（孙策案例）

**定义**：三条线同时运作——对面马超管他们的线，孙策管上线，队友管下线，中路依旧有人管线。

**对面 miss 时兵线进塔怎么清**：孙策第一时间挂在边路不动；**等庄周、队友慢慢靠过来 → 再上去清**（甚至可以把自己卖出去——对方哪怕开这波团也打不过我们）；对面漏视野 → 安稳清线；身位继续顶出到进攻点位。

**半图视野（过线的前置条件）**：中后期要过兵线，前置条件是**有半图视野**——要清的是上路这条兵线，对应的就是**对抗路半图那一块的视野**。

**截线（职业节奏快的核心）**：

- 相对固定的画面：**队友帮你把红区的口子占好**（能站到最好；占住对方的红背也可以）→ 对方很难从口子插过来包夹 → 能出来的只有上路二塔或红区上口子 → **做不成包夹 → 这就是可以去截线的节点**；再叠加接的英雄是庄周 → 不怕连续控制。
- 截完这波兵线速率很快 → 上路兵线过得快 → 用上路兵线给对面推进压力 → 队友起推进 → **上路一塔顺势爆破**。
- 「为什么职业比赛里面他们的节奏会比较快？因为他们能很好地分辨出来，什么时候我可以去截线。」

**10 分钟节点：远端线**：

- 10 分钟前**优先处理对抗路兵线** → 10 分钟节点就有一波相对于黑暗暴君的**远端优势线**（近端线 = 发育路兵线，离龙近；远端线 = 对抗路兵线，离龙远）。
- 对方想接远端线 → **漏视野 → 他们在黑暗暴君的地方就会人少**；对方接的是近端线 → 龙坑照样五个人在 → 这时候孙策要谨慎一点点。

**四拖一压中线**：对方视野全漏 → 孙策靠过来；这是标准的需要打架碰撞的节点，但也得有人去管线 → **队友正面用四个人拖住对方五个 → 空出来的一个人给对方兵线压力：把中线抢了 → 对方有中二塔防守压力 → 分人管中线 → 挤不进来**。打完龙一样：队友往中 / 上靠 → 我们过一波队友管不了的线（有大招的情况下，大家的速度并没有相差很多）。

**推进线节奏**：

- 没后续 → 绕一圈（船是加速的，可以正面撞一个船用来拆）；拆完没船 → 不好这么快退过去接劣势线——**一退，队友这波推进节奏就走不成了**。
- 推进节点：下路还有推进线 + 后续连带两波线；把对方的线堵住 → 后续还有一波推进线。**状态好 → 赖在这里一直打到两波推进线打完；状态不好 → 退过去管劣势线；无论如何，先配合队友打完这波五零抱团的推进节奏。**
- 推进线还没打完 → 依旧可以压：大招、技能闪现接冰甲，目标非常明确，还能骗掉一个闪现。

**中下速率线与回家时机**：

- 取消回城的原因：队友想堵下线 + 对方掉了两个点 → 上路劣势线变成**平线**（两边兵线互相磨损、没人加速）→ 上路根本没有防守压力 → 现在着急的是**把中线顶出去** → 下线也过来 → 中下差不多速率的两波线 → 把对面堵在家里（下路要管、中路也要管）→ 队友顺带先给中压力 → **切到打对面红区的时候，才是慢慢清理上路兵线的节点**。
- 上线不急的另一面：虽然有船，但管完上线还是要回家；**残血状态一直明视野漏给对面 = 告诉对面「有个残血孙策」→ 他们就敢压出来** → 清完中线赶紧回家补状态。

**主宰先锋运营**：

- 下一波节奏非常明确：打主宰。打完主宰下线不需要我们管（**下路有超级兵会自己带过去**）；**先锋（龙兵）不放下路，放中上都行**；孙策只需要管边线或中线——**哪边没有队友管，就归我们管**。
- 主宰先锋所在那条路有减伤 → 正确用法：**先给上路压力 → 兵线顶出去 → 对方分一个人在上路管线 → 切到中路打起来**（中路有先锋减伤，打得更舒服）；对面但凡敢守 → 撞船进去接冰甲打；对方不敢接 → **这里就可以一波了**。

### 3.2 打半图（达摩案例）

**定义：四一分带，且「一」必须和「四」同处一个半图**：队友的四在中 → 我们这个一在上或下都可以（都跟队友同一边）；**四在上 → 一不能再上 → 一去中路**（四下同理）。推上高时：四个人在上路做推进 → 一去中路。「还是半图，非常简单——理清楚了，就能明确自己每一步的动向。」

**夹位（半图核心技巧）**：

- 定义：队友顶前，对面要守塔 → 那个位置就是**夹位**；**侧边进场和队友形成侧面包夹 = 夹位，前后夹击也是夹位**。
- 时机：**优（U）完一波边线，就是很好找夹位的时机**——同时看对面视野在哪漏完，预测下一波节奏节点。
- 前提：**找夹位一定要提前预判这波会不会出现对抗节点**（例：拿完龙之后对方想守蓝区 = 很标准的能打起来、且能找夹位的节点）。
- 走法：上线不急着清、**不漏视野直接从小地图这边绕过来**；对面想退 → 直接拉过来夹；哪怕中路兵线到位是明视野也无所谓——**对方必守这个蓝区 → 进退两难** → 夹位成功帮队友控住一波蓝区。
- 收益：**对方阵型后排靠后 → 找到夹位，能第一时间碰到对方的后排**（职业对决不会给你这么多机会）。

**10 分钟标准掉点（与巅峰路人局最像的一段）**：10 分钟前掉点 → 队友能稳拿龙 → 达摩把上路兵线看情况优掉；龙这边不需要这么多人 → **落位直接落在对面的红区**。**线是对称的：我们的线来到这个地方，对方的线一定也来到对应的地方** → 可以考虑把下一波线截住。

**半图分工**：射手走边路 → 射手那一路可以起推进；对抗路英雄不好起推进 → **这个「一」负责护线，运线推进交给队友**。想阻断对方在队友面前「上嘴脸」→ 应当插进容易进攻的点位：**吃进对方的红区、踩住那个草 → 对方不敢挤进来、不敢去上路清线 → 永远躲在家里**（下二要守、上路兵线出不去、中二也要守 → 持续被堵在家里）。队友在中给到压力 → 自己身位可以继续嚣张一点 → **封锁住上半图**。

**次序（节奏不卡壳的关键）**：

- 为什么可以持续赖在这里打：**中下都有后续的推进线** → 留在中路继续打下一波推进；**给足压力 → 对面不敢守 → 这时候才轮到去管线的节点**：推进线已经用完 → 要**造下一波推进线出来** → 节奏才不会卡住——**都是有次序的**。
- 打掉影一波状态 → 影不敢再绕去上路 → 一样的打半图：队友在下路 → 达摩把中线接了；上路不急着清。

**野区速率补回**：进了对方的野区 → 自家野区速率会落下；两片野区同时刷，大司命反杀了对面的蓝、而我们身上空蓝 → **拿个蓝很合理 → 把整片野区都提完 → 接下来才是去做兵线**。做兵线不要急：**先分清楚半图在哪一边**（队友在中打中四、我们身位靠上 → 打上路的半图）；等队友顶进去 / 提供半图视野 → 顺势出去把兵线优掉、把下一波截住。

**推进与拆火收官**：

- 抓掉影之后：下路有主宰 + 龙兵压着中线对方没空管 → 把中线带过来 → 中下都有一波推进线 → **先打完这波推进节奏**（上路二塔不需要急着管）；对方掉点 → 抓紧机会打进攻；还有连续一波推进线 → **多打一波推进节奏再重新整理**。
- 队友去推中路一塔，我们边路不是做推进的 → 去管下路兵线很合理：**不让对面快速处理好下路线 + 给压力 → 对面分人管下路 → 中路兵线失守 → 队友把中高推掉**。
- 黑暗暴君不需要我们 → 前去上路；队友帮我们罩住中轴 → 对方不可能来顶这个地方包夹 → 管上路兵线相对轻松；哪怕对面追击 → 往大道退就行（打半图一定互相照应、互相协防）。
- **中后期管兵线三问：这波兵线的压力重不重？被追的话撤退方向是哪？打半图能不能互相协防？**

**防夹位（推高时角色反转）**：

- 为什么推高的时候从「找夹位」变成「**防夹位**」：**推高总不能从对面的泉水过来夹对面吧——只有对面夹我们的场景，没有我们夹对面的场景** → 推进高地时，边路更多时候做的是防夹位。
- 细节：下路超级兵会把下路线自然送过来；队友信号的意思是**影会来截线 → 达摩要提前动起来把影截住、不给他优这波兵线 → 保证中上依旧是推进线**；影一直没在正面漏 → 大概率在屁股（后方） → 成功护住队友。
- **后期团战思路：哪怕对方真的找到了一个夹位，我们也能第一时间拆火，不让对面打到过多的输出** → 对方身位已经没办法退走 → 优势被一波结束。
