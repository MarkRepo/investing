## 0. 主旨（30 秒版）

**经济 = 自然增长 + 兵线 + 野怪 + 击杀四要素；击杀只是额外提速手段。** 本期的胜负手是「多人共享经济团队收益更高」这一组精确数字（两人吃线 210% > 一人 150%），以及由此推出的**最强经济分配模式**：辅助在场让打野蹭中线从 50% 涨到 130%、中野互提速、射手吃双线——通过辅助动向提高打野强度 → 加速射手发育 → 解放中路协助对抗路。**零人头的对局，莫名其妙就比对方多几百过千经济**。这也是职业比赛中 AG 的经济比其他队高一档的原因。

## 1. 分均经济：概念与基准线

- 常听博主说「分均 1900」，含义是每分钟平均获取的经济。
- **分均不是均匀的**：前期（4 分钟前）每分钟可能只有 ~600，后期 11 分钟节点单分钟可能有 ~1000，整体拉平均才是分均 800。原因：英雄成长性高于兵线野怪，**越刷越快**。
- 基准线（对照自己主页-游戏栏-主玩分路详细数据）：

| 分均经济 | 评价 |
|---|---|
| ~800 | 偶然一把已经是 C 了 |
| 900–1000 | 带飞局 |
| ≥750 | UP 主学员靠熟悉兵线野怪稳定达到的线 |
| ≥800（无击杀） | 本期视频的教学目标 |

- **击杀 = 提速（复利）**：对 C 位来说，额外击杀经济让「本该一分钟赚 600 的赚成 700」，更快做出装备 → 下一分钟不用击杀也能刷出 700。这就是**让人头给 C 位重要的底层原因**——击杀是额外获取经济的手段，很多玩家没深刻体会到让人头的重要性。

## 2. 峡谷经济学：机制数字

### 2.1 基础加成

| 机制 | 数值 |
|---|---|
| 补刀 | 兵线 +50% 额外收益 |
| 二级/三级打野刀 | 野怪 +30% 经验、+20% 金币；且**单独**获得兵线 50% 收益 |
| 辅助宝石 | 蹭兵线收益是成长性的：**前期 25%，后期 50%** |

### 2.2 多人共享经济（核心）

| 场景 | 中单 | 打野 |
|---|---|---|
| 中野同吃中线，兵**全都没补到** | 100% | 50% |
| 中野同吃中线，**全都补到了**（无论谁补刀） | **150%** | 50% |
| 中野同吃野区 | 80% | **156%** |
| 中单扔技能就走、打野**单独**吃野区 | — | **180%** |

- 打野刀的独立经济（兵线 50%）**不受补刀影响**，无论如何都拿原有的 50%；辅助装蹭线同理。
- 蹭兵线（打野/辅助来吃线）现在**全分段已通用**，但「提速野区」（中帮打野清野）暂时还没普及。
- 问题：打野来中路蹭兵线会**影响自己的野区速率**——为 50% 兵线经济拖慢野区，打野前期做不了事情一直在刷。所以需要**中野互提速**：打野帮中清兵、中单帮打野清野（见上表 156%/80%）。

### 2.3 多人吃线的团队总收益

| 吃线人数 | 团队收益 |
|---|---|
| 1 人 | 150%（补刀） |
| 2 人 | **210%** |
| 3 人 | 215% |

**一到两人这个跨度最大** → 最大化收益 = 两人加打野或辅助吃线。（打野刀和辅助宝石的单独额外收益不计算在「人数」内：**打野和辅助吃兵线的时候不算人；打野辅助同时在场时，打野算人、辅助不算人**。）

### 2.4 弹幕考题：中野辅三人吃中线，打野拿多少？

答案：**最高 130%**。规则拆解：

- 当**辅助到位**时，打野刀的「单独计算」**不生效**；
- 打野和中单**不补刀**：各拿 80%；
- 一人**单独补完全部刀**：拿 130%，另一人拿 80%；
- 辅助宝石额外拿 25% 以上。

**峡谷经济学核心要点**：只需加入「辅助」这个变量，打野蹭中线就能**从 50% 变成 130%**。中单兵线经济被分走，但更高团队收益让打野完全可以接受中单一同吃野区。比起旧的「打野蹭中、中单提速不失野区」，这种方式团队多出 **10% 兵线经济 + 56% 野区经济**；隐形加成：辅助帮忙更快清中线、中单帮忙更快收野区、经济调配给前期转化率更高的打野位。

## 3. 五路发育公式（按强线权 / 弱线权分型）

### 3.1 中单 · 强线权（抢线快、有游走权）

- 最好用的方法：**半靠其中一条边路**；如果没打起架就**不要完全靠过去**——第二波线就能快速回中，继续抢第二波线权。不错过 GANK 边路的节奏，哪怕没节奏也吃到每一波中线。
- **半靠哪边？看打野刷野动向（反向对称）**：

| 打野开局 | 中单半靠 |
|---|---|
| 发育路野区开 | 对抗路 |
| 对抗路野区开 | 发育路 |

- 原理：当打野刷到另一边野区时，你刚好也在这边；你回中的路上就**顺道帮打野提速**，后续打野出来一起帮抢中路线 → 吃到额外野区经济，中线留着和打野一起吃。
- 一句话公式：**有线权的中单，预判下一片野区刷新，往那边出节奏，回中时顺带替（补）打野的节奏**——一边游走一边蹭经济，还帮打野提速了。简单无脑且好用。

### 3.2 中单 · 弱线权（抢线慢）

- 核心技巧：**反跑挂边后提速**。「反跑」= 对方抢线比你快、会先去游走；第一波清完，我们**半靠没有敌方中单的那一边**。
- 队友要争夺野区资源或打架 → 完全靠过去**以多打少**。
- 我们是后清线，支援完队友**来不及回中** → 第二波线**完全放给打野**，自己挂在边路半图施压。
- 打野后续打的是另一边野区、我们回不去 → 顺带提速、继续挂这边施压；另一边有我方打野刷着、能随时支援，不会有过多压力。
- 等打野**第二轮野区刷新**时，帮他提速的**同时顺道回中**。
- 本质（字幕原词「转列为优先」，存疑，按文意应为「**线让给核心位优先**」）：**把中线经济集中给前期的核心位（打野），自己挂边帮其中一条边路，保证前期优势不受中路劣势影响**；第二轮野区再帮打野补回节奏，同时蹭野区给自己补回经济。这就是中单的两条发育公式。

### 3.3 对抗路（与中单有大量同款逻辑）

**30 秒时看打野刷野动向、哪片野区开刷。**

强线权（能摸线、能摸对方资源）：

- 一轮野区资源 + **空间灵**，能拿多少拿多少。
- 2 分钟还能抢到线权 → 继续摸对方**二轮刷新**的野区资源。
- 有线权但对方来支援、不好摸对方野区：打野是对抗野区开 → 回来帮打野提速二轮野区；打野是发育路野区开（字幕原音含糊）→ 对抗路野区还是空的，**抢完线后夹击中路**——对方对抗路忙于过边路兵线来不及支援中路，中路有一波临时节奏机会；**2:50 左右再回来提速对抗路野区**。
- **提速目标**：蓝方提速小蜥蜴、红方提速红 Buff。
- 效果：分均经济比之前**高出不止 100**。

弱线权（线也不好摸、资源也摸不到）：

- 2 分钟前只需要保证**状态**和**自家野怪资源**。
- 技巧（兼并发育和出节奏）：**过完一波劣势线，立刻夹中和敌方对抗路打「下一波兵线」的时间差**——下一波线本就是对方先抢，利用这段时间先夹中、再回对抗路接劣势线 → 容易出临时节奏，爆发额外人头经济。
- 2 分钟或 2:50 抢不到线权 → 帮打野提速就可以了；**其余时间都利用时间差去夹中**。

### 3.4 发育路

- 看打野开局动向：**发育路野区开 → 2 分钟提速；对抗野区开 → 2:50 提速**。
- 提速目标（与对抗路镜像）：**蓝方提红 Buff、红方提小蜥蜴**。
- 射手与战士的区别：**部分没位移的射手不好夹中，半靠中路即可**——这也是这个射手版本射手前期很难出节奏的原因。
- **中后期开始吃双线**，标志事件 = **发育路一塔爆破**（两种情况都利用兵线速率差）：

| 情况 | 动作 |
|---|---|
| **敌方**一塔爆破 | 在二塔前**提前截断对方发育路兵线**，来得及切去中路吃双线 |
| **我方**一塔爆破 | 先和队友把**中路顶出去吃中路线**，再回发育路二塔前吃劣势线 |

- 期间被留下了兵线 → 收野区就可以；野区都没有 → 没办法（「发育公式摆在这，也还是需要队友有点脑子的」）。

### 3.5 打野（三种路线，按英雄强度选）

前提：对英雄强度有基本了解（边野 2V2 / 中野 2V2 打不打得过对方打野）。

| 路线 | 条件 | 打法 |
|---|---|---|
| ① 边野 2V2 打得过 | 对抗路侧能赢 | **发育路野区开速刷**，刷到对抗路野区时**放掉一片小野（蓝方放蜥蜴、红方放猴子）**，直接去对抗路抢空间灵；抢完空间灵上线后 **TP 去中路再吃一波**；后续把野区清理干净。**前 4 分钟都可以循环** |
| ② 中野 2V2 打得过 | 中路侧能赢 | **发育路野区开**，吃第二波中线后再收对抗路野区，**把中轴做强**；线权优出去后控对方**小猪**：对方红区开 → 2 分钟抢中线控小猪；对方蓝区开 → 2 分钟抢中线后先收自家野区下波线、再抢中控小猪。发育路野区开的打野 **4 分钟控龙后顺带收发育路野区** |
| ③ 边野中野都打不过 | 前期弱势 | **对抗路野区开，不争空间灵**；速刷野区后**利用和对方打野的位置差/时间差蹭发育路兵线**、打这一边的节奏（蹭发育路兵线收益比蹭对抗和中更高，抢队友的补刀就行），顺带帮队友控发育路野区资源。前期弱势阵容效果不错 |

### 3.6 辅助（全部东西都要懂）

- 辅助的发育公式 = **保队友发育**。方法（UP 主称为「超脱大部分玩家认知」）：**照敌方打野所在的半图跟着走**。
- 敌方打野发育路野区开 → 辅助 **1:30 就可以选择靠中帮中抢线**：和敌方打野同处一边，对面一定没有我们支援快；这波无事发生、敌方打野回到发育路野区 → 我们也回发育路对线，仍同处一边，**随时切半图**支援队友。
- 反面：敌方打野在打对抗路半图时我们还在发育路，支援对抗路要**切全图** = 基本上是看着队友送。
- 信息量拆解：① 得知道对方打野什么开；② 每一步靠中都能帮队友**三打二过中线**；③ 利用辅助宝石机制把经济先集中给打野位；④ 然后去发育路野区**提速一波野区一波线**——辅助发育比对方更快、**更快到四级**。
- 这就是「游戏理解极高但又非常简单」的游走公式。

## 4. 总结：最强经济分配模式（AG 模式）

- 职业比赛上 **AG 的经济比其他队伍高一档**的打法链条：
  1. 辅助帮发育路拿完资源后**来夹中**，让辅助宝石生效 → **经济集中给打野**；
  2. 打野**和射手共享发育路野区** → 两个核心位置经济都提高；
  3. 前期本应该做事的中单**不再需要过多帮打野提速** → 去帮对抗路争夺资源以及抢线。
- 一句话：**通过辅助的动向提高打野强度 → 加速射手发育 → 解放中路协助对抗路**。
- 结果：同样零人头的对局，莫名其妙就比对方多几百过千经济。「这就是当前以及未来几个版本的峡谷经济学。」
