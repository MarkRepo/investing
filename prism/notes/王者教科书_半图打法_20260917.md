## 0. 主旨

**峡谷分为上半图 / 下半图，我方的主动节奏同一时刻只会出现在其中一边（人多的那一边）。**

- 判断半图：己方看自家打野的开局走向（蓝开往下刷 = 下半图；红开往上刷 = 上半图），敌方看对方打野哪个 Buff 开。
- 跟着己方半图出节奏，另一半图收缩避战；4 分钟后每打一侧半图要把**防御塔 + 野区 + 兵线**三件事做干净，再轮换到另一侧（半图轮换），并用兵线速率差（防御塔减速机制、截线加速）让节奏越滚越快。
- 视频断言：完全理解透这套 4–20 分钟的大局观，可以随便碾压巅峰赛 2400 分以下。

## 1. 问题与答案：什么是半图打法

- 过往"王者公式"系列讲的都是开局如何走相对固定的路线；本期回答的问题是：有没有一种核心打法适用于所有位置、所有分段，让玩家从零变一、从新手变高玩。
- 答案即半图打法：对所有分段甚至职业选手，都是每把对局的主心骨。
- **原理**：把峡谷地图分为上半图和下半图，主动节奏只会出现在其中一边；半图打法不允许上下半图同时出节奏——下半图击杀、上半图被击杀，这波节奏就完全不转（等于白打）。
- **用法**：把第一期"时间轴"的精简版与半图打法结合，所有位置就能非常明确自己在整把对局里该干什么。关键在于判断半图在哪一边——**就是人多的那一边**。

## 2. 0–4 分钟（对线期）：两种开局走势定半图

- 结构：**固定量是对抗路**（必在边线），中路、发育路各归各路；**变量是打野和游走**——打野可以上半图开刷或下半图开刷，游走随便游。半图跟着打野的刷野方向走。

### 走势一：打野蓝开往红区刷（= 往发育路方向刷）

1–2 分钟阶段，半图 = **下半图（中路 + 发育路一侧）**：

| 位置 | 该做什么 |
|---|---|
| 中野 | 在中路附近和对方摩擦 |
| 发育路 | 往前压 |
| 对抗路 | **不能往前压**：哪怕抢到线，也不好去抢空间灵（疑为"空间之灵"）和对方野区资源——上半图孤立无援，是不应该出节奏的地方 |

### 走势二：打野红开往上半图刷

到了 1–2 分钟节点，半图 = **上半图**：

| 位置 | 该做什么 |
|---|---|
| 中野 | 依旧在中路附近摩擦 |
| 发育路 | 不能往前压 |
| 辅助 | 发育路不能压 → 辅助不需要过多停留线上，来中路协防、帮抢线，让中野更快去打上半图 |
| 对抗路 | 往前压、占空间灵，甚至去摸对方的资源 |

> 弄懂这两种开局走势，前 2 分钟就简单了；绝大部分玩家只要掌握这两种，就已经可以走通前期。

### 进阶：加入敌方半图的判断（打还是不打）

- 判断链：**我方打野动向 → 己方半图；对方打野哪个 Buff 开 → 敌方半图**。综合两者即可决策。
- 例：我玩对抗路，我方打野往发育路刷（我方半图在下半图），此时我方中单来帮我抢资源，打还是不打？
  - **敌方打野蓝开打上半图** → 这波和中单一起往前压有风险，得考虑我方边+中能否打得过对方边+野，甚至要算上对方中辅。
  - **敌方打野红开打下半图** → 这波可以和中单一起往前压，不怕丢节奏；但己方下半图的队友就不好往前打了。
- 路人局情况繁多，但只要信息量够多，就能判断出应该打节奏的半图。

### 4 分钟前口诀

> **路人半图节奏：信息量得足够。一边半图人多，另一半图人缩；中野辅转线（抱团），双边照半图对线。**

## 3. 4 分钟节点：暴君打法（路人局与比赛局最大的割裂点）

- 4 分钟：野区保护和防御塔保护机制消失；暴君、主宰出现，当前版本侧重**暴君**（原因详见第一期教科书）→ 4 分钟时双方聚焦**发育路版图**。
- 这是大众路人局与比赛局最大的节奏割裂点。比赛/顶尖局在此节点有三种半图打法：

| 打法 | 内容 | 风险/收益 |
|---|---|---|
| ① 龙团对抗 | 双方固定打发育路半图龙团，谁赢谁拿全部：暴君 → 推发育路一塔 → 入侵敌方发育路野区，发育路半图资源全拿 | 高风险高收益 |
| ② 换半图 | 一方打发育路半图；另一方把发育路资源收干净后把龙放掉：对方想拿暴君？直接给。趁对方打龙赶紧收完发育路野区，己方放掉暴君（掉发育路一塔），集中人员去推敌方对抗路一塔。双方收益差仅一条暴君 | 低风险低收益 |
| ③ 各自发育 | 双方阵容都偏发育，哪怕拿下暴君也不一定能打起来/想打。拿完暴君的一方继续回守野区，不推进不入侵，利用暴君 Buff 加速自身发育。比赛里这是阵容决定；路人局里就是"拿完暴君不知道该干什么"，两边尬住 | 节奏放缓 |

- 第①②种节奏更快；路人局不用强求，走进第③种只是节奏放缓，之后一样能继续走半图节奏——大部分对局都会走进第三种。

## 4. 4–20 分钟：大局观与半图轮换（碾压 2400 分以下的核心）

- 视频称这是全片最重要的部分：完全理解透这个阶段的大局观，随便碾压 2400 分以下。
- 4–20 分钟可以用一个点讲清楚：**半图轮换**——打完一边半图，轮换到打另一边。
- 这个阶段打的是野区与推进（原音"五星"，存疑）；越高分段的对局节奏越快，靠的是**同时做入侵和推进**。
- 蓝方例：对方蓝区要刷新 → 下一波主攻半图选发育路半图 → 同时入侵蓝区 + 推发育路防御塔 → 防守方面临防入侵与防推进的**双压力，只能二选一** → 这波半图节奏怎样都能赚到。这就是加快节奏的逻辑。
- **路人局的死胡同**：哪怕因为巧合走出来这种节奏，如果不轮换（"来都来了"，打完蓝区继续一路推进），对抗路那边还得处理线 → 节奏散在全图，敌方看到你在对抗路漏了人，就容易集中人手在另一边半图打掉点。
- 解法就是半图轮换：把发育路半图打干净后**立刻切到另一边半图**。野区是轮流刷新的，只要切到另一面就又能继续打——对抗路的野区和对抗路的防御塔。

## 5. 各位置怎么做半图轮换

"一边半图人多，另一半图人缩"在 4 分钟后依旧适用且有延伸，针对的是负责带双边线的玩家。

### 5.1 战士刺客（对抗路 / 打野带线）

- 队友打发育路半图时：要**缩**并且**靠中**（称为"半靠"）——互相照应，并且能接应队友回中路。
- 等队友回到中路后做半图轮换，两种处理：
  1. **让另外四人去打对抗路半图节奏**，自己后续清理发育路兵线。原因：大部分战士刺客英雄不具备正面推进能力，和队友换线、自己切去下半图管兵线更符合各自的定位。
  2. **如果这波半图节奏连带着入侵野区打架**，就需要五人抱团来打这边半图，不要急着切图管兵线。

### 5.2 发育路（射手）

- 跟随大部队打完野区和一波推进后，**尽量不要连续打两波推进**，提前想好半图轮换：往中靠，然后切到另一边图。
- 路人局最常见的问题：没有半图轮换，哪怕你指挥了，队友也不知道该怎么做。两种情况的处理：
  1. **队友想打对抗路半图**：配合五人抱团进野区，并且逐渐切图到对抗路去推进。
  2. **队友没想法、换不了线**：打完发育路半图后**靠中**（这一步很关键），和队友一起把中线顶出去，这样敌方就没办法出来。之后无论队友是不是跑去对抗路，你都可以安稳回收发育路野区资源——"一边半图人多，另一半图人缩"，射手缩起来打钱。
- **为什么有的射手发育很慢**：没有先顶中吃线再收野区。如果不顶中就回野区，刷完野区再出来，会发现草丛、河道被敌方占了，不好出来，甚至想去发育路收兵线也不好去——因为发育路半图黑了（没视野）。
- 射手正确的发育与推进节奏：**推进完 → 顶中 → 收野 → 收下线**；狠狠发育完后，对方的发育路半图资源又刷新了，再去集合队友打自己这边的半图、给双压力。

### 5.3 中单（半图节奏的核心中轴）

- **中轴** = 中路这条大道 + 两边的草丛。谁先抢到中轴，谁就有**游走权**：先动起来、入侵敌方野区、没有任何阻碍地从一边切到另一边。
- 队友推进或入侵野区时，注意中轴情况：
  - **中轴没人留守（破防）** → 屁股会露出来，很容易被关羽这类英雄抄后路。此时中单就要自己做那个**留中**的角色，半图节奏才会密不透风，下波半图轮换的动线也更舒服。
  - **已有队友留在中轴** → 自己就可以动起来，配合队友打半图。半图人多时不用去中轴，节奏得持续。
- 留守中轴的人：中单，也有可能是辅助。

### 5.4 辅助

- 打半图时职能和中单相近；与 4 分钟前辅助游走的动向原理类似——4 分钟前队友打对抗路半图时辅助可靠中帮忙争夺中轴，4 分钟后同理。
- 如果对方往中轴放的人很多，只留一位玩家看不住屁股 → 辅助和中单都可以留在中轴，把对方的人卡住，队友就可以安全过线。

### 半图视野（"人多人缩"的进阶判据）

- 当队友把**中左草丛**站好、随时能往上靠 → 可以抢上路兵线权。
- 当队友占的是**中右草**、人多的半图是下半图 → 上路兵线就不好抢了：队友没办法帮忙拦截，支援速度也不够快 → 这边的半图就得缩。
- 这就是中后期清双边兵线的前置条件：**得有对应的半图视野**。

### 5.5 打野（找主攻半图的核心）

- 在所有分段的对局里，打野都是负责找主攻半图的核心。组织野区入侵节奏靠**野区速率差**：我刷得比你快，先把自家 Buff 拿完，再去入侵敌方的 Buff。
- 两类打野：
  - **天生刷野快的英雄（如镜）**：靠自己造速率差，组织队友进攻敌方野区，哪怕进不成自己也不亏任何东西 → 非常适合路人局上分。
  - **刷野慢的打野（如坦野，原音"弹野"，存疑）**：让队友帮忙提速野区造速率差，再靠非常强的对抗强度明晃晃进对方野区 → 只会出现在顶尖对局。这也是坦野在比赛里比刺野（原音"四野"，存疑）强、却不好上分的原因。
- **判断对方打野速率的局内方法**：不确定对方哪个 Buff 开/后续刷哪个 Buff 时，只需时刻盯着对方身上**没有什么 Buff**——Buff 持续时间 **70 秒**，红蓝野怪刷新 **90 秒** → 对方没有的 Buff 一定会在 **20 秒内**刷新 → 这个时间足够打野去组织入侵节奏。
- 知道了但队友不配合时，摆在打野面前的两条路线：
  1. 组织全体队友打半图。
  2. **自行抓一波小节奏**：明确对方野区刷新时间点后，就知道下一波对方打野得回哪边野区 → 利用速率差去**另一边半图 GANK**。路人局第二种非常好用，也更适合刺客英雄。
- 对中辅来说这也是一种游走思路：对方打野要回去刷野 → 另一边就可以组织越塔、抢中轴。例：看到对方打野要回对抗路野区了 → 拉上队友来发育路**四越二**（4 人越塔抓 2）。这是高端局常见的小战术。

## 6. 进阶：兵线速率

- **防御塔减速机制**：防御塔被破掉之后会有减速机制，减缓兵线的行进速度。
- 由此推出**尽量不要连续打两波推进**：推完一塔继续赶二塔，哪怕推掉了，这一路兵线也会吃到连续两次减速；不如推完一座一塔就去推另一路的一塔。
- 中期想加快游戏节奏，要做的是**兵线运营**——兵线越快，推进越快。
- 兵线的三个状态与控制手段：

| 状态 | 含义 | 控制 |
|---|---|---|
| 加速 | 兵线没碰到任何阻碍 | 想要加速：在兵线未相抵之前把敌方兵线截掉 |
| 减速 | 兵线行进被防御塔机制减速 | 不想减速：强行把塔推掉，保持兵线加速 |
| 停止 | 兵线与敌方兵线相抵 | 如果有其他事干，不需要着急处理 |

- 结合实际运用得当，可以让 C 位拿到**分均 900 以上的经济**。
- **实战例子**：打发育路半图，一塔推了、兵线被减速，不做连续的第二波推进，但继续往前给一波压力，**截掉下一波兵线**。两点好处：
  1. 敌方哪怕过来把这波兵线收了，也还需要继续等清理下一波——因为我们截断的这条兵线，实际对应的是后方那条兵线，**比敌方快了整整一波兵线的速度**。
  2. 队友回中时，中路的兵线才刚刚相抵 → 可以**同时吃到两路兵线**。原理：三路兵线相抵的速度是一致的，提前截掉一路，就可以去中路吃到两波兵。

## 7. 半图节奏总结 & 路人局轮换不了怎么办

- **半图节奏 = 三个点：防御塔、野区、兵线。** 三个点都做完，这波半图才算得上打干净了，才可以开始组织半图轮换。
- 路人局确实做不到半图轮换时，打好自己这边的半图需要一个**前提条件**（以发育路半图为例）：
  - 推掉了敌方（发育路）一塔，且**敌方没有换节奏** → 我方对抗路一塔还在。
- 满足前提后可以一直打发育路半图，循环：**截发育路兵线 → 顶中路兵线 → 收发育路野区 → 继续推进发育路**。
- 因为己方对抗路一塔还在，哪怕猛打发育路半图，对方想换到对抗路半图也一定会受防御塔减速、兵线一定比我们在发育路的慢 → 继续猛打发育路即可。
- 所以 4 分钟之后，无论哪个位置都要去熟悉**兵线的速率差**，才能更好地找准主攻半图在哪里。

## 8. 结尾感言（要点）

- 以上全部掌握 = 一名非常专业的比赛级选手，绝对可以碾压大部分玩家。
- 教科书系列是抱着良心做的：内容不难，但一般玩家很难接触到（UP 身份较多——教学博主、职业教练等，此处玩了几个玩笑称号）。
- 每一期内容打磨都接近三个月以上，所以更新速度慢，希望大家继续支持。
