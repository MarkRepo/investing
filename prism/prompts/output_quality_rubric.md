# Output Quality Rubric

每份产出完成后对照此 rubric 自评。

## 必须通过（任何一项不通过则重写相关部分）

| 检查项 | 通过标准 |
|--------|----------|
| 有具体数字 | 至少 3 处有具体数据（不是「较高」「约几倍」） |
| 多空兼顾 | 有乐观视角也有悲观视角，不是单一方向 |
| 有「哪里可能是错的」 | 每份产出都明确指出当前判断最可能错在哪里 |
| 来源透明 | 训练知识 vs 资料来源有区分 |
| 结论在前 | 核心判断不埋在末尾 |

## 加分项（有则更好）

- 有量化的置信度估计（「60% 概率」比「可能」更有用）
- 有具体的可验证节点（「下个季报/2026Q1 如果 X 则...」）
- 有反直觉的洞见（不只是重复卖方共识）
- 类比案例有具体时间和幅度数据

## 减分项（有则在汇报时说明）

- 字数超过 3000 字（过长难以消化）
- 结论过于中性（「需要继续观察」不是结论）
- 数据老于 2 年（除历史类比外）
