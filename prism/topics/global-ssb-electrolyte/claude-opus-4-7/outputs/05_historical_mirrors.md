## 成功案例（4 个）

### S1：NCM 三元正极商业化（2014-2020），潜在收益 +400-800%

- **类比维度**：技术替代 S 曲线 + 头部供应商高溢价窗口
- **核心节奏**：2014 NCM 622 商用 → 2017 量价齐升 → 2018 NCM 811 切入 → 2020 高镍渗透率短暂超 LFP
- **代表标的表现**：当升科技 2014-2018 股价 +5x；容百从 2018 IPO 到 2020 高点 +3x；杉杉前 3 年正极业务毛利率 30%+ 后压缩到 15-18%
- **对本主题的启示**：
  - **领跑者前 3 年溢价 + 第 4-5 年毛利率压缩**——容百 / 当升若 2027 真量产硫化物电解质，2027-2029 享受高毛利窗口，2030-2031 大概率被压缩
  - **路线对赌成败定生死**：杉杉早期押注 NCM 三元成功；天津国安押注 LMO 长期落败
  - **本主题映射**：硫化物 vs 卤化物 vs 复合电解质三选一，押错路线则零回报甚至负回报

### S2：LFP 价格断崖式下行 + 中国厂商规模化突破（2010-2020），潜在收益 +1000% (CATL/BYD)

- **类比维度**：中国厂商工艺规模化突破后的全球份额掠夺
- **核心节奏**：2010 LFP 量产 → 2015 价格从 80 万 → 4 万元/吨（-95%）→ 2020 中国占全球 LFP 产能 95%+
- **代表标的表现**：CATL 2018 IPO → 2021 高点 +12x；比亚迪刀片电池 2020 推出后股价 +6x；德方纳米 2019-2021 +8x
- **对本主题的启示**：
  - **硫化物 SLDP 隐含 ¥7,500/kg vs 远期 ¥4,000/kg 仅 -47%——按 LFP 节奏其实可能 -90% 到 ¥800/kg**（mat-756a01 / 父 mat-f6cc96）
  - **中国厂商一旦突破工艺会非常快**：但前提是 Li2S 千吨级 + 干法工艺定型，目前 2 个条件都未满足，**乐观节奏 2028-2030 触发**
  - **本主题映射**：赣锋 / 雅化 / 多氟多 / 新宙邦的硫化锂规模化是 LFP 之于 CATL 的"工艺突破"等价信号

### S3：光伏多晶硅卖铲人 2008-2011（保利协鑫）+ 2020-2022 再现（通威），潜在收益 +800-1500%

- **类比维度**：上游稀缺环节估值从被忽视到被透支的全周期
- **核心节奏**：2008 多晶硅 480 美元/kg 历史高点 → 2012 跌至 16 美元 → 2020 反弹至 270 元/kg（10x）→ 2022 高点后崩盘 -80%
- **代表标的表现**：保利协鑫 2009-2011 +5x → 2012-2015 -90%；通威 2019-2022 +10x → 2024 -70%
- **对本主题的启示**：
  - **赣锋的"硫化锂 + 金属锂卖铲人逻辑"高度类似多晶硅**——稀缺、上游卡点、规模化突破后崩塌
  - **估值高点信号**：当行业新闻每天讲"硫化锂涨价" + 二级券商出"卖铲人专题" + 上游公司 PB > 3 倍时（赣锋当前 1.6× mat-fd945b / 父 mat-e62c68 仍偏低），就是顶部前奏
  - **本主题映射**：赣锋 / 三井 / 出光的估值演进高度可能复制 2020-2024 通威路径——**2026-2028 上行 5-10x + 2029-2031 下行 -60-80%**

### S4：AI HBM 卖铲人（SK海力士 / 三星 / 美光）2022-2025，潜在收益 +300-500%

- **类比维度**：上游稀缺工艺被下游硬需求拉爆 → 估值快速透支
- **核心节奏**：2022 末 ChatGPT 发布 → 2023 H2 HBM3e 紧缺 → 2024 SK海力士股价 +200%、三星电子 +50%、美光 +150%
- **对本主题的启示**：
  - 跟多晶硅类比的差异：**HBM 路径是技术领跑者通吃**（SK 海力士 60% HBM3e 份额），多晶硅是工艺标准化后被掠夺
  - 本主题映射：**硫化物电解质如果出现"技术领跑者垄断"则更像 HBM**（出光 + 三井日韩派可能复制 SK 海力士的 60% 份额），如果出现"工艺标准化被中国掠夺"则更像多晶硅
  - **现在判断更像哪条？基于 mat-afa444 三井设投 +40% + mat-ec4e1e 出光 capex 仍持平，日韩派暂时领先但中国当升 / 容百正在追赶，结果未定**

## 失败案例（3 个，本部分必须重点呈现）

### F1：燃料电池（PEMFC）1990s-2010s 商业化推迟 20 年，潜在亏损 -80% 到 -95%

- **类比维度**：技术路线被多次"推迟 5 年"杀死，估值反复重估
- **核心节奏**：1990s 通用汽车 + 巴拉德 Power 推出"5 年商业化"承诺 → 2000-2005 第一波概念股暴涨暴跌（巴拉德 1999 高点 $150 → 2005 $5，-97%）→ 2010s 丰田 Mirai 2014 量产但销量从未突破 5,000 辆/年 → 2020s 韩国 / 日本仍在推但全球市场份额 <0.1%
- **代表失败标的**：巴拉德 Power Systems（最高点 $150 / 当前 $5 / 跌幅 -97%）、Plug Power（2000-2003 -98%）
- **对本主题的启示**：
  - **"5 年商业化"承诺是危险信号**——本主题中"2027 千吨级 + 2030 量产 100 GWh+"高度类似 1990s 燃料电池的"5 年"承诺，需要警惕 SLDP / Factorial / QS 在 2027-2028 重演巴拉德 2000-2005 崩盘路径
  - **SES 已经在重演这条路**（mat-ccf921 三家 OEM JDA 2025 全部 conclude / A-sample EV 产线改造为无人机线 / 2026 capex 转 AI 不投制造），市值已从 IPO 高点 -85%
  - **本主题失败情景估算**：SLDP 当前市值 $400M-$600M，若 2027 时点证伪 + DOE $50M 暂停 + SK On 单一客户砍单 → 现金 runway 缩到 18 个月以内 → 估值可能再 -60-80% 到 $80-150M

### F2：锂硫电池（Li-S）2015-2020 商业化失败，潜在亏损 -70% 到 -90%

- **类比维度**：技术先进性 ≠ 商业化能力，多个"突破"被材料工程难题反复打回
- **核心节奏**：2014-2015 学术界 PR "下一代电池" + 比能量 400-600 Wh/kg → 2016-2018 OXIS Energy / Sion Power 等小厂融资数亿美元 → 2019-2020 循环寿命 200-500 圈天花板未被突破 → 2021 OXIS Energy 破产 / Sion Power 转向无人机小众场景
- **对本主题的启示**：
  - **学术 PR vs 工程化是两个量级**——本主题中赣锋 "400Wh/kg @ 1100 次循环" + "500Wh/kg @ 10Ah 小批量"（mat-fd945b）数据非常类似 2015 锂硫的学术 PR，**乘用车 OEM 客户名单 0 披露**是危险信号
  - **场景从乘用车切换到无人机/eVTOL/低空**是失败前兆而非新机会——SES 2025 把 A-sample EV 产线改成无人机线（mat-ccf921）+ 赣锋唯一具名装机是沃飞 AE200 eVTOL（mat-fd945b），与 2020 锂硫从 EV 撤退到无人机如出一辙
  - **本主题失败情景估算**：赣锋若 2027-2028 仍无乘用车 SOP，半固态业务估值将从当前期权（PB 1.6×）回归到液态主业平均（PB 1.2×），股价 -25-40%

### F3：氢能源 2020-2022 PSA / SPAC 概念股周期，潜在亏损 -85% 到 -95%

- **类比维度**：美股 SPAC 概念股从狂欢到出清的 24 个月节奏
- **核心节奏**：2020-2021 Nikola / Plug Power / Ballard / Bloom Energy 等氢能源 SPAC 平均 +500-1500% → 2022 利率上行 + Nikola CEO 欺诈案件 + 商业化推迟 → 2023 集体 -85-95%
- **对本主题的启示**：
  - **本主题 SPAC 系（QS / SLDP / SES / Factorial）正在重演这条路**——QS 2021 高点 $54 / 当前约 $5（-91% 已 in），SLDP 当前 $1-2，但只要 2027 时点正式证伪 + 任一家现金链断裂 → 整个赛道 SPAC 系再 -50-70%
  - **关键观察点**：SLDP 现金 runway 4-5 年（mat-9fb50a）相对最长但仍脆弱；SES 现金 runway 2-2.5 年（mat-ccf921）最短最先暴露；QS 现金最厚但商业化最远
