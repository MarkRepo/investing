## 行业周期类型

**主导周期：技术替代 S 曲线 + 资本开支周期叠加**。本主题与传统液态锂电池"库存周期 + 锂盐价格周期"不同，主导驱动是：

1. **技术替代 S 曲线（核心）**：从液态 → 半固态 → 全固态的 3 段式技术跳跃。当前处于 S 曲线**底部承前 + 半固态先发上市**阶段（mat-c660fb 海通 2027 / 2030 渗透率 0.31% → 3.19% → 20.88% 的预测明确体现 S 曲线特征）。
2. **资本开支周期（次要）**：日韩传统化工 + 中国正极厂 + 美国 SPAC 玩家三阵营的 capex 节奏决定 2-3 年节拍。当前三井 FY27 设投扩 4 成至 900 亿日元 + M&A 框架翻 2.5 倍至 600 亿日元（mat-afa444）+ 出光中计 2026-2030 即将公布 capex 节奏（mat-ec4e1e）—— **正进入资本开支扩张前期**。
3. **政策周期**：中国 CASIP 2030 + 日本 GX + 美国 IIJA + 欧盟关键原材料法案——4 大政策窗口未来 3 年高度共振。

**与"传统液态锂电池周期"的关键差异**：液态体系 2024 年触底反弹（赣锋集团锂化工营收 + 22%、归母净利 +178% mat-fd945b），但**固态电解质本身处于商业化前夜**——上游碳酸锂触底反弹与固态电解质周期解耦，传统的"锂盐价格周期"判断无法套用本主题。

## 历史周期复盘（训练知识为主）

**新型电池材料历史 S 曲线（4 案例）**：

### 1. 三元正极 NCM 商业化（2014-2020）
- 时间：2014 NCM 622 商用 → 2018 NCM 811 切入 → 2020 高镍渗透率超 LFP（短暂）
- 触发：特斯拉 Model S 标杆 + 中国新能源汽车补贴
- 峰谷：价格从 50 万元/吨 → 12 万元/吨（-76%），4 年时间
- 结束信号：LFP 反超份额（CATL 2021 切换）+ 钴价突破 50 万触发供应链反思
- **对本主题启示**：技术领跑者（杉杉 / 容百 / 当升）在前 3 年享受溢价，第 4-5 年随产能扩张毛利率被压缩 5-10 pcts；硫化物电解质可能复制相同节奏

### 2. LFP 价格断崖（2010-2015）
- 时间：2010 LFP 量产 → 2015 大规模商用
- 峰谷：80 万元/吨 → 4 万元/吨（-95%），5 年时间
- 结束信号：中国厂商（比亚迪 / 国轩 / 德方）规模化突破，日韩退出
- **对本主题启示**：硫化物电解质若中国厂商规模化突破，价格可能 5 年内复制 -90% 路径；目前 SLDP 隐含 ¥7,500/kg（mat-756a01）vs 远期目标 ¥4,000/kg 仅 -47%——按 LFP 节奏其实可能 -90% 而非 -50%

### 3. 隔膜湿法替代干法（2015-2020）
- 时间：2015 湿法隔膜量产 → 2020 干法份额降至 <20%
- 结束信号：恩捷股份 / 星源材质规模化 + 设备国产化
- **对本主题启示**：电解质从"湿法 → 干法 → 连续法"工艺切换大概率走相同路径，**连续法是 2026-2028 关键工艺节点**（SLDP 2026 底 commissioning 连续法 pilot mat-9fb50a 是 leading indicator）

### 4. 1980s 索尼锂离子石墨负极（10 年从 2000 → 20 美元/kg，-99%）
- **对本主题启示（mat-fd945b 赣锋"锂金属是新石墨"叙事）**：石墨学习曲线 10 年 - 99% 但石墨是稳定材料，**锂金属加工难度高 5 个数量级**（roadmap.yaml 类比），不能简单照搬

**周期类比综合**：本主题如果 2030 真的达到 100-200 GWh 全固态装机（vs 海通乐观 538 GWh），价值释放节奏类似 2014-2018 三元正极兴起 + 2010-2015 LFP 价格下行的叠加——**前 3 年（2027-2029）领跑者享受溢价，第 4-5 年（2030-2031）才形成商业化竞争格局**。
