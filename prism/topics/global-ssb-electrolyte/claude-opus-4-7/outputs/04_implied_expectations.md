### 3. 利润池迁移分析（必须做）

**当下利润池在哪里**：
- 90% 在液态电池中下游（电芯厂 + 正极 / 负极 / 电解液 / 隔膜传统供应链）
- <5% 在固态电池试制（半固态产能 28.3 GWh 但毛利率薄 mat-f6cc96）
- <5% 在 R&D 政府 grant / JDA 服务费（SLDP $21M / SES $21M 全部来源 mat-756a01 / mat-ccf921）

**2030 利润池将从哪里迁到哪里（中性情景）**：
- 从 → **传统电解液 / 隔膜（六氟磷酸锂 / 湿法隔膜）**：约 -50 亿元/年（份额被全固态替代）
- 到 → **硫化物 + 卤化物固体电解质合成商**：约 +150 亿元/年净利
- 到 → **硫化锂 Li2S 前驱体（赣锋 + 出光 + 三井 + 有研 + 恩捷）**：约 +30 亿元/年净利
- 到 → **金属锂 + 锂金属负极（赣锋 + Albemarle + SQM）**：约 +50 亿元/年净利
- 到 → **干法极片 + 连续法设备商（先导 / 纳科诺尔 / 利元亨）**：约 +20 亿元/年净利

**关键判断**：利润池从下游"成熟材料"环节迁到上游"卡点材料 + 设备"环节，这正是叙事 B（thesis 主线）的数学基础。但 timing 是关键——五矿（mat-f6cc96）判断 2030 后才形成，海通（mat-c660fb）判断 2030 已经形成，差 3-5 年。

### 4. 隐含增速对比

**当前 arena 估值嵌入隐含增速测算**：
- 假设当前 arena SSB 业务嵌入估值 = 各公司 SSB 隐含份额 × 当前估值 = 约 500-800 亿元（仅 SSB 部分）
- 反推 2030 SSB 净利 = 500-800 / 25× PE = 20-32 亿元/年
- 当前 SSB 业务净利 ≈ 0 / 负
- **隐含 5 年 CAGR = 无意义（从 0 到 20-32 亿元）**
- 但隐含的"路径假设"是：2027 装机 50 GWh → 2030 200 GWh + 价格曲线 ¥8,000→¥4,000 + 龙头市占率 30%+ —— **三个假设必须同时成立**

**市场似乎在假设**：硫化物 / 锂金属赛道 2027-2030 三年内完成"从 0 商业化 → 250 亿元利润池 / 年"的跳跃，且龙头公司能拿到 30% 份额。

**这个假设属于**：**乐观但非极度乐观**（取决于路径假设的复合概率，约 25-40%）。

## Arena 观点光谱（5 级）

### Super-bull（超级乐观，概率 10%）
**核心逻辑**：海通 2030 538 GWh 装机兑现 + 硫化物路线占主导 + 价格曲线提前 1 年到位
**关键假设**：
1. 出光 / 三井 2027 千吨级硫化锂产线如期投产（K1 主方兑现）
2. 容百 / 当升 2026 H2 中试线良率 ≥70%（K2 主方兑现）
3. SLDP 隐含价从 ¥7,500/kg → ¥3,500/kg by 2028（超过 K3 阈值的 -53%）
4. eVTOL / 国防 + EV 主战场双驱动（叙事 E + A 共振）

**潜在回报**：arena 利润池上限 580 亿元/年，CR3 合计估值上看 5,000-8,000 亿元（vs 当前嵌入约 500-800 亿元 → **+800-1,000%**）

### Bull（乐观，概率 25%）
**核心逻辑**：2027 SOP 推迟到 2028-2029 但方向不变，主流叙事 A 微调而非崩塌
**关键假设**：
1. 出光 / 三井 2027 时点推迟到 2028 但披露明确（K1 弱化）
2. 容百中试线 2026 H2 投产 + 良率 60-70%（K2 部分兑现）
3. 硫化物价格 2028 底降到 ¥5,000/kg（K3 时点后延但路径不变）
4. 赣锋金属锂 + 硫化锂业务被独立 spin-off 或单独披露（卖铲人逻辑被 price-in）

**潜在回报**：arena 利润池 250-400 亿元，CR3 合计估值上看 2,500-4,000 亿元 → **+200-400%**

### Base（中性 / 基准，概率 35%）
**核心逻辑**：S 曲线启动延后 12-18 个月 + 路线分歧扩大 + eVTOL / 国防场景接力 EV 主战场
**关键假设**：
1. 2030 装机 200 GWh（折中假设）
2. 硫化物 + 卤化物 + 氧化物三路线分庭抗礼（CR3 集中度 <50%）
3. 赣锋 / 出光 / 三井是 K3 + K1 + K5 综合赢家，容百 / 当升估值期权部分被消化
4. 美股 SLDP / SES 长期 -20-30% 折价但不破产

**潜在回报**：arena 利润池 ~250 亿元/年，CR3 合计估值上看 2,000-2,500 亿元 → **+150-200%**

### Bear（悲观，概率 20%）
**核心逻辑**：全固态推迟到 2030+；液态系统级安全反超半固态性价比
**关键假设**：
1. 出光 / 三井 6/17 有報将 2027 时点推迟到 2030（K1 反方兑现）
2. 容百 / 当升中试线良率 <50% 或未披露（K2 反方兑现）
3. CATL 凝聚态 + 钠电组合 2026-2027 性价比突破（边缘叙事 F 兑现）
4. 海通 538 GWh @2030 修订到 100-150 GWh

**潜在下跌**：arena 利润池 100 亿元/年，CR3 合计估值收缩到 1,000-1,500 亿元；中游正极公司估值（容百 / 当升）期权部分清零 → **arena 整体 -20-40%；中游正极公司单股 -40-60%**

### Super-bear（超级悲观，概率 10%）
**核心逻辑**：硫化物路线被氧化物 / 卤化物绕开 + 欧美对中国非市场化封锁
**关键假设**：
1. 边缘叙事 D 兑现：氧化物 / 卤化物 2026-2027 弯道超车
2. 欧美 IRA / 欧盟关键原材料法案将硫化锂列入战略物资清单
3. SLDP / SES 现金链断裂（runway <2 年）→ 美股 SPAC 系崩盘
4. CATL 钠电完全替代乘用车主流场景

**尾部风险**：硫化锂卡点逻辑彻底破产；赣锋 SSB 业务期权清零；中游正极公司 forward PE 从 20-30× 重估到 8-12× → **arena 整体 -50-70%；硫化物全产业链 -60-80%**

## 关键分歧点

**多空双方最核心的一个分歧**：**2027 时点共识是否成立**。

- **多方认为**：日本（出光 / 三井 25 中计 + 三井 A-SOLiD 初期量产工厂动工 mat-afa444）+ 韩国（三星 SDI 重申 2027 mat-13806e）+ 中国（CASIP 2030 + 60 亿元国补）三大阵营全面承诺，资本动员已启动，2027 时点即使延迟 6-12 个月，方向不变；技术路线（硫化物）确定 + 价格曲线（¥8,000→¥4,000）符合 LFP / NCM 历史规律。

- **空方认为**：五矿（mat-f6cc96）已明确判断推迟至 2030 后；SLDP 隐含价 ¥7,500/kg（mat-756a01）距目标差 47%；容百中试线已后移至 2026 H2 投产（mat-f09fd5）+ 良率未披露；SMM 至 2026-05-19 无独立 SKU（mat-89797a）= 商业化未跨过最低门槛；SES / SLDP / Ford / BMW 等美股 + 欧美 OEM 端已经在悄然撤退（mat-ccf921 / mat-756a01 / mat-9fb50a），意味着真实工程进度低于公开承诺。

**解决这个分歧需要的关键节点**：
- **2026-06-17**：出光兴产有報（最早披露 2027 时点 + capex 明细）
- **2026 Q3-Q4**：SK On pilot 线 + 容百 / 当升中试线投产实质数据
- **2027 Q1**：日韩 + 中国头部 2027 年内首次"全固态装车 SOP"是否兑现

**我自己当前的判断（基于资料）**：**空方略占优势**——出光决算 capex 维持水平（mat-ec4e1e）+ 容百时点已后移（mat-f09fd5）+ SLDP 隐含价距目标差 47%（mat-756a01）三个一手数据点已经构成 K1+K2+K3 三角形空方阵地；多方目前的支撑主要依赖"承诺 + 路线选择"而非"capex + 良率 + 价格"硬数据。**v0→v1 thesis 校准结果：2027 时点共识不成立，2028-2030 才是真实窗口。**
