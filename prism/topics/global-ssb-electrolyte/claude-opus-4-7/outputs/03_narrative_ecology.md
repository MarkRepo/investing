## 主流叙事（市场最常见的 3 个框架）

### 叙事 A：「2027 是全固态量产元年，中国 - 日本头部全面竞速」

**核心逻辑（卖方主流，海通 / 中信 / 东吴口径）**：
1. 海通预测 2027 全球固态装机 50.68 GWh、渗透率 3.19%（mat-c660fb），是从 2025 的 3.3 GWh 跳跃 15 倍。
2. 日本（丰田 / 出光 / 本田）+ 韩国（三星 SDI 2027 商用化 mat-13806e）+ 中国（清陶 / 卫蓝 / 宁德 / 比亚迪 / 蜂巢 / 屹锂）几乎全部承诺 2027-2028 量产时间表。
3. 硫化物 LPSC 离子电导率 10⁻² S/cm（vs 氧化物 10⁻⁴ S/cm 低 2 个量级 mat-c660fb），是物理上的唯一选择。
4. 中国国家级支持 60 亿元 + CASIP 平台到 2030（mat-756a01 SLDP 引述）+ 日本 GX 补贴形成全球军备竞赛。

**主要支持者**：海通国际新能源团队（mat-c660fb，立场偏 bull）、东吴证券、中信建投，大部分中国新能源车产业链卖方。

**关键证据**：
- 出光 / 三井 25 中计同步发布（mat-ec4e1e / mat-afa444）— 资本动员信号
- 三星 SDI Interbattery 2025 重申 2027 时点（mat-13806e）+ ASB 商业化推进团 2023.12 成立（mat-3770c8）
- 容百 / 当升固态电解质中试线进展披露（mat-f09fd5 / mat-cc4b89）
- 赣锋 400Wh/kg @ 1100 次循环工程验证 + 沃飞 AE200 装机（mat-fd945b）

**脆弱点**（这个叙事可能崩塌的条件）：
- 出光 / 三井 6/17 有報未给具体 2027 时点
- SLDP 隐含 ¥7,500/kg vs 远期 ¥4,000/kg 目标差 47%（mat-756a01）——成本曲线在物理边界附近停滞
- 五矿（mat-f6cc96）明确判断头部全固态从 2027-2028 推迟至 2030 后
- 容百中试线已从 2025 H2 后移至 2026 H2 投产（mat-f09fd5）

### 叙事 B：「硫化锂前驱体卡点 + 上游卖铲人是真错误定价」（本主题 thesis 主线）

**核心逻辑**：
1. 硫化锂全球年产能 <100 吨（mat-c660fb / mat-f6cc96），是硫化物电解质成本 80% 的决定因子。
2. 出光 2027 千吨级目标 + 容百 2026H2 中试线良率首披是仅有两个量化时点，市场对前者忽视、对后者过乐观。
3. SMM 至 2026-05-19 仍无独立 SKU（mat-89797a）= 产能稀缺 + 信息差未消化的双重信号。
4. 锂金属负极（赣锋 mat-fd945b）作为同样稀缺的上游卡铲人，估值嵌入母公司，未独立定价。

**主要支持者**：少数派 fund manager（聚焦"卖铲人"框架），部分私募调研深度报告。

**关键证据**：
- SLDP 自承"Li2S 不是当前商业规模可支持"+ 双轨自建 + 多渠道采购（mat-756a01）
- 赣锋牵头制订《电池级硫化锂》行业标准 + 全球金属锂第一 + 青海 1000 吨金属锂在试生产（mat-fd945b）
- 当升氯碘卤化物路线规避硫化锂（mat-cc4b89）= 卡点真实存在的另一种证明（绕开是为了避开稀缺资源）

**脆弱点**：
- 如果卤化物 / 氧化物路线 2026-2027 量产突破，硫化锂卡点逻辑被绕开
- 出光 / 三井 2026-2028 大规模授权许可（mat-afa444 暗示 600 亿日元 M&A 框架可能切入电池材料并购）
- 赣锋金属锂 + 硫化锂当前嵌入 230 亿元营收 + 16 亿元归母（mat-fd945b），独立卖铲人估值差额测算难以精确

### 叙事 C：「美股 SPAC 系硫化物 / 锂金属是 SOP 推迟 + 现金链脆弱」（空头叙事）

**核心逻辑（空头机构 + 部分大行 cross-sector 团队）**：
1. SES 三大 OEM JDA 全部在 2025 年内 conclude（mat-ccf921）= 美国硫化物 / 锂金属赛道 EV 故事线已破产。
2. SLDP / QS / Factorial 商业化时点全部从 2027 推迟到 2028-2030 后，4-5 年 runway 在烧钱速度下趋紧（mat-756a01 SLDP $100M/年烧钱 vs $336M 现金 + Q1 后 $455M = ~4-5 年 runway）。

4. SLDP 退化为"电解质材料商 + 工程服务"（mat-9fb50a），BMW JDA 实质归零（Q1 BMW 收入 $0）。

**主要支持者**：空头基金、部分大行美股新能源团队、ESG 怀疑论者。

**关键证据**：
- SES 2026 Q1 服务收入 $0.3M（-95% YoY mat-8c64a7）+ 首席科学家 10b5-1 减持
- SLDP Ford 退出（mat-756a01）+ BMW 降级为"Samsung SDI 评估链中的评估方"（mat-9fb50a）
- 整组美国玩家 2025 商业电解质 / 商业 cell 收入 = $0

**脆弱点**：
- SLDP 现金 $255M + runway 4-5 年（mat-9fb50a）是赛道最厚现金垫，2028 前不会倒下
- 三星 SDI 接续 BMW，三方 JEA 维持（mat-9fb50a）= "退出 EV"叙事并不完全

## 边缘叙事（少数派 / 反共识的框架）

### 边缘叙事 D：「氧化物 / 卤化物路线 2026-2027 弯道超车，硫化物路线全盘失效」

**核心逻辑**：
1. 三星 SDI 2025 年报（mat-3770c8）未披露任何电解质路线选择，但 ASB 商业化推进团已成立 2 年，组织上信号已发；如果敢列"商业化"，更可能是工艺成熟度更高的氧化物 - 聚合物复合而非硫化物。
2. 当升明确主推**氯碘复合卤化物**（mat-cc4b89），公司认为该路线"高离子电导率 + 界面浸润性 + 规模化能力 + 头部客户验证"。卤化物的优势：无 H2S 工业安全风险（mat-756a01 SLDP 公开承认硫化物大批量生产 H2S 处理是隐性成本）。
3. 五矿（mat-f6cc96）测算氧化物 LATP 原材料成本仅 2 万元/吨 vs 硫化物 12.3 万元/吨——长期成本结构性优势。

**为什么市场不接受**：
- 硫化物离子电导率优势是物理定律，2 个量级差距难以弥补
- 中国厂商虽然推卤化物（当升 mat-cc4b89），但日韩头部（丰田 / 出光 / 三井 / SDI / SK On）几乎全押硫化物，全球供应链方向已经选定
- 卤化物量产规模国内外都很小，没有形成商业化标准

**如果它是对的**：硫化锂卡点逻辑（叙事 B）彻底破产；赣锋金属锂业务（mat-fd945b）+ 出光 / 三井估值需要重估 -40%；当升相对容百估值溢价拉开（mat-cc4b89 vs mat-f09fd5）。

### 边缘叙事 E：「赛道从 EV 主战场迁移到 eVTOL / 低空 / 国防，本批新场景才是真增量」

**核心逻辑（本批 findings 揭示的最大 narrative shift）**：
1. SES 把 A-sample EV 产线改造为无人机 / UAM 线（mat-ccf921）+ NDAA 合规无人机布局
2. 赣锋唯一具名"装车"是沃飞长空 AE200 eVTOL，2025/12 完成第一阶段载人试飞（mat-fd945b）
3. 当升固液正极导入"清陶、卫蓝、辉能、赣锋、中汽新能"+ 应用市场含"具身智能 / 人形机器人 / 无人机 / eVTOL"（mat-cc4b89）
4. 美国 OEM EV 端耐心已用尽（Ford 退、BMW 降级、Honda/Hyundai/GM 全退 mat-756a01 / mat-ccf921），但**国防 / 国家级场景对成本不敏感、对能量密度高度敏感**——硫化物 + 锂金属在此场景下溢价能力更强

**为什么市场不接受**：
- 主流卖方仍在"乘用车装车量"框架内测算固态电池 TAM（mat-c660fb 2030 538 GWh 全部基于乘用车假设）
- eVTOL / 低空场景全球年产硬上限可能仅几万架，对应电池需求 0.x-1 GWh 级，规模远小于 EV
- 国防 / NDAA 场景信息严重不对称，难以精确建模

**如果它是对的**：
- 海通 538 GWh @2030 大幅高估，实际 100-200 GWh @2030 + 大部分是 eVTOL / 国防场景
- 赣锋（mat-fd945b 沃飞 + 国家科技重大专项）+ SES（mat-ccf921 NDAA）成为新场景龙头
- 中国 / 美国"国家队"卡位优于纯民用 EV 路线

### 边缘叙事 F：「CATL 凝聚态 + 钠电组合在 2026-2027 性价比突破，全固态被定位为高端窄场景产品 2030+ 才放量」

**核心逻辑**：
1. 父 topic 07 K1 已暗示这一可能性
2. mat-f6cc96 五矿数据：液态 NP 2.0 系统级降温 270℃ + 无 EC 电解液热失控 +64℃ → 液态体系系统级安全持续迭代
3. 半固态溢价 43% 仅换 +15℃ 热失控提升（mat-f6cc96）= 性价比逻辑短期不成立
4. CATL 钠电 + 凝聚态如果 2026-2027 达到 400 Wh/kg + 0.5 元/Wh，全固态在乘用车主战场被压缩到 800 km+ 高端窄场景

**为什么市场不接受**：CATL 自己也在押硫化物（mat-c660fb）= 内部对冲；钠电路线对能量密度上限有物理边界

**如果它是对的**：硫化锂需求曲线推迟 3-5 年；本主题整体投资逻辑后延至 2030+

## 叙事与估值的关系

**当前主流叙事（A）暗示的估值逻辑**：
- 给固态电池正极厂（容百 / 当升）20-30 倍 forward PE（vs 液态正极厂 10-15 倍），溢价代表"固态期权"价值
- 给赣锋金属锂业务 50-80 倍隐含 PE（嵌入母公司），溢价代表硫化锂 + 金属锂卡点
- 给美股 SPAC 系（SLDP / QS / Factorial）2-3 倍 EV / Sales（vs cash burn），溢价代表 2027-2028 商业化预期

**估值框架假设**：
1. 2027 装机 50 GWh 假设成立 → 推算电解质材料 5 万吨 + 锂金属 2,000 吨需求
2. 头部市占率 30%+ 假设成立 → 容百 / 当升 / 赣锋 / 出光 / 三井 任一龙头能拿到 1-2 万吨电解质份额
3. 价格曲线 ¥8,000 → ¥4,000/kg 假设成立 → 远期毛利率 25-35%

**这些假设是否合理**：
- 第 1 条：海通 vs 五矿 5 倍差距，本身已极不稳固
- 第 2 条：当前 SMM 无独立 SKU（mat-89797a），份额无法测算
- 第 3 条：SLDP 隐含价 ¥7,500/kg（mat-756a01）距 ¥4,000 还有 47%——按 LFP 历史看可能突破（5 年 -95%）也可能停滞（受 Li2S 卡点）

**估值层面的实质**：当前正极厂期权部分已被 price-in 20-30% 隐含溢价（容百 / 当升），但**上游卖铲人（赣锋金属锂、出光 Li2S）的卡铺人价值仍嵌入母公司，未独立定价**——这是叙事 B 的核心 alpha 空间。

## 叙事风险

**最危险的叙事风险（小概率大影响）**：
1. **氧化物 / 卤化物突破（边缘叙事 D 兑现）**：当升氯碘卤化物 2026-2027 中试线良率 70%+ 突破，三星 SDI / SK On 公开采用——硫化物全产业链 -40-60% 重估

- 2026 Q2-Q3：「2027 SOP 共识」向「2028-2030 推迟」的"软着陆"——日韩 25 中计明确把时间窗放在 2028-2030，中国玩家口径同步后移；正极厂期权部分压缩 -10-20%
