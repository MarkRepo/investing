# 商业全景：全球固态电解质 + 锂金属上游

> 生成于 2026-05-22，训练知识占比约 55%，资料更新截至 2026 Q1（SLDP/SES 10-Q）+ FY26/3 通期（出光/三井）+ 2025 年报（容百/当升/赣锋/三星 SDI）

## 行业定义与边界

固态电池电解质 + 锂金属负极上游，是把"传统液态锂电池"中的两个核心组件——电解液 / 隔膜（用固体电解质替代）和石墨负极（用锂金属或硅 - 锂复合体替代）——重新工程化为新产品类目的新材料赛道。**严格说不是一个独立行业，而是横跨电池材料 + 化工 + 稀土金属三个 GICS 分类的"卡点材料集"**。本研究主题边界划定：

- **算在内**：硫化物固体电解质（LPSC / Li6PS5Cl / Argyrodite 系）、氧化物（LATP / LLZO / LLTO）、卤化物（Li3InCl6 / Li2ZrCl6 / 氯碘复合）、聚合物 - 无机物复合电解质；硫化锂（Li2S）前驱体；电池级金属锂、硅 - 锂复合负极、薄膜锂、铜箔基复合锂带。
- **不算在内**：传统液态电解液（六氟磷酸锂、添加剂）、传统隔膜（湿法 / 干法 PE / PP）、传统石墨负极、电芯整机厂（QS / Solid Power 整机部分、宁德 / 比亚迪整机部分）。
- **关键词标准分类**：GICS Materials → Specialty Chemicals + Industrials → Electrical Components & Equipment 交叉；SW 行业为电池材料子板块。

边界关键提示：**电芯厂（CATL / 比亚迪 / 三星 SDI / 丰田）不在本主题内**——它们是 K1-K5 验证的"客户端 + 路线选择端"，但本主题聚焦"材料卖铲人"。

## 市场规模与结构

**总量基线（2025）**：
- 全球固态电池装机量约 **3.3 GWh**（mat-c660fb 海通预测，渗透率 0.31%）——基本对应几条半固态产线 + 试制线。
- 对应硫化物电解质需求**仅几十吨级**（全固态用量 ~1000 吨/GWh，半固态 ~100 吨/GWh，但 2025 几乎全是半固态）。
- 硫化锂前驱体全球**实际产能 <100 吨/年**（mat-c660fb / mat-f6cc96）。
- 金属锂全球年产 ~1 万吨，赣锋一家占 ~50% 份额，电池级金属锂占其中 <20%。

**增长预测（2027 / 2030）**：
- 海通预测 2027 装机 **50.68 GWh**（YoY 15 倍）、2030 装机 **538 GWh**（渗透率 20.9%）——属偏激进口径。
- 五矿（mat-f6cc96）判断头部全固态量产时点从 2027-2028 **推迟至 2030 后**，2030 实际全固态可能仅 100-200 GWh。
- 对应电解质需求弹性：100 GWh 全固态 → 约 10 万吨电解质（vs 当前几十吨级，1000 倍弹性）；硫化锂需求约 8 万吨（vs 当前 <100 吨）。

**国内 / 海外分布**：
- 电解质 R&D 玩家：中国（容百 / 当升 / 赣锋 / 鹏辉 / 卫蓝 / 清陶 / 辉能 / 太蓝等 20+ 家）+ 日韩（出光 / 三井金属 / 三星 SDI / LGES / SK On）+ 美国（SLDP / Factorial / QS / SES）三足鼎立。
- 实际产能集中度：中国占现有 28 GWh 半固态全部（mat-f6cc96），但全固态电解质中试线集中度 ≈ 0（几乎都在 pilot / batch 阶段）。
- 硫化锂上游：日本（三井 / 出光）+ 中国（赣锋牵头制订国标 mat-fd945b、有研 / 恩捷 / 厦钨小批量）。

**CR3 / CR5 集中度**：
- 当下伪命题——产能尚未形成商业池（SMM 至 2026-05-19 仍无独立 SKU，mat-89797a）。
- 中长期格局推测：硫化物电解质 CR3 候选（出光 + 三井金属 + 容百），全球份额可能在 2028-2030 形成 50%+；金属锂 CR3 候选（赣锋 + Albemarle + 智利 SQM），赣锋一家可能 50%+。

## 价值链解析

```
[硫资源 / 锂资源]
       ↓
[硫化锂 Li2S 前驱体（瓶颈）] ←—— 中国：赣锋、有研、恩捷（吨级）；日本：三井金属、出光（百吨级）
       ↓
[固体电解质合成（湿法 / 干法 / 连续法）] ←—— 中国：容百（中试 2026H2 投产）、当升（氯碘卤化物）、赣锋；日本：出光、三井；美：SLDP（75 吨/年 pilot 2026 底）
       ↓
[电解质膜 / 极片复合涂覆 / 注塑成型] ←—— 设备商：先导智能、纳科诺尔、利元亨
       ↓
[电芯组装（NMC 正极 + 电解质膜 + 锂金属 / 硅基负极）] ←—— 电芯厂：CATL / 比亚迪 / SLDP / SDI / 丰田 / 三星 SDI
       ↓
[Pack / BMS / 系统集成] ←—— 电池厂 + OEM
       ↓
[EV / eVTOL / 国防 / ESS]
```

**毛利率分布**（v0 测算 + 资料校准）：
- 硫化锂前驱体：理论毛利率最高（30-50%），但需要规模化；当前实际无独立 SKU 可推算
- 固体电解质合成：当前 SLDP 隐含售价 ¥7,500/kg（mat-756a01），毛利率从公司财务推断 < 0（仍在 R&D 阶段）；远期目标 4000 元/kg，达产后毛利率 25-35% 是合理上沿
- 电芯组装：全固态远期成本 0.69 元/Wh vs 液态 0.51 元/Wh，**远期仍贵 35%**（mat-f6cc96）——意味着电芯毛利率取决于高端车型溢价
- 设备：电芯产线 capex 强度 SLDP 给出 $1.47M/吨年产能 ≈ ¥10.6M/吨年（mat-756a01），是液态体系 2-3 倍 — 设备商弹性大

**价值链利润池迁移判断**：
当前（2025-2026）利润池基本在传统液态电池中下游；2027-2030 利润将从电解液 / 隔膜上游切片转移给**硫化锂前驱体 + 金属锂 + 固体电解质合成商 + 干法 / 等静压设备商**四个环节。这是本主题的核心 alpha 来源。

## 商业模式

**主要模式**：To B 工业品销售 + 长协供货 + 联合开发（JDA）混合。
- **整机厂 → 电芯厂 → 材料厂**三段式供应链，材料厂从 R&D 阶段就要进入 OEM 认证（A 样 → B 样 → C 样 → D 样 → SOP，48-54 个月，mat-f6cc96）。
- **SLDP 模式（轻资产）**：只卖电解质 + 卖电芯设计授权，不做整电芯（mat-756a01 / mat-9fb50a）——把 capex 外包给 SK On / 三星 SDI 韩国伙伴。
- **赣锋模式（垂直一体化）**：硫化锂 → 电解质 → 锂金属 → 电芯全链条自营（mat-fd945b），通过制订行业标准捆绑下游。
- **容百 / 当升模式（材料卖铲人）**：以传统正极业务为现金流，固态电解质 / 正极作为期权（mat-f09fd5 / mat-cc4b89）。

**收入结构**：
- 当下：政府 grant + OEM JDA milestone + 少量样品 / 工程服务费（SLDP 2025 营收 $21M，其中 $6M DOE + $15M JDA collaborative，0 商业销售 mat-756a01）。
- 中期（2026-2028）：硫化物电解质开始有少量商业销售（SK On 8 吨 / 2030 已签 mat-756a01），但仍以验证级为主。
- 长期（2028-2030+）：取决于全固态 EV 装车节奏。

**盈利驱动因子**：量（产能利用率 + 客户数）× 价（每代际 - 30-40% 学习曲线）× 成本（Li2S 前驱体降本是 80% 决定因子，mat-c660fb）。

## 需求端分析

**核心客户群体（按重要性排序）**：
1. **日韩三大电芯厂**（LGES / SK On / 三星 SDI）：长协绑定中国正极厂（mat-cc4b89 当升），是 2027-2030 出货放量的主要载体。
2. **中国电池厂 + OEM**（宁德 / 比亚迪 / 清陶 / 卫蓝 / 辉能 / 赣锋）：半固态先发，全固态时点对赌。
3. **欧美车厂**：BMW（与 SLDP+三星 SDI 三方 JEA，mat-9fb50a）、奔驰（Factorial / QS）、福特（已退出 mat-756a01）、Stellantis、现代汽车——耐心比中国市场更短，2025 年内 SES 三家 OEM JDA 全 conclude（mat-ccf921）就是注脚。
4. **eVTOL / 低空 / 无人机 / 国防新场景**（新增）：沃飞长空 AE200（吉利系，mat-fd945b 已试飞）、SES NDAA 无人机线（mat-ccf921）、商用车 / 矿卡。**这是本批 findings 最大的 narrative shift**——赛道正在悄然从乘用车 EV 主战场迁移到 eVTOL / 低空 / 国防。

**购买决策驱动因素**：
1. **安全**（针刺、热失控温度 vs 液态 NP 2.0 体系）—— mat-f6cc96 数据显示半固态溢价 43% 仅换 +15℃ 热失控提升，性价比逻辑被液态体系电解液改性（+64℃）反超。
2. **能量密度**（>400Wh/kg 高端车 / 长航 eVTOL 真实需求）。
3. **快充倍率 / 循环寿命**（赣锋 400Wh/kg @ 1100 次循环已基本过线 mat-fd945b）。
4. **成本**（远期目标全固态 0.69 元/Wh vs 液态 0.51 元/Wh 仍贵 35%）。

**需求增长核心驱动**：
- 高端 EV（800+ km 续航）+ eVTOL / 低空（300+ Wh/kg 硬性能量密度要求）+ 国防（NDAA 合规去中国化）三大场景。
- 政策驱动：中国 CASIP 2030 时间表（SLDP 10-K 内引用 mat-756a01）、日本 GX 补贴、美国 IIJA（2025/1/20 行政令暂停风险 mat-756a01）、欧盟关键原材料法案。

## 竞争格局

**格局类型**：极度分散 + 路线分化的早期赛道。当前任何玩家都没有商业级独立 SKU 报价权（mat-89797a SMM 无独立 SKU 是关键信号）。

**核心竞争要素**（3 个）：
1. **上游 Li2S 自主**——决定毛利率上沿 80%（mat-c660fb）。垂直一体化的赣锋 + 日韩三井 / 出光占绝对优势。
2. **路线押注**——硫化物（主流）vs 氧化物（绕开 Li2S）vs 卤化物（当升氯碘复合 mat-cc4b89）vs 聚合物-硫化物复合（出光）。押对路线决定 2028-2030 cell 端份额，押错完全归零。
3. **OEM 客户绑定深度**——A→SOP 48-54 个月窗口期内，几家 OEM 锁定决定未来 5-10 年地位。当升 LGES/SK on/三星 SDI/Murata 长协（mat-cc4b89）是 K2 论点的核心定价信号。

**行业龙头与优势来源**：
- **出光兴产**：硫化物复合电解质工艺 + 财务弹性（FY26 营收 8.1 万亿日元 + FCF 3,924 亿日元 mat-ec4e1e）+ 与丰田绑定。
- **三井金属**：Li2S 前驱体 + A-SOLiD® 初期量产工厂在建（mat-afa444）+ M&A 600 亿日元框架。
- **赣锋**：中国唯一上下游一体化 + 全球金属锂第一 + 行业标准制订方（mat-fd945b）。
- **SLDP**：纯硫化物 R&D 深度 + 三星 SDI / SK On / BMW 三家合作 + 现金 255M / runway 4-5 年（mat-9fb50a）。

## 发展阶段

**当前所处阶段：导入期早段 ↔ 成长期前夜**。

判断依据：
1. **技术成熟度**：CATL 自评 4/9，目标 2027 达 7-8 分（mat-c660fb）；五矿判断头部全固态从 2027-2028 推迟至 2030 后（mat-f6cc96）——主流共识在「7-8/9 阶段还有 24-48 个月」。
2. **商业化进度**：2025 全球装机 3.3 GWh（绝大部分半固态），SLDP 2025 商业电解质销售收入 $0（mat-756a01），SMM 至 2026-05-19 无独立 SKU（mat-89797a）——尚未跨过商业化报价池形成的最低门槛。
3. **产能格局**：分散 + 玩家 30+ 家，无任何玩家占有独立可披露的市场份额——典型导入期早段特征。
4. **资本投入**：日韩传统化工 25 中计加码（三井 M&A 框架 ×2.5 至 600 亿日元 mat-afa444、出光中计 2026-2030 同日发布 mat-ec4e1e）+ 中国正极厂 capex 在液态主业未在固态电解质（mat-cc4b89 / mat-f09fd5）+ 美国 SLDP 烧钱 $100M/年但仍属 pilot 阶段（mat-756a01）。

**未来 5 年阶段判断**：
- 2026-2027：仍处导入期，关键节点是 SK On pilot 落地（mat-9fb50a 2026-04-10 site acceptance 完成）+ 容百中试线 2026 H2 投产（mat-f09fd5）+ 三井 A-SOLiD® 初期量产工厂投产时点（mat-afa444 待 6/17 有報）。
- 2028-2030：成长期前夜（"7-8 分"成熟度跨越），独立 SKU 可能形成，CR3 格局开始浮现。
- 2030+：成长期主升段。
