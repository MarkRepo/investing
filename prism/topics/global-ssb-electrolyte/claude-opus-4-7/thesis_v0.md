# Thesis v0 — 全球固态电解质 + 锂金属上游

> 写于 2026-05-21（开盘前训练知识 + 父 topic global-solid-state-battery v1 已合成产出）
> Stage 锚点：开 arena 前的 LLM 初判，未读 arena 级新增资料

---

## 1. 核心 thesis（一句话 + 强度）

**分化看法**：硫化物电解质降本路径（8000→4000 元/kg）**结构性可达但 2027 时点过度乐观**；最大错误定价在**硫化锂前驱体 + 锂金属负极的"卖铲人"环节**（产能稀缺、独立 SKU 缺失、估值嵌入母公司），而非容百/当升等中游正极公司的"电解质期权"估值（已部分透支）。

**强度**：
- 上游卡点（硫化锂前驱体 / 锂金属）：**+7**（看多，但仓位需小、等催化）
- 中游正极公司的电解质期权：**-3**（中性偏空，已 price-in 高确定性）
- 日韩（出光/三井/Mitsui）专利墙：**+2**（看多技术领先，但估值已反映）
- 全固态量产时间窗：**-4**（2027 SOP 共识过乐观，2028-2029 才是真窗口）

---

## 2. 支持理由（5 条）

1. **硫化锂前驱体是真正卡点**：父 K3 + mat-c660fb / mat-f6cc96 双重确认，全球年产能 <100 吨级，出光 2027 千吨级目标 + 容百 2026H2 中试线良率首披是仅有两个量化时点；SMM 至今未给独立 SKU 是"产能稀缺 + 信息差未消化"双重信号。

2. **锂金属负极对全固态/半固态都是必需**：赣锋千吨试产是中国唯一规模化路线，与电解质同步成熟才有意义；mat-e62c68 显示 2024 年仍在实验室级良率，但 2025 年报应有进展。这条赛道独立于电芯厂的"路线之争"——只要任一路线胜出都要用锂金属。

3. **降本路径有强工艺先例**：硫化物 LPSC 从 8000→4000 元/kg 需要的不是新化学，而是规模化 + 干法工艺 + 纯度提升，类似 2017-2020 年正极三元材料从 30 万→15 万元/吨的工艺学习曲线——**3-5 年路径可信，但需要至少 1 个千吨级标杆产线投产证明**，2027 时点过紧。

4. **日韩专利墙形成有效护城河**：出光（聚合物-硫化物复合）、三井金属（前驱体 Li2S）、Mitsui Chemicals 的硫化锂工艺专利集中于 2018-2022 年申请，2030 年前中国厂商绕开成本高；这给日韩 5-7 年的技术租金窗口。

5. **市场没有独立估值锚 = alpha 空间**：09 arena 已明确"嵌入正极/电芯母公司估值"，意味着当独立标的（如硫化锂专精玩家、设备商）出现时会有重估，参考早期负极石墨化（贝特瑞/璞泰来从一体化拆出独立 SKU 时的估值跳变）。

---

## 3. 最大反方观点（3 条）

1. **氧化物路线（LATP/LLZO/LLTO）可能短中期替代硫化物**：氧化物加工性更好、不需要硫化锂前驱体，三星 SDI（mat-13806e）的 Interbattery 2025 路线就主推氧化物-聚合物复合，如果氧化物先量产，硫化锂这一硬卡点的"投资逻辑"会被绕开。**反驳难度**：高——硫化物的离子电导率 + 能量密度优势确实是物理定律，但商业化≠技术最优。

2. **CATL 凝聚态 + 钠电的"性价比路线"挤压全固态空间**：父 topic 07 K1 已暗示，如果 2026-2028 半固态 + 凝聚态足够好（能量密度 400Wh/kg + 安全 + 成本 0.6 元/Wh），全固态推迟到 2030+ 会让硫化物电解质需求曲线延后 3-5 年；硫化锂产能扩张可能"两头不靠"。

3. **欧美对中国硫化物产业链的"非市场化封锁"风险**：IRA + 欧盟关键原材料法案已开始对中国电池材料征税，硫化锂若被列入战略物资清单，中国厂商出海受限——容百 / 当升的硫化物海外授权路径可能比预期复杂。

## 4. Killer Questions（5 条 — 可观测、可证伪）

- **K1（时点验证）**：出光兴产 2027 年千吨级硫化锂产线**是否准点投产**？跟踪节点：2026 Q3 出光 IR 会披露具体投产时间表与设备订单。**证伪**：若 2026Q4-2027Q1 IR 中将时间推迟到 2028+，硫化物降本路径整体后延，K3 路径破产。

- **K2（中国中试良率）**：容百科技 / 当升科技 2026H2 硫化物电解质中试线**首披良率是否 ≥70%**？跟踪节点：2026 年报或 2026Q3 业绩会。**证伪**：若良率 <50% 或未披露，中国厂商窗口缩窄到 2028-2030，日韩独占 2026-2028 窗口。

- **K3（价格曲线）**：硫化物 LPSC 价格从 8000 → 4000 元/kg **是否在 2027 年底前实现**？跟踪节点：SMM 独立 SKU 上线 + 季度价格。**证伪**：若 2027 年底仍 >6000 元/kg，硫化物相对氧化物的成本优势不足，全固态量产推迟到 2030+。

- **K4（锂金属经济性）**：赣锋锂金属负极**千吨试产单位经济性**是否优于内部模型？跟踪节点：2026 年报 + 投资者交流披露。**证伪**：若试产成本 >2 倍内部模型 or 良率 <60%，锂金属"实验室 → 中试"门槛未跨过，半固态车型成本曲线断裂。

- **K5（专利/封锁）**：日韩三井 / 出光的硫化锂工艺专利**是否在 2026-2027 出现"中国厂商授权许可"或"无效化诉讼"事件**？跟踪节点：USPTO / JPO 专利动态 + 上市公司公告。**证伪**：若无任一信号，中国厂商专利绕开方案不成熟，海外授权门槛长期存在。
