## 环 ① 看懂这个赛道（理解闸门）

> 详细机理/路线/玩家背景见 `00_primer`。这里只落 case 需要的三点。

- **怎么赚钱 + 价值链卡位**：利润来自"专利独占期内的高定价"，卡在三段——**专利/IP（护城河根本）× 渠道装机（黏性）× 产能（吃平权化的量）**。谁三段都占，谁是规模领跑；只占专利+疗效、缺渠道产能的，是"疗效领跑但落后一身位"（primer §6）。
- **路线之争（是什么，不判胜负）**：口服多肽（口服司美，费料贵）vs 口服小分子（orforglipron 等，能海量便宜造）。本 arena 主角是小分子路线；小分子内部又分纯 GLP-1（orforglipron、aleniglipron）与含 GIP 的双靶（VK2735）。客户结构：B2C 处方药、经医生/PBM/保险三重闸门到患者，政府医保（Medicare/Medicaid）是放量后半程的关键增量买单方。
- **赛道周期位**：**早期成长 → 中段加速的拐点**。首个口服小分子 2026-04 才获批（orforglipron/Foundayo）[mat-f39c3c]，美国 GLP-1 渗透率仅 ~2%[mat-ff23c8]——放量刚起步，远未到分化饱和。50 个口服小分子项目在研[mat-ff23c8]，低渗透阶段"共同做大蛋糕"，但疗效趋同后会分化为"特许经营 vs 大宗商品"两极。

**闸门结论**：赛道看得懂、方向明确（针→片、窄口→基层）。下一步必须问：谁会赢、市场定价了没。

## 环 ② 赢家由什么决定 + 市场已把谁当赢家定价了【锚 · 天然硬】

### 关键胜负变量（按决定性排序）
1. **渠道装机 × 先发**（最决定性）：先获批、先建库存、先铺多适应症 = 抢占医生处方习惯和保险 formulary 位置。医药放量的黏性主要来自装机，不是边际疗效。
2. **产能/单位成本**：吃下平权化的量、在净价下压下保住利润。小分子结构性占优。
3. **疗效档位**：决定能否守住高价值人群、以及"疗效为王"情形下的天花板——但在口服内部，"够用"可能比"最强"更重要。
4. **专利/IP 深度**：决定利润池的**寿命**（悬崖时点）和能否防第三方诉讼抽利。

### 市场已把谁当赢家定价了（用 Step 1 peer 财务 + 2026-07-21 行情）
- **市场共识赢家 = 礼来（LLY）**：PE(TTM) **40.8x**、市值 **$1.05 万亿**、PS 14.5x[market_data]，2025 营收 +45%、Q1'26 +56%、毛利率 83%[mat-82221a, mat-c9c6aa]。40.8x 是历史高位——**市场明确在为"LLY 会同时赢下口服+高端两条迁移路径"付溢价**（父行业 thesis 同判）。
- **诺和诺德（NVO）**：PE **11.9x**、市值 $218B、−29% YoY[mat-21a243]——**市场已把"份额流失 + 口服多肽被小分子挤压"深度定价**（困境价）。
- **疗效领跑纯标的**：Viking 市值 **$4.4B**（价 $37.95，较 2026-02 的 $30.45 已涨）、Structure **$3.5B**——**注意 VKTX 市值已反超 GPCR**（父级用的旧 EV 口径 VKTX $2.65B < GPCR $4.05B 已过时）。这两家 pre-revenue，市值本质是"成功概率 × 未来利润池 + 并购溢价"的期权定价；分析师给 VKTX 平均目标价 $92.72（+204%）[mat-87d0af]。
- **隐含预期一句话**：**市场共识 = "LLY 靠规模统治口服利润池主体（付 40.8x 溢价），疗效领跑者是弹性期权/并购标的（付几十亿期权价），NVO 出局（付困境价）"。**

### 定价锚 × 证据强度张力（与 ③ 缝合 · 硬落地）
**市场为 LLY 付的 40.8x / $1T 溢价，恰恰踩在 ③ 里证据最弱的两块假设上**：
- 溢价隐含"orforglipron 10.5% 疗效**够用**"（WMBT-1）——但这是全 arena 证据最薄的判断（10.5% vs 20%+ 落差远大于他汀-PCSK9 的边际差[mat-a6e783]）；
- 溢价隐含"放量斜率**不被支付摩擦压制**"（WMBT-2）——但商业保险仅 1/3 覆盖肥胖、Medicare Part D 肥胖覆盖迟至 2027、净价在下行[mat-fd18f6, mat-1cc9d9, mat-f39c3c]，这是硬约束。

**换句话说：市场对"LLY 会赢"的定价笃定度（40.8x）> 支撑它的证据强度。** 这不是说 LLY 不会赢，而是说**在这个价位，赔率不对称地压向下行**——一旦"疗效够用"或"放量顺畅"被证伪，40.8x 溢价回吐空间大。这正是本 arena 把 LLY 放进"观察档而非深研档"的定价逻辑（环⑥）。

### 同一把尺切自己押的标的（对称拆解 · 防"对赢家苛刻、对自己宽松"）
把切 LLY 的手术刀同样切 VKTX/GPCR，避免只质疑共识赢家、放过自己的下注：
- **VKTX $4.4B / GPCR $3.5B 的市值隐含什么**：两家 pre-revenue、全部价值系于 2029/30 才商业化的 Phase 3 资产。$4.4B 市值本质在为"**Phase 3 成功概率 × 未来利润池 + 并购溢价**"付钱——但支撑它的证据**全是 Phase 2 数据**（VK2735 口服 12.2%、aleniglipron 核心 11.3%）。**Phase 2→3 疗效能否守住是这两家定价踩的最弱地**（对应 WMBT-4，证据强度"中"），与 LLY 踩 WMBT-1/2 是同构的"定价笃定度 vs 证据强度"缺口。VKTX 已从 2026-02 的 EV $2.65B 涨到 $4.4B，**期权已部分兑现、并购溢价空间收窄**——不是"无脑便宜"。
- **风险性质根本不同（苹果 vs 橘子，必须言明）**：LLY 的下行是"40.8x→28x 回吐"（有收入托底、可回调加仓）；VKTX/GPCR 的下行是"**Phase 3 失败腰斩/归零**"（低胜率 × 大弹性的期权）。所以④说"赔率在 VKTX/GPCR"指的是**低概率大上行的期权赔率，不是同一赔率轴上比 LLY 更优的点**——押它们等于用可承受的仓位买期权，不是用它们替代 LLY 的核心仓。
- **反向暴露提醒**：VKTX/GPCR 商业化更晚，**对 WMBT-2（支付摩擦）的暴露反而 ≥ LLY**——若 2027 后支付通道仍未打通，已上市的 LLY 只是增速受损，而两家纯标的的"平权化放量"投资根基被直接抽掉。这层在④下注与⑤证伪里显式对冲。

- **LLY（观察）**：WMBT-3 的最强兑现者（规模已锁），但②已把胜利定价透支，且它是 WMBT-1/2 弱假设的最大暴露方（疗效最弱+净价压力最大）。*K1 兑现但估值透支*。
- **恒瑞（观察）**：国产小分子进度不落后（HRS-7535 Ph3 完成入组）+ BD 出海提前货币化期权，但 44.9x 贵 + 国产内卷。*K2/K4 期权*。
- **NVO（淘汰）**：口服司美 65% 新处方是**多肽路线的短期领先**，但结构劣势（费料/成本高/难规模化）+ 份额流失，且注射存量已在 `injectable-incumbent` arena 覆盖。*本 arena 出局*。
- **华东（淘汰）**：HDM1002 进度不落后，但集团毛利率 32% 与高利润池论冲突、减重仍小基数。*K4 影子股*。
- **AZN（淘汰）**：AZD5004 仅 Phase 2b、差异化偏耐受性非疗效领跑。*太早*。

## 环 ⑤ 如果错了会怎样、怎么第一时间知道【证伪机制】

### 已知风险 + 盲点风险
- **已知**：① 支付慢坡（WMBT-2）把放量压平；② "疗效为王"情形下口服降级为补充入口（WMBT-1 破），高价值利润仍留注射剂；③ 远期 generic 悬崖（WMBT-5 远期弱）。
- **盲点**：① **IP 诉讼二次抽利**——50 项目挤在相似化学空间，Gilead 即便有自家专利仍被判向持基础方法专利的 Merck 赔 25.4 亿[mat-56ee94]；② **竞品降价早于专利到期**——丙肝式"竞品存在即逼降价"，50 个玩家涌入可能在专利期内就把净价打崩（份额稳 ≠ 利润稳）；③ **VKTX/GPCR 估值已部分透支期权**（VKTX 已从 $2.65B 涨到 $4.4B），并购溢价空间收窄。

### arena 级 kill 触发条件（尽量数据化）
- **K-kill-1（放量证伪）**：orforglipron 上市首 12 月 TRx/收入斜率显著低于同期注射装机增速（如口服占新增 GLP-1 处方份额不升反降）→ 平权化放量证伪，全 arena 降级。
- **K-kill-2（疗效领跑证伪）**：GPCR/VKTX 口服 Phase 3 顶线减重大幅回落到 <8%（Phase 2 幅度守不住）→ WMBT-4 破，深研档降级。
- **K-kill-3（利润池提前塌）**：出现首个口服小分子 generic/授权仿制申报，或大厂发动价格战使口服净价腰斩 → 利润池自毁提前，全 arena re-rate。

### 历史镜鉴（≥2 · 曾经的赢家如何被取代）
1. **他汀 vs PCSK9（疗效领跑者被可及性者碾压）**——PCSK9 抑制剂（Repatha/Praluent）疗效更强，上市时被寄望百亿峰值，却因注射+高价被保险大量拒付、长期屈居小众；口服廉价的他汀稳坐一线[mat-a6e783]。**失败模式**：疗效领跑 ≠ 商业领跑，可及性/先发碾压边际疗效。**峰谷**：PCSK9 实际放量长期远低于上市预期（早期保险拒付率一度极高）。**最早预警**：上市后放量斜率远低于分析师模型。**现在是否已现**：GPCR/VKTX 尚未商业化，NA——但这正是**对深研档最锋利的 bear 镜鉴**（疗效领跑者可能重蹈 PCSK9）。**教训**：押疗效领跑者必须叠加"可及性/产能/并购退出"的对冲，纯疗效不够。
2. **丙肝 DAA（Gilead Sovaldi/Harvoni · 利润池被竞争而非专利摧毁）**——颠覆性口服药 3 年建成 $19B 峰值，竞品降价+患者池耗竭数年内快速侵蚀（2016 美国 HCV 销售 −33%）[mat-da05cc]。**失败模式**：竞品"存在"即逼降价，专利未到期利润池已崩。**峰谷**：峰值 ~$190 亿 → 数年腰斩。**最早预警**：竞品（AbbVie/Merck）上市即触发折扣（挂牌价近腰斩）。**现在是否已现**：50 项目在研 + 净价下行——**价格侧信号已部分显现**。**教训 + DIS-analogy**：丙肝是一次性治愈（存量耗竭驱动崩塌），减重是慢病长期用药（患者池再生），故对 GLP-1 侵蚀驱动主要是**价格/generic 竞争**而非池耗竭——这条差异必须扣除，否则高估崩塌速度。
3. **（K3 补充）DPP-4/SGLT2 口服糖尿病小分子**——sitagliptin（DPP-4）等口服小分子专利到期后 generic 快速侵蚀，比多肽 biosimilar 更彻底[mat-daac55]。**教训**：印证 WMBT-5 远期弱——口服小分子悬崖陡。

> **红旗自检**：本环刻意选了两个"赢家被取代/利润池崩塌"的失败镜鉴（他汀-PCSK9、丙肝），而非只找"超级赛道成功"案例——符合 arena 层镜鉴纪律。

### signpost（未来 3–12 月验证/证伪事件）
- **2026 H2**：orforglipron 上市首季 TRx 斜率（验 K-kill-1 / WMBT-2）+ Medicare Bridge Program 2026-07 启动后 uptake[mat-c9c6aa]。
- **2026 Q3**：VKTX VANQUISH-2 皮下顶线 + GPCR aleniglipron Phase 3 启动[mat-63a6fb]。
- **2026 Q4**：GPCR SWITCH（注射→口服维持）+ T2DM 数据（验长期维持叙事）[mat-63a6fb]；华东 HDM1002 递 NDA。
- **持续**：口服占新增 GLP-1 处方份额、首个口服小分子 generic 申报、IRA/TrumpRx 净价落地。

## 环 ⑥ shortlist 谁、谁进 company 深研【行动 = 漏斗】

> tier = **卡位/质量 × 当前定价**（②做闸门），非只按好坏排。档名映射：深研=shortlist / 观察=watch / 淘汰=eliminated。

### 深研档（shortlist · 进 company 深研，≤2 家）
1. **Viking Therapeutics（VKTX → `us-viking-vktx`）** — *thesis*：口服+皮下双剂型、口服 12.2% 逼近注射的最大弹性纯标的，同时对冲"疗效落差"与"独立利润池/并购期权"，估值（$4.4B）相对分析师 +204% 空间未透支胜利。*为什么优先*：在深研档里最全能（疗效+剂型+产能），并购与独立商业化双路径都通。*介入纪律（期权仓）*：**加仓触发** = VANQUISH-2（2026 Q3）皮下顶线守住 Phase 2 幅度（≥13% vs 安慰剂）**或**被大厂并购要约；**止损/降级** = 口服/皮下 Phase 3 顶线回落 <8%（K-kill-2）或现金跑道击穿 2027Q1 被迫大幅摊薄增发。仓位定性为可承受的期权仓（下行可归零），非核心仓。
2. **Structure Therapeutics（GPCR → `us-structure-gpcr`）** — *thesis*：小分子纯口服疗效领跑（高剂量 16.3% 无平台期）+ 全赛道最强 IP（Roche $1 亿背书）+ amylin 第二条腿，现金到 2028 不贱卖。*为什么优先*：纯小分子 + IP 护城河，是"疗效 + 专利寿命"双押；但深研须先校准核心剂量 11.3% 与 10.4% 停药率的可及性含义。*介入纪律（期权仓）*：**加仓触发** = aleniglipron Phase 3（Q3'26 启动）首个读出守住核心 ≥11% 且高剂量耐受性可用，**或** SWITCH（Q4'26）证明注射→口服维持可行；**止损/降级** = Phase 3 疗效回落 <8%（K-kill-2）或核心剂量因 10.4% 停药率无法用高剂量导致疗效领跑收窄。同为期权仓。

### 观察档（watch · 暂不深研 + 触发器）
- **礼来（LLY）** — 规模卡位 A 级、WMBT-3 最强兑现者，但 40.8x 已把胜利定价透支且是弱假设最大暴露方。*触发深研*：forward PE 回调 <28x，**或** orforglipron 上市首季 TRx 斜率验证放量（K-kill-1 未触发）。
- **恒瑞医药** — 国产小分子进度不落后 + BD 出海货币化期权，但 44.9x 贵 + 国产内卷。*触发深研*：再现规模化 BD 出海（首付+里程碑），**或** HRS-7535/HRS9531 头对头司美优效读出。

### 淘汰档（eliminated）
- **诺和诺德口服司美（NVO）** — 淘汰主因：口服走**多肽路线**（费料/成本高/难规模化），与本 arena"小分子平权化"结构相悖，且份额流失；注射存量已在 `injectable-incumbent` arena 覆盖。*quarantine=false*（口服司美若守住 65% 份额且净价企稳，可 revive 观察）。
- **华东医药** — 淘汰主因：集团毛利率 32% 商业分销拖累，与高利润池论冲突，减重仍小基数。*quarantine=false*（HDM1002 头对头司美/替尔泊肽优效读出可 revive）。
- **阿斯利康（AZN）** — 淘汰主因：AZD5004 仅 Phase 2b、差异化偏耐受性非疗效领跑，太早。*quarantine=false*（AZD5004 Phase 2b 减重%超预期可 revive）。
