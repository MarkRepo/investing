## 核心数据点与事实
- [Business/Overview] [2025] 主打候选药 aleniglipron（GSBR-1290）——口服小分子 biased GLP-1R 激动剂，截至10-K时已在 5 项在研临床研究中（obesity/overweight）。
- [Business/ACCESS Phase 2b] [2025-12 topline] 核心 Phase 2b ACCESS（n=230）36 周安慰剂调整体重降幅：45mg −8.2%、90mg −9.8%、120mg −11.3%（均 p<0.0001）；120mg 组 86% 达 ≥5% 减重、70% 达 ≥10%。（K1 核心剂量守住）
- [Business/ACCESS II] [2025-12 interim 36wk] 探索性 ACCESS II（n=85）安慰剂调整降幅：120mg −14.1%、180mg −14.4%、240mg −15.3%（均 p<0.0001）；44 周 topline 预计 2026Q1。
- [Business/tolerability] [2025] ACCESS 各剂量 AE 相关停药率 7.7%–13.3%，全活性臂均值 10.4%；最常见 AE 为恶心/呕吐（GI 类效应）。（K1 耐受性命门）
- [Business/titration] [2025] 新的更低 2.5mg 起始滴定剂量（Body Composition 与 ACCESS OLE）显著改善耐受性，2.5mg 及后续 5mg 剂量下无 AE 相关停药——Phase 3 将采用 2.5mg 起始。（K1 高剂量落地路径）
- [Business/Phase 3] [2025] 已计划 EOP2 FDA 会议；Phase 3 注册项目预计 2026 下半年启动，2.5mg 起始 + 多个维持剂量。（K3 时间线）
- [Business/amylin] [2025] 两个口服小分子 amylin 激动剂：ACCG-2671（2025-12 进入 Phase 1）、ACCG-3535（2025-11 declared 第二 DACRA 候选）；临床前 sub-nanomolar 活性、与 semaglutide 联用优于单药。
- [Business/manufacturing] [2025] 当前 aleniglipron 产能 6,000 吨/年，足供 >1.2 亿患者/年（口服小分子可及性论点 K3）。
- [Business/IP] [2025-12-31] 专利组合 >480 项专利及申请，含 >125 项已授权。GLP-1（Gasherbrum）24 个专利族，预计 2041–2045 到期；amylin（Aconcagua）13 族 2044–2046；GIPR（Gimigela）6 族 2046。（K4）
- [Business/Roche] [2025-12] 子公司 Gasherbrum 与 Genentech/Roche 签 GNE 授权协议：就一类不同于 aleniglipron 的口服 GLP-1 专利授予非独占许可（覆盖 GNE 自有化合物 CT-996），Genentech 一次性支付 $100M + 低个位数销售分成；不 encumber aleniglipron 等在研管线。（K2/K4 Roche 背书）
- [Business/competition] [2025] 迄今无口服小分子 GLP-1 获批用于糖尿病/肥胖；在研竞品含 Pfizer、Eli Lilly（orforglipron）、Regor、AstraZeneca/Eccogene、Terns、Hengrui、Merck（HS-10535）、Kailera 等。（K3 竞争格局）
- [Business/market] [2025] 肥胖/超重全球影响 >30 亿人，可及市场 >$1000 亿/年；已获批注射 GLP-1 一年停药率 65%、两年 85%（口服维持治疗机会窗）。
- [Business/Schrödinger] [2025] Aconcagua-Schrödinger 协议截至 2025-12-31 已达成两项里程碑共 $9.0M，已付 $3.0M，余 $6.0M 于 2026-01 支付。
- [Business/pipeline 其它] ANPA-0073（APJ，已决定不适合选择性减重）；LTSE-2578（LPA1R/IPF，Phase 1 完成，寻求非代谢适应症战略选择）。

## 叙事主线
因为 aleniglipron 在 Phase 2b ACCESS 守住核心剂量 120mg −11.3%（240mg −15.3%），叠加 2.5mg 起始滴定把停药率压回、24 族 2041-45 专利 + Roche $100M 背书 → 所以其口服小分子减重资产的可信度与护城河被强化 → 对投资意味着这是数据风险已部分释放、但仍需 Phase 3 复制并面对 Lilly/Novo 口服竞争的高质量 binary 资产。

## 反常识/分歧点
- 市场常把 10.4% 停药率当高剂量落地障碍，但本章数据显示 2.5mg 起始滴定下无 AE 相关停药——耐受性主要源于旧的 5mg 起始而非药物本身，对 K1 偏正面。
- Roche 的 $100M 授权针对 CT-996（不同类别），并非 aleniglipron；市场易误读为 Roche 为 aleniglipron 背书。真实含义是 Gasherbrum 专利族广到能覆盖竞品化合物，反证 IP 护城河宽度（K4），而非并购信号（K2 需谨慎解读）。

## 质量备注
数据来自 2026-02-26 归档的 2025 10-K，权威一手；临床数据为公司披露 topline/interim（LSM + primary efficacy estimand 口径，非 ITT），Phase 3 口径可能不同。
