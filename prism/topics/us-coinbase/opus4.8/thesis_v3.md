## §0. v2 → v3 changelog（release notes · 仅 review 用）

- **触发**：Q2'26 财报（2026-07-30 报，季末 2026-06-30）。这是 v2 预登记的 K1 决胜点。
- **【K1 红灯正式翻牌 ✅】** v2 预登记红灯 = "Q2'26 S&S 绝对额再度同比负增长（连 2 季负）"。**实际：S&S $555M vs Q2'25 $632M = −12% Y/Y，Q1'26 亦 −13.6% Y/Y → 连 2 季同比负 → 红灯确认**。坐实"S&S 抗周期利润地板是斜坡而非地板"，**根因是降息压缩 USDC/利息类收入**（USDC 平台余额创 ATH $20B，但 stablecoin 收入 $292M 被利息下滑抵消）。**→ 移除"S&S 缓冲垫"看多支柱、正常化经营盈利下修。**
- **【macro 依赖从背景升为 load-bearing】** v2 挂起的 thesis review（regime v3→v4：偏松但缓冲抽干、降息路径）**已被本季财报兑现**——降息传导为 S&S 逆风。macro_stamp 更新为 regime v4，rates_us 标 load_bearing。
- **base 下修 $135-145（中枢 $140）→ $125-140（中枢 ~$132）**：正常化经营净利 $1.75B → **$1.6B**（S&S 侵蚀 + 利率逆风打折），倍数轴（SOTP 混合 ~16.5x）与资产负债表桥不变（桥更新：净现金 $3B→$2.7B、BTC $1.6B→$1.47B）。股数改用 Q2 实际稀释 264M。
- **EV 由负回升到 ~零**：现价 $159.5 → **$146.26（−8%，财报 miss 后两日累计 −11~13%）**；概率加权目标价 $153 → **$148 ≈ 现价**；**现价 EV −4% → ~+1%**。股价下跌 + base 下修（S&S 证伪）两个方向大致抵消 → **由"略贵/观望"收敛为"≈公允/观望"**。
- **介入纪律微调**：真安全边际 ≤$120-130 → **≤$115-125（EV +12~25%）**，强力买 ≤$110 → **≤$105（EV +40%）**；现价 $146 = **≈公允/观望（EV ~零）**，不建仓、不做空。
- **thesis 重构（strength 维持 5/10）**：从"逆周期看多 + S&S 缓冲垫"→ **"纯周期高 beta 加密期权 + 合规份额赢家；S&S 归入利率敏感的顺周期腿、不再算抗周期支柱；现价公允、等深跌 capitulation 才是逆周期机会"**。方向仍未翻空（份额 ATH 10.3% + 逆周期资本配置 + bull 尾部不对称 + 资产负债表垫底）。
- **新增正面事实**：加密交易量份额 **ATH 10.3%**（连 3 季创高，盘子缩但份额赢）、预测市场年化 **$100M+**（新曲线、翻倍）、5 月裁员 14% + 砍成本 ~$600M（低谷成本纪律）。
- **新增负面事实**：**Adj 净利连 2 季亏（−$105M，恶化）**、Adj EBITDA 连 4 季降至 $208M、运营层转亏 ~$114M；Q1'26 回购均价 $169 > 现价 $146（回购择时打脸）。

## §1. 核心 thesis（当前完整版）

**COIN 是一台"杠铃"，但本季确认了它是"顺周期的杠铃"：一个顺周期交易佣金引擎（59%）+ 一层曾被寄望"减震"、如今证明同样受利率/周期拖累的经常性平台（41%）。** Q2'26 两条腿一起降（交易 −21% Q/Q、S&S −5% Q/Q、−12% Y/Y），S&S 的抗周期溢价被证伪。按 **SOTP 混合倍数（经营 ~16.5x）+ 资产负债表桥** 定价，正常化经营净利 $1.6B（下修）对应 base **~$125-140（中枢 ~$132）**（含净现金 $2.7B + BTC $1.47B + 战略股权 + Base/Deribit 期权加回）。

- **强度：5/10**（中性偏谨慎·维持）。方向仍偏多（合规 franchise 未损、份额 ATH 10.3%、逆周期资本配置、bull 尾部不对称、资产负债表垫底），但这是 **高 beta 加密杠杆工具，现价 ≈ 公允、无安全边际**。
- **落在 company 终局**：**现价 $146.26 ≈ 公允/观望（EV ~+1%、高于 base ~10%）。真逆周期机会在 ≤$115-125（EV +12~25%），强力买 ≤$105（EV +40%）。** base ~$132、bull ~$310、bear ~$65。
- **明确不站卖方 $215-310**（需强牛 + 平台倍数重估双叠加；且卖方已把 Q2 EPS 下调为亏损）。
- **看多逻辑收缩为窄两条**（S&S 支柱本轮移除）：**①合规 franchise + 份额 ATH（份额赢家）②逆周期资本配置 + 果断砍成本（低谷未损、有期权）**。这两条撑不起高于 base ~$132 的溢价——现价的溢价是市场在 price-in 温和周期修复，而我信心仅"低-中"。

## §2. 支持理由（当前完整清单）

1. **合规龙头 franchise 在熊市未受损 + 份额创新高**：美国最大合规交易所、多数现货 BTC/ETH ETF 托管方、SEC 带偏见撤诉 `[mat-977fb4]`；**Q2'26 加密交易量份额 ATH 10.3%（连 3 季创高）**、USDC 平台余额 ATH $20B `[mat-62bb40]`；机构 Prime 质押 $15.2B + 散户 $7.5B、Base 占 L2 DeFi TVL 46% `[mat-fe0dd9]` `[mat-b4e2c4]`。**盘子在缩、份额在赢**是 franchise 质量的最硬证据。
2. **逆周期资本配置 + 成本纪律（K5 强信号）**：低谷回购授权翻倍到 $4B、$4.3B 收 Deribit、增持 BTC $788M；**Q2'26 新增：5 月裁员 14%（4,321 vs 4,988）、砍成本 ~$600M、下调 2026 费用指引** `[mat-62bb40]` `[mat-2c07c9]`——低谷主动收缩护 Adj EBITDA 正（14 连正季）。
3. **新增长曲线在冒头**：预测市场年化 $100M+（翻倍、新）、Deribit 衍生品第二曲线、Base 链上基建 `[mat-62bb40]`——平台层期权仍在扩张。
4. **温和下行季"下行被账面噪声高估"（限温和情景）**：Q2 GAAP 亏 $360M 但 Adj EBITDA 仍 +$208M，币价 mark 夸大经营恶化。⚠️ 但 **Adj 净利也已转亏 −$105M**，说明经营层确实承压、非纯噪声；深熊下此支柱失效。
5. **bull 尾部不对称仍在**：下轮牛市 + 平台倍数重估可到 $310（+112% 自现价、自 $105 则 +195%）——这是 ≤$105-115 值得持有的加密周期期权价值、不翻空的原因。
6. **资产负债表稳健**：现金 $8.6B、净现金 ~$2.7B、三年 FCF 全正——无生存风险、有熊市弹药 `[mat-62bb40]`。

## §3. 反方观点（当前完整清单）

1. **现价 ≈ 公允、无安全边际（首要）**：概率加权目标价 $148 ≈ 现价 $146.26；base ~$132 < 现价 ~10%、EV ~+1%。市场已 price-in 温和修复，无折价可捡。
2. **S&S 减震腿证伪（本轮致命·K1 红灯）**：S&S 连 3 季降（Q3'25 $717M 峰 → Q2'26 $555M）、−12% Y/Y；USDC 余额 ATH 也没扛住利率降 `[mat-62bb40]`。"多元化抗周期"叙事破产。
3. **顺周期本质 + 盈利转亏**：Q2'26 总收入 −14% Q/Q、交易 −21%、**Adj 净利连 2 季亏（−$105M，恶化）**、Adj EBITDA 连 4 季降 `[mat-62bb40]`。
4. **take rate 竞争性侵蚀（K4·独立非周期承重轴）**：散户 1.575% vs HOOD 0.50%（3x），均值回归与周期无关；若溢价被磨平，占 59% 的交易收入腰斩 `[mat-4529fe]` `[mat-0ded80]`。
5. **稳定币利率杠杆 + Circle 集中**：降息压息差已兑现；单一对手方 19-23% 收入集中 `[mat-2c07c9]` `[mat-fe0dd9]`。
6. **稀释 + 商誉减值**：Deribit 76% 股票支付、商誉 $1.1B→$4.2B，深熊下减值冲击账面 `[mat-2c07c9]`。
7. **回购择时打脸**：Q1'26 均价 $169 回购、现价 $146——管理层估值判断偏乐观，不因"管理层在买"就跟买。
8. **价值陷阱 + 监管双刃**：2022 收入曾 −59% `[mat-b0635b]`；GENIUS NPRM 若并入分销方返奖则击穿 rewards 链条 `[mat-adcede]`。
9. **治理集中**：双重股权（Class B 20 票），创始人控制多数投票权 `[mat-977fb4]`。

## §8. 思维过程留痕

- **本轮关键改动**：K1 从"缓冲垫（黄灯）"翻到"红灯·支柱移除"——Q2'26 S&S 连 2 季同比负是财报级铁证，不是可辩护的口径问题。这也把 v2 挂起的 macro review（降息）从"背景"升为"load-bearing 逆风"。
- **刻意避开的偏见**：① 不因股价跌 8% 就机械看多（base 也随 S&S 证伪同步下修，抵消了大部分"变便宜"）；② 不把份额 ATH 10.3% 当"一切都好"（份额赢但盘子缩、盈利转亏）；③ 不把 GAAP 巨亏当纯噪声（Adj 净利也转亏，经营层确在承压）；④ 不因"管理层 $169 在回购"就跟买（择时已打脸）；⑤ 仍不把纯周期倍数套到经常性平台利润上（保留 SOTP 混合，不接受反方纯 12x）。
- **关键差异（我 vs 市场）**：市场把 COIN 定在概率加权公允价 $148 ≈ 现价——**我与市场本轮基本同调（EV ~零）**，分歧从 v2 的"现价略贵"进一步收敛为"现价公允"。真正的 edge 只在 ≤$115-125 的深跌区才出现。
- **最可能错的方向**：① 若利率企稳 + 平台层（USDC/Base/衍生品/预测市场）增速恢复，S&S 止跌、混合倍数该更高、base 上修（我可能低估、K1 红灯解除）；② 若 take rate 结构性侵蚀 + 周期二次探底叠加，则价值陷阱、bear $65 甚至更低。
