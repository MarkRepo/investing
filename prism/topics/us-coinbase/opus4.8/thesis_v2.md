## §0. v1 → v2 changelog（release notes · 仅 review 用）

- **强度下调 6/10 → 5/10**（逆周期看多 → **中性偏谨慎 / 只在深跌逆周期买**）。方向未翻空，但现价从"微看多"降为"观望偏回避"。
- **【05-critic 第3轮三评·2026-07-15 · 采纳倍数轴修订】** 独立空头命中一个未披露的孪生轴：v1/v2 case 只补了 base 的**盈利轴**敏感性（$1.2-1.5B→$110-145），却对**倍数轴**用单一乐观倍数（25x PE / 17x EV-EBITDA / 8x PS，8x 还 > 现价 6.69）。**主 agent 裁决估值方法 = SOTP/混合倍数**（COIN 是"杠铃"：59% 顺周期交易佣金应给 12-14x + ~40% 经常性订阅/托管/稳定币基建应给 16-25x），加权 **~15-16x**，非单一 25x（那把平台倍数套到周期利润上）、也非单一 12-15x（那把周期倍数套到经常性利润上——反方 overstate 处）。
- **base 下调 $170-180 → $120-140（中枢 ~$130）**：正常化盈利中枢仍取 $2.0B（第2轮已辩护、本轮不动盈利轴），仅把倍数从单一 25x 改为混合 ~15.5x。三口径互证 $113-140。
- **EV 由正翻负**：概率加权目标价 ~$145，**现价 $159.5 的 EV ≈ −9%**（v1 为 +3-4%）；EV 盈亏平衡 ~$145。
- **介入纪律下移**：真安全边际买入区 v1 的 ≤$130 → **≤$120-125（EV +15-30%）**，强力买 **≤$110**；现价 $159.5 = **观望偏回避（EV 负）**。
- **take rate 结构性侵蚀升为独立于周期的承重轴**（K4）：3x 溢价（1.575% vs HOOD 0.50%）均值回归与周期回暖无关，base 不再隐含"周期好转则费率无忧"。
- **不变**：命门 K1-K5 不变；bull / 深熊 结构不变（bull 尾部不对称仍在，故 ≤$110 是有吸引力的加密周期期权，不翻空）；franchise 质量、逆周期资本配置、无生存风险等支持理由不变。
- **【2026-07-15 资产负债表桥修订 · 就地补正，stance 不变】** 用户点出估值未干净计入自持资产。补正：正常化盈利已剔除自持币重估，故 **净现金 ~$3B + BTC 持仓 $1.6B（折后 ~$1.3B）+ Circle/战略股权 $0.9B（折后 ~$0.6B）+ Base/Deribit 期权 ~$4B 必须作为独立资产加回**（漏计 ~$2.5B）。三模型统一为"经营价值（$1.75B×经营17x）+ 资产负债表桥"。**base $120-140 → $135-145（中枢 ~$140）；现价 EV −9% → −4%；现价高于 base 23% → ~9~14%；介入 ≤$110-120 → ≤$120-130**。方向/强度/命门全不变，仅补足漏项后 base 回升、现价从"偏贵"软化为"略贵"。

## §1. 核心 thesis（当前完整版）

**COIN 是一台"杠铃"：一个顺周期的交易佣金引擎（59%）+ 一层正在长大的经常性平台（订阅/托管/稳定币基建，~41%）。** 用单一倍数给整体估值两边都错——把它当纯成长平台（25x）会高估、当纯周期交易所（12-15x）会低估。按 **SOTP 混合倍数（经营 ~17x）+ 资产负债表桥** 定价，正常化盈利 $2.0B 对应 base **~$135-145（中枢 ~$140）**（含净现金 $3B + BTC 持仓 + 股权 + Base/Deribit 期权加回）。

- **强度：5/10**（中性偏谨慎）。方向仍偏多（franchise 未受损 + 逆周期资本配置 + bull 尾部不对称），但这是 **beta 3.35 的高波动加密杠杆工具，现价并不便宜**。
- **落在 company 终局**：**现价 $159.5 略贵/观望（EV ≈ −4%、高于混合 base+桥 ~9~14%）。真逆周期机会在 ≤$120-130（EV +18-40%），强力买 ≤$110（EV ~+40%）。** base ~$135-145（中枢 ~$140，含资产负债表桥）、bull ~$310、bear ~$95、深熊 $65。
- **明确不站卖方共识 +90%**（$292-316 = bull 情景 + 平台倍数重估叠加）。
- **看多逻辑收缩为窄两条**（承 v1 第2轮）：①温和下行季"下行被账面噪声高估"（深熊失效）②合规 franchise + 逆周期资本配置在低谷未受损；S&S 只作缓冲垫。**本轮再加一条约束：这两条支柱撑不起高于 ~$140 的 base（含资产负债表桥）——现价的溢价是市场在 price-in 周期修复 + 平台倍数重估，而我对这两者信心仅"中/中-低"。**

## §2. 支持理由（当前完整清单）

1. **合规龙头 franchise 在熊市未受损 + 量化壁垒**：美国最大合规交易所、多数现货 BTC/ETH ETF 托管方、SEC 带偏见撤诉 `[mat-977fb4]`；机构 Prime 质押 $15.2B + 散户 $7.5B、平台托管资产 $294B（-22% 主因币价非净流出）、Base 占 L2 DeFi TVL 46% `[mat-fe0dd9]` `[mat-b4e2c4]`。
2. **经常性平台层在长大（值更高倍数的那部分）**：订阅（Coinbase One）+ 托管 + 稳定币基建约占收入 40%，粘性高、半经常性——这是 SOTP 里该给 16-25x 的部分，也是 COIN 不该被当纯交易所（12-15x）的理由。
3. **Q1 转亏是账面现象非经营崩坏（限温和情景）**：税前亏损 $465M 中 $482M 来自自持币重估（不对冲），剔除后经营接近打平 `[mat-fe0dd9]`。⚠️ 仅温和下行季成立，深熊下 mark/交易量/S&S 同崩、此支柱失效。
4. **管理层逆周期资本配置（K5 强信号）**：低谷把回购授权翻倍到 $4B、实际 $1.06B@$169、$4.3B 收 Deribit、增持 BTC $788M、裁员 700 `[mat-2c07c9]` `[mat-22fcff]`。
5. **bull 尾部不对称仍在**：下轮牛市 + 平台倍数重估到 22-25x 可到 $300（+88% 自现价、自 $110 则 +173%）——这是 ≤$110 值得持有的加密周期期权价值，也是不翻空的原因。
6. **资产负债表稳健**：现金 $10.4B、净现金 ~$3B、三年 FCF 全正——无生存风险、有熊市弹药 `[mat-22fcff]`。

## §3. 反方观点（当前完整清单）

1. **现价并不便宜（本轮新升为首要反方）**：按 SOTP 混合经营倍数 ~17x + 资产负债表桥，base ~$140，**现价 $159.5 高于 base ~9~14%**、EV ≈ −4%。市场已 price-in 周期修复 + 平台倍数重估，两者我信心仅中/中-低。
2. **顺周期本质未变，"多元化"是被动的**：Q1'26 营收 -31%、交易量 -50%、Adj EBITDA -67%；S&S 占比升到 44% 主因分母塌陷，绝对额 -14% `[mat-fe0dd9]` `[mat-22fcff]`。
3. **take rate 竞争性侵蚀是独立于周期的承重轴**：散户 1.575% 是 HOOD 0.50% 的 3x，均值回归与周期回暖无关；FY25 mix 迁移已拖 -$384M `[mat-0ded80]` `[mat-4529fe]`。若溢价被磨平，占 59% 的交易收入腰斩。
4. **S&S 内部高度集中 + 利率杠杆**：52% 靠稳定币，±150bp≈±$540M；rewards/other 分别 -49%/-22% `[mat-abfc11]` `[mat-22fcff]`；单一对手方（极可能 Circle）占收入 19%→23% `[mat-2c07c9]` `[mat-fe0dd9]`。
5. **稀释 + 商誉减值**：Deribit 76% 股票支付、商誉 $1.1B→$4.2B（占市值 ~10%），深熊下减值冲击账面 `[mat-2c07c9]`。
6. **监管双刃 + "洞"可能被补**：GENIUS NPRM 未定稿，若最终细则并入"分销方返奖"则击穿 rewards 链条 `[mat-adcede]`。
7. **价值陷阱风险**：2022 收入曾 -59% `[mat-b0635b]`；若主因是竞争性衰退而非周期底，"均值回归"逻辑失效。
8. **治理集中**：双重股权（Class B 20 票），创始人控制多数投票权 `[mat-977fb4]`。

## §8. 思维过程留痕

- **本轮关键改动**：估值方法从"单一倍数×混合盈利"改为"**SOTP 混合倍数**"——依据 COIN 杠铃业务属性（59% 周期交易 + 41% 经常性平台）。这是三评致命一击（"25x × 无法举证的 $2.0B"）的正确回应：不是接受反方的纯周期 12-15x（那忽略平台层），而是按 mix 加权到 ~15.5x。
- **刻意避开的偏见**：① 不把卖方 +90% 当 base；② 不把 GAAP 巨亏当经营崩坏（限温和情景）；③ 不把 S&S 占比升当多元化胜利（被动、绝对额 -14%）；④ **不把平台成长倍数套到周期交易利润上**（本轮新增·纠正 v1 的单一 25x）；⑤ 也不把纯周期倍数套到经常性平台利润上（避免反方 overstate 的反向错误）。
- **关键差异（我 vs 市场）**：市场现价隐含 EV/EBITDA ~14x + price-in 周期修复；我按混合 base + 资产负债表桥判现价 **略贵 ~9~14%**、EV −4%。我 vs 市场的分歧从 v1 的"看多 +delta"收敛为"现价略贵、等回调"。
- **最可能错的方向**：① 若平台层（USDC/Base/衍生品/订阅）增速远超预期，混合倍数该更高、base 上修（我可能低估）；② 若 take rate 结构性侵蚀 + 周期二次探底叠加，则价值陷阱、bear $90 甚至更低。
