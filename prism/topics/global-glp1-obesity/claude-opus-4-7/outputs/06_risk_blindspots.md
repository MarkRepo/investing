## 已识别的核心风险（v1 反方 + critic 加重）

### R1：LLY PE 50x + BALANCE/IRA/MFN/DTC 四轨压价 → 戴维斯双杀（K5+K2，**critic 加重**）

- **触发条件**（critic 加重）：reta TRIUMPH-3 顶线 ≤22.5% + BALANCE Bridge 2027-12 续期失败 + Trulicity 2028 IRA + 第二梯队 ≥3 家成熟 + Trump 政府已 cancel CMS pilot 显示监管态度收紧
- **概率**：中等（**30-35%**，上调 5pp） — LLY 2026 Q1 量价剪刀差正向已实证短窗口，但 2027-12 后 + 2028+ 阻力结构性
- **timing 边界**：
  - 2026 H2 - 2027 H1：量价剪刀差正向延续（强度 8.0/10 看多）
  - 2027 Q4 - 2028 H1：BALANCE Bridge 终止 + Trulicity IRA 临近（中性 6.0/10）
  - 2028 H2+：第二梯队商业化 + oral 替代注射（看空 4.5/10）
- **影响**：LLY 估值收敛到 PE 30-35x → 股价下跌 30-40%
- **来源**：mat-3a4b6e + mat-20e63b + mat-92bc1e + mat-a29026 + mat-cms-cancels + mat-e8d389（LLY 自承）

### R2：第二梯队收购溢价改变 LLY 估值锚（K6，**critic 重估**）

- **触发条件**：Viking 被收购溢价 ≥3x ($30→$90+) — 但 critic 重估概率
- **概率**（critic 重估）：**15-22%**（Phase 3 成功 60-70% × 被收购 50% × 溢价 ≥3x 50%），不是 v1 的 30-40%
- **影响**：LLY PE 收敛 5-10x，NVO 修复 2-3x → LLY 跌 15-20%、NVO 涨 10-15%
- **下行不对称**：Viking $30 已 price in 70-80% Phase 3 成功率 + 50% 收购概率 → Phase 3 成功但溢价 ≤2x → -47%
- **VKTX 自营产能压制溢价**：100M 注射器 + 1B+ oral tablets（mat-20420a）— Big Pharma 不为产能溢价支付
- **来源**：mat-1f9505 + mat-ef091e + mat-20420a + mat-dfd8f0 + mat-0ed0b9 + critic-review § 反方 3

### R3：GLP-1 终身服药商业不可持续（K2 长期，**critic 加重**）

- **触发条件**：停药 1 年内反弹 50-70% → 政府长期不愿承担 → BALANCE/IRA 是开端，2028+ Medicare 全面收紧 → 单价回归 generic 水平
- **概率**：低-中（**15-20%**，上调 5pp 含 Trump 政府 2026-05 cancel CMS pilot 信号） — 短期 2026-2027 量增可吸收
- **历史镜像加重**：渗透率 ≥20%（2029+）→ 支付方明确不愿继续买单（参 anti-obesity 文献，PCSK9 渗透率永远 <1% 类比）
- **影响**：极端情况下 GLP-1 单价腰斩，LLY/NVO 估值整体下移 50%+
- **来源**：mat-524100 + mat-a29026 + mat-cms-cancels

### R4：NVO 反弹失败 + 多元化兑现慢（K3，**critic 重估**）

- **触发条件**（critic 加重）：amycretin Phase 2 数据 base case 15-17%（未必达 18% 阈值）/ Wegovy 7.2mg 美国销售爬坡慢 / Akero MASH Phase 3 失败 / **HIMS 合作 2026-05-22 已破裂（catalyst 1 个已废）** / 340B 一次性 $4.2B Q2 反向砸盘

- **NVO 反弹胜率**：从 v1 "≥ LLY 续涨" 调整为 **30-40% 反弹胜率**
- **影响**：NVO PE 进一步收敛到 18-20x，下跌 15-20%
- **来源**：mat-2bbc64 + mat-606af8 + mat-653869 + mat-novo-drops-hims + mat-5b9ef4

### R5：中国创新药估值泡沫破裂（K4，**critic 加重**）

- **触发条件**（critic 加重）：

- **概率**：中等（**30-35%**，上调 5-10pp）

- **来源**：mat-25971d + mat-11a269 + mat-3c1ced + mat-cc70d1 + mat-shouguan-jy29 + mat-7edea3

### R8：MFN 协议长期国际定价对齐传导（K5 长期，**critic 加重**）

### R9：oral GLP-1 四家同台 → 注射 GLP-1 价值主张减弱（K1，**critic 加重**）

## 共识的盲点（市场可能没充分定价的）

### B1：信达 / 恒瑞 BD 出海现金流的可持续性（**critic 加重**）

- **盲点**：信达 2025 BD 收入 $1.5B+ + 恒瑞 2025 BD ¥33.92 亿（5 笔）— 市场可能把这些视为一次性而非常态化基础
- **critic 加重**：2025 三大单是研发管线集中爆发的一次性收成，2026 H1-H2 BD 大概率回落到 1 单 → 2026 营收增速失望
- **如果是常态**：信达/恒瑞 long-term 估值结构性重估
- **如果一次性**：2026 BD 收入大幅回落 → 2026 营收增速失望
- **决策含义**：在 2026 H1 / H2 BD 大单尚未实证常态化前，不应给信达 Tier 1 仓位

### B2：retatrutide 抗肿瘤前临床数据

- **盲点**：mat-5804fb 提到"retatrutide 临床前提示对肥胖相关癌症抑制效果好于 sema"——若 Phase 3 在 cancer outcome 验证，是 LLY 没披露的潜在第二增长曲线
- **影响**：极端 upside 情景下 LLY 估值再涨

### B3：NVO 340B $4.2B 一次性收益的非经常性（**critic 加重**）

- **盲点**：mat-5b9ef4 NVO 2026 Q1 一次性确认 $4.2B 之前因诉讼推迟收入。市场可能误读为基本面改善 → 后续 quarter 同比反向
- **critic 加重**：Q2 同比反向是高概率事件 → NVO 反弹 catalyst 中"基本面已改善"假设要重新校准
- **影响**：NVO 2026 Q1 财报或显著超预期但 Q2 反转

### B4：MFN / BALANCE Bridge 实际执行力的脆弱性（**critic 加重**）

- **盲点**：CMS BALANCE Model 已被无限期延迟（mat-a29026 KFF）vs LLY 单边 Bridge Program 已生效（mat-3a4b6e）—— 政府机制和公司单边协议的脆弱性是市场没充分讨论的
- **critic 实证**：**Trump 政府 2026-05 已 cancel CMS Medicare GLP-1 pilot**（mat-cms-cancels）— 政策方向比 KFF "无限期延迟" 更明确收紧
- **如果脆弱**：2027-12 后任何政策摇摆都可能让"已有协议"失效

### B5：oral GLP-1 替代注射 timing 的市场低估（**critic 新增**）

- **盲点**：market consensus 把 oral GLP-1 视为 LLY orforglipron 独占 → 实际 VKTX/GPCR/信达 三家 Phase 3 顶线 2027 H2-2028 H1 集中读出
- **如果显现**：注射 GLP-1 unit 营收 2028+ 应做 **-15-20%/年压力情景**
- **影响**：thesis 强度按时段拆分（详见综合风险评估）

### 应对建议（v2 升级）

1. **集中度管理**：LLY 持仓不超过总仓位 **25-30%**（v1 30-40% 下调）— 避免单标的依赖型增长的 2028+ 远期风险
2. **对冲策略**：长 LLY + 长 NVO（pair）+ **降信达至 Tier 1.5（10-15%）** + 中性 恒瑞（边际持）
3. **VKTX 期权式配置**：~3-5% 仓位作为 K6 收购溢价 catalyst 的 binary 押注（v1 5%，下调上限至 5%；按重估概率 15-22%，按 binary 处理）
4. **核心监控触发卖出**：reta ≤22.5% / VKTX 顶线 + 不被收购 / BALANCE 实际渗透 >1000 万 / oral 三梯队 ≥15% 顶线读出 → 任一触发 → 评估减仓 LLY
5. **HIMS 仓位归零**：NVO 合作 2026-05-22 破裂后，HIMS 不再具备配置价值
6. **时段调仓**：2027 Q3 起逐步减仓 LLY/NVO（thesis 强度从 8.0 → 6.0）；2028 H2 起评估全面退出 GLP-1 板块（强度 4.5/10）
