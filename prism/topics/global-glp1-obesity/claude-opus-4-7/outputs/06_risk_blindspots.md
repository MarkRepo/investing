# 风险与盲点：GLP-1 减肥药 thesis 的下行情景

> 列出 thesis_v1 已知的反方 + 03-extract findings 浮现的新风险 + 当前共识的盲点。每条标注其触发概率和影响幅度。

## 已识别的核心风险（thesis_v1 反方持续的）

### R1：LLY PE 50x + BALANCE/IRA/MFN/DTC 四轨压价 → 戴维斯双杀（K5+K2）

- **触发条件**：reta TRIUMPH-3 顶线 ≤22.5%（仅平 tirz）+ BALANCE Bridge 2027-12 后 Medicare 长期机制比预期更严 + Trulicity 2028 IRA 实际打击 + 第二梯队 ≥3 家 Phase 3 顶线优于预期
- **概率**：中等偏低（25-30%）— LLY 2026 Q1 量价剪刀差正向已实证，但 2028+ 阻力结构性
- **影响**：LLY 估值收敛到 PE 30-35x → 股价下跌 30-40%
- **来源**：mat-3a4b6e + mat-20e63b + mat-92bc1e + mat-a29026

### R2：第二梯队收购溢价改变 LLY 估值锚（K6）

- **触发条件**：Viking 被收购溢价 ≥3x ($30→$90+) + Structure / Carmot 类似溢价 → 第二梯队估值上修，LLY/NVO PE 锚相对收窄
- **概率**：中等（30-40%）— Roche Carmot $2.7B 已是先例
- **影响**：LLY PE 收敛 5-10x，NVO 修复 2-3x → LLY 跌 15-20%、NVO 涨 10-15%
- **来源**：mat-1f9505 + mat-ef091e + mat-20420a + mat-dfd8f0 + mat-0ed0b9

### R3：GLP-1 终身服药商业不可持续（K2 长期）

- **触发条件**：停药 1 年内反弹 50-70% → 政府长期不愿承担 → BALANCE 是开端，2028+ Medicare 全面收紧 → 单价回归 generic 水平
- **概率**：低（10-15%，仅 2028+ 长期风险）— 短期 2026-2027 量增可吸收
- **影响**：极端情况下 GLP-1 单价腰斩，LLY/NVO 估值整体下移 50%+
- **来源**：mat-524100 + mat-a29026

### R4：NVO 反弹失败 + 多元化兑现慢（K3）

- **触发条件**：amycretin Phase 2 数据弱 / Wegovy 7.2mg 美国销售爬坡慢 / Akero MASH Phase 3 失败
- **概率**：中等（25-30%）
- **影响**：NVO PE 进一步收敛到 18-20x，下跌 15-20%
- **来源**：mat-2bbc64 + mat-606af8 + mat-653869

### R5：中国创新药估值泡沫破裂（K4）

- **触发条件**：sintilimab FDA 失败前科重演（信达海外信誉折价）/ HRS9531 Kailera 商业化慢 / mazdutide 国内被 sema 仿制价格战切走
- **概率**：中等（20-30%）
- **影响**：信达 PE 收敛 35-40x，下跌 20-30%；恒瑞 BD 现金流不及 2025 5 笔常态 → 估值收敛
- **来源**：mat-25971d + mat-11a269 + mat-3c1ced

## 03-extract 新发现的风险（thesis_v1 没充分体现）

### R6：LLY 业务集中度 56% → 65% 一年内 → 单产品依赖加重（K5+R1 协同）

- **触发条件**：tirz 任一安全性事件（FDA 警告 / 罕见严重不良反应）→ LLY 单一支柱风险敞口大；同时 retatrutide 商业化推后或失败 → 接力管线缺失
- **概率**：低（10-15%）— tirz 已被 SURMOUNT 三年随访 + 心衰 MACE 验证
- **影响**：LLY 极端情境下跌 50-70%（类似 NVO 2024-2025 跌 50%）
- **来源**：mat-20e63b（业务集中度）+ mat-3a4b6e（5 万员工 + $10B 产能 commit 的下行刚性）+ mat-e8d389（LLY 自承 counterfeit/MFN/竞争三轨风险）

### R7：第二梯队 Phase 3 失败概率 30-40%（K1+K6 反向）

- **触发条件**：reta TRIUMPH-3 失败 / VK2735 VANQUISH 失败 / CT-388 ENITH 失败任一
- **概率**：每条 30-40%，至少一条失败概率 70%+
- **影响**：取决于哪条失败：
  - reta 失败 → LLY 下一代护城河失败 → LLY 估值下移
  - VK2735 失败 → Viking 估值崩塌 50%+，但 LLY 受益
  - CT-388 失败 → Roche $2.7B Carmot 减值，但 LLY 受益
- **来源**：mat-de8d68 + mat-ab8919（Phase 3 失败概率 SEC 模板风险）

### R8：MFN 协议长期国际定价对齐传导（K5 长期）

- **触发条件**：MFN 协议（LLY+NVO 都签）→ 美国不能比国际市场贵 → 欧洲/日本/中国低价倒逼美国净价压制 + 美国净价压制传导到拉美/亚太
- **概率**：中等（30-40%，2027-2030 渐进传导）
- **影响**：单价多级压制，long-term LLY/NVO net price 下移 -25-30% to 2030
- **来源**：mat-20e63b + mat-653869（NVO 同时签 MFN 类似协议）

### R9：oral GLP-1 四家同台 → 注射 GLP-1 价值主张减弱（K1）

- **触发条件**：LLY orforglipron + VK2735 oral + GPCR aleniglipron + 信达 IBI3042/IBI3032 任一商业化大成功 → 注射 GLP-1（tirz/sema）逐渐被替代 → "便利性 + 价格"成为压制注射 net price 的额外杠杆
- **概率**：中等（30-40%，2028+ 显现）
- **影响**：注射 GLP-1 单价被 oral 拉低，LLY/NVO 主业务 unit 营收 2028+ 加速下行
- **来源**：mat-dc8a8e + mat-1f9505 + mat-0ed0b9 + mat-11a269

### R10：HIMS 渠道战略转型成本高于预期（Q7+K3）

- **触发条件**：HIMS 2026 Q1 美国营收 -8% YoY 是 timing-of-revenue 问题但延续到 Q2-Q3 → 实际是订阅 churn 而非时点
- **概率**：中等（25-30%）
- **影响**：HIMS 估值下跌 30-40%；NVO 失去关键 DTC 放大器
- **来源**：mat-69b291 + mat-c11032 + mat-16065f

## 共识的盲点（市场可能没充分定价的）

### B1：信达 / 恒瑞 BD 出海现金流的可持续性

- **盲点**：信达 2025 BD 收入 $1.5B+ + 恒瑞 2025 BD ¥33.92 亿（5 笔）— 市场可能把这些视为一次性而非常态化基础
- **如果是常态**：信达/恒瑞 long-term 估值结构性重估
- **如果一次性**：2026 BD 收入大幅回落 → 2026 营收增速失望

### B2：retatrutide 抗肿瘤前临床数据

- **盲点**：mat-5804fb 提到"retatrutide 临床前提示对肥胖相关癌症抑制效果好于 sema"——若 Phase 3 在 cancer outcome 验证，是 LLY 没披露的潜在第二增长曲线
- **影响**：极端 upside 情景下 LLY 估值再涨

### B3：NVO 340B $4.2B 一次性收益的非经常性

- **盲点**：mat-5b9ef4 NVO 2026 Q1 一次性确认 $4.2B 之前因诉讼推迟收入。市场可能误读为基本面改善 → 后续 quarter 同比反向
- **影响**：NVO 2026 Q1 财报或显著超预期但 Q2 反转

### B4：MFN / BALANCE Bridge 实际执行力的脆弱性

- **盲点**：CMS BALANCE Model 已被无限期延迟（mat-a29026 KFF）vs LLY 单边 Bridge Program 已生效（mat-3a4b6e）—— 政府机制和公司单边协议的脆弱性是市场没充分讨论的
- **如果脆弱**：2027-12 后任何政策摇摆都可能让"已有协议"失效
