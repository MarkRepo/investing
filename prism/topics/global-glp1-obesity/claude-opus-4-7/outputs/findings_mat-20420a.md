## 叙事主线

因为 **(X) VKTX 已完成注射 + 口服双 Phase 2 + 注射 Phase 3 入组 + 维持剂量探索**（产品矩阵已 hedged across formulations and dose regimens）+ **CordenPharma 大规模产能预付**（自 2026 起 ramping，2027-2028 商业化级别就绪）→ 所以 VKTX 已不是"概念性 Phase 2 标的"，而是"**Phase 3 前夜 + 产能就绪**的差异化 GLP-1 玩家" → 对投资意味着 **K1 阈值（VK2735 顶线 vs reta TRIUMPH-3 / CT-388 ENITH 同窗读出）+ K6 阈值（被收购溢价 ≥3x，收购时机大概率 Phase 3 顶线后）**两条都是 6-18 个月内事件——VKTX 是 K1+K6 双射的最有 catalyst 的标的。

## 反常识/分歧点

- **VKTX 已签 100M 注射器 + 1B+ 口服片产能**——通常 Phase 3 期 biotech 不会自建商业化级别产能（因为 Phase 3 失败概率仍 30-40%）— VKTX 这种 commit 暗示**自主商业化路径准备**（与 K6 反方"可能不被收购"叙事一致：VKTX 自身有 standalone go-to-market 能力，谈判杠杆强）
- **VK2735 + VK2809（MASH）+ DACRA 三条管线** ——VKTX 不只是"GLP-1 单标的"，是组合下注（与 NVO Akero/MASH 收购 同方向）
