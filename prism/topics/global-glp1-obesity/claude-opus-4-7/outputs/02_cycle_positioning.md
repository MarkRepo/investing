# 周期定位：GLP-1 减肥药全球赛道

> 生成于 2026-05-26，训练知识占比约 55%（行业代际跃迁史、政策周期、历史先例），实证锚自 LLY/NVO 2025 + 2026 Q1 财报

## 行业周期类型

GLP-1 减肥药属于**结构性长周期赛道**叠加**代际竞争短周期**双重特征：
- **结构性长周期**（2010s - 2040s）：肥胖人口持续增长 + 适应症外溢 + DTC + 中国/印度/巴西/中东市场逐步覆盖。这层周期由人口结构、慢病预防医保政策、终端患者支付意愿驱动，不轻易反转。
- **代际竞争短周期**（每 5-10 年一代）：分子代际跃迁（GLP-1 单靶 → GLP-1/GIP 双靶 → GLP-1/GIP/GCG 三靶 → 长效月注射 → 口服小分子）每 5-10 年发生一次，决定双寡头/挑战者格局重构。

第二层周期更短（24-36 个月），主导每个具体投资标的的相对收益和估值倍数。

## 历史周期复盘

**第一代（2005-2014）：byetta / 利拉鲁肽时代**
- 2005 byetta（exenatide）首批 GLP-1 类，糖尿病小品种
- 2010 NVO Victoza（利拉鲁肽 / liraglutide）每日注射，糖尿病大品种
- 2014 NVO Saxenda（利拉鲁肽减重剂型）— GLP-1 减重适应症首次拓宽
- 减重幅度：4-6%（temperate）；DTC 不普及；商保覆盖严格

**第二代（2017-2022）：semaglutide 时代**
- 2017 NVO Ozempic（sema 糖尿病每周一次）— NVO 真正起飞
- 2021-06 NVO Wegovy（sema 减重剂型）— 减重 12% 大幅领先利拉鲁肽
- 同时 LLY 推 Trulicity（dulaglutide GLP-1 单靶），但减重效果一般
- 2022 起减重 sema 供应短缺持续，NVO 估值 + 销售双上行

**第三代（2022-2025）：tirzepatide 时代（LLY 反超）**
- 2022-05 LLY Mounjaro（tirz GLP-1/GIP 双靶糖尿病）
- 2023-11 LLY Zepbound（tirz 减重）— SURMOUNT 减重 20.9% 首次突破 20%
- 2024-12 Zepbound 获 OSA 适应症（首批）—— 适应症外溢加速
- 2024-10 NVO 还是全球药企 #2（仅次 LLY）→ **2025-07 跌至 #5**（10 个月，mat-2bbc64 / mat-6ddfd9）
- 2025-11 LLY 成首个 $1T 医药公司
- 2025-12 NVO sema 阿尔茨海默 evoke 试验失败
- 2025-12 NVO oral Wegovy 减重批 + LLY 推动 orforglipron NDA

**第四代（2026-2030+）：next-gen + 第二梯队 + 中国出海（当前周期）**
- 2026-01 Roche CT-388 Phase 2 22.5% 同档 tirz（mat-6c585f）
- 2026-04 LLY orforglipron (Foundayo) 美国批 — 首个口服 GLP-1 减重小分子（mat-dc8a8e）
- 2026-05 NVO Wegovy 7.2mg STEP UP 20.7% EU CHMP 推荐（mat-606af8）
- 2026-2027 retatrutide TRIUMPH-3 / VK2735 VANQUISH-1/2 顶线读出窗口
- 中国国产化：mazdutide 2025-06 NMPA 首批（信达 + LLY 合作）+ HRS9531 Phase 3 阳性 + sema 仿制开闸（10+ 家申报）
