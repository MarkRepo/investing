### 反方 2：信达 Tier 1 重仓（20-25%）是 thesis 内部最大逻辑张力 — **强**

多方假设（S5+决策套件 Tier 1）：信达 2025 +38% 营收 / 首次盈利 / Non-IFRS +420% / 三个 BD → Tier 1 重仓候选。

反驳：
- 2025 +420% Non-IFRS 是低基数 + 一次性 BD 确认（武田 $1.2B + Roche $80M + 另一 $350M 同年入账）双重叠加，不可线性外推
- mazdutide 国内放量与 sema 仿制冲击正面冲突：
  - 中国 sema 减重剂型已先降 50%（¥1893→¥987）
  - 九源 JY29-2 NMPA 受理 2026-02-25，预计 2026 Q4 - 2027 Q1 上市
  - 华东、齐鲁、正大天晴、复星 10+ 国内药企申报 sema 仿制
  - sema 仿制 ¥500/月级放量 → mazdutide ¥1500+/月自费市场被同价段切走 → K4 阈值 mazdutide 2026 ≥¥15-20 亿很难达到
- sintilimab FDA 失败前科是结构性海外信誉折价，不是周期性
- HRS9531 / Kailera 是恒瑞资产，信达不直接受益（thesis P0 自承）但 Tier 1 仓位仍 20-25% — **仓位决策与风险声明矛盾**
- BD 现金流"常态化"假设（B1 盲点）：2025 三大单是研发管线集中爆发的一次性收成，2026 BD 大概率回落到 1 单

修补点：降信达至 Tier 1.5（10-15% 仓位）+ 拆分"业绩拐点（强）vs Tier 1 重仓（需 2026 H1 mazdutide 实际销售 ≥¥10 亿验证）"。

### 反方 3：第二梯队收购溢价 ≥3x 概率被高估 — **中等**

多方假设（O4+决策套件 VKTX 期权式）：Roche Carmot $2.7B + Big Pharma 需 GLP-1 暴露 → Viking 收购溢价 ≥3x ($30→$95+) 中等概率 30-40%。

反驳：
- Roche $2.7B 收购 Carmot 是 2024 Q4 的 reference — 当时 GLP-1 第二梯队估值乐观高峰
- 2026 Q2 后情景已变：BALANCE/IRA/MFN/中国仿制 四轨长期定价压制可见 + 第二梯队 Phase 3 失败概率 30-40%（thesis R7 自承）→ Big Pharma 收购热情 cooling
- VKTX 自有 100M 注射器 + 1B+ oral tablets 产能（mat-20420a）— Big Pharma 不会为产能溢价支付，反而成压制因素
- Viking 当前 ~$30 已 price in 70-80% Phase 3 成功率 + 50% 收购概率 — 下行不对称：Phase 3 成功但溢价 ≤2x → -47%
- 实质概率拆分：Phase 3 成功 60-70% × 被收购 50% × 溢价 ≥3x 50% = **15-22% 综合概率**（不是 thesis 的 30-40%）

支撑：mat-1f9505 / mat-ef091e / mat-20420a / mat-dfd8f0 / thesis R7

修补点：VKTX 期权式仓位 5% binary 的概率重估。

### 反方 4：oral GLP-1 替代注射 timing 被低估 — **中等强**

多方假设（S4+O5）：oral 减重幅度 8-12% << 注射 22.5% → 替代慢 → LLY tirz / NVO sema 注射主业 unit volume 2028+ 仍 +20-30%/年。

反驳：
- thesis O5 已承认"oral 四家同台" 但没量化替代 timing

- 一旦 oral 减重 ≥15% + 价格更低（generic-like）→ 注射 GLP-1"周注射 vs 每日口服"便利性溢价崩塌
- LLY orforglipron 商业化预测 ≥$3-5B/年到 2028 — 这个数字假设 oral 不切 tirz —— 逻辑矛盾
- 信达 IBI3042/IBI3032 + GPCR aleniglipron Phase 3 启 2026 H2 — **2027 H2 - 2028 H1 是 oral 第三梯队顶线集中读出窗口**
- 历史镜像：长效胰岛素 2010-2014 量价剪刀差正向 → 2015 起 biosimilar + 口服降糖药 → -10% YoY

支撑：mat-dc8a8e / mat-1f9505 / mat-0ed0b9 / mat-11a269 / mat-2bbc64
