# 历史镜像：GLP-1 减肥药的相关历史先例

> 通过对 3 个不同维度的历史先例分析，识别哪些机制在 GLP-1 周期里可能复现，哪些差异点会让历史不简单重演。

---

## 镜像 1：2014-2018 索菲布韦 (Sovaldi/Harvoni) — 政府压价

**情景**：
Gilead 2013-12 推 Sovaldi（HCV 治愈药）$84,000 全疗程（12 周）。短期商业化巨大成功（2014 全年销售 $10B+），但**美国 Medicaid 各州联手压价 + 国会传讯 Gilead 总裁 + 私营保险拒付** → 2015 起单价腰斩 → 2018 销售跌至 $3B/年。Gilead 股价 2015-2018 跌 50%+。

**类比 GLP-1 的相似点**：
- "高价 + 治愈效果"诱发**支付方政治压力**：HCV 治愈是一次性付费；GLP-1 是终身服药 → 政府长期成本意识更强（叙事 F 直接对应）
- BALANCE Model + IRA 第二批 + LLY-政府双边 Bridge Program 与 Sovaldi 时代的 "Medicaid 联合谈判 + 国会传讯" 有结构性相似

**类比的局限**：
- Sovaldi 是治愈性短疗程（12 周）→ 单笔销售；GLP-1 是终身服药 → 客户 LTV 高 + 替代成本高，定价博弈更复杂
- HCV 是 high-cost 罕见病；肥胖是大众慢病 → 政府收紧的政治意愿不同
- 2015-2018 时代美国保险体系更分散，未有 IRA 系统性谈判机制

**对 GLP-1 的启示**：
- 政府对单价的政治压力可能比卖方共识更高（叙事 F 风险）
- LLY/NVO **主动**把 list price 削成 DTC $299-449（mat-e84be3）和与政府签 MFN/BALANCE Bridge → "提前自降"是从 Sovaldi 教训学的
- IRA 第二批 sema $274 = list $959 降 71% 与 Sovaldi 单价腰斩同等量级

## 镜像 2：2015-2020 PCSK9 抑制剂 (Repatha/Praluent) — 商保拒付

**情景**：
Amgen 2015-07 推 Repatha（evolocumab）+ Sanofi 2015-07 推 Praluent（alirocumab），均为 PCSK9 抑制剂，预期颠覆血脂治疗市场。**临床有效**（LDL-C 降 60%+），但**商保严苛预先授权 + 严格患者条件 + 高出 statin 类 3-5 倍单价 → 实际销售远低于预期**。Amgen 2018 把 Repatha 单价从 $14,500/年砍到 $5,850/年（-60%）+ Sanofi 同步 → 销售爬坡才略恢复，但远低于"100 亿美元年销售"的卖方初期预测。

**类比 GLP-1 的相似点**：
- **临床效果显著但价格被支付方反噬**：商保看 cost-effectiveness 严格审核 GLP-1 减重药（mat-a070ec："US self-insured employers 必须 opt-in 才覆盖减肥药"）
- **预先授权流程**：很多商保要求患者先尝试 metformin / GLP-1 单靶 / 生活方式改变后才报销 GLP-1 减重 → 实际渗透率受限
- 2026 Q1 LLY 自承 Mounjaro net price 下行 — 与 Repatha 2018 自降价同款应对

**类比的局限**：
- PCSK9 是预防性药物（无症状降 LDL）→ 患者付费意愿低；GLP-1 减重有**明显主观体验改变**（体重 / 饮食 / 信心）→ 患者付费意愿高 + DTC 渠道覆盖广
- PCSK9 替代品多（statin 一线 / Repatha vs Praluent 同档）；GLP-1 减重唯一性强（vs 老减肥药 4-12% 减重）
- DTC 平台（LillyDirect / NovoCare / HIMS）让 GLP-1 部分跨过商保 — 这是 PCSK9 时代没有的渠道结构

**对 GLP-1 的启示**：
- 商保覆盖率不是 100% 自动，"opt-in 雇主 self-insured" 是结构性瓶颈
- DTC 渠道是 GLP-1 vs PCSK9 的关键 buffer
- 主动降价（DTC $299-449）是行业默认应对，不是失败信号 — 是商业化执行力的体现

## 镜像 3：1990s NVO 胰岛素霸权 → 2010s 长效胰岛素侵蚀

**情景**：
NVO 1990s 是全球胰岛素 #1（人胰岛素 + Mixtard 系列），2000-2010 推出长效胰岛素 Levemir 维持地位。但 2010s LLY 推 Humalog (lispro) + Sanofi 推 Lantus (glargine) → 长效胰岛素被 Sanofi 切走 ~30% 份额；2010s 末 LLY 推 Tradjenta + Trulicity (GLP-1 单靶) → NVO 在糖尿病多产品类被 LLY/Sanofi 三家分食。直到 sema 2017 起重新崛起。

**类比 GLP-1 的相似点**：
- **单产品依赖型增长在长周期里的脆弱性**：NVO 1990s 几乎完全依赖胰岛素 → 现在 NVO sema 占总营收 55%+ + GLP-1 类占 90%+（mat-5b9ef4）— 同一陷阱
- 2024-10 → 2025-07 NVO 全球 #2 → #5 跌幅 50%+ 与 1990s-2010s 胰岛素被多家瓜分的节奏类似
- Akero $4.7B 收购 + amycretin / oral Wegovy 是 NVO 学习多元化的尝试（vs 1990s 完全被动失份额）

**类比的局限**：
- 胰岛素是仿制品类成熟后被价格战吞噬；GLP-1 仍处新分子涌现期（reta / CT-388 / VK2735 / aleniglipron 还在 Phase 3）
- NVO 这次主动多元化（MASH / 阿尔茨海默 / 肿瘤 BD）反应比 1990s 当年快得多
- 政策环境差异：当年没有 IRA / BALANCE / DTC 机制，全球商保覆盖也不如现在系统

**对 GLP-1 的启示**：
- NVO 现在的状态比 1990s NVO 强（财务 healthy + 主动多元化 + amycretin/CagriSema 储备厚）—— 反方 2 (over-sold) 论据成立
- 单产品依赖型增长长期一定衰减，问题是衰减斜率和接力管线的兑现速度
- LLY 也在重蹈 NVO 1990s 的"集中度上升"路径（56% → 65% 一年内）—— 这是 LLY thesis 的远期风险锚

## 综合启示：哪些机制可能复现，哪些不会

**会复现的机制（GLP-1 周期里大概率发生）**：
1. **政府 + 支付方系统性压价**（Sovaldi 教训）— BALANCE Bridge / IRA / MFN 三轨已是新版
2. **商保严格审核降低实际渗透率**（PCSK9 教训）— US self-insured opt-in + 预先授权
3. **单产品依赖型增长的远期衰减**（NVO 1990s 教训）— LLY 业务集中度上升是 2028+ 风险

**不会简单重演的差异点**：
1. **DTC 平台机制**让 GLP-1 部分绕过商保 — Sovaldi/PCSK9 时代没有的结构
2. **临床代际跃迁速度更快**（reta / CT-388 / VK2735 在 2026-2027 集中读出）— 不像胰岛素 1990s-2010s 年级演化
3. **中国 + 印度 + 巴西 + 中东市场逐步开放** — 全球 TAM $100B+ 长期空间远超 HCV/PCSK9
4. **多适应症外溢**（CV / OSA / MASH / CKD）— 不是单一适应症故事
