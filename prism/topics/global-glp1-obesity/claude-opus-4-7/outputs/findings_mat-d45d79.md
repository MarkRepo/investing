## 核心数据点与事实

- HIMS 业务覆盖：sexual health / hair loss / hormone / **weight loss** / dermatology / mental health / 实验室检测
- 全球市场：**US + Canada + UK + EU 4 国（Germany / Ireland / France / Spain）** — 国际化 footprint 已具备
- **50M+ 历史 telehealth 累计** — 数字健康头部规模
- 业务模式：**订阅制为主**（30/60/90 至 360 天周期），自营全资药房，提供 generic + brand-name + **compounded medications** 三类（compounded 是 GLP-1 关键扩张品类）
- 2025 推出 testosterone / menopause / perimenopause / 实验室检测等新条线 — 多元化扩品类
- **omnichannel 营销**：社交媒体 + 搜索 + TV + 实体零售 + 物理品牌广告
