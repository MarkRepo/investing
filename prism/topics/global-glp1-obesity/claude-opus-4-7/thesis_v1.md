## 一、核心 thesis（强度 7/10）

**LLY > NVO > 信达，主仓 LLY、次仓 NVO 做 mean reversion，国产标的（mazdutide / HRS9531 出海）作"中国 GLP-1 国产化 + BD 回流"主题性配置但不重仓。** GLP-1 减肥药 2025-2030 仍是医药板块最大 structural alpha 来源，但 2026 已从 v0 描述的"定价/政策/竞争三杀"切到**「BALANCE 托管价 + IRA 谈判 + DTC 自费 + 国内仿制」四轨定价**——alpha 集中在 **临床代际领先 × 长专利期 × 自有产能 × 多渠道商业化执行力** 四件套，LLY 在四件套上系统性领先 NVO 与第二梯队。

**方向：看多但分化**——不是"all-in GLP-1"，而是 **集中买 LLY、警惕 PE 50x 在第二梯队竞争 + 政府托管价双因素下的估值收敛、回避 sema 仿制冲击直接暴露**。

## 二、支持理由（5 条）

1. **替尔泊肽临床数据全面碾压 + 适应症爆发**：SURMOUNT 72w 减重 20.9%（15mg）vs Wegovy 14.9%；SURMOUNT-1 三年随访 T2D 风险降 94%；心衰 MACE 降 38%；2024-12 OSA 首批；2025 SURMOUNT 系列扩展指征。CagriSema REDEFINE 1 20.4% < 替尔泊肽 15mg，REDEFINE 2 T2D 仅 13.7%——NVO 主力武器在临床直接比试中处于下风。`[mat-31e7e6][mat-ce4112]`

2. **专利护城河差距 5 年 + sema 仿制实际已开闸**：sema 加拿大 2026-01 / 印度 2026-03 / 巴西 2026-03 / 中国 2026-03-20 已到期；印度 40-50 个仿制药已上市；**中国 10 家国内药企已申报，九源 JY29-2 减重 2026-02-25 NMPA 受理**；中国 sema 价格已先降 50%。替尔泊肽美国 2036 / CN+IN 2034——再多 **10 年**护城河。`[mat-7edea3][mat-pharnexcloud-sema][mat-sina-jiuyuan]`

3. **管线代际接力但有竞争者**：LLY 储备 retatrutide（GLP-1/GIP/GCG 三靶 Phase 3）+ orforglipron 2026-04 已获批（口服 8% 减重）+ eloralintide（amylin）。NVO 储备 amycretin + oral CagriSema + 2025-12 oral Wegovy 减重已获批。**第二梯队实质入场**：Roche CT-388 Phase 2 减重 22.5%（同替尔泊肽档）Phase 3 2026 Q1 启动 + Viking VK2735 注射 Phase 3 已完成入组（VANQUISH-1/2）+ oral Phase 2 13w 减 12.2%。**LLY 一家独大叙事被压缩，但综合储备仍最厚**。`[mat-5804fb][mat-dc8a8e][mat-roche-ct388][mat-prnewswire-viking]`

4. **财务规模与估值反转明确**：LLY 2025 营收 **$65.18B** / 净利 $20.64B / 营业利润 $26.3B；Mounjaro+Zepbound 占 56% ≈ **$36.5B**；2025-11 成**首个 $1T** 医药公司。NVO 2024 营收 $42.1B (+25%) / 净利 $14.5B；2024-10 还是全球第二大药企，**2025-07 跌至第五**。两者完全反转。**但 LLY PE 约 50x 是高估值**，第二梯队竞争 + 政府托管价同时压价会触发"戴维斯双杀"。`[mat-2bbc64][mat-6ddfd9]`

5. **国产 GLP-1 出海格局成形**：信达 mazdutide 2025-06 NMPA 首批（首个国产 GLP-1 减重）+ 京东健康分销 + Lilly 共开发；信达 2024 营收 ¥9.42B 仍净亏 ¥94.63M。**恒瑞 HRS9531 中国 Phase 3 减重 17.7%，2024-10 授权 Hercules→Kailera Therapeutics（$600M 融资），恒瑞首付 $100M + 总里程碑 up to $5.925B + 版税，保留中国权益**——是中国创新药"真出海"标杆。华东医药利拉鲁肽 2 个月达 30% 国内份额验证国内执行力。`[mat-25971d][mat-5d9b4d][mat-biospace-hrs9531][mat-medcity-kailera][mat-21jingji-huadong]`

## 三、最大反方观点（4 条 — 较 v0 加 1 条）

1. **LLY 估值 + 多重新竞争 = 戴维斯双杀风险**（较 v0 加重）：PE ~50x，**Roche CT-388 22.5% 已同档**、**VK2735 oral 12.2% 13w**（vs orforglipron 40w 8%）、Amgen MariTide Phase 3 2027 读出；同时 **BALANCE Model $245/月 + IRA $274**（虽未含 tirzepatide 但 MFN 协议有传导风险）+ LillyDirect $299-449 DTC——LLY 单位营收四轨压制。**这是看多 LLY 最大尾部风险，比 v0 时认知更严峻**。`[mat-roche-ct388][mat-kff-balance][mat-fierce-ira]`

2. **NVO 反弹胜率显著高于看上去**（较 v0 增强）：NVO 2025-07 跌至全球第五，市场已 price in CagriSema 失望（实际 20.4% 不是失败而是"略低于预期"）+ 阿尔茨海默 evoke 失败 + sema 仿制开闸。**NVO 反向 catalyst**：amycretin（口服 GLP-1+amylin Phase 2 数据强）+ 2025-12 oral Wegovy 减重已获批 + NovoCare DTC $149-349 + 与 HIMS 2026-03 和解合作扩渠道。短期 0.5-1 年 NVO 估值修复胜率不低于 LLY 续涨。`[mat-2bbc64][mat-hims-ir]`

3. **GLP-1 终身服药生意的支付方收紧风险**：停药 1 年内体重反弹 50-70% → 终身服药 → 支付方"年复一年成本意识"。**BALANCE Model 把 sema/tirzepatide 价格压到 $245 实际证实了这个担忧**——政府"不想把这个变成长期 entitlement"。一旦商保跟进 BALANCE 价 → 单位营收再压一层。`[mat-524100][mat-kff-balance]`

4. **第二梯队收购改变估值锚**（NEW）：Viking 当前 ~$30 vs 目标 ~$95；Structure Therapeutics 同列收购候选；Roche $2.7B 收购 Carmot 已验证"低价买管线 = 大药企最优解"。**如果 LLY 不是收购方而是被对标方** → 第二梯队估值参考会让 LLY 50x PE 更难支撑。`[mat-fool-viking][mat-biospace-ct388]`

## 四、Killer Question（6 条 — 较 v0 加 K6 + 改 K3/K5）

- **K1 [下一代竞争代际]**：**retatrutide TRIUMPH-3 + Roche CT-388 ENITH-1/2 + VK2735 VANQUISH-1/2 三家 Phase 3 数据 2026-2027 谁先谁高**？
  - 阈值：retatrutide >25% + CV outcome 阳性 → LLY 一家独大叙事继续
  - 阈值：retatrutide ≤22.5%（仅平 tirzepatide 当前水平）→ LLY 下一代护城河存疑
  - 阈值：CT-388 ≥23% 且 Phase 3 数据先出 → Roche 抢位 → LLY/NVO 双弱

- **K2 [BALANCE Model 实际渗透 + 单位营收冲击]**（改 framing）：BALANCE Model 2026-2027 实际有多少 Medicare/Medicaid 受益人加入？$245/月对 NVO + LLY 实际单位营收冲击多少？
  - 阈值：BALANCE 覆盖 >1000 万 Medicare 受益人 + 商保跟价 → 利空
  - 阈值：BALANCE 覆盖 <300 万 + 商保不跟价 → 利好（量大于价压制）

- **K3 [sema 全球净价 2026-2028 衰减路径]**（改 framing — v0 只盯仿制时点，但仿制已开闸，问题是"价格衰减"）：sema 净价 2026 全球 / 美国 / 中国分渠道衰减斜率？NVO sema 总营收 2027 vs 2025 同比 ±多少？
  - 阈值：NVO sema 2027 营收 <2025 同期 →"仿制 + IRA + BALANCE 三重压制"已彻底兑现
  - 阈值：NVO sema 2027 营收 ≥2025 同期 →"DTC + 适应症扩展" 抵消价格压制

- **K4 [国产 GLP-1 出海 + 国内市占]**：HRS9531 全球 Phase 3 启动时间 + Kailera 商业化路径？mazdutide 2026 销售 ¥10-30 亿？华东医药 sema 仿制 2027 国内份额？
  - 阈值：HRS9531 美国 Phase 3 2026 Q3 前启动 → 恒瑞潜在 $5.7B 里程碑兑现路径打开
  - 阈值：mazdutide 2026 销售 ≥¥15 亿 → 国产 GLP-1 商业化曲线验证

- **K5 [三轨/四轨定价对 LLY 单位营收冲击]**（改 framing）：LLY 2026-2027 Mounjaro+Zepbound **单位 net price**（list - PBM rebate - DTC discount - BALANCE 渠道差）实际跌幅？unit volume 增长能否覆盖？
  - 阈值：unit volume +50% + unit net price -20% → 营收 +20% → 估值可承受
  - 阈值：unit volume +30% + unit net price -30% → 营收 -10% → 估值杀

- **K6 [第二梯队收购触发估值锚下移]**（NEW）：Viking / Structure / 其他 GLP-1 biotech 2026-2027 是否被 big pharma 收购？收购溢价倍数？
  - 阈值：Viking 被收购溢价 ≥3x（市值 $30 → 收购价 ≥$90）→ 二梯队估值上修但相对 LLY 50x 仍便宜 → LLY PE 收敛压力↑
  - 阈值：无收购 + 二梯队继续融资稀释 → LLY 一家独大溢价保留
