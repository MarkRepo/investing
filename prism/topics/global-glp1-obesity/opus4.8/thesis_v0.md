# thesis_v0 — 全球肥胖/GLP-1 减重药物行业

## 核心 thesis（分化看法 · 强度分化）

**利润池不会"雨露均沾",而是向两个 arena 集中——「口服小分子平权化」+「三激动/amylin 疗效天花板」——且这两条迁移路径都被 LLY 独占先手;NVO 的注射 sema 存量池被份额流失 + CagriSema 头对头失败 + 中国仿制先到期三面侵蚀而结构性缩水;国产双靶/sema 仿制/telehealth 分销是期权或价值陷阱,非耐久利润池。**

**方向**：超配「口服 + 三激动」两 arena（现实映射 ≈ LLY 独占）；低配「sema 注射存量池」（NVO）+「sema 仿制价格战」（国产类似药）。
**强度评分（分化）**：LLY 侧 **8/10** | NVO 侧 **3/10** | 行业总 beta 看多但被净价/政策压制，**6/10**。

> 终局映射（industry = 把注意力分给哪几个 arena，深挖/观察/淘汰三档）：
> - **深挖**：口服小分子（Foundayo/orforglipron 领跑）、三激动/amylin 高端（retatrutide 领跑）——两者现实入口高度收敛到 LLY。
> - **观察**：国产双靶 + BD 出海（信达 mazdutide / 恒瑞 HRS9531→Kailera）、挑战者 biotech 并购期权（VKTX/GPCR）、Amgen MariTide 差异化月针。
> - **淘汰/低配**：NVO sema 注射存量池、中国 sema 仿制价格战、telehealth 复方分销（HIMS）。

## 支持理由

1. **LLY 是唯一同时领先两条迁移路径的玩家**：口服（Foundayo 已获批、1H2026 上市）+ 三激动（retatrutide TRIUMPH-1 80周 28.3%、104周 30.3%）双牌在手；$1T 市值 + 2026 指引 $80-83B(+25%) + Zepbound Q1 美国 +79% 至 $4.1B 印证执行力。
2. **NVO 三面结构性受压**：份额流失（CagriSema 2026-02 头对头败于 Zepbound、股价 -15%）、2026 销售指引负增长(-5~-13%)、中国 sema 化合物专利 2026 先于美国到期引仿制——存量 sema 利润池缩水而非仅增速放缓。
3. **口服小分子是 TAM 从窄口扩到基层的唯一路径**：绕开注射依从性 + 冷链 + 多肽产能瓶颈，规模逻辑压过单价；利润池增量向有口服牌者集中，LLY 独占先手，GPCR(GSBR-1290)/VKTX 落后 ≥1 身位。
4. **疗效阶梯持续上移**：单靶→双靶→三激动/amylin，高端市场向 retatrutide/MariTide(22-30% 减重)/Roche CT-388(22.5%) 迁移；但 LLY 之外多为管线期权，兑现前不构成利润池。
5. **国产双靶是本土 + BD 出海期权但利润率天花板低**：信达 mazdutide 已获批 6 天闪电商业化(~¥1260/月)、恒瑞 HRS9531 III 期 19.2% 且 Kailera 2026-04 纳斯达克 IPO——出海模式跑通，但本土受医保谈判 + sema 仿制价格战压制，毛利结构低于美国注射针。

## 最大反方观点（非稻草人）

1. **「LLY 一家独大」可能被高估**：若 orforglipron 放量慢——口服减重 10.5% 显著弱于注射 tirzepatide 20%+，且保险/PBM 仍偏好已装机注射剂——则口服 arena 利润池 < 预期，LLY 的成长溢价(PE 30-40x)回吐。口服"平权化"是假设，不是既成事实。
2. **NVO 极度悲观已 price-in，做空拥挤**：NVO PE 已压到 ~15-20x，amycretin 后续读出或 Wegovy 份额触底反转都会是超预期；"结构性缩水"叙事一致、赔率不对称。
3. **净价/政策把整个利润池做小（beta 塌缩淹没 arena alpha）**：TrumpRx $245/月 + Medicare 覆盖扩张的代价是净价年降 + IRA 谈判 + 仿制提前，若绝对利润池远小于 $60-150B TAM 叙事，则所有玩家（含 LLY）估值需下修，arena 分化的 alpha 被行业 beta 塌缩淹没。

## 会改变看法的事件 / Killer Questions

- **K1（口服 arena 兑现）**：orforglipron/Foundayo 上市后首 12 个月放量斜率——TRx/收入是否兑现"口服平权化放量"，还是被现有注射装机 + 保险偏好限制在慢坡？→ 证伪则口服 arena 利润池 < 预期，深挖档降级。
- **K2（疗效 arena 安全性）**：retatrutide(TRIUMPH 全套) 与 MariTide III 期的安全性/依从性——三激动疗效天花板是否被 retatrutide 心率/胃肠道、MariTide 呕吐、高停药率抵消？→ 翻车则高端 arena 收窄。
- **K3（NVO 止血与否）**：amycretin 关键读出 + Wegovy 季度份额——NVO 是止血反转还是继续被 LLY 蚕食 + 仿制侵蚀？→ 反转则"sema 存量池缩水"证伪、低配 NVO 错。
- **K4（国产仿制节奏）**：中国 sema 仿制 2026-2027 实际获批 + 放量——是"申报堰塞湖"还是价格战真爆发？对国产双靶(信达/恒瑞)本土定价的挤压幅度？→ 锚定国产 arena 利润率天花板。
- **K5（净价 vs 放量）**：支付端净价路径——TrumpRx $245 + IRA 谈判价(Wegovy $385/月) + 商保覆盖，净价年降幅是否吞噬放量收入增长？→ 决定整个行业利润池的绝对大小（beta）。
