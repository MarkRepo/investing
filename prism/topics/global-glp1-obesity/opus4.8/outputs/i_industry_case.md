## 起点诊断：这行业的命门在哪

读完 49 份 findings，本行业的利润池迁移判断，命门收敛到三个张力（详见 `decomposition_v1`）：

1. **命门1｜口服的"疗效↔可及性"权衡**：口服放量押的是一个行为假设——足量增量患者为"免针/可及"接受更弱疗效（orforglipron 仅 10.5% vs 注射 20%+）。若真实市场"疗效为王"，口服只是补充入口而非利润池迁移目标。**这是主支柱，方向错则 thesis 塌。**
2. **命门2｜NVO 存量池衰减是"斜率"还是"断崖"**：低配 NVO 押的是"结构性缩水"，但存量装机有粘性，且悲观已被深度定价（trailing PE ~12x）。衰减的时点/幅度是低配 NVO 的赔率风险。
3. **命门3｜净价路径 = 利润池总闸**：利润池 = 放量 × 净价。政策 + 仿制同时压净价，TAM 已被下修 20% 到 $80B。若净价年降 > 放量增长，arena 分化的 alpha 被行业 beta 塌缩淹没。

case ① 只做"决策导向速写"，价值链/机理全景已在 primer。

## 环① 看懂这个行业：利润池此刻在哪、被什么驱动

### 价值链与利润池定位（一句话 + 决策相关段）

价值链：**原研药企 → API/CDMO（原料）→ 分销/PBM → 器械（注射笔）→ 患者**。**利润此刻高度集中在原研药企（制造端），且集中在双寡头礼来 + 诺和诺德手里**——2025 全球品牌肥胖市场按量翻倍，但利润没有雨露均沾 [mat-77d015]。

关键决策事实（背景见 primer §7，此处只留判断相关）：
- **利润池正在原研药企内部再分配**：礼来靠疗效（替尔泊肽 20.9%）+ 口服（orforglipron 已获批）+ 三靶（retatrutide 30%）三张牌，2025 抢走了诺和诺德在美国"肥胖 + 糖尿病处方量第一"的双料位置 [mat-77d015]；2026 指引二者"急剧分化"——礼来营收再跳增、诺和预警销售下滑 [mat-715f0d]。
- **分销/器械环节没吃到利润**：HIMS 转型证明分销商只能赚薄价差、被药企供货条款卡住（primer §5.3）；口服化还会削弱注射笔器械的议价 [mat-c489df]。
- **利润池的"流出方向"就是本篇要押的迁移路径**：从注射存量 → 口服（规模）+ 三靶/amylin（疗效）。

### 驱动因子 + 周期定位

- **主驱动 = 技术 S 曲线**（机制升级：单靶→三靶；剂型革命：注射→口服），叠加**政策**（覆盖扩张 vs 净价压制双向）+ **需求**（十几亿肥胖人口、渗透率极低——德国 BMI 记录仅 10.8% [mat-ade082]）。
- **周期位 = 早期成长，但进入"分化年"**：IQVIA 框定 2024 转型 / 2025 整合 / **2026 加速年**，三大"首次"同时发生：口服 GLP-1 首发、首个 GLP-1 类专利到期、肥胖首次进 Medicare formulary [mat-ade082]。技术 S 曲线在中段加速，但玩家开始分化。
- **本轮周期的"结束信号"**：不是需求见顶（渗透太低），而是 **① 净价崩塌超过放量增长（利润池被做小），或 ② 疗效阶梯撞副作用天花板 + 口服 generic 长期侵蚀（护城河瓦解）**。这两个信号进环⑤ kill。

### 相对水位

- **礼来 41.8x**：相对全球大药企历史中枢（~15-20x PE）处于**绝对高位**；相对自身历史也是成长溢价拉满区间。
- **诺和 ~12x trailing**：相对自身历史（曾 ~30x）处于**历史低位**，-29% YoY [mat-21a243]——已被 de-rate 到"困境股"档位。
- **恒瑞 44.9x / 信达 170x**：中国创新药高位（成长溢价）；**华东 15.5x** 低位（质地折价）。

### 叙事 + 资金流（钱在追谁）

- **主流叙事**：GLP-1 是十年一遇超级赛道，利润池向"口服平权化 + 疗效领先"迁移，礼来是定盘星。
- **钱在追**：礼来多头（口服/三靶兑现）+ 信达（国产双靶放量）**拥挤**；**冷落/做空**诺和（存量衰退）+ 仿制/分销。

### 隐含预期一句话 + 归类

**市场对这行业的定价 = "偏乐观"**：几乎把"口服平权化真放量 + 疗效阶梯持续兑现 + 净价压不垮利润"三个假设叠加的乐观情形，全押在礼来一家的 41.8x 溢价上；同时把诺和定价成"结构性衰退不可逆"。

### 🔑 定价锚 × 证据强度张力（与③缝合 · 命门环收口）

**市场定价笃定度最高（礼来 41.8x）的地方，恰恰踩在③里证据最弱的结构假设上**：
- 礼来 41.8x 的溢价 ⟸ 主要为 **WMBT1（口服平权化真放量）** 付费——但 orforglipron 自身减重仅 **10.5%**（弱于注射 20%+），口服放量斜率尚未被真实上市数据验证；
- 同时也为 **WMBT3（净价压不垮利润）** 付费——但 TAM 已被 Jefferies 下修 20% 到 $80B [mat-ee7fd6]，IRA/TrumpRx 净价压制是已兑现的下行。

**换句话说：定价最贵处（LLY 溢价）= 证据最薄处（口服疗效弱 + 净价总闸压制）。这正是本行业最大的"定价笃定度 > 证据强度"陷阱**——不是"礼来不好"，而是"41.8x 的价把两条最弱假设当既成事实定了进去"。这直接决定环⑥：好 arena（口服/三靶）但入口标的（LLY）已贵 → 深挖 arena 逻辑，但对入口设价格触发器、不追高。

## 环④ 我对这行业整体什么立场 + 利润池落到哪几个 arena（下注）

### 行业整体 stance（一句话）

**中性偏多（选择性看多）**：行业 beta 被净价压制 + TAM 下修拖累（总 beta **5-6/10**），但"利润池向少数 arena（口服规模 + 疗效高端）集中"的 alpha 清晰——问题是**这个 alpha 高度收敛到礼来一家**，且入口已贵。

### 我和共识的核心分歧（一句话）

- **共识押**："口服平权化 = 一个雨露均沾的新利润池，多家（LLY + 挑战者 + 国产）分享增量"；且把"疗效为王 vs 可及性为王"看成非此即彼的单选。
- **我押**：口服平权化**真放量，但主角高度收敛到礼来（规模领跑）**——因为口服的胜负手是"最快获批 + 最大规模铺货 + 装机渠道"，不是口服疗效（礼来 orforglipron 疗效反而弱）；**疗效高端 arena 也是礼来（retatrutide 独占天花板）**；挑战者（VKTX/GPCR/罗氏）多为**并购期权**而非独立耐久利润池；NVO 结构性受压但**已被定价**，低配的赔率不对称。
- **更细的分歧**：疗效（A 逻辑）锁高端高价利润、可及性/规模（B 逻辑）锁大众放量——**两条逻辑都被礼来一家占了先手**（primer §8.3）。所以本行业的真相不是"押 A 还是押 B"，而是"**利润池的两种逻辑都在向同一个玩家收敛**"，这才是被共识低估的结构。

各 arena 判断依据（挂回假设 + 证据）：
- **三激动/amylin 高端（4.1，深挖）**：retatrutide 独占疗效天花板（竞争 5——挑战者 MariTide 2027 且耐受性差 [mat-cf0f51]、CagriSema 败 [mat-54d41a]、罗氏 CT-388 22.5% 落后 [mat-c68134]、VKTX 皮下 14.7% [mat-b1dcfc]）。估值 2（锚在 LLY 41.8x 溢价）。**证据强度最高的深挖档**（WMBT2 中高）。
- **口服小分子平权化（4.0，深挖）**：口服放量最快（口服 Wegovy 65% 新处方）、TAM 最大（B 逻辑主战场）。竞争 4——礼来规模领先但疗效领跑者是 GPCR（-16.3% 无平台期 [mat-63a6fb]）/VKTX（口服 12.2% [mat-b1dcfc]），且长期有 generic 风险。**TAM 最大但证据强度略低于三靶（WMBT1 中，orforglipron 10.5% 疗效弱是软肋）**。
  > **口服 arena 的 moat 耐久性量化（补齐 moat 维 · 化解"深挖最脆 arena"的自相矛盾）**：口服小分子的 generic 悬崖是"**时点远、但一到就陡**"的双特征——① **时点**：化合物专利通常自申报起 ~20 年，orforglipron 由 Chugai 2018 发现授权 [mat-264d97]、GPCR aleniglipron 专利族到期 **2041-2045** [mat-124143]，即口服小分子的专利悬崖大概率落在 **2038 年之后**，**反而晚于多肽 sema 的美国 2032 [mat-77d015]**；② **陡度**：一旦到期，小分子走普通 generic（vs 多肽走 biosimilar），侵蚀更快更彻底（可参照普通化学药专利崖近乎断崖式降价）。**结论**：在本决策链的可执行时间轴（约 10 年内），口服 arena 的护城河由"最快获批 + 装机渠道 + 产能"支撑、耐久性充分；generic 自我摧毁是 **2038+ 的远尾风险**，不构成深挖档降级理由——但作为盲点风险纳入⑤长期监控。
- **注射 incretin 存量池（3.7，观察）**：当前利润池绝对主体（利润池 5），但增量正流出（增速 3——LLY 端强增/NVO 端负增）、净价压最狠、且面临被自身口服化替代。**是"守成"不是"迁移目标"**，故观察不深挖。
- **国产双靶 + BD 出海（3.3，观察）**：出海期权兑现是 alpha（恒瑞/Kailera $6B [mat-479a41]、信达首盈利 [mat-97c2bb]），但本土低毛利 + 估值高位（信达 170x/恒瑞 44.9x）。升档看 BD 规模化。
- **sema 仿制价格战（2.5，淘汰）**：价格腰斩 + 10+ 家内卷（竞争 1，完全竞争）[mat-7de0c1, mat-742120]，量迁移到"国产群体"但不迁移到"某一家"，无耐久利润——**价值陷阱**。
- **telehealth 复方分销（1.8，淘汰）**：compounding 窗口关闭、branded 低毛利中间商、利润被药企收回制造端 [mat-c489df]——**恰是 WMBT3 的反证：利润池没迁到分销**。

> **同档内 composite 排序说明（机器↔叙事一致性）**：深挖档内**三激动(4.1) > 口服(4.0)**，与叙事同向——三激动因 retatrutide 独占（竞争维 5）+ 近端证据更硬，composite 略高；口服 TAM 更大但受"疗效弱"拖累证据强度，composite 略低。两者均为深挖，无倒挂。

## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

### 已知风险 + 盲点风险

- **已知风险1（命门3/WMBT3）**：净价压缩 > 放量增长，行业 beta 塌缩淹没 arena alpha——TAM 从 $80B 进一步下修。
- **已知风险2（命门1/WMBT1）**：口服疗效弱（10.5%）导致放量斜率远慢于预期，口服 arena 利润池 < 预期，礼来 41.8x 成长溢价回吐。
- **盲点风险1**：**疗效阶梯纸面见顶**——retatrutide 30% 的最高剂量因 GCG 心率/肌肉/耐受性问题无法全剂量落地，"疗效领先"缩水。
- **盲点风险2**：**"礼来一家独大"本身成政治/反垄断靶子**——利润池过度集中，招致定价政策专门针对（IRA 下一轮把替尔泊肽纳入、或反垄断审视），alpha 被政策削平。
- **盲点风险3**：**口服 generic 长期自我摧毁**——口服小分子专利到期后走 generic 路径（悬崖比多肽陡，primer §6.1），利润池迁到口服后长期反而更脆。

### 行业级 kill 触发条件（尽量数据化）

1. **口服平权化证伪**：orforglipron/口服 Wegovy 上市后**首 12 个月 TRx 斜率显著低于同期注射装机**，或口服占新增处方份额掉头下行 → 深挖档「口服」降级。
2. **疗效+口服兑现证伪**：礼来 **2027 后营收增速跌破 15%** → 41.8x 溢价的核心假设破，行业定盘星 re-rate。
3. **总闸关小**：TAM 共识进一步下修到 **<$60B**，或 IRA 把替尔泊肽纳入谈判 → 行业 beta 塌缩，所有 arena alpha 被淹。

### ≥2 个历史行业镜鉴（热过但利润没兑现——只想成功案例本身是 red flag）

1. **PCSK9 降胆固醇药（Repatha/Praluent，2015）**：疗效硬（LDL 大降）、TAM 喊到 $100 亿+，但**保险 prior-authorization 卡处方 + PBM 压净价**，放量远低预期，长期峰值仅 $10-20 亿级，**缩水 ~80%**。最早预警信号：上市首年处方被保险 PA 拦截、毛净价差急拉。**"现在是否已现"：减重药同样面临保险 PA + 净价压（已现，见 mat-c9c6aa 净销售冲减翻倍）**。教训：**疗效硬 ≠ 放量硬，支付端才是总闸**（直击 WMBT3）。
2. **丙肝治愈药（Sovaldi/Harvoni，吉利德，2013-14）**：治愈率 >95%，Sovaldi 首年爆发 $100 亿+。但支付方限制用药人群 + 价格战，峰值后**断崖**：吉利德 HCV 收入从 2015 $190 亿跌到 2018 $40 亿，**缩水 ~80%**。最早预警：支付方限制治疗池 + 患者池耗尽。**"现在是否已现"：减重是慢病需长期用药（与丙肝相反，这点减重更抗跌），但"价格战 + 支付限制"已现**。教训：**超级重磅的绝对利润池可能远小于 TAM 叙事，且政策/支付会主动做小它**（直击 WMBT3 + TAM 下修）。
3. **胰岛素（百年老药）**：专利到期 + 生物类似药 + 政策定价（$35/月上限），从高利润变微利。教训：**多肽/生物药最终也逃不过政策定价 + biosimilar，只是时间差**——诺和 2032 专利悬崖虽平缓，但方向确定（直击 WMBT4/WMBT5）。

### signpost（未来 3-12 月验证/证伪事件）

- orforglipron 上市**首季 TRx**（2026 下半年）→ 验 WMBT1；
- retatrutide TRIUMPH 完整读出 + FDA 提交 → 验 WMBT2；
- VANQUISH-2（VKTX）顶线 2026 Q3 [mat-b1dcfc] → 验挑战者弹性；
- IRA sema 谈判价 2027-01 生效落地 → 验 WMBT3；
- 中国 sema 仿制**首个正式获批**时点 → 验 WMBT5；
- NVO amycretin 关键读出 → 验命门2（NVO 止血与否）。

## 环⑥ 资本/注意力怎么分配（行动 = 漏斗）

### 强制三档分流（tier = 吸引力 × 当前定价）

**深挖档（deep · 综合 ≥4）**
1. **三激动/amylin 高端疗效**（composite 4.1）——吸引力最高 + 证据最硬。但②判入口标的 LLY 41.8x 贵 → 深挖 arena 逻辑，对入口设价格触发器。
2. **口服小分子平权化**（composite 4.0）——TAM 最大、B 逻辑主战场。同样入口贵。

**观察档（watch · 综合 2-3 或有不确定性）**
3. **注射 incretin 存量池**（3.7）——最大池但增量流出、净价压最狠；盯 NVO 估值触底反转（命门2）。
4. **国产双靶 + BD 出海**（3.3）——出海期权 alpha，但本土低毛利 + 估值高位；盯 BD 规模化。

**淘汰档（eliminated · 综合 ≤2 或硬伤）**
5. **sema 仿制价格战**（2.5）——完全竞争无耐久利润，价值陷阱。复活条件：某家拿到首仿独占期 + 避开集采降价。
6. **telehealth 复方分销**（1.8）——利润被药企收回制造端。复活条件：药企主动让出分销利润 / 出现新监管套利窗口。

### tier 锚回②的定价（不是只按好坏排）

深挖档两个 arena 吸引力最高（4.0/4.1），但②判**现实入口标的礼来已贵（41.8x 历史高位）**——所以 tier 不等于"立刻重仓 LLY"，而是：**深挖 arena 迁移逻辑 + 对入口标的设价格触发器（回调至 forward PE <28x 或口服 TRx 首季验证再加仓）**。这是"好 arena 但②判贵 → 进深挖但带价格纪律"的落地。

### 注意力预算（深挖档 ≤2，为什么这几个优先）

**深挖档限 2 个（口服 + 三靶），因为两者的现实入口高度收敛到礼来一家**。资源有限下，注意力的实际分配是：
- **主线**：深挖"礼来的口服（orforglipron）+ 三靶（retatrutide）兑现斜率"——这是两个深挖 arena 的共同入口，一份深挖覆盖两个 arena 的核心变量。
- **对冲入口**：跟踪能**独立捕获该迁移**的纯标的（VKTX/GPCR 口服疗效领跑者、信达国产双靶）——作为"礼来过贵"时的替代入口 + 并购期权。
- **不深挖**：注射存量（守成）、国产仿制/分销（无耐久利润）——只监控。
