# Cagrilintide/Semaglutide (CagriSema) Overview

## Trial Results
REDEFINE 1 (68 weeks, 3,417 participants):
- CagriSema: 20.4% weight loss
- Cagrilintide alone: 11.5%
- Semaglutide alone: 14.9%
- Placebo: 3.0%

REDEFINE 2 (68 weeks, 1,206 participants with type 2 diabetes):
- CagriSema: 13.7% weight loss
- Placebo: 3.1%
（T2D 患者减重幅度显著低于非糖尿病——糖尿病减重难度本就高）

## Comparison to Tirzepatide
Phase 2 试验 CagriSema 32 周减 15.6%，与替尔泊肽 "comparable in efficacy"。
但 Phase 3 20.4% 仍低于替尔泊肽 15mg 22.5%——这是 2024-12 NVO 股价暴跌主因。

## Development Timeline
Phase 3 试验 2023 启动，结果 2025-06 发表。
