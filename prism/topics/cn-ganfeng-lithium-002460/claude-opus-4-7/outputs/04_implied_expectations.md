## 五、关键估值模型 sensitivity

### 模型 A：周期反转 base case
- 假设 2027 锂价回到 10-12 万元/吨 + 销量 30 万吨 LCE → 主业归母 35-40 亿元 → PE 20x → 市值 700-800 亿元（+15-25% 当前）

### 模型 B：半固态期权兑现 base case
- 假设 2028 半固态独立产能 5-10 GWh + ASP 0.5 元/Wh + 净利率 8% → 半固态贡献 2-4 亿元利润 → DCF 折现到 2026 估值贡献 ~50-100 亿元市值（+8-15%）

### 模型 C：上游卡位独家溢价
- 假设硫化锂 2027 商业化 + 售价 5,000-8,000 元/kg + 销量 100-500 吨 → 上游卡位贡献 1-3 亿元利润 → 给 30-50x PE → 估值贡献 50-150 亿元市值（+8-25%）

### 模型 D：组合（A + B + C 部分兑现）
- 三层 narrative 各兑现 50% → 估值上修 +25-40%（对应 A 股 PB 上修到 2.5-2.8x）

### 模型 E：bear case
- 锂价二次探底 + 半固态 narrative 塌缩 + 海外法律风险显现 → PB 下修到 1.0-1.2x → 估值下修 -30-40%
