# thesis_v0 — GLP-1 三激动/amylin 高端疗效 arena

> **Changelog（相对继承 stub）**：继承 stub 以父行业薄知识押"LLY 独占天花板、挑战者为并购期权，强度 7/10"。本版经 00-prescan 校准（26 份 web-search，10/10 命中）：**retatrutide TRIUMPH-1 天花板已于 2026-05-21 实证兑现（30.3%@104wk）**——赌注从"押注"升级为"实证"，强度 **7→8/10**；同时把 GCG 安全窗（停药率 11.3% + dysesthesia）与高端定价压制两项下压因子写实。

## 核心 thesis（arena 视角 · ≤120 字）

高端疗效利润池（减重 22-30% 档）由 **LLY retatrutide（三激动）独占天花板已实证**（TRIUMPH-1 104wk 30.3%、45.3% 患者 ≥30%，达手术级 [mat]）；挑战者集体落后 1-2 身位——CagriSema 20.4% 败、MariTide ~20% 且耐受性差、罗氏/VKTX Phase 3 未读出。押 **"疗效领先权稳固在 LLY，shortlist = LLY(核心) > VKTX(疗效期权/并购期权) > NVO amycretin(反击变量)"，挑战者多为并购期权而非独立利润池**。**强度 8/10**。

## 支持理由

1. **天花板已从预期变实证**：retatrutide TRIUMPH-1 80wk 28.3% / 104wk 30.3%，45.3% 患者达 ≥30% 减重，匹配减重手术级——三靶（GCGR 能量消耗放大器）机理带来的疗效代差被 Phase 3 实证，且**30% 未因副作用缩水**（最高剂量仍达标）。
2. **挑战者代差未收窄**：CagriSema REDEFINE 20.4% 且头对头败于 Zepbound；MariTide Phase 2 52wk 仅 ~20% + 高呕吐/停药（III 期被迫改滴定、推迟至 ~2027）；罗氏 CT-388 落后、VKTX VANQUISH-2 顶线未读出。无一在疗效+耐受性双轴上逼平 retatrutide。
3. **amylin 路线是"减重质量"新轴而非疗效反超**：CagriSema/amycretin/petrelintide 主打瘦体重保护，是差异化维度而非天花板挑战——NVO amycretin 是最实的反击（已进 Phase III），但目标是追平而非超越。

## 反方观点

1. **GCG 安全窗可能封顶商业剂量**：TRIUMPH-1 最高剂量停药率 11.3% + dysesthesia（感觉异常）新型不良反应——若真实世界耐受性差于试验，可用剂量下移则"30% 疗效"在处方端缩水，疗效独占在临床≠在商业。
2. **疗效已近生理上限，差异化战场转移**：30% 逼近减重手术，边际疗效递减；竞争维度可能从"减重%"转向给药频率（MariTide 月频）/口服（VKTX/orforglipron）/减重质量（amylin），LLY 的疗效独占护城河边际价值下降。
3. **高端定价在净价压制下不可持续**：IRA 第二批已纳入 sema、TrumpRx/Medicare 覆盖收紧——高端疗效药能否守住高净价维持利润率存疑；疗效赢家 ≠ 利润赢家。
4. **入口标的已贵**：LLY forward PE 高位（父级记 41.8x），疗效兑现可能已 price-in；VKTX 并购期权价值依赖顶线读出，binary 风险大。
