# thesis_v2 — GLP-1 三激动/amylin 高端疗效 arena（05-critic round-2 复评后的结论层修正）

## § 0. v1 → v2 changelog（仅 review 用）

- **触发**：05-critic round-2 复评。独立反方（不喂上轮 critic 报告）**二次复现同一致命一击**——"LLY 核心多头@42x 仍编码被 PCSK9/胰岛素证伪的『疗效→耐久利润』命题，v1 拆 35%/20% 权重只改标签未改可执行结论（化妆）"。
- **最大结论移动（本版核心）**：组合结构从 **"LLY 核心 + VKTX 期权 + NVO 观察/对冲"** 改为 **"LLY / NVO 跨命门3两结局杠铃双核 + VKTX 小仓期权"**。逻辑：case 自判"命门3（净价→利润转化）先崩"是**最高概率死因**，而该情景的赢家正是 NVO（低成本走量 + 已让净价换覆盖 + 下行大部已定价）——把最高概率死因情景的赢家压到"观察/小对冲"，与自身概率权重相反。**不确定性应对称配置，而非单边押"命门3守住"。**
- **LLY 留核心的理由重写**：从"疗效独占"换成 **"两层通吃"**——LLY 自家 **orforglipron 是领先的『够用口服』**，若高端池被口服商品化（KILL-D 情景），LLY **也吃到**那一层。这才是 LLY 能留核心多头的诚实理由（内在对冲），直接拆解反方"单一赌注"指控；而非"疗效必然变现"。
- **NVO：观察/对冲 → 深研（shortlist）杠铃腿**。不再一笔"半步妥协"。
- **KILL-D 补硬阈值**（v1 全定性 → 可监测止损）。
- **估值锚刷新**：LLY TTM PE 40.7x→**42.44x**、PB 32.8x→**34.17x**（2026-07-27，5 天内更贵）；forward 仍 ~30x。介入区据此上抬/收紧。
- **强度**：arena 总 **7/10** 维持——杠铃不改赛道基本面强度，但**显著改善组合的鲁棒性**（跨命门3两结局都有赢家腿），降低"押错命门3方向"的单边风险。

## § 1. 核心 thesis（当前完整版）

**高端疗效池（22-30% 档）的疗效天花板由 LLY retatrutide 独占已实证（TRIUMPH 80wk 28.3%、45.3%≥30%），但"疗效独占 → 耐久利润独占"隔着三道折价，其中最狠的净价压制（Medicare $245 + MFN 新药条款 + PCSK9/胰岛素镜鉴）让"命门3（疗效→利润转化）先崩"成为本 arena 最高概率的死因。既然如此，正确的下注不是单边押"命门3守住"重仓 LLY，而是跨命门3两种结局做杠铃——命门3 守住 → LLY 疗效溢价耐久（赢）；命门3 崩/池子商品化 → NVO（低成本走量、下行已定价、amycretin 免费疗效期权）赢，且 LLY 靠自家 orforglipron『够用口服』也吃到商品层。故 LLY / NVO 双核（不对称权重、跨结局对冲），VKTX 为小仓 binary/M&A 期权。**

- **方向**：
  - **LLY = 杠铃"命门3守住"腿 + 两层通吃的核心锚**：疗效领先权最稳（幅度独占）+ orforglipron 内在对冲商品化情景。但 42x TTM/30x forward 已 price-in 疗效 → **当前非介入区**，等回调/等命门3 实证再分批建；bear（命门3崩纯净价路径、EPS 下修）真实下行 -40~50%（向行业 18x 收敛）。
  - **NVO = 杠铃"命门3崩"腿 + 深度价值 + amycretin 期权**：11.5x/ROIC 42.8%/-56%，下行大部已定价；商品化情景赢家模型；amycretin 24.3% no-plateau 是近乎免费的疗效再入场。**小-中核心仓可现在起**（对冲 LLY 命门3暴露），满仓催化剂 = amycretin Ph3 H2H "疗效≥24% 且耐受不劣"。
  - **VKTX = 小仓 binary/M&A 期权**：口服非独家、零营收、2027 VANQUISH binary、增发几乎确定、买家池薄 → 纯期权小仓，顶线 miss 归零。
  - **观察 AMGN（月频差异化）；淘汰 Roche/Zealand。**
- **强度评分**：**arena 总 7/10**。LLY 疗效领先权 8/10、命门3守住确定性 6/10；NVO 深度价值+对冲赔率 7/10（下行已定价）；VKTX 期权高赔率但 binary。
- **估值带**：LLY TTM **42.44x**/forward ~30x（行业 18.45x，当前非介入区，回调 + 命门3 实证再建）；NVO forward 11.5x（**不再是"价值陷阱"——是杠铃对冲腿的合理起点**，下行已定价）；VKTX $4.18B 零营收（PB 8.31x 管线期权）。
- **时间维度**：命门1 看 reta FDA 提交 + 完整 TRIUMPH 安全性谱；命门2 看 VANQUISH-1 顶线 + amycretin Ph3 H2H；命门3 看 IRA 下轮是否纳入 tirzepatide + MFN 新药执行 + **orforglipron/够用口服品的上市净价与放量斜率（KILL-D）**。

## § 2. 支持理由（当前完整清单）

1. **疗效天花板已从预期变实证**：retatrutide 80wk 28.3%、45.3% 患者 ≥30%（近减重手术级），三靶 GCGR 能量消耗机理带来的疗效代差被 Ph3 实证 [mat-6bd7d7, mat-6f71bc]。
2. **LLY 两层通吃（本版新增·LLY 留核心的真理由）**：不只握金标准 tirzepatide + 天花板 retatrutide，还握 **orforglipron（领先的『够用口服』）**——高端池若被口服商品化（本 case 最担心的 KILL-D 情景），LLY 在商品层**也是主要赢家**。这使 LLY 并非"疗效→利润"的单一赌注，而是对命门3两结局都有暴露的玩家。财务碾压（营收 $65.2B、GM 83%、3Y ROIC 27.2%）。
3. **NVO 是命门3崩情景的赢家模型（本版升级·杠铃对冲腿）**：按胰岛素镜鉴，净价被压平时，低成本 + 走量 + 已让净价换覆盖的疗效领先者才是走量赢家——NVO 正是。ROIC 42.8%（全场最高）、GM 81%、D/E 0.67（最干净）、11.5x、已跌 56%（下行大部已定价）。amycretin 24.3% no-plateau 是近乎免费的疗效再入场期权、直接反证 WMBT-2。
4. **挑战者集体单轴掉队（截至 2026-07）**：CagriSema 20.4% 且 H2H 败 Zepbound [父 mat-54d41a]；MariTide ~20% + 高呕吐/停药、Ph3 改滴定推迟 2027 [父 mat-cf0f51]；Roche CT-388 落后未充分读出 [父 mat-c68134]。无一在疗效+耐受双轴同时逼平 reta（利于 reta 疗效独占 + NVO 减重质量差异化并存）。
5. **需求端放量逻辑成立**：Medicare 首次覆盖肥胖 + 患者自付封顶 $50/月 → 价格不敏感、利于走量弥补压价 [mat-8edc63]（对 NVO 走量腿尤其正向）。

## § 3. 反方观点（当前完整清单 · 含 critic round-2 强反驳）

1. **命门 3（最狠）——疗效领先 ≠ 利润领先，且是最高概率死因**：净价被腰斩到 $245、MFN "所有新药保证 MFN 价"、tirzepatide 净价折让反更大（79% vs sema 41%）、健康节省 $18.2B << 药费 $65.9B [mat-f91712, mat-c4b77e]；PCSK9 前车（疗效碾压却被降价 2/3 仍嫌贵、压回窄人群 [mat-61df5e]）。**本版据此把 NVO 升为杠铃腿——因为若这条崩，NVO 赢、LLY 靠 orforglipron 部分对冲。**
2. **命门 2——挑战者疗效轴逼近超预期**：amycretin 皮下 24.3% 36wk 无平台 [mat-053d60, mat-d59bb4]；VK2735 口服 12.2% [mat-d49f82]。reta 疗效独占权在变窄。
3. **命门 1——GCG 安全窗可能封顶商业剂量**：12mg dysesthesia 20.9% 剂量依赖，真实世界耐受若差于试验 → 商业剂量下移 → 30% 在处方端缩水 [mat-6f71bc]。
4. **战场转移风险（KILL-D 核心）**：竞争维度加速从"疗效幅度"转向减重质量 [mat-e3fe45]/口服/月频——某"够用 20-24% + 更便宜/口服"品无需击败 reta 即以低净价放量商品化高端池，reta 幅度独占贬值。**这正是本版把 NVO 升腿 + 给 KILL-D 补硬阈值的理由。**
5. **入口贵（本版硬化）**：LLY TTM **42.44x**（比 v1 写作时 40.7x 更贵）/forward ~30x，已 price-in 疗效兑现，市场为 WMBT-3 隐性买单 → **当前非介入区，bear 真实下行 -40~50%**；VKTX 价值压在 2027 binary + 增发稀释（现金 $603M 对两项 78wk Ph3 偏紧 [mat-732553]）→ 仅小仓期权。
6. **[critic round-2 已应答] 组合曾是"单一赌注"**：v1 把最高概率死因（命门3崩）情景的赢家 NVO 压到观察档、以最暴露该风险的 LLY 为唯一核心多头 = 与自身概率权重相反。**本版通过 LLY/NVO 跨结局杠铃 + LLY orforglipron 两层通吃应答——组合不再单押"疗效变现"。**

## § 8. 思维过程留痕

- **已知**：疗效阶梯/GCG/amylin 机理、玩家读出阶段、净价框架、PCSK9 镜鉴均已实证；LLY 疗效领先权是最硬事实；NVO 财务质量（ROIC/D-E）实为全场最优。
- **刻意避开的偏见**：① 疗效独占叙事偏差——不把"reta 天花板"外推为"LLY 利润独占"，命门3 显式拆开；② 只找成功案例的 red flag——环⑤强制用 PCSK9/胰岛素失败镜鉴；③ **本版新增·诊断-行动一致性**：既判命门3崩是最高概率死因，就必须让该情景的赢家（NVO）进核心，而非单边押守住——这是 round-2 critic 抓到的"化妆"病根，本版用杠铃结构纠正；④ **反方过度点的抵抗**：critic 反方称"财务质量与入场券共线、55%都奖励在位者"不精确（NVO 纯财务反胜 LLY），故本版不因反方全盘否定 LLY，而是保留 LLY 核心地位但换真理由（orforglipron 两层通吃）。
- **关键差异（我 vs 共识）**：共识把 LLY 当"已兑现的利润赢家"付 42x；我认为 arena 最高概率是命门3崩（净价压制），故做跨结局杠铃——命门3守住 LLY 赢、崩则 NVO 赢 + LLY 靠 orforglipron 部分兜，而非单边追高已定价的疗效赢家。
