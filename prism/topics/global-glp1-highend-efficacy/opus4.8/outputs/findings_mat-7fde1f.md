## 核心数据点与事实（PCSK9 镜鉴：成本效益争议）

- 明确结论：PCSK9 抑制剂"不如他汀被广泛使用，因为其成本"（cost 是放量核心障碍）——疗效革命性但商业受阻。★arena-mirror
- 各国成本效益（每患者成本 / QALY，2021-2023）：
  - 德国 evolocumab EUR 62,722 / 0.55 QALY；alirocumab EUR 87,002 / 0.87。
  - 英国 evolocumab GBP 45,279 / 0.53；alirocumab GBP 46,375 / 0.86。
  - 加拿大 evolocumab CAD 66,453 / 1.00；西班牙 evolocumab EUR 289,677 / 1.00。
  - 沙特 evolocumab $60,708 / 1.00；俄罗斯 3.6M RUB / 1.00。
- **英国 NHS 支付意愿阈值 = GBP 30,000/QALY**；PCSK9i 约 GBP 45,000/患者，超阈值→"不具成本效益"。
- 早期分析"一致认为"PCSK9i 不具成本效益，从发达国家到发展中国家皆然。
- 价格下调（引用未量化）：Regeneron/Sanofi 下调列表价，跟随 Amgen 早前动作——印证被迫降价模式。
- 正向异类：瑞典认定 PCSK9i 对极高危二级预防（联合治疗）具成本效益——存在细分适应症的窄放量空间。
- 已获批：3 个单抗（Evolocumab、Alirocumab、Tafolecimab）+1 个 siRNA（Inclisiran）；LOF 变异者终生 CV/CHD 风险低 88%（疗效上限锚）。

## 叙事主线（★环⑤历史镜鉴）

因为 PCSK9 抑制剂疗效革命性（LOF 者 CV 风险低 88%）但各国成本效益普遍超阈值（英国 GBP45K vs 阈值 GBP30K）→ 支付方"一致"判定不具成本效益、厂商被迫降价、临床只在极高危窄人群（如瑞典二级预防）站稳 → 教训：**革命性疗效被"成本效益阈值 + 覆盖窄化"双重压制，最终沦为窄适应症用药而非全人群重磅；GLP-1 高端疗效池须警惕同样从"全民重磅"被压回"高危/难治窄人群"的降级路径。**

## 反常识分歧点

- 反常识点：疗效越强（88% 风险下降）越易被拿来对标高价，但成本效益是相对他汀（平价老药）算的增量——高端疗效的边际价值被平价基准稀释，这是"疗效领先反被成本效益逻辑反噬"的机制。
- 与 GLP-1 映射：GLP-1 的平价基准正在形成（generic/口服/MFN 价），高端三激动的增量疗效同样会被"相对基准的增量成本效益"审视。
