## 环 ① 看懂这个赛道（理解闸门）

> 背景（机理阶梯/玩家名册/净价链条）详见 `00_primer`。这里只点**直接驱动选股的三条张力**。

**这块高端利润从哪来、谁卡在哪段**：高端疗效池 = 减重药阶梯最顶端的 22-30% 档。利润来自**在同一适应症里做出别人做不出的疗效差异**，从而在放量竞争中拿溢价份额。价值链上，卡位最硬的是**同时握有已上市金标准（tirzepatide）+ 天花板管线（retatrutide）的礼来**——它既收着当下的钱，又占着下一代的天花板。挑战者卡在"单一在研资产 + 未读出"这一段（VKTX/Roche）或"整体承压、靠新分子反击"这一段（NVO）。

**路线之争（是什么，不判胜负——判胜负归 ④）**：三条路线并存——① 三靶（GCGR 加能量消耗，reta，冲幅度天花板）；② 双靶（GLP-1/GIP，tirzepatide/VK2735/CT-388，成熟且可做口服）；③ amylin 组合（CagriSema/amycretin/petrelintide，冲减重质量/保瘦体重）。**关键：这不是单轴赛道**——"减多少（幅度）"和"减得好不好、停药反不反弹（质量）"是两根轴，决定高端池可能**分层**而非赢家通吃 [mat-3cb00b, mat-e3fe45]。

**客户结构 + 赛道周期位**：终端付费方在美国是 Medicare/PBM/雇主（净价被政府总闸压制，见 ②③），患者端自付极低（$50/月 [mat-8edc63]）→ 需求端价格不敏感、利于走量。周期位 = **中段加速 + 顶部分化**：整体减重药仍高速放量（全球 $66B→2033E $185B [mat-61becc]），但高端这一格已进入"疗效逼近生理上限、竞争维度转向剂型/质量/净价"的分化期。

> **闸门判定：看得懂。** 高端池是"疗效差异 → 溢价份额"的生意，但溢价能否兑现受净价总闸约束——这把 ①②③ 缝在一起。

- **当前介入吸引力**（现价风险调整后该不该现在买）：**NVO 4.0 > VKTX 3.0 > LLY 2.5**。**倒过来了**——LLY 42x 非介入区（好公司错价格）、NVO 11.5x 下行已定价（当前最优介入）。
- **两列拆开就解决了反方的"NVO<LLY 别扭"**：NVO 业务质量确实略低于 LLY（存量承压），但**当前该买的是 NVO 不是 LLY**。杠铃的当前主力多头 = NVO；LLY 是"等回调的守住腿"。

> ⚠️ **两列各自排序（dashboard 必读）**：业务质量 **LLY 4.5 > NVO 4.0 > VKTX 3.5 > AMGN 2.5 > Roche 2**；当前介入吸引力 **NVO 4.0 > VKTX 3.0 > LLY 2.5**。**别把"LLY 质量最高"误读成"现在重仓 LLY"**——当前可执行主力多头是 NVO，LLY 非介入等回调。这一拆同时收口 round-3 反方两点：①"分数偏袒 LLY"（其实是质量分vs介入分没拆）②"orforglipron 撑 4.5"（orforglipron 只进业务质量的"崩情景不归零"、**不进估值辩护**）。

**每家一句话 thesis（挂回 WMBT + K# 校准）**：
- **LLY（杠铃"命门3守住"腿 · 业务质量最强但当前非介入）**：入场券满格（WMBT-1/2 强支持）+ 财务碾压（ROIC 27/GM 83）+ 双路径收敛 = **业务质量分 4.5 当之无愧**。**关于 orforglipron（round-3 收口·修正 v2 的过度声称）**：它是 LLY 在命门3崩情景的**盈利/份额下限**（不被挤出局），但**护不住 42x 倍数**——商品层低毛利走量，高端溢价一塌倍数就向 18x 压缩（自我蚕食甚至加速）。故 orforglipron **不作 LLY 高估值的辩护**，反而**印证"42x 非介入、bear −40~50%"**。**当前介入吸引力低（2.5）**：好公司、错价格，非介入区、等回调+命门3实证再建（见 ⑥）。**K# 校准：K1/K2 强支持、K3 靠 orforglipron 保盈利（非保倍数）。**
- **NVO（杠铃"命门3崩"腿 · 当前介入吸引力最高）**：命门3崩（本 case 自判最高概率死因）情景的**相对赢家/最抗跌模型**（低成本基数+走量弥补），**但非免疫**——自家 $44B 高价 sema 存量同受净价压制，故是"相对赢/少亏"不是干净赢。① amycretin 24.3% no-plateau 已够到入场券、反证 WMBT-2，**但下行对称提示：CagriSema 已 H2H 败 Zepbound，amycretin 同类，Ph3 H2H 有重蹈风险，"近乎免费期权"是乐观读**；② 11.53x + ROIC 42.8%（全场最高）+ D/E 0.67 + 已跌 56% = 下行大部已定价。**当前介入吸引力最高（4.0），小-中核心仓可现在起（对冲 LLY 命门3暴露）**，满仓催化剂 = amycretin Ph3 H2H"疗效≥24% 且耐受不劣"。**K# 校准：K2 反击 + K3 崩情景相对赢 + K4 深度价值（下行已定价）。**
- **VKTX（小仓 binary 期权·与命门3正交）**：口服 + amylin 第二腿 + 疗效执行到位，但**口服非独家**（orforglipron 侵蚀"稀缺"叙事）、**零营收 + 2027 VANQUISH binary + 增发几乎确定（$603M 对两项 78wk Ph3 偏紧 [mat-732553]）+ 被并购买家池薄（LLY/NVO 自有更强口服双靶）** → **纯 binary 催化剂/M&A 期权、不占杠铃腿逻辑**，小仓。**K# 校准：K2 支持但 K4(binary/稀释)高风险。**

## 环 ⑤ 如果错了会怎样、怎么第一时间知道【证伪机制】

**已知风险 + 盲点风险**：
- **已知风险 R1**：净价压制超预期（IRA 下一轮纳入 tirzepatide、MFN 全面执行），高端溢价塌缩 → 整个 arena 的超额利润被做小（命门 3）。
- **盲点风险 R2**：竞争维度**加速**从"疗效幅度"转向"减重质量/口服/月频"——若 amylin 派的"保瘦体重→抗复胖"被大样本 + 支付方认可，reta 的 30% 幅度独占**贬值**，高端池分层而 LLY 只占其中一层 [mat-e3fe45, mat-3cb00b]。这是最容易被"reta 天花板独占"叙事挡住的盲点。

**arena 级 KILL 触发条件（尽量数据化）**：
- **KILL-A（路线被颠覆）**：某挑战者 Ph3 头对头读出"减重 ≥25% 且停药率/dysesthesia 显著优于 reta 最高剂量" → reta 双轴独占被打破，LLY 疗效溢价重估。
- **KILL-B（共识赢家失速）**：retatrutide 完整 TRIUMPH 项目群 or 真实世界出现"最高剂量因安全性无法落地、商业剂量下移致减重 <24%" → 命门 1 坍塌，LLY 30x 无支撑。
- **KILL-C（净价改写格局）**：高端疗效新品上市即被打到与存量双靶净价价差 <15% → 命门 3 坐实，"疗效赢家 ≠ 利润赢家"，arena alpha 塌缩为行业 beta。
- **KILL-D（商品化：够用即够，不必击败 reta）★05-critic 补**：**这是把上面盲点风险 R2 武装成可监测开关**——最可能让本 thesis 翻车的不是"某挑战者击败 reta"（KILL-A 门槛过高、易留后门），而是**某"够用"档挑战者（减重 20-24% + 显著更便宜/口服/月频）以低净价大规模放量抢占份额，无需击败 reta，就把高端池商品化**。触发即：疗效幅度不再是定价锚、reta 30% 独占贬值为"更贵一点点的选项"，LLY 30x 无支撑、arena 超额利润塌缩为行业 beta。**数据化触发信号（硬阈值·任两条同时命中即 KILL-D 触发）**：
- **① 净价断层**：某"够用 20-24%"口服品上市**月净价 ≤ 高端注射品净价的 60%**（即够用口服净价便宜 ≥40%），且**商保覆盖 ≥ 主流商业计划的 50% 处方集**（覆盖广非小众）。
- **② 放量反超**：该"够用"品上市后**≤3 个季度内 TRx（或 NBRx）季度环比放量斜率 ≥ 高端注射品同期斜率**（份额侵蚀实测，而非叙事）。
- **③ 高端被迫跟降**：高端注射品被迫降净价，**高端↔"够用后发口服"净价价差自峰值收窄 ≥1/3**（例：若初始价差 100%，收窄到 ≤67%）。
- 与 **KILL-C 互补且不重叠**：KILL-C 盯高端↔存量双靶净价价差 <15%（同注射档内压缩）；KILL-D 盯高端↔"够用后发口服"跨剂型的份额+净价侵蚀。
- **触发后动作**（挂环⑥）：NVO 对冲腿转主动加仓；LLY 减仓至"orforglipron 商品层能兜"的暴露、疗效溢价腿下修。

**≥2 个历史镜鉴（曾经的赢家如何被取代 · arena 层比 company 更值钱）**：

1. **PCSK9 抑制剂（疗效碾压 → 被平价逻辑压回窄人群）★主镜鉴**
   - 失败模式：疗效确凿（LOF -88% CV 风险 [mat-624267]）却以 >$14,000/yr 高端价上市，成本效益 $414K-503K/QALY（阈值 $100K 的 4-5 倍）、$592B 药费 vs $29B 节省 [mat-61df5e]。
   - 峰谷损失：被迫**降价 2/3**（$14,000→$4,536）仍被专家判"没法为大众埋单"，放量远不及预期，沦为窄高危人群用药而非全民重磅 [mat-7fde1f, mat-61df5e]。
   - 当年最早预警信号：**成本效益研究测出远超 $100K/QALY + 支付方喊"承受不起"**。
   - **现在是否已现**：**已现**——GLP-1 健康节省 $18.2B << 药费 $65.9B [mat-c4b77e]，是同一失衡；MFN "所有新药 MFN 价"是同一压制机制。教训一句话：**革命性疗效若匹配不上成本效益阈值，会被支付方从"全民重磅"压回"窄人群"。**

2. **胰岛素疗效竞赛（疗效/便利领先者让出净价换覆盖 → 净价被系统性压平）**
   - 失败模式：疗效/便利领先的胰岛素类似物（长效/速效新一代），在 PBM 回扣战下"列表价涨、净价跌"背离，最终被政策封顶（Medicare/州法 $35/月上限）压平——疗效领先没换来利润领先。
   - 损失幅度：列表价 vs 净价缺口一度达 **70%+ 回扣**（净价长期个位数甚至负增长）；本轮 GLP-1 的 tirzepatide 净价折 **79%** > sema 41% [mat-c4b77e]，量级与胰岛素同级——**高端疗效品在 Medicare 端反而让出更大折让换覆盖**。
   - 当年最早预警信号：**列表价与净价持续背离（gross-to-net 缺口逐年扩大）+ 政策定价封顶立法出现**。
   - **现在是否已现**：**已现**——GLP-1 净价已被 Medicare $245 + MFN "所有新药 MFN 价"锁定 [mat-f91712]，且 tirz 79% 折让正是 gross-to-net 缺口现形。教训：**在强势支付方市场，"疗效领先"的定价权远小于叙事，越高端越可能被要求让利换准入。**

> 两镜鉴分工：PCSK9 = 定量主镜鉴（成本效益阈值把疗效领先者压回窄人群）；胰岛素 = 净价机制镜鉴（gross-to-net 缺口 + 政策封顶把疗效领先者利润压平）。两者从"覆盖窄化"与"净价压平"两条路径共同支撑命门 3。

> ⚠️ 只想得到"疗效领先者最终称霸"的成功案例本身是 red flag——本 arena 的两条镜鉴都指向"疗效领先被平价/支付方逻辑反噬"，这正是命门 3 的历史依据。

**signpost（未来 3-12 月验证/证伪事件）**：
- retatrutide FDA 提交 + 完整 TRIUMPH 项目群安全性谱（各剂量停药率/心率/dysesthesia）→ 验 WMBT-1/KILL-B。
- **VKTX VANQUISH-1 顶线**（早于 VANQUISH-2）+ 口服 Ph3 4Q26 启动 → 验 WMBT-2/VKTX 期权。
- NVO amycretin Ph3 启动 + 任何头对头 reta/tirz 信号 → 验 WMBT-2/KILL-A。
- IRA 下一轮谈判名单是否纳入 tirzepatide + MFN 对新药执行细则 → 验 WMBT-3/KILL-C。
- **orforglipron（LLY 自家口服）+ 任一"够用"口服品的商保覆盖广度、上市净价、放量斜率 → 验 KILL-D（商品化路径）**；同步盯高端注射品与"够用"档的净价价差是否收窄。
