## 核心数据点与事实

- 主体/时点：VKTX 2026-04-29 发布 2026 Q1（截至 3/31）财报 + 管线更新。
- 现金：现金+等价物+短投 6.03 亿美元（$603M），较 2025-12-31 的 $706M 下降（单季净减约 $103M）。资产负债表明细"现金及等价物"$118.1M（vs 年末 $165.8M），余额主要为短投。
- 烧钱：Q1 研发费用 $150.2M（去年同期 $41.4M，同比 +263%，主因临床/生产扩张）；G&A $14.0M（去年 $14.1M，基本持平）。
- 净亏损：Q1 净亏 $158.3M，每股亏 $1.37（去年同期净亏 $45.6M、$0.41/股）。
- 现金跑道隐忧：按 Q1 ~$100M+ 净现金消耗速率，$603M 约支撑 5-6 个季度（未含未来融资）—— 现金 vs 78 周 Phase 3 成本是介入纪律变量。
- VANQUISH-1、-2 皮下 Phase 3 均已完全入组（VANQUISH-1 超 4,500 例、超原目标并提前；VANQUISH-2 约 1,000 例）；均 78 周皮下每周给药，剂量 7.5/12.5/17.5 mg + 安慰剂；均"on track"。
- 口服 VK2735 Phase 3（肥胖）预计 4Q26 启动（12 月已完成 FDA end-of-Phase 2 会议）；若成，将是首个上市的口服双激动剂。
- 维持剂量研究（约 180 例，含每周/隔周/每月给药）2026-01 完成入组，数据预计 3Q26。
- 新型 amylin 激动剂 VK3019 已递交 IND，Phase 1 预计 2Q26 启动（切入 amylin 赛道，对标 NVO amycretin/CagriSema）。
- 疗效锚：Phase 2 VENTURE 皮下 13 周减重最高 14.7%（AE 多轻中度、GI 早发快消）；口服 VENTURE 13 周减重最高 12.2%，≥5% 达标最高 97%（安慰剂 10%）、≥10% 达标最高 80%（安慰剂 5%）。
- 口服 Phase 1：28 天减重最高 8.2%，停药后 Day57 仍达 8.3%（耐久性信号）。
- 口服维持探索队列：快速滴定至 90 mg/日 → 下调至 30 mg/日维持 7 周，提示 <30 mg/日或可维持减重。

## 叙事主线

因为 VKTX 手握 $603M 现金、两项皮下 Phase 3 全入组、口服 Phase 3 4Q26 启动、且已用 VK3019 补上 amylin 第二腿 → 研判其在"疗效×剂型×赛道广度"三维卡位齐备，但单季净亏 $158M 使现金跑道成为最硬约束 → 投资意味着 VKTX 是收窄代差的高确定性执行者，但 2027 读出前需盯融资/稀释与烧钱斜率。

## 反常识分歧点

市场易被"clinical-stage 无收入烧钱"吓退；本料显示研发费同比翻三倍（$41M→$150M）实为 Phase 3 全面铺开的必要投入，且入组超额提前，属"贵但在推进"。反向风险：$603M 对两项 78 周 Phase 3 + 口服 Phase 3 启动可能偏紧，增发概率高。
