# _synthesis_brief — global-glp1-highend-efficacy / opus4.8

> 04 合成的工作台：核心 thesis / 关键假设 / v0→v1 强度调整 / K# 校准 / peer 财务锚。供 ④⑥ 与 critic 复用。生成于 2026-07-24。

## 一、核心 thesis（进 04 前 = thesis_v0 起点）

高端疗效池（22-30% 档）由 **LLY retatrutide（三激动）独占天花板已实证**（TRIUMPH 80wk 28.3%、45.3% 患者 ≥30%）；挑战者集体落后 1-2 身位。shortlist=LLY(核心) > VKTX(疗效/并购期权) > NVO amycretin(反击变量)。v0 强度 8/10。

## 二、04 findings 对 thesis 的三个校准（v0→v1 delta）

1. **疗效轴：挑战者逼近超 v0 预期，但双轴（疗效+耐受同时）无人证平**
   - NVO amycretin 皮下 Ph1b/2a 36wk **24.3%**（20mg 22%）、**36 周无平台**、高剂量维持仅 4 周（曲线未跑满）[mat-053d60, mat-d59bb4]；口服 Ph1 12wk 13.1% [mat-053d60]；T2D Ph2 皮下 14.5% [mat-c97859]；两剂型直推 Phase 3（2026）。
   - VKTX VK2735 皮下 Ph2 13wk 14.7%、口服 Ph2 13wk **12.2% / ≥10% 达标 80%** [mat-d49f82, mat-732553]；VANQUISH-1/-2 已全入组，**顶线 2027 才读出（binary，尚未读出）** [mat-5003e0, mat-732553]。
   - → 疗效轴代差正被压窄（amycretin 24.3% no-plateau 已够到 reta 档），**但都还是小样本/短窗/未头对头/未 Ph3 读出**；无一在**疗效+耐受性双轴同时**逼平 reta。命门 2 仍 open，VANQUISH-2 是最大不确定源。

2. **安全窗：命门 1 未坍塌但被量化实证**
   - retatrutide dysesthesia **剂量依赖**：9mg 8.8% → 12mg **20.9%**（约每 5 人 1 人）[mat-6f71bc]。NEJM Ph2 曾判"安全谱与同类一致" [mat-f6eb26]，但三期口径出现新型 GCG 相关信号。
   - → 顶剂量（30% 疗效来源）落地存在耐受折价风险；"最高疗效 ≠ 可无损落地的最高剂量"。命门 1 从"待观察"升为"实证有代价、未封顶"。

3. **利润转化：命门 3 证据从"低置信"升为"证据充分"——这是最被低估的下压**
   - 净价压制硬锚：Medicare $245/月（腰斩）、患者自付 $50/月、TrumpRx 现金 $346-350/月、口服起始 $150/月 [mat-f91712, mat-8edc63]；**MFN "所有新上市药保证 MFN 价"** → 前置压制三激动/amylin 高端管线 [mat-f91712]；tirzepatide 净价折 **79%**（sema 41%）——**高端疗效品让出更大净价换覆盖** [mat-c4b77e]。
   - 财政不可持续螺旋：Medicare 10yr 净增 $47.7B，健康节省 $18.2B << 药费 $65.9B——"药物自付其费"证伪 [mat-c4b77e]。
   - **PCSK9 镜鉴（环⑤一等定量料）**：疗效确凿（LOF -88% CV 风险）但发布价 >$14,000/yr、$414K-503K/QALY（阈值 $100K 的 4-5 倍）、$592B 药费 vs $29B 节省 → 被迫降价 2/3 至 $4,536 仍嫌贵、放量受阻、沦为窄高危人群用药 [mat-61df5e, mat-7fde1f, mat-624267]。**剧本与 GLP-1 高度相似**（$18.2B << $65.9B）。
   - → 疗效领先 → 利润领先的转化被系统性削弱。"疗效赢家 = 利润赢家"是市场为 LLY 付 30x 溢价时踩的最弱一块地。

## 三、定价锚 × 证据强度张力（环②↔③缝合的核心）

- 市场**定价笃定**：LLY forward PE **30.2x**（行业 18.45x）、trailing 39-40.7x、市值 **$1.02T**、1yr +17.4%、2026E EPS $33.86 上修 [mat-505828, mat-61becc]；NVO forward 11.76x、1yr **-56.4%**、指引 -5~13% CER = 市场已用股价把 LLY 判赢家、NVO 判输家 [mat-505828]。
- **证据最弱处**：③ 里"疗效领先能转化为耐久利润领先"（命门 3）证据支持度**最低**（净价压制 + PCSK9 镜鉴双重反证）。
- **张力一句话**：市场为"疗效独占"付了 30x 溢价，却在为"疗效→利润转化"这条最弱假设隐性买单——定价笃定度 > 证据强度。
