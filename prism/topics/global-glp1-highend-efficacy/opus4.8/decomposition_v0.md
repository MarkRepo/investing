# decomposition_v0 — GLP-1 三激动/amylin 高端疗效 arena

> 从 thesis_v0 终局赌注（shortlist=LLY核心>VKTX期权>NVO amycretin反击）拆命门 + 每环 B 靶点 + primer 入门目标种子。薄拆解（thesis_v0 + K# + baseline + prescan 校准），深度重拆留 04。

## 一、命门 1-3

- **命门 1（GCG 安全窗 = 疗效独占的兑现闸门）**〔置信度：中〕
  retatrutide 30% 疗效独占已实证，但**能否在最高剂量商业落地**取决于 GCG 靶点安全窗。prescan 实锤：TRIUMPH-1 最高剂量停药率 11.3% + dysesthesia 新型不良反应。若真实世界耐受性迫使商业剂���下移，"疗效独占"在临床成立但在处方端缩水——LLY 的赢家地位从"疗效碾压"退化为"疗效领先但幅度受限"。**方向错了（安全窗宽、剂量全落地 vs 窄、剂量下移）直接改变 shortlist 里 LLY 的权重与挑战者的相对空间。**

- **命门 2（挑战者双轴逼平 = shortlist 洗牌触发器）**〔置信度：中〕
  挑战者能否在**疗效+耐受性双轴同时**逼平 retatrutide（而非单轴）。当前全部单轴掉队：CagriSema 疗效败、MariTide 疗效近但耐受差、VKTX/罗氏未读出。若 VANQUISH-2（最近催化剂）或 amycretin Phase III 出现"疗效≥25% 且耐受性优于 reta"的读出，则 arena 从"LLY 独占"变为"双雄/多雄"，VKTX/NVO 从并购期权升为独立利润池。**这是 shortlist 排序的最大不确定源。**

- **命门 3（疗效领先 → 利润领先的转化）**〔置信度：低〕
  高端疗效能否在 IRA/TrumpRx 净价压制下转化为**耐久利润溢价**。若净价被压平、高端药与存量双靶价差收窄，则"疗效赢家"拿不到"利润赢家"——arena 的终局（选谁）意义下降（选出的赢家无超额利润）。置信度低 → B 靶点优先砸料（定价/净价/支付方料）。

> 命门 vs K#：命门 1↔K1（安全窗）但更聚焦"剂量落地机理"；命门 2↔K2 但强调"双轴同时"这一翻盘阈值；命门 3↔K3 但落在"疗效→利润转化"机理。命门 4 缺位是刻意的——K4（介入纪律）是终局收口动作，非机理翻盘点，归环⑥。

## 二、每环 B 靶点（决策链 6 环）

- **环①（看懂赛道：赚钱/技术路线/卡位）**：三靶 vs 双靶 vs amylin combo 的机理分野与疗效阶梯定位；高端疗效池在整个减重利润池的相对大小（增量 vs 存量）。〔背景，A 合同 scope〕
- **环②（胜负变量 + 定价锚）**：**胜负变量 = 疗效×耐受性双轴**；定价锚 B 靶点——LLY forward PE（父级 41.8x，需最新）是否已 price-in 疗效兑现？VKTX 市值是否已含并购溢价？〔挂命门 3 + K4〕
- **环③（翻可证伪假设）**：把"LLY 独占稳固"翻成 3-5 条假设（安全窗、挑战者读出、定价）。〔B 靶点由命门 1/2/3 直接供给〕
- **环④（押注 · peer 横比矩阵 · 终局环强制非空）**：**候选公司横比料靶点**——LLY / NVO / AMGN / VKTX / Roche 五家的疗效数据（减重%/剂量/耐受性）+ 财务（收入/毛利/ROIC/PE/历史 PE 区间）+ 管线卡位，跨家**同口径可比**。这是选 shortlist 的一手锚，父级 peer 财务 findings 可复用，缺口用 financial_data 拉。〔终局环 · 挂 K2/K4〕
- **环⑤（证伪 · kill + signpost + 赢家被取代镜鉴）**：每家的 kill 信号（reta→安全性黑天鹅；VKTX→VANQUISH-2 顶线 miss；NVO→amycretin 掉队）+ 历史镜鉴（PCSK9/胰岛素疗效领先者被平价者取代）。〔挂命门 1/2〕
- **环⑥（shortlist 三档分流 · 终局环强制非空）**：**shortlist 判定料靶点**——各候选进"深研/观察/淘汰"的 tier 依据 + 介入纪律（介入时点/估值触发/binary 风险）。深研档建 company stub。〔终局环 · 挂 K4〕

> **终局环 B 靶点非空核对**：arena 终局 = 环④ peer 横比 + 环⑥ shortlist。两环 B 靶点均已写出并进 5.3/01 收料优先级（peer 财务料 + 各候选疗效读出料）✓。
