2. **深跌档放开旧的 −39% 成本地板封顶**：悲观端至 −50%+（地板失效）。EV(12M) 由 v1 的 −3.6%/−4% 下修至 **−6.7%**。
3. **估值中枢下移**：normalized 下尾计经营去杠杆（base Normalized PE 21-23、Bear 13-15）；PB 4.58x（可比最高）由"增速溢价 vs 治理折价对冲=中位"改判"治理净折价"（同业横截面 base 26-30）。综合 base 中枢 26-30 → **25-29 元**。
4. **强度 5.5 → 5.0/10**：方向仍看多，但唯一"下行保护"支柱被抽走、下行破坏力放大、现价负 EV 更明确、信心降为"中偏谨慎"。
5. **补价格行情语境**：现价 27.9 已贴 52 周低（27.47）、当日 −7.46%、距 52 周高（43.94）−36%——"等回调"须警惕接下跌中继而非折价。
6. **C1 缺口升级为 P0 承重命门**（原为"影响 bull 论据强度"→ 现"决定深跌幅度与成本地板成立与否"），已挂 P0 suggested_drilldown。
7. **勘误备查**：财务 API `get_financial_context` 显示"商誉占净资产 190%"为 `_fmt_pct` 二次×100 显示 bug，真实约 1.9%，不构成减值风险（独立空头据错误数据所提"商誉减值黑洞"已作废）。

## § 1. 核心 thesis（当前完整版）

**A 股稀缺的"银锡量价双击"资源股。方向看多，但现价 27.9 元定价中性偏贵、EV≈−7%（负），故现价观望、回调才买。** 赌的核心不是银价还能涨多少（共识已在价里），而是**宇邦近端放量的确定性 + 银漫二期远期期权未被定价**；对冲项是**价格从历史高位回撤 + 成本地板可能失效 + 治理披露折价**。原 v1 并列的第二支点"极低成本抗跌性"经 05-critic 复核后撤下，降级为待一手 C1 证实的假设。

- **强度评分：5.0 / 10**（方向看多但现价负 EV、下行保护假设被抽走；高 β + 价格历史高位 + 100%质押 + 治理瑕疵 + 承重级 C1 缺口 → 中偏谨慎、试探仓）。
- **估值带**：base 中枢 25-29 元（现价落此偏上沿）；强力买入 <24（EV+8%）、<21（EV+24%）；不追 >30。
- **时间维度**：中期 1-3 年（非长持——管理层资本纪律与治理信任不足）。

## § 2. 支持理由（当前完整清单）

**A. 量增确定性（近端）**
1. 宇邦矿业产能释放驱动 2026 白银产销大增，Q1 已兑现、H1 预告印证 `[mat-786786]``[mat-3f3de8]`。这是"量"里确定性最高的一块。
2. 资源禀赋一流：白银 24,537 吨（亚洲第一）、锡 24.35 万吨（国内第二）`[mat-74ce34]``[mat-db9ab1]`，长寿命高品位共伴生矿，A 股独家"银锡双击"卡位。

**B. 资产质量硬**
3. ROIC 连续 3 年 13-17%（>矿业 WACC）、FCF 连续 3 年正且 2025 增至 19.6 亿——真实造血，区别于纯故事资源股。

**C. 远期期权（市场未定价 · 保留的正向 edge）**
4. 银漫二期（165→297 万吨）、Achmmach 锡矿等在建产能是现价未计入的向上期权 `[mat-f5b19a]``[mat-b84471]`。

**D. 价格 β（周期顺风）**
5. 银($57)/锡($58.7k)高位，实际利率下行/弱美元/降息宏观体制对美元计价银锡量价双击友好（macro_stamp v3）。

**（原 B "成本地板"支柱已移至 §3 反方/§7 缺口——降级为待证实假设，不再计入支持理由。）**

## § 3. 反方观点（当前完整清单）

**A. 价格处历史极值、下行风险真实**
1. 银锡同创历史新高，锡业分会公开警示"背离基本面、非理性繁荣" `[mat-5df37d]`；股票已从 5 月峰值 −30%、现贴 52 周低、当日 −7.46% 是脆弱性实证。
2. 锡"强预期弱现实高库存"：社库 2.07 万吨历史高位、表观消费弱、加工费上涨（矿端转松）`[mat-5df37d]`。
3. 银"光伏去银化"：2024 或为光伏用银峰值，技术降银快于装机增速 `[mat-5d4695]`。

**B. 成本地板可能是会计幻象（05-critic 致命一击 · 承重）**
4. $13/oz 白银 C1 是共产品分摊反推、零一手数据；共生金属同向下跌时互抵的副产 credit 缩水，单金属报表单位成本可能不降反升，"深跌只少赚不亏损"未必成立。2025"银价+140%、银成本+126.6%"近乎同步是信号（部分来自宇邦并表）。深跌情形不再封顶于 −39%，悲观端 −50%+。

**C. 盈利质量弱于表观**
5. 2026Q1 净利含一次性 4.47 亿（扣非才 +138%）`[mat-786786]`；2025 价涨 140% 毛利率反降 5-7.5pp `[mat-74ce34]`——成本+并表低效吞噬价格红利；下行时经营去杠杆或使 normalized 扣非滑向 20-22 亿。

**D. 治理/资本纪律（最大折扣）**
6. 控股股东 100% 质押、集团 36.55 亿债务 `[mat-702ef6]`；H 股发回 + 中金贴堂（12 年仅 26 例，媒体指向资源量分类被质疑）`[mat-7d7ae5]`；密集海外亏损勘探小额并购（FEG/Tartana/西藏阳光/大西洋锡业 `[mat-cae236]`，撒胡椒面）；派息率仅 11.5% `[mat-74ce34]`。PB 4.58x 为可比最高，应给净折价。

**E. 量增的时间结构**
7. 银漫二期 2028Q4 才带料试车 `[mat-f5b19a]`，2026-2028 近端量增几乎全靠宇邦；2025 锡产量 −25%（安全事故）证明"量"脆弱。

**F. 估值不便宜**
8. 现价 EV≈−7%、base 中枢偏上沿、PB 4.58x 可比最高——市场定价充分偏贵，无预期差。

## § 8. 思维过程留痕

- **已知**：量价双击正在报表剧烈兑现；资源禀赋真实；治理瑕疵真实。~~成本地板真实~~ → v2 校准为"表观毛利厚但一手 C1 未证、抗跌性待验"。
- **刻意避开的偏见**：①不被"产能翻倍"锚定（银漫二期是远期期权、须贴现）；②不被表观净利 +257% 误导（看扣非）；③不被"低 PE"诱惑（周期顶部高 E 低 PE 陷阱）；④不被"翻身叙事"冲昏（先记住当初怎么倒的——2018 事故）；⑤**v2 新增：不把反推的会计成本当硬现金地板**（独立空头点破）；⑥不被脏数据带偏（商誉"190%"实为显示 bug 1.9%，已核实剔除）。
- **关键差异（我 vs 市场）**：市场按"价格维持"给 14x、我按"价格回落+量增对冲"给 base 中枢——结论现价中性偏贵、EV 负；我的 edge 不在银价（共识）、也不再在成本地板（已撤），而在**量增近端确定性 + 银漫二期期权未定价**。
- **为什么现价不买却看多**：EV≈−7% 是中性偏贵的证据；方向靠量增+资产质量+回调后弹性，纪律是"等更深的回调"（成本地板保护撤下后，安全边际要求比 v1 更高）。
