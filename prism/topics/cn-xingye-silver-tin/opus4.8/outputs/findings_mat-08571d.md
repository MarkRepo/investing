# findings — 2026年度沪锡展望：供需双驱，"锡"牛或归

## A. 核心数据点
1. **价格区间（价·命门2）**：预计2026沪锡主力参考区间 **26万-39万元/吨**，均价约 **27万-28.5万元/吨**；另一口径沪锡指数运行区间 **30-40万元/吨**，沪锡加权26-35万元/吨。
2. **供需平衡（口径一）**：全年全球供应约 **36.9万吨**、需求 **37.8万吨**，缺口 **0.9万吨**；中国亦有 **0.3万吨** 缺口。
3. **供需平衡（口径二·静态）**：2026全球轻微过剩约 **0.45万吨**；新增锡元素约2.1万吨（曼相锡矿0.9kt + 刚果金0.4kt 复投产为最大动态不确定项）→ 或从静态过剩转为动态紧平衡。
4. **2026-2030平衡表**：-6.3 / +0.3 / +3.1 / -0.8 / -10 千吨（占当年需求 -1.5% / +0.1% / +0.7% / -0.2% / -2%）。
5. **需求增速**：2026全球锡消费增速有望接近 **约4%**（另口径+3.1%至39.6万吨）；数据/AI服务器2026环比新增约 **0.23万吨**；2026/2027需求分别增1.2/1.1万吨。
6. **供应**：2026全球精锡供应37.7万吨(+7.1%)，增量主来自佤邦禁矿放开后恢复性增长；刚果金冲突或带来约 **1750吨** 减量。
7. 结构：2026呈"前紧后松"——上半年供需双弱但仍短缺，年中缅甸佤邦/掸邦复产 + 印尼增产释放，供应边际宽松。
8. 需求验证：8月全球半导体销售额649亿美元(同/环比+22%/+4%)刷新历史高点。
9. 宏观：2026处全球降息周期 + "十五五"开官之年，弱美元对美元计价锡价构成支撑。

## B. 叙事主线
2026锡市"前紧后松、供需双驱"：上半年供应释放缓慢维持偏紧短缺、下半年缅甸复产+印尼增产边际宽松，全年小幅缺口(0.9万吨)或静态轻微过剩(0.45万吨)间摇摆；AI/半导体焊料需求高增 + 降息宏观暖势支撑价格中枢，策略以逢低做多为主，"锡牛或归"。
