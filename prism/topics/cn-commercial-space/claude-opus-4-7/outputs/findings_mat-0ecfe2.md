# 信科移动 (SSE_688387) 2025 年报 finding — 5G+卫星互联网空天地一体化龙头「亏损减小 + 载荷市占率第一」

## 核心数据点与事实

### A1. 财务画像：营收微降 / 减亏 / 现金流稳健
- `[fact-A1.1]` **营收 61.45 亿元（-5.33% YoY）/ 归母净利 -2.70 亿（与上年基本持平）/ 扣非 -4.07 亿（同比减亏 1,953 万）** —— 亏损减小但仍处深度亏损
- `[fact-A1.2]` 综合毛利率 **23.08%（+0.33pp）** —— 微提升
- `[fact-A1.3]` 经营现金流 5.98 亿（-14.84%）—— 仍维持现金流入
- `[fact-A1.4]` **研发投入 12.82 亿（+5.92%）/ 占营收 20.86%（+1.16pp）/ 资本化 1.56 亿（+27.92%）/ 资本化率 12.20%**
- `[fact-A1.5]` 研发人员 **1,898 人（-146 人 / -7.1%）** —— 适度优化

### A2. 业务结构与卫星互联网突破
- `[fact-A2.1]` 主设备业务：中国移动 2.6G 集采份额较现网提升 **超 40%** / 中国电信 800M 集采份额翻番
- `[fact-A2.2]` 天馈室分：基站天线集采市场份额排名第一 / 室分小站第一；天馈 2025 营收 -35.31%（国内运营商缩减投资）
- `[fact-A2.3]` **卫星互联网全谱布局：星载基站 + 星载相控阵天线 + 核心网 + 网管 + 专用终端 + 仪器仪表**
- `[fact-A2.4]` **"重要客户载荷综合市场份额排名第一"**（公司明文）—— 卫星互联网核心成绩
- `[fact-A2.5]` 荣获 **2025 卫星互联网现代产业链"优秀合作伙伴"**
- `[fact-A2.6]` 行业应用：矿用 4G+5G 无线专网综合市占 30%+；5G-R 高速铁路第一梯队
- `[fact-A2.7]` 国际市场：主设备重启，中标乌干达 / 印尼存量；天馈突破亚太/独联体/东欧/巴西

### A3. 6G+ 卫星互联网技术领导力
- `[fact-A3.1]` **5G NTN 立项数全球第一**（在 3GPP）+ ITU 星地融合领域重要贡献者
- `[fact-A3.2]` "**面向星地融合的卫星移动通信关键技术与应用**"荣获中国通信学会 2025 科学技术**特等奖**
- `[fact-A3.3]` 实现**手机宽带直连卫星技术突破**（与上海瀚讯、ST 臻镭、海格通信形成手机直连四方)
- `[fact-A3.4]` **业界首发基于全息超表面的新型天线阵列（第二代）等 5 项 6G 创新成果**
- `[fact-A3.5]` 牵头组建武汉市星地融合新一代无线通信产业创新联合实验室 + 北京市 6G 无线接入网演进重点实验室
- `[fact-A3.6]` 联合运营商/航天/芯片伙伴发布 **"九万里计划 2.0"**（星地融合系统能力跃升）
- `[fact-A3.7]` 全年 3GPP 标准提案 2,800+ 篇（全球第六）/ 5G 标准必要专利全球第九 / 境内外发明专利 17,000+

### A4. 股权
- `[fact-A4.1]` 母公司：**中国信科集团**（央企）—— 武汉光谷大本营

## 叙事主线

信科移动 2025 营收 -5.33% 但**扣非减亏 1,953 万 + 亏损收窄**；核心驱动是**卫星互联网业务全面突破**："重要客户载荷综合市场份额排名第一" + 5G NTN 全球第一 + 手机宽带直连卫星技术突破 + 6G 全息超表面天线 + 国际市场重启；同时 5G 主设备份额持续提升、运营商缩减天馈投资带来短期阵痛；研发投入维持 20.86% 高强度 + 适度优化人员 -7.1%。对投资意味着：信科移动是**卫星互联网空天地一体化最完整投资标的之一**（产品 + 标准 + 客户三位一体），**K1+K3+K4 强支持 + K5 由极反向（深亏）逐步修复**；估值需考察 2026/2027 卫星互联网载荷规模化交付节奏和减亏速率。

## 反常识/分歧点

1. **市场共识：信科移动是 5G 通信公司，与卫星无关** → 实际：**"重要客户载荷综合市场份额排名第一"** + 5G NTN 全球第一 → 卫星互联网核心标的
2. **市场共识：通信设备股是夕阳行业** → 实际：6G 全息超表面天线 + 星地融合 + 手机直连卫星 → **6G 时代领头羊定位**
3. **市场共识：扣非亏损 -4.07 亿应该减仓** → 实际：减亏 1,953 万 + 现金流 5.98 亿 + 卫星互联网订单兑现节奏 → 业务体质修复中
4. **市场共识：天馈业务 -35.31% 大幅下降** → 实际：基站天线集采份额排名**第一**（基期效应），运营商缩减投资是周期性
