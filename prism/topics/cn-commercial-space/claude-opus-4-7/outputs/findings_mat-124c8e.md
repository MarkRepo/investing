# 中科星图 (SSE_688568) 2025 年报 finding — 空天信息地理 SaaS 龙头「主业塌方 + 两翼跑通」

## 核心数据点与事实

### A1. 财务画像：营收-17.83%、扣非由盈转大亏、现金流逆转
- `[fact-A1.1]` **营收 26.77 亿元（-17.83% YoY）**
- `[fact-A1.2]` 归母净利润 0.29 亿元（**-91.64% YoY**） / **扣非归母净利润 -1.47 亿（-161.39%）** — 扣非已亏损
- `[fact-A1.3]` 利润总额 0.92 亿（-83.20%）
- `[fact-A1.4]` **经营活动现金流 +1.58 亿（vs 上年 -0.81 亿，逆转 +2.40 亿）** — 现金流是唯一亮点
- `[fact-A1.5]` 财务费用 +3,069%（利息收入降 + 借款利息升），管理费用 +12.77%（人工成本增）
- `[fact-A1.6]` 综合毛利率 **45.68%（-3.91pp）** — 业务结构尚健康但全线下滑

### A2. 业务结构：地理信息塌方 + 商业航天/低空增长
- `[fact-A2.1]` **地理信息-特种：6.37 亿（-38.13%）/ 毛利率 44.91%（-5.97pp）** — 主业重创
- `[fact-A2.2]` **地理信息-民用：14.51 亿（-25.17%）/ 毛利率 43.31%（-5.15pp）** — 仍是收入基本盘
- `[fact-A2.3]` **商业航天：3.83 亿（+32.93%）/ 毛利率 53.57%（+0.77pp）** — 两翼之一兑现
- `[fact-A2.4]` **低空经济：2.05 亿（新业务，无上年同期）/ 毛利率 50.14%** — 两翼之二新增
- `[fact-A2.5]` 商业航天 + 低空合计 5.88 亿（22.0%），但**贡献毛利占比**约 30% — 新业务毛利率显著优于传统
- `[fact-A2.6]` 分产品：GEOVIS 软件销售与数据服务（毛利率 64.49%，-47.05% 营收）/ 技术开发服务 50.88% / 专用设备及系统集成 27.01%

### A3. 商业航天/卫星产业链布局
- `[fact-A3.1]` **"天箭"系列火箭电子系统** —— 商业火箭天基通信系统 + 新一代环形网络火箭测量系统（低成本/可回收火箭测控）
- `[fact-A3.2]` **"天星"系列卫星电子系统** —— 综合电子/测控/数传/通信，满足"大规模商业星座建设需求 + 太空算力星座配套"
- `[fact-A3.3]` **"洞察者"+ 星图太空云** —— 测运控全球站网（地基激光+微波融合）+ 太空交通管理 + 大模型驱动卫星全生命周期管理
- `[fact-A3.4]` **"星眼"太空感知星座建设计划** —— 自建太空感知星座，提供专业化太空交通管理
- `[fact-A3.5]` 商业航天电子装备 + 测运控两块为 2025 业绩驱动器，**已突破火箭信号采集-传输-处理全业务链核心技术**（在研项目 #8）

### A4. 研发：投入逆周期增长 + 资本化率上升
- `[fact-A4.1]` 研发投入 **7.47 亿（+14.05%）**，占营收 **27.89%（+7.79pp）** —— **研发强度大幅提升**
- `[fact-A4.2]` 费用化 5.11 亿 + **资本化 2.36 亿 → 资本化率 31.56%（+4.16pp）** —— 资本化率提升，**美化利润嫌疑**
- `[fact-A4.3]` 研发人员 **1,807 人（占总员工 59.09%）** —— 团队规模/占比极高
- `[fact-A4.4]` 学历：博士 42 + 硕士 438 + 本科 1,166（硕博占 26.6%）
- `[fact-A4.5]` 在研重点 16 项：累计投入 22.99 亿 / 总规划 58.19 亿 —— **资本支出沉淀压力**
- `[fact-A4.6]` 重点项目：地球圈层数据 + 智能体平台 + 超算云网 + GEOVIS Online（11.5 亿规模）+ 太空商业测量通信 + 太空感知星座 + 低空云数字底座 + 复杂电磁空间智能平台

### A5. 客户/股权结构
- `[fact-A5.1]` 前 5 客户合计销售 3.20 亿，**占 11.97%**（无关联方）—— **客户极度分散**（与铖昌/航天电器 50-94% 集中度形成强反差）
- `[fact-A5.2]` 前 5 供应商 2.79 亿，占采购 12.51%
- `[fact-A5.3]` 控股股东：**中科九度**（实际控制人 = **中国科学院空天院**）—— 央企（中科院系）非航天系
- `[fact-A5.4]` 季节性：营收集中下半年特别是 Q4，全年费用平摊 → Q1/Q2 业绩易亏损

### A6. 战略与定位
- `[fact-A6.1]` "**一体两翼**"战略：智能地球（一体）+ 商业航天/低空经济（两翼）
- `[fact-A6.2]` 转型为"**产品型公司**"，从项目制 → 平台化/SaaS（GEOVIS Online、星图云、星图低空云）
- `[fact-A6.3]` 数字地球底座：星瞳大模型 + 星图超算云网 + 数字孪生 + 四域融合架构
- `[fact-A6.4]` 商业航天战略："产业链中下游向上游拓展"（年报明文）—— 从应用层主动进入太空算网/星座规划/卫星电子上游

## 叙事主线

因为「传统地理信息（特种+民用）受财政紧缩+一般信息化萎缩+行业技术演进影响营收双位数下滑」+「商业航天/低空两翼营收 +32.93% / 新增正增长但 22% 占比尚不足以填补 78% 主业塌方」+「研发投入逆周期增长 27.89% + 资本化率上升 4.16pp 美化利润」+「财务费用 +3000% + 计提减值 → 业绩雪上加霜」→ 所以呈现「营收-17.83% / 扣非 -1.47 亿（首次扣非亏损）/ 现金流逆转 +2.4 亿（强催收）」**「主业塌方+两翼跑通+现金流自救」三重信号同时出现**；对投资意味着：中科星图正在经历**业务结构的"剪刀差"切换**，从地理信息项目制 → 商业航天/低空 SaaS；**短期 12-18 个月业绩深谷**（高研发投入 + 资本化释放 + 减值）但战略方向正确；估值需考察两翼业务能否在 2026-2027 加速到 30% 占比以上来逆转业绩曲线。

## 反常识/分歧点

1. **市场共识：商业航天概念股都是炒预期** → 本文表明：中科星图商业航天**已贡献 3.83 亿真实收入（+32.93%）**、毛利率 53.57% > 公司平均，但被 78% 传统主业拖累 → **细看"两翼"是有 alpha 的**
2. **市场共识：央企体系内空天龙头估值有保护** → 本文表明：中科九度（控股股东）= 中科院空天院（实控人）—— 央企背景但 2025 扣非已亏损 -1.47 亿，**央企身份非业绩护城河**
3. **市场共识：高研发投入 27.89% 是利空** → 本文表明：研发资本化率 **31.56% 反而美化利润**（费用化 5.11 亿 vs 资本化 2.36 亿）—— **研发投入加大同时资本化率上升 = 双重利润操纵嫌疑**
4. **市场共识：扣非由盈转亏意味着主业崩坏** → 本文表明：经营现金流 +2.40 亿逆转 + 投资活动现金流改善 + 商业航天/低空真增长 → **业务质量在好转、只是利润表滞后**
5. **市场共识：中科星图是卫星遥感公司** → 本文表明：公司已**整体转型为"空天信息 SaaS+ 产业链整合者"**，火箭电子/卫星电子/太空云已是核心业务，**远超传统遥感定位**
