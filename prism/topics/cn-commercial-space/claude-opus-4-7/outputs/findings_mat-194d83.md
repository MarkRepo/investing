# 铖昌科技 (SZSE_001270) 2025 年报 finding — 民营 T/R 芯片唯一"业绩+97% 同时毛利率+6.6pp"

## 核心数据点与事实

### A1. 财务画像：罕见的"量价毛利率三杀齐升"
- `[fact-A1.1]` 营收 4.05 亿元 (**+91.28% YoY**) —— 上年 2.12 亿，**爆发性增长**
- `[fact-A1.2]` 净利润 1.17 亿元（**扭亏为盈**，上年净亏损）
- `[fact-A1.3]` **综合毛利率 72.69%（+6.61pp YoY）** —— 极高毛利 + 还在提升
- `[fact-A1.4]` 营业成本 +44.79% << 营收 +91.28% → 规模效应释放
- `[fact-A1.5]` 应收账款 5.65 亿（占总资产 **34.57%，+6.15pp**） + 应收账款余额净增 1.26 亿（+25.33%） → 增长伴随应收激增（典型快速放量阶段特征）
- `[fact-A1.6]` 经营活动现金流 -4736 万（vs 上年 -4757 万，**几乎持平**）—— 净利润 1.17 亿但现金流不同步，应收账款占用 + 备货推动
- `[fact-A1.7]` 累计收回现款及票据 3.36 亿，应收账款周转率大幅提高（公司自述）

### A2. 业务结构：99.78% 收入靠 T/R 芯片单一产品
- `[fact-A2.1]` **T/R 芯片收入 4.04 亿（占 99.78%，+108.61% YoY）** —— 完全单产品依赖
- `[fact-A2.2]` 研制技术服务收入仅 91 万（占 0.22%，**-94.95%**）—— 一次性技服业务大幅萎缩
- `[fact-A2.3]` **T/R 芯片销售量 230 万颗（+110.34%）/ 生产量 242 万颗（+218.75%）/ 库存量 47.4 万颗（+33.87%）** → 生产量增速 > 销售量增速，备货激进
- `[fact-A2.4]` 国内 100%、无外销 → 完全国内市场（美国实体清单限制下安全）

### A3. 产品/技术：星载核心供应商 + 机载高速增长 + 低轨卫星通信
- `[fact-A3.1]` 业务板块：**星载（核心优势板块）+ 机载（高速增长，已成主要营收部分之一）+ 地面（GaN 功放规模应用）+ 低轨卫星通信（解决方案完成迭代）**
- `[fact-A3.2]` 星载领域："**多系列遥感卫星项目已进入常态化批量交付阶段**" → 卫星互联网 + 千帆星座规模化部署的直接受益方
- `[fact-A3.3]` 低轨卫星通信："为下一代低轨通信卫星及地面配套设备新研发出多款产品，**完成卫星通信 T/R 芯片解决方案的迭代研制**，已在依据客户需求备货并按计划批量交付"
- `[fact-A3.4]` 机载领域："多个项目通过用户系统验证，进入量产阶段，营收实现高速增长"
- `[fact-A3.5]` 公司自评："**作为 T/R 芯片研发和量产单位的民营企业代表之一**" —— 国内 T/R 芯片民营赛道领头羊（vs 国博电子是央企赛道）
- `[fact-A3.6]` 产品已达上千种 + 频率覆盖 L 波段至 W 波段（民用宽频段全覆盖）

### A4. 客户/供应链：高集中度，单一大客户依赖
- `[fact-A4.1]` **前 5 客户合计销售 3.82 亿，占 94.36%**（无关联方）
- `[fact-A4.2]` 第一大客户 1.50 亿（**37.14%**） + 第二大客户 1.35 亿（**33.36%**） → 双头客户合计 70.50%，**极度集中**
- `[fact-A4.3]` 前 5 供应商占采购 85.45%（其中关联方 7.03%），**第一大供应商占 51.76%** → 供应商更极端集中（晶圆代工依赖度）
- `[fact-A4.4]` 风险段公司明文："核心技术人员流失 + 应收账款增加 + 毛利率波动 + 存货跌价" 4 项财务/运营风险
- `[fact-A4.5]` 客户主要为"科研院所及下属单位"（即航天科技集团 + 航天科工集团下属研究所）

### A5. 研发：高投入 + 完全费用化
- `[fact-A5.1]` 研发投入 1.46 亿（占营收 **36.08%**，同比 +66.14%）—— 比例**比铖昌芯（铖昌科技）2024 的 41.53% 略降是营收基数变大所致**
- `[fact-A5.2]` **资本化率 0%**（完全费用化，会计极保守）—— 与中国卫星 72.56% 形成核弹级反差
- `[fact-A5.3]` 研发人员 92 人（占 41.63%）—— 同比微降 7 人；博士 8 + 硕士 33（硕博占 44.56%）
- `[fact-A5.4]` 30 岁以下 58 人（63.04%）—— 极度年轻化团队
- `[fact-A5.5]` 在研重点项目：星载高集成 T/R 套片 + 地面高集成 + 机载高集成 + **低轨卫星通信 T/R 套片** + **高性能卫星通信射频芯片产业化** → 5 个项目全部为相控阵/T/R 芯片技术延伸

### A6. 战略：定位"民营 T/R 芯片唯一"+ "片上系统化"
- `[fact-A6.1]` 战略：从"模块集成"向"**片上系统化（SoC）**"转型 —— 集成度跨越
- `[fact-A6.2]` 资质：国家专精特新"小巨人" + 浙江省"隐形冠军" + 浙江省重点企业研究院 + 浙江省重点实验室
- `[fact-A6.3]` 国内行业地位：**"国内具有 T/R 芯片研发和量产的单位主要为科研院所以及少数具备三、四级配套能力的民营企业"** —— 民营赛道极少数玩家
- `[fact-A6.4]` 新兴应用场景：**气象/水利雷达 + 低空监测**（除卫星互联网外的第二/第三增长曲线）

### A7. 资本运作/资产负债
- `[fact-A7.1]` 总资产 16.35 亿（vs 上年 15.04 亿，+8.69%）—— 轻资产快速增长
- `[fact-A7.2]` 在建工程仅 109 万（占 0.07%，-85% YoY） → 产能扩张 capex 有限，主要靠晶圆代工
- `[fact-A7.3]` 固定资产 2.68 亿（占 16.40%） + 货币资金 3.00 亿（占 18.37%）—— 财务结构健康
- `[fact-A7.4]` 报告期内回购股权激励限制性股票 1,444,268 股 → 股权激励持续锁定

## 叙事主线

因为「下游卫星互联网 / 千帆星座 + 国家卫星互联网组网密集发射期到来」+「机载相控阵装备批量量产」+「公司星载领域核心供应商先发优势」→ 所以 2025 实现「营收 +91.28% / 净利由亏转盈 1.17 亿 / 毛利率 72.69%（+6.6pp）」**罕见三重正向**，**完全验证了"卫星互联网 + 机载相控阵装备爆发"的产业 narrative**；但 99.78% 收入靠 T/R 芯片单产品 + 前 5 客户 94.36% + 应收账款占总资产 34.57% → 对投资意味着：铖昌科技是 **K1（千帆 ITU 缺口）和 K3（国家队卫星制造产能拐点）的真实业绩兑现方**，是「**alpha 真兑现」的标的代表**，但同时是"成长股早期高估值高集中度"组合，估值需考察 PEG 和未来 12 月订单可见度。

3. **市场共识：商业航天受益方主要是火箭+卫星总装企业** → 本文表明：**上游元器件（T/R 芯片）是利润最厚环节** —— 总装毛利率 8.23%（中国卫星）vs 元器件 72.69%（铖昌）→ **利润分布严重不对称**
