# 复旦微电 (SSE_688385) 2025 年报 finding — FPGA 唯一 1xnm + 卫星通信明文应用，但利润大幅下滑 -59.42%

## 核心数据点与事实

### A1. 财务画像：营收增 / 利润大幅崩 / 现金流逆周期改善
- `[fact-A1.1]` **营收 39.82 亿元（+10.92% YoY）/ 归母净利 2.32 亿（-59.42% YoY）** —— 罕见的"营收增但利润崩"
- `[fact-A1.2]` **综合毛利率 56.19%**（公司明示"产品综合毛利率受部分产品线价格变动影响呈现下降趋势"）
- `[fact-A1.3]` **经营现金流 7.84 亿（+7.06%）** —— 与净利润背离，现金/净利 = 338%（异常高）
- `[fact-A1.4]` 应收账款与应收票据余额合计**占营收 57.29%** —— **应收占比极高**，下游客户回款周期长
- `[fact-A1.5]` 研发投入合计 10.70 亿（**-6.24%**），其中费用化 9.75 亿、**资本化骤降至 9,565 万（-58.85%）**
- `[fact-A1.6]` 研发投入占营收 26.88%（-4.92pp），资本化率 **8.94%**（中低）
- `[fact-A1.7]` 研发人员 **993 人（vs 1,130，-137 人 / -12.1%）** —— **大幅裁员研发**

### A2. 业务结构：FPGA + 安全 + 存储 + 智能电表 四象齐放
- `[fact-A2.1]` **FPGA 产品线 13.16 亿（33.0%）** —— FPGA 子产品稳健增长，PSoC 大幅增长，FPAI 新拓客户
- `[fact-A2.2]` 安全与识别 8.55 亿（21.5%）—— NFC + 智能卡 + 智能识别设备芯片
- `[fact-A2.3]` 非挥发存储 10.42 亿（26.2%）—— 其中**高可靠存储器 6.81 亿（占存储 65.4%）**
- `[fact-A2.4]` 智能电表 MCU 5.18 亿（13.0%）—— 单相 MCU 国内市占率 **>60%**；汽车 MCU 年销 2,000 万颗+

### A3. FPGA + 卫星通信明文应用
- `[fact-A3.1]` **公司明文："FPGA 子系列产品广泛应用于工业控制、测试测量、电力能源、消费电子、音视频、人工智能、卫星通信以及高可靠等领域"** —— 卫星通信场景
- `[fact-A3.2]` **国内首款亿门级和十亿门级 FPGA + 国内首颗 2.5D 封装超大规模 FPGA + 国内首款亿门级 PSoC + 国内首款 FPAI** —— 多项国内首发
- `[fact-A3.3]` **公司是 RF-FPGA 单片架构的"首创单位"** 和"目前国内该类产品的主要供货商" —— 卫星射频前端核心 FPGA
- `[fact-A3.4]` 2025 完成 1xnm FPGA / RF-FPGA / RFSoC 三款流片 + 可靠性验证 —— **唯一 1xnm 节点的国产 FPGA**
- `[fact-A3.5]` 谱系：逻辑资源 50K-4000K、算力 4TOPS-128TOPS（FPAI 32TOPS 推广良好、8/128TOPS 验证中）
- `[fact-A3.6]` 高可靠存储器（NOR/NAND/EEPROM 高可靠版本）—— 卫星电子+航天关键备份元器件

### A4. 客户/供应链
- `[fact-A4.1]` 前 5 客户合计 11.72 亿（**占 29.42%**，无关联方）—— 客户中度集中（vs 紫光 45%）
- `[fact-A4.2]` 前 5 供应商 8.09 亿（**占 54.18%**，无关联方）—— 供应商高度集中（晶圆代工依赖）
- `[fact-A4.3]` Fabless 模式 + A+H 上市公司（也在港股上市）

## 叙事主线

因为「FPGA 主业受益高可靠+卫星通信领域需求 + PSoC/FPAI 谱系扩张持续放量（同时业绩高质量增长）」+「但消费/中低端物联网/智能卡市场承压，毛利率被价格战压低 + 高研发投入难以缩减」+「全行业 NOR Flash 价格下行 + 智能电表替换周期下降」→ 所以「营收 +10.92% / 净利 -59.42% / 毛利率压力 / 研发人员 -12.1%」**典型"营收增但利润崩+主动收缩研发以止血"**信号；现金流 +7.06% + 经营现金/净利 338% 反向印证业务体质未坏，**只是定价权丢失**；对投资意味着：复旦微电是 **K1+K3 间接受益方**（FPGA + 高可靠存储是卫星电子刚需），但 **K5 强反向**（业绩深谷且利润弹性还未恢复），相比紫光国微利润+21.86% 形成"FPGA 双雄一兴一损"对比；估值底要看 2026Q1/Q2 毛利率是否触底反弹。

## 反常识/分歧点

1. **市场共识：FPGA 国产化双雄都吃肉** → 本文表明：紫光特种 IC +24.63%，复旦微电营收 +10.92% 但**净利-59.42%** → "FPGA 双雄分化"（紫光在特种领域、复旦微电在工业+卫星通信民用，价格敏感性差异巨大）
2. **市场共识：26.88% 研发投入比是利好** → 本文表明：**研发人员主动 -12.1%、资本化研发 -58.85%** —— 公司在收缩研发以保利润，**释放"不能再亏"信号**
3. **市场共识：高可靠存储是航天概念股 narrative** → 本文表明：**高可靠存储 6.81 亿，占存储 65.4%，已是公司核心业务** —— 不是 narrative，是基本盘
4. **市场共识：净利-59% 必有重大问题** → 本文表明：经营现金流 +7.06% / 现金/净利 338% / 主要客户应收 + 智能电表周期影响 → **业务正常，是利润表受 NOR 价格 + 智能卡价格 + 行业去库存周期共同压制**
5. **市场共识：1xnm FPGA 是未来 2-3 年的事** → 本文表明：**2025 三款 1xnm 产品（FPGA+RF-FPGA+RFSoC）流片+测试+可靠性验证完成**，2026 客户端导入 —— **比预期早一年**
