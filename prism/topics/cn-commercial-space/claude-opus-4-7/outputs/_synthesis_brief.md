## K# 调整明细

### K1 蓝箭朱雀三号 Q2 + Q4 回收试验是否成功（强度方向变化：维持中性）

- v0：成 → +2；败 → -1
- **v1 调整**：已确认 H1 遥二箭再回收试验时间窗 + Q4 首次复用飞行计划 ([ws-K2] mat-eaf0a9 / mat-e4f149)；新增证据 2026-06-20 一级动力系统试车成功 [mat-64bfd6]
- **v1 强度**：维持原判断，但路径风险已**部分被价格 in**（电科蓝天 4 天失守千亿后蓝箭概念股已有调整）
- **关键 mat_id**：ws-aggregate-K2 / mat-64bfd6 / mat-eaf0a9 / mat-bc316e
- **校准**：朱雀三号一子级是天鹊-12A（不是 12B）[mat-e4f149]

### K2 千帆星座 2026-09 在轨 ≥250 颗（强度方向变化：明显恶化）

- v0：<200 → ITU 风险被定价板块杀；≥300 → 反方暂时被推翻
- **v1 调整**：**ITU 校准后时间表是 2026 底 648 颗（不是原 baseline 2027 底）**，缺口 83% [ws-K1] mat-dfb26b
- 当前在轨 108 颗，要达 2026 底 648 颗，需 2026 全年再发 540 颗——按"招标投标方<3 家"的供给瓶颈实证 [mat-dfb26b]，几乎不可能
- **v1 强度**：K2 已从"待验证"切到"高概率不达标"——已成为 **最大未定价空头**
- **关键 mat_id**：ws-aggregate-K1 / mat-dfb26b / mat-f2592e

### K3 长征十号乙 2026-04-28 海上回收（强度方向变化：维持中性偏空）

- v0：成 → 央企可回收破局；
- **v1 状态**：截至 v1 generated（2026-05-26）已是月余前事件，但 84 份 web-search 中**未直接命中"已验证成功 + 已常态化"**——属于"做了一次性试验"性质
- **v1 强度**：央企可回收节奏"小步快跑"，K3 短期催化已耗散；2027 才能进入常态化海上回收发射
- **关键 mat_id**：ws-aggregate-K2 / mat-585b04 / mat-4d1a1b

### K4 2026 年内第二家民营火箭企业完成入轨级回收尝试（强度方向变化：恶化）

- v0：0 家 → -1；≥1 家 → +2
- **v1 调整**：2026-04-03 天龙三号首飞失利 [mat-76de31]，归零整改至少 6-12 个月；双曲线三号 2026 年底首飞但回收时间未明 [mat-e9b0cd]；星河智神星一号 2026 入轨首飞但回收未确定
- **v1 强度**：2026 年内第二家民营完成入轨级回收尝试**概率 <30%**，K4 已从"机会"切到"风险"
- **关键 mat_id**：ws-aggregate-K2 / mat-76de31 / mat-e9b0cd / mat-fbb183

### K5 H1 主流 A 股标的商业航天业务收入 yoy 是否 >100%（强度方向变化：分化加剧）

- v0：<50% → 反方加重；>150% → 业绩兑现确认
- **v1 调整**：6 家核心标的中（航天电器 / 中国卫星 / 海格 / 国博 / 上海瀚讯 / 铖昌）：
  - **铖昌 H1 +180.16% 扭亏** [mat-efd82e] → 已达 ">150%"标准（业绩兑现确认）
  - **航天电器 H1 订单 +200% + 商业航天占比 24% → 35%** [mat-fdfe8f] → 订单端确认，收入端待 H1 中报验证
  - **上海瀚讯营收 +42.23%** [mat-1f63e8] → 介于 50-100%
  - **中国卫星营收 +18.35% / 净利率 0.58%** [mat-79b7be / mat-d5722c] → 量增价滞
  - **海格通信营收 -10.81% / 亏 7.86 亿** [mat-e04cbf] → "<50%"标准，反方加重
  - **国博营收 -7.92%** [mat-91477b] → 反方加重
- **v1 强度**：K5 分化为 **2:4**——2 家业绩兑现 + 4 家业绩证伪。整体属于**中性偏空（4:6）**
- **关键 mat_id**：ws-aggregate-K5 / mat-efd82e / mat-fdfe8f / mat-79b7be / mat-e04cbf / mat-91477b

### K6 蓝箭航天 IPO 是否 2026 内完成（强度方向变化：维持中性偏多）

- v0：完成且发行 PE >120x → 板块情绪重燃；流产 → 系统性下杀
- **v1 调整**：2025-12-31 已受理 + 2026-01-22 进入问询阶段（22 天，快） [ws-K6] mat-786075；估值校准至 **207 亿（中金辅导）vs 凤凰 750 亿**（以中金为准）[mat-0aa9d5]；电科蓝天首日 +600% / 1145 亿 / 4 天失守千亿 [ws-K5] mat-4ca4c3 已设上限

- **关键 mat_id**：ws-aggregate-K6 / mat-0aa9d5 / mat-82bba0 / mat-c98dbf / mat-4ca4c3
