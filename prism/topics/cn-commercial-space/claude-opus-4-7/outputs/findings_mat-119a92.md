# 中国卫通 (SSE_601698) 2025 年报 finding — 央企卫星运营商「19 颗高轨卫星 + 国际业务被星链击穿」

## 核心数据点与事实

### A1. 财务画像：稳健微降 + 国际业务塌方 + 大额投资
- `[fact-A1.1]` **营收 26.45 亿元（+4.08% YoY）/ 归母净利 4.41 亿（-2.92% YoY）** — 类公用事业稳健
- `[fact-A1.2]` 总资产 **224.06 亿** / 归母净资产 159.88 亿 / **资产负债率仅 9.63%** — **极低杠杆**
- `[fact-A1.3]` 经营现金流 13.67 亿（-25.23%）/ **投资活动现金流 -25.02 亿（大幅卫星 capex）**
- `[fact-A1.4]` 财务费用 -1.63 亿（利息收入，**仍现金净流入 1.63 亿**）/ 研发费用 7,620 万（-4.71%，仅占营收 2.88%）
- `[fact-A1.5]` 毛利率：广播电视/卫星传输服务 29.45%（+1.75pp）— 主业毛利率回升
- `[fact-A1.6]` 研发投入合计 1.11 亿（4.19% 营收）/ 资本化研发 3,468 万 / **研发人员仅 128 人** —— 类公用事业型

### A2. 业务结构：境内 +8.85% 强势 / 境外 -10.64% 崩盘
- `[fact-A2.1]` **境内营收 20.89 亿（+8.85%）/ 毛利率 37.25%（+4.62pp）** —— 境内业务量价齐升
- `[fact-A2.2]` **境外营收 5.56 亿（-10.64%）/ 毛利率仅 0.16%（-12.32pp）** —— **几乎完全打不出毛利**
- `[fact-A2.3]` 公司明文："**全力克服星链对国际业务冲击影响以及传统业务下滑**" —— **直接承认 Starlink 击穿境外业务**
- `[fact-A2.4]` 折旧摊销占成本 67.94%（126.77 亿）—— **典型资本密集卫星运营商**
- `[fact-A2.5]` 主营单一：广播电视和卫星传输服务（无业务细分披露）

### A3. 卫星资源与生态布局
- `[fact-A3.1]` **截至 2025-12-31 拥有 19 颗在轨商用通信广播卫星**（C / Ku / Ka 频段）
- `[fact-A3.2]` **2025 发射中星 10R + 中星 9C** —— "十四五" 空间与地面资源建设主体任务圆满收官
- `[fact-A3.3]` "海星通"全球网覆盖 **>95% 海上航线**
- `[fact-A3.4]` 2025 业务进展：
  - 广电：9 省市 4K 节目上星 / 超高清行动计划
  - 行业：新签约近 5,000 个高通量接入点 + 1,000 个物联网接入点
  - 国际：**中星 26 落地老挝，高通量业务首次境外商业化运营**
  - 海空：50 个海上平台商用 VSAT；中标民航大学创新平台
  - 大众消费：约 1,000 个客户卫星车载服务；"卫星互联网网吧"
- `[fact-A3.5]` 升级为"中国航天科技集团卫星应用创新研究院"（央企集团技术总体）
- `[fact-A3.6]` 数字化 1+3 平台：数字化营销 + 多星统一测控 + 大波束综合服务 + 电信级宽带卫星运营平台

### A4. 客户/股权结构
- `[fact-A4.1]` 前 5 客户合计 10.60 亿（**占 40.07%**，无关联方）—— 中高集中度
- `[fact-A4.2]` 前 5 供应商 13.80 亿（**占 75.27%，关联方 51.73%**）—— **极度依赖关联方供应商**（航天科技集团下属卫星制造厂）
- `[fact-A4.3]` 母公司：**中国航天科技集团**（航天科技 / 航天科工系内三大上市平台）

### A5. 政策与竞争环境
- `[fact-A5.1]` 公司援引：2025-03 政府工作报告"商业航天从'培育'升级为'推动'"；2025-08 工信部《关于优化业务准入促进卫星通信产业发展的指导意见》—— **2030 目标 1,000 万卫星通信用户**
- `[fact-A5.2]` 国家航天局 2025-11 发布《推进商业航天高质量安全发展行动计划（2025-2027 年）》
- `[fact-A5.3]` 公司业务现状：高轨通信广播为主，低轨卫星互联网建设步入快车道但**公司尚未自营低轨星座**

## 叙事主线

因为「境内主业（广电 + 行业接入）量价齐升 +8.85%、毛利率回升 +4.62pp」+「但境外业务被星链 Starlink 击穿，营收 -10.64%、毛利率 0.16%（几乎不盈利）」+「19 颗高轨卫星折旧摊销占成本 67.94% + 2025 仍在持续高 capex（投资活动 -25 亿）」+「低杠杆 + 国资背景 + 政策三重共振」→ 所以「营收 +4.08% / 净利 -2.92% / 类公用事业稳健 + 国际业务塌方」**典型"稳态运营 + 海外业务被颠覆"**信号；公司处于"高轨运营商 vs 低轨星座（千帆 / GW / 鸿鹄）"的战略尴尬位置（中国卫通体系内**没有自营低轨星座**，可能成为低轨星座地面站集成的合作方）；对投资意味着：中国卫通是 **K1+K4 间接受益方**（卫星通信用户 2030 千万级政策红利）但 **K5 反向**（国际业务塌方 + 缺乏低轨星座所有权），适合作为高股息防御性配置而非成长性配置。

## 反常识/分歧点

1. **市场共识：中国卫通是卫星互联网受益方** → 本文表明：**公司体系内没有自营低轨星座**，定位高轨广播电视传输运营商；千帆/GW/鸿鹄是其他主体 → **卫星互联网概念股错配**
2. **市场共识：Starlink 对中国影响有限** → 本文表明：**中国卫通境外业务 -10.64%，毛利率塌至 0.16%** —— **Starlink 直接打穿"一带一路"国际业务**
3. **市场共识：央企卫星运营盈利稳定** → 本文表明：**主业 -2.92%，研发投入仅 4.19%（远低于 IC/装备业 20-27%）** —— 资本密集 + 折旧 67.94% 决定增长曲线扁平
4. **市场共识：A 股商业航天概念股估值贵** → 本文表明：中国卫通 PE 约 30 + 折旧后实际现金流回报较高 → 适合分红型估值
5. **市场共识：19 颗卫星 + 频轨资源是无形资产** → 本文表明：**关联方供应商占采购 51.73%**（卫星制造完全依赖航天科技集团），折旧 12.68 亿 → **资产端是国家投入，运营端是央企体系内利益分配**
