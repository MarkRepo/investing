# 西部超导 (SSE_688122) 2025 年报 finding — 钛合金 + 超导 + 高温合金「营收 52.26 亿 / 净利 8.39 亿 / 商业航天材料受益方」

## 核心数据点与事实

### A1. 财务画像：营收 / 利润稳健 / 现金流大幅改善
- `[fact-A1.1]` **营收 52.26 亿元 / 归母净利 8.39 亿元** —— 体量大、利润稳健
- `[fact-A1.2]` **经营现金流 6.06 亿（+35.73% YoY，vs 上年 4.46 亿）** —— 现金流改善
- `[fact-A1.3]` 研发投入占营收 **7.49%（+0.07pp）** —— 中等强度
- `[fact-A1.4]` **前 5 客户合计 31.80 亿（占 60.85%）** —— 较高集中（航空军工主机厂）
- `[fact-A1.5]` 净利率 16.05%（远高于航发动力体系内毛利率 5-8%）

### A2. 业务结构：钛合金 + 超导 + 高温合金（航空航天关键材料）
- `[fact-A2.1]` 主营：**超导产品 + 高端钛合金材料 + 高性能高温合金材料**
- `[fact-A2.2]` 钛合金应用：**航空 / 航天 / 舰船 / 兵器** —— 服役安全性寿命要求"十分苛刻"的高端钛合金
- `[fact-A2.3]` 高温合金应用：**航空航天发动机 / 燃气轮机 600-1200℃ 热端部件**（燃烧室、燃烧室隔板、涡轮盘、高温部件）
- `[fact-A2.4]` 高温合金"已通过**航空发动机 + 航天型号等多用户产品认证，产能和出货量增长迅速**" —— 商业航天关键材料受益
- `[fact-A2.5]` 超导产品：MRI / 加速器 / 受控核聚变（ITER）等高端应用

### A3. 商业航天关键材料突破
- `[fact-A3.1]` 航空航天**紧固件用 Ti45Nb、TC16 钛合金丝材**实现国产化 —— 高端连接件突破
- `[fact-A3.2]` 高温合金通过"航天型号等多用户产品认证" —— 火箭发动机 / 卫星推进系统材料
- `[fact-A3.3]` 公司是"**航空发动机 + 航天型号 + 兵器舰船 + 生物医疗 + 核工业**"多领域材料供应商

## 叙事主线

西部超导是高端金属新材料平台（钛合金 + 高温合金 + 超导），**2025 营收 52.26 亿 / 净利 8.39 亿 / 现金流 +35.73% 改善**；高温合金已通过"航空发动机 + 航天型号"双认证，**产能和出货量增长迅速**；钛合金材料用于航空 / 航天 / 舰船 / 兵器全谱；前 5 客户 60.85% 集中度反映航空主机厂深度绑定。对投资意味着：西部超导是 **K2+K3 强支持**的商业航天上游材料受益方（火箭发动机 + 卫星推进系统 + 火箭壳体），与光威复材碳纤维形成 **"金属材料 + 复合材料"** 双胞胎；估值需考察 2026 商业航天材料放量节奏。
