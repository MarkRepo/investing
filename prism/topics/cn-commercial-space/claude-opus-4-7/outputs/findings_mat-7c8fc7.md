# 电科蓝天 (SSE_688818) 2025 年报 finding — 宇航电源央企新上市，业绩稳健但增长平淡

## 核心数据点与事实

### A1. 财务画像：营收微增、利润微降的"宇航电源龙头平台型业绩"
- `[fact-A1.1]` 营收 32.86 亿元（**+5.10% YoY**） —— 平稳但缓慢增长
- `[fact-A1.2]` 营业利润 3.71 亿（**-0.80%**）/ **归母净利润 3.27 亿（-3.02%）** / **扣非归母 2.68 亿（-7.32%）**
- `[fact-A1.3]` 营业利润率约 **11.28%**（vs 中国卫星 0.27% / 航天电器 3.89% / 国博电子 22.68%）—— 中等水平
- `[fact-A1.4]` 总资产 77.60 亿（+6.64%），归母净资产 38.52 亿（**+9.66%**） —— 净资产增长 > 总资产增长（盈利留存增加）
- `[fact-A1.5]` 研发投入 2.17 亿（占营收 **6.62%**，同比 +0.20pp）—— 中等研发率
- `[fact-A1.6]` 公允价值变动收益 684 万（交易性金融资产理财收益）
- `[fact-A1.7]` 涉密披露豁免：按《军工企业对外融资特殊财务信息披露管理暂行办法》，部分客户名称 / 合同 / 产品信息**脱密处理** —— 真实业务结构有所遮盖

### A2. 业务结构：宇航电源（核心基石）+ 特种电源 + 新能源应用及服务
- `[fact-A2.1]` 主营 3 大领域：**宇航电源**（核心基石）+ **特种电源**（国防军工 / AGV 等民品）+ **新能源应用及服务**（微电网 / 储能 / 电源检测 / 锂钠电正极材料 / 消费类锂电）
- `[fact-A2.2]` 宇航电源："**国内少数具备宇航电源系统级整体解决方案能力的企业之一**"，覆盖载人航天 + 深空探测 + 北斗导航 + 低轨卫星星座 + 商业航天 + 太阳能无人机 + 飞艇等
- `[fact-A2.3]` 宇航电源 5 大核心产品：**宇航电源系统 + 空间太阳电池阵 + 空间锂离子电池组 + 电源控制设备 + 砷化镓外延片**
- `[fact-A2.4]` 砷化镓外延片：**实现外延片-砷化镓太阳电池-太阳电池阵-宇航电源系统的全产业链自主可控**——解决"卡脖子"问题
- `[fact-A2.5]` 特种电源：携行装备 / 特种车辆 / AGV 锂离子电池组（**国内 AGV 锂离子电池组重要供应商之一**）/ 燃料电池系统
- `[fact-A2.6]` 新能源应用：智能微电网（**南极秦岭站全绿电越冬**）+ 储能系统 EPC + 电源检测（CNAS+CMA+DIAC 等多重资质）+ 锂电正极/钠电正极/消费锂电
- `[fact-A2.7]` **2024 年以来主动收缩光伏 EPC 业务**："**为避免同业竞争风险**" → 母公司中国电科系内部业务整合

### A3. 技术突破：第五代空间锂离子电池 + 砷化镓 32% 转化效率
- `[fact-A3.1]` **第五代空间锂离子电池完成技术鉴定，综合性能达到同类国际领先水平**
- `[fact-A3.2]` **砷化镓三结太阳电池**：单体转化效率 **32%**，处于国际先进水平；2025 外延层厚度有效减薄，**迭代周期缩短，成本得以有效降低**
- `[fact-A3.3]` 启驻一体钠离子电池完成漠河、海拉尔**冬季测试** —— 极寒环境验证
- `[fact-A3.4]` 多能源协同互补微电网：**首次实现南极科考站（秦岭站）全绿电越冬**
- `[fact-A3.5]` 在研：低成本异质叠层太阳电池 / 低空飞行器动力电池 / 机器人电源 / 第三代半导体电源控制 / 宽温域无人机高比能电池 / 大功率脉冲电源
- `[fact-A3.6]` 中国化学与物理电源行业协会**理事长单位** —— 行业领导地位

### A4. 商业航天新进展：业务突破清晰但未量化收入
- `[fact-A4.1]` **2025 公司获得低轨通信、遥感等多个国内商业航天项目研制任务** —— 商业航天客户的初步开拓
- `[fact-A4.2]` 高安全无人车电池通过验收 → 无人车（含商业航天发射场配套）订单
- `[fact-A4.3]` 便携式高功率电池完成整机测试 → 为后续规模化推广奠定基础
- `[fact-A4.4]` 宽温域钠离子电池储能实现商业化运行 → 大规模储能场景验证
- `[fact-A4.5]` "公司积极拓展外部战略合作，**与国内商业卫星优质客户建立了长期稳定合作关系**" → 客户开拓但未量化
- `[fact-A4.6]` 公司明确："**商业航天的规模化发展将推动宇航电源产品向标准化、模块化、批量化制造方向发展，降本增效成为产业核心竞争力**" → 公司对自身角色认知清晰

### A5. 政策环境（K4 直接论据）
- `[fact-A5.1]` 公司引用："**2025 年 11 月，国家航天局印发《国家航天局推进商业航天高质量安全发展行动计划（2025—2027 年）》**" → 关键时点新增证据
- `[fact-A5.2]` "国家将航空航天产业纳入**'十五五'规划重点发展**的战略性新兴产业" → 政策定位再次强化
- `[fact-A5.3]` **2026 国防支出预算 1.94 万亿（+6.9%）** —— 国防开支持续高速增长
- `[fact-A5.4]` 国家发改委 + 国家能源局 2025 年 8 月《**新型储能规模化建设专项行动方案（2025-2027 年）**》—— 钠离子电池储能纳入新型储能商业化发展多元技术路线
- `[fact-A5.5]` 工信部 + 市场监管总局 2025 年 8 月《**电子信息制造业 2025-2026 年稳增长行动方案**》—— 卫星定位/导航/授时/遥感/通信协同发展

### A6. 战略：央企控股（中国电科）+ 军工"核心供应商"
- `[fact-A6.1]` 公司归属：**中国电科系（中国电子科技集团）** —— 与国博电子 mat-6da987 同属中国电科系
- `[fact-A6.2]` 子公司架构：**空间电源**（空间锂离子电池）+ **蓝天太阳**（砷化镓外延片 + 太阳电池阵）+ **天津恒电**（参股，与中国卫星共享） —— 全产业链覆盖
- `[fact-A6.3]` 资质：**通过 GJB9001 军工质量管理体系等多项军工资质体系认证** + 中国实验室认可委员会（CNAS）+ 中国国家认证认可监督管理委员会（CMA）+ 国防工业认可委员会（DIAC）
- `[fact-A6.4]` 战略定位："**电能源系统领域的技术引领者、产业推动者和生态构建者**"
- `[fact-A6.5]` 行业地位："**国内宇航电源的核心供应商**" + "**特种电源国产化替代的核心力量**"

## 叙事主线

因为「宇航电源主业（载人航天 + 深空探测 + 北斗 + 低轨卫星星座）持续配套，订单交付节奏稳定」+「特种电源国防军用平稳增长 + AGV 民用拓展」+「砷化镓 32% 转化效率 + 第五代空间锂离子电池技术鉴定保持国际领先」+「商业航天新订单获取（低轨通信/遥感项目）但规模尚小」+「2024 主动收缩光伏 EPC 业务以避免同业竞争」→ 所以「营收 +5.10% / 归母净利 -3.02% / 扣非 -7.32%」的**"宇航电源央企龙头平台型业绩"**画像，符合"高科创板 IPO 后平稳期"特征 → 对投资意味着：电科蓝天是**A 股宇航电源稀缺标的**（与国博电子并列中国电科系核心），**业绩"稳健但平淡"**，**真正的弹性需等卫星互联网卫星制造端真正放量**（千帆 + GW + 鸿鹄三大万星星座），**2027-2030 才可能进入业绩爆发期**；当前估值需从"科创板新股溢价"回归基本面，**长持 alpha 适合而非 short-term catalyst**。

## 反常识/分歧点

1. **市场共识：宇航电源央企龙头 = 商业航天高弹性受益方** → 本文表明：**营收仅 +5.10%、归母净利 -3.02%**，业绩弹性远低于市场预期；央企体系决定**业绩平稳但慢**
2. **市场共识：千帆星座组网放量 = 卫星电源订单大爆发** → 本文表明：公司仅称"获得低轨通信、遥感等**多个**国内商业航天项目研制任务"——**未量化收入贡献**，可能仍处于送样/小批量阶段
3. **市场共识：宇航电源是寡头垄断高利润业务** → 本文表明：营业利润率 11.28% 处于中等水平（vs 国博电子 22.68%）—— 寡头利润已被定价
4. **市场共识：电科蓝天 = "中国卫星 plus"** → 本文表明：电科蓝天是**电源专业户**（中国电科系），与中国卫星（航天科技集团系，卫星总装）不在同一产业链位置；**两者更应该是供应链关系而非同业**
5. **市场共识：科创板新股 IPO 估值高、业绩跟不上** → 本文表明：**电科蓝天业绩客观（净利 3.27 亿）+ 主营业务稳健 + 国家电网/南极科考等高门槛订单**，IPO 溢价**部分可由基本面支撑**
6. **市场共识：南极秦岭站全绿电是公关稿** → 本文表明：实证案例**多能源协同微电网首次实现南极科考站全绿电越冬** + 钠离子电池漠河/海拉尔冬季测试通过 —— **技术领先性确实存在**
