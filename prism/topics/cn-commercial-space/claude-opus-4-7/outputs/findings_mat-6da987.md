# 国博电子 (SSE_688375) 2025 年报 finding — 央企 T/R 组件龙头「营收下滑但利润稳健」

## 核心数据点与事实

### A1. 财务画像：营收下滑、利润微增、现金流大幅改善
- `[fact-A1.1]` 营收 23.86 亿元 (**-7.92% YoY**) —— **营收下滑**
- `[fact-A1.2]` 营业利润 5.41 亿 (+5.25%) / 利润总额 5.41 亿 (+5.17%) / **归母净利润 5.08 亿 (+4.72%)**
- `[fact-A1.3]` 扣非归母净利 4.93 亿 (+3.50%)，基本每股收益 0.85 元 (+4.94%)
- `[fact-A1.4]` 营业成本 13.82 亿（-13.16%）—— 成本降速 13.16% > 营收降速 7.92% → **隐含毛利率约 42.09%（vs 上年 38.59%，+3.5pp）**
- `[fact-A1.5]` **经营活动现金流 +8.89 亿（+226.99%）**—— vs 上年 +2.72 亿，现金流大幅改善
- `[fact-A1.6]` 投资活动现金流 **-4.92 亿（去年 +6.92 亿，逆转 811%）**—— 大幅投入产能 / 资产
- `[fact-A1.7]` 总资产 85.58 亿（+7.04%），归母所有者权益 64.66 亿（+4.52%），归母每股净资产 10.85 元（+4.53%）
- `[fact-A1.8]` 销售费用 +50.18% —— 市场拓展激进（vs 营收 -7.92%）

### A2. 业务结构：T/R 组件 + 射频芯片 + 射频模块三线
- `[fact-A2.1]` 主业：**有源相控阵 T/R 组件 + 射频集成电路（基站 PA + 终端模组 + 卫星通信射频）** + **GaN 射频模块（4G/5G 基站）**
- `[fact-A2.2]` **关键披露**："在低轨卫星和商业航天领域，多款 T/R 组件产品已批量交付客户，**成为公司 2025 年度的主要收入来源之一**" → 商业航天已是主驱动力之一
- `[fact-A2.3]` GaN 射频模块业务："**5G、5G-A、U6G 基站和终端应用**" + "Massive MIMO 通道数进一步增加，单站射频集成电路用量激增" → 5G/6G 持续放量
- `[fact-A2.4]` "宏站/小站/皮站**全面氮化镓化**" → 公司 GaN 业务的长期增长驱动
- `[fact-A2.5]` 经营模式：T/R 组件 = **IDM 模式**（设计+制造+测试）；射频芯片 = Fabless 模式

### A3. 技术突破：硅基氮化镓功放业内首次终端量产
- `[fact-A3.1]` **公司自研硅基氮化镓功放芯片，与国内头部终端厂商共同研发，业内首次实现硅基氮化镓功放在终端射频领域的量产交付** → 工艺突破
- `[fact-A3.2]` 技术体系：**化合物半导体为核心**（GaN + GaAs + 硅基），覆盖 Si / GaAs / GaN 三代半导体射频 IC
- `[fact-A3.3]` 终端市场：射频开关 / 天线调谐器 / WIFI 模组 / 终端模组（华为/中兴/小米类）已批量供货
- `[fact-A3.4]` **关键技术：三维高密度异构异质集成 + W 波段产品谱系（毫米波）** → 集成度跨越
- `[fact-A3.5]` 累计获各类知识产权 208 项（发明专利 60 项 + 实用新型 38 项 + 集成电路布图 101 项 + 软著 9 项）

### A4. 研发：投入持平 + 完全费用化
- `[fact-A4.1]` 研发投入 3.03 亿（占营收 **12.69%**）—— 同比 **-7.39%**（与营收 -7.92% 同步收缩）
- `[fact-A4.2]` **资本化率 0%**（完全费用化）—— 会计极保守，**与中国卫星 72.56% 形成对照**
- `[fact-A4.3]` 研发人员 **466 人（同比 +53 人，+12.83%）**，占总人数 26.24%（+2.81pp）—— **逆周期招人**（vs 航天电器 -348 人）
- `[fact-A4.4]` 学历结构：博士 13 + 硕士 238 + 本科 172 → 硕博占研发人员 53.86%
- `[fact-A4.5]` 30 岁以下 257 人（占研发 55.15%），30-40 岁 174 人，**40 岁以上仅 30 人（6.44%）**—— 团队极度年轻
- `[fact-A4.6]` 在研重点项目：5G-A/6G 高效高线性射频前端模组 + **基于国产半导体工艺的毫米波核心技术（总投资 5.93 亿）** + 下一代探测和通信用高频收发前端 + 微波毫米波高密度集成工艺
- `[fact-A4.7]` 4 个在研项目累计投资 4.19 亿（占研发当年 138%）—— **多年滚动投入**，未来折旧/摊销压力会显现

### A5. 客户/风险：客户集中 + 美国实体清单
- `[fact-A5.1]` 客户集中度：年报未直接给前 5 客户百分比，但风险段明文 "客户相对集中"（**主要为科研院所或整机单位、国内主流移动通信设备制造商**）
- `[fact-A5.2]` **公司被列入美国"实体清单"**（自 2018 年 8 月）→ 采购美国生产原材料 + 含有美国技术的 IP 和工具受限
- `[fact-A5.3]` "**整机单位 T/R 组件采购模式由对外采购变更为内部配套的风险**" —— 公司明文承认是关键风险：整机厂商可能由"外采"转"内部配套"，影响 T/R 组件业务（核心收入）
- `[fact-A5.4]` 风险段 9 大类（核心竞争力 + 经营 + 财务 + 行业 + 宏观 + 实体清单 + 税收优惠 + 管理 + 募投/折旧）—— **披露详尽**
- `[fact-A5.5]` 产品销售存在"**审价机制**"（暂定价 + 后置补价）→ 收入和毛利率有未来集中确认价差风险

### A6. 战略：从 Fabless 向"Fabless + IDM 双模式"转型
- `[fact-A6.1]` T/R 组件 IDM 模式 + 射频芯片 Fabless 模式 —— **产业链垂直整合度**比纯 Fabless（如铖昌）更高
- `[fact-A6.2]` 募集资金投资项目：**射频芯片和组件产业化项目**（重大资本支出，未来折旧/摊销将显著增加）
- `[fact-A6.3]` 重点发力领域：**5G/5G-A/6G 基站 + 终端 + 卫星互联网 + 6G 空天地海一体化** —— 主线是移动通信，商业航天为重要扩展
- `[fact-A6.4]` 公司获多项荣誉："2023-2024 年度射频芯片市场最佳产品奖" + "2025 科创板价值 50 强" + 多家主流通信设备商"最佳交付奖"和"最佳合作奖"

### A7. 资本结构与基本面
- `[fact-A7.1]` 总资产 85.58 亿 / 归母净资产 64.66 亿 → 资产负债率约 24.4%（健康）
- `[fact-A7.2]` 营业利润率约 22.68%（5.41 亿 / 23.86 亿）—— vs 铖昌 28.93% / 航天电器 3.89% / 中国卫星 0.27%（央企 T/R 龙头水平）
- `[fact-A7.3]` ROE 隐含约 7.85%（5.08 亿 / 64.66 亿）—— 央企 + 实体清单限制下的中等水平
- `[fact-A7.4]` 财务费用 -1487 万（vs 上年 -2276 万，利息收入显著下降）—— 货币资金可能已开始消耗

## 叙事主线

因为「主业基础（移动通信基站 PA / 终端模组）受 5G 资本开支放缓影响下滑」+「但低轨卫星和商业航天 T/R 组件批量交付（2025 主要收入来源之一）+ 硅基氮化镓功放业内首次量产」+「公司在压成本（毛利率 +3.5pp）+ 现金流大幅改善（+227%）」→ 所以呈现「营收 -7.92% / 净利 +4.72%」的**"业务洗牌期"画像**，新业务（卫星 + 6G + 硅基氮化镓）爬坡填补老业务（4G/5G）下滑 → 对投资意味着：国博电子是**商业航天 T/R 组件赛道的央企龙头**，业绩"稳健但平淡"，**真正的弹性需等卫星互联网订单 ramp + 6G 终端突破**，估值适合长持基本盘投资者，但 12-18 个月 short-term catalyst 有限。

## 反常识/分歧点

1. **市场共识：国博电子受益商业航天 → 营收会爆发增长** → 本文表明：**营收 -7.92%**，但利润 +4.72%；商业航天是"主要收入来源之一"但**老 4G/5G 业务下滑被其填补**
2. **市场共识：央企 T/R 组件龙头一般业绩稳健、增长慢** → 本文表明：经营现金流 +227% + 在研项目持续投资 +12.83% 招人 → **现金流和团队动能比账面增长更强**
3. **市场共识：硅基氮化镓功放是 6G 概念股逻辑** → 本文表明：**业内首次终端量产交付**（业绩已经在 2025 兑现），不是概念
4. **市场共识：国博电子 vs 铖昌科技 - 央企 vs 民营对比简单** → 本文表明：**国博营收 23.86 亿 / 净利 5.08 亿 / 毛利率 42%** vs **铖昌营收 4.05 亿 / 净利 1.17 亿 / 毛利率 73%** → 完全不同的赛道（基站 + 通信 vs 雷达 + 卫星专用）+ **国博体量大但成长性弱、铖昌体量小但成长性强**
5. **市场共识：被列入美国实体清单意味着供应链卡脖子** → 本文表明：公司已基本实现国产化（化合物半导体核心 + 多个在研国产工艺项目），实体清单影响**部分外采美系工具/IP** 但不是生死问题
