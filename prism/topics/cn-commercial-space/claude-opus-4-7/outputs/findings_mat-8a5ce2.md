# 中国卫星 (SSE_600118) 2025 年报 finding — 央企卫星总装厂的「政策利好 vs 业绩兑现」剪刀差

## 核心数据点与事实

### A1. 财务画像：增收不增利，毛利率历史新低
- `[fact-A1.1]` 2025 营收 61.03 亿元 (+18.35% YoY)，归母净利润 0.36 亿元 (+27.38% YoY)
- `[fact-A1.2]` **净利率 0.58%**（归母 0.36 亿 / 营收 61.03 亿）—— 央企平台典型"打不透水"
- `[fact-A1.3]` **综合毛利率 8.23%（-2.88pp YoY），创近年新低**；营业成本 +22.29% > 营收 +18.35%（**剪刀差恶化**）
- `[fact-A1.4]` 公司在 MD&A 中**自述毛利率下降原因**："本期宇航部组件产品交付量显著增加，但**交付增量是以毛利率较低的商业航天产品为主**" → 直接说明**商业航天对央企不是利润提升器，反而是利润压制器**
- `[fact-A1.5]` 经营活动现金流 +3.63 亿（上年 -3.17 亿，回正） vs 投资活动 -7.63 亿（主要为新增三个月以上定期存款）→ 自由现金流大幅留存而非再投资

### A2. 产能投放：实际为 0，与"批产化"叙事矛盾
- `[fact-A2.1]` **在建工程从 0.14 亿降至 0（-100%）** → 公司本期没有任何新产能在建
- `[fact-A2.2]` 总资产 132.01 亿（YoY -0.27%）→ 资产规模**停滞**
- `[fact-A2.3]` 固定资产仅 9.20 亿（占总资产 6.97%）→ 轻资产，与"卫星总装厂"惯常想象冲突
- `[fact-A2.4]` 合同资产 22.42 亿（YoY -26.66%）→ 订单交付加快但**没用增加新订单储备的形式呈现**
- `[fact-A2.5]` 全年发射小/微小卫星 **11 颗**（含张衡一号 02 星等）+ 完成 ~160 万片空间太阳电池交付配套数百颗星船 → 当年发射节奏并不快

### A3. 研发：金额低 + 资本化率反常高
- `[fact-A3.1]` 研发投入 3.78 亿（占营收 **6.19%**）—— 对照 SpaceX 年研发数十亿美元，**完全不在同一量级**
- `[fact-A3.2]` **研发资本化率 72.56%**（费用化 1.04 亿 / 资本化 2.74 亿） → 行业正常 30-40%，72.56% 严重偏高，**美化利润嫌疑大**：若按 30% 资本化重算，归母净利润可能由 +0.36 亿变为亏损
- `[fact-A3.3]` 费用化研发同比 **-8.79%** → 研发投入实际收缩
- `[fact-A3.4]` 研发人员 1193 人（占员工 38.42%），博士 111 + 硕士 664（学历占研发人员 65%），但 30-40 岁占 60.2% → 团队偏年轻，骨干结构存在断层风险

### A4. 客户/供应链：极度集中，关联交易占比高
- `[fact-A4.1]` **前五客户销售额 49.13 亿，占年度销售 80.50%**（其中关联方 23.61 亿 = **38.69%**）
- `[fact-A4.2]` 前五供应商采购额 25.05 亿，占年度采购 50.36%（关联方 12.13 亿 = 24.38%）
- `[fact-A4.3]` 风险因素第 1 条公司自述："**主要用户调整采购定价政策和具体采购策略，也将对公司的经营业绩产生重大影响**" → 公司承认对单一大客户高度依赖
- `[fact-A4.4]` 母公司中国航天科技集团（空间院）持股 51%+，"通过选举董事或行使股东会投票表决权对人事任免、经营决策、投资方向等重大事项施加较大影响"

### A5. 业务结构：宇航制造 + 卫星应用一个分行业，无产品级拆解
- `[fact-A5.1]` 主营业务分行业**只有"宇航制造及卫星应用"一个 line**（营收 60.47 亿，毛利率 8.23%） → **看不到分产品（卫星整机 vs 部组件 vs 终端 vs 服务）的利润结构**
- `[fact-A5.2]` 分地区：华北 56.41 亿（**93.3%**） / 华南 2.15 亿 / 西北 1.37 亿 → 业务高度依赖北京/天津地区客户（航天科技集团本部）
- `[fact-A5.3]` 子公司业绩分化：航天东方红净利 0.81 亿 / 航天恒星 0.59 亿 / 天津恒电 0.13 亿 / 星地恒通**亏 0.39 亿** / 深圳东方红**亏 1.04 亿**（业务转型订单减少）→ 利润集中在 2-3 家子公司

### A6. 政策环境（K4 直接论据）
- `[fact-A6.1]` 中国 2025 全年航天发射 **92 次创历史新高**
- `[fact-A6.2]` 2025 国家航天局**首次设立"商业航天司"**（一级行政架构变化）
- `[fact-A6.3]` 2025 国务院国防科工局 + 国家航天局发布《推进商业航天高质量安全发展行动计划 2025-2027》
- `[fact-A6.4]` **2026 政府工作报告：将"航空航天等新兴支柱产业"** + "加快发展卫星互联网"明确写入 → 政策定位从战略性新兴产业升级为**支柱产业**
- `[fact-A6.5]` 截至 2025 底，**国家卫星互联网星座 + 千帆星座各达在轨"百余颗"**（与本研究 baseline fact-04 中千帆 2026 底 648 颗目标对照，**当前进度仅 16%**）

### A7. 战略表述（指引未来）
- `[fact-A7.1]` "十五五"宇航制造定调："立足高质量发展要求，致力于巩固公司在小卫星研制领域的传统优势地位" → **守势思维**，而非进攻
- `[fact-A7.2]` 提出研发方向："低成本、短周期、高质量" + "智能卫星平台批产化" → 与商业航天降本压力一致
- `[fact-A7.3]` 主要研发投入项目："某安全应用研究"（北斗 + 能源安全应用）+ "某通信综合应用系统（一期）"（第三代通信装备）→ **军民两端布局，民用为主**

## 叙事主线

因为「宇航部组件产品 + 地面系统集成订单交付量同比增加（量起来）」+「商业航天产品 mix 上升（毛利率被压制）」+「研发资本化率 72.56% 美化报表」→ 所以 2025 业绩呈现「营收 +18.35% / 归母净利 +27.38%」的弱增长画像，**但实际净利率仅 0.58%、毛利率 -2.88pp 创新低**；同期**总资产停滞、在建工程归零、研发实际投入收缩** → 对投资意味着：**中国卫星不是 "中国版 SpaceX"，是被千帆/卫星互联网概念错配定价的传统央企卫星制造商**，alpha 在政策面真实，业绩面 12-18 个月内难传导，主要受益方更可能是**专业组件厂商（铖昌/国博/航天电器/天银等专精特新）而非总装厂**。

## 反常识/分歧点

1. **市场共识：中国卫星是商业航天稀缺标的，受益低轨组网最大** → 本文表明：**商业航天产品反而压低毛利率（公司明文自述）**，组网放量对央企总装是"赔本赚吆喝"，**真正利润空间在元器件/部组件层**
2. **市场共识：央企卫星制造商批产化产能正在投放** → 本文表明：**在建工程为 0（-100%）+ 总资产 -0.27%**，公司没有任何新产能扩张，"批产化"是规划用语而非进行时
3. **市场共识：央企国家队卫星 R&D 强劲** → 本文表明：研发 3.78 亿 / 营收 6.19% / 资本化率 72.56% / 费用化研发同比 -8.79% → **实际研发支出萎缩，仅靠会计处理装好看**
4. **市场共识：国家队卫星总装厂是 alpha 龙头** → 本文表明：**前五客户占 80.5%，其中关联方占 38.69%**，定价权完全在母公司空间院手里，**公司盈利能力受集团内部转移定价支配**
