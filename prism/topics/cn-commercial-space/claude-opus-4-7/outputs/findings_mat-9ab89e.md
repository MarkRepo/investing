# 航天电器 (SZSE_002025) 2025 年报 finding — "订货历史新高"叙事下的业绩崩塌

## 核心数据点与事实

### A1. 财务画像：营收增、利润崩、现金流恶化的"三重剪刀差"
- `[fact-A1.1]` 营收 58.20 亿元 (+15.82% YoY)，但**归母净利润 1.83 亿元 (-47.32% YoY) / 净利润 2.35 亿元 (-41.77% YoY)**
- `[fact-A1.2]` **综合毛利率 30.04%（-7.95pp YoY）** —— 历史性大幅恶化
- `[fact-A1.3]` 营业成本 +30.36% > 营收 +15.82% → 成本端失控
- `[fact-A1.4]` 公司自述毛利率恶化原因："**贵金属材料价格上涨** + **部分产品价格下降** + **2021 年定增募投项目转固后折旧费用增长**" → 三个原因都是趋势性的，不是一次性
- `[fact-A1.5]` **经营活动现金流 -6.14 亿（vs 上年 -2.59 亿，恶化 137.21%）** —— "订货创历史新高，为保障交付公司生产物料采购及外协外购结算支付的现金相应增加"
- `[fact-A1.6]` **现金及现金等价物净增加 -13.21 亿**（大幅净流出）—— 货币资金从 27.73 亿降至 15.42 亿（占总资产 23.21% → 13.18%）

### A2. 业务结构：电机爆发，连接器/光通信疲软
- `[fact-A2.1]` 分产品：连接器 39.84 亿（68.46%，+17.59%，毛利率 29.07% **-9.61pp**）/ 电机 13.58 亿（23.33%，+21.65%，毛利率 30.67% -4.94pp）/ 继电器 2.40 亿（4.13%，**-3.27%**，毛利率 **44.88%**）/ 光通信 1.32 亿（2.27%，**-8.97%**）
- `[fact-A2.2]` **电机销售量 +35.46%、生产量 +36.33%、库存 +38.18%** → 防务 + 民用电机爆发增长，备货激进
- `[fact-A2.3]` 连接器销售量仅 +8.81%（量 < 价：14.6% 价提，但毛利率 -9.61pp 说明结构性降价）
- `[fact-A2.4]` 光通信库存激增 +82.87% → 备货 / 滞销悬念，需后续观察
- `[fact-A2.5]` 分地区均衡：华北 27.58% / 华东 21.33% / 中南 18.50% / 西北 13.70% → 客户分布优于中国卫星（华北 93.3%）

### A3. 研发：投入收缩 + 资本化率 0%（与中国卫星 72.56% 反向）
- `[fact-A3.1]` 研发投入 7.38 亿（占营收 **12.68%**）—— 同比 **-1.75%**（**实际收缩**）
- `[fact-A3.2]` **研发资本化率 0%**（vs 中国卫星 72.56%）—— 完全费用化，会计极度保守 → 真实研发投入可信度高
- `[fact-A3.3]` 研发人员 1895 人（占 32.64%），**同比 -15.51%（主动裁员 348 人）** —— "适度控制用工总数，提升公司运营效能"
- `[fact-A3.4]` 30 岁以下研发员从 1149 降至 893（-22.28%）+ 40 岁以上从 257 升至 276（+7.39%）→ 年轻骨干快速流失，**显示真正的人才流失风险**
- `[fact-A3.5]` 重点项目：液冷互连、高速背板连接器、毛纽扣集成互连、光背板布线、深海电机、伺服/高速/空心杯电机 → 与 AI 数据中心 + 商业航天双线布局

### A4. 客户/供应链：相对分散，关联方占比相对低
- `[fact-A4.1]` 前五客户 28.61 亿（占 49.17%）—— 比中国卫星 80.50% 更分散，但**第一大客户 12.26 亿 (21.07%) = 中国航天科工集团下属企业（关联方）**
- `[fact-A4.2]` 前五供应商 4.45 亿（仅占 10.29%，无关联方）—— 供应链非常分散，议价较弱（贵金属上涨直接传导成本）
- `[fact-A4.3]` 主要子公司：苏州华旃（连接器）营收 17.44 亿（+15.89%），**净利 1793 万 (-73.28%)** → 子公司利润同样腰斩
- `[fact-A4.4]` 贵州林泉电机营收 12.60 亿 (+21.16%)，**净利 8338 万 (+0.47%)** → 电机子公司利润稳定但增长几乎为 0

### A5. 战略：从"单一元器件"向"互连一体化 + 驱动控制解决方案"转型
- `[fact-A5.1]` 公司提出 **"2+N"（大互连、大电机 + 专精特新）产业战略** —— 加速从元器件向组件/系统解决方案升级
- `[fact-A5.2]` 商业航天明确列入 **战新产业重点布局**（与 AI 算力 + 信创 + 海洋装备 + 通用飞行器并列）
- `[fact-A5.3]` 2025 下半年组织架构调整："压缩管理层级，构建高效、扁平化、穿透式组织架构" → 公司本身在压成本
- `[fact-A5.4]` "2026 政府工作报告：将航空航天、低空经济等战略性新兴产业集群发展" → 公司年报多次援引，作为业务驱动力定位

### A6. 在建工程 +157% — 唯一的逆周期信号
- `[fact-A6.1]` **在建工程 1.32 亿（+157%，从 0.51 → 1.32 亿）** —— vs 中国卫星在建工程归零，**航天电器在投钱扩产**
- `[fact-A6.2]` 应收账款 35.04 亿（占总资产 29.96%）— 几乎无变化（YoY -2.0%），账款管理可控
- `[fact-A6.3]` 存货 24.91 亿（占 21.29%，+34.6% YoY）—— "为保障及时交付订单生产所需物料储备" + "客户产品验收周期延长"
- `[fact-A6.4]` 财务费用 -377 万（vs 上年 -1837 万，**利息收入大幅减少 79.43%**）—— 货币资金大幅消耗

### A7. 重要披露：连接器/电机配套商业航天 是真正的"卖铲人"逻辑
- `[fact-A7.1]` 业务覆盖明确包含商业航天，但**不是收入主驱动力**——主驱动力是防务（第一大客户航天科工）+ AI 数据中心（光模块 + 液冷连接器 + 高速背板）
- `[fact-A7.2]` 公司视角："新能源、商业航天、量子科技、人工智能等新兴领域正通过技术突破和产业协同形成新的规模化需求" → 业务多元化降低单一商业航天暴露度

## 叙事主线

因为「订货创历史新高 + 防务装备订单交付集中（电机爆发 +35%）」+「贵金属材料涨价 + 部分产品降价 + 定增募投项目折旧增加」→ 所以「营收 +15.82%、归母净利 -47.32%」的**经典"增收不增利"**画像，但**比中国卫星更糟**：经营现金流 -6.14 亿（vs 中国卫星 +3.63 亿），货币资金净流出 13.21 亿；研发支出反而**主动收缩**（-1.75%）+ 研发人员**裁 348 人**（-15.51%） → 对投资意味着：航天电器是商业航天概念的**真"卖铲人"但定价权弱**，处于产业链中游被两头夹（上游贵金属涨价 + 下游降价），**业绩兑现节奏可能在 2026 持续走弱**，配置应等待毛利率 stabilize 信号或贵金属周期反转。

## 反常识/分歧点

1. **市场共识："订货创历史新高" = 业绩向好** → 本文表明：订货高+生产物料采购激增 = 现金流恶化 137%，本期净利润反而 **-47.32%**
2. **市场共识：商业航天受益方是头部元器件厂商如航天电器** → 本文表明：主营业务确实覆盖商业航天，但**真正驱动收入的是数据中心 + 防务 + 新能源汽车**，商业航天权重很小；商业航天概念股 valuation 上来但业绩未传导
3. **市场共识：央企/国资背景科技公司研发投入持续加码** → 本文表明：**研发人员主动 -15.51%、研发投入 -1.75%、研发资本化率 0%** —— 公司在压成本，与中国卫星 72.56% 资本化美化报表形成鲜明对照
4. **市场共识：在建工程归零意味着产能停滞** → 本文表明：**在建工程从 0.51 → 1.32 亿（+157%）** —— 航天电器是少数仍在产能投放的标的（vs 中国卫星 -100%）
