## 三、产业链 / 竞争格局认知

### 产业链分层
```
上游：原材料 + 元器件 + 芯片
  - T/R 芯片：铖昌科技、国博电子、臻镭科技
  - 宇航 FPGA：复旦微电、紫光国微
  - 滤波器/波导：灿勤科技、盛路通信
  - 高温合金/复材：航天彩虹 / 钢研高纳
  - 连接器/线缆：航天电器、航天电子

中游：卫星制造 + 火箭制造
  - 卫星：中国卫星（国家队） / 银河航天 / 格思航天 / 时空道宇 / 微纳星空（民营）
  - 火箭：长征系列（国家队） / 蓝箭 / 星河 / 天兵 / 中科宇航 / 东方空间（民营）

下游：发射服务 + 运营 + 应用
  - 发射场：文昌国际 / 海南商发 / 山东海阳东方港 / 酒泉 / 太原 / 西昌
  - 星座运营：垣信（千帆）、中国星网（GW）、时空道宇、银河航天
  - 卫星运营：中国卫通（高轨）
  - 终端 + 地面段：华为 / 海格通信 / 华力创通 / 上海瀚讯 / 信科移动
  - 应用：通信、导航、遥感、气象
```

### 三大竞争主线
1. **国家队 vs 民营**：长征/中国卫星份额还是占大头，民营在快速发射节奏、单星成本上突破。星座制造产能上民营贡献关键增量。
2. **火箭可回收赛跑**：朱雀三号、天龙三号、星河智神星、长征九号、长征十二号 —— 谁先成功复用决定 2027 后成本结构。当前**全部落后 SpaceX 约 5 年**。
3. **星座组网窗口**：ITU 频率保留 deadline 倒逼，2025-2028 必须完成关键节点（108/648/1296 颗千帆，类似 GW），否则丢频段。这是商业航天**最确定的需求驱动力**。

### 卡脖子环节
- **发射成本**：单 kg LEO 成本仍是 SpaceX 2-3 倍
- **发射节奏**：2024 年全国 68 次 vs 千帆+GW 测算每年需要 200-300 次发射才能完成组网 → 发射场+火箭产能瓶颈最实
- **可回收火箭**：训练截止时无一民营可回收火箭首飞成功
- **手机直连 / 海事终端商业化**：B/C 端需求未真正放量
