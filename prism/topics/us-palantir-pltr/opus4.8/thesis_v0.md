# thesis_v0 — Palantir Technologies (PLTR)

## 1. 核心 thesis（方向 + 强度）

> **伟大的公司，危险的股票。** 业务执行远超预期（增速 29%→85% 加速、美国营收 +104%、稀释近乎归零、Army $10B ELA），但现价 $134 仍对应 ~40x forward P/S / ~59x TTM，且已从 2025 末 ~$194 峰值回调 31%——**市场在基本面加速的同时压缩倍数**，这是去估值化的前沿。终局判定：**现价偏卖出 / 回避，持有者减仓；base 12 个月合理价 ~$100-115（低于现价与 $189.65 一致预期）。**

**强度评分：4/10**（对股票温和看空——非高信念做空，因业务质地极强、散户+指数被动流+beat-and-raise 节奏可延续动能；但风险回报在现价明显向下不对称）。

**估值方法裁决（我的职责）**：PLTR 是单一超高增长（40%+）、GAAP 盈利、Rule-of-40 ~135 的软件公司，不适用 SOTP（政府/商业同为软件订阅、无独立周期属性），采用**前瞻 P/S 情景带 + "几年长进倍数"交叉校验**：
- 现价 $310B / FY26 $7.65B = **40.5x forward P/S**；给一个仍属溢价的 **25-30x forward** 中枢，
- FY26 $7.65B × 25-30x = $191-230B → **$74-89/股**；FY27 ~$11B（假设 +45%）× 25-30x = $275-330B → **$107-128/股**。
- 即：即便给 FY27 一年后 30x 的富裕倍数，也仅 ~$128（约等于现价）。要有实质上行，需要**倍数维持 35-40x + 持续超预期**同时成立——这正是空头的不对称点。
- **base 目标 ~$105**（倍数向 25-30x forward 压缩）；bull ~$150（倍数守 35x+ 且持续 beat）；bear ~$70（任一季度增速破位 → 倍数塌向 15-20x）。

## 2. 支持理由（我现在最相信的依据）

1. **估值与增长的数学不对称**：$310B 市值需未来数年维持 50%+ 复合增长才能"长进"合理倍数；40-60x forward sales 的历史前瞻回报（即使业务成功）普遍偏低。倍数压缩是均值回归的默认路径。
2. **市场已在用脚投票**：Q1'26 交出 85% 增速 + 4 倍净利的 blowout，股价却仍较峰值 -31% 且未收复——说明估值重力已启动，好消息的边际定价能力在下降。
3. **一致预期在下修**：39 位分析师均值目标 $189.65，近 3 月**下修 2.08%**；虽仍高于现价，但方向是收敛而非扩张。
4. **增速必然减速**：85% 是"2020 上市以来最强"，属周期高点；FY26 指引隐含增速已低于 Q1，Street 模型对 2026 只给 ~41%（后被证明保守，但方向指向减速）。任何单季破位都会触发倍数重估。
5. **政府集中度 + 政治敞口两面性**：Army $10B ELA 与 $1.5T 国防预算是真利好，但 Pentagon 削减预算传闻已能压股价，DOGE 是双刃，政府营收对政治周期敏感。

## 3. 最大反方观点（诚实列出，非稻草人）

1. **AIP 是真·平台级拐点，不是炒作**：美国商业 +104%、NDR 150%、Rule-of-40 ~135、稀释停滞——这些是"赢家通吃平台"而非"故事股"的财务特征；若 AIP 成为企业 AI 落地的事实标准，$310B 可能只是中途。**这是我这个空头 thesis 最可能错的地方。**
2. **beat-and-raise 可自我延续**：Q1 超预期 + FY26 两次上调 + Q2 指引超一致预期——高增长公司在动能未破时，倍数可长期维持甚至扩张（参 NVDA 2023-2024）。做空高动能成长股的时机风险极高。
3. **稀释担忧已被证伪**：股数仅 +0.71% YoY，SBC 空头核心论据大幅削弱；GAAP 盈利 + 强 FCF（$4.2-4.4B）使"不赚钱"叙事失效。

## 4. 会改变看法的事件 / Killer Questions（可观测、可证伪）

- **K1｜美国商业增长的持久性（核心命门）**：US commercial 营收能否在 FY2026-2027 持续 >40% YoY？**任一季度美国商业增速跌破 30%** = 减速确认 → 强化空头；若连续 4 季维持 >50% → 我的空头 thesis 需下调。
- **K2｜倍数体制（终局对齐 · 目标价核心）**：股票能否守住 >35x forward P/S，还是 de-rate 向 20-25x？**跌破 30x forward（≈ $100 以下 on FY26）而基本面未破** = 估值压缩兑现我的 base；**维持 >40x 且创新高** = bull 情景。
- **K3｜政府板块：扩张还是政治拖累**：Army $10B ELA 模式是否复制（更多 ELA 落地）？还是 DOGE/Pentagon 预算削减使政府营收增速掉到商业之下？**观测：FY2026 政府营收增速 vs 商业增速缺口、新 ELA 数量。**
- **K4｜盈利质量与稀释（反方证伪点）**：GAAP 运营利润率 + FCF 是否继续扩张（Rule-of-40 守 >100）、净稀释是否维持 <2%/年？**若稀释重新加速或利润率见顶** = 反方 3 被推翻，利好我的空头；反之持续 = 反方成立。
- **K5｜beat 幅度衰减信号**：beat-and-raise 的**幅度**是否收窄（Q2 实际 vs $1.8B 指引超出幅度、FY26 是否再上调）？**beat 幅度逐季缩小** = 增长成熟化的领先信号 → 支持减速判断。
