# decomposition_v0 — 中国 PD-1/VEGF 双抗 arena（薄拆解，v0 种子）

> 基于 thesis_v0（prescan 校准后）+ K1-K5 + baseline §六。v0 只做置信度 tag + 机械自检，深度 delta 重拆留 04。

## 一、命门 1-3（机理/兑现路径上方向错了就翻盘）

- **命门1 · OS 优势的"真实性"**（置信度：**中**）
  依沃西全球 HARMONi OS HR=0.78 是 **nominal p=0.0332**（非预设 alpha 严格控制）。命门 = 这个 OS 优势是"分子机理真优（VEGF+PD-1 协同）"还是"试验设计/人群富集/统计口径的产物"？若 FDA 审评认定 nominal-p 不足以支持 OS 声称、或学界跨试验比较质疑成立 → 全球注册价值与"取代 K 药"叙事大打折扣，thesis 翻盘。
  → 跨人群（东西方）一致性提供支持，但 nominal-p 是硬伤，**优先砸料**（FDA 审评动态 + 学界质疑原文）。

- **命门2 · 先发壁垒的"时间窗"**（置信度：**低** ⚠️——最薄环节）
  依沃西对后来者（707/BNT327/LM-299）有 ~2 年先发。命门 = 这个时间窗能否在后来者（携 MNC 全球临床+商业化火力）追上前，转化为不可逆的适应症卡位/医生处方习惯/医保占位？若后来者 2-3 年内在 1L NSCLC 头对头/OS 追平 → 先发溢价蒸发，arena 从"一个赢家"退化为"多分子内卷"。
  → 后来者的临床阶段/数据成熟度/追赶速度**训练未校准**（`[fact-14][fact-15]`），是收料首要缺口，**优先砸料对冲薄拆解**。

- **命门3 · 中国利润池的"可维系性"**（置信度：**中**）
  命门 = 依沃西中国商业化（医院准入 + 医保放量）能否在不被价格战摧毁的前提下支撑估值？"赢了 K 药没赢市场"是结构性（中国支付端天花板 + 医保压价）还是暂时（准入爬坡期）？若结构性 → 大中华权益（康方）价值需下修，估值锚失效。

## 二、每环 B 靶点（决策链 6 环 · 命门特化补充）

- **环①（机会/生意本质）**：PD-1/VEGF 机理双面性资料——协同证据（血管正常化+免疫激活）vs 代价（VEGF 类效安全性：出血/蛋白尿，鳞癌尤重）。支撑命门1。
- **环②（格局/玩家）**：5 款出海分子（康方/三生/普米斯/宜明昂科/礼新）+ 未出海跟进者（恒瑞/齐鲁/神州细胞等）全景 + 各自背后 MNC 火力与开发阶段。支撑命门2。
- **环③（关键变量/驱动）**：依沃西全球注册进度（BLA 审评/PDUFA/欧盟）+ OS nominal-p 争议的学界与监管讨论原文。支撑命门1。
- **环④（价值/估值）**：康方（09926.HK）/ 三生（01530.HK）rNPV + 峰值销售假设（高盛 $530亿等）+ 卖方目标价 + 当前估值水位。支撑命门3 + K5。
- **环⑤（风险/反脆弱）**：中国医保谈判压价机制 + PD-1 单抗价格战镜鉴 + 后来者追赶节奏。支撑命门2/3。
- **环⑥（shortlist 选拔）· 终局环 · B 靶点强制非空 ✅**：依沃西 vs SSGJ-707 vs BNT327 vs LM-299 vs IMM2510 **同口径横向比较料**（临床阶段 / OS·PFS 数据 / 适应症广度 / 交易首付·总额·保留权益 / 可投标的映射），用于选出赢家 + 定介入纪律。→ 已排进 5.3 todo #5（P0）。
