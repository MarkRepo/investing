## 核心数据点与事实

**A组 · 命门1 的基准口径（本研究最关键的一组数字）**
- **以AXT终端销售价格模拟计算，2021年通美分产品毛利率：磷化铟 57.47% / 砷化镓 23.86% / 锗 1.18%**（8-1-22页）。这是"无AI短缺、无出口管制、无涨价"的常态年份口径，且已还原到与今日 AXT 合并报表可比的终端价基础上。
- 通美自身账面（未还原终端价）分产品毛利率：磷化铟 2019/2020/2021 = **40.65% / 38.64% / 54.42%**；砷化镓 = **-9.13% / 8.65% / 25.59%**；锗 = **20.60% / 18.44% / 0.21%**。
- 2021 年 InP 毛利率同比 +15.78pct，其中 **17.67pct 全部来自"业务切换"**（AXT 境外销售职能收归美国通美，把原属 AXT 的转售价差并回体内），并非价格上涨或降本。反事实测算：若外销仍按关联价，2021 年 InP 综合毛利率仅 **36.75%**。
- 2021 年 InP 销售单价 1,196.06 元/片（折2寸口径），较 2020 年 +74.98%——该涨幅同样主要是"从关联价换成终端价"的口径跳变，不是市场涨价。

**B组 · 关联交易与股权结构（环①B(b) / K6）**
- 2019-2021 合并口径，通美售 AXT 价 vs AXT 对外售价（元/片）：**砷化镓 391.18 / 377.11（+3.73%）；磷化铟 483.15 / 1,275.32（-62.12%）；锗 428.07 / 430.54（-0.57%）**。
- InP 价差逐年收窄：2019 -68.85% → 2020 -59.41% → 2021 -51.84%。
- **该价差已终止**：2021年3月 AXT 将境外销售业务及客户切换至美国通美，2021年5月通美完成对美国通美收购，**自2021年7月起与 AXT 的关联销售彻底终止**。AXT 现仅为控股平台+境外应用研发，不再自营销售。
- 通美对 AXT 销售收入占营收比：2019 47.91%（2.21亿元）→ 2020 48.35%（2.82亿元）→ 2021 **6.97%**（0.60亿元）。
- 通美向 AXT 销售 InP 的加权平均毛利率仅 7.67%（通美端口径）。
- AXT 同期销售与研发支出：450.84 / 496.76 / 121.59 万美元——即 AXT 主体本身的费用体量极小（2021 仅约 120 万美元）。
- 中介核查：海通证券（保荐）、金杜（律师）、安永华明（会计师）+ 独立转移定价报告交叉复核，结论"不存在利益输送、不存在通过关联交易调节利润"。

**C组 · 命门2 的硬锚：单位产能 capex 与产能利用率（K2/K5）**
- 通美 InP 产能（折2寸万片）：2019 26.70 → 2020 30.70 → 2021 **40.78**；产量 23.32/28.32/39.26；**产能利用率 87.34% → 92.24% → 96.27%**（长期满负荷运行）。
- 通美 GaAs 产能（折2寸万片）：190.50 → 232.25 → **313.64**；利用率 93.91%/88.63%/97.78%。
- 募投项目：**InP（晶片）项目拟投 1.81 亿元 → 新增年产 81 万片（折2寸）**；GaAs 项目拟投 3.67 亿元 → 实现 8 寸量产并扩 2-6 寸。
  → **单位产能 capex ≈ 1.81亿元 ÷ 81万片 ≈ 224 元/片（折2寸）年产能 ≈ $31/片**。这是判"扩产成本曲线平不平"的直接同口径基准。
- 产销率：InP 2019 100.05% → 2020 95.60% → 2021 90.94%（产量已开始快于销量）；GaAs 98.35%/98.36%/**86.06%**。
- 2022年1-5月：InP 收入 1.62 亿元（+69.64% yoy），GaAs 1.32 亿元（+40.70%）；截至 2022-06-20 两者在手订单合计仅 **1.43 亿元**。

**D组 · 份额与市场规模的权威口径（K5，解决 36% vs 45% 冲突）**
- **Yole 口径：2020 年通美 InP 衬底全球份额 36%，全球第二**；住友第一、日本JX 第三；**三家合计占 2020 年全球 InP 份额 91%**。
- GaAs：2019 年通美全球份额 **13%，全球第四**（Freiberger 第一、住友第二）。
- **Yole 预测 2026 年全球 InP 衬底市场规模仅 2.02 亿美元**（2019-2026 CAGR 12.42%），其中光通信细分 1.57 亿美元、占比 >70%（CAGR 13.94%）。
- 锗：通美已退出美国航空航天市场，Umicore 全球份额高于通美；境内与云南锗业双寡头。
- 同业体量对照（2020/2019）：住友营收 29,186 亿日元、净利 563 亿日元；JX 营收 10,044 亿日元、净利 166 亿日元；Freiberger 营收 6,600 万欧元、净利 400 万欧元；**通美 2021 营收 8.57 亿元、净利 0.94 亿元**。

**E组 · in-house 历史镜鉴：锗衬底（环⑤最贴切的样本）**
- 云南锗业 2014 年切入锗衬底 → 2021 年锗衬底收入 7,710.93 万元，"与通美收入规模相当"。
- **云南锗业锗衬底产能一年 +150%**（2020 30.00 → 2021 75.00 万片折4寸），产量 +20%（23.57 → 28.28）。
- 结果：通美 4 寸锗衬底毛利率 **2020 21.55% → 2021 0.46%**（整体锗毛利率 18.44% → 0.21%），**从竞争者产能翻倍到毛利率归零，时滞约 1 年**。
- 同期单价：通美 336.81 → 287.74 元/片（-14.57%）；云南锗业 390.06 → 283.70（-27.27%）——**后进入者以更狠的降价换份额**。
- 成本端同时恶化：73 名转岗人员推升 4 寸单位成本 +9.24%；锗锭采购均价 7,008.32 元/kg（+12.42%）。
- 2022年1-5月锗衬底毛利率仅 0.22%，价格 281.83 元/片——**两年半未恢复**。

**F组 · 其他可用数据点**
- InP 外销数量占比：2019 79.88% → 2020 77.18% → 2021 **59.77%**（境内占比快速抬升，是"中国队身份"命门3 的量化底色）。
- InP 尺寸结构（2020 vs 2019 收入占比）：2寸 37.57%/26.54%、3寸 43.32%/65.58%、4寸 18.90%/7.84%、6寸 0.22%/0.04%——**2020年6寸几乎为零**，大尺寸良率低于小尺寸、毛利率更低。
- 生产成本地域套利：北京/保定/朝阳生产人员月均工资 11,372 / 8,414 / 8,881 元；电价 0.76 / 0.72 / 0.55 元/度；水价 7.84 / 5.76 / 3.80 元/吨。
- 研发投入：2,682.64 / 4,510.82 / 9,016.64 万元。
- 汇率（美元兑人民币）：期初 6.79 → 各期末 7.01 / 6.54 / 6.37。
- InP 境外主要客户：IQE、台湾联亚光电、台湾全新光电、台湾稳懋半导体；整体客户含 Osram、II-VI(现 Coherent)、Broadcom、三安光电、长光华芯。
- 董事长 MORRIS SHEN-SHIH YOUNG 为 VGF 技术产业化奠基人之一，本文件由其签署真实性声明。
- 技术替代风险自陈：GaAs 在射频领域存在被 SOI 部分替代的风险（SOI 成本更低）。

## 叙事主线

因为通美在"无短缺、无管制"的 2021 年、以终端价还原口径，InP 单品毛利率就已达 57.47%，且当年 InP 毛利率的抬升 17.67pct 全部来自把 AXT 转售价差并回体内的口径变更（反事实仅 36.75%）→ 所以本文件表明 AXT 今日 44.9% 的**合并**毛利率并不天然等同于"出口许可造的短缺租金"，它更可能是"InP 收入占比抬升 + GaAs 从 -9% 修复到 25%+"的产品结构效应叠加涨价 → 对投资意味着**先验看空论点的核心支柱（45% 是人为短缺租金）必须先被拆成"结构 vs 租金"两段再定价，否则会把可持续的结构性台阶误判成周期顶部的一次性租金**；但同一份文件也给出了最锋利的反向证据——锗衬底那条业务里，竞争者产能一年翻 1.5 倍就把毛利率从 21.55% 打到 0.46%，且两年半未恢复，这正是 InP 在 2027 供给应答下的 in-house 剧本。

## 反常识/分歧点

- **市场预期/常识**：AXT 45% 毛利率是 AI 光模块短缺 + 中国出口许可造的人为租金，周期一转就归零。**本文表明**：2021 年（AI 光模块叙事尚未启动、出口管制尚未落地）以终端价模拟的 InP 毛利率已 57.47%，比今日合并毛利率 44.9% 还高。"45% 是租金"的论断缺一个基准对照，真正的租金部分只能是"当期实际 InP 毛利率 − 57.47% 基准"这一超额。
- **市场预期/常识**：AXT 是 $200M+ 营收、$4.4B 市值的 InP 龙头。**本文表明**：Yole 口径 **2026 年全球 InP 衬底市场规模仅 2.02 亿美元**（与 Mordor $221M、Maius ~$200M 三源交叉一致）。AXT 市值 ≈ 全球 InP 衬底市场规模的 20 倍以上——环②反推必须直面"这个池子有多大"，而非只推份额。
- **市场预期/常识**：483 vs 1275 元/片的关联交易价差是当期的利益输送/估值折价来源。**本文表明**：该价差自 2021 年 7 月起已彻底终止，AXT 对通美收入占比从 48% 降到 7%，并经三家中介 + 独立转移定价报告交叉核验。用它做当期折价理由已经过期；真正的当期结构性折价来源应是可赎回少数股东权益与人民币基金赎回权。
- **市场预期/常识**：InP 是寡头护城河、扩产极难。**本文表明**：通美自己的 InP 募投项目单位产能 capex 仅约 224 元/片（折2寸）年产能（≈$31/片），即 1.81 亿元人民币就买到 81 万片折2寸年产能——**相对其 ASP 1,196 元/片，capex/年收入比不到 0.19x，属极轻的扩产成本曲线**。这与"扩产曲线陡、供给应答慢"的多方叙事直接冲突，是命门2 目前最强的看空证据。
- **市场预期/常识**：AXT 的中国身份只是政治风险。**本文表明**：其生产端有实实在在的地域成本套利（朝阳电价仅为北京的 72%、水价 48%、工资 78%），这部分成本优势是结构性的、与许可无关。
