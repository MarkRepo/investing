## 环① 看懂这个行业（理解闸门）

**一句话生意模式**：人形机器人是"AI 大脑 + 几十个执行器组成的通用机器人本体"，产业链利润此刻集中在上游执行器核心零部件。

**价值链利润池定位（决策导向速写，背景详见 primer §2-3）**：硬件成本结构是这条链的脊柱——执行器相关占整机成本一半以上（特斯拉口径 56%，高盛口径含传感器约 62%）[§prescan][mat-b0c512]。单项价值量排序：**行星滚柱丝杠 31% >> 六维力矩传感器 10% > 空心杯电机 6% > 无框电机/谐波减速器各 4%** [mat-b0c512]。**利润池此刻在"线性执行器（丝杠）+ 传感器 + 电机"这一段最厚，且与国产化难度正相关——价值量越大越卡脖子。**

**驱动因子 + 周期定位**：
- 驱动 = 技术（VLA/具身智能让通用机器人可行）+ 政策（工信部 2025 量产、2027 成生态目标）[mat-215f5f] + 资本（2022 以来中国 25 笔融资 44 亿元 [mat-852ece]）。
- 周期 = **技术 S 曲线早期 + 量产前夜 + 资本周期高位回调中**。2025 全球出货约 1.3 万台（中国主导）、2026 预测约 9 万台 [§prescan]——真实但仍小。结束信号：若 2026-2027 出货不及万→十万台级、或估值 price-in 的量产被证伪，则资本周期向下。

## 环③ 这个价需要什么结构性假设为真（What-Must-Be-True）

要让②的乐观定价成立，以下 4 条结构性假设必须为真（按对定价的杠杆排序）：

1. **【量产兑现】Optimus + 中国 OEM 在 2026-2028 把出货从万台级拉到十万→百万台级。** 证据支持度：**弱-中**。中国出货真实领先（2025 全球第一）[§prescan]，但特斯拉 10-K 官方仍称"尚未商业化、可能延迟" [mat-5bd1f9]，量产斜率高度不确定。
2. **【利润落零部件】利润池留在执行器核心零部件，而非被整机厂（尤其 Tesla 自研）攫取。** 支持度：**不确定**。BOM 价值量确在零部件 [mat-b0c512]，但 Tesla 纵向一体化叙事强化（半导体自制 + Optimus 升格"business"）[mat-c5a73f]，执行器自研边界 10-K 沉默 [mat-5bd1f9]。
3. **【国产高端突破】中国厂突破丝杠等高端环节良率 + 拿到全球（含 Tesla）定点，把"量"变成"高价值的量"。** 支持度：**弱**。丝杠国产份额仅 19%、磨床 95% 进口 [mat-529f3d][mat-b0c512]；精度需 C5→C3 且要与 Tesla 协同 [mat-ac86a8]；有诺仕等国产降本进展 [§prescan]但高端未突破。
4. **【量价齐升】出货放量的同时单价/毛利企稳，国产替代不沦为低价内卷。** 支持度：**弱**。绿的销量 +72% 但单台均价 -15%、毛利三年降 [mat-38d7ed]；整机端宇树 G1 $16k 低价 [mat-ac86a8]——"以价换量"信号明确。

> 4 条假设中，2 条弱、1 条不确定、仅"中国出货领先"部分为真。**这意味着②的乐观定价缺乏结构性支撑——这是④谨慎 stance 的根据。**

## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

**已知风险**：①估值进一步消化——纯人形玩家几百倍 PE 还有大幅下行空间，若量产持续低于预期，绿的/鸣志可能腰斩。②Tesla 自研执行器——利润被整机厂吃掉，中国供应链"有定点没大单"。

**盲点风险**：③**路线突变**——若"准直驱（行星减速器，成本仅谐波 1/5）"路线被整机厂大规模采用 [mat-215f5f]，会改写各零件价值分配，丝杠/谐波的利润池假设动摇。④**中国出货领先反而压垮利润**——低价内卷向上游传导，零部件厂被迫降价，"有量无利"全行业化。

**行业级 kill 触发条件**（数据化）：
- Tesla 2026 全年 Optimus 出货仍 <5,000 台 或 V3 整机再次跳票 → 假设1 破，量产叙事失血。
- Tesla 定点公告显示核心执行器自研/给海外 → 假设2 破，中国供应链逻辑失血。
- 行业代表（绿的/北特）2026 中报人形收入占比仍 <5% 且单价继续下滑 → 假设3+4 破。

**≥2 个历史行业镜鉴**（"热过但利润没兑现"——只想成功案例本身就是 red flag）[§prescan]：
1. **中国光伏（2010s-2020s）**：政策强推 + 国产替代 + 高估值叙事，最终产能过剩、价格战、**五大光伏企业一年预亏合计约 300 亿、行业进入破产重整** [§prescan 光伏镜鉴]。失败模式：补贴/叙事催生过度扩产 → 利润被价格战吞噬。峰谷损失幅度：龙头股价从高点回撤 70-90%。当年最早预警信号：扩产竞赛 + 单价持续下滑（**现在人形零部件已现单价下滑信号——绿的单台 -15%**）。教训：国产替代成功 ≠ 股东赚钱，量增可能伴随利润崩。
2. **无人驾驶 / Robotaxi（2018-2025）**：L4 时间表反复跳票，烧钱长、兑现晚。**"摇摆的百度、跳票的特斯拉、渐近的拐点"——十年才到拐点边缘** [§prescan Robotaxi 镜鉴]；Cybercab 量产下线但特斯拉股价仍回调近两成。失败模式：技术叙事先行、商业化远慢于预期，估值多轮回调。预警信号：时间表反复推迟（**Optimus V3 已多次推迟** [§prescan]）。教训：颠覆性技术的"量产前夜"可能持续数年，估值要为漫长等待打折。
3. **协作机器人 / 服务机器人（2015-2020）**："机器替人"叙事先行，商业化兑现远慢于预期，cobot 泡沫回调。教训：场景验证（实训 12-24 个月 [mat-529f3d]）比想象慢。

  - monitor_metrics：国产丝杠定点数 / 良率(精度等级) / 人形丝杠收入占比 / 纯玩家 PE 分位

### 🟡 观察档（4 个，等价格/格局信号）
- **谐波减速器**（3.4）：国产最成熟（绿的领先），但绿的 410x PE 极端透支 → **好生意贵价格**，等估值消化或人形收入占比实质爬升再升档。触发：绿的 PE 回落至 <150x 且人形收入占比 >10%。
- **电机（无框+空心杯）**（3.3）：空心杯灵巧手刚需但海外 80% 垄断、鸣志 379x 且净利下滑、越南产能 2026Q4 才投产 [mat-d1ef8c]。触发：国产空心杯拿到北美定点放量 / 鸣志净利转正。
- **六维力传感器**（3.7）：第二大价值量、高壁垒，但 A 股纯标的稀缺（多为非上市/业务占比小）。触发：出现可投的纯标的 / 国产批量化突破。
- **灵巧手（总成）**（3.4）：占整机工程量一半、潜力大，但格局未定、可投标的早期。触发：DOF/触觉量产路线收敛 + 头部整机锁定供应商。

### ⚫ 淘汰档（1 个）
- **整机/本体**（2.8）：A 股投资视角下——中系低价内卷无利润（宇树 G1 $16k）、美系不可 A 股直投、格局极度分化无赢家。**复活条件**：出现盈利且可 A 股投资的整机龙头（如宇树 A 股 IPO 落地且兑现盈利），或整机格局收敛出现定价权。

**注意力预算**：深挖只放 1 个（丝杠），因为资源有限且它是唯一"高价值×高壁垒×估值未极端透支×命门所在"的交集。其余好赛道（谐波/电机/六维力/灵巧手）全部进观察档挂价格/格局触发器——**这正是"吸引力×定价"的纪律：好生意贵价格不是买入理由。**

## 环⑥补｜核心受益标的指认（直面最终目标后半句"受益标的是谁"）

> 漏斗的 arena 选拔（丝杠 deep）回答了"哪个环节最有价值"，但**最厚的环节恰恰最贵最难（丝杠国产仅19%、磨床卡脖子、五洲326x/北特135x透支）——这对"现在配钱"的人是真问题**。所以"受益标的是谁"的诚实答案不是"买丝杠龙头"，而是分三类落到具体公司 + 配介入纪律：

| 类别 | 标的 | 质地(ROIC/主业) | 定价(PE) | 人形弹性 | 当前动作 |
|---|---|---|---|---|---|
| **A. 主业托底+低价人形期权（当前唯一可重仓）** | 三花智控 | 强(ROIC13.4%/净利+31%/车规护城河) | 47.7x | 中(机电执行器送样) | 主业撑估值、人形免费期权，回调可配 |
| | 拓普集团 | 中(ROIC11.4%/营收新高利润首降) | 39.2x | 中高(执行器总成+Tesla关系) | 主业型参与，盯执行器定点 |
| | 双环传动 | 中(ROIC9.95%/汽车齿轮β) | **26.3x最低** | 中(环动RV分拆IPO催化) | 低估值+减速器期权，盯环动招股书 |
| **B. 高弹性但估值劝退（等消化）** | 绿的谐波 | 高毛利但ROIC仅2.95% | **410x** | 最纯(谐波销量+72%) | 弹性最纯但极端透支，等PE<150x |
| | 五洲新春/北特科技 | 丝杠纯玩家 | 326x/135x | 高(丝杠) | 深挖档但透支，等定点+消化 |
| **C. 基本面弱+估值高（暂避）** | 鸣志电器 | 弱(ROIC3.16%/净利-21.5%) | 379x | 高(空心杯)但越南产能2026Q4 | 双杀风险，回避 |
| **D. 深挖待定点（相对温和可先盯）** | 恒立液压/贝斯特 | 液压龙头/温和 | 52.8x/42.4x | 丝杠新业务弹性 | 丝杠 arena 估值最温和的入口，盯定点 |

**一句话受益标的答案**：**环节上"行星滚柱丝杠"利润池最厚（命门 deep），但当前可下手性差；标的上当前最现实的参与方式是"主业托底型"——三花/拓普/双环以主业 ROIC 撑估值、低价持有人形期权（双环 26x 估值+环动 RV 分拆催化是性价比最优的当下选项）；纯弹性玩家（绿的/丝杠纯玩家）需等估值消化+定点验证再切入。** 这不是"空仓"，而是"用主业托底型低成本持有期权 + 用 deep arena 跟踪何时切换到纯弹性"。

> **整机 eliminated 的边界（回应：是否漏赢家）**：整机进淘汰是**A 股交易性约束**（中系低价内卷无利润、美系不可直投），**非战略否定**。值得警惕的反向风险：信通院判"长期价值在软件/算法（整机厂）"[mat-215f5f]，且宇树已盈利+出货全球第一+A 股 IPO 辅导中 [§prescan]——**若宇树 A 股上市且兑现盈利，整机可能从淘汰档反转为最大赢家**（已列复活条件）。本研究的零部件聚焦是"当下 A 股可投性"下的选择，不代表长期利润一定归零部件——这是 thesis 保留的最大开放性分歧。
