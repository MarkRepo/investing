# thesis_v0 — 人形机器人行业

## 1. 核心 thesis（一句话 + 强度）

**人形机器人的利润池结构性集中在「执行器及其核心零部件」（占整机成本 ~56%），中国零部件厂凭制造+成本+政策优势是国产替代长逻辑的最大受益者；但 2026 年中 A 股供应链正处「产业向右、估值向左」的证伪消化期——方向看多执行器核心环节，节奏上谨慎，等量产兑现与估值出清验证。**

**强度评分：6/10**（分化看法：长期看多执行器核心零部件赢家；短期对当前估值与兑现节奏谨慎，不追高）

## 2. 支持理由

1. **利润池逻辑硬**：Tesla 官方称 Optimus 56% 成本是执行器；执行器（谐波减速器+无框电机+编码器 / 行星滚柱丝杠+伺服）是价值最集中、技术壁垒最高的环节，利润池定位清晰 [fact-07, §六校准]。
2. **中国需求+供给双优势已兑现**：2025 中国厂商主导全球人形出货（Unitree 5,500+ 全球第一、AgiBot 单季 5,000），中国供应链占 Optimus 约 70%（长三角集群）——制造与成本优势是既成事实 [fact-05/26, §六]。
3. **国产替代+基本面在兑现**：绿的谐波 2025 净利翻倍、三花净利 +31.1%、拓普营收创新高；政策（工信部 2025 量产目标 + 国地共建中心）持续强推 [fact-08/13/14/23, §六]。
4. **周期早期 + 技术拐点**：VLA/具身智能打开应用可行性，行业处技术 S 曲线早期，长期空间大（Goldman $38B by 2035，bull case 更高）[fact-18/24]。

## 3. 最大反方观点（诚实，非稻草人）

1. **估值已透支且正被证伪**：三花年内市值蒸发 500 亿+、绿的净利翻倍股价反大跌（"为泡沫买单"）、拓普利润首降+"百万台产能证伪考验"——前期股价 price-in 的量产预期正被打回，**基本面改善 ≠ 股价上涨**，"情绪向左产业向右" [fact-22, §六]。
2. **Tesla 垂直整合风险**：Tesla 倾向自研核心执行器，供应链可能"有定点无放量"，价值捕获被整机厂吃掉 [fact-25]。
3. **中国整机低价内卷**："出货全球领先"可能是低价换量（Unitree G1 ~$16k），供应链被压价，最终"有量无利"，利润不落在零部件厂 [fact-05/20]。
4. **量产仍千台级，证伪窗口长**：2025 全球仅 ~13k 台，人形业务对供应链厂收入贡献仍微（<5%），当前纯期权定价，证伪/兑现需数年 [fact-21]。

## 4. 会改变看法的事件 / Killer Question

- **K1｜Optimus 量产兑现**：Tesla 2026 实际出货是否达数千→上万台 + 外销启动？可证伪：2026 出货仍千台级 或 V3 整机再跳票。（攻打"产业向右"是否成立）
- **K2｜利润池归属环节**：利润是否真落在执行器核心零部件（谐波/丝杠/电机总成），而非整机或被 Tesla 自研吃掉？可证伪：Tesla 自研执行器份额过半 或 零部件价值量被压缩。
- **K3｜国产替代+高端突破**：中国零部件厂能否拿到全球 OEM（含 Tesla）定点 + 突破丝杠等高端精度良率？可证伪：Tesla 线性执行器丝杠定点给海外/自研，国产仅供国内低端。
- **K4｜估值出清到位**：A 股供应链泡沫消化后估值是否已合理？可证伪：龙头 PE 仍高位 且 人形收入占比持续 <5%。
- **K5｜中国出货→供应链利润转化**：整机出货领先是否转化为中国供应链的价值捕获，还是低价内卷无利润？可证伪：中国 OEM 出货大但单价/毛利持续下滑、供应链跟跌。
- **K6｜细分 arena 选拔**：谐波 / 行星滚柱丝杠 / 灵巧手 / 电机 / 传感器——哪个细分利润池最厚 + 竞争结构最好 + 当前定价最合理？（漏斗核心选拔问题）
