# decomposition_v0 — 人形机器人行业（命门 + primer 入门目标 · 薄知识种子）

> B 轴种子：thesis_v0 + K# + baseline（含 §六 prescan 校准）拆。v0 不做 LLM critic，只置信度 tag + 机械自检。深度重拆留 04 厚料期。

## 一、命门 1-3（决定 thesis 成败的特化问题）

- **命门1｜执行器价值池能否守住**（置信度：中）
  Tesla 垂直整合（自研执行器）+ 中国整机低价内卷 的双重挤压下，零部件厂能否真正捕获利润？
  → 若价值被整机厂两头吃掉，"投执行器核心零部件"整条 thesis 翻盘。对应 K2/K5。
- **命门2｜兑现-证伪的时间差**（置信度：低）
  基本面兑现（出货/订单放量）能否在估值进一步出清、市场耐心耗尽前到来？
  → "情绪向左产业向右"的核心：产业向右是真的，但若兑现节奏跑不赢估值消化，持有者先死在黎明前。对应 K1/K4。
- **命门3｜高端精度国产突破**（置信度：uncertain）
  行星滚柱丝杠良率 / 六维力传感器等高端环节，国产是真突破并拿到全球（含 Tesla）定点，还是卡在低端替代？
  → 决定中国供应链是捕获高价值还是只吃低毛利。对应 K3。

## 二、每环 B 靶点（命门特化补充，指导 01 收料 priority）

- **环①（看懂行业）**：价值链各段**单台价值量拆解**（执行器/谐波/丝杠/电机/灵巧手/传感器各占多少 $/比例）+ 行业财务弧线（绿的/拓普/三花/双环/鸣志多年营收·利润率·ROIC）。
- **环②（定价锚）**：A 股龙头当前 PE/PS/市值 + 历史分位 + **人形业务收入占比**（反推 priced-in 的量产预期）+ 卖方目标价/一致预期。
- **环③（结构性假设）**：利润池迁移证据——Optimus BOM 拆解、丝杠 vs 谐波路线之争、Tesla 自研 vs 外采动向、灵巧手 DOF 演进。
- **环④（下注/arena 评分）**：各细分 arena（谐波/丝杠/电机/灵巧手/传感器/整机）6 维评分料（利润池规模/增速/竞争结构/估值/周期）。**低置信命门 3 → 丝杠 arena 优先砸料**。
- **环⑤（证伪/镜鉴）**🔴：历史镜鉴实证——服务机器人 / 协作机器人(cobot) / 无人驾驶 / 光伏 的"叙事先行、利润兑现滞后"复盘（三项真·欠供，需主动收）。
- **环⑥（分流）**：三档分流触发器（深挖/观察/淘汰各 ≥1 arena + 价格/订单触发器）。

## 三、primer 入门目标 v0（门外人读完应能做到，12 条 · 种子）

1. 能解释人形机器人由哪几大系统构成（执行/感知/控制/能源），DOF 是什么、为何 40+。（训练知识可覆盖）
2. 能区分旋转执行器 vs 线性执行器及各自核心零件（谐波减速器 vs 行星滚柱丝杠）。（训练知识）
3. 能说出执行器为何占整机成本 ~56%、价值池为何集中于此。（prescan 校准）
4. 听到"谐波/RV减速器/行星滚柱丝杠/无框力矩电机/空心杯电机/六维力传感器/灵巧手"知道各指什么、装在哪。（训练知识）
5. 能画出产业链三层（上游零部件→中游整机→下游AI/算力）+ 利润此刻在哪段。（训练+findings）
6. 能列出全球主要整机厂（Tesla/Figure/宇树/智元/优必选）及路线差异（美系AI vs 中系低成本）。（prescan）
7. 能说出 A 股主要供应链标的（绿的/拓普/三花/双环/鸣志）各做什么环节。（findings 年报）
8. 能解释"国产替代"为何是 A 股投资主线 + 其风险（低端内卷/Tesla自研）。（thesis 驱动，findings）
9. 能用基本框架判断供应链标的"贵不贵"（人形收入占比 vs 估值 vs 期权定价）。（market_data+findings）
10. 知道行业周期位（技术S曲线早期、量产前夜、2025全球~13k台）+ "情绪向左产业向右"含义。（prescan）
11. 能说出关键催化剂/证伪信号（Optimus量产、Tesla定点、估值出清、中国OEM毛利）。（thesis）
12. 能识别人形术语墙（VLA/具身智能/sim2real/端到端）大致含义。（训练知识）

> 全部 12 条有数据源（训练知识/prescan/findings）；无"只生成不收料"孤儿。
