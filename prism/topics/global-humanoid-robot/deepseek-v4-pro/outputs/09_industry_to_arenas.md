## 评分维度说明

- **利润池规模**：当前及 5 年期 arena 总利润池（亿元，区间）。1: <10亿, 5: >1000亿。来自 01_business_panorama BOM 占比 × Goldman Sachs 2035E TAM $38B × 合理净利率假设。
- **增速预期**：3 年 CAGR。1: <5%, 5: >30%。来自 02_cycle_positioning 周期分析 + Goldman Sachs 成本曲线。
- **竞争结构**：CR3 / 是否有自然垄断 / 是否同质化。1: 完全竞争, 5: 自然垄断。来自 01_business_panorama 竞争格局 + 前瞻蓝皮书 进口依赖数据。
- **估值水位**：当前 PE/PS 相对该 arena 历史 + 全球 peer。1: 历史高位, 5: 历史低位。来自 04_implied_expectations 估值分析 + 各标的 2025 年报。
- **周期位置**：早期成长 / 中段加速 / 晚期分化 / 成熟饱和。1: 衰退/饱和, 5: 早期成长。来自 02_cycle_positioning 综合判断。
- **综合评分**：1-5（5 = 最值得深挖），为上述 5 维度等权平均。

## 入选深挖（深挖档）

### 行星滚柱丝杠 / 线性执行器

- **建议 slug**: `global-humanoid-roller-screw`
- **入选理由**：产业链中竞争结构最好的环节——81% 进口依赖意味着近乎寡头的供给侧格局，国产替代成功后的定价权极强。利润池增速有"行业增长+国产替代"双重驱动。估值尚未像谐波减速器那样被充分定价（贝斯特等标的 PE 合理）。这是"卖铲子的铲子"中最锋利的那个。
- **预期关键洞见**：
  - 国产行星滚柱丝杠与 Rollvis/GSA 的真实技术差距（精度/寿命/一致性）
  - 高精磨床的出口管制风险等级和应对路径
  - 绿的谐波、贝斯特、其他潜在进入者的竞争态势和产能时间表
- **预填 L4 狩猎问题**：
  1. 绿的谐波 vs 贝斯特的行星滚柱丝杠产品，哪家更可能率先拿到 Tier 1 整机厂的正式供应资格？
  2. 高精磨床（95% 日欧依赖）被纳入出口管制的概率有多大？如果发生，国产替代路径是什么？
  3. Rollvis/GSA 的扩产意愿和能力如何——他们会主动降价打击中国替代者，还是坐享产能溢价？

## 进入 watchlist（观察档）

### 谐波减速器 / 旋转执行器

- **暂不深挖理由**：绿的谐波已在国内工业机器人谐波减速器领域占据主导地位，市场认知充分，PE 80-120x 已将人形机器人期权大部分定价。竞争格局不如行星滚柱丝杠纯粹（Harmonic Drive 全球竞争 + 国内新进入者）。此时深挖的边际信息增量较小。
- **升档触发条件**：绿的谐波 PE 回调至 40-60x 区间（如板块进一步调整 30%+），或公司正式公告获得 Tesla Optimus 执行器订单。
- **监控指标**：
  1. 绿的谐波 PE（TTM）是否回落至 60x 以下
  2. 人形机器人执行器收入是否在年报中独立披露且占比 >5%

### 空心杯电机 / 灵巧手

- **暂不深挖理由**：高端空心杯电机市场仍由 Faulhaber/Maxon/Portescap 主导，鸣志电器的国产替代进度是核心变量但目前公开信息极少（2025 年报未量化披露）。灵巧手作为系统级产品，格局更不确定——可能由整机厂自研而非外购。
- **升档触发条件**：鸣志电器或国产厂商宣布获得整机厂灵巧手电机批量订单，或灵巧手技术路线收敛（外购 vs 自研格局清晰化）。
- **监控指标**：
  1. 鸣志电器年报/半年报中空心杯电机收入增速（尤其出口/高端客户）
  2. 整机厂（Tesla/Figure/优必选）灵巧手方案是否采用国产空心杯电机

### 整机制造

- **暂不深挖理由**：数十家竞争者、无明确壁垒、利润池大概率像汽车 OEM（薄利）。当前阶段无法判断谁是赢家。宇树科技 IPO 招股书是获取整机厂实际经营数据的第一个窗口，在此之前信息不对称严重。
- **升档触发条件**：宇树科技 IPO 招股书公开（可获取真实经营数据），或某家整机厂实现千台级出货且客户复购。
- **监控指标**：
  1. 宇树科技 IPO 进展和招股书披露
  2. 优必选 Walker S1 比亚迪工厂复购/扩展情况

### 碳纤维 / 轻量化结构件

- **暂不深挖理由**：BOM 占比高（17.18%）但被市场忽视——这本身是一个有趣的"反向信号"，但也意味着信息极度匮乏。当前没有明确的纯标的（碳纤维供应商的主业是风电/航空），人形机器人收入占比可以忽略。需要等到有更清晰的供应商绑定信号再投入研究资源。
- **升档触发条件**：某碳纤维/复材公司明确披露人形机器人结构件订单或绑定整机厂，或整机厂公布轻量化方案供应商。
- **监控指标**：
  1. Tesla Optimus/Figure AI 结构件供应商信息
  2. 碳纤维上市公司（光威复材/中复神鹰等）年报中的人形机器人提及

## 淘汰记录（淘汰档）

### 感知系统 / 传感器

- **淘汰理由**：利润池被视觉/力/触觉三个子领域分散，单个子领域 TAM 小（<50 亿 CNY）。竞争格局高度分散（奥比中光、汉威科技、禾赛科技等各自在不同细分领域），没有明确的"人形机器人传感器龙头"。六维力传感器壁垒高但国内量产能力不足——这个领域更像是"需要跟踪的技术变量"而非"当前可投资的 arena"。
- **复活条件**：出现一家公司明确以人形机器人传感器为核心战略（收入占比 >20%）且具有跨子领域的技术平台能力；或六维力传感器国产突破取得量产验证。
