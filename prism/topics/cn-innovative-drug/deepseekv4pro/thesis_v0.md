# thesis_v0 — 中国创新药行业

## 一、核心 thesis（含强度评分）

**中国创新药正处于「全球 BD 兑现 + 国内业绩拐点」双引擎驱动期，行业 β 方向明确看多，但超额收益全在 alpha 甄别——ADC/双抗赛道中具 first/best-in-class 全球数据、且 BD 首付→里程碑转化率可验证的龙头，是唯一值得配置的资产；回避纯国内 me-too、管线同质化严重、及 BD 预期已透支估值的企业。**

**强度评分：7 / 10（看多 · 强分化）**

## 二、支持理由

1. **BD 出海 2025 爆发式增长，中国首次成为全球创新药授权第一大国**：license-out 交易总额 ~$1357 亿（≈2024 的 2.6×），首付款 ~$70 亿创纪录。交易结构从"卖青苗"升级到 NewCo/共同开发分润（信达-武田 40/60 美国分润），为无收入 biotech 提供真实现金流与全球背书。

2. **2026 是"业绩兑现"关键年**：2023-2025 获批 76 款创新药进入放量期；百济 2025 全年首次 GAAP 盈利（营收 >¥382 亿）、信达首次全年盈利、荣昌扭亏。基本面从"研发故事"转向"利润表"——这是估值体系切换的临界点。

3. **中国在 ADC/双抗具全球工程化相对优势**：依沃西 HARMONi-2 头对头击败 K 药（PFS 阳性）、HARMONi-A OS 终点达成；BL-B01D1（$84 亿 BMS）、sac-TMT（默沙东/黑石 $7 亿研发承担）被 MNC 高价收购。first/best-in-class 比例上升，不是"便宜替代"而是"最优选择"。

4. **支付端政策打开新通道**：全链条支持 + 丙类目录（2025-09 落地）为高价创新药提供基本医保之外的支付路径。虽体量有限，但方向性意义重大——政策从"控费"转向"扶创新"。

5. **港股创新药估值修复 + 融资窗口重开**：2025 牛市（18A 两月 8+ 家翻倍），扭亏 + 流动性 + 政策共振。但 2025 下半年起"BD 利好→股价反跌"（信达-武田 10 月、加科思-AZ 12 月 -13%），说明市场已从"听故事"进化到"看价值"。

## 三、最大反方观点（非稻草人）

1. **"高预期、低落地"——BD 首付仅占总额 5-7%**：里程碑/分成高度依赖海外临床成功率与 MNC 推进意愿。若任一头部资产全球 III 期失败（依沃西 HARMONi OS / BL-B01D1 IZABRIGHT），估值与现金流双杀。2025 下半年"BD 利好→股价反跌"已是市场进化信号。

2. **国内支付天花板未根本解除**：丙类/商保体量有限（惠民保增长陷瓶颈），国谈降价仍压制国内销售。真实利润主要押注出海，本质是"美国生物科技 β + 人民币研发成本"的套利——受 BIOSECURE/地缘与 MNC 专利悬崖周期左右。

3. **估值已部分透支 + 极端分化**：TOP10 企业占 60% 交易额，尾部 22 家仅占 7%。指数化买入会被大量无兑现 me-too 拖累，alpha 在甄别而非 β。

4. **赛道拥挤度上升**：PD-1/VEGF 辉瑞已自研入局、GLP-1 国产扎堆（>20 家在研），ADC 靶点同质化（HER2/TROP2/EGFR 拥挤）。"中国速度"优势可能被 MNC 自研 + 国内内卷双向侵蚀。

## 四、会改变看法的事件 / Killer Question

- **K1（出海兑现率）**：2026 关键全球 III 期 / OS 读出——依沃西全球 HARMONi OS、BL-B01D1 IZABRIGHT、sac-TMT 海外注册是否如期阳性？*任一头部资产全球 III 期明确失败 → 出海逻辑实质受损。*

- **K2（业绩兑现）**：头部药企 2026 **剔除 BD 首付后的产品收入增速** + 利润是否延续 2025 扭亏/盈利趋势（百济/信达/恒瑞/荣昌）？*若产品收入增速 <20% 且利润靠 BD 一次性 → 拐点证伪。*

- **K3（BD 持续性）**：2026 license-out 总额/首付款能否维持（vs 2025 $1357 亿高基数），首付占比是否提升？*2026 全年 BD 总额同比 -30% 以上 → "持续现金流"叙事弱化。*

- **K4（支付端实质改善）**：丙类目录落地后高价创新药国内放量是否兑现？商保赔付占创新药销售比例是否实质上升？

- **K5（细分赛道 + 龙头甄别）**：ADC / 双抗 / GLP-1 / 自免 / 小核酸各品类，哪些龙头具可持续 best-in-class 壁垒 vs 估值透支？*这是研究问题「哪些细分赛道+龙头值得配置」的直接落点，驱动 arena 选拔。*
