# decomposition_v0 — 中国创新药行业（命门拆解 + primer 入门目标 · B 轴种子）

> 薄知识拆解（thesis_v0 + K# + baseline §六）。v0 不做 LLM critic，只标置信度 + 机械自检。
> 真正可靠性闸门是 04 厚料 delta 重拆（decomposition_v1）。

## 一、命门 1-3（每个一句话 + 置信度）

- **命门 1 — 出海兑现路径**（置信度：**中**）：BD 的里程碑/分成能否真兑现为**持续**现金流，取决于头部资产**海外关键临床（全球 III 期 / OS）成功率 + MNC 推进意愿**。这是整个看多逻辑的兑现脊柱——首付只占总额 5-7%，大头是或然的。
  - → 01/02 **优先砸料**：依沃西全球 HARMONi OS、BL-B01D1 IZABRIGHT、sac-TMT 海外注册等头部资产试验进度与读出；MNC 合作推进/暂停信号。

- **命门 2 — 内生拐点真伪**（置信度：**中**）：2026"业绩兑现"是真拐点还是 BD 首付一次性粉饰，取决于**剔除 BD 首付后的产品收入内生增速 + 盈利质量可持续性**。
  - → 优先砸料：头部药企（恒瑞/百济/信达/荣昌/康方/科伦博泰）**分季度产品收入 vs BD 收入拆分**、毛利/费用结构、BD 首付确认节奏。

- **命门 3 — 龙头壁垒可持续性**（置信度：**低** ⚠️ 最难、最该砸料）：best-in-class 是真壁垒，还是会被国内快速跟随 / MNC 自研追平（PD-1/VEGF 辉瑞已自研入局、GLP-1 赛道拥挤、ADC 靶点同质化）。**直接决定"配哪个龙头"**。
  - → 优先砸料：各赛道在研管线密度 / 靶点扎堆度 / 专利与临床数据壁垒 / MNC 自研替代进度。

## 二、每环 B 靶点（决策链 6 环 × 1-2 条，A 合同之上的命门特化补充）

- **环① 看懂行业**：B1 价值链利润池此刻在哪段（研发/BD/商业化/CXO）、谁攫取——量化"出海首付 vs 国内销售 vs 里程碑"现金流结构；B2 行业代表主体（恒瑞/百济/信达/康方/科伦博泰）3-5 年营收/利润率/ROIC/FCF 弧线 + 扭亏拐点。

- **环② 定价锚（命门环）**：B3 龙头及各细分代表 PE/PS 反推隐含增速；B4 港股 18A / 恒生医疗当前估值水位（vs 2021 高点 / 2024 低点）+ 全球 peer 对标。

- **环③ What-Must-Be-True**：B5 支撑当前定价的 3-5 条结构性假设（出海持续性、国内放量、利润池向创新迁移）各自证据支持度。

- **环④ stance + arena 下注（命门 3 落点）**：B6 ADC/双抗/GLP-1/自免/小核酸 各 arena 6 维（规模/增速/竞争结构/估值/周期/综合）；B7 行业整体 stance + 与共识在"出海 β vs 内生 α"的分歧。

- **环⑤ 证伪机制**：B8 ≥2 个历史行业镜鉴（PD-1 价格战/me-too 泡沫、仿制药集采挤压、2021 上一轮 18A 泡沫破裂）+ kill 触发条件 + signpost（2026 关键读出/年报/国谈）。

- **环⑥ 漏斗分流**：B9 三档 arena 分流（深挖/观察/淘汰）+ tier（吸引力 × 定价）+ 触发器。

## 三、primer 入门目标 v0（门外人为投资读完应能做到，种子非定稿）

1. 说清中国创新药"挣钱的钱从哪来"——区分国内销售 / BD 首付 / 里程碑分成 / CXO 代工四种现金流及确定性差异。（高）
2. 看到一笔 license-out 能拆解"首付/里程碑/分成"结构并判断兑现确定性（为何首付才是硬钱）。（高）
3. 区分 ADC/双抗/GLP-1/自免/小核酸五大品类各自技术逻辑、代表药与中国相对全球的位置。（中·需补料）
4. 解释"国谈/医保/集采/丙类目录"如何决定一款创新药国内的天花板与放量节奏。（中·需补料）
5. 读懂一家 biotech 关键临床节点（I/II/III 期、NDA、OS/PFS 终点）对估值的意义。（高）
6. 用 PE/PS / 管线 NPV 框架理解无收入 biotech 为何能有高估值、何时戴维斯双杀。（中）
7. 识别"first/best-in-class vs me-too/fast-follower"及为何它决定能否出海。（中）
8. 说清港股 18A / 科创板第五套上市机制与创新药板块 2021-2025 牛熊周期成因。（中·需补料）
9. 列出 TOP 级公司（恒瑞/百济/信达/康方/科伦博泰/荣昌/百利天恒）各自核心资产与定位。（高）
10. 理解出海地缘风险（BIOSECURE / MNC 专利悬崖周期）如何影响 BD 需求。（低·需补料）
11. 判断一个细分赛道"拥挤 vs 蓝海"——从在研管线数 / 靶点扎堆 / BD 价格看竞争结构。（中·需补料）
