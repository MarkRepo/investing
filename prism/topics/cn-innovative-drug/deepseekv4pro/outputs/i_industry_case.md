## 环① 看懂行业：价值链、利润池与周期位

### 1.1 价值链全貌

中国创新药价值链从上游到下游：

```
靶点发现 → 药物设计 → 临床前研究 → 临床 I-III 期 → 注册审批 → 生产 → 商业化（国内/出海）
  ←── 研发段（烧钱、高风险）──→←── 生产段 ──→←── 变现段 ──→
```

**利润池此刻在哪段**（2026 年判断）：

| 价值链段 | 利润池特征 | 谁攫取 |
|---------|----------|--------|
| 早期研发（靶点发现→IND） | 负利润（纯烧钱），但价值最高 | BD 首付在此段变现 |
| 临床开发（I-III 期） | 负利润，但 III 期成功 = 估值跳升 | CRO 赚服务费，药企承担风险 |
| 生产（CMC） | 稳定但薄利 | CDMO（药明生物等）+ 自建产能 |
| 国内商业化 | 有收入但利润受国谈压制 | 销售团队强的龙头（恒瑞/信达） |
| 海外 BD 变现 | 利润率最高（首付/里程碑/分成） | 管线质量好的 Biotech/Pharma |

**核心判断**：利润池正在从"国内销售"向"海外 BD 变现"迁移。BD 首付/里程碑/分成是当前中国创新药行业最确定的利润来源，国内销售提供基础现金流但做不出超额利润。

## 环⑤ 证伪：历史镜鉴、Kill 与 Signpost

### 5.1 历史行业镜鉴

**镜鉴 1：PD-1 价格战与 me-too 泡沫（2018-2022）**

- **失败模式**：热门靶点扎堆（>10 款 PD-1 上市）→ 国谈大幅降价（50-60%）→ 单药商业化天花板极低
- **峰谷损失**：PD-1 从"千亿赛道"预期跌至实际国内销售 <¥100 亿
- **最早预警信号**：2019 年信达/君实/恒瑞/百济四家 PD-1 同时进医保，价格战开打
- **现在是否已现**：ADC 的 HER2/TROP2/EGFR 靶点有同质化迹象，但双抗 ADC 差异化明显；GLP-1 国产 >20 家在研是隐忧
- **教训**：靶点同质化 + 支付端单一 = 利润池快速蒸发。**best-in-class 能出海，me-too 只能卷国内**

**镜鉴 2：2021 港股 18A 泡沫破裂**

- **失败模式**：估值透支（PE >100x）→ 加息 + 流动性收紧 → 戴维斯双杀
- **峰谷损失**：恒生医疗指数从 2021-06 高点跌至 2024-08 低点，跌幅 >70%
- **最早预警信号**：2021H2 美联储转鹰、一级市场融资冻结
- **现在是否已现**：本轮有真实 BD 现金流 + 扭亏支撑，基本面远强于 2021；但 18A 部分企业被爆炒后暴跌（药捷安康入通 +655%→单日蒸发 1900 亿），局部泡沫重现
- **教训**：**板块 β 上涨 ≠ 个股安全**。没有基本面支撑的 18A 炒作，涨得快跌得更快

**镜鉴 3：仿制药集采对利润池的挤压（2018 起）**

- **失败模式**：政府以量换价→ 仿制药利润归零 → 倒逼转型
- **教训**：**政策定价权可以瞬间重塑行业利润池**。理解"为什么必须转创新"的关键背景

- 核心逻辑：全球竞争优势确定 + BD 变现路径清晰 + 关键催化剂密集（2026H2）

**观察（watch）— 小核酸 / GLP-1 / 自免**：
- 小核酸：等 2026 更多临床数据 + BD 交易验证，升级触发：首个国产 siRNA III 期成功
- GLP-1：精选标的（信达玛仕度肽已商业化），回避纯 me-too，升级触发：国产 GLP-1 海外 III 期启动
- 自免：等荣昌泰它西普/Vor Bio 进展，升级触发：自免新药海外获批

**淘汰（eliminated）— 暂无**：
- 行业整体向上，无 arena 需完全淘汰
- 但个股层面：纯国内 me-too / 管线同质化严重 / 现金 runway <12 月的 18A 企业应回避

### 6.2 行业 stance

**看多中国创新药行业（7/10），但"买龙头不买行业"**：
- 行业 β 方向确定（BD 出海 + 业绩兑现 + 政策支持），但 α 极度分化
- 超额收益来自甄别"真正有全球竞争力的 best-in-class 管线"，而非指数化买入
