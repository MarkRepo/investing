## 核心数据点与事实

**［K1 · 四年成本序列（本 finding 独有：把 FY2023 基期补齐）］**

1. [FY2024 通期説明資料 2024-06-12 Appendix 財務データ] **直接変動費率四~五年序列**：FY2023/4 **48.3%** → FY2024/4 **46.5%** → FY2025/4 46.4% → FY2026/4 **48.5%**。→ **FY2026 的 48.5% 只是回到 FY2023 的水平，不是历史新高的失控**（且其中约 3.2pt 是 ¥18亿 评价损）。
2. [同前] **人件費合計对营收比四年序列**：FY2023 **7.4%** → FY2024 **7.5%** → FY2025 7.9% → FY2026 **7.9%**。→ **四年区间仅 7.4-7.9%，波幅 0.5pt**。「员工 506→621 人（+22.7%）导致人件費压垮利润率」在比率上完全不成立。
3. **［自算］** **その他原価・販管費合计对营收比**：FY2023 **14.6%** → FY2024 **14.8%** → FY2025 15.6% → FY2026 **15.2%**（FY2026 反而比 FY2025 改善 0.4pt）。四年累计漂移仅 **+0.6pt**。
4. [同前] FY2023/4 与 FY2024/4 完整损益：FY2023 营收 ¥25,342 / 売上原価 ¥13,762（54.3%）/ 粗利 ¥11,580（**45.7%**）/ 販管費 ¥2,170（8.6%）/ 営業利益 ¥9,410（**37.1%**）/ 純利益 ¥6,699（26.4%）；FY2024 营收 ¥31,996 / 粗利 ¥15,207（**47.5%**）/ 販管費 ¥2,845（8.9%）/ 営業利益 ¥12,362（**38.6%**）/ 純利益 ¥8,726（27.3%）。
5. **［自算 · 关键 · 营益率五年真序列］** **37.1%（FY2023）→ 38.6%（FY2024）→ 38.0%（FY2025）→ 36.2%（FY2026，剔除评价损 ≈39.5%）→ 32.1-33.3%（FY2027 会予）**。→ **加上 FY2023 后，"单调下滑"变成"37→38.6→38.0→36.2 的高位盘整 + FY2027 指引的台阶"**。thesis_v0 §3-1 的四期表格恰好从峰值 FY2024 起算，制造了单调性错觉。
6. [同前] 粗利率序列：45.7%（FY2023）→ 47.5%（FY2024）→ 46.9%（FY2025）→ 44.7%（FY2026）。→ FY2026 的 44.7% 相对 FY2023 的 45.7% 仅低 1.0pt。
7. [p.4] FY2024 Q4 的公司自陈（同季节性机理，可复用于读 FY2026 Q4）：「**決算賞与が計上される第4四半期は他四半期対比で利益率が落ち込む傾向にある**ものの、変動費の改善効果等により…営業利益率が改善」→ **Q4 利润率结构性偏低是公司自己承认的常规季节性**，FY2026 Q4 的 23.9% 是"常规季节性 + ¥18亿 评价损"的叠加。

8. [p.4 業績予想対比] **FY2024/4：期初指引 营收 ¥33,000 / 営業利益 ¥12,700（营益率 38.5%）→ 实绩 ¥31,996 / ¥12,362 → 达成率 97.0% / 97.3%（未达）**。

11. [p.12] **⚠ 最重要的类比：FY2025/4 的 Q1 指引形状**——营收 ¥8,100-8,300（同比 **-9.5~-7.2%**）、営業利益 ¥3,000-3,100（同比 **-25.8~-23.3%**）、纯利 -24.9~-22.4%。理由：「前年度は第1四半期におけるコマース施策の集中により第1四半期偏重の業績であったが、**今期は四半期間のバランスを平準化した計画**を策定しており、前年同期比では減収・減益を見込む」。
12. **［自算 · 该类比的结局］** FY2025 Q1 实绩 营收 ¥7,436（**低于指引下限**，-16.9% YoY）、営業利益 ¥2,719（**低于指引下限**）→ **Q1 双杀**；但 **FY2025 全年实绩 营收 +34.0% / 営業利益 +31.7%，且超期初指引 10%**。→ **"Q1 大幅减收减益指引 + Q1 实绩再破指引"在本公司历史上曾经与"全年超指引 10%"共存**。FY2027/4 Q1 指引（-1.1% / -18.8%）比当年温和得多。**这是 K1/K2 最强的历史校准证据。**
13. [p.11] FY2025 期初的季度平准化意图：「コマース、イベントの施策時期により業績の変動は生じるものの、**前年度よりも四半期間の変動は平準化を目指す**」→ 实际 FY2025 波动更大（Q1 -16.9% / Q4 +60.2%）。**公司对自身季度分布的预测能力弱，这是区间指引的根因，不是需求信号。**

## 叙事主线

因为把成本与损益序列向前拉到 FY2023/4 后可以看到：① 直接変動費率 48.3%→46.5%→46.4%→48.5% 是**区间波动而非单向恶化**，人件費率四年只在 7.4-7.9% 之间动，その他原価·販管費率四年累计漂移仅 +0.6pt 且 FY2026 反而改善；② 营益率真序列是 37.1→38.6→38.0→36.2%（剔评价损 39.5%）的**高位盘整**，thesis_v0 的"四期单调下滑"恰好从峰值年 FY2024 起算；③ 三年期初指引达成率 97.3% / 110.0% / 100.9%，**无系统性乐观偏差**，而 FY2025/4 曾给出**比 FY2027 更狠的 Q1 指引（营收 -9.5~-7.2% / 营益 -25.8~-23.3%）并且 Q1 实绩再破指引下限，全年却超期初指引 10% 收在 +34.0%/+31.7%**；④ NIJISANJI EN 从 FY2023 的 ¥64亿 衰减到 FY2026 的 ¥19.5亿（-69.6%），拖低合并增速约 13pt/年，但基数已只剩 3.6%，**拖累即将耗尽** → 所以本资料把 case 的重心从"利润率是否结构性崩坏"转向两个更可检验的问题：「FY2027 指引的保守度有多少」与「海外拖累耗尽后合并增速能否向国内 34%+ 收敛」 → 对投资意味着 thesis_v0 §3 的第 1 条（最强利空）应被降级为"取样偏差 + 会计事件"，而一个**未被任何一方计入的机械性顺风（海外拖累归零）**应进入环④的营收预测。

## 反常识/分歧点

- **thesis_v0 §3-1「营益率 38.6→38.0→36.2→32.8% 单调下滑，每一年都在掉」。本资料表明**：序列起点选在**峰值年 FY2024**。补上 FY2023 的 37.1% 后，形态是 **37.1→38.6→38.0→36.2**（先升后微降），再剔除 FY2026 的 ¥18亿 评价损则为 **37.1→38.6→38.0→39.5**（创新高）。**"单调性"是取样起点造成的。**
- **市场/thesis_v0：Q1 营益 -18.8% 指引是拐点信号。本资料表明**：FY2025/4 期初给的 Q1 指引是**营收 -9.5~-7.2% / 营益 -25.8~-23.3%**（比 FY2027 严重得多），且 Q1 实绩 **-16.9% / 营益 ¥2,719 双双低于指引下限**——而 FY2025 全年收在 **+34.0% / +31.7%、超期初指引 10%**。→ **本公司的 Q1 与全年之间几乎没有可外推关系**（原因是 commerce 施策时点在年度间漂移，公司自己反复说明）。K1/K2 的观测阈值不应挂在 Q1。
- **完全未被计入的顺风（本轮独有发现）**：海外（EN）+ 其他从 FY2023 的 ¥69.37亿 萎缩到 FY2026 的 ¥20.25亿，**过去三年每年从合并增速里扣掉约 13pt**；如今余额仅占合并营收 3.6%，**FY2027 起这项拖累最多只值 -0.9pt**。国内にじさんじ三年 CAGR 43.1%、FY2026 仍 +34.0%。→ 若国内增速即使减半到 +17%，合并营收也能到 **+16%**（远高于指引 +0.6~7.8%）。这条不对称性**不在公司指引里、不在券商模型的讨论中、也不在 thesis_v0 里**。
- **NIJISANJI EN 是公司内部的现成 historical mirror（喂环⑤）**：一个曾占营收 25%（FY2023 ¥64亿/¥253亿）的分部，在三年内 -69.6%，且**衰亡最剧的正是 commerce（-75.8%）**。这既是"IP 生命周期见顶后 commerce 如何崩"的**同公司同商业模式实证样本**（对 K2 是警示），也说明**管理层面对失败分部的处理方式是收缩止损而非烧钱硬撑**（对环① mgmt 是正面）。→ 比外部的 MIXI/コロプラ 复盘更贴切，应作为环⑤主镜鉴。
- **"轻资产"的四年确认**：四年投资CF 合计仅 -¥33亿 = 营业CF 的 8.2%；四年营业CF ¥405亿、财务返还 ¥210亿（51.8%）。→ 这不是某一年的偶然，是**上市以来的一贯资本结构**。
- **Q4 利润率偏低是公司自陈的常规季节性**（決算賞与计提月）——FY2024 就写明「決算賞与が計上される第4四半期は他四半期対比で利益率が落ち込む傾向」。→ FY2026 Q4 的 23.9% 应拆为"常规季节性 + ¥18亿 评价损"，而非"经营断崖"。

## 未回答问题

1. FY2023/4 及更早的期初指引达成率（把校准窗口拉满到上市首年），以及上市时招股书的中期计划兑现情况——用于判断 103% 平均达成率是否稳定。
2. 従業員数的四年序列——本资料 p.6 仍是图表（未 OCR）。四份説明資料的员工数图都在 images/ 内，**这是 K1「员工增速降至 +10% 内」阈值目前唯一的观测缺口**，需 有価証券報告書 补。
3. NIJISANJI EN 衰亡的**归因**（是 talent 集体卒業、算法/平台变化、还是运营资源被抽调回国内？）——四份説明資料均只给数字不给原因。若归因是"公司主动放弃并抽调资源回国内"，则国内的高增长部分是这笔资源再配置的产物，对管理层评价更正面；若是"IP 自然衰亡不可逆"，则对 K2 的警示更强。**这是本轮最值得追加深挖的问题。**
4. FY2024/4 期初指引未达（97.3%）的原因——若是可识别的一次性因素，则三年校准的"无系统性偏差"结论更稳。
