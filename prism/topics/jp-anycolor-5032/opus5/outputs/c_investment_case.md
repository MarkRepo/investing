### 历史失败镜鉴（≥2）

1. **NIJISANJI EN（同公司同模式，最贴切）**：一个曾占营收 25% 的分部，FY2023 ¥64 亿 → FY2026 ¥19.5 亿（**-69.6%**），衰亡最剧的正是 commerce（-75.8%）[mat-ea34f4]。**失败模式**：IP 生命周期见顶后 commerce 崩塌。**当年最早预警**：liver 净流出（FY2024 即 EN 2 卒業 0 出道）+ commerce 同比转负。**现在是否已现于国内**：**否**——国内 commerce FY2026 仍 +40.8%、liver 净增、ID +20.6%；但"10-20 岁再生横盘"是需要盯的早期同类信号。**教训**：盯国内 commerce 的 TTM 同比 + liver 净增减，别等年度数字。
2. **MIXI / モンスト（单引擎依赖）**：モンスト 收入占约 7 成，见顶后"モンスト頼み"脱却成高墙，相关收入降到峰值约一半，第二支柱迟迟不成 [mat-f3824b]。**失败模式**：单产品依赖 + 无第二增长极。**对 ANYCOLOR 的映射与差异**：ANYCOLOR commerce 也是单引擎（68%），**但它的"引擎"是 179 个角色的组合 IP，而非单一产品**——依赖度性质是"单分部"而非"单 IP"，风险分散度高得多。**教训**：区分"单分部依赖"与"单 IP 依赖"，别把 ANYCOLOR 误当 MIXI。
3.（辅）**COVER 重资产化路径**（父级 topic）：营益率 18.4%→14.3%，重资产 + 头部卒業双杀。ANYCOLOR 若走向自建 studio/大型自办演唱会（中期计划已提 studio 投资 ¥40 亿 + M&A 可能），需警惕范式漂移。

### Kill 触发条件（可观测、数据化）

- **K-1**：TTM commerce 同比连续两季转负（剔施策漂移）→ 需求饱和坐实，kill 多头。
- **K-2**：剔一次性后营益率跌破 31% **且**公司再上调费用预期 → 成熟度税向下突破新锚。
- **K-3**：到 FY2027 期末（2027-04）累计新回购决议 < ¥50 亿 → ¥350-450 亿承诺证伪，下行托底失效 + 治理折价扩大。
- **K-4**：单季头部 liver 卒業 ≥3 名 → commerce 需求端失血。
- **K-5**：ANYCOLOR ID 增速连续两期 <+10%。
