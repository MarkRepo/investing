# Decomposition v0 — 澜起科技（688008 / 06809.HK）

> 薄拆解（thesis_v0 + K# + baseline + prescan）。v0 只做置信度 tag + 机械自检，不做 LLM critic；深度 delta 重拆留 04 厚料期。

## 一、命门 1-3（方向错了整个 thesis 翻盘）

- **命门1｜极端估值能否被增长消化（估值均值回归 vs 成长兑现）** — 置信度：**中**
  若 A 股三位数 PE / 港股 6000 亿市值不能被后续增长与盈利质量消化（增速掉档或估值继续脱离基本面），则"好生意"也会因买入价过高而 EV 为负——thesis 从"等买点"翻盘为"任何价都贵"。对应 K2（终局命门）。
- **命门2｜AI 互连第二曲线的放量斜率** — 置信度：**中/低**
  成长逻辑的机理支柱是 AI 互连从 2.69 亿基数陡峭放量。若 Retimer/CXL/MRCD 放量斜率显著低于市场隐含预期（竞争被 Astera Labs 压制、CXL 商用继续延后、PCIe Switch 转向不及预期），第二曲线证伪→估值支撑坍塌。对应 K1/K5。置信度低 → **优先砸料验证**。
- **命门3｜增长的"含金量"（扣非真实增速 vs 一次性/周期）** — 置信度：**低**
  2026Q1 净利 +61% 含约 2.4 亿一次性出售股权收益；H1 预增 85.5-102% 的可持续性、剔非后扣非真实斜率、以及内存周期是否见顶拖累主业，均未证实。若"加速"主要靠一次性/周期高点，则减速命门可能只是被暂时掩盖。对应 K3。置信度低 → **优先砸料验证**。

## 二、每环 B 靶点（A 合同地板之上的命门特化补充）

- **环①（生意本质 / 需求端）**：内存接口芯片单条 DDR5 含量与 ASP 弹性；服务器 + AI 内存需求、DDR5 渗透曲线（明年或超 DDR4）。
- **环②（护城河 / 竞争格局）**：JEDEC 话语权 + 三大原厂认证壁垒的持久性；澜起 vs 瑞萨/Rambus 的 DDR5 份额；PCIe Retimer 赛道 vs Astera Labs 的竞争卡位（命门2）。
- **环③（成长驱动 / 兑现路径）**：AI 互连四新品放量斜率与客户导入名单、PCIe Switch 转向的收入支撑、MRDIMM 2027 接力时间表（命门2）。
- **环④（估值 / EV · 终局环 · 强制非空）**：
  1. **一致预期** — 2026-2027 卖方盈利预测区间、覆盖机构数与目标价分布；
  2. **估值锚** — 历史 PE/PB 分位、A/H 折溢价序列、可比 Astera Labs 的 EV/Sales 与 PE 对照；
  3. **目标价支撑** — DCF / PEG / 情景（牛熊）分析所需的增速/毛利/贴现输入。
  → 这是定介入买点的核心料靶，直接服务 company 终局（买/卖/持有 + EV + 目标价），已排入 5.3/Step6 收料优先级（命门1）。
- **环⑤（管理层 / 资本配置）**：历年分红/回购/减持史、股权激励、H 股募资用途、创始人（杨崇和）持股与治理结构、Intel 等早期股东退出情况。
- **环⑥（催化剂 / 介入纪律）**：回调催化剂清单、扣非增速验证节点（H1 半年报 / Q3）、估值回落触发位、A/H 联动信号。
