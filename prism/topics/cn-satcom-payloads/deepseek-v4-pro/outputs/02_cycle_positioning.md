# 周期定位：卫星通信载荷

> 生成于 2026-05-11，训练知识占比约 65%，资料更新截至 2025年12月

## 行业周期类型

卫星通信载荷不是传统意义上随库存/产能波动的周期性行业。其周期由三重驱动叠加，主次关系如下：

1. **部署周期（主导）**：星座建设从规划→验证→批量发射→补网替换，呈典型的 S 曲线。当前处于 S 曲线前 10% 的加速拐点。周期长度约 10-15 年（一个完整星座的建设+替换周期）
2. **技术周期（次要）**：相控阵芯片工艺（GaAs→GaN→硅基 CMOS）、激光终端速率（1 Gbps→100 Gbps→200 Gbps）的代际升级。技术周期约 3-5 年一代，与部署周期叠加决定竞争窗口
3. **政策/预算周期（扰动项）**：军方订单、航天专项经费、发射场建设等受财政周期影响，短期扰动但不改变长期方向

**没有传统意义上的库存/价格/产能过剩周期**——这是因为：
- 产能建设（产线）本身需要 12-18 个月，且产能瓶颈始终在供给端而非需求端
- 价格是成本加成+规模下降的单边趋势，不存在「涨价去库存」逻辑
- 需求来自星座规划而非终端消费，不存在消费者推迟购买等需求波动

## 历史阶段复盘

该行业没有「过去 10 年多个完整周期」——它本身是 2020 年后才从 0 到 1 的行业。更合适的框架是阶段演进：

### 阶段 1：技术验证期（2016-2020）
- **触发**：星链计划启动（2015）+ 中国商业航天政策放开
- **特征**：单星验证为主。中国首颗低轨宽带卫星（银河航天首发星 2020.1，48 Gbps 容量）、北斗三号激光星间链路（2018-2019，1 Gbps）
- **结束信号**：多颗在轨验证成功 + 国家星网公司揭牌（2021.4）

### 阶段 2：规划与早期部署（2021-2025）
- **触发**：中国星网成立 + GW/G60 星座正式规划
- **特征**：GW 截至 2025.12 在轨仅 136 颗，千帆 108 颗，占规划 0.87%。发射节奏明显加速（2025H2 共 13 组）。企业开始拿到小批量载荷订单
- **结束信号**：可复用火箭首飞（朱雀三号 2025.12 入轨成功但回收失败）+ 卫星工厂投产

### 阶段 3：批量部署期（2026-2032，当前正进入）
- **触发**：ITU 时限倒逼 + 火箭回收开始工程化 + 卫星产线投产
- **预期特征**：发射量从每年 ~300 颗（2025）跃升至 ~900 颗（2026E）→ ~15000 颗（2030E），载荷需求爆发

## 未来 12-24 个月展望

### 基准情景（60% 概率）：2026-2027 批量发射启动，载荷订单放量
- **触发条件**：GW 星座 2026H2 进入 100+ 颗/年级别发射，G60 一期 300+ 颗完成部署
- **对载荷的影响**：T/R 组件和相控阵天线率先兑现业绩（订单可见性高），激光终端订单 2027 年开始出现
- **关键数据**：铖昌科技/国博电子星载业务收入增速 >50%，上海瀚讯 G60 载荷交付
- **关键验证节点**：2026 年中 GW 批量发射公告、2026 年海南商发工位排期、铖昌/国博 2026 半年报星载收入

### 上行情景（20% 概率）：星座建设加速超预期
- **触发条件**：朱雀三号/长征 12 甲回收成功 + 海南商发双工位满负荷 + 军方追加订单
- **幅度**：发射量远超基准线（200+ 次/年），载荷需求非线性跳升
- **信号**：国博电子/铖昌科技公告「产能不足，启动扩产」、激光终端出现首单批量招标

### 下行情景（20% 概率）：部署节奏延迟 12-18 个月
- **触发条件**：火箭回收持续失败 + 发射场工位不足 + 载荷在轨故障率超预期

- **信号**：GW 发射公告持续推后、铖昌/国博星载收入低于预期、星座运营商要求延迟交付

## 对投资的含义

**周期位置适合建仓，但节奏把控是关键**：

- 当前相当于 Starlink 产业链在 2018-2019 年的位置（批量组网前夜）。SpaceX 那时载荷供应商经历了从 0 到大规模放量的跨越
- **仓位节奏**：T/R 组件/芯片（2026 年兑现）→ 天线整机/转发器（2027 年兑现）→ 激光终端（2028+ 年兑现），三个环节的业绩释放有时间差
- **最大不确定性**：基准情景的实现高度依赖火箭回收技术突破，而火箭回收的工程难度可能被市场低估。如果火箭回收延迟 2 年以上，所有载荷订单的「放量」节奏都需要后移
- **与估值的关系**：当前 A 股载荷标的估值（铖昌/国博 ~40-60x PE）隐含了对 2027-2028 年增长的预期，下行风险在于「放量延迟」可能导致估值消化时间拉长
