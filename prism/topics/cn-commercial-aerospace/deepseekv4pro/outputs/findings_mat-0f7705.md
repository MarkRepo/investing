# B. 叙事主线

因为蓝箭航天在营收几乎为零、四年累计亏损34.67亿的情况下，通过朱雀三号首次入轨+回收试验取得里程碑式技术突破，满足科创板商业火箭专项指引第五套标准，从而获得IPO募资通道 → 所以IPO募资(估算约75亿元对应200亿估值)将100%投入可重复使用火箭产能与技术提升，本质上是把公司的生存赌注全部押在"朱雀三号回收成功→规模化商业发射→降本→盈亏平衡"这一链条上 → 投资含义：蓝箭航天当前是一张深度虚值期权，核心价值不来自任何现有财务指标，而来自可重复使用火箭技术验证成功后的发射经济性拐点；IPO定价200亿估值对应零收入和零盈利的现实，买方本质在赌的是"中国版SpaceX降本曲线能否成立"以及"中国商业发射市场能否在3-5年内兑现足够发射需求来填满产能"。

# C. 反常识/分歧

- **营收隐匿的严重程度超过预期**：招股书直接声明研发费用占收入比例"不具备参考意义"，暗示收入接近零或处于试制阶段，这与媒体渲染的"商业航天第一股""商业化加速"叙事形成巨大落差。实际上蓝箭航天本质上仍是一家研发阶段公司，与成熟商业化之间有巨大鸿沟。
- **现场检查风险的信号**：2026-01-05抽中现场检查是监管层面发出的谨慎信号。A股历史上科创板IPO被抽中现场检查后的撤回率较高，虽然蓝箭已进入"已问询"阶段，但现场检查仍可能暴露出收入确认、研发资本化等问题，构成IPO进程的不确定性。

# D. 未回答问题

1. **蓝箭航天的实际营收是多少？** 招股书刻意模糊处理，但年报期(2022-2025H1)跨度3.5年，按"营收极小"暗示年收入可能在数百万至数千万级别，需要精确数字来评估商业化进度。
2. **朱雀三号单次发射的单位经济性是什么？**目前完全无法从公开数据推算(单发成本/报价/盈亏平衡发射次数)，这是评估200亿估值合理性的核心缺失变量。
3. **IPO估值200亿对应多少隐含发射量和市场份额假设？** 需要IPO定价区间和发行价公布后才能倒推，但200亿估值对于一家零收入公司而言，已隐含了极高的未来市场占有率预期。
