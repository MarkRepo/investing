# findings — 2026年中国汽车产业：汽车智驾产业进入新阶段 (mat-d9818f)

## A 核心数据点与事实
- **L2 渗透率**：2025 年前三季度具备 L2 功能的乘用车新车销量同比 +21.2%，渗透率达 **64%**，2025 年底或升至 **66.1%**。
- **城市 NOA 放量**：2025 年 1–11 月搭载城市 NOA 的乘用车累计销量 **321.9 万辆**，占乘用车上险量 **15.1%**，较 2024 全年 **+5.6pct**。
- **第三方城市 NOA 供应商格局**：呈"双强主导"，**Momenta + 华为合计约占第三方供应商八成（~80%）**；百度、元戎启行、文远知行等分食其余份额。
- **L3 商业化里程碑**：极狐阿尔法S(L3版)获工信部准入并拿到全国首批 L3 专用号牌（北京试点）；红旗 E-HS9 取得北京无人驾驶测试牌照、累计自动驾驶里程 >12 万公里；智己汽车 2025-12 入选 L3 项目、获上海指定高速路段试点。北汽、长安等已获 L3 准入。
- 数据来源：中汽协子公司《2025 城市 NOA 汽车辅助驾驶研究报告》。

## B 叙事主线
因为技术（端到端/VLA/世界模型）突破 + 央地政策协同（L3 准入+专用号牌破冰）→L2 渗透率触顶(66%)、城市 NOA 快速上量(15%+)、L3 从试点转商业化验证→行业进入"以法规许可和商业化验证为核心的新阶段"；投资含义：第三方 NOA 供应商竞争格局高度集中（Momenta+华为~80%），份额与卡位是核心 alpha 来源。

## C 反常识/分歧点
