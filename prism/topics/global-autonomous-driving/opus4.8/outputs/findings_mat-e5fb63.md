# Findings — 1天能跑2.4万单，李彦宏透露萝卜快跑武汉盈亏平衡了（36氪 / 智能车参考）

## A 核心数据点与事实
- **UE 盈亏平衡**：李彦宏透露武汉已实现 **UE（单位经济模型）收益平衡**，百度成为**左舵市场首家 UE 收益平衡的公司**；含义为当地每辆自动驾驶车的**收入已能覆盖其直接运营成本**（最小运作单元=一辆车）。技术栈与运营方法具跨地域可迁移性，验证后可"复制粘贴"到其他市场。
- **日订单量**：武汉 **日均能跑 2.4 万单**（标题口径）。
- **单车成本**：投放车型为最新一代 **RT6（颐驰06），对外售价 20.46 万元**；称是全球首款也是唯一从设计之初专为 L4 打造的量产车型，L4 车中单位成本已做到**全球最低**。
- **票价定位**：武汉属**中等票价市场，平均票价较国内一线城市低约 30%**；海外车费通常比国内高出好几倍（暗示更高票价市场盈利弹性更大）。
- **规模扩张（车队数+范围双轮）**：
  - 中东：进驻迪拜、阿布扎比并公开路测，与 **Uber 合作**，计划在中东和亚洲部署**数千台**无人车，首批今年底落地。
  - 欧洲：签约 **Lyft**，以德国、英国为起点逐步扩张。
  - 香港（右舵）：半年三度扩区，测试范围拓展至东涌及南区。
- **领先根因**：技术（百度 2013 年立项、十余年积累，行业数十位创始人系出百度——文远韩旭、小马彭军/楼天城、元戎周光、地平线余凯/黄畅）+ 成本（RT6 单车成本全球最低）；在中国大陆已实现所有车辆完全无人驾驶。

## B 叙事主线
因为 RT6 单车成本做到全球最低 + 中大陆全无人运营（X）→ 武汉率先跑通 UE 收益平衡（收入覆盖直接运营成本），且模型可跨地域复制（Y）→ 投资含义：单车成本领先 → 更早收支平衡 → 更快铺队/商业化闭环，且中等票价市场先盈利意味着一线/海外高票价市场盈利空间更大（Z）。

## C 反常识/分歧点
- "UE 收益平衡"仅指**收入覆盖直接运营成本**，不含前期研发/资本开支摊销——与"整体盈利"是两个概念，需警惕口径混淆。
