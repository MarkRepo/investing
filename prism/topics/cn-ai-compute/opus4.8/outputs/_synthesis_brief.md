# Synthesis Brief — cn-ai-compute / opus4.8（供 ④⑤⑥ 与 critic 复用）

## 核心 thesis（v0 强度 6.5/10 · 差异化看多）
做多国产替代"兑现层"（芯片/昇腾生态/国产HBM/上游高壁垒卖铲人），规避 capex-beta"估值顶部风险"（光模块/服务器ODM·赚业绩不赚估值），智算中心/IDC 挑回报模型清晰者。**不是全行业 all-in，是结构里挑卡位。**

## 3 命门（decomposition_v0 → 厚料 delta）
- **命门1 国产替代产能可得性（中）**：厚料 delta = 瓶颈**未解除、仅被缓冲**。昇腾 910C 仍 80% 台积电7nm + 95% 三星HBM，靠囤 1300万颗HBM + Sophgo 绕道续命；中芯7nm 月5万片辅助源、长鑫HBM 2026才可能量产 [mat-bcc950]。thesis_v0 "上游瓶颈在解除"需下修为"在缓冲、未解除"。
- **命门2 capex-beta 周期位置（中）**：厚料 = 兑现仍强（工业富联2026Q1净利+102%、中际旭创FY25净利破百亿+108%），但增速斜率回落（中际旭创营收+122%→+60%）；DeepSeek效率(-73% FLOPs)威胁"量"逻辑；估值 TTM PE 中际旭创95x/工业富联35x [mat-3a5f2a][mat-5cd92d]。
- **命门3 推理价值再分配（低→中）**：厚料 = 推理占比 40-50%、DeepSeek V4 单token FLOPs-73%/KV Cache-90%，摊薄光模块量逻辑；但国产推理卡生态门槛低受益、头部IDC上架率者受益；智算中心闲置率70-80%证明"有卡用不起来" [mat-f82211][mat-f3c41b]。

## 关键假设（③ WMBT 种子）
1. 中芯7nm产能翻倍 + 长鑫HBM3 2026规模量产进BOM（命门1兑现物理前提）
2. 英伟达/北美云厂 capex 2026-27 延续高增（前五大云厂2026 6000亿美元 [mat-3a5f2a]）—— capex-beta 层脊柱
3. 推理放量 + 国产推理卡生态成熟，价值不被 DeepSeek 效率完全摊薄
4. 智算中心从"投资驱动"转"利润驱动"，头部IDC靠上架率兑现马太效应

## v0→v1 强度调整方向
维持差异化看多，但**命门1 需诚实下修**（产能瓶颈未解除只缓冲）→ 兑现层多头信心从"瓶颈在解除"改为"兑现已财务证实但产能上限受制于台积电/三星依赖"。估值锚新增硬数字（2026-06-30 实时倍数）使 capex-beta"赚业绩不赚估值"判断更实。整体强度 6.5 维持或微调。
