## 核心数据点与事实
- [CSDN/V4技术报告][2026-05][V4 效率] V4-Pro vs V3.2 单 token 推理 FLOPs 下降 73%（仅需 27%）、KV Cache 占用下降 90%（仅需 10%）；MLA 把 KV cache 压至原约 1/28。
- [CSDN][2026-05][V4 规格] V4-Pro 1.6 万亿总参/490 亿激活；V4-Flash 2840 亿/130 亿激活；1M token 上下文为所有官方服务标配；双轨压缩注意力 CSA(128×)+HCA(1024×)+mHC+Muon 优化器；32T token 预训练。
- [CSDN][2026-05][双体系验证] 细粒度专家并行(EP)已在英伟达 GPU 与华为昇腾 NPU 双体系验证，推理速度提升约 1.5-2x。
- [DeepSeek定价表][2026-06][定价与算力绑定] Pro 输入 1元/百万token、输出 24元；Flash 0.2/2元；定价表注明"受限高端算力 Pro 吞吐有限，预计下半年昇腾 950 超节点批量上市后大幅降价"——算力结构开始决定价格体系。
- [36氪][2026-06][价值从计算流向存储] 英伟达 Vera Rubin VR200 NVL72（2026H2 交付）物料成本约 780 万美元，其中约 200 万花在内存(HBM4+LPDDR5X)，内存成本一年涨 435%。
- [36氪][2026-06][效率折算硬件节省] DeepSeek 让同硬件有效 token 产出提至 4 倍≈省 75% 硬件投资。
- [麦肯锡《计算的成本》][2026][长期需求] 2030 全球数据中心需约 6.7 万亿美元投资，AI 负载约 5.2 万亿。
- [贝恩][2025-02][三情景-基础] 推理基础架构支出缩减 30-50%，云厂 capex 从 800-1000 亿美元/年降至 650-850 亿（仍比 2023 高 2-3 倍）。
- [贝恩][2025-02][三情景-悲观] 训练预算收缩，云厂 capex 降至 400-600 亿（仍比 2023 高 1.5-2 倍）。
- [贝恩][2025-02][三情景-乐观] 杰文斯悖论：效率降本刺激需求增长，前沿训练支出仍强；结论数据中心硬件短期波动、中期仍强、应用层最受益。
- [共绩科技(王鹏)][2026][范式迁移] 训练:推理占比从 9:1 → 现 40-50%；推理对国产芯片生态门槛低于训练 CUDA 栈，利好昇腾/寒武纪推理卡。
- [36氪][2026-05][降 CUDA 依赖] DeepSeek 用 TileLang"万能转换头"+PTX 降低对 CUDA 依赖；黄仁勋警告顶尖 AI 模型优化在华为芯片运行对美"可怕后果"。

## 叙事主线
因为 DeepSeek-V4 把单 token 推理 FLOPs 降 73%、KV Cache 降 90%、同硬件有效 token 产出提 4 倍（省约 75% 硬件），且推理占比已升至 40-50%、门槛低于训练 CUDA 栈 → 所以单位算力的卡/网络/光模块用量被摊薄，"量"逻辑被削弱，价值向存储/记忆(HBM)与国产推理卡再分配 → 对投资意味着 K3 支持 thesis 的差异化看多：对光模块/服务器 capex-beta 转谨慎（效率革命压量），放大"推理放量+国产推理卡(昇腾/寒武纪)"逻辑。

## 反常识/分歧点
- 市场预期：AI 算力需求线性放量、光模块/服务器长期高增；本文表明：DeepSeek 式效率(省75%硬件)反向压缩单位需求，"量"逻辑被摊薄，钱从"算的零件"流向"记的零件"(HBM内存成本一年涨435%)。
- 市场预期：软件/生态锁定英伟达；本文表明：EP 已在昇腾 NPU 双体系验证、TileLang+PTX 降 CUDA 依赖，推理侧国产门槛显著低于训练侧，构成国产推理卡切入口。
