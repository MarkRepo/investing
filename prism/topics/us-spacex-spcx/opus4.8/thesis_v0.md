## 1. 核心 thesis（终局立场）

**当前价 ~$136（≈$1.78T 完全稀释估值，~94x FY25 P/S）下，评级 = 卖出 / 回避（AVOID）；强度 2.5/10（偏空）。**

一句话：世界级、已盈利的 Connectivity（Starlink）+ 发射内核是真的，但 ~$1.78T 估值把「Starlink 现金机器转型 + Starship 万亿 TAM 兑现 + xAI 并表 AI 分部止血」三重奇迹同时定价进去，且置于 Musk 绝对控制 + 关联交易之下——合理 SOTP 的 EV 显著为负，**目标价区间 $50–90（中值 ~$70，隐含约 –48% 下行）**，介入纪律为「仅在 ~$70–80 以下、即内核 + 发射足以托底、AI 作为免费期权时才建仓」。

> 我的立场比同 topic 的 gpt-5.6-sol 变体（「观望偏空、EV ~–4%」）**更明确偏空**：其 –4% 低估了 AI 分部 –$6.4B 营业亏损 + Q1 FY26 单季 –$4.3B 净亏 + ~94x P/S 三者叠加下的下行幅度。

## 2. 支持理由（偏空，5-6 条）

1. **估值极端**：~$1.78T FDV / ~$19B FY25 收入 = ~94x P/S，而合并层面 FY25 净亏 –$4.9B、Q1 FY26 单季净亏 –$4.3B（近全年水平，暗示烧钱在加速）——这是给「未来多年零失误执行」定价。
2. **AI 分部是现金焚化炉**：AI 分部（并表 xAI）FY25 收入 $3.2B 但营业亏损 **–$6.4B**；它把「AI + 太空」故事灌进估值，却在持续吞噬 Starlink 产生的现金。
3. **SOTP 兜不住**：即便给盈利的 Connectivity（$4.4B 营业利润）40x = ~$176B、发射内核 + Starship 期权再给 $200–400B，合计仍远低于 $1.78T——缺口是纯 Starship/AI 期权 + 稀缺性溢价。
4. **现金消耗期长**：2029 年前 FCF 不转正 + 举债 $25B；重资本 LEO 星座补网（卫星 ~5 年寿命）是长期现金黑洞，历史镜鉴（Iridium/OneWeb/Globalstar）对重资本卫星网络毫不留情。
5. **治理折价结构性**：Musk 绝对投票权 + 双层股权 + xAI 关联并表 → 少数股东保护弱、Starlink 现金被引去补贴 AI 烧钱的风险；学术研究普遍显示永久双层股权随时间损害少数股东。
6. **供给面压顶**：IPO 后提前出售机制 + 锁定期到期 + 内部人减持，向一个建立在故事溢价上的价格释放筹码；首日 $161 → 6/18 $189 → 7/14 $136 的高波动已显现脆弱性。

## 3. 最大反方观点（看多，诚实列，非稻草人）

1. **Connectivity 是真·顶级资产**：$4.4B 营业利润、10.3M 订户 / 164 市场、$27.6B backlog、D2C 期权——一个真实盈利、垄断式、高增长的宽带资产，单独就值可观。
2. **发射近乎垄断 + Starship 期权**：Falcon 现金牛 + Starship 若量产将解锁任何 SOTP 都难以量化的万亿级 TAM（巨型星座降本、深空、政府），静态倍数会系统性低估。
3. **稀缺性溢价可长期存在**：唯一能同时买到「太空 + LEO + 前沿 AI」的标的，指数纳入 + 散户需求可让溢价维持得比基本面证明的更久。
4. **街面看多**：分析师均价目标 ~$240（较近价 +50%）、14 家买入评级——街的模型假设 AI 分部转正 + 收入年复合 40–50%。

## 4. 会改变看法的事件 / Killer Questions（可观测、可证伪）

- **K1 — Starlink 现金穿透**：Connectivity $4.4B 营业利润能否穿透为**集团层面 FCF**，还是被补网 capex + AI 烧钱吞掉？
  - 证伪锚：FY2026/2027 Connectivity 分部 FCF 披露；集团 FCF 转正时点较 2029 提前/推迟 ≥12 个月。
- **K2 — AI 分部烧钱轨迹**：AI（xAI）分部营业亏损是收窄还是加速？是否会出现「Starlink 现金被明确引去补贴 xAI」的资本承诺？
  - 证伪锚：季度 AI 分部营业亏损环比（Q1 FY26 –$6.4B 年化基准）；任何 xAI 去并表/分拆或新增数十亿美元 AI 资本承诺公告。
- **K3 — Starship 兑现时钟**：Starship 能否进入常态化商业发射，从而 ①压低 Starlink 补网 capex ②打开新 TAM？
  - 证伪锚：FAA 复飞许可后连续成功入轨节奏 + 首个商业载荷在 2027 前兑现；反之再现事故/停飞则右移。
- **K4 — 估值反推 / EV 收敛**：市场是向可辩护的 SOTP 收敛，还是故事溢价持续？
  - 证伪锚：SOTP 隐含合理值 vs 现价的差；卖方 $240 目标 vs 实际；锁定期/供给驱动的 de-rating 是否发生。
- **K5 — 治理 / 控制折价**：绝对控制 + 关联并表触发的是持续折价，还是治理事件（关联交易损害少数股东）？
  - 证伪锚：关联交易规模披露；被引去 xAI 的资本量；少数股东保护条款的实际强度。
