## 1. 切换为 Bull 视角的 Steelman 反方

thesis_v3 整体偏看空（7/10 bear），下面以**最强 Bull 论证**反驳每个核心空方假设。

### 对「核心假设 1：2 年单向整治期 → 13% 账户 -78% NPV」的质疑

**空方原假设**：13% 大陆账户 2 年线性衰减至 0，按 r=10% DCF 等价当期 -78%（v3 §0a F7 + 04 v2 §SOTP 校准）

**Bull 反驳**：
- **存量客户不等于存量资产**：13% 账户占比是"funded accounts 数量"，不是"client assets / 收入贡献"。FUTU 官方从未披露大陆客户实际收入贡献，sell-side 普遍估计 8-12%（因为大陆客户中小户偏多，户均资产显著低于 HK/海外 high-net-worth 客户）。若实际收入贡献仅 8-10%，则 -78% NPV 应改为 -50% × 8%/13% ≈ -30% 当期价值，比 v3 假设温和 48pp。
- **"2 年只能卖不能买"实际是缓退而非清退**：客户在 2 年内可以慢慢转移到合规账户（如香港本地券商、海外券商），FUTU 可能通过**关联方/海外子公司**接住部分客户（合规边界内的"客户迁移"），实际净流失可能仅 40-50% 而非 100%。
- **历史路径参照不对**：v3 用 BIDU/DIDI 类比，但那两家是"业务模式被禁"，FUTU 是"业务范围调整"，本质差异。更接近的类比应是 2018 BABA 大陆电商监管 → 业务调整而非清退。

**支撑证据**：
- mat-474086 IR 公告原文未给出大陆客户**收入贡献**数据，只给 13% **账户数量**
- mat-e7abd3 sell-side 共识 +800K paying clients (+24% YoY) 完全是 PRE-CSRC 数字，但若 sell-side 在 5-22 后下修也只下修到 +500-600K → 隐含市场认为大陆账户损失对客户增长影响 **<35%**

**强度评估**：**中-强** — 这是 v3 最薄弱的假设之一。-78% NPV 是基于"账户数 = 收入"的线性外推，但实际券商行业 ARPU 高度非线性。**关键变量是 5-28 业绩会是否披露大陆收入贡献占比**。

### 对「核心假设 2：CEO 罚款是 3 阶段递进的第 1 步」的质疑

**空方原假设**：李华个人罚款 RMB 1.25M → 第 2 阶段（公开通报）P2=40% / 第 3 阶段（失信名单 / SFC 撤销 RO）P3=10%（v3 §2.12 + 06 v2 §B4）

**Bull 反驳**：
- **罚款金额对 CEO 个人是"象征性"**：RMB 1.25M ≈ USD 183K，对李华（FUTU 控股股东，身价超百亿）是九牛一毛，明显是 CSRC 给出的"程序性定责"而非"实质惩罚"。这个金额恰恰说明 CSRC 不想搞 CEO 个人 - 给个数字让监管闭环就行。
- **BIDU/DIDI 类比不准确**：李彦宏从未被 CSRC 单独罚款（百度本身不在中国 CSRC 监管范围）；DIDI 程维罚款是因为故意 IPO 违规情节恶劣。FUTU CEO 罚款 1.25M 量级远低于"实质处罚"门槛。
- **第 3 阶段路径概率被高估**：v3 给 P3=10%（SFC 撤销 RO 资格 / 列入失信名单），但 SFC 与 CSRC 是独立监管机构，FUTU 香港业务合规无问题 → SFC 主动撤销 RO 的法理基础几乎不存在。这是 v3 最"恐慌驱动"的假设。

**支撑证据**：
- 历史上 SFC 仅在持牌主体严重违反香港《证券及期货条例》时撤销 RO（FUTU 香港业务从未被 SFC 立案）
- DIDI 程维罚款 RMB 80M（量级是李华的 64×）才进入"治理风险升级"区间
- 监管定责到自然人也可以是"程序性 → 程序性 → 程序性"3 阶段封闭，不必然递进

**强度评估**：**强** — Bull 在这一点上有合理性，v3 P2/P3 概率应下修。建议 v4 把 P2 从 40% → 25%，P3 从 10% → 4%。

### 对「核心假设 3：sell-side 目标价集中下修 → 二次下行 -10 到 -20%」的质疑

**空方原假设**：$217.75 stale target vs $91.90 现价 → sell-side 集中下修 + 基金被动调仓 → 二次下行（v3 §0a F10 + 06 v2 §R5）

**Bull 反驳**：
- **股价已自我先行**：5-22 单日 -26% 已经把 sell-side 模型滞后定价提前 priced in。sell-side 目标价下修发生时市场往往**已经走出**，不再有新的卖压（参照 2018 BABA 监管事件：sell-side 下修目标价时 BABA 已经反弹 +20%）。
- **基金被动调仓时点错位**：KWEB ETF 调仓在季度末（6-30 / 9-30），距 5-22 还有 5 周时间窗，且 KWEB 跟踪指数权重调整通常滞后 6 个月——5-22 事件最快影响是 11 月调仓。
- **sell-side 集中下修反而是反向指标**：当 sell-side 集中下修目标价到现价附近时，往往意味着"机构卖盘释放完毕"，是技术性 buy signal 而非 sell signal。

**支撑证据**：
- mat-f8fcc2 Simply Wall St 视角："管理层借 5-28 业绩会重塑海外扩张故事" — 暗示 sell-side 等业绩会数据后才会真正下修，5-28 是 inflection point 而非中间过程
- 历史参照：BABA 2020-11-03 监管事件 -8% 当日，sell-side 集中下修 11-04 至 12-15，股价反而从 $250 反弹到 $290

**强度评估**：**中** — Bull 的"sell-side 下修反指"有历史依据但样本量小。R5 风险存在但幅度可能 -5 到 -10%（而非 v3 假设的 -10 到 -20%）。

### 对「核心假设 4：罚款现金流 Q2 一次性冲击 → EPS miss」的质疑

**空方原假设**：RMB 18.5 亿 = USD 257M 占 FY2025 净利 18%，Q2 一次性计入 → 单季 GAAP 净利可能从正变负（v3 §2.14 + 06 v2 §B7）

**Bull 反驳**：
- **大型上市公司行政处罚通常分摊计提**：USD 257M 一次性计入对 EPS 影响过激，财务上可以：(a) Q1 计提 50% + Q2 计提 50%；(b) 部分作为"提前计提"在已结束的 FY2025 Q4 重做；(c) 直接计入"营业外支出"不影响 operating EPS。Sell-side 通常用 "non-GAAP excluding regulatory" 报告 EPS，市场对此口径熟悉。
- **罚款是已知数字 → 不构成"miss"**：5-22 后所有 sell-side 估算都会把 18.5 亿计入 2026 EPS 预测，不存在 "miss" 概念（miss 是"未预期到"，已知数字不算）。
- **罚款抵税效应**：在大陆/香港税务框架下，行政处罚可作为"营业外支出"抵减应纳税所得（部分），实际现金流影响可能仅 USD 200-220M。

**支撑证据**：
- 历史参照：BIDU 2021 Q1 反垄断罚款 RMB 8.1 亿，分 Q1+Q2 各 50% 计提，未触发 EPS miss
- sell-side（mat-5f8b8a）虽未明确下修方法但行业惯例是 spread across quarters

**强度评估**：**中-强** — B7 假设过激，v4 应改为"罚款已 fully informed 不构成 incremental risk"。

### 对「核心假设 5：5-28 业绩会需海外 ARPU 占比 ≥ 50% 才能做多」的质疑

**空方原假设**：v3 §5 仓位策略要求"必须 5-28 披露海外 ARPU 占比 ≥ 50% 才入场"（07 v2 §仓位决策更新）

**Bull 反驳**：
- **门槛设得过高**：海外账户占比 87%、海外收入占比 32%（mat-af428c），海外 ARPU 已经显著低于 HK/PRC。要求海外 ARPU 占比 ≥ 50% 等于要求海外收入 +57%（从 32% → 50%）——这相当于一年内海外 ARPU 翻倍，业务逻辑上不现实。
- **更合理的门槛**：海外**收入占比** ≥ 40%（vs 当前 32%）+ 海外 paying clients +30% YoY → 即可视为 K1' 国际化承接通过。50% 门槛过严，把"通过/不通过"概率人为压到 <15%。
- **门槛是"事后可解释"陷阱**：v3 把门槛设得很高，但 5-28 业绩会结果不达标时，作者很难判断是"门槛设错"还是"业务真的不行"——这种 ex-post rationalization 风险高。

**支撑证据**：
- 行业经验：高 ARPU 客户占比超过 50% 的散户券商极少（IBKR 是机构占比高才达到 60%）
- mat-e7abd3 sell-side 共识隐含全年 paying clients +24% 但没说海外占比 → 市场对海外接力期望也不到 50% ARPU

**强度评估**：**强** — Bull 反驳准确。v4 应把门槛改为"海外收入占比 ≥ 40% + 海外 paying clients +30% YoY"。
