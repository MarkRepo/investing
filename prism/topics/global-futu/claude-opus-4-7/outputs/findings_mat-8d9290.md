## 核心数据点与事实

- 【事件】 2026-05-22 FUTU 收到中国证监会及深圳证监局《立案告知书》+《行政处罚事先告知书》
- 【违法事实】 FUTU 在大陆+香港的"相关公司"（Related Companies）**未取得相关牌照或批准**，在中国大陆开展证券业务 / 公募基金销售业务 / 期货业务
- 【适用法律】 中国《证券法》《证券投资基金法》《期货和衍生品法》
- 【拟处罚措施】 责令改正/停止 + 没收违法所得 + 罚款，总额约 **RMB 18.5亿（USD 271M）**
- 【个人处罚】 创始人 + CEO 李华个人罚款 **RMB 125万（USD 183,575）**
- 【最终性】 处罚尚需进一步程序 + 证监会最终决定（公司有权申辩、陈述、申请听证）
- 【公司回应】 一直与证监会保持沟通 + 已实施整改措施
- 【关键披露】 截至 **2026 Q1 末，大陆 funded accounts 占总 funded accounts 约 13%**
- 【关键保证】 大陆以外地区的业务运营保持正常；海外 funded accounts 持续稳定增长

## 叙事主线

因为 **CSRC 5-22 处罚事件让 K5（大陆监管最终落地）从风险变成 confirmed event + 罚款规模 RMB 18.5亿 接近 FUTU 2025 全年净利 HKD 11.3B（约 RMB 10.4B）的 18% + 个人罚单首次涉及李华** → 所以 thesis_v1 §1 super-bear（K5 触发）从假设升级为基线，roadmap K5'（二次监管/限制扩大）+ K6（罚款上调）触发概率显著上升 → 对投资意味着：5-22 是 FUTU 估值锚被市场强制重置的"事件冲击日"，PE 锚从 25-30× 下沉到 15-22× 是常识应对，但**大陆账户已只剩 13% + 海外业务正常**给出"利空出尽"的反弹半径。

## 反常识/分歧点

- 市场可能假设"罚款=继续大陆运营但缴费" → **实际处罚措辞是"责令改正/停止"——意味着大陆业务必须彻底退出，未来不存在"罚后照常"的回旋**
- 市场可能担心罚款会因后续 negotiation 大幅上调 → **CSRC 已明列条款 + 公司放弃抗辩可能更快结案**，18.5亿是法律框架内的明确上限（违法所得没收 + 法定倍数罚款）
- 大陆账户只剩 13% → **这意味着 FUTU 在 2024 中已经预判事件且主动清退，5-22 事件的财务冲击仅相当于罚款一次性 + 失去 13% 账户存量收入（≈年化 HKD 1.5B 收入冲击，仅 6.6%）**
- 5-22 同日 TIGR 也宣布被 CSRC 北京局调查 → **行业系统性事件，不是 FUTU 单独被点名**——可能限制 PE 单独折价幅度
