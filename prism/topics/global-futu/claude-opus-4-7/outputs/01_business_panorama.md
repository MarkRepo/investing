# 商业全景：富途控股（FUTU）

> 生成于 2026-05-25，训练知识占比约 35%，资料更新截至 2026-Q1。

## 行业定义与边界

富途控股属于"**亚太跨境互联网券商**"细分赛道——以 HK 为核心持牌主体（Futu Securities International (HK) Limited 持 SFC 1/2/4/5/9/10 等多类牌照），向**全球华人散户 + 香港本地散户 + 东南亚/日澳新马 6 地散户**提供港股/美股/美股期权/A 股北上/加密资产等多市场跨境交易和财富管理服务。

**边界**：
- **算行业**：跨境零售券商（FUTU、TIGR、Longbridge）+ 美国零售券商（IBKR、HOOD、SCHW）+ 美股清算商
- **不算行业**：传统投行（GS、MS）+ 大宗商品交易商 + B2B prime broker

**行业分类**：GICS 4020 多元化金融，SW 二级"证券" + "互联网金融"。

## 市场规模与结构

- **全球散户跨境券商市场**：可投资财富 SCHW 自估美国 USD 85T（2026 上调）+ 亚太华人圈估算 USD 5-8T = 全球 USD 90-93T TAM（mat-468de9）
- **当前渗透**：SCHW 在美国渗透 14.9%（USD 11.9T / USD 80T），FUTU 在亚太华人圈渗透 < 3%（USD 158B / USD 5-8T 估算）
- **集中度**：美国 CR3 = SCHW + IBKR + HOOD ≈ 80% 客户资产；亚太华人圈 CR2 = FUTU + TIGR ≈ 70%
- **FUTU 体量锚**：FY2025 收入 HKD 22,847M（USD 2.93B），净利 HKD 11,302M（USD 1.45B），客户资产 HKD 1,233B（USD 158B）— 仅 SCHW 客户资产的 1.34%

## 商业模式

**主体**：To C 多业务平台
- **佣金**：港股/美股/期权 take rate 7.2 bps（2025）vs 9.3 bps（2023）持续下行但被交易量上行覆盖
- **利息**：客户保证金贷 + 客户隔离现金 + 自营资金 → 客户资产规模 × NIM；FY2025 利息收入 HKD 10.4B
- **财富管理**：基金代销 + 养老金 + 私募；占 FY2025 收入约 5%
- **银行**：Airstar Bank 2025 收购完成（HK 虚拟银行 + 跨境清算）—— 商业模式向 SCHW 收敛
- **加密**：通过 Hashkey Omnibus 接入，2025 Q4 交易量 HKD 20B（占总交易量 1.5-2%）

**盈利驱动公式**：
```
净利润 ≈ 客户资产 × (佣金率 × 周转率 + NIM + 财管费率) - 平台 / S&M / 监管成本
```

S&M 费率从 2023 的 10.4% 优化到 2025 的 8.7%（mat-af428c），规模效应已经显化。

## 需求端分析

- **客户类型**：高净值散户（中位 AUM ~USD 47K vs HOOD ~USD 7K，gap 6.7×）
- **决策驱动**：跨境投资便利度 + 港美股低费率 + 一站式平台 + 中文界面
- **核心需求增长**：
  1. **亚太华人财富全球化**：高净值客户从单一市场（HK / SG / TW / JP 本地）转向全球化资产配置
  2. **大陆居民海外配置渠道收缩后的存量挤迁**：5-22 事件之后 13% 大陆账户被迫退出，但**存量华人海外持仓需求**（已在海外的 HK 永居、新加坡 PR、加拿大 / 澳洲华人）反而上升
  3. **加密牌照渐进开放**（K2）

## 供给端分析

- **主要参与者**：
  - 跨境券商：FUTU + TIGR + Longbridge（HK/SG 系）
  - 全球券商：IBKR（瑞士背景）
  - 美国本土：SCHW + HOOD（不与 FUTU 重叠）
- **进入壁垒**：
  - 高：监管牌照（SFC/HKMA/SEC/MAS/JFSA 多牌齐全）
  - 高：清算系统 + 跨境结算技术
  - 中：用户教育 + 中文社区运营
  - 低：APP 体验同质化（已成熟）
- **产能 / 供给增速**：FUTU 持牌地区从 2020 年 3 地（HK/US/CN）扩展到 2025 年 9 地（HK/US/SG/JP/MY/AU/CA/NZ/CN(已限制)）

## 竞争格局

- **类型**：地理细分市场内**双寡头**（亚太华人圈 FUTU + TIGR），但**全球散户大格局碎片化**
- **核心竞争要素**（仅 3 个）：
  1. **跨境合规深度**：跨境券商最稀缺资源是"在多国同时持牌且合规无瑕疵"——FUTU 5-22 事件后这条护城河有缺口
  2. **客户 ARPU**：FUTU USD 870 客户 ARPU 是 HOOD 的 8.7×、TIGR 的 ~1.3× → 高质客户群是稀缺资产
  3. **业务多元化**：佣金 + 利息 + 银行 + 加密 + 财管的多腿并行能力——FUTU 通过 Airstar Bank 收购已比 TIGR 多 1 腿
- **行业龙头与优势来源**：
  - 亚太：FUTU（占据 HK 散户 ~30% + 跨境平台先发）
  - 美国：SCHW（资管 + 银行 + 经纪三业）
  - 全球：IBKR（专业 / 机构 / 国际，但 retail 端不强）
