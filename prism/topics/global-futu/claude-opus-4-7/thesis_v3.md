## 2. 支持理由（看空 / 看跌，当前完整清单）

### A. 已实锤项（不可逆事件）

1. **K5 super-bear 触发**（mat-8d9290 / mat-dd79f7 / mat-474086）：CSRC 5-22 处罚 RMB 18.5 亿 + 2 年单向整治期 + CEO 个人罚款 1.25M，违反三法定性比"跨境违规"严厉
2. **2 年单向整治模式比"业务损失"更狠**（F7，mat-fc40d5）：v0/v1 假设大陆 13% 业务"一次性损失 50%"，实际是"2 年只准卖不准买"——客户存量 NPV 按 r=10% 衰减约 -78%（线性假设下）；同时 2 年期内客户不能补充新资金，意味着流失账户的 ARPU 在剩余 2 年内可能高于历史平均（plumage shedding 临死前的资产保护性出货）。**注**：critic 指出 -78% 是基于"账户数 = 收入"的线性外推，实际券商行业 ARPU 高度非线性；大陆账户实际收入贡献可能 8% / 13% / 25-30% 三档情景（待 5-28 业绩会校准）
3. **CEO 个人罚款已实化**（F8，mat-474086）：B4 治理风险已发生第 1 阶段；critic 下修后续阶段概率为 P2（公开通报）25% / P3（SFC 撤销 RO 资格 / 失信名单）4%——比 v3 初稿（40%/10%）温和，但仍是 super-bear 路径的潜在打通口
4. **公司估值标签从"科技成长"→"政策风险中概"**（mat-af428c / 训练知识）：市场会用"中概股折价"评估 FUTU 而非"跨境券商成长股"，PE 中枢可能从 25-30× 压到 12-18×（参照 BIDU/TME/JD 估值轨迹）

### B. 未完全 priced in 的下行风险

5. **二次监管悬剑**（K5'，mat-76154a / mat-0efe7b）：CSRC 5-22 公告口径是"证券+公募基金销售+期货经纪"三业，未提加密 / 数据出境 / 反洗钱，意味着 CAC（数据出境）/ HKMA（加密牌照）/ SFC（反洗钱核查）后续接力发动的概率至少 1/4
6. **sell-side 目标价集中下修期是定时炸弹**（F10，mat-5f8b8a）：$217.75 stale target vs $91.90 现价 = 137% gap。未来 2-4 周 sell-side 模型更新 + 基金被动调仓 + ETF 删除 → 技术面 -5 到 -10% 二次下行。**注**：critic 指出"sell-side 集中下修反向指标"理论有历史依据但样本小，幅度从 v3 初稿 -10~-20% 下调至 -5~-10%
7. **罚款现金流冲击可能在 Q2 一次性计入**（B7）：RMB 18.5 亿 = USD 257M 占 FY2025 净利 USD 1.45B 的 18%，公告未说明支付时点 → Q2 GAAP 净利可能从正变负，触发 EPS miss。**注**：critic 指出大型上市公司行政处罚常分摊计提，部分作 "non-GAAP excluding regulatory"，且罚款已知数字不构成"miss" → 该风险等级中-弱，主要看 5-28 业绩会管理层口径
8. **K1' 国际化"收入端"被严重高估**（F3，mat-af428c）：87% 海外账户但仅 32% 海外收入 → 海外 ARPU 仅 HK 1/9，即使大陆 13% 账户全部流失，海外要承接需账户数再翻倍才能补齐收入；按当前 +47% YoY 速度需 24-30 个月才能完成

### C. v0 周期性逆风继续成立

9. **2024-2025 戴维斯双击高基数压力**（mat-352f09 / mat-692050 + akshare）：港股 ADV 2025 高达 2700-3100 亿 HKD，2026 H2 进入高基数对照后经纪佣金 YoY 压力大

## 3. 最大反方观点（看多 / 看不空，当前完整清单）

### A. 罚款数字反而比恐慌预期低

1. **罚款金额比市场恐慌时低**（F6 衍生）：5-22 盘前 -40% 隐含市场对罚款最高估计 ≥ 30 亿 RMB；实际公告 18.5 亿——比恐慌情景低 38%。意味着首日 -26% 收盘已含"超过事实的恐慌"成分，技术性反弹 10-15% 至 $100-105 区间是 base case
2. **TIGR 罚款比例线性印证 CSRC 不会"杀鸡儆猴"**（F6 衍生 + mat-474086）：FUTU 18.5 亿 / TIGR 4.112 亿 ≈ 4.5:1 与市值比例线性 → CSRC 按市占率分级处罚而非政治性单边打击，部分降低 K5' super-bear 概率
3. **罚款金额对总市值占比可控**（v1 既有逻辑）：USD 257M vs 事件后市值（USD 12-13B）约 2%——一次性可消化

### B. 大陆冲击边际有限 + 国际化对冲

4. **大陆 13% 占比远低于市场恐慌想象**（v1 既有逻辑 + mat-af428c）：2022 第一次行动后 FUTU 已悄然完成大陆比例从 45% → 13% 的去化，事件冲击边际有限
5. **大陆账户实际收入贡献可能低于线性 13%**（critic 强反驳 §对假设 1）：sell-side 普遍估计大陆客户收入贡献 8-12%（中小户偏多，户均资产显著低于 HK/海外 high-net-worth 客户）。若实际 8-10%，则 -78% NPV 应折减为 -50% × 8%/13% ≈ -30% 当期价值，比 v3 初稿温和 48pp
6. **"2 年只能卖不能买"实际是缓退而非清退**：客户在 2 年内可通过香港本地券商/海外券商缓慢转移，FUTU 可能通过关联方/海外子公司接住部分客户（合规边界内的"客户迁移"），实际净流失可能仅 40-50% 而非 100%
7. **盈透 IBKR +11% 承接溢出预期未必兑现**（v1 既有逻辑）：合规迁移摩擦大（美国账户对大陆居民也有限制），溢出客户可能流向新加坡/日本本地券商，富途的国际化布局直接接住一部分
8. **海外接力可能比 v2 预期更快**（F9 衍生 + mat-e7abd3）：sell-side 共识 +800K paying clients (+24% YoY) 显示市场对海外承接信心仍在 → 若 5-28 业绩会 Q1 实际 +200K-250K（符合季节性）则 F3 "海外 ARPU 9× gap" 论点边际弱化（账户数 +24% × ARPU 改善 +10% = 收入 +36% 即可覆盖大陆流失）

### C. 业务底盘 + 第二估值锚

9. **Airstar Bank 第二估值锚**（F1，mat-af428c）：FUTU 不再是"纯佣金券商"——Bank deposit fee + 港币利息差 + 跨境清算手续费 = 类 utility 现金流，长期支撑 PE 不应跌破 SCHW 锚定的 16-18×
10. **行业 Q1 2026 仍然双位数高增长**（F4，mat-352f09 / mat-d84b6f / mat-692050）：IBKR commission +19% / HOOD 客户 +6% QoQ / SCHW +16% → FUTU 2026 Q1 业绩（5-22 事件前 1 个月数据）也极可能 +30-50%，意味着事件冲击是**估值压缩**而非"基本面恶化"，技术性反弹空间仍存在
11. **客户 ARPU 是 HOOD 的 8.7 倍**（F4 衍生）：HOOD 客户 25M+ vs FUTU 3.4M，但客户资产 HOOD 200B / FUTU 158B = 1.27× → 客户质量是 HOOD 的近 9 倍，"高 ARPU 贵宾散户"模式在监管周期中仍是稀缺资产
12. **加密业务 K2 仍在演进**（v0 既有逻辑 + mat-0efe7b）：富途通过 Hashkey Omnibus 接入，2026 H1 美股加密落地 + 香港 VATP 渐进落地，5-10% 收入贡献仍有上行可能

### D. 技术面 + 市场结构

13. **市场已 fully informed pricing 不需要进一步下行**（critic 强反驳）：v3 期望值 $93.1 ≈ 现价 $91.90 → 后续行情 5:5 双边对赌，做空 risk/reward 收紧；做多需 5-28 业绩会 + 6-05 罚款两个 catalyst 都正面，路径苛刻但非不可能
14. **市场反应不极致**（v1 既有逻辑）：盘前 -39% → 收盘 -26%，说明部分多头愿意 dip-buy，存在反弹技术面支撑
15. **CEO 罚款 RMB 1.25M 是"程序性定责"非"实质惩罚"**（critic 强反驳 §对假设 2）：对李华（FUTU 控股股东，身价超百亿）是九牛一毛——CSRC 明显给出"程序性定责"而非"实质惩罚"。SFC 与 CSRC 独立监管，FUTU 香港业务合规无问题 → SFC 主动撤销 RO 法理基础几乎不存在，P3 路径概率应仅 4%
