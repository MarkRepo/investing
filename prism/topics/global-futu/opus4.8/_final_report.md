**补料后结论实质变化**（已落地 thesis_v2 / c_investment_case v2 / 07_decision_kit v2 / findings_mat-ebfa48）：
1. ❌ **撤回错误红旗**："回购授权累计零执行" → Q1 实际回购 **US$418M ADS**。原"资本配置减分"作废。

**这是本轮最大的流程教训**：复用模式 ≠ 不抓时效料；最该抓的恰是发生在"资料收集日之后"的最新财报。下方第五节的"复用模式根本局限 #1"应以此更正为准。

## 一、最终决策答案（一句话 + 可执行）

**审慎试探的"监管错杀"机会，强度 5/10——买入但只试探仓，绝不裸空，务必等 Q2 财报。**

- **方向**：偏多（不做空）。在 11.5x 的悲观定价上裸空需"大陆高利润占比 + 监管追加动作"同时成立，赔率差。
- **价位**：当前 $104 落在"可建仓区"（$85-115，锚相对倍数模型 base 下半段）；强力买入 ≤$85；>$145 不追。
- **仓位**：**试探仓 ≤1.5%**（或零仓观望——对不接受"黑箱上下注"者更诚实）；满仓上限 5%，仅当 Q1/Q2 证实大陆利润 ≤15% + 罚没一次性落定后才升仓；加仓阶梯 $95/$85/$75。
- **EV**：概率加权 ≈ **+8%（12mo）**，下行 −40% / 上行 +65%，赔率 ~1.6:1（边际偏多，非强信号）。
- **核心赌注（命门1）**：大陆 13% 入金账户对应多少利润？——**一手报表是黑箱，无法证伪**；罚没 RMB18.5 亿"违法所得"反向提示大陆收入基数不小。
- **kill**：2 年整治期内任一监管追加动作 → 清仓；财报证实大陆利润 >25% → 减仓。

## 五、流程问题 & 可优化点（完整见 `_process_notes.md`）

**复用模式（换模型重研）的根本局限**（呼应 memory `project_variant_reuse_gotchas`）：
1. **形式完整但一手深度薄**：最关键的 Q1 2026 业绩（5-28 披露）晚于资料收集日（5-25）未入库 → 命门1 + 罚没计提的解锁信息缺位。
2. **consensus 整条 ring 无料（v3 复核后依旧成立）**：卖方一致预期/目标价/利率敏感模型未收 → EV/估值带建立在"无卖方锚校准"的自推上，置信度封顶"中"。**注：一手 SEC EX-99.1 入库也补不了这条**——业绩稿/财报本就不含卖方一致预期，仅第三方援引一个 $150 目标（非官方 consensus）。要真正闭合需另抓卖方研报/Bloomberg/Refinitiv consensus（一手财报无能为力）。详见本轮答复。
3. **mat_id churn**：复用 add_material 生成全新 mat_id，旧变体 findings 引用作废 → 跨变体不能直接搬正文，须重抽。

**对 prism 系统的可优化建议**：
- **#1 [脚本]** 提供 `retag_addresses_by_filename` 批量按文件名打 K#/rings，免 32 条逐条调。
- **#2 [环境]** 任务期间静音 gitnexus 只读 DB 的 FTS 噪声 hook。
- **#3 [金融特例]** financial_data 对券商类吐 ROIC 2858%（客户资金并表失真），quality_screen 应行业特例标注或改 ROE/ROTCE。
- **#4 [复用语义]** `check_prescan_health` 在"复用资料"模式下误报 failed（只数本轮注册）；需"prescan 继承/复用"语义，否则被迫手动判 partial。
- **#5 [合成]** EV→首仓可加机械映射（chain-critic 指出当前非 Kelly、仅定性）。

**正向验证**：
- prescan 纪律真实提升质量——剔除了 opus4.7 曾写入的未证实"大陆占比 45%"流言。
- findings 抽取用 read-only subagent 返回文本、主 agent 落盘——干净绕开"subagent 脑补 Write 幻觉"，3/3 成功。

1. **P0 命门1 黑箱**：大陆真实收入/利润占比，一手报表不可得 → 须 Q1/Q2 财报或卖方大陆敞口测算。

4. **P2 罚没最终金额**：听证程序后可能变动。
