**"现价 $97.54 是错杀，还是基本公允？"** —— 多头信"罚没一次性 + 大陆≈13% + 盈利不压缩 → Base $115+、错杀"；空头信"峰值-E 注水 + 降息/ADV 压缩 + 政策尾部 → Base ~$95-110、现价公允甚至偏贵"。v6 偏向后者（中性）。

### 观点光谱（v6 · Base 去峰值-E，校至现价 $97.54）
> v6 相对 v5 的唯一结构变化：**Base 不再用峰值-E**。v5 Base $125（+35%）是靠 FY2025 峰值净利算出来的；代入作者自承的 20-30% 盈利压缩 + Q1 经营线"尚未压缩"的对冲，正常化 Base = **$95-125（中 $110）**。两条 bear 路径保持独立：

| 情形 | 触发假设 | 12mo 价位（中点） | 相对 $97.54 |
|---|---|---|---|
| **政策 de-rate Bear** | KILL-A 追加动作 或 命门1>25% 清退 → 政策性 de-rate（无底，对齐滴滴 −80%） | $38–45（中 $41） | **−58%** |
| **盈利压缩 Bear**（独立于命门1） | 2026 净利 −20~30%（降息+ADV），前瞻 PE 13-15x，无政策升级 | $58–72（中 $65） | **−33%** |
| **Base**（正常化口径·v6 去峰值-E） | 大陆利润 15-20%、罚没一次性、盈利温和压缩或持平、微 re-rate | $95–125（中 $110） | **+13%** |
| **Bull**（无外部硬锚·主观） | 大陆≈13%、阴霾彻底散、海外接棒、**盈利不压缩**、re-rate 向 15x | $160–190（中 $175） | **+79%** |

> Bull 要四重连环（阴霾散+海外接棒+盈利不压缩+re-rate）同时成立，真实联合概率低，权重压到 ≤15-25%（按信念）。

### ⚠️ EV 敏感性测试（v6 · Base 去峰值-E 后全面下移，@$97.54）
| 配权方案 | 政策/盈利/Base/Bull | EV@$97.54 | 解读 |
|---|---|---|---|
| **偏多** | 15/15/45/25 | **+12%** | 即便最乐观配权，去掉峰值-E 注水后头条 EV 从 v5 的 +25% 砍半到 +12% |
| **bear-tilt（对政策尾部更现实）** | 25/25/35/15 | **−6%** | 翻负——v5 此处还是 +4%，Base 去注水后跨进负区 |
| **重 bear（周期见顶 + 命门1偏空都计入）** | 30/30/30/10 | **−15%** | 明显翻负 |
| **灾难 bear** | 35/30/30/5 | **−22%** | 政策 de-rate 主导 |

算式留痕（供复核，Base=+13%）：
- 偏多：`0.15×(−58%)+0.15×(−33%)+0.45×(+13%)+0.25×(+79%) = −8.7−4.95+5.85+19.75 = +11.95%`
- bear-tilt：`0.25×(−58%)+0.25×(−33%)+0.35×(+13%)+0.15×(+79%) = −14.5−8.25+4.55+11.85 = −6.35%`
- 重 bear：`0.30×(−58%)+0.30×(−33%)+0.30×(+13%)+0.10×(+79%) = −17.4−9.9+3.9+7.9 = −15.5%`
- 灾难 bear：`0.35×(−58%)+0.30×(−33%)+0.30×(+13%)+0.05×(+79%) = −20.3−9.9+3.9+3.95 = −22.35%`

**诚实结论（v6）**：v5 的"偏多 +25%"是 Base 用峰值-E 注水撑起来的。去注水后，**只有最乐观配权才勉强 +12%，任何对政策尾部现实一点的配权（bear-tilt 起）即为负**。这把结论从"中性偏多/错杀"收回到"**中性 / 现价基本公允**"——上行靠"盈利不压缩 + 监管散"的乐观连环，下行有两条独立肥尾。
- **赔率不再非对称**：上行 +13%~+79%、下行 −33%~−58%，且下行一条（盈利压缩）根本不需命门1 输。这是一笔**对配权高度敏感、中位 EV 贴近零甚至偏负**的赌。
- **"它从 $92.62 回升到 $97.54"不构成多头加分**：回升只是把 v5 那点"接刀缓冲"也抹掉了，赔率更差。

### 我的判断 + 信心
**中性 / "高质量复利机器，但现价基本公允、非错杀"，信心：中（4/10，v6 自 5/10 下调）**。下调理由：① Base 去峰值-E 后正常化中枢仅 ~$110、距现价 +13%，"错杀"叙事的安全垫蒸发；② EV 在任何现实 bear 配权下为负（−6%~−22%），偏多 +12% 依赖乐观连环；③ consensus 纠偏后 bear 档目标（$87-102）已贴近/低于现价，外部锚不再支持"保守 base"。**未变的**：franchise 质量、罚没一次性（Q1 ex-penalty +36%）、回购落地、经营引擎 Q1 仍加速——所以**不是看空、绝不裸空**，只是"质量高 ≠ 现价值得买"。
**行动取向（v6）**：**零仓观望为默认**——在命门1（大陆口径）+ 2026 盈利轨迹两个关键变量于 2026-Q2/H2 揭盅前，正 EV 仅存在于最乐观配权、无证据支撑。**绝不裸空**（10.8x 悲观定价 + 运营加速 + 在回购的标的做空赔率差）。**小仓试探（≤2%）仅在 ≤$80**——此处对应"周期/盈利 bear 大体定价、且贴近 SOTP 30%-情形下沿"，但须明示**政策 de-rate bear（$38-45）仍裸露**。

## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

### 已知风险 + 盲点风险
- **已知**：① 大陆利润占比远超 13%（命门1 反向，JPM 测算切割→盈利 −30% 是偏空外部锚）；② **盈利压缩（独立翻车路径，不依赖命门1）**：降息侵蚀利息（占 45.7%）+ 港股 ADV 持续收缩 → 2026 净利同比可能转负、10.8x 峰值-E 幻觉戳破、杀向前瞻 13-15x。25Q4 净利 QoQ−8% + 指引不上调是先兆——**但 Q1 经营线尚未兑现压缩（剔除罚没 +36%、成交额 +29%），故为前瞻风险非既成事实**。
- **盲点**：① 大陆**精确**收入/利润占比仍未拆分（一手只到港 vs 其他），偏空官方口径仅二手 + JPM 外部测算；② 罚没"没收违法所得"口径若追溯多年历史，金额可能远超 RMB18.5 亿账面；③ 双层股权下小股东对资本配置无话语权（但 Q1 已证回购落地）。

### kill 触发条件（→ sidecar kill_criteria）
- **KILL-A（命门2 尾部，super-bear）**：2 年整治期内 CSRC/HKMA 出现**任一追加动作**（追加罚没/牌照吊销/责令加速清退/对李华扩大追责）→ 立即清仓多仓（政策 de-rate，下行 −58%）。
- **KILL-B（命门1 证伪）**：任一财报/披露证实**大陆收入或税前利润占比 >25%** → 下调至 3/10，减仓至观察仓。
- **KILL-C（引擎熄火）**：非大陆付费户净增 < 50 万/年 或 海外持续亏损获客 → bull 支柱倒，退出。

### signpost 调和（v6 · daily-monitor 翻 bear 的正确读法）
- **2026-Q2 业绩会：大陆口径披露 + 罚没计提**（命门1 关键窗口）。

- 美联储 2026 降息节奏（K4，直接驱动盈利压缩 bear）。

### ≥2 历史失败镜鉴
1. **蚂蚁集团 IPO 暂停（2020）** —— 失败模式=政策反转/监管重定义商业模式。教训：中国金融科技的监管风险可瞬间从"尾部"变"主体"。**现在是否已现**：✅ 已现（2026-05-22 行政处罚就是这种转向的实锤）。
2. **滴滴下架退市（2021-22）** —— 失败模式=数据/合规触发强制下架 + 退市，市值蒸发 ~80%。**现在是否已现**：⚠️ **部分已现，且不应读成"没那么糟"的安慰**——富途大陆 App **下架已坐实（mat-4d2cb9，FUTU+TIGR 同步下架）**，这正是滴滴剧本的**第一幕实据**（滴滴当年也是先下架 App、仍正常上市，随后才被强制退市 −80%）。"富途仍美股+H 股正常上市"不是"未到滴滴程度"的安全证据，而是这出戏可能才演到中段——这是环④"政策 de-rate bear −58%"和 KILL-A 的实证模板，不是反例。
3. **嘉信 2023 久期错配挤兑** —— 失败模式=利率急升暴露久期错配 + 客户现金搬家。教训：券商的"利息收入"在利率剧变时是双刃剑；**且回购不构成估值地板（嘉信当年在回购仍 −45%）**。**现在是否已现**：❌ 未现（富途是降息侧风险非挤兑，但提示利息线脆弱 + 回购≠地板）。
> 三个镜鉴失败模式各异（政策反转/强制下架/利率冲击），不是只挑成功案例。镜鉴据训练知识 + 大陆 App 下架一手锚（mat-4d2cb9）。
