# thesis_v0 — 药明合联（继承自父 arena cn-adc）

## 一、核心 thesis（含强度评分）

**药明合联是 ADC 赛道唯一盈利的"卖水人"——全球 ADC CRDMO No.1、份额 >24%、643 客户/前 20 大药企覆盖 14 家、在手订单 +50.3% 至 14.9 亿美元——不押单一临床、不承担二元风险，是 arena 里风险调整后最优的 beta 配置（K5 答案）。看多其行业 β（ADC 市场 CAGR 30%）+ 份额 α + 项目阶段后移三重驱动；核心风险在地缘（北美收入 51%）与下游砍管线传导。强度 5/10。**

（父 arena 6/10；卖水人确定性高 +1，但 PE 43x/PS 11.7x 不便宜 + 地缘风险显著 -2 → 5/10）

## 二、支持理由
1. 盈利+高增长：2025 营收 59 亿(+46.7%)/净利 14.8 亿/经调整净利率 26.2%/EBITDA margin 33%，与烧钱 biotech 截然不同 [mat-8a6432]。
2. 前瞻可见度：backlog +50.3% 至 14.9 亿美元、252 个一体化项目、128 post-IND [mat-8a6432]。
3. 护城河：全球份额 >24% No.1 + "All-in-One"一体化消除分散供应链痛点 + 客户随分子推进锁定。
4. 第二曲线：WuXiTecan-2 平台授权 up to 8.85 亿美元，从纯服务向 IP 变现延伸。

## 三、反方观点（最有力）
1. **地缘风险（最大盲点）**：北美收入占比 51%，BIOSECURE 类去中国化立法风险年报未显性披露，是确定性溢价的最大威胁 [mat-8a6432]。
2. **"不承担二元风险"非完全免疫**：下游临床失败/砍管线仍经项目活跃度传导 backlog，只是被组合分散。
3. **估值不便宜 + 重资本**：PE 43x/PS 11.7x，PP&E +48% 重资本扩张期、不派息，回报兑现节奏待验。
4. 母公司药明系关联交易，独立性需关注。

- **K4（核心新增）**：北美 51% 收入的地缘（BIOSECURE）敞口有多大，最坏情形对估值的冲击？*(新增·公司专属最大风险)*
