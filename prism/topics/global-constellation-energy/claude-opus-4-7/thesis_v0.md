# Constellation Energy（CEG）— Thesis v0

## 1. 核心 thesis

**CEG 作为美国最大核电运营商（55GW、不可复制存量资产），未来 18-30 个月将经历从公用事业估值（PE 15-18x）→ 科技基础设施估值（PE 22-28x）的系统性重估；三哩岛重启 + 后续 ≥2 份大科技公司 PPA 是关键验证锚点。**

**强度评分：7/10**（看多，方向明确；保留 3 分余量给监管事故风险与 SMR/储能替代速度的不确定性）

## 2. 支持理由（5 条）

1. **物理稀缺性**：核电是当前唯一规模化、可调度的 24/7 无碳基荷电源，AI 数据中心负荷因子 75-90%，太阳能/风能 + 储能在 2030 前的 LCOE 与可调度性都无法满足顶级 hyperscaler 的"全无碳 + 全时段"承诺。CEG 173,119GWh 核电年发电量约占全美核电的 1/4。
2. **重估标杆已立**：Microsoft 20 年 PPA（三哩岛 1 号机组 / Crane CEC，835MW）是核电"科技基础设施溢价"的标志性交易；DOE $1B 贷款担保 + IRA Section 45U PTC（每 MWh ≥ $15）将下行风险显著限制。后续 Meta/Google/AWS 跟进的市场预期很强。
3. **资产不可复制**：新建核电从设计到并网在美国需要 12-15 年（Vogtle 案例），且 NRC 新堆审批门槛极高；CEG 现有 55GW 已经在运、已经赚钱、许可证大多延展到 2040-2055。这种"今天就在赚钱的未来稀缺资产"通常会享受重估溢价（参考 ASML / TSMC 路径）。
4. **利润下降的误读**：FY2025 净利润 $2.32B vs FY2024 $3.75B（-38%）主要是 Calpine 收购的一次性会计调整，营业利润 $3.09B vs $4.35B 也含整合摩擦——市场如果按 GAAP 净利润看 EPS 下修，会形成短期错杀，是逆向加仓窗口。
5. **政策与监管利好**：IRA Section 45U（核电 PTC）+ DOE 贷款担保 + 2024 年 ADVANCE Act 简化 NRC 流程 + 政府明确把核电纳入 AI 国家战略——多重政策对存量核电运营商形成正向叠加，与新能源补贴退坡形成对照。

## 3. 最大反方观点（3 条）

1. **监管/安全黑天鹅**：任何一次有人员伤亡或显著放射性外泄事故（哪怕基础概率极低）会瞬间抹掉重估溢价并触发整体行业 derate（参考 1979 三哩岛 / 2011 福岛）；Crane 项目 NRC 换发许可证非自动批准，2024-2028 任何节点延期 12 个月以上即推迟现金流确认。
2. **24/7 替代路径成熟**：储能成本（特别是长时储能 LDES）若在 2026-2028 加速下降，可再生 + 储能组合可能以更低 LCOE 满足 hyperscaler 的 24/7 无碳承诺，稀释核电的"唯一性"叙事——NEE 已经在签可再生 + 储能的 24/7 PPA。CEG 没有自有 SMR 储备，长期可能错失下一波核电浪潮。
3. **PPA 定价天花板**：当前 Microsoft PPA 推测价格在 $100-115/MWh，对 hyperscaler 是溢价但绝对量上仍是边际成本（电力占数据中心 TCO 的 ~20%）；如果 hyperscaler 自建（如 Meta 自投核电）或转向新型 SMR 直接采购的模式扩散，CEG 的议价权会被压缩。

## 4. Killer Questions（5 条，可观测可证伪）

- **K1（PPA pipeline 验证）**：CEG 是否在未来 18 个月内（截至 2027-11-30）公开签署 ≥2 份大科技公司（Meta/Google/AWS/Oracle/OpenAI 任二）的长期 PPA，单笔 ≥500MW、期限 ≥15 年？
  - 验证：公司 8-K 公告 / IR 新闻稿 / hyperscaler 官方声明
  - 证伪：12 个月内零新签 + 管理层电话会减弱预期措辞

- **K2（Crane 项目时间节点）**：Crane Clean Energy Center（三哩岛 1 号）NRC 运营许可证换发是否在 2026Q4 前获批，且 2028 年内并网投运指引未推迟？
  - 验证：NRC 官网 license amendment 状态 + CEG 季报维持 2028 重启目标
  - 证伪：NRC 程序延期至 2027+ 或 CEG 把重启时间改成 2029+

- **K3（Calpine 整合利润率）**：Calpine 收购完成（预计 2026 上半年）后，CEG 核电 segment 的 EBITDA margin 在 FY2027 全年是否 ≥ 55%（vs 行业可再生 30-40% / 燃气基荷 35-45%）？
  - 验证：FY2027 10-K segment 数据
  - 证伪：核电 segment EBITDA margin 跌破 50% → 重估逻辑动摇

- **K4（PPA vs 现货价差）**：CEG 已签订的 PPA 加权平均锁定价格是否 ≥ $90/MWh（PJM 现货长期均值约 $40-55，2025 因 AI 需求飙至 $80+）？且新签 PPA 价格是否高于上一份？
  - 验证：财报披露的 PPA 平均价格 / Bloomberg / S&P Global Platts 跟踪
  - 证伪：连续两份新 PPA 单价低于前一份 ≥ 10% → 议价权见顶

- **K5（EPS 上修）**：FY2026 + FY2027 共识 EPS 在 Microsoft PPA 收入正式确认（预计 2028 起逐步入账）前 12 个月是否有 ≥ 15% 的上修？管理层是否在 FY2026Q3 或之前给出 FY2028+ 的明确数字 guidance？
  - 验证：FactSet / Bloomberg 共识 EPS 跟踪 + 管理层电话会 transcript
  - 证伪：共识 EPS 持续下修 + 管理层回避具体数字 → 估值倍数无法扩张

## 5. 研究中重点验证项（5 条 → 引导 workflow 01 roadmap）

1. **PPA pipeline 全景**：CEG 已签 + 谈判中的所有 PPA（不仅 Microsoft）的客户、容量、单价、期限、起算日；与 NEE / Vistra / Public Service Enterprise 的核电 PPA 对照
2. **资产清单与许可证时间轴**：55GW 容量结构（核电 22GW / 天然气 / 可再生）、机组逐一列出运营寿命剩余、许可证到期年份、重启或新建潜力
3. **估值锚点搭建**：构建 PE 15-18x（公用事业历史均值）↔ PE 22-28x（科技基础设施目标）的隐含 EPS 与目标价区间；FY2027/FY2028/FY2030 三档情景
4. **政策风险与监管 calendar**：NRC 换发流程、DOE 贷款担保里程碑、IRA Section 45U 实际现金流入、2026 大选潜在政策反复
5. **同业对照**：vs Vistra（核电 6GW 同样在重估，VST 涨幅 vs CEG）/ vs NEE（可再生 24/7 PPA 是否成形）/ vs SMR 远期期权（NuScale 估值方法学差异）
