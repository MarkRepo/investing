## 3. 支持理由（必须有 mat_id 引用）

1. **核电存量稀缺 + 14 个站点规模化运营** — CEG 22 GW 核电 + Crane 0.84 GW 重启 = 美国独立核电运营商第一（mat-4182c2 CEG 10-K）。美国新建核电周期 12-15 年，AP1000/SMR 2030+ 才有 1 GW 级实际投运（同业 mat-fc68eb NEE 10-K Duane Arnold 重启对照）。

2. **Hyperscaler PPA 模板已立 + 行业三向验证** — Microsoft 20 年 Three Mile Island PPA（CEG, 2024）+ Meta 20 年 Clinton PPA（CEG, 6/2027 COD）+ AWS 1.2 GW Comanche Peak（mat-9a190d VST 10-K）+ Meta 2.609 GW Comanche/Forney（mat-9a190d）+ AWS 1,920 MW Susquehanna FtM（mat-9763b5 TLN 10-K，FERC 2024-11 阻止 BtM 后转 FtM 仍生效）。模板成立，第 3-N PPA 不是"是否"而是"何时 + 哪家"。

3. **PJM 容量价持续跳升** — 2025-26 RTO 出清 $269.92/MW-day → 2026-27 $329.17 → 2027-28 $333.44（mat-9763b5 TLN 10-K）。CEG 14 GW 美东核电 + Calpine PJM 气电直接受益；2028/29 BRA 即使触及 $175 floor 也比 2024 前 $20-50 水平高一个量级。

4. **Calpine 整合协同 + 资本回报双驱** — 合并 4/2026 完成、对价 $26.6B、首季整合费用 $119M（预期内）；$4.4B 回购授权 + LS Power 4.4 GW 剥离 $5B 现金到账（mat-d4ec44 CEG Q1 2026 10-Q）。即使无新 PPA 信号，FY2026-2027 仅靠回购 + 协同也支撑 EPS CAGR 10-12%。

5. **政策护城河 + DOE 贷款锁定** — OBBBA（2025-07）保留 45U 至 2032 + 45Y 至 2035 + ADVANCE Act 加速许可；Crane 项目获 DOE LPO $1B 贷款承诺（mat-4182c2）。即使 2028 政治轮替，PTC 已为现有 + Crane 锁定到 2033+。

## 4. 反方观点（必写，必须有 mat_id 引用）

1. **核电安全尾部风险无法对冲** — 美国 25 机组任一发生 INES 4+ 级事件 → 行业系统性 -30-50% 重估，CEG 受影响 ≥40%。福岛对照 TEPCO/EDF -90%+。无法通过分散降低（CEG 占美国核电 ~22% 份额）。Kill criteria #1。

2. **第 3 PPA 12 月未现 → multiple 收缩** — 当前 PE 25.6x 已隐含 14-15% 5Y EPS CAGR，若未来 12 月 hyperscaler 核电 PPA 行业全空（含 Google/Amazon/Oracle/OpenAI），市场将质疑"AI 核电基础设施"叙事是否过度透支，PE 可能回压至 18-20x → 股价 -25-30%。Kill criteria #2。

3. **Calpine PJM 容量价见顶 + 整合协同低于预期** — Q1 整合费用 $119M 单季度 > $0.34 EPS 拖累（mat-d4ec44）；若 FY2026-2027 整合费用 > $400M/年 + PJM 2028/29 BRA 触 $175 floor → 气电 segment EBITDA 比当前预期低 $0.8-1.2B，FY2027 Adj EPS < $14（vs 卖方共识 ~$16）。Kill criteria #6/#7。

4. **SMR 自给自足叙事 2027-2028 接管** — 若 NuScale / TerraPower / X-Energy 在 2027-2028 期间公布 hyperscaler 1 GW 级订单（不是 MOU 而是实际签约），AI 数据中心电力的"必须找 CEG/VST/TLN"叙事将被冲击。NEE 已布局 SMR + LDES + 风光 24/7 包（mat-fc68eb），构成长期替代路径。是最大盲点风险。

5. **FERC 监管反转 + 共置 PPA 法律基础动摇** — FERC 2024-11 已阻止 TLN-AWS BtM 配置（mat-9763b5），改 FtM 后才生效。若 FERC 在 2027-2028 重新审视 hyperscaler-核电共置 PPA 的容量分摊、传输费补偿条款 → 已签 PPA 单价可能被强制调整 -10-15%。Kill criteria #3。
