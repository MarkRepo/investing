### 镜像 1：Vistra（VST）2021-2025 — 「IPP→PPA 长期合约平台」同业最直接对照

**类比维度**：
- 供需结构：merchant 核电（Energy Harbor 4 GW）+ 气电组合，与 CEG 22 GW 核电 + Calpine 25 GW 几乎同结构。
- 政策环境：同样受 IRA 45U PTC + PJM 容量价上涨 + hyperscaler 需求脉冲驱动。
- 估值叙事：从「公用事业 PE 12-16x」→「AI 基础设施 PE 25-32x」，2021 至 FY2025 市值从 $30B → $65B（+117%）。
- 参与者行为：Pioneer Natural Resources、活跃基金、AI 主题基金集体进入。

**类比局限**：
- VST ERCOT 比重 50%，CEG PJM 比重 70%（监管环境不同）。
- VST 核电仅 6.4 GW，CEG 22 GW（规模差 3-4 倍）。
- VST 没有 Calpine 体量的并购整合风险（CEG 整合期 18-24 月）。

**历史结果**：
- VST 2021 IPO（OTC 时 ~$15）→ 2024-04 $103 (10×) → 2025-04 ~$200 → 2026-Q1 $185。
- 2024-09 AWS PPA、2025-09 AWS 扩展、2026-01 Meta 2.6GW PPA 三笔大单加速重估。
- 2025-12 标普升 BBB- IG。
- 累计回购 $5.9B / 1.67 亿股（33% 缩股）。

**对当前的启示**：
- CEG 路径 2024-09 Microsoft 大单 → 2025-06 Meta-Clinton 大单 → 2026-Q1 Calpine 关账，比 VST 时间线晚 6-9 个月。
- 历史中"第二个大单 + IG 升级"是最强催化（VST 这两件事相隔 ~4 个月）；CEG 第二个大单已是 Meta-Clinton，下一步是 IG 升级与 LS Power 剥离 + Calpine 协同。
- 如果完全跟随 VST 路径，CEG 在 2027-2028 应有 PE 28-30x（FY2027 Adj EPS $14-16 × 28x = $390-450）。

### 镜像 3：ASML 2017-2024 — 「不可复制工艺资产 → 全球科技基础设施」估值范式跃迁

**类比维度**：
- 供需结构：ASML 是 EUV 光刻机唯一供应商；CEG 是美国 22 GW 核电唯一规模化运营商（不可复制：新核电美国 12-15 年）。
- 政策环境：ASML 受出口管制 + 半导体战略红利；CEG 受 IRA + DOE + ADVANCE Act 加持。
- 估值叙事：从「半导体设备股 PE 18-22x」→「科技基础设施 PE 35-45x」，PE 倍数翻倍以上。
- 参与者行为：长期投资基金 + 主权基金 + 主题基金集体涌入。

**类比局限**：
- ASML 全球独占（市场份额 90%+），CEG 在美国核电运营 22%（不是独占，但顶级稀缺）。
- ASML 是无形资产 + 工艺壁垒；CEG 是实物资产 + 牌照壁垒。
- ASML 自由现金流复合增速 25%+，CEG 预计 14-18%。
- 终极倍数 CEG 不会到 35-45x（公用事业属性 + ARO/退役负债）。

- ASML 2017 ~€140 → 2024 €1,000（+614%），PE 从 20x → 45x。

**对当前的启示**：
- 重估的核心机制是**估值范式切换**：从行业归类 A 切到行业归类 B。CEG 正在经历从 IPP / utility → AI 基础设施 的类似切换。
- ASML 路径暗示重估完整周期 5-7 年；CEG 自 2022 IPO 起算约 4 年，估值翻 6-7 倍，已完成中期 65-80%，还有最后 20-35% 空间。
- 关键："独占性叙事" + "终端需求结构性增长" + "合约/订单可见性" 三条件同时满足时，估值跃迁不是线性而是阶跃。CEG 已具备前两条，第三条（PPA pipeline）正在累积。

### 失败镜像 1：Exelon / Constellation 上一轮 2005-2013 — 「核电复兴叙事破灭」

**当年的相似性**：
- 叙事相似度：高 — 2005-2008 期间美国"核电复兴"叙事盛行（油价 $147、气价 $13、政治支持加州/纽约）；与 2024-2026 的 AI 核电叙事结构相同。
- 估值水位相似度：高 — Exelon 2008 年 PE 18-22x、PB 3.5x（与 CEG 当前 25.6x / 3.18x 接近）。
- 政策/资金面：UAEPC、Vogtle、Summer 同期开建，DOE 给予贷款担保（与今天 ADVANCE Act + DOE LPO $1B 相似）。

**最终结局**：
- **失败模式**：① 2011 福岛事件 → 全球核电监管全面收紧（NRC 后果分析延误新堆审批）② 美国页岩气革命 → 天然气从 $13 跌到 $2-3 → merchant 核电变亏损 ③ 可再生 PTC 推动风电 LCOE 跌至 $30/MWh → 核电 PPA 没人买。
- **损失幅度**：Exelon 股价 $90（2008）→ $28（2013，-69%）；多座核电厂提前退役（Vermont Yankee、Pilgrim、Indian Point）。
- **触发崩塌**：2011-03 福岛 + 2011-2014 持续低气价 + 风电 PTC 持续延期。

**对当前的警示**：
- **最早的预警信号**：① 天然气价格跌破 $3.5/MMBtu 持续 3 个月以上 ② 任何核电安全事件（同业即可）③ FERC / NRC 政策口径转向收紧 ④ hyperscaler 出现自建/自购 SMR 实际落地（非声明）。
- **现在已出现的信号**：弱 — 气价稳定 $3-4 区间、Meta 已表态投资 Westinghouse AP1000（轻微负面）、SMR 当前 LCOE $90-110/MWh（不构成短期威胁）。
- **如果出现，应对**：① 核电事故 → 立刻减仓至首仓的 30%以下 ② 气价持续 < $3 + IRA 削弱 → 减至 50% ③ hyperscaler 实际自建 1 GW+ SMR 投运 → 减至 70%。

## 类比综合与当前定位

**最相似的成功时刻**：VST 2024-Q4 至 2025-Q2（AWS 1.2GW 大单签订后、Meta 2.6GW 即将公告前）— 与 CEG 当前 Microsoft 已签 + Calpine 关账 + LS proceeds 即将到账阶段非常接近。

**最相似的失败时刻**：Exelon 2008-Q4 至 2009-Q2（核电复兴叙事顶部 + 福岛事件前）— 但这次"福岛"角色被两层 firebreak（IRA 政策 floor + 长合约 PPA）保护。

- **成功镜像如果实现，潜在回报区间**：+45% 到 +80%（VST 路径 9-18 月内到 $425-470 + ASML 路径 24-36 月到 $530+）。
- **失败镜像如果实现，潜在损失区间**：-30% 到 -55%（清洁能源叙事破灭 -30%；监管/安全黑天鹅 -55%）。
- **现在更像哪一类？理由**：**更像成功镜像**（70% 权重）— ① VST 已示范同类路径可行 ② IRA + ADVANCE Act + DOE 三重政策护城河 ③ 长期 PPA 形成 16-23 年现金流 floor。但失败镜像的 tail risk 不能忽略（30% 权重），主要是核电事故 + IRA 反转两个尾部。
- **最大的差异点（不能类比的地方）**：
  - vs Exelon 2008：今天有 IRA 45U/45Y、有 hyperscaler 长合约 PPA、有 PJM 容量价 collar — 这些都是 2008 没有的下行保护。
  - vs First Solar：核电不存在类似多晶硅那样的产能爆发风险（NRC 控制供给）。
  - vs TEPCO：CEG 不在地震带，美国 NRC 监管严格但稳定。

**结论**：CEG 当前位置类比成功镜像（VST 2024-Q4-2025-Q2）更准确；失败镜像主要作为风险提醒。
