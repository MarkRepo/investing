## 核心数据点与事实（17 条，全部 SEC 备案审计后数据）

- [VST 10-K FY2025] 总发电装机 43,641 MW：天然气 26,989 MW (62%) / 煤 8,743 MW (20%) / 核电 6,448 MW (15%) / 可再生 1,274 MW (3%) / 燃油 187 MW（接近零）。核电仅占装机的 15%，但贡献了非整合后的全部碳零基负荷。
- [VST 10-K FY2025] 6 座核电机组 4 座电站：Comanche Peak Unit 1/2 (ERCOT, 2×1,200 MW, 许可证至 2050/2053) + Beaver Valley Unit 1/2 (PJM, 939+933 MW, 至 2036/2047) + Perry (PJM, 1,268 MW, 至 2046, 2025-07 NRC 批准展期) + Davis-Besse (PJM, 908 MW, 至 2037)。后 4 座来自 Energy Harbor。

## 叙事主线（3 句）

VST 用 $4.6B 总对价（含 $3.1B 现金）拿下 EH 4GW PJM 核电后，18 个月内顺势锁定 AWS 1.2GW + Meta 2.609GW = 3.8GW 长期 hyperscaler PPA，相当于其全部核电（6.448GW）的 59%——这是公开市场上首次有运营商把 hyperscaler PPA 覆盖率拉到这个水平。叠加 PJM 容量价从 $270 → $333/MW-day 的阶梯 + 标普 BBB- IG 评级，VST 实质上完成了「竞争性发电商→长期合约化基础设施运营商」的身份重塑。对 CEG 的暗示是：CEG 的 thesis（PE 15-18x → 22-28x）需要的「hyperscaler PPA + 容量阶梯 + IG 信用」三件套已被 VST 跑通，CEG K1（≥2 份 PPA）已是行业标准、不是 surprise，市场会要求 CEG 接下去拿出 PPA 单价披露 + 整合后 EBITDA margin 数据兑现。

## 反常识/分歧点（3 条）

- VST 10-K 完全没披露 AWS / Meta PPA 单价、capacity payment 结构、indexation 机制。10-K 只说 "20-year PPA, 1,200 MW carbon-free power"——这意味着 K4（CEG PPA 加权均价 ≥$90/MWh）即使在已经签约的对照公司 VST 也不可被外部直接验证；CEG 若不主动披露 PPA 经济性，市场只能靠 IRA PTC + PJM 容量价 + 现货价反推，重估弹性可能受限。
- Section 45U 核电 PTC 不是 floor，是 phase out trigger。FY2025 VST 核电 PTC 收入 $220M vs FY2024 $545M，-60%——并非业务恶化，而是高电价把 gross receipts 推过 phase out 区间。这意味着 CEG 在 2026-2027 高电价情景下，PTC 收入会先升后降甚至归零——分析师如果天真把 PTC 当作业绩 floor 模型化，会显著高估 CEG out-year EPS。
- 「55% nuclear segment EBITDA margin」在 VST 数据中找不到对应锚。VST East segment（含 4GW 核电+燃气+煤）调整后 EBITDA margin 仅 ~37%（$2.282B / $6.174B）；即使全部 EH 核电产量 (32,203 GWh × 假设 $50/MWh + 容量) 估算独立核电 EBITDA margin，行业 30-50% 区间是常态。CEG K3 设定 ≥55% 看起来需要 hyperscaler PPA 高溢价 + 整合协同的双轮驱动，VST 现有口径下还看不到这种 margin 水平的同业证据。

## 对 CEG thesis 的对照启示

- 对 K1（hyperscaler 长期 PPA）：✅ 强烈验证。VST 在 18 个月内签下 3.8GW（1.2GW AWS + 2.609GW Meta），均为 20 年期 + 全部核电属性。CEG 已有 TMI 重启 + Microsoft PPA（~835MW），如果 K1 设的是「≥2 份 ≥500MW ≥15 年 PPA」——VST 已示范这是行业可达水平，CEG 完成 K1 的概率应上调。但要观察 CEG PPA 是否覆盖现役机组（高确定性）还是限于 TMI 重启（高执行风险）。
- 对 K3（核电 segment EBITDA margin ≥55%）：⚠️ 偏离同业基准。VST East segment 综合 margin 仅 37%；即使隔离纯核电业务（EH FY2025 全年并表，capacity factor 90.8%），按 hyperscaler PPA 单价 ~$80-100/MWh 估算 EBITDA margin 也大概率落在 45-55% 区间。CEG-Calpine 整合后 ≥55% 是高线目标，需要 (a) PPA 单价升至 $100+ (b) 整合协同显著兑现。
- 对 K4（PPA 加权均价 ≥$90/MWh）：❓ 无法直接对照，VST 10-K 未披露 PPA 单价。可参考的间接锚：(i) PJM Western Hub FY2025 现货 $50.25/MWh（VST 核电 90% 出现在 PJM）；(ii) PJM 容量价 ~$330/MW-day → $120/kW-yr ≈ $14/MWh-equiv；(iii) IRA 45U PTC 上限 $15/MWh。三者裸合 ~$80/MWh 不到 $90 门槛——CEG 要打到 $90+ 必须靠 hyperscaler PPA 显式溢价（10-30%）。
- 对 Q5（重估路径）：VST 路径显示，hyperscaler PPA 大单 → S&P 上调至 IG（BBB-）→ 利率下行 + 投资人结构变化 → multiple 扩张。VST 自 2021 至 FY2025 通过 $5.9B 回购缩股 + 4GW 核电整合，市值从 $30B 区间上行到 ~$65B（10-K 中 2025-06-30 非关联方持股市值 $65,311M）。CEG 类比窗口可能需要 (a) 信用评级催化 (b) 第二份 hyperscaler PPA 的 reveal effect (c) 容量价定价进一步上行。
- K2（Crane 重启）VST 无对照：VST 4GW 核电是已运营机组，不存在 NRC 重启许可问题；这意味着 K2 是 CEG 独有的执行风险，VST 完全没法做 benchmark，市场对 CEG 的折价应主要来自这一项。

## 未回答问题（3 条）

- VST 与 AWS / Meta 的 PPA 是否含 capacity payment + 现货 upside sharing 结构？纯固定 vs indexed 直接决定是 utility multiple (15x) 还是 infra multiple (25x)。10-K 未披露。
- VST FY2026/2027 PJM 容量价跳升带来的现金流，多少会被 nuclear PTC 反向消耗（因为 gross receipts 升入 phase out）？管理层没给净增量 guidance。
- Cogentrix（5,500 MW 燃气）+ Lotus（2,600 MW）整合后，VST 是否会进一步把 hyperscaler PPA 扩展到燃气 carbon-free 资产（如 with CCS）？这会影响 CEG 在燃气 + 核电组合上的可比性。

- 可信度：高 / SEC 备案审计后（独立审计师签字 Item 8）。
