# 风险盲点：Constellation Energy（CEG）

> 训练知识占比约 55%（风险框架）+ 资料 45%（已知风险提取）

---

## 市场已知风险（共识，已被定价）

### 1. FERC CIR 6/1 二元事件（短期最大）

- **市场定价方式**：已折价 5-10%（CEG 4 月以来从 $345 回落到 $294 部分反映此事件不确定性）。
- **CEG 自己披露**：CIR 豁免被拒绝 → Crane 投运推迟至 2030-12，相对 2028 推迟 24 月，FY2028-2029 EPS 影响 -$1 到 -$2。
- **是否被充分定价**：**适当** — 二元事件难以精确定价，市场用 -10% 折价应对约 50% 概率的负面情景。

### 2. Calpine 整合费用与协同兑现

- **市场定价**：折价 3-5%（Q1 整合费用 $119M / 季 × 4 = $476M 全年是已知数）。
- **风险量级**：如果 FY2027 整合费用仍 > $200M（vs 指引 < $50M），Adj EPS 会被压缩 $0.5。
- **是否被充分定价**：**适当**。

### 3. NRC 许可证更新（NMP1、Ginna 2029 到期）

- **市场定价**：折价 < 1%（市场假设 100% 续证概率）。
- **风险**：任何机组 NRC 拒绝续证 → 该机组 NPV 直接归零（NMP1 ~635 MW × $1.5B/GW = $0.95B 资产）。
- **是否被充分定价**：**不足**（历史 NRC 续证拒绝概率 < 5%，但 2029 集中到期 + Crane 同年重启 = 监管 calendar 集中风险）。

### 4. 商誉 $11.107B 未来减值

- **市场定价**：折价几乎为 0（GAAP 数字，非现金，普通投资者忽略）。
- **风险**：12 月计量期内 + 后续如气电 EBITDA 不达预期 → 单季度计提 $3-8B（GAAP EPS 大幅波动，但不影响 Adj EPS）。
- **是否被充分定价**：**过度低估**（机构投资者关注 Adj EPS，零售可能错误反应 GAAP EPS）。

### 5. PJM 容量价回落

- **市场定价**：折价中等 — collar $175-325/MW-day 已是政策固定，下方有 $175 floor 保护。
- **风险**：2028/29 + 2029/30 BRA 拍卖落在 collar 下沿（$175），相对当前 $333 减少 $158/MW-day → CEG 22 GW × $158 × 365 ≈ $1.3B/年减少。
- **是否被充分定价**：**适当**。

## 潜在盲点风险（刻意寻找）

### 盲点 1：hyperscaler 自建 / 自购 SMR 的"信号"早于实际产能（B 类：叙事掩盖）

- **风险描述**：Meta、Google、Oracle、Microsoft 都已公开表态投资 SMR 或自建核电（Meta 投 Westinghouse AP1000、Google 与 Kairos Power、Oracle 与 Holtec/Westinghouse）。即使实际 SMR 商业化在 2030 后，"hyperscaler 自给自足"叙事一旦在 2027-2028 占据主流，会直接稀释 CEG 议价权和 multiple。
- **为什么市场可能低估**：① 当前 SMR 商业化进展确实早期（NuScale 2024 已取消 UAMPS 项目，市场对 SMR 失望）② 现存 PPA 是 20 年锁定，短期不受影响 ③ 卖方一致预期忽略叙事切换风险。
- **触发条件**：① 任一 hyperscaler 公告"已与 SMR 厂家签 PPA、2028 投运"② 任一 SMR 项目实际 EPC 启动 + 投运时间在 2029-2030 ③ Meta AP1000 项目 2027-2028 期间获得 NRC 实质性批文。
- **影响量级**：**中等到严重**。PE 从 25.6x 直接重估至 20-22x（-15-20%）。
- **当前迹象**：弱（声明居多，实际 capex 投入小）。

### 盲点 2：核电运营事故（CEG 自有或同业）的连带 derate（A 类：二阶效应）

- **风险描述**：任何 1 起核电运营事故（即使非 CEG 自有），全球行业会出现"安全文化重审"，监管成本飙升，新签 PPA 议价权下行。1979 三哩岛、1986 切尔诺贝利、2011 福岛模式。
- **为什么市场可能低估**：① 50 年频次 ~3 起，base rate ~6% per decade，看似很小 ② 核电自动化与监管已超越 1979 时代 ③ 投资者把"行业安全"当作前提假设，没在估值中给折扣。
- **触发条件**：① 任一美国核电站 INES 4 级以上事件 ② 任一海外（中、俄、欧）核电站 INES 5 级以上事件 ③ Vogtle / Crane 重启过程中发生重大事故。
- **影响量级**：**严重至致命**。CEG 单日 -20-35%；持续 18-36 个月行业 derate。
- **当前迹象**：无。CEG 14 站点全年容量因子 90-95%，运营表现优良。

### 盲点 3：可再生 + 长时储能（LDES）24/7 PPA 商业化 2027 拐点（E 类：技术颠覆）

- **风险描述**：NEE / Duke / AES / 8minute 等公司 2026-2028 验证可再生 + LDES 组合可以以 LCOE $80-100/MWh 提供"24/7 carbon-free"供应；hyperscaler 转向后，CEG 新签 PPA 议价权下降 + 现存 PPA 续约 multiple 收缩。
- **为什么市场可能低估**：① NEE Duane Arnold 重启 25 年 PPA 反向证明可再生 + 储能"还不够"，市场把这当成"长期不成立"② LDES 单位 capex 仍 $400-600/kWh，2030 前不太可能跌至 $200 以下 ③ IRA OBBBA 已续期，可再生 + 储能补贴退坡时间放缓。
- **触发条件**：① 任一可再生 + 4-8h 储能项目签 ≥ 1 GW 24/7 hyperscaler PPA（明确的产品规格）② 流体电池 / 铁电池 / 重力储能任一突破到 8h+ 商业化 + $150/kWh ③ DOE LPO 给 LDES 项目大额贷款担保。
- **影响量级**：**中等**。第 3-5 个 PPA 单价从 $115/MWh 下调至 $85/MWh → FY2029 后 EPS -10-15%。
- **当前迹象**：弱（NEE 自身重启核电是反信号）。

### 盲点 4：Trump 政府 2026-2028 政策反转 / 关税战传导（D 类：政策尾部风险）

- **风险描述**：2026 中期选举共和党巩固 + 2028 大选保守派后续政策可能：① 削弱 IRA 45U/45Y 实际执行 ② 关税政策提高核电设备 / 燃料进口成本 ③ FERC 主席换人后 co-located load 政策回退。
- **为什么市场可能低估**：① OBBBA 已经在 2025-07 续期 45U/45Y，市场认为政策稳定 ② 共和党内部对核电态度普遍正面（vs 风/光）③ FERC 是独立机构，不直接受总统影响。
- **触发条件**：① 国会 2026 中期后通过新版 IRA 修订削减 PTC ② 关税导致燃料供应链断裂 ③ FERC 在 2027 推翻 co-located load 现行框架。
- **影响量级**：**中等**。PE -3-5x、Adj EPS -$1 到 -$2。
- **当前迹象**：极弱。

### 盲点 5：Calpine 气电资产的 PJM 容量市场拍卖周期性下行（C 类：结构性脆弱）

- **风险描述**：Calpine 25 GW 气电的盈利严重依赖 PJM 容量市场。当前 2025-26 至 2027-28 的高容量价（$269-333/MW-day）部分反映 PJM 容量稀缺 + 大量退役煤电；如果 2028-2029 容量价回落至 collar 下沿 $175，Calpine EBITDA 会显著减少。
- **为什么市场可能低估**：① 投资者更关注"AI 核电"叙事，对气电 segment 不够 due diligence ② 容量 collar 提供 floor，认为下行有底 ③ Calpine 部分气电已签 PPA（CyrusOne、Pin Oak、Pastoria），保留一些可见性。
- **触发条件**：① 2028/29 BRA 拍卖出清在 collar 中下沿 ② 数据中心需求增速低于预期 < 4%/年 ③ 燃气价格上涨挤压 EBITDA margin。
- **影响量级**：**轻至中等**。Calpine segment EBITDA -15-25%，Adj EPS -$0.8 到 -$1.5。
- **当前迹象**：无（容量价仍在高位）。

### 盲点 6：FERC ISA / 互联 / co-located load 监管规则未定 → CEG-Microsoft PPA 受影响（D 类：政策尾部）

- **风险描述**：FERC 2025-12 出台 PJM tariff 草案，2026-02 PJM 提交终稿，至今未生效。任何 hyperscaler 核电 PPA（含 CEG-Microsoft）在监管最终定型前都暴露在 reset 风险下；TLN 2024-11 ISA 被否就是先例。
- **为什么市场可能低估**：① 卖方一致预期已经把 PPA 收入算进 FY2027-2028 EPS ② TLN 已经在 6 个月内完成 BtM → FtM 转换 ③ FERC 当前路径 6/1 后裁决，市场把这当成"低风险技术调整"。
- **触发条件**：① FERC 6/1 拒绝 CEG CIR 豁免 ② FERC 终稿对 co-located load 提出新的容量补回 / 辅助服务费要求 ③ TLN 现存 PPA 触发任何新的法律挑战。
- **影响量级**：**中等**。Crane 推迟 24 月 → FY2028 EPS -$1.5；新 PPA 议价权下降 → multiple -2-3x。
- **当前迹象**：中（6/1 是已知二元节点）。

## Kill Criteria（致命信号 — 触发立即重评 / 退出）

1. **核电严重事故信号**：任一美国核电站发生 INES 4 级以上（涉及放射性物质泄漏 + 现场人员伤亡）— **触发：立即减仓至 30% 以下，等行业 derate 出清后重评**。
2. **第 3 笔 hyperscaler PPA 全行业 6 月内没有任何公告/MOU**：意味着市场 / hyperscaler 在重新评估核电 PPA 的吸引力 — **触发：减仓至 50%**。
3. **CEG-Microsoft 或 CEG-Meta PPA 被任意一方提前终止或大幅修订（单价/容量 -20%+）** — **触发：减仓至 50% 以下**。
4. **NRC 拒绝 Crane 重启许可证更新或附加严苛条件导致投运延后 ≥ 24 月**（vs 当前 2028 目标 → 推到 2030+） — **触发：减仓 30%**。
5. **IRA Section 45U/45Y 被国会实质性削减（PTC 上限 < $10/MWh 或 phase-out 起点 < $35/MWh）** — **触发：减仓 30%**。
6. **CEG 单季度 GAAP 商誉减值 > $5B** — **触发：检查具体原因，如属气电业务长期低于预期，减仓 20%**。
7. **PJM 2028/29 BRA 拍卖出清在 $200/MW-day 以下（接近 collar 下沿）** — **触发：减仓 20%**。
