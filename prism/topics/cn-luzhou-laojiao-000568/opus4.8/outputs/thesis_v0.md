# Thesis v0 — 泸州老窖（SZSE 000568，继承自父 arena）

## 一、核心 thesis（一句话 + 强度评分）

**泸州老窖是高端龙头里赔率最优的左侧选项——分红承诺逐年抬升（2026 ≥75%、年均 ≥85 亿）、股息率 6.34% 组内最高、2026Q1 经营现金流逆势 +37%；但营收仍 -14.19% 落后茅五、全年经营现金流 -62.86% 全行业最差，拐点确认晚，且上一轮曾因逆势提价致 2014 营收腰斩（-48.7%），量价策略须警惕重蹈覆辙。**

**强度评分：5.0 / 10**（父 arena 6.5 -1.5，赔率高但拐点滞后+历史掉队前科）

## 二、支持理由

1. 股东回报安全垫最硬：分红承诺 2024/25/26 ≥65%/70%/75% 且年均 ≥85 亿、股息率 6.34% 组内最高 [mat-78157e][mat-3bdade]。
2. 2026Q1 经营现金流逆势 +37.35%、应交税费因"收入环比增长"+44%，弱拐点信号 [mat-0f2a8b]。
3. 费用弹性大（促销可灵活投放保动销），中高档国窖1573 相对抗跌（占比反升至 89%）[mat-3bdade]。
4. 国资绝对控股、报表干净、估值低。

## 三、反方观点

1. **拐点滞后**：2026Q1 营收 -14.19% 仍两位数下滑、远落后板块 -0.66% 与茅五，第三梯队拐点确认最晚 [mat-0f2a8b]。
2. **全年现金流最差**：2025 经营现金流 -62.86%、合同负债 -15.4%、库存量 +29.76%，压货信号最强 [mat-3bdade]。
3. **历史掉队前科**：上一轮逆势提价致 2014 营收 -48.7%、修复拖到 2017；本轮量价策略（"国窖并非单纯守价"）须警惕 [mat-118a9e]。
4. Q1 经现改善官方归因"流出减少"而非回款回暖，含金量待 Q2 验证。

## 四、Killer Questions

- **K1（继承收窄·拐点）**：泸州 2026Q2/Q3 营收降幅能否收窄、追上板块拐点（当前 -14% 落后茅五）？(继承自父 K1)
- **K3（继承收窄·压货真伪）**：全年经现 -62.8% vs Q1 +37% 的反转是真动销回暖还是支出节奏/票据？合同负债能否企稳？(继承自父 K3)
- **K5（继承·资本配置）**：分红承诺（75%/年≥85 亿）能否兑现？费用弹性能否护住利润不再"净利降幅>营收降幅"？(继承自父 K5)
- **K-L1（新增）**：国窖1573 批价/倒挂能否企稳？量价策略会否重蹈 2014 逆势提价覆辙？
