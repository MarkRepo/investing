## 核心数据点与事实（价格体系定义与机理）

### 价格概念定义（环①生意机制核心）
- 出厂价/打款价：酒厂对经销商的开票价/合同价，即经销商进货成本。
- 批价（一批价）：经销商之间批发流转价，是需求领先指标（领先终端动销）——"批价为何是需求照妖镜"的机理来源。
- 终端零售价：消费者实付价。
- 倒挂：出厂价 > 批价（经销商卖一瓶亏一瓶），是行业低迷的核心信号。
- 价盘四层结构：①飞天茅台（行业价格锚）②普五/国窖 ③次高端（剑南春/红花郎）④倒挂现象。

### 库存周期四阶段机制
- ①价涨 → 渠道囤货、库存累积。
- ②价见顶 → 恐慌、被动累积"堰塞湖"。
- ③价跌 → 倒挂甩货、主动去化（最痛苦阶段）。
- ④价企稳 → 信心恢复、补库存。
- 当前定位（2026）：处于 ③向④过渡——批价初步企稳但去库未完成。
- 库存健康度基准（月）：茅台 1-2 月（直销+品牌力最优）、五粮液/国窖 3-4 月、次高端 300-500元 4-5月 / 600-800元 6-8月、区域省内 2-3 月、非头部酱酒 8-12 月（崩盘风险）。

### 价格驱动与投资信号
- 价格驱动 = 供需 + 预期；茅台金融属性弱化 → 价格更多由真实消费驱动（价盘回归健康的积极信号，但短期阵痛）。
- 拐点投资信号链（关键）：库存降至 2-3 月 → 补库拐点；批价连续 2-3 季稳 → 价盘修复；价差由负转正（倒挂消除）→ 经销商转盈 → 买入信号；打款意愿回升 → 拐点确立。

### 价盘失序"三重塌方"与供需背景
- 品牌溢价塌方：根基弱的产品先被折价（习酒君品 955 → 683，跌破 620）。
- 渠道信心塌方：压货 → 囤货 → 价格信号失真。
- 厂商关系塌方：零和博弈。
- 行业产量：2016 峰值 1358 万千升 → 2025 年 354.9 万千升（-70%）。
- 渠道库存膨胀至 >4000 亿（约全年收入六成），平均存货周转 900 天 → 供需堰塞湖以倒挂方式释放。

## 叙事主线
批价是领先于终端动销的需求照妖镜，倒挂是低迷核心信号；当前行业处于库存周期"价跌甩货③ → 价企稳补库④"的过渡期，茅台金融属性弱化使价格更依赖真实消费——价盘修复需"批价连续2-3季稳 + 倒挂消除 + 打款意愿回升"三重确认，目前仅初步企稳、去库未完成。

## 反常识/分歧点
- "倒挂"反直觉：经销商卖一瓶亏一瓶仍在卖，因要回笼现金 + 完成厂家打款任务（厂商关系塌方机制），价格因此被甩货行为持续压低。
- 金融属性弱化对长期是利好（回归消费驱动）、对短期是利空（囤货溢价出清=阵痛），多空取决于时间窗口。
- 产量 -70% 但库存膨胀至 4000 亿 / 周转 900 天——供给收缩与库存堰塞湖并存，说明问题在渠道累积而非当期产能。

## 决策链专项（喂命门2 + 环①）
- 环①生意机制（批价传导）框架：出厂价（厂家定）→ 批价（渠道供需，领先指标）→ 终端零售价（消费者）；倒挂 = 出厂价>批价 = 渠道亏损甩货信号。
