# Decomposition v0 — 高端白酒（周期拐点）

> 冷启动薄拆解（基于 thesis_v0 + K1-K6 + baseline §六 prescan 校准）。
> v0 不做 LLM critic，只置信度 tag + 机械自检。深度重拆留 04 厚料期。

## 一、命门（3 个，决定 thesis 翻盘的特化问题）

**命门 1 — 拐点真伪：2026Q1 降幅骤收窄（营收 -0.66%/净利 -1.75%）是真实需求企稳，还是厂家压货 + 会计节奏 + 低基数制造的"假筑底"？**
- 置信度：**中**。这是整个 thesis 的地基——若 Q2/Q3 降幅重新走阔，"周期大底"叙事直接崩。
- 对应 K1 + K3。**01/02 优先砸料**：卖方草根库存/动销调研 + 各家合同负债/经营现金流交叉验证（压货会体现在收入增但现金流/合同负债背离）。

**命门 2 — 批价可持续性：飞天/普五批价的"底"是由真实动销支撑的可持续底，还是厂家控量稳价撑出的脆弱平衡（控货一松就二次探底）？**
- 置信度：**低**（最该砸资源）。飞天 2026 初已破 1499 创新低、靠控货反弹至 ~1665；批价是需求真伪的照妖镜。
- 对应 K2。**01/02 优先砸料**：高频批价序列（今日酒价/酒价内参）+ 控量政策可持续性 + i茅台限购对社会库存的真实影响。

**命门 3 — alpha 归属：本轮修复赢家是否确实是"渠道最健康 + 批价弹性最大"的高端龙头，而次高端是弹性还是价值陷阱？**
- 置信度：**中**。决定"投谁"——错配次高端（在错时点买错弹性，如洋河/口子窖失血）会重伤收益。
- 对应 K5 + K6。**01/02 砸料**：茅五泸 + 汾酒/洋河/古井/舍得逐家渠道健康度 + 报表质量横比。

> **消费税改革（K4）= 跨命门外生尾部风险**，非命门（命门聚焦机理/兑现路径，税改是政策外生不可控）。列入⑤证伪机制 + 持续监控，不当命门砸料，但需收一份卖方税改影响测算。

## 二、每环 B 靶点（A 合同地板之上的命门特化补充，指导 01 收料 priority）

- **环① 看懂赛道**：高端白酒怎么赚钱（提价权+品牌+老酒稀缺+渠道杠杆）、价值链利润分配（厂→经销→终端）、当前**赛道周期位**（下行第几年、历史 13-15 镜鉴对位）。B 靶点：批价/出厂价传导机理（喂命门2）。
- **环② 赢家变量+定价锚**：胜负变量（品牌势能/批价掌控力/渠道健康/吨价）+ 茅五泸+汾酒当前 PE(TTM)/PB/股息率/历史分位。B 靶点：估值底是否已现的**分位数字**（喂命门1的"杀估值走完"判断）。
- **环③ What-Must-Be-True**：把"周期大底"翻成 3-5 条可证伪假设（Q2 降幅收窄持续 / 批价站稳 1500+ / 库存回正常 / 政务消费不再恶化）。B 靶点：每条假设的可观测代理指标（喂命门1+2）。
- **环④ 押谁横比**：茅五泸+汾酒/洋河/古井/舍得 沿"批价弹性+报表质量(现金流/合同负债)+渠道健康+管理层资本配置"横比。B 靶点：压货 vs 真动销的报表识别（喂命门1+3）。
- **环⑤ 证伪+镜鉴**：arena 级 kill 信号（批价破前低/Q2降幅走阔/税改重度落地）+ 13-15 轮"曾经赢家如何修复/掉队"历史镜鉴 + signpost。B 靶点：消费税改革落地路径与冲击测算（K4）。
- **环⑥ shortlist 分档**：深研/观察/淘汰三档 + 每家 thesis_one_liner + 介入纪律（左侧分批/批价触发器）。B 靶点：左侧布局的具体批价/业绩触发器（喂命门2+3）。

## 三、primer 入门目标 v0（种子 · 喂 00_primer，N=10）

门外人为投资高端白酒读完本 topic 应能做到：
1. 看懂"批价 / 出厂价(打款价) / 开票价 / 倒挂"的定义与相互关系，并说出为何批价是需求领先指标。【缺口：需收价格体系科普】
2. 复述高端白酒的赚钱机理（提价权+品牌+老酒+渠道杠杆）与厂-经销-终端利润分配。【训练知识可覆盖】
3. 读懂一份白酒公司财报的关键科目（营收/净利/毛利率/合同负债/预收款/经营现金流）及"压货"如何在报表留痕。【缺口：需收年报+科普】
4. 说出本轮（2023-）下行周期的成因、节奏与 13-15 轮的异同。【中置信，需收周期复盘研报】
5. 区分超高端/高端/次高端价格带及各带代表单品与玩家。【训练知识可覆盖】
6. 解释为何"估值先于批价见底"，并会看 PE 历史分位判估值位置。【缺口：需收估值分位数据】
7. 说出库存周期如何驱动白酒业绩，及如何用第三方数据交叉验证厂家口径。【缺口：需收草根调研】
8. 理解消费税改革对白酒的潜在影响路径（征收环节后移/加税）。【uncertain，需收税改测算】
9. 列出判断周期拐点的可观测高频信号清单（批价/动销/库存/季度降幅）。【中置信】
10. 说出茅五泸三家的差异化定位与本轮各自的修复看点/风险。【训练知识可覆盖，需年报补强】
