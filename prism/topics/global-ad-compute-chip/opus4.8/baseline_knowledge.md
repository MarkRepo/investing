## 三、产业链 / 竞争格局认知

### 产业链位置

```
上游：EDA/IP（Synopsys/Cadence/ARM）→ 晶圆代工（TSMC/Samsung）
  ↓
中游：AD 计算芯片设计（地平线/黑芝麻/Nvidia/高通/Mobileye/海思）
  ↓
下游：Tier-1 域控集成（德赛西威/均胜/经纬恒润）→ OEM 装车
```

### 竞争五力

1. **现有竞争者**：极高集中度，地平线一超（47.66%），但 Nvidia 高端/高通中端/海思内供各有壁垒
2. **买方（OEM）议价力**：在增强——头部 OEM 有自研选项（比亚迪/蔚小理），不依赖外采
3. **卖方（晶圆厂）议价力**：中等——7nm 以下需台积电/三星，但 AD 芯片对制程不如手机芯片敏感
4. **新进入者威胁**：低——车规认证+生态建设（工具链/算法适配）壁垒高，芯驰/寒武纪等进展慢
5. **替代品威胁**：中等——纯视觉方案（特斯拉 FSD）降低对高算力芯片依赖，但中国 OEM 仍倾向多传感器融合

### 关键胜负变量

1. **生态/工具链壁垒**：芯片不是"卖硬件"，而是"卖开发平台"——地平线 TogetheROS 生态是核心护城河
2. **定点→量产转化率**：定点 ≠ 收入，实际装车出货才是关键（黑芝麻定点多但出货少是教训）
3. **高端上探能力**：前视一体机（低阶）→ 域控（中阶）→ 城市 NOA（高阶）是价值量跃升路径
4. **舱驾融合进度**：一颗芯片管座舱+智驾，省"高通保护费+英伟达税"，是国产独有的结构性红利
