## 核心数据点与事实

- [AMZN 10-K FY2025] 总净销售额 $716.9B（2025）/ $638.0B（2024）/ $574.8B（2023）——同比 +12.4%
- [AMZN 10-K FY2025] AWS 净销售额同比 +20%（2025 vs 2024）——增速领跑三大板块
- [AMZN 10-K FY2025] 营业利润：北美 $29.6B / 国际 $4.8B / AWS $45.6B / 合并 $80.0B（2025）
- [AMZN 10-K FY2025] AWS 营业利润 $45.6B（2025）/ $39.8B（2024）——+14.5%，AWS 占总营业利润 57%
- [AMZN 10-K FY2025] 净利润 $30.4B（2025）/ $59.2B（2024）——下降（含 Rivian 估值损失等非现金项目）
- [AMZN 10-K FY2025] 现金 CAPEX $128.3B（2025）/ $77.7B（2024）——+65%，主要是技术基础设施（AWS）和履约网络
- [AMZN 10-K FY2025] AWS 增长驱动：客户使用量增加，部分被长期客户合同定价变化抵消
- [AMZN 10-K FY2025] CAPEX 预期将继续增加——公司明确说"预计将增加"

## 叙事主线

因为 AWS 需求增长（+20% YoY）+ AI 工作负载推动基础设施投资 → AMZN CAPEX 从 $77.7B→$128.3B（+65%）→ 这 $50B+ 增量 CAPEX 的大部分流向数据中心（技术基础设施）→ 数据中心建设直接拉动电力需求 → AMZN 是 AI 电力需求增长的最佳一手验证。

## 反常识/分歧点

- AWS 增速 20% 在三大板块中最快，但市场关注点可能在零售业务——AWS 作为利润中心（$45.6B OI）的结构性重要性可能被低估
- CAPEX +65% 看起来激进，但 AWS 营业利润率仍在改善——说明投资有回报，不是盲目烧钱
- MS 报告说四大云厂商 Q1 2026 CAPEX +95% YoY——AMZN FY2025 全年 CAPEX +65%，意味着 Q4 2025/Q1 2026 在加速
