## § 0. v1 → v2 changelog（仅供 review 定位增量，正文不依赖）

1. **触发（最重要）**：2026-06-24 Q3 FY26 实际结果入库（mat-895ab3/ad9a41）——营收 $41.46B（QoQ +74%）、毛利率 84.9%→Q4 指引 86%（**不是见顶下行、是继续扩张**）、16 份 take-or-pay SCA 锁定未来约一半营收延伸到 2027 之后、CEO"紧缺持续到 2027 之后"。**直接证伪 v1 的"周期顶即将 rollover"时点判断**。
2. **强度 4/10 → 5/10**（生意 8/10 维持 × 入场时点 3/10 → 5/10）：时点被证伪 + 近端契约去险，入场赔率从"偏负"改善到"近打平"。**方向从"别买、等 ≤$420"→"至多一枚 token 试探(≤1%)、真正建仓仍等回调至 base 带 ≤$720"。**
3. **EV −10% → +3%（近打平，非 +7%）**：内嵌 critic 第二轮收口——core short 裂口"$45 vs 隐含 $75-80"**几乎和 v1 一样大**；normalized EPS **守在 ~$45**（不外推峰值到 $55-70）；EV 微正几乎全部来自"高位平台"情形（SCA 锁近端、下行后移 2028+），**不来自估值变便宜**（现价仍高于 base 中枢 $620 约 50%）。
4. **② 反推翻转**：v1 说"市场定价周期永不反转"；Q3 后前瞻 PE 仅 ~7.7x（run-rate EPS $124），说明**市场在 $954 其实已 price-in 大幅正常化**——是"低 PE 陷阱"的活标本，也意味着市场并非在为"永不反转"付费。P/B 14.9x 的近端缓解属"SCA 窗口去险"、非结构性变便宜（critic 收口）。
5. **大尾部后移**：断崖风险从 2027 推到 **2028+（SCA 到期窗口之后）**；kill 的 check 窗口相应后移，新增 K-bear-3(SCA特化)/K-bear-4(Q4指引落空)。
6. **宏观**：macro_stamp 刷到 regime v3（信用利差历史地板 + 脆弱度加剧）——高 β AI 内存股顺风仍在但缓冲更薄，织进⑤。
7. **纪律留痕**：v2 是有据修正、**不是投降式外推单季峰值**——保留深周期本质、更高峰值=更大回落空间、#3 份额三点空头保留项。

## § 1. 核心 thesis（当前完整版）

**一流的存储 franchise。Q3 FY26（营收 $41.46B、毛利率 84.9%→指引 86%、16 份 take-or-pay SCA 锁需求至 2027 后）证伪了 v1 的"周期顶即将 rollover"时点判断，并把下行厚尾从 2027 后移到 2028+、把近端 1.5-2 年现金流契约化去险。但守纪律：穿越周期 normalized 盈利仍判 ~$45 EPS（结构台阶把营收基数抬高，但 84.9% 是顶、不进中枢）；当前价 $954、前瞻 PE ~7.7x、PB 14.9x，仍高于 base 中枢 $620 约 50%。EV 由 v1 的 −10% 修正到 ≈+3%（近打平），这点微正来自"下行时点后移"而非"估值变便宜"——从"别追高"调整为"至多一枚 token 试探(≤1%)、真正建仓仍等回调至 base 带"。深周期纪律保留给后置的 2028+ 正常化尾部。**

- **强度评分：5 / 10**（生意 8/10 × 入场/估值时点 5/10 加权）。看好资产 + 承认时点被证伪 + 近端去险；但仍 ATH、深周期、normalized 绝对水平未实证、现价高于 base ~50%——不配加仓、更不配重仓。
- **估值带**：base 中枢 ~$620；强力买入 ≤$560；现价 $954 高于 base 中枢约 40-50%（仍"明显偏贵"，只是不再高于所有卖方乐观目标）。
- **时间维度**：现价至多一枚 token 试探(≤1%，理由是近端去险非便宜)；核心持有（3-5 年）发生在回调至 base 带建到标准仓之后。下一 catalyst ~2026-09 Q4 FY26 财报；命门验证年 2027（已非断崖必然年）。

## § 2. 支持理由（当前完整清单 · 看多/质量侧）

1. **周期顶时点被证伪、近端契约化去险（v2 新核心）**：Q3 GM 84.9%→指引 86%（未 rollover），16 份 take-or-pay SCA 含价格带、覆盖未来约一半营收、延伸到 2027 之后，$22B+ 现金与承诺 [mat-895ab3]——需求锁死跨过原先担心的 2027 拐点。
2. **本轮内存周期有真实结构性内核**：AI 服务器内存含量数量级更高；HBM 3:1 wafer 折算 + 挤占效应 [mat-c3ac1f] 双重收紧标准 DRAM 供给。CEO 明确"供给多年低于需求"[mat-895ab3]。
3. **Micron 是有竞争力的第三供应商**：HBM4 通过 Vera Rubin 认证 [mat-14a5a4]；HBM TAM 2027 >$100B [mat-895ab3]；TrendForce 指 2027 HBM 涨价、供应商掌握上风 [mat-01b47e]。
4. **资产负债表 + 现金流质变**：Q3 现金及投资 $30.2B、经营现金流 $25.39B、调整后 FCF $18.3B [mat-895ab3]（v1 时 FCF 还被 capex 吞）；净现金为正、债务转固定 [mat-4783c9][mat-7780df]。近端不会失血致死。
5. **前瞻 PE ~7.7x = 市场已 price-in 正常化**：$954 只给 run-rate $124 EPS ~8x，说明市场并非为"周期永不反转"付费。（注：P/B 14.9x 的近端缓解靠峰值净利堆书值，只在 SCA 锁定窗口成立，属"近端去险"非结构性变便宜——不列为看多论据，见 §3.7/§8。）
6. **管理层是有纪律的周期老兵**：Mehrotra 穿越 2022；峰值期去杠杆 + 顺周期锁定 take-or-pay 需求。

## § 3. 反方观点（当前完整清单 · 看空/风险侧 + critic 强反驳）

1. **84.9% GM 是更极端的周期峰值，峰越高回落越深**：历史峰值 ~60%、normalized ~40% [mat-85c74c]；增长仍主要靠 ASP/紧缺。SCA 只把顶部拉长、把断崖后移到 2028+，不消除正常化。
2. **股价 +9x、ATH、"AI 让这次不同"**：每个内存周期顶都在 GM 创纪录 + forward PE 看着最便宜时出现（2018 顶 4.5x 仍 −57% [mat-f3679c]）——当前 84.9% GM + 7.7x 前瞻 PE 完美符合这个画像。
3. **HBM 仍是护城河也是供给定时炸弹**：#3 份额（10-20% vs SK Hynix 60-70% 分配 [mat-1aae1a][mat-14a5a4]）；HBM↔常规 DRAM 产能可回切 [mat-c6503b]。
4. **2028+ 深尾**：首批 SCA 到期后价格带能否维持未知；Samsung HBM +50% 扩产 [mat-85c74c]、CXMT/ID1 产能 [mat-035fad]——大尾部只是后移、未消除。
5. **地缘三重集中**：台湾 fab + 中国 CAC 禁令 + 稀土管制 + Section 232 关税 [mat-64ca13]。
6. **宏观脆弱（regime v3）**：信用利差历史地板 + 资金面临界 + 风险偏好亢奋但脆弱；MU 高流动性-β 高倍数股，risk-off 时杀伤放大、缓冲更薄 [transmission_map v3]。
7. **（critic 强反驳/我可能错）**：normalized ~$45 是估算、非跨完整周期实证——**这是 EV 正负号的承重单点（critic 判"终局证据薄"、已挂 P0 深挖）**。若结构台阶真被抬高（正确 normalized $60+），$954 便宜、我保守；若 $35，EV 转负、退回 v1。v2 盲点双侧：既怕外推单季峰值、也怕过度怀疑台阶。

## § 8. 思维过程留痕

- **已知**：一流 franchise + 真实 HBM 结构性内核 + 资产负债表质变 + Q3 证伪了周期顶时点 + 近端 take-or-pay 去险——这些是 v2 转正的据。
- **核心 edge（v2）**：short 裂口"$45 vs 隐含 $75-80"与 v1（$40 vs $90）几乎一样大——**v2 真正改变的不是估值裂口、而是"下一个周期底的时点被 Q3 从 2027 推到 2028+"**。市场在 $954 已对 run-rate $124 打大折(前瞻 7.7x)=已 price-in 正常化。我的 edge 从"市场太乐观"变为"下行时点已后移、近端被 SCA 垫住、赔率从偏负转为近打平"。
- **刻意避开的偏见**：(a) 不把单季爆发（$41.46B/84.9%）当永久——仍是周期峰值，峰越高回落越深，故 normalized 守在 $45 不外推；(b) 不把"低 PE"当便宜（7.7x 前瞻正是低 PE 陷阱活标本）；(c) 不把"书值累积压 P/B"当看多论据（那靠峰值净利外推、与"盈利会正常化"自相矛盾，只算近端去险）；(d) 诚实标注 normalized ~$45 是估算、EV 微正落在其误差带内、给双向敏感性护栏；(e) 承认 v1 的"周期顶即将 rollover"时点判断被 Q3 证伪——修正而非嘴硬。
- **我可能错的地方（双侧）**：低估结构台阶（正确 normalized $85+，我仍保守）；或被单季峰值骗了外推（正确 $45，EV 转负）。前者进 K-bull，后者进 K-bear-4。
- **关键差异 vs 市场**：市场在 $954 定价"高位但会正常化"（前瞻 8x）；我认为结构台阶真实但有界（normalized ~$45 而非历史 $7-15，也非市场隐含 $75-80），近端被 SCA 锁死使下行后移，故赔率从偏负转为近打平——但绝非"周期消失"、更非"估值变便宜"。
