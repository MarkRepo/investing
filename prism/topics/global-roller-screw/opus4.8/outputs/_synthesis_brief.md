# _synthesis_brief — global-roller-screw / opus4.8

> 合成期临时脑图，供 ④⑥ 与 critic 复用。thesis_v0 强度 5/10。

## 核心 thesis（v0）
新剑传动是当前赢家（唯一直接 Tesla Optimus Tier1 定点的 PRS 厂）；国产上市公司群（北特/五洲/双林/恒而达）全线 0→1、无一头部大单，胜负变量=量产良率×头部大单绑定×设备(磨床)自主。

## v0→v1 强度调整倾向
**倾向下调至 4/10**。findings 揭示三条恶化信号：① 所有在产上市公司的机器人/滚动功能部件业务**全部负毛利或零贡献**（五洲 -9.33%、恒而达 -11.16%、北特零贡献、双林尚未定点），K5"毛利>25%"在全 arena 无一兑现；② 谐波镜鉴极其锋利（来福两年降价 28.2%+三年连亏、绿的订单到 2027 不敢涨价）——同为国产替代精密件，以价换量剧本大概率复制；③ 纯玩家估值极端透支（五洲 PE 239.6、恒而达 176.6、北特 115.5），预期已远跑赢基本面。上调项：新剑 IPO 透明化 + Tesla Gen3 量产节奏明确（2026H2 交付、2027 大规模）+ 磨床国产化从政策转订单验证（华辰 100 台、秦川 P0/P1 入特斯拉）。净效应：赛道真、赢家仍高度不确定 + 现价普遍透支 → 深挖≠现价买入，需价格闸门。

## 关键假设（③ WMBT 预排）
1. Tesla Gen3/4 维持 PRS 线性执行器方案、单台 ~14 根不被准直驱大幅替代（K3）
2. 国产 C5→C3 良率 2026-2028 跨过工业门槛（≥80%）（K2，专家共识 2027-2028）
3. 上市公司群 2026-2027 至少一家拿到头部整机 Tier1 批量定点（K1）
4. 放量后 PRS 单价/毛利不重演谐波以价换量（维持>25%）（K5）
5. 螺纹磨床国产化（华辰/秦川/科之鑫/SMS）支撑丝杠厂 C3 量产（K4）

## K# 校准（哪些公司被 K# 翻盘/强支持）
- **新剑传动**：K1 唯一强支持（Tesla Tier1 现役），但非上市、机器人收入仅占 8.19%（3110 万）、募资达营收 7 倍 → 是估值锚不是可买标的。
- **双林 300100**：K4 强支持（科之鑫磨床自制 C3-C0，全 A 股少见上游垂直整合）+ 主业稳（扣非+36.6%）+ **估值最低（PE 30.2）**；但 K1 尚未定点、K5 未兑现、Q1 净利 -47%。
- **北特 603009**：K1/K2 未证实（丝杠零贡献、无定点、无良率数字）；主业输血（净利+67% 全来自空调压缩机），18.5 亿投产未落地 → 丝杠看涨期权，PE 115.5 偏贵。
- **五洲 603667**：K1 部分（已过特斯拉审厂进小批量）+ 25 亿产能豪赌（剑指 7 万台）；但机器人负毛利、Q1 营收-18.8%、**PE 239.6 极端透支**、公司自陈定增项目 IRR 仅 12.27%。
- **恒而达 300946**：K4 支持（收德国 SMS 磨床，卖铲人路线）；但 PRS 仅样品、滚动件负毛利、利润腰斩-57.8%、客户极分散（前五 11.83%）、PE 176.6 贵。
- **恒立液压 601100**：K1 部分（PRS 送样进特斯拉体系），液压龙头基本盘厚（毛利 41.6%）、估值温和（PE 52），机器人为增量期权。
- **震裕 300952**：与特斯拉联合研发线性执行器、日产 120 套、C3/C5（8μm）、过 Optimus V3 审厂——潜在黑马（本轮未拉财务）。
