## 环① 看懂这个赛道（理解闸门）

**怎么赚钱 + 价值链卡位**：PRS 是人形机器人线性执行器里**单机价值量最高（占整机 BOM 约 20%，占线性执行器成本约 31%）、壁垒最高、国产化率最低（合计约 16%）**的环节 [mat-e0bfe1][mat-c210e2][mat-fa85eb]。利润从"把旋转精确变成大推力直线运动"的精密制造能力来；卡位分三段——**丝杠部件（北特/五洲）、执行器总成（新剑/双林）、上游磨床设备（秦川/双林科之鑫/恒而达SMS）**。**一条反直觉的卡位判断：最厚利润和最硬壁垒在上游磨床（秦川丝杠磨床配套毛利 52% [mat-0f858a]），而非丝杠本身——"丝杠的终局是磨床"。**

**路线之争（是什么，不判胜负——判胜负在③⑤）**：
- **部件 vs 总成 vs 设备**三种商业模式：卖丝杠部件（北特/五洲，量大利薄、易被压价）、卖执行器总成（新剑/双林，绑定深、附加值高）、卖磨床设备（秦川/恒而达，卖铲人、通吃下游）。
- **PRS vs 准直驱/滚珠**技术路线（详见 primer §八）：PRS 刚性大承载强，准直驱成本 1/5 但功率密度低——线性关节是否会为省成本改道，是天花板变量。

**客户结构**：高度集中于少数头部整机（Tesla Optimus 是最大引擎 + 优必选/宇树/Figure/小鹏），是典型 B 端、认证周期长（1-2 年）、双供/多供的供应链。当前需求几乎全押 Tesla Gen3 量产节奏。

**赛道周期位：早期成长的最陡峭段（0→1 放量前夜）**。2022 年 PRS 全球仅约 20 亿元 [mat-6b2027]；2030 年测算 187–270 亿元（CAGR 154%–176%）[mat-c210e2][mat-6b2027]。Tesla Gen3 2026H2 交付、2027 大规模量产 [mat-5e705d]——需求真实且在加速，但**兑现节奏和用量口径分歧极大**（单台 14 根 PRS vs 含微型丝杠 64 根，别混算）。

> 闸门结论：赛道看得懂、真、且弹性最大——**但"看懂"恰恰看出胜负由"良率×定点×路线×价格"四个尚未落定的变量决定**，这正逼出环②。

## 环② 赢家由什么决定 + 市场已把谁当赢家定价了【锚】

### 关键胜负变量（排序）
1. **量产良率 ×（磨床/工艺自主）**——最决定性。良率决定 BOM 能否摊薄、利润池成不成立；而良率上限由磨床精度和螺母内螺纹工艺锁死（G1+K4）。谁掌握设备/工艺自主，谁的良率天花板更高。
2. **头部整机 Tier1 定点**——决定吃全球大单（最厚利润）还是国内/备胎（薄利）（G2+K1）。
3. **成本曲线/规模**——降本曲线 -92% 下，谁的成本护城河深谁能在价格战中活下来（K5）。
4. **技术路线站队**——押 PRS 是否被准直驱颠覆（G3+K3）。

  > **"低 PE=安全边际"必须拆账（防误读）**：30x 的表观 PE = ①存量汽零业务的合理估值 + ②为未兑现 PRS 期权付的隐含溢价。真正便宜的是①（传统汽零可比 15-20x），而②这张彩票双林付的溢价**和纯玩家没有本质区别**——只是被大盘子稀释进了低表观倍数里。所以"安全边际"不来自"低 PE"本身，而来自**存量业务这块地板还稳不稳**：一旦 Q1 -47% 的存量继续恶化，地板下沉，30x 里的期权溢价照样裸奔。**结论：双林是"值得深研"、不是"现价可买"——这把"深挖≠买入"的尺子对它和对五洲/北特一样硬，区别只在双林多一块（正在承压的）存量地板 + 一个待验证的 K4 边际。**
- **恒立液压 601100**：液压全球龙头（毛利 41.6%/负债 0.2%），机器人是"厚基本盘上的期权"，赌"再造一个恒立"，即使 PRS 慢主业不塌。
  > **"免费期权"其实不免费 + 需审视周期位（防绝对化）**：PS 12.28 / PE 52x 对一家液压公司**已明显高于对照三花（PE 38.3x）**——市场已把机器人溢价打进恒立，期权谈不上"免费"。更关键的是液压是**深周期品种（挂钩挖机/工程机械周期）**，52x/PS 12.28 有可能是在**周期高位**给的估值：一旦挖机主业进入下行，作为期权底座的"厚基本盘"会**先 de-rate**，此时机器人尚未兑现，等于两头落空。故"下行保护最强"应修正为"**下行保护取决于液压周期所处阶段**"——恒立仍是本 arena 下行敞口相对最小的，但不是无条件的安全垫。
- **震裕 300952**：与特斯拉联合研发、过 Optimus V3 审厂、日产 120 套——**上市公司群里离"第二家 Tier1"最近的黑马**，但本轮财务/估值未拉全，需补。
- **北特 603009**：丝杠纯看涨期权（18.5 亿产能未投产、零收入），主业空调压缩机输血，PE 115x 已把期权定价——好赛道但贵 + 未兑现。
- **恒而达 300946**：卖铲人叙事（SMS 磨床 K4 独特卡位），但 PRS 仅样品、滚动件负毛利、利润腰斩、PE 177x——卡位有想象力但兑现最弱 + 最贵。
- **五洲 603667**：25 亿产能豪赌 7 万台，但机器人负毛利、Q1 营收 -18.8%、公司自陈项目 IRR 仅 12.27%、**PE 240x 极端透支**——高弹性叙事的价格已透支到危险。

## 环⑤ 如果错了会怎样、怎么第一时间知道【证伪机制】

### 已知风险
- **K5 价格战（最高概率）**：多家同时扩产 PRS + 降本曲线 -92%，重演谐波"以价换量"。
- **K2 良率卡死**：良率突破晚于 2028，或 C3 高端始终依赖进口设备，规模不经济。
- **估值透支回撤**：Wind 人形机器人指数过去一年涨 33% 但最大回撤 31.5%、峰谷成交差 >4 倍 [mat-10205f]——纯玩家高 PE 对情绪极敏感。

### 盲点风险（≥1）
- **准直驱/滚珠丝杠悄然替代（G3 天花板塌缩）**：若 Figure/宇树/Tesla Gen4 为省成本把线性关节改准直驱或滚珠，PRS 单台用量从 14 根砍到 <6 根，赛道天花板腰斩——**这是所有 PRS 投资逻辑的总开关，且当前 findings 覆盖最薄**（primer §八已标数据缺口）。
- **新剑 IPO 定价"锚"崩**：作为板块估值锚，新剑若破发或招股书暴露机器人收入过低（仅 8.19%），可能引发全板块重定价。

### arena 级 kill 触发条件（数据化）
1. **路线颠覆**：任一头部整机（Tesla Gen4/Figure/宇树）量产版明确改用准直驱/滚珠、PRS 单台用量降至 <6 根 → 全 arena kill。
2. **共识赢家全线失速**：至 **2027Q2** 上市公司群仍无一家披露头部整机 Tier1 批量定点 → G2 证伪，纯玩家逻辑破。
3. **价格战确认**：PRS 批价年降 >30% 且在产厂机器人业务毛利持续跌破 20%（谐波重演）→ K5 证伪。

### shortlist 个股级证伪/退出线（双林 / 恒立——补给"我押的两家"自己设线）

- **双林 300100 降级/退出线**（任一触发即从 shortlist 降级或止损）：
  1. **卡位证伪**：至 **2027Q2** 仍未获任一头部整机（Tesla/头部厂）PRS 正式定点 → K1 卡位落空，"总成 + 磨床自制"故事仅剩存量汽零。
  2. **良率证伪**：10 万套线 2026-06 投产后，第三方/交付数据显示批量良率仍 <70% 或长期负毛利 → K2/K4 边际不成立，company 深研直接下 shortlist。
  3. **存量地板塌**：主业（汽零）扣非连续两季转负 / 现金流恶化 → 支撑"安全边际"的存量地板下沉，30x 里的期权溢价裸奔。
- **恒立液压 601100 降级/退出线**：
  1. **周期底座 de-rate**：液压主业营收/毛利环比连续两季下行（挖机周期确认转下行）→ "厚基本盘=下行保护"前提破，重估底仓逻辑。
  2. **期权归零**：至 2027 年底 PRS 仍停留送样/无批量订单、机器人收入占比无实质提升 → "免费期权"证伪，恒立回归纯液压周期股定价。

> 这两组线与 signpost 联动：任一触发 → 触发对应 company 深研的重评，而非默认继续持有。

### ★ 历史镜鉴（≥2，曾经赢家如何被取代 / 利润为何没兑现）
1. **谐波减速器国产化（中国·2020-2026，最直接镜鉴）**[mat-5cb809][mat-e35cf5]：
   - 失败模式：需求旺盛（订单排到 2027）却陷"没有赢家的消耗战"，龙头绿的谐波不敢涨价、毛利持续下滑；二线来福谐波**核心产品两年降价 28.2%、三年连亏（1.69/1.69/1.71 亿元）、应收高企**。
   - 峰谷损失：来福三年累计亏损 >5 亿；绿的曾 PE 400x+，估值大幅回落。
   - 当年最早预警信号：多厂同时扩产 + 价格函下行。**"现在是否已现"→ 已现苗头**：五洲/新剑/北特/双林/恒而达同步扩产 PRS，降本曲线 -92% 已写进预期。
   - 教训一句话：**国产替代放量本身不创造利润，胜负全在能否维持毛利——放量 ≠ 盈利。**
2. **光伏/面板国产替代（中国·2010s-2020s，行业镜鉴）**：国产化+需求爆发→全行业产能军备竞赛→价格战→即使龙头也长期微利，利润没随份额兑现。
   - 教训：**"国产替代 + 高增长"叙事下，利润池常被产能过剩吞噬；先发+成本护城河+设备自主者才可能是少数幸存者。**
3. （路线颠覆型，警惕但证据弱）**功能机→智能机（Nokia）**：曾经的赢家因路线切换（准直驱之于 PRS ≈ 触屏之于键盘）被淘汰——对应 G3 盲点，虽当前无量产替代确证，但一旦发生就是龙头归零式风险。

> **只想得到成功案例是 red flag**——本 arena 最值钱的镜鉴恰是谐波的"以价换量"惨败，它直接告诉你 K5 是真闸门。

## 综合结论（thesis take，指向 thesis_v1）

赛道真、弹性最大、国产化最弱 = 最大 alpha 所在；**但赢家高度不确定（新剑独家 Tier1、上市群全线未定点）+ 利润池未兑现（全线负毛利）+ 纯玩家估值极端透支 + 谐波以价换量镜鉴锋利 → 深挖 ≠ 现价买入。** 正确姿势是：**深研"卡位真实 + 相对有安全边际"的双林、恒立，对被爆炒的纯玩家（五洲/恒而达/北特）保持价格纪律，盯 signpost 等 K1 定点破局 / K5 毛利转正 / 估值消化三选一。** 但须说清一条纪律边界：双林/恒立的"安全边际"**须拆账**（存量地板 vs 未兑现 PRS 期权溢价，见环④），拆开后二者同样是"**值得深研、非现价可买**"——它们相对纯玩家的优势不在"低 PE 本身"，而在多一块（待验证的）存量地板 + 真实卡位边际，且各自已设个股退出线（见环⑤）。thesis 强度自 v0 的 5/10 下调至 **4/10**（赛道看多不变，但个股赢家不确定性 + 估值透支使可执行下注收窄到 2 家 + 价格闸门）。

**介入价格纪律（量化锚，估算——arena 粒度给区间，精确点位留 company 深研）**：
- **双林 300100**：PE ~30x 的表观便宜**须拆账看**（见环④拆账框）——真正便宜的是存量汽零地板，PRS 期权溢价并不比纯玩家低。故双林同样是"**值得深研、非现价可买**"（同一把"深挖≠买入"尺子对称适用），可纳入关注名单跟踪，**两个硬前置**：①company 层良率第三方验证过关、②主业存量地板不再恶化（Q1 -47% 企稳）。二者未定之前不试探性建仓；若估值回落至 **PE <25x** 且前置满足则安全边际更厚。
- **恒立液压 601100**：PE ~52x / PS 12.28 **已把机器人溢价定价、非"免费"**，且需盯液压周期位（见环④）——作相对稳健的底仓型跟踪而非无条件安全垫，机器人弹性有限、下行保护取决于挖机周期阶段；回调至 **PE <45x** 且挖机主业未确认转下行时更具吸引力。
- **纯玩家（五洲/恒而达/北特）价格闸门**：当前 PE 115-240x 远超赛道成长溢价合理上限（参照可比成长制造 **PE 60-80x** 作粗略天花板）——**在 PE 消化回 <80x 且机器人业务毛利转正之前，一律价格纪律、不追**。这两条同时满足才从"淘汰/观察"重估。
> 上述 PE 阈值为 arena 层粗略锚（基于赛道成长性 + 可比溢价估算，非精算目标价），精确买卖区间/DCF/EV 留各 company case 落地。
