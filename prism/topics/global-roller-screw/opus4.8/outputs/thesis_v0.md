# thesis_v0 — 行星滚柱丝杠（继承自父行业 thesis）

## 1. 核心 thesis（≤120字 + 强度）
**行星滚柱丝杠是人形线性执行器价值量最大(BOM~31%)、技术壁垒最高、国产化最弱(~19%)的环节，是国产替代故事中"高价值×高壁垒×可突破"的唯一交集；谁突破高端良率+拿到全球定点，谁吃下最厚利润池——但高端仍受海外磨床卡脖子，突破未证实。** 强度 **5/10**（父级 6/10 -1，arena 继承可信度低于亲验）。

## 2. 支持理由
1. 单一价值量最大（BOM 31%，远超谐波 4%/电机 10%）[mat-b0c512]，利润池最厚。
2. 国产份额仅 ~19%、仅 3 家小批量 [mat-529f3d][mat-852ece]——替代空间最大、弹性最高。
3. Tesla 线性执行器（腿部承重）采用行星滚柱丝杠，是 Optimus 刚需件 [mat-852ece]。
4. 标的（北特/五洲新春/恒立/贝斯特）估值不如绿的(410x)/鸣志(379x)极端透支，性价比相对好。

## 3. 反方观点
1. 高精度磨床 95% 进口、出口管制风险，国产高端良率短期难破 [mat-b0c512]。
2. Tesla 可能自研丝杠/给海外定点，中国厂"有定点没大单"[mat-5bd1f9]。
3. 量产慢于预期（Optimus 官方"尚未商业化"）→ 丝杠需求兑现滞后 [mat-5bd1f9]。
4. 准直驱路线（行星减速器，成本仅谐波 1/5）若胜出，线性执行器丝杠用量被削 [mat-215f5f]。

## 4. Killer Question
- **K1｜国产良率突破**：国产丝杠精度能否从 C5 突破至 C3、良率达量产要求？（新增 arena 专属）可证伪：2026-2027 国产仍卡 C5、良率不达标。
- **K2｜全球定点归属**：中国厂能否拿到 Tesla/全球头部 OEM 的丝杠定点（而非仅供国内）？（继承自父 K3）可证伪：Tesla 丝杠定点给海外/自研。
- **K3｜磨床国产化**：高精度螺纹磨床能否国产化、摆脱进口依赖？（新增）可证伪：磨床仍 95% 进口、产能受限。
- **K4｜量价齐升**：丝杠放量时单价/毛利能否企稳，不重蹈谐波"以价换量"？（继承自父 K5）可证伪：丝杠国产化后单价快速下滑、毛利崩。
- **K5｜路线稳定**：行星滚柱丝杠路线地位是否稳固，不被准直驱/其他方案替代？（新增）可证伪：头部整机转向准直驱、丝杠用量下降。
