## 三、产业链 / 竞争格局认知

### 产业链地图
```
原材料(特种钢)
  → 精密锻造/车削(毛坯)
    → 热处理(渗碳淬火)
      → 【核心工序】螺纹磨削(螺纹磨床 — 设备瓶颈)
        → 装配/检测(三坐标/圆度仪)
          → 线性执行器总成(含电机/编码器/力传感器)
            → 整机(人形机器人)
```

### 竞争格局认知(训练知识)
1. **全球格局**：Ewellix/Rollvis/Schaeffler 掌控 C3+ 高端(航天/军工/精密机床)，中国厂刚起步小批 C5-C7
2. **国产替代路径**：从 C7(工业级) → C5(机器人可用级) → C3(高精度) 逐级攻破
3. **核心卡脖子**：螺纹磨床是精度天花板，进口设备交期 12-18 月且单台 500-1000 万元，国产磨床精度差 1-2 级
4. **良率差异**：海外成熟线 C5 良率 >90%，国产 C5 良率传闻 50-70%（小批），高端 C3 国产几乎无批量
5. **定点竞赛**：2024-2025 多家宣称进入 Tesla/优必选/宇树定点流程，但实际"拿到批量供货合同"(SOP) 尚无公开确认
6. **估值水位**：机器人概念估值极高（绿的 PE~400x、鸣志~380x），丝杠股相对不那么极端但仍高（北特 PE~80-120x、五洲新春 PE~50-80x），本质都是"梦想估值"靠量产兑现

### 胜负变量假说
- **良率 × 定点 = 赢家公式**：谁先把 C5/C3 良率做到 80%+ 且拿到 Tesla 等头部定点 → 率先放量 → 规模正循环(良率进一步提升+成本摊薄)
- **准直驱路线若胜出** → PRS 线性执行器整条赛道被削(丝杠用量从 14 根降至 0-6 根)
