# 训练知识 Baseline — 行星滚柱丝杠 (Planetary Roller Screw)

## 一、关键事实记忆

### 机制与产品定位（静态为主）

- `[fact-01]` 行星滚柱丝杠（Planetary Roller Screw, PRS）将旋转变直线运动，结构上丝杠与螺母之间通过**滚柱（roller）**做行星式啮合传力，滚柱与丝杠/螺母是**线接触**（多点），区别于滚珠丝杠（Ball Screw）的**点接触** → 置信度：高 | time_sensitivity：**静态**
- `[fact-02]` 因线接触，PRS 相比同尺寸滚珠丝杠：承载力更高、寿命更长（疲劳寿命常高一个数量级）、可承受更高转速与更大导程 → 置信度：高 | time_sensitivity：**静态**
- `[fact-03]` PRS 制造核心难点在**螺纹廓形磨削**（尤指螺纹磨削精度与表面质量）、滚柱几何一致性、保持架/行星结构装配，属精密加工 + 专机设备壁垒 → 置信度：高 | time_sensitivity：**静态**
- `[fact-04]` 人形机器人线性执行器（linear actuator）方案中，PRS 是直线关节的核心传动件之一；Tesla Optimus 的直线执行器被报道采用滚柱丝杠路线（区别于部分厂家用的滚珠丝杠/谐波减速器+旋转方案） → 置信度：中 | time_sensitivity：**慢变**（车型方案可能调整）

### 市场与玩家格局（慢变为主，部分 uncertain）

- `[fact-05]` 高端 PRS 长期由海外主导：瑞典 Gemini/Geman（滚柱丝杠鼻祖之一）、Ewellix（曾属 SKF，做电动缸+滚柱丝杠）、SKF、Schaeffler/INA、Bosch Rexroth、Moog；日本 THK、NSK 亦有布局 → 置信度：中 | time_sensitivity：**慢变** ⚠️（玩家名单/并购可能变）
- `[fact-06]` 国内潜在玩家（训练时记忆，名单不全且不确定）：恒立液压、贝斯特、秦川机床、五洲新春、长盛轴承、苏州绿的、步科等被市场在不同时点提过；其中谁真正量产高端 PRS 不确定 → 置信度：**uncertain** | time_sensitivity：**慢变** ⚠️
- `[fact-07]` 国产化核心矛盾：中低端可做，**高端 C0/C1 级精度 + 高寿命一致性**良率不足；螺纹磨床等关键设备部分依赖进口（如德国 Jung/瑞士 Studer 等） → 置信度：中 | time_sensitivity：**慢变** ⚠️

### 需求侧与人形机器人弹性（快变 + uncertain，最需校准）

- `[fact-08]` 单台人形机器人用 PRS 数量：训练时记忆 Optimus 约用 14 个直线执行器/关节（记忆模糊，可能是 14±），每根 1 件 PRS → 置信度：**uncertain** | time_sensitivity：**快变** ⚠️
- `[fact-09]` 人形机器人量产节奏与 PRS 需求弹性高度依赖 Tesla Optimus 量产时间表与单价下行曲线 → 置信度：高 | time_sensitivity：**快变** ⚠️
- `[fact-10]` PRS 单价：训练时无可靠记忆（高端件单价区间我无把握，可能数百至数千元/根量级，但不确定） → 置信度：**uncertain** | time_sensitivity：**快变** ⚠️
- `[fact-11]` 全球 PRS 市场规模（不含人形）：训练时记忆偏小（约几亿美元量级，工业/航空/军工用途），人形机器人带来数倍弹性预期 → 置信度：**uncertain** | time_sensitivity：**快变** ⚠️

### 估值/股价类（快变，必须校准）

- `[fact-12]` A 股 PRS 概念标的（恒立液压/贝斯特/秦川机床/五洲新春/长盛轴承等）在人形机器人主题催化下估值被推高，PE 普遍高位 → 置信度：中 | time_sensitivity：**快变** ⚠️（具体 PE/股价必须现采）

## 二、关键人物 / 公司 / 产品

- **Geman / Gemini（瑞典）**：滚柱丝杠历史鼻祖之一，高端品牌标杆。
- **Ewellix**：原 SKF 集团旗下，做电动缸与滚柱丝杠，后被 SKF 处置/独立（具体状态不确定）。
- **SKF / Schaeffler-INA / Bosch Rexroth / Moog**：欧美综合性传动/轴承巨头，PRS 作为产品线之一。
- **THK / NSK**：日系，以滚珠丝杠/直线导轨见长，PRS 亦有但非主力。
- **Tesla Optimus**：人形机器人需求侧最大单一弹性来源，其直线执行器方案与定点厂商决定整条 PRS 链利润分配。
- **国内候选**（名单 uncertain，待 03/04 验证）：恒立液压（液压件龙头跨界）、贝斯特（精密件）、秦川机床（齿轮/螺纹磨床+丝杠）、五洲新春（轴承滚动体）、长盛轴承（自润滑/轴承）、苏州绿的（谐波减速器，可能横向延伸）。

## 三、产业链 / 竞争格局认知

1. **上游设备与材料**：螺纹磨床（外螺纹磨、内螺纹磨）是卡脖子环节，高端依赖德国/瑞士专机；材料端为高纯轴承钢（GCr15 等），国产材料基本可用但高端一致性仍短板。
2. **中游制造**：海外 Geman/Ewellix/SKF/Schaeffler/Rexroth/Moog + 日系 THK/NSK 占高端；国内尚处"能做样品→量产良率爬坡"阶段，玩家分散、各家的实际量产水平差异大且不透明。
3. **下游应用**：传统工业（机床/冶金/化工阀门）、航空航天（襟翼/起落架作动）、军工、半导体设备；**人形机器人是新增的、弹性最大的需求曲线**，单台用量大、对成本敏感、对寿命与一致性要求高，是"利润池往哪迁"的核心变量。
4. **利润池判断（先验赌注，待 thesis 校准）**：若人形量产兑现，利润池最厚一段可能在"掌握高端螺纹磨削工艺 + 拿到主机厂定点"的少数厂商，而非单纯扩产的中低端件；国产替代窗口期存在但窗口长度取决于海外厂是否扩产 + 主机厂是否接受国产二供。

## 四、训练知识盲点（自我承认）

- **盲点 A（玩家名单与真实量产水平）**：国内到底哪几家真正具备高端 PRS 量产能力、谁只是样品/概念，训练时记忆模糊且混杂了市场传闻。
- **盲点 B（Tesla 定点状态）**：Optimus 直线执行器丝杠的定点厂商是谁、是否锁定国产、单机用量，训练时无可靠信息（快变 + 信息不公开）。
- **盲点 C（良率/成本曲线）**：国产高端 PRS 当前良率水平、单根成本下行路径，训练时无定量数据。
- **盲点 D（市场规模与弹性测算）**：全球 PRS 现存市场规模、人形机器人带来的量价弹性，训练时只有量级直觉，无可靠数字。
- **盲点 E（海外厂扩产动作）**：Geman/Ewellix/SKF 等是否为人形需求扩产、是否锁产能，训练时不知道。
- **盲点 F（估值水位）**：A 股相关标的当前 PE/涨幅/资金结构，训练时数据已过时，必须现采。
