# thesis_v2 — Applied Optoelectronics (AAOI)

## § 0. v1 → v2 changelog

1. **定价锚从单源升为 5 源中枢，并因此翻转了 v1 的旗舰结论**。v1 的 `consensus` 是单一聚合页，且我在同一页两个互斥数字里取了较低的那个（FY2027 EPS **$4.18** vs 该页年表 $4.87）。5 源交叉（Chartmill / Yahoo / WSJ / Simply Wall St / Barchart）后中位 **$4.735**、均值 **$4.800** → 采用 **$4.75**（区间 $4.18-5.55），收入中位 **$2.60B**。v1 §2.10 写的「给 25x 得 $104.5，低于现价，隐含 IRR 0-5%、无风险补偿」按中枢重算变成：**当前仅 21.8x，25x 得 $118.75（+14.9%），30x 得 $142.50（+37.8%）**——**方向翻转，这是 v2 最重要的单一修正。**
2. **市场隐含净利率口径修正：15.52% → 14.80%**。v1 的 15.52% 是拿街上 EPS 除以**公司自己的 92.8M 股本指引**倒推的，等于把分歧 2（股数）偷偷折叠进分歧 1（毛利率）。干净口径来自 Simply Wall St 的 **$381M / $2,574M = 14.80%**；反推街上自己的股本假设是 **78.2-82.8M 股**，比公司指引还低。
3. **我的 Base 净利率从 12.0% 上修到 13.0%，delta 从 −3.5pp 收窄到 −1.8pp**。上修理由是 FY2019 10-K 一手数据（见第 8 条）证明这家公司在**上一个世代的高点做到过 43.50% 毛利率**，我原先隐含的"结构性天花板 32%"缺一手依据。
4. **四处表内算术与自身参数不符，已改**：① 弱空档单价 $62 按其自身参数应为 **$42.5**；② 模型 B 的每股表整体高估约 **60%**；③ v1 引的 Q2 数据中心收入 $82M 实为 **$107.6M**；④ 三处 EV 加总口径不一致（五档/三档并列但未说明取哪个）。
5. **模型 B 退出「三模型 Base 收敛」，降级为期权 sanity check**。它把一个概率加权 EV 塞进情景表，并对模型 A 的 Base 里**已经计入的同一份期权二次贴现**——结构性重复计价，不能与 A/F 并列。剩下两个每股模型 A **$81-92** 与 F **$88-99** 确实收敛，Base 带定为 **$81-99**。
6. **Bull 终值倍数从 26x 提到 30x 中枢（26x / 30x / 33x 敏感带）**。26x 对不上本案自己引用的同业带（旭创 49.53x / 新易盛 43.48x / Coherent 66.19x），也对不上本案自己那个不对称的 Bear（P/S 2.0-2.5x，低于纯代工 Fabrinet 的 3.10x）。不取 40x，因为那是**峰值倍数叠加峰值盈利**。
7. **EV 重算，分布也变了**：强多 25% / 弱多 15%（$92）/ Base 40%（$81）/ 弱空 13%（$42.5）/ 强空 7%（$30）→ EV **$99.19（26x）/ $106.17（30x）/ $111.41（33x）**，中枢 **$106**。对 v1 锚点 $113.76 是 −13% 至 −2%；**对现价 $103.39 是 −4% 至 +8%，中枢 +2.7%**。
8. **镜鉴 1（2017-2019 崩塌）从训练记忆升级为一手证据，且死因判断被改**。补到 FY2019 10-K [mat-41683c] 后拿到九年一手弧线：数据中心收入 **2017 $382.3M / GM 43.50% → 2018 $267.5M / 32.80% → 2019 $190.9M / 24.20% → 2022 $222.8M / 15.09% → 2025 $455.7M / 30.04%**。**2017→2025 收入只涨 19.2%（CAGR 2.2%），毛利率净掉 13.5pp。** 死因也修正了：不是 v1 写的"100G 没接上 40G 的班"，而是**世代切换叠加单一大客户抽单**——两个原因，而 v1 只写了一个。
9. **环③ 假设强度两处改判**：假设 2（毛利率）**弱 → 中**（门槛降到 14.8% 净利率、GM 32-35%，而公司自己在 FY2017 做过 43.5%）；假设 4（终值倍数）**中 → 中高**（现价只要求 **21.8x**，而同业带在 43-126x：旭创 49.53x / 新易盛 43.48x / Coherent 66.19x / 光迅 126.30x）。假设 1/3/5 不变。
10. **盲点 3 升格为风险**：2026Q2 未披露身份的第三大客户从一年前 6% 跳到 **24%**，这个量级不该停在"盲点"栏——已移入风险清单并配 kill。
11. **强度评分 3.0 → 4.2**。仍偏空，但"市场完全没留风险补偿"这个 v1 的核心指控在定价锚修正后不成立了；delta 收窄 + 现价回落 9.1% 共同把评分推上来。
12. **承重充分性从"单线承重"部分解除**。定价锚已多源化；但**分段毛利率（CATV 硬件 vs datacom）至今取不到**，而 M1「代工位」的定量核心正是这个对标（AAOI 含 53.8% CATV 硬件 vs 旭创纯 datacom）。已列入 §7 P0 并把 **M1 置信度从中高下调到中**。

## § 1. 核心 thesis（当前完整版）

> **AAOI 的收入主体坐在价值链毛利率最低、差异化最小的"代工位"上——公司自己在 10-K 里承认产品 "only minimally differentiated"、面临 "strong pricing pressure"，而九年一手数据显示它在上一个世代同样的紧缺高点做到过 43.50% 毛利率、随后被世代切换与单一客户抽单打到 24.20%，八年后收入只多了 19.2% 而毛利率净掉 13.5pp。因此命门不是"收入能不能上去"（紧缺是真的、订单是真的、产能在建是真的），而是"上去的收入能不能变成每股利润，以及这个利润能持续几个季度"。市场现在隐含 FY2027 净利率 14.8%、股数约 80M；我判 13.0%、96-100M。分歧比 v1 小得多，但方向未变。**

**强度评分：4.2 / 10**（偏空，但**接近中性**。**不建议做空**——空头拥挤度 12.83%、days-to-cover 1.2 天、5 季连创纪录动能，Q4 若兑现则轧空风险极大）

**落在 company 终局上的立场**：

- **买 / 卖 / 持有** → **观望（现价 $103.39 落在观望区上沿，期望回报仅 +2.7%）；不建仓，已持有者可持不加**。这比 v1 的「不买 / 降至观察仓」松了一档，原因有两个且都不是我的判断变了：定价锚修正（+）与股价下跌 9.1%（+）
- **EV** → 单一口径（v1 的五档/三档并列已废）：五档分布加总 **$106.17**（Bull 取 30x 中枢），敏感带 **$99.19（26x）～$111.41（33x）**
- **公允值三个数不要混用** → **我判断的 Base 是 $81**（13.0% 净利率）；**$92 是接受市场 14.8% 净利率时的 Base**；**$106 是含 25% Bull 概率的加权 EV**。买入框锚在 **EV $106**
- **目标价 / 介入纪律** → **强力买入 ≤$68（期望 ≥+56%）/ 可建仓 $68-86（+23% 到 +56%，上沿 $86 = EV 打 19% 安全边际）/ 观望 $86-106（0 到 +23%）/ >$106 不建仓（EV ≤0）**。加仓阶梯 **$86 / $76 / $66**（每档触发前须先查 kill 状态——跌到位不等于便宜）
- **⚠️ 口径声明** → 本 thesis 与 case 的**所有公允值都是 FY2027 年底目标价、未折现**，"公允值 vs 现价"是约 1.3 年期持有回报，不是年化收益率
- **仓位档位** → **试探**（`full_max_pct` 4%，较 v1 的 3% 上调一档因 delta 收窄；`initial_max_pct` = null 因现价仍在观望区、正确动作是不建仓）
- **持有期** → **6-18 个月事件驱动，不是 3-5 年复利持有**
- **核心命门** → **"毛利率能否结构性站上 32-35% 并同时把营业利润率做到 8% 以上" × "完全稀释股数能否守住 96M 以内"**。注意 v1 写的是"32-34%"，v2 把上沿放到 35% 并**追加了营业利润率条件**——因为 FY2019 的教训正是"毛利率还有 24% 的时候营业利润已经深亏"

**估值带**（均为 FY2027 年底未折现目标价）：**两个每股模型收敛在 $81-99**（逆向 PE-DCF $81-92 / 同业横截面 $88-99），Bull **$181-230**，Bear **$30-66**。模型 B（基本盘+期权）**不参与 Base 收敛**，仅作期权定价 sanity check：市场为期权付 **$6.86-7.82B（占市值 78-89%）**，我算期权期望 NPV **$3.75B**，**市场是我的 1.8-2.1 倍**。

## § 2. 支持理由（当前完整清单）

### 2.1 毛利率在收入翻倍时反而下行，且已被同业对照锁定为个体问题
FY2025 GAAP GM 30.04% → 2026Q1 29.06% → **2026Q2 27.72%**（同比 −2.6pp）[mat-1658c3]。同期旭创 39.96% → **46.59%（+6.63pp）**、隐含 ASP **+36.6%**、产能利用率 85.1% [mat-e7e8f2]。**同一季度、同一批客户、同一轮紧缺，方向相反 → "行业原因"不成立。**
**⚠️ 本条的量化承重仍不足**：AAOI 是混品（53.8% CATV 硬件 + datacom），旭创是纯 datacom，合并毛利率对标严格来说是苹果比橘子。分段毛利率公司从未披露（见 §7 P0-1），所以这条只能作**方向性证据**，不能当作精确的差额度量。

### 2.2 九年一手弧线：同一家公司在上一个紧缺高点做到过 43.5%，然后被打到 24.2%
FY2019 10-K 与 FY2025 10-K 拼出的数据中心分部一手序列 [mat-41683c, mat-03e60b]：

| 财年 | 数据中心收入 | 分部毛利率 | 当年语境 |
|---|---|---|---|
| FY2017 | $382.3M | **43.50%** | 40G 紧缺高点，单一大客户占比极高 |
| FY2018 | $267.5M | 32.80% | 大客户抽单 + 40G→100G 切换开始 |
| FY2019 | $190.9M | **24.20%** | 世代切换完成，价格战 |
| FY2022 | $222.8M | **15.09%** | 周期谷底 |
| FY2023 | $217.6M | 27.07% | 修复 |
| FY2024 | $249.4M | 24.78% | AI 前夜 |
| FY2025 | $455.7M | 30.04% | 本轮 AI 紧缺 |

**八年（2017→2025）收入 +19.2%（CAGR 仅 2.2%），毛利率净 −13.5pp。** 而本轮的高点毛利率（30.04%）**比上轮高点（43.50%）低 13.5pp**——同一家公司、同一种紧缺、同一位创始人 CEO。这是本 thesis 最硬的历史证据，且它是一手的。
（缺口：FY2020/FY2021 未取，弧线中间有两年空档，见 §7 P1-7。）

### 2.3 公司自己在法律文件里承认没有差异化
10-K 原文：**"our products are only minimally differentiated from those of our competitors"**，因此面临 **"strong pricing pressure"**；并承认新品定价已预支未来降本 [mat-03e60b]。

### 2.4 垂直一体化的边界远窄于叙事
InP 衬底 **100% 外购**（欧 2 + 日 2 + 中 3，正在谈合资）；CEO 亲口 **"the big challenge... is the DSP and TIA"**；**自供率从未量化披露**，最强口径只有 "more than 95% of laser will be AOI laser"，分析师直问具体数字时被绕开 [mat-4e8a59]。行业独立研究说约束是 **"assembly, test, and qualified capacity rather than the optical chips"** [mat-fb4005]。

### 2.5 收入接近翻倍仍无法把营业利润做正，而 FY2019 证明这不是新问题
FY2025 收入 +82.8%、opex 占收入 **42.0%**（R&D +55.6% / S&M +66.7%）、营业亏损 **−$54.6M（−12.0%）**；2026Q2 收入 +86.4%、营业亏损仍 **−$24.7M（−12.4%）**[mat-03e60b, mat-1658c3]。**FY2019 的一手对照说明这是结构而非阶段**：那一年毛利率还有 24.20%，营业利润已经深亏 [mat-41683c]。所以命门必须同时挂**营业利润率**（见 §1），只盯毛利率会漏判。

### 2.6 现金消耗三年放大约 40 倍，全靠发新股填
FCF：−$17.6M(2023) → −$113.4M(2024) → **−$354.0M(2025)** → **H1'26 约 −$707M**（capex 是 H1 收入的 1.85 倍）[mat-03e60b, mat-1658c3]。资金来源：FY2025 ATM 净额 $518.9M，H1'26 额度 16 天内从 $250M 翻倍到 $500M [mat-7163f5]。股东权益 $229.1M → $1,668.0M（7.3 倍）**几乎全部来自增发而非留存**。

### 2.7 每股价值的真实漏损点是股权激励，不是 ATM
2026H1：PSU 归属 1,534K 股 @ $181.57 = $278.5M；RSU 516K @ $96.42 = $49.8M；**合计约 $328.3M（≈H1 收入的 96%）**，而利润表股权激励费用**仅 $9.25M（差约 35 倍）**，另有 **$71.2M 现金**代扣个税 [mat-1658c3]。背景：2022 年 PSU 曾按目标 **200% 上限**兑付；2026-02-13 为 CFO 及三位 SVP 批准"增强的离职补偿" [mat-03e60b]。

### 2.9 FY2026 非 GAAP 营业利润指引被静默撤下，收入指引措辞退坡
| 时点 | 收入指引 | 营业利润指引 |

### 2.10 Q4'26 的三个口径互斥（命门 M4）
CFO 确认 Q4 的 800G+1.6T 约 **$330M**；CEO 同场说 Q4 **">$500M、QoQ 约 +60%"**（但 $272.5M × 1.6 = **$436M**，两数互斥）；全年 "around $1.1B" 减前三季约 $622M 隐含 **$478M** [mat-4e8a59]。若 CFO 的 $330M 成立，**800G 需从 Q2 的 $12.8M 单季跳到约 $250M（约 20 倍）**。**三个数无法同时成立，因此其中任何一个都不能当作确定的锚。**

### 2.11 收入的一半以上走单一备货型分销商，且信用风险被评估为近乎零
Quantum12 是 **CATV 产品线**，Digicomm 是**备货型分销商**（自购库存，货发到其仓库即确认收入）[mat-76fc11]。所以 **CATV 占收入 53.8% 与 Digicomm 占收入 53.1% 是同一批收入的两个切面** [mat-03e60b]。Digicomm 占应收 **71.6%(FY25) / 74.5%(Q1'26) / 67.2%(Q2'26)**、金额 $175M → $222.7M → $211.0M、DSO **178-196 天**（健康区间 45-90 天），而 FY2025 全年信用损失计提**仅 $4 千** [mat-03e60b, mat-7163f5, mat-1658c3]。**CATV 替换潮转向时，先出现的不是终端装机下滑，而是分销商停止备货 + 已备库存需消化 + $211M 应收回款变慢。**

### 2.12 估值：市场给的是龙头的收入倍数，但盈利能力要求已被下调
现采 as-of 2026-09-01：**AAOI P/S 14.73（亏损、GM 27.7%）vs 旭创 15.53（PE 49.53、GM 46.59%）vs 新易盛 16.15（PE 43.48）vs 纯代工 Fabrinet 3.10**。
**⚠️ v1 在此处的结论被 v2 推翻**：按修正后的一致预期中枢 FY2027 EPS **$4.75**，现价对应 **21.8x**（不是 v1 写的 27.2x）；给 25x 得 **$118.75（+14.9%）**。**"隐含 IRR 0-5%、无风险补偿"这句话在正确的定价锚下不成立。** 本条现在只支持一个较弱的版本：市场按 14.8% 净利率定价，而这家公司从未在任何一个财年做到过两位数净利率。

### 2.13 期权占了市值的 78-89%，而它的兑现证据在 5 个月后才出现
基本盘（CATV 约 $260M + 老世代数据中心约 $379M = **$639M**）给 1.5-3.0x P/S = **$0.96-1.92B** → **期权隐含定价 $6.86-7.82B（占市值 78-89%）**，而 800G/1.6T 当前只占公司收入约 **6.7%**（Q2 的 800G 仅 $12.8M）[mat-4e8a59]。我按 40-60% 成功概率算期权期望 NPV = **$3.75B**——**市场为同一份期权付的价是我的 1.8-2.1 倍。**
（v1 此处的每股表算错约 60%，已废除；本条现在**只作 sanity check，不产出每股公允值**。）

### 2.14 行业周期的预警信号已经出现
**LightCounting 口径 2026 年缺口约 30%、并预计 2026 年底消除** [mat-7d45cd]；机制是"短缺期客户重复下单撑价 → 缓解后价格加速下跌"；历史上 2019 末、2022 末各一次过剩，**约每三年一轮**。而 2027 年恰是一致预期要求收入从 $1.1B 跳到 $2.60B 的年份。另："需求超供给两倍"这个流传说法是 **2023-2024 旧世代口径**。

### 2.15 规模位置：在一个规模决定成本的环节里，体量是龙头的 1/32
Cignal AI：旭创 1Q26 datacom 组件 **$2.6B**（全球 $7.7B 的 34%），**AAOI 仅 $81M ≈ 旭创 1/32**，被明确形容为 "small by comparison" [mat-fb4005]。

### 2.16 管理层的长期战略表述不可作为估值依据，且跨周期重复
2022-09-15 同一位创始人 CEO 就出售中国工厂签"最终协议"作价 **$1.5 亿**，并**宣布退出光模块市场**，动因是光模块"盈利空间越来越小"；2023-09 突发终止 [mat-d9c8af]。**四年前的判断内容，正被今天 27.7% 且下行的模块毛利率验证；而管理层从未撤回那个判断，只是改变了行动。** 更值得注意的是**同一套措辞跨周期重复出现**：FY2017-2019 崩塌期与本轮，管理层都用"下一代产品认证进展顺利 + 产能在建 + 长期毛利率目标"这三件套解释当期毛利率下行 [mat-41683c, mat-4e8a59]。上一次这套说法之后是收入八年零增长。

### 2.17 订单可见度为零，管理层口述无法核对
10-Q 明确**无 backlog / 剩余履约义务披露**（所有合同期限 ≤1 年）[mat-1658c3]；10-K 明确 **"We do not have any long-term purchase commitments (in excess of one year) with any of our customers"** [mat-03e60b]。因此"$200M+ 在手订单" [mat-4e8a59] 不是假的，但**不可验证**。

## § 3. 反方观点（当前完整清单 · 诚实版，非稻草人）

### 3.1 【本版升为最强多头论据】定价锚一修正，"没有风险补偿"这句话就没了
5 源交叉后 FY2027 EPS 中枢 **$4.75**（不是 $4.18），现价对应 **21.8x**。**在一个同业 PE 带落在 43-126x 的板块里，21.8x 前瞻 PE 谈不上定价充分。** 给 25x 得 $118.75（+14.9%），给 30x 得 $142.50（+37.8%）。**这条直接推翻了 v1 的旗舰指控，是 critic 提出的九条缺陷里杠杆最大的一条。** 我保留的限定只有一个：$4.75 这个中枢自身建立在 FY2027 收入 $2.60B 上，而 $2.60B 的第一块砖（Q4'26）三口径互斥。

### 3.2 街上的模型比公司自己的股本指引还保守，所以我的分歧 2 可能是重复计价
反推 5 源的隐含股本是 **78.2-82.8M 股**，而公司 Q3 指引已给 **92.8M**。**街上并没有假设一个不切实际的低股数——反而更低。** 这意味着我在 v1 里把"股数 96-100M"当独立 delta 是有问题的：市场用的股数比公司指引低，我用的比公司指引高，**两边的差里有一部分是同一件事被数了两次**。v2 因此把 delta 从 −3.5pp 收到 **−1.8pp**。

### 3.3 市场并没有为增速付溢价——前瞻口径下 AAOI 比旭创便宜
AAOI FY2026E P/S = **7.98x**（按管理层 "around $1.1B" 与新市值 $8.778B），旭创按 2026H1 年化推算前瞻约 **11.3x**。**前瞻口径下 AAOI 便宜约 29%**（v1 算的是 22%，股价下跌让这条更强）。（我的反驳：分母 $1.1B 本身就是待检验的东西。**但如果 Q4 兑现，这条就成立。**）

### 3.4 融资端在增厚而非摊薄，且这一点我在 v0 里判错了方向
H1'26 ATM 均价约 **$132.2/股**（5-6 月 $181-197），**每股账面从 $9.79 涨到 $19.77（+102%）**，公司因此手握净现金约 $320.8M [mat-1658c3]。**按账面口径，高价增发对老股东是增厚。**（限定：这个增厚是股价的函数——股价回落到 $40-60，同样的 ATM 就从增厚变漏损。现价 $103 尚在增厚区。）

### 3.5 Amazon 用股权替代长约，是比任何卖方模型都硬的信号
7,945,399 股权证、行权价 $23.6956、10 年期、归属挂钩累计采购最高 **$40 亿** [mat-03e60b]。客户愿把自身经济利益绑在供应商股价上，通常意味着多年供应关系。**$40 亿这个门槛反过来说明：若 Amazon 真成为多年期大客户，收入会远高于现在。** 2026H1 Amazon 相关收入已达 **$84.8M（占 H1 收入 24.7%）**[mat-1658c3]。

### 3.6 "权证全额稀释"是远期风险而非近期风险
剩余 6,621,166 股需累计采购 $40 亿才归属，按每 $1,000 采购归属 1.655 股、H1'26 的 $84.8M 节奏（年化约 $170M）计，**需约 23.5 年** [mat-1658c3]。**因此近期完全稀释上限是约 97.7M。**

### 3.7 自有激光 fab 确实在赚高毛利，只是被稀释了
激光器业务毛利率 **55-65%**、EOSAP >50% [mat-4e8a59]。**这是一块真实的瓶颈位资产。** 若自供率远高于我的隐含假设，M1 的"代工位"判断会偏空。（缺口：**自供率从未量化，所以这条我无法定量反驳，只能承认为盲点。**）

### 3.8 门槛比我原先设的低：14.8% 净利率只需 GM 32-35%，而公司做过 43.5%
市场隐含净利率 **14.8%**（干净口径 $381M/$2,574M），对应所需毛利率约 **32-35%**。而 CEO 已把年底出口定在 "32%-33%"——**这个数字落在门槛区间内而不是区间外**。更要紧的是 §2.2 的一手弧线是**双刃的**：它证明这家公司**在同样的紧缺高点做到过 43.50%**。所以"32-35% 结构性做不到"这个说法我拿不出一手依据，**只能说"它上一次做到 43.5% 之后守不住"**——那是持续性问题，不是能力问题。**这条是我把假设 2 从"弱"改判为"中"的直接原因。**

### 3.9 1.6T 认证与订单是实在的进展
"AOI will be the **fourth supplier** qualified by one big hyperscale data center customer"、认证"finished within maybe two, three weeks"、**$200M+ 在手订单**、Q1'27 翻倍、2027 年底 >500,000 只/月 → $300-350M/月 [mat-4e8a59]；券商称正与微软、Oracle 接洽 [mat-e575c5]。

### 3.10 CPO 对 AAOI 是双面的，且它是供应方而非被替代方
ELSFP（CPO 外置光源）已进官方产能规划（2026Q4 起 5K/月 → 2027Q4 达 400K/月）[mat-76fc11]；400mW CPO 光芯片已送样 [mat-e575c5]。行业主流判断是 **"CPO 长期将与可插拔光模块及其他连接解决方案共存"** [mat-e7e8f2]。（反向：**AAOI 已错过 CPO 第一代部署**，ELSFP 达 400K/月的时点已从 "by end of 2027" 后移到 **"in 2028"** [mat-4e8a59]。）

### 3.11 同业倍数带支持的不止 25-27x
现采：旭创 PE(TTM) **49.53x**、新易盛 **43.48x**、Coherent **66.19x**、光迅 **126.30x**。**在这个倍数带里，v1 给 Bull 只用 26x 是自我设限**——v2 因此把 Bull 中枢提到 30x。（我保留不给 40x：那是峰值倍数叠加峰值盈利。）

### 3.12 终端需求的外生驱动仍在加速
四家北美超大厂 2026Q2 资本开支合计 **$1,649 亿，同比 +86%** [mat-e7e8f2]；以太网光模块市场 2026E 仍 +65% [mat-7d45cd]；EML 交期排到 2027 年后 [mat-7d45cd]。**紧缺现在是真实存在的，两派只在"多久"上分歧。**

### 3.13 硅光渗透与卡口迁移可能让"紧缺缓解"不等于"AAOI 受损"
硅光渗透率 2025 约 38% → 2030 约 73% [mat-e7e8f2]。若卡口从 EML 迁移到组装/认证/封装基板，**总量上"缺口消除"而个别环节仍紧**——那时受益者取决于卡在哪一环，而 AAOI 的自有激光 + 美国产能可能反而受益。

### 3.14 动能与预期差本身就是右侧理由
5 个季度连创纪录、Q3 指引 +35-45%、Q2 收入 +86.4%；一致预期 FY2027 $2.60B 只有管理层口径（$5.65B 年化）的 **46%**。**"估值贵"这个论点在 2025-2026 已被打脸多次（一年 +465%）。** 空头拥挤度 12.83% + days-to-cover 1.2 天，任何超预期都可能引发轧空。

### 3.15 我自己的四处算术错误，本身就是对我结论的减分项
critic 查出弱空档单价、模型 B 每股表、Q2 数据中心收入、EV 加总口径四处与自身参数不符。**这些错误全部方向一致地压低了公允值。** 我没有理由认为剩下没查到的地方就没有同向偏差——这一条我计入 §8.4 的"我最可能错在哪"。

## § 8. 思维过程留痕

### 8.1 我知道的（本轮最确定的三件事）

1. **九年一手弧线**：同一家公司在上一个紧缺高点做到过 43.50% 毛利率，随后三年被打到 24.20%，八年后收入只多 19.2% [mat-41683c, mat-03e60b]。**这取代了 v1 的"同业对照"成为本案最硬的单一证据**——因为它是同一家公司的纵向序列，不需要处理混品 vs 纯 datacom 的口径问题。
2. **每股价值漏损的机理**：在 SBC（$328.3M vs 利润表 $9.25M，35 倍）+ $71.2M 代扣税现金，不在 ATM（ATM 按账面口径增厚）[mat-1658c3]。这是会计事实，不依赖任何预测。
3. **市场定价与我的差距比 v1 小得多**：市场隐含 FY2027 净利率 **14.8%**、股数约 **80M**；我判 **13.0%**、96-100M。**净利率 delta 只有 −1.8pp**（v1 写 −3.5pp）。**"市场完全没留风险补偿"这个 v1 的旗舰指控在正确的定价锚下不成立。**

### 8.2 我刻意避开的偏见

1. **确认偏误（本轮最大风险，因为镜鉴全是失败案例）**：环⑤的三个历史镜鉴（AAOI 2017-2019、AAOI 2022-2023、行业 2019/2022 过剩）**全部是失败案例，我没找到一个"这类公司在这类节点成功穿越"的可比案例**。对冲动作：Bull 概率维持 25%（未因 v2 的偏空新证据下调）、Bull 倍数**主动从 26x 上调到 30x**、§3 反方论据从 12 条增到 15 条。
2. **锚定偏误——v2 的检验结果是"我确实在向旧结论锚定"**。v1 的 EV 是 −15%，而 critic 查出的四处算术错误**全部方向一致地压低公允值**。这不是随机错误的分布形状。**我把这一条从"警惕"改判为"已发生"**，并因此在 §8.4 把"剩余同向偏差"列为我最可能错的第一位。
3. **方向性错误的主动纠正（累计三次）**：v0→v1 纠正"$113 高位增发摊薄股东"（实际 ATM 均价 $132.2、每股账面 +102%）与"微软已流失"（实际 FY2025 仍是第二大客户 28.8% [mat-3ea4b8]）；**v1→v2 纠正"隐含 IRR 0-5%、无风险补偿"（实际现价仅 21.8x）**。三次都在正文明确标注，未悄悄改掉。
4. **不把"关税护城河"当免费的看空理由**：它在数据上不成立（美国制造收入 0.7%、IEEPA 已被推翻），**但我也没把它反过来当看多理由**——FCC 禁令对一家 42.8% 中国产能的公司未必净利好，两边都不计入 EV。
5. **不做空的纪律**：方向判断为负但幅度已很小（EV vs 现价 +2.7%），**赔率完全不支持空头表达**（拥挤度 12.83%、days-to-cover 1.2 天、5 季连创纪录动能、Q4 若兑现有轧空风险）。**"看空"与"做空"是两个决策。**
6. **v2 特有：抵制"跌了 9% 就是机会"的反射**。股价从 $113.76 跌到 $103.39 让期望回报从 −6.8% 变成 +2.7%，**但这只把它从"不建仓"推到"观望"，没推到"可建仓"**——买入框的上沿 $86 是 EV 打 19% 安全边际算出来的，不因股价下跌而上移。

### 8.3 关键差异（我 vs 市场，一句话）

> **我不与市场分歧于"它能不能卖出货"（紧缺是真的、订单是真的、产能在建是真的），也不再声称"市场完全没留风险补偿"（现价 21.8x 前瞻 PE，在一个 43-126x 的板块里不算充分定价）。我分歧于持续性：市场隐含 FY2027 净利率 14.8% 并默认它能守住，而这家公司上一次在同样的紧缺高点做到 43.50% 毛利率之后，三年内掉到 24.20%、八年后收入只多 19.2%。我判净利率 13.0%（−1.8pp）、股数 96-100M，两条 delta 加上"守不住"的概率权重，把 Base 从 $92 压到 $81。**

### 8.4 我最可能错在哪（诚实排序）

1. **【v2 升到第一位】剩余的同向算术偏差**。critic 查出的四处错误全部方向一致地压低公允值（弱空档 $62 应为 $42.5、模型 B 每股表高估 60%、Q2 数据中心 $82M 应为 $107.6M、EV 加总口径不一）。**没有理由认为剩下没查到的地方就没有同向偏差。** 缓解动作：v2 的每个公允值都在对话内用脚本重算过，且脚本输出保留可复现。
2. **如果 Q4'26 做到 $480M+**：假设 1 完全兑现，一致预期 FY27 $2.60B 的基数确立，Base 应回到 $92 以上，Bull 概率上调。**这是五个月后就会揭晓的事，而我的判断建立在"三口径互斥说明管理层自己也没把握"这个推论上——这个推论可能过度解读了电话会的即兴回答。**
3. **如果自供率远高于我的隐含假设**：激光业务 55-65% 毛利率对合并毛利率的贡献会大得多，M1 偏空。**这是我无法定量反驳的盲点（自供率从未披露）。**
4. **如果分段毛利率一旦披露，证明 datacom 分部毛利率远高于合并的 27.72%**：那么"代工位"这个定性会需要重写，而**这正是 §7 P0-1 那个取不到的数**。M1 置信度已因此下调到"中"，但如果这个数出来且对我不利，M1 应直接降到"低"。
5. **如果期权成功概率应取 70%+**：模型 B 的 sanity check 结论完全取决于这个概率。我取 40-60%，**如果读者认为应取 70%+，那么当前价是合理的**——这是本案多空的真正分界点，而它是判断不是计算。
6. **如果卡口迁移而非缓解**：紧缺缓解后若卡口迁到组装/认证/封装，AAOI 的自有激光 + 美国产能可能反而受益。**我的 Bear 假设的是"缺口消除 → 价格下跌"这个 2019/2022 机制，但世代不同、终端驱动力不同，机制可能不重演。**
