# Thesis v1 — In vivo CRISPR/Base Editing 罕见病

## 一、核心 thesis（一句话）

**超配 NTLA + BEAM 罕见病 in vivo CRISPR / base editing 篮子（4-7% 总组合）**：HAELO Phase 3 阳性 + rolling BLA 锁定 NTLA-2002 HAE first-in-class 2027 H1 BLA 通过；BEAM-302 60mg pivotal 启动支撑 2028 AATD 二号兑现；首年商业化曲线 + KalVista oral 抢池 + LNP IV 长期安全是核心兑现风险。

## 三、支持理由（why bullish）

1. **K1-RD 数据级胜出**：HAELO Phase 3 -87% attack reduction / 62% attack-free / 0 SAE — 这是历来 in vivo CRISPR / base editing 最强的 Phase 3 数据组合。rolling BLA 2026-04 已启动，2027 H1 PDUFA 决定。FDA 已对 Casgevy 单 trial 路径开过先例。

2. **K2-RD 平台机理双重确认**：BEAM-302 60mg single-dose AAT 16.1µM 跨过 functional threshold（≥11µM 是肺/肝病防御阈值）+ Z-AAT 致病蛋白 -84% + 0 single-dose SAE。50 例 pivotal cohort 2026 H2 启动，2027 Q2 readout。Pfizer / Apellis $1B+ opt-in 期权强背书。

3. **K3-RD base rate 强化**：BBIO Acoramidis 上市 13-15 月 NBRx >25% / 1,856 prescribers / 7,804 patients / FY2026 年化 $720M — 罕见病 first-in-class oral 商业化的"快速曲线" 模型可参考。ALNY AMVUTTRA US Q1 2026 $702.6M（+255% YoY）是 RNAi 平台扩张的 base rate。HAE 全球池 30k + AATD 100k 池子 × $400-500K 编辑价 × 50% peak penetration ÷ 5 年 = HAE peak $1.0-1.5B + AATD peak $0.8-1.2B。

4. **平台估值再扩张可能**：当 NTLA-2002 / BEAM-302 中至少一个上市 + 首年销售验证（2028 Q1），周期从导入期切换到成长期，估值锚从"催化剂期权 + DCF"转向"季度销售 KPI"。Verve PCSK9 数据如成功，in vivo 编辑从罕见病扩到心血管慢病，TAM 扩 10-100×。

5. **BP 并购上行期权**：Lilly $1.3B 收购 Verve（2025-06）+ Pfizer/Apellis opt-in（2026-Q1）已确认 BP 对 in vivo 编辑平台的战略并购意愿；BMS / Sanofi / Novartis 18 个月内并购 NTLA / BEAM 概率 25-35%，溢价 50-100%。

## 四、反方观点（why bearish）

1. **Casgevy 漏斗映射风险**（K3-RD bear）：VRTX FY2025 全球仅 64 例输注 / 漏斗 300/147/64（21% 转化），即便 NTLA-2002 LNP IV 不需 conditioning，仍可能有"患者识别 → 基因检测 → 保险审批 → 治疗中心调度 → 实际输注" 60-70% 衰减 → 上市第一年实际治疗 100-200 例 × $400K = $40-80M（远低于市场 base $150M）。

2. **KalVista oral 阵营加速**（K5-RD bear）：EKTERLY Q1 $39.2M（year 1 annualized $160M+）+ Chiesi $1.6B 收购 + BCRX ORLADEYO $602M FY2025 + Astria $874M 收购 STAR-0215 Phase 3 → oral / SC HAE 阵营在 NTLA-2002 上市前已巩固到 65-70% 池子份额，NTLA-2002 5 年 peak penetration 可能仅 30-35%（vs base 50%）。

3. **LNP IV 长期安全黑天鹅**（K4-RD bear）：NTLA Phase 1 BTR 2025-11-05 死亡（已终止项目）+ BEAM-302 2x60mg 1 例 Grade 4 ALT + ATTR 2025-10-29 临床 hold（已解除）— 单平台单事件可被 dismissed，但任何第二例严重事件（含其他公司）会触发整赛道冰冻 5-10 年（参照 1999 Gelsinger）。

4. **资本结构与稀释**：NTLA 2028 / BEAM 2027 H1 现金 runway，上市第二年若销售不及预期，再融资 dilution 10-15% 每轮。BBIO 模式（转债 + royalty SPV $300M + Sixth Street）依赖上市后销售曲线持续上行，否则 capital efficient 路径破裂。

5. **IRA / 报销天花板**：2027 中期选举后 IRA 罕见病豁免可能被收紧 + EU JCA 联合临床评估 2027-Q1 首例 in vivo gene editing → peak revenue 估算下调 20-30%。

6. **平台代际竞争**（K5-RD bear extended）：ALNY nucresiran 6-mo 90% 维持降幅 → 半年一针的便利性显著缩小 NTLA-2001 ATTR "一次性"的差异化优势。
