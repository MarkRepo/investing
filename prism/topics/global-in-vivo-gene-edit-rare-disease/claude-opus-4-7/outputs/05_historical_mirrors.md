# In vivo CRISPR/Base Editing 罕见病 — 历史镜像

## 一、成功类比（success mirrors）— 高度相似度优先

### M1. Alnylam Onpattro → AMVUTTRA TTR 平台（2018-2025）— ★★★★★ 最相似

**事件起点**：2018-08 Onpattro FDA 批准（首个 RNAi 药物 hATTR-PN polyneuropathy）

**关键数据**：
- 上市第一年（FY2019）销售 $166M（4.5 个月即 $13.5M）
- ATTR-PN 适应症 2024 销售 ~$1B → 2025 ATTR-CM sNDA 后 AMVUTTRA TTR 全 franchise FY2025 $2.31B（+138% YoY）
- 2025 首次 GAAP 盈利 $501.6M operating income → 总周期 7 年（上市 → 盈利）
- 6 个 RNAi 产品全部 BLA 通过（100% 成功率）

**与本 thesis 的相似性**：
1. ✅ 核心相似：罕见病 + LNP/GalNAc 平台 + 基因层面机理（RNAi knockdown vs CRISPR knockout）+ 一次性给药 / 长效 + 罕见病 first-in-class 路径
2. ✅ 商业化爬坡曲线：5 年从 $13M（首季）→ $2.31B 全 franchise，验证罕见病平台商业化可达 1000× 量级扩张
3. ✅ 适应症外溢：从狭窄 ATTR-PN 扩到大 ATTR-CM 是 AMVUTTRA 5× 跃升关键 — NTLA-2002 HAE 后扩 ATTR-CM (NTLA-2001) 也是同样路径
4. ⚠️ 关键差异：ALNY 用 12 年累计 6 BLA 成功（2018-2025）才实现盈利；NTLA / BEAM 还在第 1 个 BLA 阶段，烧钱期未结束
5. ⚠️ 关键差异：RNAi 是 reversible，in vivo CRISPR 不可逆 → 监管 / 患者接受度风险更高

**回报区间**（投资人持有 ALNY 2018-08 至 2025-12）：
- 2018-08-10 ALNY 收盘 $99 → 2025-12-31 收盘 ~$420 → 7 年 4.2× 总回报（CAGR ~23%）
- 期间最大回撤：2019-09 Onpattro 销售不及预期 -50%（$120 → $60）→ 2020-Q4 反弹

**对 thesis 启示**：NTLA-2002 BLA 通过后 5-7 年内总回报 3-5×，但中间有 1-2 次 -50% 回撤。**核心阅读**：罕见病 RNA / CRISPR 平台首个产品上市 → 第二适应症兑现 → 平台估值再扩张是连续 5-7 年的旅程，不是 12-18 月套利。

### M2. BridgeBio Acoramidis（2024-2026）— ★★★★ 高相似度（commercial 角度）

**事件起点**：2024-11-22 FDA 批准 Acoramidis（Attruby）治疗 ATTR-CM

**关键数据**：
- 上市第一年（FY2025）净销售 $362.4M
- Q1 2026 单季 $180.6M（+391.6% YoY，年化 ~$720M）
- 上市 13-15 个月达 NBRx >25% / 7,804 患者 / 1,856 prescriber
- SG&A FY2025 $531M（+84%）/ FY2026Q1 $164M（+54% YoY）— 商业化第一年 SG&A 仍在加速

**与本 thesis 的相似性**：
1. ✅ 罕见病 first-in-class oral 上市，类比 NTLA-2002 HAE（first-in-class in vivo CRISPR）
2. ✅ 与已批 first-gen 产品（Pfizer tafamidis）共存 + 抢占 → 类比 NTLA-2002 与 ORLADEYO/EKTERLY oral 共存
3. ✅ 上市第一年 SG&A +84% → 类比 NTLA / BEAM BLA 后第一年现金消耗模式
4. ⚠️ 差异：Acoramidis 是 oral 每日服药，NTLA-2002 是一次性 IV → 患者接受度路径不同（一次性顾虑 vs 依从性顾虑）
5. ⚠️ 差异：ATTR-CM 诊断池 50k → 5 年 10× 增长是核心驱动；HAE 池 30k 已稳态，靠"诊断率提升"空间小

**回报区间**：
- BBIO 2024-11-22 上市前 $30 → 2026-05 ~$76（+150% 18 个月）
- 期间最大回撤：2025-Q3 SG&A 暴涨期 -25%（短暂）

**对 thesis 启示**：first-in-class oral 罕见病上市后 18 个月可 +150%，但 SG&A 同时在加速 → cash burn 不收敛是常态。NTLA / BEAM 模型时**不应假设 BLA 后第一年盈亏改善**。

### M3. Vertex CAR-T / Casgevy（2017-2025 整段 cell therapy 周期）— ★★★ 中等相似（部分参考）

**事件起点**：2017 Kymriah 首批 CAR-T；2023-12 Casgevy 首批基因疗法（SCD/β-thal）

**关键数据**：
- Kymriah 上市第一年 $70M → 第三年 $470M
- Yescarta 上市第一年 $264M → 第三年 $850M
- Casgevy FY2025 全球仅 $42M / 64 例输注（上市 24 个月）
- 漏斗 300/147/64 = 患者识别 → 干细胞收集 → 输注 21% 转化率

**与本 thesis 的相似性**：
1. ✅ 一次性基因疗法商业化曲线 — first-in-class 上市第一年 $50-150M 是 base case
2. ✅ 漏斗效应 — 复杂治疗（conditioning / IV / 监测）天然首年低渗透
3. ⚠️ 关键差异：Casgevy 需 myeloablative conditioning（住院 4-6 周），NTLA-2002 不需 → 漏斗效应弱很多
4. ⚠️ 关键差异：CAR-T 是个性化，Casgevy 是个体化干细胞，NTLA-2002 是 off-the-shelf LNP IV → 制造 / 物流便利度差 5-10×

**回报区间**：
- VRTX 2023-12-08 Casgevy 批前 $360 → 2026-05 ~$510（+42% 30 个月，CAGR ~16%）
- CRSP 2023-12-08 ~$50 → 2026-05 ~$48（持平 → -4%）

**对 thesis 启示**：复杂一次性基因疗法首年商业化普遍低于市场预期；NTLA-2002 LNP IV 路径"轻"得多，应介于 Acoramidis（快）与 Casgevy（慢）之间，base case 首年 $80-150M 美国销售。

### M4. Spark Luxturna / Novartis Zolgensma（2017-2024）— ★★★ 中等相似（罕见病 gene therapy 全周期）

**事件起点**：2017-12 Spark Luxturna（视网膜 RPE65 基因疗法，~$0.85M/眼）；2019-05 Novartis Zolgensma（SMA AAV，$2.1M/患者）

**关键数据**：
- Luxturna 上市第一年 $27M → 2020 peak $32M → 2024 $26M（patient population 仅 ~6,000，市场天花板）
- Zolgensma 上市第一年 $361M → 2022 peak $1,370M → 2024 $1,210M（SMA 新生儿池子有限，渗透 90%+ 后稳态）
- 两者均为 AAV + 一次性永久治疗

**与本 thesis 的相似性**：
1. ✅ 一次性永久治疗 + 罕见病 + 高单价（>$0.5M）商业化模式
2. ⚠️ Luxturna 失败镜像（参 M-1 失败章节详述）— TAM 仅 6,000 患者过小
3. ⚠️ Zolgensma 部分成功 — SMA 1 型新生儿池子集中（每年 ~700 美国新发）→ 一次性治疗几乎"清空池子"

**回报区间**：
- Spark 2018-02 被 Roche 收购 $4.3B（vs IPO 2015 $1.6B）= +170%
- Novartis Zolgensma 收购 AveXis 2018 $8.7B → 7 年累计销售 ~$5.5B = ~63% recoupment

**对 thesis 启示**：一次性基因疗法的 TAM "清空速度"是关键变量 — HAE 30k 池子若 NTLA-2002 5 年治疗 60% = 18,000 例 × $400K = $7.2B 累计 → 单产品天花板可达 $3-5B peak revenue。

## 二、失败镜像（failure mirrors）— ≥2 强制覆盖

### M-1. Spark Luxturna 商业化失败（2017-2024）— ★★★★ 高警示

**事件**：上市后单年销售从未突破 $35M，市场天花板远低于预期

**关键数据**：
- Roche $4.3B 收购 Spark 2018，按销售曲线 7 年仅 $200M+ 累计 = ~5% recoupment
- 上市第一年 $27M → 第三年 peak $32M → 第七年 $26M（萎缩）
- 美国 Luxturna 患者池仅约 6,000（RPE65 基因突变盲症罕见）
- 复杂手术 + 视网膜下注射 + 老年患者风险 → 治疗中心仅 8 家美国

**失败原因**：
1. **TAM 过小**：6k 患者 × 50% peak penetration × $0.85M = $2.5B 累计 = 不够回报 $4.3B 收购
2. **手术依赖**：罕见医生能操作（视网膜下注射），形成商业化漏斗
3. **保险审批难**：每例 $850K 需 prior authorization 6-9 个月

**与 in vivo CRISPR thesis 的警示对照**：
1. ⚠️ HAE 患者池 30k 全球、AATD 100k → 比 Luxturna 大 5-15×，TAM 风险**部分缓解**但仍非 megablockbuster 级
2. ⚠️ NTLA-2002 IV 给药相对 Luxturna 视网膜下注射是简化的，但仍需输液中心 + 监测 → 漏斗效应仍存在
3. ⚠️ 保险审批漏斗 — Casgevy 在美国保险审批 6-12 个月是 in vivo CRISPR 的同样困境
4. ✅ 关键差异：HAE 患者主要由变态反应医生 / 免疫科管，治疗中心数量比视网膜外科多 50-100×

**钝化的回报情形**：若 NTLA-2002 完全复制 Luxturna 路径（首年 $30M、5 年 peak $50M、TAM 萎缩 → NTLA EV 砍至 $0.5-0.8B（current EV $3.0B 下行 -75%）

### M-2. CSL Hemgenix（2022-2024）— ★★★★ 高警示

**事件**：2022-11 FDA 批准 Hemgenix（CSL/uniQure 血友病 B AAV 基因疗法，$3.5M/患者，史上最贵药），2024 全年仅 $86M

**关键数据**：
- 上市第 1 年（FY2023）$13M → 第 2 年（FY2024）$86M → 第 3 年（FY2025）$100M+ run rate
- 美国血友病 B 池约 6,500 患者 + 严重型 ~2,500
- 2 年累计仅 ~50 例输注（vs Casgevy 64 例 / 18 月）

**失败原因**：
1. **现有竞争产品太好**：Roche Hemlibra（皮下注射，每周/双周）已是血友病 A 黄金标准，血友病 B 也有效（off-label）
2. **一次性永久顾虑**：血友病 B 患者多为年轻男性，对一次性 AAV 永久转染 + 5-10 年长期不良反应顾虑高
3. **极高单价**：$3.5M/患者 → 保险审批 6-12 个月，疗效不及预期还可能被拒
4. **AAV 长期数据不充分**：2026 已有 Hemgenix 5 年随访 ALT 轻度升高、长期不良反应未结案

**与 in vivo CRISPR thesis 的警示对照**：
1. ⚠️ HAE 同样有"现有 oral / SC 较好"问题（KalVista EKTERLY oral on-demand $39M Q1 + BCRX ORLADEYO oral $602M FY2025）
2. ⚠️ 一次性永久顾虑 → HAE 患者中位年龄约 35-45 岁，类似血友病年轻群体顾虑高
3. ⚠️ NTLA-2002 单价（市场预期 $400-500K，相对 Hemgenix $3.5M 低 7-9×）但仍属高价层
4. ✅ 关键差异：HAE 急诊就诊次数多（年均 1-3 次发作 + 部分 ICU 抢救）→ 相对血友病 B "已有 Hemlibra 控制良好"，HAE 仍有 unmet need 信号

**钝化的回报情形**：若 NTLA-2002 复制 Hemgenix 路径（FY2028 首年 $30M / 第三年 $150M peak $300M）→ NTLA EV 砍至 $0.8-1.5B（current $3.0B 下行 -50-70%）

### M-3. Pfizer Beqvez 撤市（2024-2025）— ★★★ 严重警示

**事件**：2024-04 FDA 批准 Beqvez（Pfizer 血友病 B AAV，$3.5M/患者）；2025-09 Pfizer 宣布**主动撤市退出**，因医疗资源限制 + 销售低于预期 + Hemgenix 同期销售困难

**关键数据**：
- 上市 17 个月累计销售 ~$10M（极少几例输注）
- Pfizer 2025-Q3 财报：Beqvez 写减 ~$300M

**失败原因**：
1. **市场已被 Hemgenix 吃下**（仅 50 例 / 2 年），但 Beqvez 没法分到余地
2. **Pfizer 内部并购整合 + Roivant deal 后聚焦肥胖 / 精神，砍掉非核心**
3. **AAV 平台质疑加深** + Pfizer Astellas 同时撤掉多项 gene therapy

**与 in vivo CRISPR thesis 的警示对照**：
1. ⚠️ 严重警示：罕见病一次性疗法**不仅可能商业化失败，还可能被主动撤市** — NTLA / BEAM 若上市第 2-3 年销售 < $50M，BP 接盘方主动放弃概率不容忽视
2. ⚠️ Pfizer 撤市决定主因是"内部聚焦优先级" — BP 收购 NTLA 后若新的 management 认为 in vivo CRISPR 不是 strategic fit，存在同样风险
3. ✅ 关键差异：Beqvez 是 second-mover（Hemgenix 已先），NTLA-2002 是 first-in-class HAE in vivo 编辑

### M-4. Editas Medicine（2017-2025）— ★★★ 中等警示（同代际平台失败）

**事件**：Editas 是 CRISPR 三巨头之一（与 NTLA / CRSP 并列），上市后从 $30 跌至 $2.5（2026-05），市值从 $1.5B 跌至 $0.3B

**关键数据**：
- 第一个候选 EDIT-101（LCA10 视网膜 ex vivo CRISPR）2022 终止（疗效不足）
- 第二个候选 reni-cel（SCD/β-thal ex vivo）2024-Q4 vs Casgevy 拼到一半，疗效不及，最终砍掉商业化决定
- 累计烧钱 ~$1.5B → 2026 仍无 BLA pipeline

**失败原因**：
1. **平台代际跟不上**：Editas Cas12a 平台 vs NTLA / BEAM 的 SpCas9 / Adenine Base Editor，效率与靶点偏好都落后
2. **管理层多次重组**（CEO 2-3 次更换）→ 战略飘忽
3. **资本市场惩罚**：Editas 上市后 9 年仅烧钱无 BLA → 2025 fund 已完全 capitulate

**与 in vivo CRISPR thesis 的警示对照**：
1. ⚠️ NTLA / BEAM 若任一项 BLA 失败 → 估值可下跌至 Editas 量级（$0.3-0.5B EV，下行 -85%）
2. ⚠️ in vivo CRISPR 平台**赢家通吃**特征 — 不是每家都能成功，单点失败可能彻底退场
3. ✅ 关键差异：NTLA / BEAM 已有 Phase 3 数据 + BLA pipeline + LLY/PFE/APLS 战略合作；Editas 长期未达 Phase 3

## 三、综合定位（mirror-based 投资回报区间）

**汇总**（NTLA / BEAM 等权篮子持仓 18-30 个月，2026-Q2 → 2028-Q2）：

| 情形 | 概率 | 类比镜像 | 18-30 月回报 |
|------|------|----------|-------------|
| 极乐观（M1+M4 路径）| 15% | ALNY + Zolgensma 双成功 | +200-400% |
| 乐观（M1 路径）| 25% | ALNY 启动 7 年 4×，前 18-30 月 +60-100% | +60-100% |
| 中性（M2+M3 路径）| 30% | BBIO Acoramidis 商业化 + Casgevy 谨慎模式 | +0-40% |
| 悲观（M-2 路径）| 20% | Hemgenix 商业化失败 | -30-50% |
| 极度悲观（M-1+M-4 路径）| 10% | Luxturna TAM 萎缩 + Editas 平台失败 | -60-85% |

**期望回报**（概率加权）：
= 15%×300% + 25%×80% + 30%×20% + 20%×(-40%) + 10%×(-72%)
= 45% + 20% + 6% + (-8%) + (-7.2%)
= **+55.8%**（18-30 月）

**风险调整后**：考虑到尾部 -85% 极端情形 → 仓位 ≤5% 总组合，30% IRR 期望，sharpe ~0.7-0.9。

**核心结论**：mirror 分析支持"乐观但谨慎篮子持仓"，避免 single-name 集中（Editas 镜像下 -85% 不可接受），M1/M2 成功镜像（ALNY/BBIO）是核心 base case。
