# In vivo CRISPR/Base Editing 罕见病 — 周期定位

## 一、行业周期类型识别

In vivo 基因编辑罕见病行业是 **三重周期叠加**：

1. **临床事件驱动型生物科技周期**（biotech clinical-event cycle，主导）— 周期由"III 期 readout / BLA 受理 / 上市首年销售曲线"三个时点驱动，单只标的 12-18 个月内可现 2-5× 振幅。这是 NTLA / BEAM / VERV 在 2026-2028 年的主周期。
2. **大药企并购整合周期**（BP M&A wave，叠加加速器）— 2024-2026 BP 现金充裕（VRTX/LLY/BMS/SNY/PFE 合计可用现金 >$200B）+ 专利悬崖（2027-2030 多款 mega-blockbuster 到期，含 Eliquis/Keytruda/Stelara/Eylea）→ 罕见病 platform 资产被频繁并购或合作。Lilly-Verve $1.3B 并购（2025-06）、BMS-Orbital $400M license（2025-Q3）、Pfizer/Apellis BEAM-302 opt-in 已落地。
3. **支付端报销 + 监管加速通道周期**（reimbursement & regulatory tailwind）— FDA 2024 启动 Operation Warp Speed for Rare Diseases（2025-09 first cohort 4 个 in vivo 项目入围）+ CMS Cell & Gene Therapy Access Model（2025 启动，覆盖 SCD/β-thal，2026 拟扩展 HAE/AATD）→ first-in-class in vivo 编辑首年支付通道比 ex vivo（Casgevy）快 12-18 个月。

三重周期的关键差异：临床事件周期是个股 alpha 主驱动；M&A 周期是估值上限驱动（被收购溢价 50-100%）；支付/监管周期是 first-year 销售爬坡速度的 beta 驱动（决定 K3-RD 渗透率）。

## 二、历史周期复盘

**周期一：基因疗法 1.0（1999-2003）— 失败镜像**
1999 Jesse Gelsinger 死亡（OTC 缺乏症 AAV 试验）+ 2002 法国 X-SCID 4 例白血病 → 行业冰冻 5 年。**核心教训**：罕见病 + 一次性治疗 + 不可逆基因改造 = 单一 SAE 即可冻结整条赛道。NTLA Phase 1 BTR 项目 2025-11-05 死亡事件 + BEAM-302 2x60mg Grade 4 ALT 是当前周期"小 Gelsinger 风险"。

**周期二：RNAi 1.0（2006-2010）— 半失败镜像**
Sirna Therapeutics 2006 卖给 Merck $1.1B + Alnylam 2007 IPO + Roche/Pfizer/Novartis/Abbott 大举投资 → 2010-2012 集体退出 RNAi（Pfizer/Roche 砍掉整个部门）。**核心教训**：递送平台不成熟时（早期 LNP-IV 给药安全性差）即便靶点对，5-7 年烧钱期也熬不过。Alnylam 2018 才出 Onpattro，2025 才首次 GAAP 盈利 — 整个周期长达 20 年。

**周期三：CAR-T 1.0（2017-2020）— 部分成功镜像**
Kymriah 2017 首批 / Yescarta 2017 / Tecartus 2020 → 上市 5 年内 CAR-T 整个赛道年销 $5B+，但单产品爬坡远慢于市场预期：Kymriah 上市第一年仅 ~$70M，第三年 ~$470M。**核心教训**：复杂治疗（autologous + 住院 + 化疗预处理）首年渗透率低，需 3-5 年才到 peak。Casgevy 64 例/年（2025）正在重演这个曲线。**对 NTLA-2002 / BEAM-302 启示**：LNP-IV 一次性给药无 conditioning，渗透速度应介于 RNAi（快）与 CAR-T（慢）之间。

**周期四：基因疗法 2.0（2017-至今）— 当前周期**
Spark Luxturna 2017 / Zolgensma 2019 / Hemgenix 2022 / Casgevy 2023 / Lyfgenia 2023 / Beqvez 2024 / Elevidys 2023 — 7 个一次性基因疗法上市。**关键观察**：(a) AAV/ex vivo 路径首年销售普遍低于预期（Zolgensma 上市第一年 $361M，Hemgenix 2024 全年仅 ~$86M，Casgevy 2025 全年 $42M），(b) 定价天花板已确认（$2.2-3.5M/患者），(c) 商业化瓶颈是患者 → 输注转化漏斗（VRTX 300/147/64）。In vivo CRISPR/base editing 是 2.0 周期的"第二波"，理论上避开了 ex vivo conditioning 漏斗。

## 三、当前周期定位

**位置：导入期晚期，2026-2027 进入成长期前夜**

判断依据三条：

**1. Phase 3 集中读出（导入期标志事件）**
- NTLA-2002 HAELO Phase 3 阳性 topline 已落地（2026-Q1，-87% / 62% AF / 0 SAE）
- NTLA-2001 ATTR-CM MAGNITUDE clinical hold 已解除（2026-03）
- BEAM-302 60mg pivotal dose locked（2026-Q1），50-pt cohort 启动 2026 H2
- VERV-101 PCSK9 重启（hold lifted 2025-Q4）

**2. 首个 BLA 时点确定（成长期前的临门）**
NTLA rolling BLA 已于 2026-04 启动（HAELO 数据基础），按 12-18 个月 review 窗口，2027 H1-H2 会拿到 first-in-class in vivo CRISPR 罕见病批准 — 这是行业从导入期跨入成长期的标志事件。

**3. 估值层面：导入期典型"信号 → 急涨 / 噪声 → 急跌"双向行情**
NTLA 股价从 2025-12 $11 涨至 2026-05 $25-30（HAELO topline 后单日 +52%），同期 BEAM 从 $20 涨至 $35（60mg 数据后），均属导入期 catalyst 驱动重定价；但 NTLA Phase 1 死亡（2025-11）单日 -28% 也确认了下行尾部。**这种 "高 vol + Catalyst-driven" 是导入期典型 signature**。

**对比：** 若已在成长期（如 2018-2020 的 Alnylam Onpattro 后），股价波动会被"季度销售 KPI" 锚定，单 catalyst 振幅压缩到 ±10-15%。当前 NTLA/BEAM 仍在 ±30-50% 范畴 → 仍处导入期。

| 维度 | RNAi 平台（ALNY 2018-2020）| 基因疗法 2.0（VRTX 2023-2025）| In vivo 编辑（NTLA/BEAM 2026） |
|------|--------|--------|--------|
| 第一个上市产品 | Onpattro 2018-08 | Casgevy 2023-12 | NTLA-2002 预计 2027 |

## 四、未来 12-24 月（2026-Q2 → 2028-Q1）展望

**主线 Catalyst 时间表**：

| 时点 | 事件 | 影响 |
|------|------|------|
| 2026 H2 | BEAM-302 60mg pivotal cohort（50 pt）启动入组 | BEAM 估值再定价（成功 +30-50%）|
| 2026 H2 | NTLA-2002 BLA 受理 + Priority Review 决定 | NTLA 估值再定价（PR 给定 +20-40%）|
| 2026 H2 | NTLA-2001 ATTR Phase 3 入组加速（hold 解除后）| NTLA 估值再定价（次要）|
| 2027 H1 | NTLA-2002 PDUFA 日期 + BLA approval 决定 | first-in-class in vivo CRISPR 批准（±50% 振幅）|
| 2027 H1 | BEAM-302 60mg pivotal data readout | AATD pivotal 决定（±30-50%）|
| 2027 H2 | NTLA-2002 美国上市 + 商业化首季销售 | K3-RD 首年渗透率验证起点 |
| 2027 H2 | BEAM-302 BLA 提交（如 60mg pivotal 阳性）| AATD 首个 in vivo BLA |
| 2028 H1 | NTLA-2002 上市第一年销售 readout | K3-RD 决定性数据 |

**子周期展望**：

- **临床事件子周期（个股 alpha）**：2026 H2-2027 H1 是 catalyst 最密集窗口，NTLA / BEAM 个股波动率会保持 ≥40% annualized；建议持仓在 catalyst 前 1 个月加仓、catalyst 后 1 周内减仓的"事件套利"框架。
- **M&A 子周期（估值上限）**：BMS / Pfizer / Sanofi / Vertex 任何一家未来 18 个月内并购 NTLA 或 BEAM 概率 > 40%（参照 Lilly-Verve $1.3B 类比 + Pfizer/Apellis BEAM-302 opt-in 已落地的近场信号）。被并购情形下溢价 50-100%。
- **支付端子周期（爬坡 beta）**：CMS CGT Access Model 2026-09 拟扩展决定 + IRA 罕见病豁免清单更新（2026-12）+ EU JCA 2027-Q1 联合临床评估首例 in vivo gene editing → 共同决定 NTLA 上市第一年欧美双市场可访问性。

**反向 / 终止信号**（kill criteria，详见 06_risk_blindspots）：
- NTLA-2002 BLA 收到 CRL 或要求额外 trial → 行业整体回到 2025-Q3 估值
- 任何 in vivo CRISPR / base editing 项目出现第二例死亡（不限公司）→ 整个赛道 -30-50%
- KalVista EKTERLY 上市第二年销售 > $400M → K5-RD 信号强反转，oral 抢患者池

## 五、投资含义

**1. 当前位置类比 2017 H2 的 CAR-T**：first-in-class 上市前 1 年 + Phase 3 数据已确认 + 监管路径清晰，但首年商业化曲线仍未验证 → estimate 不应假设 ALNY-AMVUTTRA 速度（$2.31B FY2025），而应介于 Casgevy（慢）与 BBIO Acoramidis（快）之间。base case = $100-300M FY2028 NTLA-2002 美国销售。

**2. 个股 vs 篮子 — 推荐篮子**：catalyst 密集 + 单事件 -50% 尾部存在 → 单押 NTLA 或 BEAM 风险敞口过高。建议构建 **NTLA + BEAM + Verve + Editas** 等权重 4 标的篮子，对冲单标的死亡 / 失败 / 监管事件。

**3. 仓位与时间窗**：导入期高波动 → 仓位 ≤ 总组合 5-8%（biotech 高 beta），时间窗 18-30 个月（覆盖 2027-Q1 BLA 决定 + 2028-Q1 首年销售）；catalyst 密集期建议提前 30-45 天加仓。

**4. 周期切换信号**：当 NTLA-2002 / BEAM-302 中至少一个完成上市首年 + 首年销售 readout（预计 2028-Q1），周期从导入期切换到成长期，估值锚从"催化剂期权 + DCF"转向"季度销售 KPI"。届时单标的 vol 收敛至 ±15-20%，篮子分散收益下降 → 应转向单标的精选。
