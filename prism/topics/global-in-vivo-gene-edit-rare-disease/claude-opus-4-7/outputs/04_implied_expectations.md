## A2. 反推市场隐含预期（reverse DCF）

### NTLA EV $3.0B 隐含什么？

**情形拆解**：
- HAE BLA 2027 H2 上市概率假设 = 75%（HAELO 阳性 + rolling BLA 已启动）
- HAE peak revenue 假设 = $1.0-1.5B（HAE 全球 30k 患者 × 50% peak penetration × $400-500K editing 价 ÷ 5 年）
- ATTR-CM 进入 commercial = $1.0B peak（远期 2030+）
- 总 SOTP risk-adjusted NPV = HAE $1.5-2.0B + ATTR $0.5-1.0B = $2.0-3.0B
- 减 cash burn 至 BLA $0.5-1.0B
- 合理 EV ~ $1.5-2.0B

**当前 EV $3.0B 高于合理 EV $1.5-2.0B → 市场隐含**：
- HAE peak penetration 不止 50% → 接近 60-70%（即 oral 阵营被压制到 30-40%），或
- ATTR-CM 提前兑现到 2029-2030（hold 已解除是支撑）
- M&A 期权溢价 ~20-30%

**Bull case 验证**：若 HAE BLA 拿到 + 2028 首年 $200M+ 美国销售 → fair EV $5-7B（current 上行 60-130%）
**Bear case 验证**：若 BLA 收 CRL → fair EV $1.0-1.5B（current 下行 -50-65%）

### BEAM EV $2.5B 隐含什么？

**情形拆解**：
- AATD BLA 2028-2029 概率 = 50%（60mg pivotal H2 才启动，readout 2027）
- AATD peak revenue 假设 = $0.8-1.2B（AATD 美国 100k × 30-40% peak penetration × $350-450K 价 ÷ 5 年）
- risto-cel SCD/β-thal 2027 BLA = $0.3-0.5B peak（与 Casgevy 竞争）
- BEAM-301 GSDIa = $0.2-0.3B peak
- 总 SOTP = $0.5-1.0B AATD + $0.2-0.3B risto + $0.1-0.2B GSD = $0.8-1.5B
- 加 Pfizer/Apellis BEAM-302 opt-in 期权 ~$0.3-0.5B
- 合理 EV ~$1.5-2.0B

**当前 EV $2.5B 高于合理 EV $1.5-2.0B → 市场隐含**：
- BEAM-302 60mg pivotal 一次成功（不需要 dose adjust 或重启）
- Pfizer / Apellis opt-in 必然行使 = ~$0.5B 升 $1.0B 期权值
- 双 BLA 同步成功（risto + BEAM-302）

### KALV $27 tender vs 内含价值

Chiesi 2026-04-29 出 $27/股 全现金 tender = $1.5B EV，相对 Q1 EKTERLY $39.2M（年化 $160M）= 9-10× revenue → 罕见病 oral 罕见急 launch 后估值定价（vs ALNY 早期 RNAi 平台 ~15-20×）。**说明 oral camp 估值已无大上行**，N3 叙事进入"售出 + 整合"阶段。

### BCRX EV $4.5B + Astria $874M 隐含什么？

ORLADEYO FY2025 $602M + 2026E Q1 $148M（年化 $600M+，5 年成熟期 +37% YoY 罕见 saturation）+ Astria STAR-0215（HAE Phase 3 Q4 2025 enrolment）→ HAE oral 阵营 EV ~7.5× revenue → 隐含**oral camp 5 年内仍能维持 60-70% HAE 池子**，即 in vivo 编辑只吞掉 30-40%。

## A3. 五级观点光谱（5-tier opinion spectrum）

### 极度乐观 ★★★★★（Ultra-Bull）— "in vivo 编辑是罕见病终结者"

**代表人物 / 机构**：
- NTLA 创始人 Jennifer Doudna 公开演讲；BEAM 联合创始人 David Liu MIT 系列演讲
- Cathie Wood ARKG ETF（NTLA / BEAM 重仓）
- 部分 healthcare specialty fund（OrbiMed / Baker Bros / Avoro / Perceptive）

**核心论据**：
- HAELO Phase 3 -87% / 62% AF / 0 SAE 已是 first-in-class 数据级胜利
- BEAM-302 60mg AAT 16.1µM 跨过 functional threshold
- 患者调研 99%/92% 接受度 + 一次性治疗终极便利
- BP 并购浪潮即将启动，Lilly / Pfizer / BMS 皆是潜在买家

**对应估值**：NTLA 12-18 月目标 $50-70（current 2-3×），BEAM $80-100

**关键假设**：BLA approval = 上限 + 首年销售复制 BBIO Acoramidis $362M

### 乐观 ★★★★（Bull）— "首批兑现 + 篮子持仓胜出"

**代表人物 / 机构**：
- Stifel / Cowen / Leerink biotech analyst（多家 Buy with PT $40-50）
- Long-only biotech HF（Casdin Capital / Foresite / RTW）

**核心论据**：
- N1（Cure narrative）已数据级支持，但漏斗（N2）会拖慢首年爬坡
- 篮子持仓（NTLA + BEAM + Verve + Editas 等权）= 单事件 -50% 尾部对冲
- M&A 期权附加 50-100% 溢价（若兑现）

**对应估值**：NTLA $40-50（+50-100% 上行），BEAM $50-65；持仓 5-8% 总组合

**关键假设**：4 标的篮子至少 1 个被并购或 1 个上市首年超预期

### 中性 ★★★（Neutral）— "等数据，导入期不确定性高"

**代表人物 / 机构**：
- 大多数 generalist 基金（Fidelity / T. Rowe / Wellington）
- 部分 sell-side（JPM / Morgan Stanley Hold rating）
- Vanguard 等 passive 仓位（行业 ETF 自动配置 1-2%）

**核心论据**：
- HAELO 数据虽好但 BLA approval 仍有变数（FDA Priority Review 决定 + 长期安全数据）
- Casgevy 漏斗（VRTX FY2025 $42M）反向警示 in vivo 编辑商业化曲线
- KalVista / BCRX 已巩固 HAE oral 阵营，K5-RD 不易破

**对应估值**：NTLA fair value $25-35（持平 / 小幅上行），BEAM $30-40；持仓 1-3%

**关键假设**：等 BLA approval 后再决定加减仓

### 悲观 ★★（Bear）— "Casgevy 漏斗 + KalVista 抢池 = 上限受限"

**代表人物 / 机构**：
- 部分 short-biased fund（Spruce Point / Citron 历史；当前 BLA 临近期专门 short）
- Bear case sell-side（少数 Sell rating）
- Adam Feuerstein STAT 评论（持续质疑 in vivo gene editing 商业化）

**核心论据**：
- Casgevy 64 例 / 年 → in vivo 编辑虽避开 conditioning 但仍有 LNP-IV 安全顾虑 + 不可逆性顾虑 + 报销审批漏斗
- KalVista EKTERLY $39M Q1（年化 $160M+）+ Chiesi $1.6B 收购证明 oral on-demand 是 "good enough"
- BCRX Astria $874M = HAE oral / SC 阵营巩固，in vivo 编辑能吃 30-40% 已是上限

**对应估值**：NTLA fair value $15-22（current -15-40%），BEAM $20-28；建议 short 或避开

**关键假设**：NTLA-2002 上市第一年 < $100M / FY2028 < $200M

### 极度悲观 ★（Ultra-Bear）— "LNP 长期肝毒 + IRA 收紧 = 平台终结"

**代表人物 / 机构**：
- 极少数（无 mainstream sell-side 持此观点）
- 部分 academic 经济学家 / FDA hepatology 顾问

**核心论据**：
- LNP IV 重复给药 5-7 年后会爆肝毒（NTLA Phase 1 死亡 + BEAM 2x60mg Grade 4 ALT 已是早期信号）
- IRA 罕见病豁免 2027-2028 被收紧 → $2M 标价天花板降至 $1M
- 第二例 in vivo CRISPR 死亡（任何公司、任何项目）会冻结整个赛道 5-10 年（参照 1999 Gelsinger）

**对应估值**：NTLA fair value $5-10（current -60-80%），BEAM $10-15；strong avoid

**关键假设**：5 年内出现 1+ in vivo CRISPR 严重 SAE 或 IRA 实质修订

## A5. 当前共识位置（2026-05）

**主流共识**位于"乐观 ★★★★ vs 中性 ★★★"区间，偏向乐观侧：
- 多数 sell-side PT $35-50（vs current $26）
- 篮子配置 NTLA / BEAM 共 ~5% biotech ETF 仓位
- Implied success prob ~50-55%

**最大未定价的尾部**：
1. **下行尾部未充分定价**：第二例 in vivo CRISPR 死亡（极度悲观 ★ 触发条件）— 当前 NTLA EV $3.0B 隐含此尾部仅 5% 概率，但实际 multi-trial cumulative 5-10%
2. **上行尾部未充分定价**：BMS / Pfizer 18 个月内并购 NTLA — 当前隐含期权 ~20-25%，实际可能 30-40%
3. **首年商业化不确定性低估**：NTLA-2002 FY2028 首年销售方差极大（$30-300M 6× 范围），市场仅 priced in $100-150M base case

## A6. 投资含义

**1. 当前估值偏多 ★★★★ 乐观侧**：仍有上行空间但需谨慎；建议**篮子 ★★★★ 配置**而非全 in
**2. 关键 catalyst 验证窗口**：2026 H2-2027 H1 BLA 受理 + Priority Review + PDUFA → 这 12 个月可让观点光谱大幅缩小（中性 → 乐观或悲观）
**3. 最佳风险收益比组合**：核心 NTLA 50% + BEAM 30% + Verve（已私有化通过 LLY 间接）+ Editas 等权 → 单事件 ≤-15% 总组合敞口
**4. 关键反向监控**：KalVista 第二季度销售（$50M+ → 强化 N3）+ 任何 in vivo CRISPR 平台 SAE 事件 + IRA 立法动向 → 触发降仓信号
