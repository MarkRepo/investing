# In vivo CRISPR/Base Editing 罕见病 — Living Feed（追加式日志）

## 2026-05-23 — 研究启动 + v1 thesis 落地

**事件**：本 arena topic 从父级 `global-ai-drug-gene-edit` fork 创建，完成全套 8 输出 v1 综合。

**当前 thesis（v1）**：超配 NTLA + BEAM 罕见病 in vivo 编辑篮子（4-7% 总组合，等权 4 标的）— HAELO Phase 3 阳性 + rolling BLA 锁定 NTLA HAE first-in-class in vivo CRISPR BLA（2027 H1）；BEAM-302 60mg pivotal 启动支撑 AATD 二号兑现。

**关键不确定性（按重要性）**：
1. **首年商业化曲线**（K3-RD）— 现有 base rate 跨度极大：BBIO Acoramidis 上市第一年 $362M，VRTX Casgevy 仅 $42M，Hemgenix 仅 $13M。NTLA-2002 在 IV 给药 + 无 conditioning 的优势下，首年应介于 Acoramidis 与 Casgevy 之间，但具体落点（$50-300M）方差 6×，是当前最大不确定性。
2. **KalVista / BCRX oral 阵营吃池速度**（K5-RD）— EKTERLY Q1 $39.2M（年化 $160M+）+ Chiesi $1.6B 收购 + BCRX Astria $874M 整合 → oral 阵营在 NTLA-2002 上市前已巩固。NTLA-2002 5 年 peak penetration 是 30%（bear）/ 50%（base）/ 70%（bull）的关键判断点。
3. **LNP IV 长期安全**（K4-RD）— ALNY Onpattro 7 年支持但 NTLA Phase 1 1 例死亡（2025-11，已终止项目）+ BEAM-302 2x60mg 1 例 Grade 4 ALT 是早期信号。任何第二例严重事件（不限公司）会触发整赛道冰冻。
4. **BP 并购信号**（M&A 上行期权）— Lilly $1.3B 收购 Verve（2025-06）+ Pfizer/Apellis BEAM-302 opt-in 已落地，但 NTLA / BEAM 是否是 BMS / Sanofi / Novartis 下一收购目标无定论；M&A 期权在估值中已部分定价（约 25-30%）但尾部 +50-100% 仍可能。
