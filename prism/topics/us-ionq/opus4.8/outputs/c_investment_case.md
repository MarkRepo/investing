**护城河判断——真差异化，但护城河正在"变软"**：

**读数**：EV ≈ 0 但分布**明显负偏**（下行两档合计 40% 概率、幅度 −39%~−64%；上行两档 35% 概率、幅度 +30%~+103%）。这个形状说明：
- 对**做多**：现价的期望回报几乎为零，却要承担巨大下行波动——**不被补偿**。
- 对**做空**：EV ≈ −1%，且上行尾部（squeeze/主题脉冲/consensus 翻倍预期）是实打实的爆仓风险——**裸空同样不划算**。

**⚠️ 必须点破 EV≈0 与"我看空"的张力（诚实交代）**：既然我判公允在 $10-15（模型 A/B），为何 EV 还能被拉回 ≈0？因为上行两档（35% 概率）挂靠的是"主题溢价维持"（模型 F 世界观）——**而那正是我自己判为高估的那一端**。这里要说清：**给上行 35% 概率，不是我认同 $69 的世界观，而是承认"主题股可以长期非理性上行"（reflexivity/动能/逼空）这一经验事实**。所以我把 EV 拆成两个读数：
- **主题在场 EV（reflexivity-aware）≈ 0**：把"市场可以继续不理性"计入——这解释了**为什么不裸空**（stance = 回避而非重仓沽空）。
- **基本面锚定 EV（若主题溢价压缩、基本面兑现）**：剔掉两档主题驱动的上行，剩下的分布中枢落在 −25%~−35%——**这才是我方向性看空的真实表达**。**"基本面终会浮现"的世界里，这是明确的负 EV。**

两个读数的差 = 主题溢价的期权价值。**当前价 $34.52 = 市场几乎完全为"主题溢价永不塌 + 商业化如期"付费。我的看空是对"基本面锚定 EV 为负"的确信；我的不裸空是对"主题何时压缩无法择时"的谦卑。**这正是"带敬意的看空、非裸空"的算术底座。

### 我的判断 + 信心度

**判断：回避（Avoid）。信心度：中。**

### 历史失败镜鉴（≥2 · 刻意找失败而非成功）

1. **量子板块自身 2021-2022 回撤**：IONQ 上市后从 $30+ 跌到 ~$3（**−90%**）。失败模式 = 长久期估值杀 + 加息 + NISQ 商业化遥遥无期。当年最早预警 = 加息周期启动 + 无商业兑现。**现在是否已现：部分重演**——股价已从 2025 峰值腰斩，macro 又是鹰派 + 长久期逆风。教训：主题股在流动性收紧时最脆弱、最猛。
2. **3D 打印泡沫（DDD/SSYS, 2013-2015）**：颠覆叙事 + 主题狂热推高 P/S，随后从峰值 **−85%**。失败模式 = 主题资金退潮 + 商业化远慢于叙事 + 毛利恶化。预警 = 增速放缓 + 毛利率下滑 + 内部人减持。**现在是否已现：部分已现**——IonQ 毛利率已从 52% 恶化到 24%、增速靠并购拼装。教训：颠覆叙事不敌单位经济现实。
