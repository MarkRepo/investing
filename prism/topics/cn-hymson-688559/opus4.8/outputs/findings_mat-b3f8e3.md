## 核心数据点与事实

- 2026Q1 营业收入 13.17 亿元，同比 +144.36%（上年同期 5.39 亿）——受制造业复苏+设备更新+新能源扩产，订单交付增加。
- 2026Q1 归母净利润 +2521 万元（上年同期 -1.89 亿），扣非归母净利 +735.6 万元（上年同期 -1.97 亿）——双扭亏但扣非利润极薄。
- 2026Q1 非经常性损益合计 +1785.4 万元：其中委托投资收益 962 万、公允价值变动 477 万、政府补助 454 万——**非经常损益(1785万)是归母净利(2521万)的71%，扣非后仅剩735万，"拐点"利润质量薄**。
- 2026Q1 经营活动现金流净额 +13.04 亿元，同比 +1447.95%（上年同期 8426 万）——公司归因"在手订单增加、合同预付款及发货进度款回款增加"。
- **现金流真相：合同负债从 2025 年末 36.97 亿 → 2026Q1 末 53.17 亿，单季 +16.2 亿**；经营现金流 13 亿主要由预收款(合同负债)堆砌，非利润转化。命门1坐实：现金流与净利背离，靠预收款而非盈利兑现。
- 存货继续膨胀：2025 年末 48.54 亿 → 2026Q1 末 54.51 亿（单季 +6 亿），堰塞湖未消反增。
- 应收账款 2026Q1 末 19.84 亿（2025 年末 18.24 亿），继续小幅上升。
- 研发投入 7073 万元，同比 -39.68%（上年同期 1.17 亿），研发投入占营收比从 21.76% 降至 5.37%——降本聚焦成熟产品，但研发强度大幅下滑值得警惕（固态叙事 vs 研发收缩矛盾）。
- 加权平均 ROE +1.05%（上年同期 -6.02%）。基本 EPS 0.10 元。
- 总资产 150.66 亿，归母所有者权益 24.22 亿；**资产负债率 ≈83.7%（负债 126.09 亿 / 总资产 150.66 亿）**——高杠杆但股东权益为正（校正 API 显示的 145.84% 异常值）。
- 短期借款从 21.21 亿降至 13.28 亿（还款），货币资金 18.65 亿（略降）。
- 毛利率提升：营业成本 10.29 亿 / 营收 13.17 亿 → 毛利率 ≈21.9%（上年同期约 17.6%），公司归因"高毛利项目收入占比提升"。
- 信用减值损失 -2236 万、资产减值损失 -2541 万（Q1 仍在继续计提，合计 -4777 万拖累利润）。
- 股东户数 17,935；前十大股东中实控人系（盛世海康15.78%+盐城海合5.77%+泰安海合2.74%+赵盛宇1.06%）合计约25.35%；员工持股计划持股1.35%；高盛国际2.18%、社保/瑞众人寿等机构在列。

## 叙事主线

因为营收同比+144%叠加高毛利占比提升带动毛利率回升 → 所以 Q1 实现归母/扣非双扭亏、经营现金流暴增1447% → 但对投资意味着：**利润质量薄（扣非735万、非经损益占71%）、现金流靠合同负债+16亿堆砌、存货反增6亿，"经营拐点"证据尚不充分，是低基数+预收款制造的账面改善多于可持续盈利拐点**。

## 反常识/分歧点

- 市场解读：Q1 双扭亏+现金流暴增=经营拐点确立。本文表明：扣非净利仅735万、经营现金流靠合同负债单季+16.2亿撑起，存货不降反增6亿——现金流暴增不等于盈利兑现，拐点真伪需半年报扣非利润走阔+存货/账龄改善验证。
- 研发投入同比-39.68%、研发占比从21.76%骤降至5.37%，与"固态/AI液冷三重引擎"高研发叙事形成张力。
