## 三、产业链 / 竞争格局认知

1. **价值链定位**：泡泡玛特处于"IP 孵化/签约 → 设计开发 → 供应链代工生产 → 全渠道零售"的链条，核心壁垒在 **IP 运营 + 渠道 + 会员数据 + 供应链反应速度**，而非单纯制造。盲盒机制把普通玩具变成高复购、高情绪溢价的收藏品。

2. **IP 是命脉**：潮玩生意本质是"IP 热度的资本化"。单一 IP 生命周期通常有起→爆→稳→衰节奏，公司价值取决于①能否把爆款 Labubu 的热度延长（产品线扩展、内容化、全球轮动）②能否持续孵化/签约下一个爆款形成矩阵。这正是多空最大分歧点。

3. **全球化是当前主线**：2024-2025 海外从"补充"变成"增长引擎"，东南亚→北美→欧洲依次引爆，海外坪效/品牌溢价高于国内。全球化既是估值想象空间，也带来供应链/汇率/本地化/抄袭仿冒/关税（尤其美国）等新风险。

4. **竞争与护城河**：国内潮玩竞争激烈但泡泡玛特凭先发、IP 储备、渠道规模、会员数据领先；海外面对本地潮流玩具与仿冒。护城河强度（IP 可替代性、渠道可复制性）是估值能否支撑的关键。

5. **需求性质**：潮玩属可选消费/情绪消费/收藏投机三重属性叠加。宏观可选消费走弱、或"炒娃"投机退潮，都可能放大波动——区分"真实使用/收藏需求"与"投机性囤货需求"对判断可持续性至关重要。
