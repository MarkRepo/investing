# Primer — 商业航天上游精密零部件（门外人入门）

> 目标读者：完全门外人。读完应能：①说清这块生意怎么赚钱 ②区分主要玩家赛道 ③听懂路线之争。决策性判断（押谁/估值）归 case，不在本文。

## 1. 这块生意是什么、怎么赚钱

商业航天上游精密零部件，指火箭制造链上"精度高、工艺壁垒厚、单件价值量大或随发射频次放量"的材料与组件层。赚钱逻辑有两类：

- **耗材型**：热防护材料、推力室内壁、推进剂等——每发火箭都消耗/需更换，**随发射频次线性放量**；火箭复用成熟后甚至因"使用次数更多"而耗材需求上升。这是本 arena 看好的属性。
- **整箭型**：发动机本体锻件、箭体结构锻件、贮箱——单发用量大，但**一旦一子级实现复用，单发需求被摊薄（反噬）**。这是本 arena 规避的属性。

核心赌注：在"复用 vs 不复用"的分化下，押耗材型 + 独家技术壁垒。

## 2. 价值链卡位

```
原材料(铜/铬/铌/钛) → 合金材料商(斯瑞) ┐
                  → 3D打印粉末/丝材(铂力特) ├→ 组件/锻件 → 整机厂(蓝箭/星际荣耀/九州云箭) → 发射
                  → 超材料结构(光启)        ┘
```
关键卡位：**材料—成形—构件全工艺链**打通者壁垒最高（斯瑞 Cu-Cr-Nb 从铸锭到组件）。整机厂（蓝箭航天）冲刺科创板 IPO 是上游估值催化。

## 3. 关键材料/技术路线（"是什么"——中立讲）

### 推力室内壁材料四代演进
1. 不锈钢 → 2. 锆铜合金(Amzirc) → 3. 银锆铜合金(NARloy-Z) → 4. **铜铬铌合金(Cu-Cr-Nb, NASA GRCop-84)**

- 铜铬铌（Cu-8Cr-4Nb）由 NASA Glenn 研发，Cr2Nb 相在 >1600℃ 仍稳定，软化温度 750-3000℃，是再生冷却推力室内壁顶档材料。
- **重要事实（K2）**：GRCop-84 的主流制造路线**就是增材制造（SLM 选区激光熔化，即 3D 打印）**——NASA 自 2014 起 MSFC 用 SLM 制造 GRCop，成本省 >60%、交期降 3 倍。所以"3D 打印 vs 锻造"不是简单的替代关系：铜铬铌的先进制造本身就是 3D 打印。斯瑞走锻造/成形路线，铂力特走 3D 打印路线——两者可能对应不同代际/不同客户。

### 金属 3D 打印（增材制造）
- 技术：PBF-LB/M（选区激光熔化）、WAAM（电弧增材，可成形 10m 大构件）。
- 适用：涡轮泵、管路件、薄壁/蜂窝/异形孔减重结构件、一体结构件。铂力特为朱雀三号核心供应商。

### 超材料（光启）
- 电磁功能/热防护结构材料，国内唯一产业化。**但光启自称暂无商业航天业务**（在手订单 34.85 亿全为军品）——这是认知修正点，不是商航上游标的。

## 5. 赛道周期位 / 客户结构

- **2025 是中国商业航天放量元年**：全年发射 50 次（占全国 54%）、入轨卫星 311 颗（占 84%）；产业规模 2.83 万亿（+21.7%）。
- **2026 复用元年**：10 余款新火箭瞄准可复用路线；朱雀三号已验证二子级入轨（一子级回收待成熟）。
- 客户结构：民营整机厂（蓝箭/星际荣耀/九州云箭/深蓝航天）+ 国企（星网/千帆 G60 星座组网拉动）。耗材型需求随星座组网的高频发射放量。
- 政策：十五五规划纳入战略性新兴集群；国家航天局三年行动计划（2025-2027）。

## 6. 主要争议（中立陈述）

1. **"全球仅 2 家量产 Cu-Cr-Nb"是否成立**：斯瑞独家性叙事的实证来源不一；GRCop 路线 NASA 体系内有多个 vendor，国内是否真只有斯瑞一家待证。
2. **复用成熟后耗材价值量是否被摊薄**：乐观方认为耗材+备件双收入，悲观方担心单发耗材需求下降。
3. **估值透支**：商航耗材业务利润体量仍小（斯瑞推力室相关推测 <1 亿 vs 整体 15.72 亿），估值靠远期渗透定价。
