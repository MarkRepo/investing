### 历史失败镜鉴（≥2）
1. **Invitae（遗传检测 rollup → 2024 破产）** [mat-1b712c][mat-c41324]：失败模式=**并购堆量 + 持续烧钱 + 股权/债务再融资依赖 → 资不抵债**（负债 $1-10B vs 资产 $500M-1B），Labcorp $239M 拍走资产。峰谷损失约 **-99%**。当年最早预警信号=经营 FCF 持续为负 + AR 增速超营收 + 靠融资续命。**"现在是否已现"**：TEM 部分已现（FCF 三年负、AR +101% > 营收 +83% [mat-b837e8]、融资依赖），但 TEM 增长质量与资产负债表**显著强于**晚期 Invitae（有 $820M 流动性、25% 有机增长）——镜鉴是"稀释/烧钱型 rollup 的终局风险"，非"即将破产"。教训：**并购堆量掩盖的弱有机 + 稀释，终会在融资窗口关闭时反噬。**
2. **23andMe（基因数据故事股 → 2025 破产）**〔训练知识估算，非本研究 findings〕：失败模式=**"数据授权/AI 平台"叙事无法规模化变现**，药企数据收入停滞 + 消费诊断商品化，从 SPAC ~$6B 市值归零。峰谷约 **-98%**。预警信号=数据收入客户集中/增速停滞、平台叙事迟迟不落地成高毛利经常性收入。**"现在是否已现"**：TEM 的 Data 增长绑关联方 Pathos（集中度风险）+ 真 AI 产品仅 1.6%——**正是同一类风险的早期形态**。教训：**"数据飞轮"若不能兑现为独立第三方的高毛利经常性收入，终究是被高估的诊断公司。**

> 只找成功案例是 red flag——两个镜鉴都指向 TEM 命门（稀释/rollup 终局 + 数据故事变现失败），故意选来对冲确认偏误。

## 环⑥ 在什么价、什么仓位、什么时点，做什么？（行动）

### ① 买入框（锚在环② SOTP，不凭空）
- **不建仓区（现价）**：$40-50。含摊薄 SOTP base ~$34、成交前 $39、市场 $47 之间，无安全垫，EV 略负。

- **减持/了结区**：$65-70（接近 consensus/成交前 SOTP bull，需 Bull 假设已兑现才追）。

### ② 仓位框架（接环④ 的 EV）
- **position_tier = 试探（probe）**。理由：EV ≈ -5%（负）、信心中、黑箱项多（Data 有机拆不出、Spruce 未决）——**不具备"标准/重仓"资格**。

- **满仓上限**：即便 thesis 上修（A+C 转绿），因治理折价（双层股权+关联方）+ 稀释结构，**封顶"标准档"，不给"重仓"**——治理黑箱是永久性折价。
- **加仓阶梯**：仅在"命门逐个证真"时分档加（每证真一条环③假设加一档），不在下跌中盲目摊平（避免 Invitae 式价值陷阱）。

### ③ 时间维度
- **持有期**：不建长持（管理层信任梁不足，见环①）；若介入，定位**事件驱动/估值修复**（1-2 年，绑 FCF 转正 + Data 证真 catalyst），而非 3-5 年复利托付。
- **下一 catalyst**：下季财报（剔 Pathos 有机 Data + FCF）、Personalis 交割。
- **"到 X 未发生 Y 怎么办"**：到 2027 中若 FCF 仍未转正且 Data 有机未证 → 判定 Base/Bear 主导，永久回避。

### ④ 什么会让我改主意
- **转多信号**（上修 thesis）：连续 2 季剔 Pathos 有机 Data ≥25% + 季度 FCF 转正 + 无 SEC 动作 → EV 转正，从"回避"升"试探/标准建仓"。
