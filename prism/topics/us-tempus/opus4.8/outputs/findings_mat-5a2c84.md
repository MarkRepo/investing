# Finding — Tempus AI Q2'26 10-Q · Item 3 市场风险

## §A 核心数据点

1. **现金/等价物/受限现金 = $604.3M**（截至2026-06-30），主要为现金存款与货币基金——与 Item 1 资产负债表勾稽一致。
2. **利率风险受控**：持有固定利率债务（零息2032/0.75%2030可转债+Google本票），降低利率敞口；主要敞口是利息收入。**利率±100bp 对财务状况/经营成果无重大影响。**
3. **外汇风险极小**：绝大部分营收在美国产生，外币营收微不足道；**外汇±10% 无重大影响**；未做任何外汇对冲。随国际化（含日本 SB Tempus JV）扩张，未来敞口或上升。
4. **通胀风险**：原材料/间接成本上涨可能压缩毛利，但迄今无重大影响；高通胀情形下或损及毛利率与费用率。

## §B 叙事主线
标准样板式市场风险披露，信息量低。核心结论：Tempus 的市场风险敞口（利率、外汇、通胀）当前均不重大——因债务为固定利率、营收基本美元计价。**真正的风险不在此章**：本季 GAAP 盈利完全由有价证券（Recursion/Personalis）按市值计价浮盈驱动，而**股票价格风险/权益证券波动并未在 Item 3 作为量化敏感性披露**——这是本章的实质性遗漏（见 §C）。

## §C 反常识 / 与共识分歧
- **最大的"市场风险"被漏在市场风险章之外**：$216.4M 有价证券的市值波动在 Q2 贡献 $98.5M 浮盈、直接决定 GAAP 盈亏，但 Item 3 未对权益证券价格风险做敏感性分析。投资者若只看本章会低估 Tempus 损益表对第三方股价（Recursion/Personalis）的高度敏感性。
- 固定利率债务"降低利率风险"的另一面是：$1.36B 可转债的真实风险是**股权转换稀释**（$69.26 转股价），属股本而非利率/市场风险，本章不覆盖。

## §D 未回答 / 需外部追踪
