### 内部逻辑（费雪 + 曲线四形态）

费雪拆美国长端：10Y(4.38%) ≈ 实际(2.16%) + 通胀预期(约 2.2%)。**本轮长端下行的三分归因**：① **增长降温分量**——GDPNow 从 3.3 回落到 2.5%，实际利率随之从 2.2 微降到 2.16%；② **通胀预期分量**——油价塌 17%、5y5y 回落，盈亏平衡走低；③ **期限溢价/供给分量**——Kim-Wright 代理从 0.80 回落到 0.68%，非预期补偿收缩。三者叠加 = 长端牛平。
>
> **本轮利率体制的核心张力 = 官方/市场转鹰 vs 长端牛平**。短端（政策 + FedWatch）在说"通胀没搞定、可能加息"，长端（10Y、期限溢价）在说"增长/油价在降温、终将降息"。这是政策与市场对"限制性够不够 + 通胀会不会顺利回落"的对赌，也是**政策错配风险**的来源：若 Fed 因短端通胀信号维持/加码鹰派、而增长继续降温，牛平可能演变为"政策过度紧缩 → 硬着陆"的牛陡。曲线**低斜率正向续平**（2s10s +30bp）。中国侧清晰"低位偏松"，与美国背离。

### 关键输入指标

**美国金融条件 NFCI：约 −0.516（宽松区、较 v2 略更松）**（FRED NFCI）
- `这是什么`：芝加哥联储综合利率/信用/波动的金融条件总指标，负值=宽松。
- `为什么看它`：一个数概括整体金融条件松还是紧。
- `现在说明什么`：**−0.52 处宽松区**（v2 −0.51 → 略更松）—— 尽管政策利率高、点阵图转鹰，市场层面融资环境仍偏松（利差窄、波动更低、股市高）。**政策端鹰、条件端松**的背离持续，典型晚周期 risk-on。

**美国资金面 SOFR−IORB：约 −3bp（无压，较 v2 −5bp 略收敛）/ RRP 约 269 亿（从近零小幅回补）/ 准备金 2.95 万亿**（FRED 派生 / RRPONTSYD / WRESBAL）
- `这是什么`：SOFR−IORB＝担保隔夜利率减准备金利率，走阔=准备金稀缺咬合信号（spec §5#4 binding driver）；RRP＝过剩流动性蓄水池。
- `为什么看它`：RRP 耗尽后，SOFR−IORB 才是资金面真正咬合处。
- `现在说明什么`：SOFR−IORB **约 −3bp**（仍为负、无稀缺压力，但从 −5 向 0 微收敛，值得留意），**RRP 从近零小幅回补到 269 亿**（缓冲垫略有回血，非单边耗尽），准备金约 **2.95 万亿**（较 v2 3.01 万亿降）。当前**资金面无压但临界**，SOFR−IORB 向 0 靠拢是第一预警表。

**美国净流动性（资产 − TGA − RRP）：约 5.82 万亿（降权使用，较 v2 微降）**（FRED 派生 WALCL−TGA−RRP）
- `这是什么`：金融系统里真正能去买资产的钱。
- `为什么看它`：风险资产水位总开关——RRP 耗尽后边际有效性下降（spec §5#4 已降权）。
- `现在说明什么`：WALCL 约 6.74 万亿、TGA 约 9187 亿、RRP 约 269 亿 → 净流动性约 5.82 万亿（较 v2 5.84 微降）。量上中性、不再是顺风。**此项已按 §5 降权**，资金面真信号看 SOFR−IORB。

**美国信用利差（IG/HY OAS）：IG 0.76% / HY 2.80%，仍在历史地板**（FRED BAMLC0A0CM / BAMLH0A0HYM2）
- `这是什么`：公司债比国债多要的补偿，市场恐惧温度计（spec §5#3：单一 B、同步非领先）。
- `为什么看它`：流动性体制的"质量"维度——利差极窄=风险偏好极高。
- `现在说明什么`：**IG 76bp、HY 280bp**，本轮微升但仍远低于 10 年均值（HY 约 380bp），信用市场**几乎不为违约要补偿**。上版此边（判 expected down_or_flat）实际微升是小 miss——利差已在地板，向下空间几乎没有、向上（走阔）是主要风险方向。HY OAS 报警带（>4.5% 警示 / >5.5% 触发），当前 2.80% 距警戒远，但缓冲极薄是脆弱度的核心。

**中国社融/M1M2/信贷：社融增速历史低位、信贷脉冲转负（−1.85）、M1-M2 剪刀差负但收窄、社零转弱**（2026-04~05）

### 内部逻辑（三层传导 + 四象限）

美国：金融条件偏松 + 信用利差地板 → "风险偏好高、缓冲薄"的脆弱顺风后期（不是"收紧"，而是"宽松但临界"，且波动进一步被压平 → 反转跳升幅度更大）。中国：央行→银行这层水很足，但银行→实体这层更堵（信贷脉冲转负、社零走弱）→ 典型**宽货币 × 紧信用**、"推绳子"风险加深（primer 争议 5：资产负债表衰退苗头）。

### 输出形态

- **美国**：流动性体制＝**金融条件偏松、资金面无压但临界（RRP 小幅回补、SOFR−IORB 向 0 微收敛）、风险偏好亢奋但脆弱**（信用利差地板 + 波动进一步压缩＝缓冲更薄）。

## ③ 汇率体制

**输出形态（先给结论）**：**人民币企稳但边际偏弱（USDCNY 从 6.766 微贬到 6.798、CNH 约 6.797、年内仍偏升区间）、外资流向观测硬度仍低**——尽管中美 10Y 利差深度倒挂（约 −265bp，因美长端下行较 v2 −278bp 略收窄）。利差对人民币解释力仍为**压力表**（spec §5#1），真驱动是中间价/逆周期因子 + 资本管制 + 贸易顺差。本轮张力加大：广义美元（DTWEXBGS）从 120.1 **升到 120.9（更强）**、日元 carry（USDJPY **161.67 越带**）。结论：汇率端**当下对中国资产中性偏友好但边际转弱**，强美元 + 深度负利差 + carry 越带是结构性悬顶；**"外资回流"实证因北向净流入停发而硬度持续偏低**。

> **口径提示（延续 v2）**：本表"DXY"= Fed AFE 美元指数代理（DTWEXAFEGS，约 114.2），与 ICE/WSJ DXY 不同基不可比；判断中国 FX 一律用广义美元 DTWEXBGS（约 120.9，spec §5#7）。

### 关键输入指标

**USDCNY / USDCNH：在岸约 6.798 / 离岸约 6.797、价差极小（~39pip）**（as_of 2026-06-11~30）
- `这是什么`：1 美元换多少人民币，数字大=人民币贬；CNH-CNY 价差=离岸贬值压力表。
- `为什么看它`：汇率体制的"结果"读数；离在岸价差小=无明显贬值预期。
- `现在说明什么`：从 6.766 微贬到约 **6.798**（本轮小幅走弱、仍在年内偏升区间），价差极小（~39pip、无恐慌性贬值预期）——人民币在主要 EM 货币里仍偏稳，但**升值动能本轮转为微贬**，与广义美元走强对应。中间价约 6.807、中间价偏离约 +135pip（逆周期因子代理仍在维稳侧）。

**广义美元（Fed DTWEXBGS）：从 120.1 升到 120.9（偏强区、本轮走强）**（FRED）
- `这是什么`：贸易加权广义美元，真正作用于中国/EM 的美元强弱（替代 DXY 做中国 FX，spec §5#7）。
- `为什么看它`：广义美元强 → 全球美元回流、EM 失血。
- `现在说明什么`：**从 120.1 升到 120.9**（偏强区、本轮再上一小台阶）——是人民币企稳的**外部逆风增强**。人民币能守住，靠中间价维稳 + 顺差 + 去美元化再配置对冲，而非外部顺风；广义美元继续上台阶是汇率体制反转的首要外部触发。

**中美 10Y 利差：约 −265bp（压力表，非驱动；较 v2 −278bp 略收窄）**（FRED 派生，中债 1.73 − 美债 4.38）
- `这是什么`：中国 10Y − 美国 10Y，套利资金指南针。
- `为什么看它`：理论上深负利差 → 资金外流压人民币；但本 regime 下链路断裂/反向（spec §5#1），**只当压力表读**。
- `现在说明什么`：约 −265bp（因美长端牛平下行而略收窄），仍深度倒挂；人民币照稳（微贬）——印证套利链失灵，由中间价/管制/顺差托住。

**北向资金 / 外资流向：净流入方向仍停发，仅余成交活跃度（北向成交额本轮放量，as_of 2026-06-11）**
- `这是什么`：原为外资"脚投票"（净买入方向）；但**北向日频/累计净买入自约 2026-04-08 停止披露**，现仅余**成交额（活跃度，非方向）**。
- `为什么看它`：成交额是外资参与 A 股换手强度代理；方向性流向须改靠结售汇差额 / 外储 / 海外主动基金判。
- `现在说明什么`：成交活跃度本轮放量（未塌）、南向港股通转正、结售汇/涉外收付顺差延续 → 侧面支持"外资未大规模撤离"，但**方向性"脚投票"仍失明**，"外资偏回流"硬度持续偏低——本汇率体制读数的持续数据盲区。

**日元 carry（USDJPY）：约 161.67（越带、更拥挤、尾部触发）**（as_of 2026-06 live）
- `这是什么`：借便宜日元买高息资产的套息交易拥挤度代理。
- `为什么看它`：carry 渠道传感器——拥挤越极端，去杠杆平仓的非线性冲击越大（spec §5#6 阈值尾部）。
- `现在说明什么`：USDJPY **161.67 突破 v2 的 160 阈值（本轮 breached）**——日元 carry 更拉伸（历史干预区上沿）。常态非驱动，但一旦 BoJ 转紧或风险骤升触发拥挤平仓，会经强制平仓资金流冲击全球风险资产——本轮**脆弱度 high**的越带来源。

### 内部逻辑（利差→汇率→资本流动套利链，及其失灵）

经典链：负利差 → 抛人民币买美元 → 人民币贬 + 外资流出。**2026 这条链仍被三股力量对冲**：①中间价/逆周期因子 + 资本管制；②贸易顺差与结售汇改善；③全球去美元化/再配置。本轮变化：广义美元走强 + 人民币微贬 = 对冲仍在但被外部逆风侵蚀了一点边际，出现"深度负利差 + 更强广义美元 + 人民币微贬 + carry 越带"的组合。**利差仍为压力表，真驱动在政策与流量端；但外部逆风（强美元/carry）本轮增强，脆平衡的天平略往承压侧移。**（北向净流入口径停发，"外资回流"硬度持续偏低。）

### 输出形态

汇率体制＝**人民币企稳但边际偏弱、外资流向观测硬度低、当下对中国资产中性偏友好但转弱**；**强广义美元（120.9）+ 深度负利差 + 日元 carry（161.7）越带是结构性悬顶**——一旦广义美元再上台阶、政策容忍度松动或 carry 平仓，可能快速反转为"人民币承压 + 外资流出"。
