- `现在说明什么`：10Y 续处低位（资产荒需求延续）、DR007 微降（资金面更松），与美国 4.69% 形成约 **−296bp** 温差（较 v3 −265bp **走阔 31bp，全部来自美长端上行**）。央行定调"适度宽松、结构性工具为主"。**中美利率背离本轮再拉大**。

### 内部逻辑（费雪 + 曲线四形态）

费雪拆美国长端（**先把两套分解拆干净、勿重复计**）：名义 10Y **+31bp** = 实际利率 **+27bp** + 盈亏平衡通胀预期 **约 +4bp**（5y5y 仅 +2bp）→ **本轮长端上行 ~87% 是实际利率故事、仅 ~13% 是通胀预期**，通胀预期基本锚定。期限溢价（ACM 代理 **+9bp**）**不是第三个加总项、而是嵌在上述名义/实际移动里的一块**——它告诉我们实际利率的上行有相当比例来自"非预期补偿"（财政/QRA 供给面），而非纯增长强。故**本轮准确的定性是"实际利率主导的熊陡"，而非"通胀预期驱动的再通胀"**（盈亏平衡几乎没动，油价反弹尚未传导到通胀预期端）。
>
> **本轮利率体制的核心已从"背离张力"转为"同向再上"**，v3 的"短端鹰 vs 长端牛平"对赌由长端"投降"收场。新的核心问题是**这 +27bp 实际利率上行的成因归属——这是一条对持仓含义方向相反的岔口**：
> - **① 需求真强（增长再加速）**：初请骤降 187k、油价反弹 → 若实际利率上行主要是需求强，则**利好顺周期/银行/周期成长、利空长久期估值，但组合可承受**（分子跟得上分母）。
> - **③ 供给/期限溢价失锚（财政面）**：ACM +9bp、QRA 发行压力 → 若主要是供给推升，则是**"股债双杀"系统性尾部**（所有资产贴现率同步抬、分子不补偿）。
> - **当前证据略偏①**（实际利率 + 劳动力 + 盈亏平衡未脱锚，非增长恐慌），但期限溢价 +9bp 使③不可忽视，二者尚未分清——**这是 v4 首要命门（见 decomposition），下期看核心 PCE surprise / QRA 票券构成 / 实际利率是否续升破 2.5% / ISM 能否止跌来裁**。曲线**低斜率正向走陡**（2s10s +34bp）。中国侧清晰"低位偏松"，与美国背离进一步拉大。

### 输出形态

- **美国**：利率体制＝**高位 + 官方/市场/长端同向再上、再通胀式熊陡**。久期重新不友好（实际利率 2.43% 周期新高，推翻 v3 边际转松），核心不确定性从"预期差方向"转为"熊陡成因（需求 vs 供给）"。
- **中国**：利率体制＝**低位偏松、方向中性偏下**，托底国内顺周期与红利资产；中美背离本轮再拉大。

## ② 流动性体制

**输出形态（先给结论）**：美国——**金融条件仍偏松**（NFCI 约 −0.55 处宽松区、净流动性 5.92 万亿续升 +1008 亿），**但缓冲已被抽干**：RRP 从 269 亿抽干到 **近零（13.8 亿）**、SOFR−IORB 从 −3bp 向 0 咬合（**binding driver 亮黄灯**，spec §5#4）；信用利差 IG 微升到 0.80、HY 仍地板 2.79。"有钱、还敢冒险，但减震器没了"——这是本轮流动性体制的核心变化。中国——**宽货币但紧信用**：央行水足（DR007 更低），但信贷需求仍弱（**信贷脉冲仍负 −1.85**、社融增速续降 7.4、M1 续降 8.0），钱传不到实体；社零环比转正是边际暖意。

### 关键输入指标

**美国金融条件 NFCI：约 −0.552（宽松区、较 v3 更松）**（FRED NFCI）
- `这是什么`：芝加哥联储综合利率/信用/波动的金融条件总指标，负值=宽松。
- `为什么看它`：一个数概括整体金融条件松还是紧。
- `现在说明什么`：**−0.55 处宽松区**（v3 −0.52 → 更松）—— 尽管政策利率高、长端上行，市场层面融资环境仍偏松（利差窄、股市高）。**政策端鹰 + 长端上行 vs 金融条件端松**的背离持续，典型晚周期 risk-on，但下方（利率/波动轴）的地基已在松动。

**美国资金面 SOFR−IORB：约 −1bp（向 0 咬合）/ RRP 约 13.8 亿（近零抽干）/ 准备金 3.06 万亿**（FRED 派生 / RRPONTSYD / WRESBAL）
- `这是什么`：SOFR−IORB＝担保隔夜利率减准备金利率，走阔=准备金稀缺咬合信号（spec §5#4 binding driver）；RRP＝过剩流动性蓄水池。
- `为什么看它`：RRP 耗尽后，SOFR−IORB 才是资金面真正咬合处。
- `现在说明什么`：**RRP 从 269 亿抽干到 13.8 亿**（过剩流动性蓄水池几乎见底、缓冲垫消失），SOFR−IORB 从 −3bp 收敛到 **约 −1bp**（向 0 靠拢，稀缺咬合的第一信号亮起）。准备金 3.06 万亿（较 v3 2.95 万亿升）。**这是 v4 流动性体制最重要的变化：宽松还在，但吸收冲击的 RRP 减震器没了，SOFR−IORB 向 0 咬合意味着下一次资金面扰动会更直接地传到回购利率/风险资产。** 资金面真信号盯 SOFR−IORB 是否转正。

**美国净流动性（资产 − TGA − RRP）：约 5.92 万亿（续升 +1008 亿，降权使用）**（FRED 派生 WALCL−TGA−RRP）
- `这是什么`：金融系统里真正能去买资产的钱。
- `为什么看它`：风险资产水位总开关——RRP 耗尽后边际有效性下降（spec §5#4 已降权）。
- `现在说明什么`：WALCL 约 6.75 万亿、TGA 约 8296 亿（较 v3 降 890 亿，财政放钱）、RRP 约 14 亿 → 净流动性约 5.92 万亿（较 v3 5.82 升 1008 亿，**TGA 下降释放为主力**）。量上仍是顺风，**但增量来自 RRP/TGA 抽水而非扩表**——这类顺风"一次性"、且以缓冲耗尽为代价。**此项已按 §5 降权**，资金面真信号看 SOFR−IORB。

**美国信用利差（IG/HY OAS）：IG 0.80% / HY 2.79%，IG 微升离开地板**（FRED BAMLC0A0CM / BAMLH0A0HYM2）
- `这是什么`：公司债比国债多要的补偿，市场恐惧温度计（spec §5#3：单一 B、同步非领先）。
- `为什么看它`：流动性体制的"质量"维度——利差极窄=风险偏好极高。
- `现在说明什么`：**IG 80bp（+4bp、率先离开地板）、HY 279bp（仍地板）**。IG 微升是本轮信用侧率先松动的一环（与利率/波动轴的兑现相呼应），HY 仍几乎不为违约要补偿。HY OAS 报警带（>4.5% 警示 / >5.5% 触发），当前 2.79% 距警戒远，但**缓冲极薄 + IG 起步走阔**是脆弱度进入兑现期的信用侧印证。

**中国社融/M1M2/信贷：社融增速续降(7.4)、M1 续降(8.0)、信贷脉冲仍负(−1.85)、社零环比转正(+1.0)**（2026-05~06）
- `这是什么`：社融＝实体拿到多少钱总闸；信贷脉冲＝信贷加速度；剪刀差＝钱的活性。
- `为什么看它`：中国信用松紧的总量与传导读数。
- `现在说明什么`：社融增速从 7.7 降到 **7.4**、M1 从 8.6 降到 **8.0**（总量端边际转弱）、信贷脉冲仍 **−1.85**（信贷加速度持续为负）→ **紧信用延续**；但社零环比从 −0.6 转正到 **+1.0**（需求端边际暖意，是本轮中国侧唯一改善）。官方 PMI 50.3（弱企稳）、CPI +1.0%、PPI +4.1%（降幅收窄）。**宽货币 × 紧信用格局未变，需求端出现第一缕暖意但未成趋势。**

### 内部逻辑（三层传导 + 四象限）

美国：金融条件偏松 + 信用利差近地板，但**RRP 缓冲抽干 + SOFR−IORB 咬合 + IG 起步走阔 + MOVE 解压** → 从 v3 的"宽松但临界"进入"宽松但减震器失效、且下方地基松动"的更脆阶段（不是"收紧"，而是"宽松的质量在恶化"）。中国：央行→银行这层水更足（DR007 更低），但银行→实体这层仍堵（信贷脉冲负、社融/M1 续降）→ 典型**宽货币 × 紧信用**、"推绳子"风险延续，社零转正是唯一边际暖意（primer 争议 5：资产负债表衰退苗头）。

### 输出形态

- **美国**：流动性体制＝**金融条件偏松、净流动性续升，但缓冲抽干（RRP 近零）、资金面咬合（SOFR−IORB 向 0）、信用侧起步松动（IG 走阔、MOVE 解压）**——"没有减震器的宽松"。
- **中国**：流动性体制＝**宽货币 × 紧信用（信贷脉冲续负）**，社零转正是边际暖意；对顺周期成长仍是"政策友好但传导不畅"。

## ③ 汇率体制

**输出形态（先给结论）**：**人民币企稳偏强（USDCNY 从 6.798 走强到 6.772、中间价 6.793 更强、逆周期因子更用力=中间价偏离越带）、外资流向观测硬度仍低**——尽管中美 10Y 利差本轮走阔到约 **−296bp**（因美长端上行）。**这再次印证利差对人民币是压力表而非驱动（spec §5#1）**：利差走阔、人民币反走强，真驱动是中间价/逆周期因子 + 资本管制 + 贸易顺差 + 略微走弱的广义美元（120.7）。结论：汇率端**当下对中国资产中性偏友好、且本轮由 v3 的"边际转弱"回摆到"企稳偏强"**（v3 判贬被证伪）；但**北向成交塌（42.9 万→27.7 万）、南向港股通转负、日元 carry 越带（163.7）**是外资参与度收缩 + 结构性悬顶的隐忧。

> **口径提示（延续 v3）**：本表"DXY"= Fed AFE 美元指数代理（DTWEXAFEGS，约 114.1），与 ICE/WSJ DXY 不同基不可比；判断中国 FX 一律用广义美元 DTWEXBGS（约 120.7，spec §5#7）。

### 关键输入指标

**USDCNY / USDCNH：在岸约 6.772 / 离岸约 6.769、价差极小（~4pip）**（as_of 2026-07-25~28）
- `这是什么`：1 美元换多少人民币，数字大=人民币贬；CNH-CNY 价差=离岸贬值压力表。
- `为什么看它`：汇率体制的"结果"读数；离在岸价差小=无明显贬值预期。
- `现在说明什么`：从 6.798 走强到约 **6.772**（本轮小幅升值、重回年内偏升区间），离在岸价差极小（~4pip，无贬值预期）——**v3"微贬"方向本轮逆转为"企稳偏强"**。中间价约 **6.793（更强）**、中间价偏离越带（逆周期因子代理本轮 breached，央行按更强方向引导）。

**广义美元（Fed DTWEXBGS）：从 120.9 微降到 120.7（偏强区、本轮微弱）**（FRED）
- `这是什么`：贸易加权广义美元，真正作用于中国/EM 的美元强弱（替代 DXY 做中国 FX，spec §5#7）。
- `为什么看它`：广义美元强 → 全球美元回流、EM 失血。
- `现在说明什么`：**从 120.9 微降到 120.7**（仍在偏强区、但本轮小幅回落）——是人民币企稳偏强的**外部逆风略减**。人民币走强 = 广义美元微弱 + 中间价维稳 + 顺差 + 去美元化再配置共同作用；广义美元是否重新上台阶仍是汇率体制反转的首要外部触发。

**中美 10Y 利差：约 −296bp（压力表，非驱动；较 v3 −265bp 走阔 31bp）**（FRED 派生，中债 1.73 − 美债 4.69）
- `这是什么`：中国 10Y − 美国 10Y，套利资金指南针。
- `为什么看它`：理论上深负利差 → 资金外流压人民币；但本 regime 下链路断裂/反向（spec §5#1），**只当压力表读**。
- `现在说明什么`：走阔到约 −296bp（全部来自美长端上行）、深度倒挂加剧；人民币照样走强——**本轮是对"利差→汇率"链失灵最强的一次印证**（利差走阔 31bp，人民币不贬反升）。由中间价/管制/顺差托住。

**北向资金 / 外资流向：净流入方向仍停发，成交活跃度本轮明显回落（成交额 42.9 万→27.7 万），南向港股通转负**（as_of 2026-07）
- `这是什么`：原为外资"脚投票"（净买入方向）；但**北向日频/累计净买入自约 2026-04-08 停止披露**，现仅余**成交额（活跃度，非方向）**。
- `为什么看它`：成交额是外资参与 A 股换手强度代理；方向性流向须改靠结售汇差额 / 外储 / 海外主动基金判。
- `现在说明什么`：北向成交活跃度本轮**明显回落**（42.9 万→27.7 万，参与度收缩）、**南向港股通转负**（+59→−20.6）→ 外资/南向参与度双双走弱。外储 3.48 万亿小升（+49 亿）、人民币企稳偏强侧面支持"未大规模撤离"，但**方向性"脚投票"仍失明 + 成交活跃度回落**，"外资偏回流"硬度持续偏低——本汇率体制读数的持续数据盲区，且本轮参与度信号转弱。

**日元 carry（USDJPY）：约 163.71（再越带、更拥挤、尾部触发）**（as_of 2026-07 live）
- `这是什么`：借便宜日元买高息资产的套息交易拥挤度代理。
- `为什么看它`：carry 渠道传感器——拥挤越极端，去杠杆平仓的非线性冲击越大（spec §5#6 阈值尾部）。
- `现在说明什么`：USDJPY **从 161.67 升到 163.71（再越带、更拉伸）**——日元 carry 进一步拉伸（历史干预区上沿）。常态非驱动，但一旦 BoJ 转紧或风险骤升触发拥挤平仓，会经强制平仓资金流冲击全球风险资产——本轮**脆弱度 high**的越带来源之一，且比 v3 更绷。

### 内部逻辑（利差→汇率→资本流动套利链，及其失灵）

经典链：负利差 → 抛人民币买美元 → 人民币贬 + 外资流出。**2026 这条链仍被三股力量对冲**：①中间价/逆周期因子 + 资本管制；②贸易顺差与结售汇改善；③全球去美元化/再配置。本轮变化：**利差走阔 31bp（到 −296bp）而人民币反走强**——套利链失灵在本轮最为鲜明。广义美元微弱 + 中间价更强 + 逆周期因子越带（更用力维稳）共同把人民币托到偏强。**利差仍为压力表；真驱动在政策与流量端，本轮政策端明显发力（中间价/逆周期因子）。**但北向成交塌 + 南向转负提示外资参与度在收缩（方向仍失明）。

### 输出形态

汇率体制＝**人民币企稳偏强、外资流向观测硬度低、当下对中国资产中性偏友好（v3 微贬被证伪、本轮回摆偏强）**；**深度负利差（−296bp）+ 日元 carry（163.7）越带 + 北向/南向参与度收缩是结构性悬顶**——一旦广义美元重新上台阶、政策容忍度松动或 carry 平仓，仍可能快速反转为"人民币承压 + 外资流出"。
