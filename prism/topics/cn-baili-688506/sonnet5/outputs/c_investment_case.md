## 环④：我信哪边，凭什么（下注+期望收益加总）

### 核心分歧——锚回环②隐含数

**市场隐含**（terminal PS=25x情形）：未来5年营收CAGR ≈ **28.8%**，且市场愿意持续给予25倍以上PS溢价。
**我的判断**（base case）：未来5年营收CAGR更审慎估计约**18%**（对应模型A Base情形，terminal PS也应向荣昌历史常态18x回归而非维持25x+）。
**delta**：**-10.8个百分点**（我 vs 市场隐含，CAGR维度），且我认为terminal PS本身也应更低（18x vs 隐含的25x+）——**两条杠杆（CAGR假设+terminal PS假设）我都比市场隐含更保守**，这是双重保守而非单一维度的分歧。⚠️ 这不是"市场太乐观/我太悲观"的空泛表态——delta的证据基础是：BMS里程碑触发质量目前仍全部是开发型（环③假设2的低中支持度）、iza-bren首个适应症患者池窄（primer §2.2已讲透）、荣昌生物这一最直接可比案例走完完整周期后的常态区间恰恰是18x而非25x+[mat-863746]。

### 观点光谱

〔概率/相对当前价(335.5元)涨跌幅〕
1. **极端牛（概率10%，+46.6%）**：三阴乳腺癌+食管鳞癌均快速获批放量+BMS后续里程碑加速触发（含注册/销售分成型）+H股顺利重启融资 → 对应模型A Bull情形492元。
2. **温和牛（概率20%，-16.0%）**：至少1个新适应症2027年内获批放量、BMS里程碑维持开发型节奏但未加速 → 对应模型F Bull情形282元。
3. **Base（概率30%，-53.5%）**：鼻咽癌窄适应症放量缓慢、新适应症获批但爬坡慢，PS向18-25x区间回落 → 对应模型A Base情形156元。
4. **温和熊（概率25%，-54.7%）**：放量显著不及预期+BMS里程碑停滞+H股持续搁置 → 对应模型F Bear情形152元。
5. **极端熊（概率15%，-83.9%）**：BMS客户关系生变/关键里程碑失败+资金链压力显性化(需新一轮股权融资稀释) → 对应模型A Bear情形54元。

### 期望收益加总

E[return] = 10%×46.6% + 20%×(-16.0%) + 30%×(-53.5%) + 25%×(-54.7%) + 15%×(-83.9%)
= 4.66% - 3.20% - 16.05% - 13.68% - 12.59% = **-40.9%**

**EV显著为负**——这是本篇最重要的量化结论：即使给予10%的极端牛情形概率，加总后的期望收益仍明确为负，主因是Base/温和熊/极端熊三档合计占概率70%且跌幅均在50%以上，而牛市情形的涨幅空间不足以对冲。

### 我的判断+信心度

**判断**：不追高、当前价不建新仓；已持仓者应考虑逢高部分兑现而非加仓。**信心度：中**——逻辑链条完整（三梁看懂、定价锚现采、分歧锚回具体假设、EV量化），但K1(commercialization实际数据)几乎为零、卖方一致目标价336-386元与本判断存在系统性分歧，需保持对"我可能低估管线厚度上修速度"的谦逊——尤其T-Bren8项III期同步推进、三阴乳腺癌PFS/OS双阳性这类证据比v0撰写时显著更充分，若这些资产在未来2-3个季度密集兑现正面读出，牛市情形概率可能需要上修。

## 环⑤：如果错了会怎样、怎么第一时间知道（证伪机制）

### 已知风险
1. **BMS客户集中度84.79%**[mat-697099]——若BMS战略调整/管理层变动/被并购，收入冲击是系统性的，不只是"某笔里程碑延迟"。
2. **一年内到期非流动负债暴增238.74%（8.65亿元）+经营现金流转负（-7.98亿元）**[mat-697099]——"借新钱补经营性失血"模式下，若放量/里程碑不能在1-2年窗口内接棒，将同时面临到期债务+再融资挤压。
3. **传统业务持续萎缩**（化药制剂/中成药双降）——现金压舱石正在失血，边际支撑力下降。
4. **股权高度集中（72.22%）**——H股/定增等重大资本运作决策高度取决于单一实控人判断，中小股东话语权有限。

### 盲点风险
1. **是否存在未披露的EGFR×HER3双抗ADC后期竞品**——训练知识+findings均未发现直接竞品，但这只是"目前没搜到"而非"确定不存在"，需持续监控海外临床数据库。
2. **医保准入谈判降价幅度**——创新药进医保通常大幅降价（历史案例常见50%+），iza-bren具体降价幅度数据缺失，可能显著压低"获批"到"实际放量收入"的转化率，这是当前估值反推里未被充分讨论的一层风险。

### Kill 触发条件（具体、可观测）
- **kill-1**：2026H2起，iza-bren剔除BD/里程碑款后的商业化销售收入，连续2个季度环比负增长或增速<10%（反映放量显著不及预期）。
- **kill-2**：BMS另一笔最高2.5亿美元近期里程碑，在2027年底前仍未触发（反映里程碑节奏实质性停滞）。
- **kill-3**：一年内到期负债出现展期困难，或公司需通过新一轮股权融资（股本稀释>10%）紧急补血（反映资金链时钟真正绷断）。
- **kill-4**：BMS公开宣布终止或大幅调整合作条款（参照科伦博泰-默沙东终止案例的更极端版本）。

### 历史失败镜鉴（≥2个）

1. **荣昌生物RC48获批+BD密集期PS冲高后腰斩式回归**[mat-863746]：2023年PS峰值51.4/均值38.99，2024-2025回落至18附近（约50-55%腰斩）。**失败模式**：估值透支放量预期。**当年最早预警信号**：获批后实际放量斜率慢于市场隐含预期、BD兑现节奏不及峰值定价假设。**教训**：PS均值回归是biotech常态，不是例外。**现在是否已现**：百利天恒当前PS(54.38x)已超荣昌历史峰值(51.4x)，若重复该模式，理论下探空间比荣昌案例本身更大——这是本篇模型A/F给出Base/Bear情形跌幅50%+的直接历史依据。
2. **荣昌生物-Vor Biopharma泰它西普授权，首付款过低+交易对手困境，单日暴跌16.65%-25%**[mat-73c26d]：**失败模式**：BD交易headline金额与实际兑现/交易对手信用质量脱节引发信心崩塌。**当年最早预警信号**：首付款金额远低于同类交易/交易对手财务状况恶化。**教训**：总额数字很大不代表确定性很高。**现在是否已现**：百利天恒交易对手BMS信用质量显著优于Vor Bio，此失败模式**当前未现**，但提示一旦出现"BMS态度生变"的市场传闻，历史上反应可能是断崖式而非渐进式（kill-4正是为此设置）。
3. **科伦博泰-默沙东2023年终止2款临床前ADC项目，单日跌6.9-7.2%**[mat-863746]：**失败模式**：总额百亿美元级BD中个别子项目中止是常见现象，冲击相对温和但确实存在。**教训**：不必对单一里程碑延迟过度反应，但也不能假设"总额大=每笔都会兑现"——这是对kill-2设置阈值（"另一笔里程碑未触发"而非"任一里程碑延迟"）的依据。

**只想得到成功案例本身就是red flag——本篇三个镜鉴均为负面/中性案例，无正面镜鉴混入稀释警示信号。**
