# thesis_v0 — 百利天恒（继承自父 arena cn-adc）

## 一、核心 thesis（含强度评分）

**百利天恒是中国 ADC 平台差异化壁垒最硬的实证样本——iza-bren(BL-B01D1)已成全球首个且唯一获批上市的 EGFR×HER3 双抗 ADC、一个 linker-payload 平台派生 6+ 成药 ADC、BMS 84 亿美元交易背书。看多其平台可复用性与双抗代差（命门 2 最强正面样本）；但千亿市值（PS 42x）几乎全部踩在一次性 BD 与 iza-bren 放量预期上，2025 剔 BD 后重回亏损，估值不给安全边际。强度 5/10。**

（父 arena 6/10；平台壁垒/双抗代差实证最硬 +1，但 PS 42x 透支 + 剔 BD 后亏损 + 单一资产依赖 -2 → 5/10）

## 二、支持理由
1. 平台可复用性最强实证：同一连接子+毒素平台派生 BL-M05/08/09/11/14D1 等 6+ 成药 ADC，平台呈代际迭代 [mat-ea14bb]。
2. iza-bren 已 de-risk：鼻咽癌已获批、食管癌全球首个 PFS/OS 双阳、TNBC 双终点阳性 [mat-ea14bb][mat-ed47a3][mat-4273c9]。
3. MNC 背书：BMS 84 亿美元交易（8 亿美元首付已落袋），第三方价值认证。
4. 双抗 ADC（EGFR×HER3）是靶点+结构双重代差，区别于单抗 ADC 红海。

## 三、反方观点（最有力）
1. **估值透支（最大风险）**：千亿市值 vs 2026Q1 营收仅 9459 万/亏 7.75 亿，PS 42x，纯期权定价对临床/BD 节奏极脆弱 [mat-5ce1dd]。
2. **剔 BD 后重回亏损**：2025 净利 -10.5 亿、研发占营收 99.75%、剔 BD 产品收入仅 3.8 亿——盈利兑现高度依赖 iza-bren 放量 [mat-ea14bb]。
3. **单一核心资产依赖**：估值集中押 iza-bren，BMS 剩余 7.35 亿美元里程碑确认节奏不明。
4. 现金虽厚（73 亿）但靠定增+借款堆砌，自身造血为负。

## 四、Killer Question
- **K1**：iza-bren 食管癌/三阴乳腺癌 NDA 获批及海外全球扩张能否如期兑现？*(继承父 K1，收窄)*
- **K2**：iza-bren 鼻咽癌获批后真实销售放量曲线，剔 BD 后产品收入能否在 2-3 年接力一次性 BD？*(继承父 K2，收窄)*
- **K3（核心）**：平台可复用性的天花板有多高——BL-M 系列 6+ 资产能否成药兑现，验证"一平台多资产"是真壁垒？*(继承父 K3/命门2)*
- **K4（核心新增）**：千亿市值 PS 42x 在何种 iza-bren 放量/BMS 里程碑假设下才合理，回调到什么估值分位才有安全边际？*(新增·公司估值锚+介入纪律)*
- **K5**：BMS 剩余 7.35 亿美元里程碑确认时点对 2026-27 利润波动的影响？*(新增·公司专属催化)*
