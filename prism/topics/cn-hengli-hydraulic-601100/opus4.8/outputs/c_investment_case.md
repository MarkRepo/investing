## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

### 已知风险 + 盲点风险

- **已知风险**：① **期权回吐**——748-831 亿溢价若因 Optimus 延期/PRS 路线更替/份额不及而缩水（v2 首要下行）；② 主业周期反转（挖机内销回落 + 出口受阻）叠加海外新厂持续亏损，压制 WMBT-1。
- **盲点风险**：① **良率黑箱（K2）**——恒立丝杠实际良率/精度等级公开无硬数据 [mat-1b0ced]，可能比预期好（上行盲点）也可能踩坑；② FX 波动双向——2026Q1 既有汇兑损失也有外汇掉期收益，人民币剧烈波动会持续扰动报表利润的"成色"判断 [mat-13a734, mat-4eee9a]；③ 我可能仍低估 Optimus 2026Q3 放量 + 国产替代加速对期权重定价的催化（做空/踏空风险）。

### Kill 触发条件（可观测）

1. **转空（主业证伪）**：2026 半年报 + 三季报**扣非归母连续两季负增长且 EBIT 增速同步转弱** → WMBT-1 证伪（v2 加"EBIT 同步转弱"条件，避免再被单季 FX 噪音误触）。
2. **转积极（bull kill）**：出现**特斯拉/国内头部整机的 PRS 批量定点公告** → WMBT-3 兑现，重估期权。
3. **转积极（估值 kill）**：股价回落至 **前瞻 PE ≤ 35x（约 91 元，2026E EPS 2.60 口径）或 TTM PE ≤35x（约 72 元）** → 期权费大幅出清，安全边际出现。
4. **降级**：汪立平事件**升级至上市公司层面**（资金占用/资产牵连）→ 命门 C 复活为下行核心。

### 历史失败镜鉴（v2 补成功镜鉴、平衡确认偏误）

**失败样本（第二曲线未兑现即回吐）**：
1. **拓普集团机器人执行器**：2025 营收仅 1359 万（占比 0.05%），机器人执行器毛利率一年 **-22.65pct**（成本 +47.92%）[mat-6d898e]。失败模式=**放量早期毛利崩塌**；教训：机器人毛利趋势向下，K5"毛利>25%"乐观假设有实证反例。
2. **双林股份反向 PRS**：2025-06 交付首批样品，至年报仍**未获正式定点**，却已建 10 万套量产线 [mat-6d898e]。失败模式=**产能先行、定点滞后**；送样到定点的鸿沟极长，作恒立 K1 的时间标尺。

**成功样本（第二曲线兑现、早期高估值被追上 · v2 新增，训练知识镜鉴）**：
3. **三花智控（汽车热管理→机器人执行器）**：家电/制冷龙头切入新能源车热管理成功兑现第二曲线，机器人执行器再造想象，市场早期给的高估值后被业绩追上（训练知识，非本研究实证）。启示：**有真主业现金流 + 制造 know-how 迁移逻辑的龙头，第二曲线兑现概率高于纯蹭概念**——恒立与此类更近（区别于拓普/双林纯玩家）。
4. **汇川技术（工控→新能源车电驱）**：工控龙头以平台化能力切入电驱，第二曲线兑现（训练知识）。启示：平台型制造龙头的多元化更易成——但也提示**兑现需要数年、且早期估值波动剧烈**。

> 注：拓普/双林为实证 [mat-6d898e]；三花/汇川为训练知识镜鉴（非单一实证），已标注。**两组镜鉴对恒立是双向的**：主业质地 + know-how 迁移逻辑近成功样本，但 PRS 定点/良率未证则近失败样本的早期阶段——胜负手在 K1/K2 兑现。

## 环⑥ 在什么价、什么仓位、什么时点，做什么（行动）

### 买入框（锚在②的反推，非拍脑袋 · v2 双口径）

以 2025 EPS 2.04 元（TTM）与 2026E consensus EPS 2.60 双口径（现价 106.79）：

| 区间 | TTM PE | 前瞻 PE(2026E) | 价格 | 动作 |
|------|--------|---------------|------|------|
| 强力买入 | ≤35x | ≤28x | **≤72 元** | 期权费基本出清，安全边际足 |
| 可建仓 | 35-42x | 28-33x | 72-87 元 | 主业估值 + 折价期权 |
| 观望 | 42-52x | 33-42x | 87-110 元 | 期权溢价偏高但主业腿已实 |
| **above_hold** | >52x | >42x | **>110 元** | 机器人溢价充分/过度，不追 |

**现价 106.79 处观望区（前瞻 PE 41x）**——v2 较 v1 把上沿从 107 抬到 110（因主业腿被 consensus + EBIT 坐实，base 中枢从 80 上移到 97）。

### 仓位框架

- **position_tier：试探**。理由：主业腿已被证据支撑（较 v1 改善），但**核心上行仍押未证期权**（K2 良率黑箱、K1 定点未兑现）+ 现价估值充分 + EV 仅约 +2% + 信心中——信息在期权侧仍不足，只配试探档。
- **initial_max_pct：null**（给不出有依据的精确首仓 %，只留档位；若参考，试探档 ≤2-3%）。
- **full_max_pct：5%**（主题集中度上限）。
- **加仓阶梯**：现价可小额试探性底仓（区别于 v1 的"不追"）；主加仓仍等进入可建仓区——87 元 / 78 元 / 72 元三档。

### 时间维度

- **持有期**：中性持有 / 小额试探为主，不设长持承诺——先看期权侧（K1 定点）是否出现实证。
- **下一催化时点**：2026-08 半年报（看 EBIT 是否延续高增、新厂是否减亏）+ 2026Q3 Optimus 投产（期权重定价催化）。
- **"到 X 未发生 Y 怎么办"**：若到 2026 三季报 PRS 仍无整机 Tier1 定点 → 期权兑现证据链未启动，即便主业稳健也不为期权在 41x 前瞻付费加仓。

### 什么会让我改主意

- **转多（加仓）**：① PE 回落至前瞻 ≤33x（约 87 元）；② 特斯拉/头部整机 PRS 定点公告；③ 半年报 EBIT 延续 +30%、新厂减亏、扣非转正。
- **转空（减仓/回避）**：① 扣非连续两季负增长**且 EBIT 增速同步转弱**；② 汪立平事件升级至公司层；③ 挖机周期反转 + 出口熄火 + 新厂持续亏。

### 研究成熟度自评

**中。** 主业财务/估值锚扎实且 v2 新增 25 家 consensus 与 Q1 EBIT 归因（年报+季报+实时行情+券商一致预期一手）；短板在 **K2 良率（data-missing）** 与 **K1 定点（未兑现、公开信息天花板）**——这两条是期权侧黑箱，靠公开料补不齐，需产业链一手调研（已挂 drilldown）。
