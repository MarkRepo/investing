## 核心数据点与事实

### Merck-INT 合作条款（K6 命门的一手原文）
1. **[10-K Note 5] 时间线与已收现金**：2016-06 签 PCV 协作与许可协议（2018 修订），**Merck 首付 $2.00 亿**；2022-09 Merck 行使 intismeran（含 mRNA-4157）选择权，2022-10 支付**行权费 $2.50 亿**。行权前按 ASC 606、行权后（Merck Participation Term）按 **ASC 808** 核算。
2. **[10-K Note 5] 经济分配原文**："**costs and any profits or losses generally shared equally on a worldwide basis, subject to certain exceptions**"；开发阶段 **Moderna 主责工艺开发与 intismeran 物料生产，Merck 主导临床试验**。→ 确证为**全球 50/50 利润分成**，非 Moderna 记 50% 销售额。（"certain exceptions" 10-K 未展开，属残余未知）
3. **[10-K Note 5] Moderna 承担的 INT 净费用（扣 Merck 报销后）：2025 $4.07 亿 / 2024 $3.90 亿 / 2023 $1.84 亿**；同期资本支出净回收 $0.24 / $1.09 / $1.02 亿。→ **INT 对 Moderna 的现金投入稳定在约 $4 亿/年**，是"低成本高杠杆期权"的量化证据。

### 其他合作：权益已被前置分走的部分
4. **[10-K Note 5] Blackstone 流感融资**：承诺最高 **$7.50 亿**；**已确认 R&D 费用抵减 2025 $3.40 亿 + 2024 $2.67 亿（合计 $6.07 亿）**，2025 年末剩余融资负债 $0.43 亿 → **额度已用掉约 8 成，2026-2027 起该抵减基本消失**。代价：获批后**低个位数 royalty + 最高 $7.50 亿销售里程碑**（基于流感与组合疫苗净销售）。
5. **[10-K Note 5] Immatics（2023-09/10）**：Moderna 付**首付 $1.20 亿**并直接费用化；Immatics 另有研究资助、里程碑、阶梯 royalty，**且对最先进的 TCER 拥有"进入全球盈亏分享"的选择权**。
6. **[10-K Note 5] Vertex（CF）**：Vertex 承担开发与商业化及其成本，Moderna 独家生产 mRNA（ASC 606）。→ 罕见病/CF 线的经济学同样是"Moderna 出产能、别人出钱"。

### 存货减值史 = 需求预测能力的硬证据（historical-mirror）
7. **[10-K Note 7] 存货减值：2023 $22 亿、2024 $4.95 亿、2025 $2.91 亿 —— 三年累计约 $30 亿**；firm purchase commitment 损失另计 2023 $1.41 亿 / 2024 $0.60 亿 / 2025 $0.24 亿。其中 2023Q3 一次性原材料减值 $9.03 亿。
8. **[10-K Note 7] 2025 年末存货仅 $1.53 亿（+非流动 $1.14 亿），在手存货 $2.67 亿**；**Spikevax 保质期 9-12 个月、mNEXSPIKE 12 个月、mRESVIA 18 个月** → 季节性市场 + 短保质期 = **结构性减值机器**，这是"呼吸道分部地板"必须扣的常态成本项。

### 税务资产（多头方向的一条真实资产）
9. **[10-K Note 14] 2025 年末结转亏损：联邦 NOL $41 亿（永久不过期）、州 $33 亿（其中 $16 亿不过期、$17 亿自 2032 起到期）、境外 $0.89 亿**；另有联邦 R&D 税收抵免 $1.11 亿 + 州 $2.08 亿（多数自 2030 起到期）。**全额估值备抵**。
10. 含义：**若 INT 成功，前约 $41 亿的联邦应税利润可被 NOL 屏蔽** → 现金税率接近零，DCF/rNPV 里 Moderna 分成的**税后价值高于按 21% 简单折算**。这条须写进环④多头论据（此前未校准）。

### 承诺与法律（与 10-Q 交叉验证）
11. **[10-K Note 12] 不可撤销采购承诺：原材料/生产 $4.11 亿（付至 2029）+ R&D 及其他 $10 亿（付至 2032）**；另有可撤销未结订单约 **$18 亿**。
12. **[10-K Note 12] Arbutus/Genevant 美国案原定 2026-03-09 开庭** → 实际 **2026-03-03 以 $9.50 亿一次性和解**（开庭前 6 天）。这坐实了"临门和解"性质，非主动清障。
13. **[10-K Note 12] 特许权费与商业里程碑（计入 COGS）：2025 $0.88 亿 / 2024 $1.55 亿 / 2023 $3.01 亿**；Cellscript/mRNA RiboTherapeutics 与 NIAID（COVID 刺突 2022-12、RSV 2025-01 付 $0.10 亿）均为**低个位数 royalty + 最低年费 + 里程碑**。
14. **[10-K Note 12] 同一 IP 诉讼阵列在 2025 年末已成形**（GSK 2 美 + 2 UPC + 2 西班牙、Northwestern、Bayer/Monsanto、mNG Bio、BioNTech；Moderna 反诉 Pfizer/BioNTech）+ **mRNA-1345（RSV）陈述引发的股东集体诉讼与派生诉讼**。

### 股本与分部口径
15. **[10-K Note 15] 加权平均股本：2025 389 百万 / 2024 384 / 2023 382**；反摊薄工具 2025 合计 **38 百万**（期权 27 + RSU/PSU 11），2024 34、2023 31 → **摊薄悬顶在持续扩大**（与 10-Q 的 42 百万一致）。
16. **[10-K Note 16] 单一报告分部**（CEO 按合并口径管理）。收入地理：2025 美国 $11.99 亿 / 欧洲 $0.53 亿 / 其他 $6.92 亿。**固定资产 $21.34 亿：美国 $14.68 + 欧洲 $3.03 + 其他 $3.63 亿** → 海外产能（英/澳/加）已占 32%，对应的是与各国政府的长期协议义务。

## 叙事主线

因为**INT 的一手条款是"全球 50/50 成本与利润分成"（ASC 808）且 Moderna 年净投入仅约 $4 亿**，而**存货减值三年 $30 亿、royalty 与合作方（Blackstone/Immatics/Cellscript/NIAID）在多条产品线上前置抽成、$18 亿可撤销订单与 $14 亿不可撤销承诺构成刚性成本地板** → 所以公司的真实结构是"**一个极高杠杆的肿瘤期权 + 一个持续毁灭价值的呼吸道制造平台**" → 对投资意味着估值必须**分部相加而非整体倍数**：INT 按 50% 利润分成 + $41 亿 NOL 免税做 rNPV，呼吸道按"边际毛利 - 常态减值 - 闲置产能 - royalty"的地板情形（很可能接近零或负），两者不可混算。

## 反常识/分歧点

1. **市场把"Moderna 与 Merck 五五分"理解为收入五五分；原文表明是"成本与利润/亏损"五五分** → 卖方峰值销售数字落到 Moderna 的实得经济须打大折（口径校正，非观点分歧）。
2. **市场把"$41 亿 NOL"当作僵尸资产；实际上它使 INT 成功情形下的分成近乎免税** → 这是**看空方向必须诚实承认的估值加项**。
3. **市场共识"Arbutus 和解是清理历史包袱"；10-K 表明和解发生在开庭前 6 天，且 GSK/Northwestern/CureVac/Sanofi/BioNTech 的 LNP 与 mRNA 专利诉讼全数仍在** → LNP IP 风险**未**因和解而解除，只是传染病组合线被买了个"无未来 royalty"。
4. **"降本增效"叙事 vs 三年 $30 亿存货减值 + 短保质期 + 季节性市场**：减值不是一次性重组，而是**商业模式内生的经常性成本**。
