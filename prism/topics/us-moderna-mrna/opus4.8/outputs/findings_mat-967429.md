## 核心数据点与事实

1. **[BioNTech 6-K（SEC 一手），2021-10-01] BNT122 结直肠癌 P2 首例患者给药**：试验在**美国、德国、西班牙、比利时**启动，计划入组**约 200 例**，**对照组为"术后观察等待（watchful waiting）"**。
2. **[同上] 患者筛选机制（对 INT 有直接借鉴意义）**：在**手术切除后或辅助化疗前**做筛查以识别潜在候选者；在德国由分子登记库 **Colopredict Plus 2.0（AIO-KRK-0413）**支持筛查（德国癌症协会内科肿瘤学工作组 + 波鸿鲁尔大学）。→ 该试验以 **ctDNA/分子残留病灶阳性**为富集策略（结直肠辅助场景的标准做法）。
3. **[同上] 设计含义（关键）**：**对照组是"观察等待"而非活性药** → 这是"辅助治疗 + MRD 富集"场景下**最容易出统计学差异的设计**；相较之下 INTerpath-001 的对照组是 **KEYTRUDA 单药（活性对照）**，属**更难的比较**。
4. **推论**：INTerpath-001 在**活性对照**（pembrolizumab，本身已是黑色素瘤辅助治疗标准）之上做出 RFS+DMFS 双终点显著，**统计学难度高于 BNT122 结直肠的观察等待对照** → INT 的这次成功在**方法论上比同类竞品的设计更硬**，这是须计入多头一侧的实质加分。

## 叙事主线

因为**BNT122 结直肠 P2 用的是"观察等待"对照 + ctDNA 富集（较易出差异），而 INTerpath-001 用的是 KEYTRUDA 活性对照（较难）** → 所以 INT 的 P3 成功在方法论质量上高于同类竞品的在研设计 → 对投资意味着我在环④必须承认：**"活性对照上的增量获益"这一事实，使 INT 在黑色素瘤辅助这一适应症的价值实现概率非常高**（接近获批确定性）；看空的落点只能在**定价/分成/可及人群/跨瘤种**，不能在"疗效是否真实"。

## 反常识/分歧点

- **对照组设计的差异被市场完全忽略**：媒体把 BNT122 与 INT 并列为"同类竞品"，但一个是活性对照、一个是观察等待，**统计学门槛差一个量级**。
- **同时须注意反向含义**：若 BNT122 用更容易的设计**仍未在结直肠成功**（截至本轮材料无阳性读出），则冷肿瘤的困难程度被进一步坐实。
