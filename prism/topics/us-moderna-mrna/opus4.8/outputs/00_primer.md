## §2 第一块地基：mRNA 是什么，为什么它是"可编程的药"

### 2.1 从中心法则说起

你身体里每个细胞都在做同一件事：把 DNA（存在细胞核里的"总蓝图"）里的一段指令，**转录**成一份可携带的拷贝，叫 **mRNA（信使核糖核酸，messenger RNA）**；这份拷贝跑到细胞质里的"工厂"（核糖体），被**翻译**成蛋白质。蛋白质是干活的分子——你的肌肉、酶、抗体，全是蛋白质。

这条链条是：**DNA →（转录）→ mRNA →（翻译）→ 蛋白质**。

传统药物（小分子药、抗体药）是**直接给你成品蛋白或化学分子**。mRNA 药物的思路完全不同：**它不给你成品，而是给你一段"指令"（mRNA），让你自己的细胞照着这段指令去生产它需要的蛋白质。**

打个比方：传统药是"给你一条鱼"，mRNA 是"给你一张写着怎么钓鱼的纸条，你自己的细胞照着纸条去钓"。

### 2.2 为什么这是"可编程"的

关键洞察在这里：**决定生产什么蛋白的，只是 mRNA 上那串碱基序列（A/U/G/C 的排列）。** 换一段序列，细胞就生产另一种蛋白，而**生产的机器（细胞本身）、递送的方式、制造的工艺几乎不用变**。

这就是为什么 Moderna 反复把自己描述成一个"**平台**"而不是一个"药"。它的 10-K 原话是：mRNA 有"**软件式的特征**"[mat-df9859]——就像同一台电脑能跑不同的软件，同一套 mRNA 技术只要换"代码"（序列），就能做不同的药：

- 序列编码**新冠病毒的刺突蛋白** → 你的细胞造出刺突蛋白 → 免疫系统认识它、以后见到真病毒能反应 → 这就是 **COVID 疫苗**；
- 序列编码**流感病毒的抗原** → **流感疫苗**；
- 序列编码**你自己肿瘤上的突变蛋白** → 免疫系统去攻击带这些突变的癌细胞 → 这就是 **个体化癌症疫苗**（本研究的核心，§3 详述）；
- 序列编码**一个你天生缺失的酶** → 治疗遗传病（罕见病管线）。

同一个平台，换代码就换适应症——这是 mRNA 叙事的全部魅力，也是"平台估值"的根据。

### 2.3 mRNA 药物的三个固有弱点：递送、稳定性、反应原性

光有序列不够，裸露的 mRNA 进到体内会被迅速降解，也进不了细胞。所以需要一层"包装",这就是 **LNP（脂质纳米颗粒，lipid nanoparticle）**——一个由几种脂质分子组成的微小油泡，把 mRNA 包在里面，保护它、帮它钻进细胞。

LNP 是 mRNA 药物的**卡脖子技术之一**，也是一堆专利诉讼的战场（后面 §7 会讲到 Moderna 为 LNP 专利付了 $9.5 亿和解[mat-f2d0a8]）。你只需要记住：**mRNA 序列决定"造什么"，LNP 决定"能不能送到"，两者缺一不可。**

固有弱点也要记住三个：**① 反应原性**（LNP+mRNA 会激起免疫反应，所以打完疫苗常有发烧乏力）；**② 冷链**（mRNA 不稳定，早期 Spikevax 要 -20°C 保存，物流成本高）；**③ 免疫持久性有限**（这也是为什么 COVID 疫苗要反复打）。这些弱点解释了后面很多商业现象。

## §3 第二块地基：个体化癌症疫苗——Moderna 的核心期权

现在进入本研究**最重要**的科学概念。Moderna $618 亿市值里的大部分，赌的就是这一个东西：**intismeran autogene**（旧代号 mRNA-4157，Merck 那边叫 V940），中文可叫"个体化新抗原疗法"，行话缩写 **INT**（Individualized Neoantigen Therapy）。

### 3.1 先厘清一个致命的认知误区：这不是"预防癌症的疫苗"

很多散户一听"癌症疫苗"，以为是像打 HPV 疫苗那样**预防**你将来得癌症。**完全不是。**

INT 是**治疗性**的，而且用在一个非常具体的场景：**"辅助治疗"（adjuvant）**——病人已经确诊癌症、已经**手术切除了肿瘤**，但医生知道**体内可能还残留着肉眼看不见的微小癌细胞**（叫"微小残留病灶"，MRD），这些残留物是将来**复发**的种子。INT 的目标是：在手术后，训练病人自己的免疫系统去**清剿这些残留癌细胞，防止复发**。

所以三种"疫苗"的区别，你必须分清：

| 类型 | 用在谁身上 | 目标 | 例子 |
|---|---|---|---|
| **预防性疫苗** | 健康人 | 防止将来感染/得病 | HPV 疫苗、COVID 疫苗 |
| **治疗性癌症疫苗（辅助）** | 已手术切除肿瘤的病人 | 清剿残留、防复发 | **INT（本研究核心）** |
| **治疗性癌症疫苗（晚期）** | 已有可见转移灶的病人 | 缩小/控制现有肿瘤 | Provenge（§4 镜鉴） |

记住：**INT 卖的是"术后防复发"**，它的可及人群 = "每年新发的、可手术切除的、高危复发的某种癌症患者数"，而不是"所有癌症患者"。这个区分直接决定了它值多少钱（§6 会算）。

### 3.2 "个体化"是什么意思：一人一药

普通药是"标准化"的——同一种药片,卖给一百万个病人都一样。INT 的颠覆性（也是它的商业噩梦）在于：**每一个病人的药都不一样，是现造的。**

为什么？因为它靠的是"**新抗原**"（neoantigen）。癌细胞之所以是癌细胞，是因为基因发生了突变；这些突变会让癌细胞表面出现一些**正常细胞没有的、突变造出来的蛋白碎片**——这就是新抗原。它们像是癌细胞身上的"通缉犯标记",免疫系统本可以据此识别并攻击癌细胞，但癌细胞有各种手段躲过。

**关键事实：绝大多数新抗原是每个病人独有的**——你的肿瘤突变谱和另一个黑色素瘤病人的完全不同。所以不可能造一个"通用"的癌症疫苗去覆盖所有人的新抗原。INT 的解法是**为每个病人量身定制**。

**先把"免疫系统怎么看见癌细胞"这个画面建起来**（这是 INT 全部机理的地基，也是理解后面"冷热肿瘤""检查点刹车"的前提，务必看懂）：

你身体里每个细胞都会随时把自己**内部**正在造的蛋白切成小碎片，然后用一种叫 **HLA（人类白细胞抗原）的分子当"托盘"，把这些碎片托举到细胞表面展示出来**——这个"托举展示"的动作，行话就叫**"呈递"（presentation）**。你可以想象每个细胞表面都插着一排小牌子，牌子上写着"我内部在造什么蛋白"。免疫系统的 **T 细胞**像巡警一样挨个读这些牌子:读到的是正常蛋白 → 放行;**读到的是身体从没见过的异常碎片 → 判定这个细胞有问题、发起攻击**。

**癌细胞的麻烦在于**:它内部因为突变造出了异常蛋白,这些突变碎片(=新抗原)本来会被 HLA 托举到表面、被 T 细胞读到并干掉。但癌细胞有两手:一是有些新抗原**没被有效呈递**(牌子没举出来,T 细胞看不见);二是即使被看见,癌细胞会**踩住 T 细胞的"刹车"**让它不敢动手(这个刹车就是下一段和 §4.1 要讲的 PD-1/检查点)。

**HLA 是每个人独特的**——你的 HLA 分子能托举哪些碎片、举成什么形状,和别人不一样。所以 INT 第 3 步 AI 选靶,选的不是"随便哪个突变",而是"**这个病人的 HLA 能有效托举、从而能被 T 细胞读到**的那些突变"。这就是为什么 INT 必须一人一药:靶子(新抗原)和托盘(HLA)都是这个病人独有的。

而 INT 常和 Merck 的 **Keytruda(一种"免疫检查点抑制剂")联用**,道理也在这:光让 T 细胞"看见"癌细胞还不够,还得**松开癌细胞踩住的那个刹车**。Keytruda 的作用就是松刹车(机制细节见 §4.1),INT 的作用是"提供更多牌子让 T 细胞看见"——一个负责"看见",一个负责"敢打",所以两者配合。

### 3.3 INT 的完整生产流程（这决定了它的成本命门）

这条流程你要能复述，因为它的每一步都是成本和失败的来源[mat-df9859]：

1. **取样**：手术时取下病人的肿瘤组织（和一份正常血液做对照）；
2. **测序**：对肿瘤做基因测序，找出所有突变；
3. **AI 选靶**：用机器学习算法预测——这几十上百个突变里，**哪些**造出的新抗原最可能被病人自己的 HLA 分子有效"呈递"出来（即§3.2 讲的"举牌"，被举出来才能被 T 细胞看见）。Moderna 的算法会选出**最多 34 个**新抗原[mat-df9859]（竞品 BioNTech 选最多 20 个[mat-20fec5]）；
4. **定制合成**：把这 34 个新抗原的编码**串成一条 mRNA**，用 LNP 包好——**这条 mRNA 是这个病人独有的**；
5. **给药**：肌肉注射，**1mg、每 3 周一次、总共最多 9 针**[mat-bc7e01]，通常和 Merck 的 Keytruda 联用（Keytruda = "免疫检查点抑制剂",负责"松刹车"让 T 细胞敢动手,机制见 §4.1;INT 负责"多举牌"让 T 细胞看见——见 §3.2 末尾）;
6. **免疫应答**：病人的免疫系统被这 34 个新抗原"训练",产生能识别这些标记的 T 细胞，去巡逻清剿残留癌细胞。

**这里藏着 INT 最大的商业难题**：普通药是"一条产线造一百万份";INT 是"**每个病人一条独立的生产、测序、放行流程**",而且一个疗程要 **9 针**——不是打一次,是 9 个定制批次。这套"一人一药、一人九批"的模式,能不能做到成本可控、产能够大、周转够快,是本研究的核心命门之一（§4.3、§6.3 详述）。

### 3.4 已经证明了什么、还没证明什么

**已经证明的（黑色素瘤）**：在一个叫 KEYNOTE-942 的二期试验（P2b）里，黑色素瘤术后病人用 INT+Keytruda vs 只用 Keytruda，5 年随访显示**复发或死亡风险降低 49%**（HR=0.51）[mat-df9859]。2026 年 8 月 19 日，规模大 7 倍（**1,137 例**[mat-6fbd47]）的三期试验 **INTerpath-001** 也宣布成功——同时达到了两个终点（RFS 和 DMFS，§5 解释）[mat-99916a]。**这一点现在基本是确定的**：INT 对黑色素瘤有效，几乎肯定能获批。

**还没证明的（其它所有癌症）**：黑色素瘤是最"好打"的癌种（下一节解释为什么）。INT 能不能从黑色素瘤**外推**到肺癌、肾癌、膀胱癌——这是 $618 亿市值里最脆弱、争议最大的假设。要理解这个争议，你必须先懂"肿瘤的冷热"。

## §4 第三块地基：肿瘤的"冷"与"热"——外推争议的科学核心

### 4.1 为什么黑色素瘤是"简单模式"

不是所有癌症在免疫系统眼里都一样。有两个维度决定 INT 这类疗法好不好使：

**维度一：突变多不多（TMB，肿瘤突变负荷）。** 突变越多 → 新抗原越多 → INT 能选到的"通缉犯标记"越多 → 越好打。**黑色素瘤（皮肤癌）是所有癌症里 TMB 最高的之一**——因为它主要由紫外线晒出来，DNA 损伤累积极多。突变多到"遍地都是靶子"。

**维度二：免疫系统进不进得去（"热"vs"冷"）。**
- **"热"肿瘤**：免疫细胞（T 细胞）能浸润进肿瘤内部，免疫系统本就在"现场",只是被癌细胞的"刹车"压制了。这种肿瘤对免疫疗法反应好。**黑色素瘤是典型的热肿瘤。**
- **"冷"肿瘤**：免疫细胞根本进不去肿瘤，或者肿瘤微环境把免疫细胞全"策反"成帮凶。免疫系统在"现场之外",再多标记也没用。**胰腺癌、多数结直肠癌、胶质母细胞瘤是典型冷肿瘤。**

> **补一句"刹车"到底是什么**（这样 Keytruda 为何有用、为何要和 INT 联用就彻底清楚了）:T 细胞表面有一个叫 **PD-1 的受体**,像一个"别开火"的安全开关;很多癌细胞会在自己表面挂出对应的 **PD-L1 分子**去按住这个开关——T 细胞明明看见了癌细胞,却被按住"别开火"。**Keytruda(PD-1 抑制剂)的作用就是挡在中间、不让癌细胞按到这个开关**,于是 T 细胞恢复"可以开火"。所以:INT 负责让 T 细胞**看见更多癌细胞**(多举牌),Keytruda 负责让 T 细胞**敢开火**(松刹车)——这就是为什么两者几乎总是联用。**"热"肿瘤 = T 细胞已在现场、只差松刹车(所以单用 Keytruda 就有不少效果);"冷"肿瘤 = T 细胞根本没进场,松刹车也没用(所以更难)。**

黑色素瘤 = **高 TMB + 热** = 免疫疗法的"简单模式"。INT 在这里成功,**科学上并不意外**。

### 4.2 争议：能不能外推到"困难模式"

撑起 Moderna 市值的卖方模型,把 INT 的价值大头压在了**别的癌种**上：Guggenheim 的 2040 年模型含 **NSCLC（非小细胞肺癌）$100 亿 + RCC（肾癌）$33 亿**[mat-923b7e，见 baseline §六]。问题是：

- **NSCLC（肺癌）**：TMB 中等,吸烟者的肺癌 TMB 高、非吸烟者低——**亚型差异巨大**,不能一概而论;
- **RCC（肾癌）**：**低 TMB 却偏偏对免疫疗法有反应**——这是个"异类",它的免疫反应机制和"新抗原数量"关联很弱。如果 INT 的疗效靠的是"新抗原够多",那 RCC 这种低 TMB 肿瘤理论上不该有效;可 RCC 又确实对别的免疫疗法有效……**机理上到底靠什么,学界本身没定论。**

这就是**命门 1**：**INT 的疗效到底靠"新抗原数量"(那冷肿瘤没戏),还是靠"个体化激发的 T 细胞记忆"本身(那可能广谱有效)?** 方向错了,整个 thesis 两个方向都翻。

### 4.3 两条相互矛盾的证据（本研究抓到的关键张力）

本研究收集的材料里,这个争议有**正反两条硬证据**,值得你自己掂量:

**偏乐观的一条**[mat-df9859]：INT 在黑色素瘤的转化数据显示,疗效**与 PD-L1、TMB、ctDNA、HLA 杂合度都无关**——先解释这四个生词:**PD-L1** 是上面说的癌细胞"按刹车的手"的表达量、**TMB** 是突变多少、**ctDNA**(循环肿瘤 DNA)是血里能测到的肿瘤残留信号、**HLA 杂合度**指病人那套"托盘"分子的多样性(越多样理论上能举的牌越丰富)。这四个都是通常**用来预测免疫疗法有没有效的指标**。数据说 INT 的疗效**与它们都无关**——也就是说,即使在这些指标"不利"的病人身上 INT 也有效。如果"有效与否不挑生物标志物"这个特性能跨癌种成立,那外推就有戏。

**偏悲观的一条**[mat-edc57c]：整个新抗原疫苗领域的历史数据显示,在真正的**冷肿瘤**里(胶质母细胞瘤、胰腺癌),同类疗法**连免疫学指标(IFN-γ 反应)都难以稳定产生**,更别说临床获益。竞争对手 BioNTech 的同类药在胰腺癌的"积极"早期数据发布已 4 年多,至今没有注册性成功[mat-8842c2]。

**怎么调和?** 关键区分是:那个"与生物标志物无关"的证据,**只在黑色素瘤病人内部的亚组之间**成立(已证实);它是否能**跨癌种**成立(冷肿瘤也有效),**没有任何证据**。市场当前的定价,把"黑色素瘤内部广谱"错当成了"跨癌种广谱"。这是本研究看空立场的科学落点之一(详见 thesis 与 case 环③)。

## §5 第四块地基：怎么读临床试验——HR、CI、RFS/DMFS/OS

要跟得上后面所有关于"读出"的讨论,你得会读三个终点和两个统计量。

### 5.1 三个终点(辅助治疗场景)

- **RFS(无复发生存,Recurrence-Free Survival)**：从手术到"癌症复发或死亡"的时间。辅助治疗试验最常用的**主要终点**——因为要等"总生存"要很多年,RFS 能更早看出药有没有用。
- **DMFS(无远端转移生存,Distant Metastasis-Free Survival)**：从手术到"癌症转移到远处器官或死亡"的时间。比 RFS 更"硬"一点,因为远端转移基本等于不治。
- **OS(总生存,Overall Survival)**：从治疗到死亡的时间。**金标准**,但要等很多年,且受后续治疗干扰。

INTerpath-001 同时达到了 **RFS 和 DMFS** 两个终点[mat-99916a]——两个都中,比只中一个更有说服力(说明不只是"推迟复发",而是真的"减少转移")。

### 5.2 两个统计量:HR 和 CI

**HR(风险比,Hazard Ratio)**：治疗组 vs 对照组的"坏事发生速率之比"。
- HR = 1.0 → 两组一样,药没用;
- HR = 0.5 → 治疗组的复发/死亡风险是对照组的一半,即**风险降低 50%**;
- HR 越小 → 药越好。INT 在黑色素瘤 P2b 的 HR=0.51[mat-df9859],即风险降 49%,这是个**很强**的信号。

**95% CI(置信区间,Confidence Interval)**：HR 的估计不是一个点,而是一个范围。关键规则:**如果 CI 的上界越过了 1.0,统计上就不显著(可能药其实没用)。** INT 的 P2b 首次读出 HR=0.56 但 CI 上界是 1.02(略微越过 1.0)[mat-df9859]——因为样本量小(157 例)。后来 3 年、5 年随访 CI 收窄到不越 1.0,才算稳。三期用了 1,137 例[mat-6fbd47],样本大 7 倍,统计确定性高得多。

### 5.3 一个关键的"信息空窗"

这里有个对估值极重要的点:**2026-08-19 官方只宣布"达到了 RFS 和 DMFS 终点",但至今没有公布 P3 的具体 HR 数字、置信区间、亚组分析和安全性**[mat-99916a]。市场现在只能拿 P2b 的 HR=0.51 去猜。真正的 P3 数据可能要等 **ESMO 2026(约 10 月)或期刊发表**——这是本研究里一条被用户确认"公开无源、等会议"的结构性空窗(K1)。

一个合理的先验:**大样本试验的效应量通常会比小样本"回归"到更温和的水平**(即 P3 的 HR 可能不如 P2b 的 0.51 那么亮眼),但**统计确定性大增**。"效应量可能缩水、确定性大增"是对 P3 最中性的预期。

## §6 第五块地基:一家亏钱的生物科技,到底怎么估值?

这是最反直觉的一块,但对 Moderna 是**决定性**的。

### 6.1 为什么 PE、PS 在这里没用

你平时估值一家公司,可能看市盈率(PE)、市销率(PS)。对 Moderna,**这两个都失灵**:

- **PE 失灵**:Moderna 在亏损,forward PE 是 **-33.8**[mat-fd317b,行情]——负的市盈率没有意义。
- **PS 有误导性**:当前 PS 约 **27.8 倍**[行情],而整个生物科技板块的中位 EV/Revenue 只有 **4.4 倍**[mat-092291]。用 PS 你会觉得"贵了 6 倍",但这个结论没抓住重点——因为**市场根本不是在给"当前收入"定价**,它在给"2030-2040 年的未来收入"定价。当前收入几乎被赋值为零。
- 更根本的:Moderna 的收入曲线是 **$0.6 亿(2019)→ $184 亿(2022)→ $19 亿(2025)**[mat-d04406]——**它从来没有一个"正常年份"的基准收入**,任何基于历史收入的倍数法都没有合法基期。

### 6.2 正确的方法:rNPV / 分部加总

亏损的、价值全在"未来某个药能不能成"的生物科技,行业标准估值法是 **rNPV(风险调整净现值,risk-adjusted Net Present Value)**,也叫"概率加权峰值销售法"。逻辑是:

**一个在研药的价值 = 它成功后的峰值年销售 × 利润率 × 一个估值倍数 × 成功概率 ÷ 折现(因为钱要好几年后才到)**

对 Moderna 这种多业务公司,就把各块**分部加总(SOTP,Sum-of-the-Parts)**:

```
公司价值 = INT 肿瘤业务(按概率加权的 rNPV)
         + 呼吸道疫苗业务(COVID+流感+RSV 的稳态现金流)
         + 净现金
         + 其它管线期权
```

三个输入决定一切,且都是"猜":**峰值销售、成功概率、折现率**。这也是为什么不同分析师的目标价能差好几倍——他们对这三个数的假设不同。本研究选的正是这个方法(见 thesis:"rNPV 分部加总,不用倍数法")。行业方法论也确认:生物科技估值"较少取决于当期收入,更多取决于管线价值:临床阶段、批准概率、可及人群、IP 强度"[mat-489d4a]。

### 6.3 一个门外人也能做的粗算(帮你建立数量级直觉)

以黑色素瘤这一个已 de-risk 的适应症为例,把"峰值销售"拆开:

**峰值销售 = 可及患者数 × 渗透率 × 每疗程定价**

- **可及患者数**:美国+欧洲每年新发的、可切除的、高危复发黑色素瘤,量级约 2-3 万例;
- **定价**:参照同类个体化疗法。历史上 Provenge(前列腺癌治疗疫苗)定价 $9.3 万/疗程[mat-32ed4a];CAR-T 疗法 $37-47 万。但 INT 是 **9 针的疗程**,支付方会倾向按"整个疗程"谈判压价,合理落点约 **$15-25 万/疗程**[mat-32ed4a 推导];
- **再乘以 Moderna 的分成**——这里是**关键**,下一节讲。

粗算下来,黑色素瘤单适应症给 Moderna 带来的年峰值**分成收入**量级约 **$8-19 亿**[mat-32ed4a 推导],而不是卖方口径里那个"$54 亿销售额"直接归给 Moderna。为什么会差这么多?因为你必须懂 Moderna 和 Merck 是**怎么分钱**的。

## §7 进入公司本身(一):Moderna 和 Merck 怎么分钱——被误读最深的一环

这是本研究最重要的"口径校正",很多卖方模型在这里犯了系统性错误。

### 7.1 合作结构:50/50,但分的是"利润"不是"收入"

INT 是 Moderna 和 Merck 共同开发的。合作条款(10-K/10-Q 附注原文)是[mat-de0507][mat-f2d0a8]:

- 2016 年签约,Merck 先付 $2 亿;2022 年 Merck 行使选择权、再付 **$2.5 亿**;
- 此后按 **ASC 808 会计准则**核算,"**成本与任何利润或亏损,在全球范围内原则上五五分**"(costs and any profits or losses generally shared equally);
- 开发阶段:**Moderna 主管生产和工艺,Merck 主导临床试验**。

**划重点:是"利润 50/50",不是"收入 50/50"。** 这两者天差地别。

举个例子帮你理解:假设 INT 黑色素瘤全球年销售 $54 亿。
- **如果是"收入五五分"**:Moderna 记 $27 亿收入;
- **实际是"利润五五分"**:先扣掉生产成本、销售费用等,假设产品层利润率 60%,那利润是 $32 亿,Moderna 分一半 = **$16 亿**,而且这 $16 亿是以"合作净额"形式体现(可能记在"合作收入"里或作费用抵减),**不是产品销售收入**。

所以当你看到卖方写"Moderna 2040 年黑色素瘤销售 $54 亿"[mat-923b7e],**必须打个 40-50% 的折**才能落到 Moderna 实际入账的经济。这是**命门 2** 的核心,也是本研究对市场定价提出质疑的技术支点之一。

### 7.2 一个反直觉的"好消息":INT 对 Moderna 是高杠杆期权

分成结构对看空是利空,但有一面对看多有利,你要诚实记住:**INT 花 Moderna 的钱其实很少。** Moderna 每年为 INT 净投入只有约 **$4 亿**[mat-de0507](Merck 出资一半、且 Merck 主导临床)。也就是说,Moderna 用 $4 亿/年,换一个"若跨癌种成功就是数十亿美元级分成流"的期权——**这是极高的杠杆**。这条必须计入看多一侧(见 case 环④)。

还有一个隐藏资产:Moderna 有约 **$41 亿的联邦税务亏损结转(NOL)**[mat-de0507],永不过期。意思是 INT 若成功,前 $41 亿的利润基本**免税**——这抬高了成功情形下的税后价值。

## §8 进入公司本身(二):钱从哪来——COVID 断崖与呼吸道基本盘

### 8.1 收入的"过山车"

Moderna 的收入史是一条罕见的抛物线[mat-d04406][mat-fd317b]:

| 年份 | 营收 | 说明 |
|---|---|---|
| 2019 | $0.6 亿 | 疫情前,纯研发公司 |
| 2021 | $184 亿 | Spikevax 爆发 |
| 2022 | $193 亿 | 巅峰 |
| 2023 | $68 亿 | 断崖开始 |
| 2024 | $32 亿 | 继续跌 |
| 2025 | $19.4 亿 | -90% vs 2022 |

2026 年 Q2 单季营收只有 **$1.45 亿**,GAAP 净亏损 **$7.82 亿**[mat-f2d0a8]。**今天的 Moderna 实质上仍是一家单产品公司**——COVID 疫苗占产品销售的 99.6%[mat-fd317b]。

### 8.2 三个呼吸道产品,各自的现实

Moderna 想用"呼吸道特许经营"补上 COVID 断崖,但现实很骨感:

**① COVID 疫苗(Spikevax + mNEXSPIKE)**:已成季节性成熟市场,和 Pfizer/BioNTech 分份额,收入集中在 Q3/Q4。2025 年约 $18 亿,还在缓慢下滑。一个隐藏利好:Moderna 因竞争对手与欧盟委员会的排他合同**被挡在许多欧洲市场外,该合同 2026 年底到期**[mat-10e2e6]——所以 **2027 年欧洲市场有结构性重开的机会**(这条对看空不利,要计入)。

**② RSV 疫苗(mRESVIA)——商业上已经失败**:2025 年销售只有 **$800 万**[mat-fd317b],2026 上半年 $1000 万,同比还在降。管理层在 10-K 里**自己承认**"our RSV sales have been minimal"[mat-df9859]。为什么卖不动?RSV 成人疫苗市场已被 GSK(Arexvy)和 Pfizer(Abrysvo)靠**零售药房合同**锁死,GSK 一家占三分之二[mat-ace761];Moderna 作为第三家、晚入场、没有渠道优势,份额约 **0.3%**。第三方机构给 mRESVIA 2030 年最乐观预测也只有 **$5 亿**[mat-d946d7],且判定整个品类因美国疫苗态度转变而下滑。**RSV 这条腿基本可以按零计。**

**③ 流感疫苗(mFLUSIVA / mRNA-1010)——刚获批,但赚钱不容易**:2026-08-06 FDA 批准(50 岁+),此前经历过 refuse-to-file 的波折、最后咨询委员会一致推荐[baseline §六]。但流感是**高度成熟的市场**,管理层自己在 10-K 说"可能需要提供更优惠的条件来获取份额"[mat-10e2e6];而且流感的经济学还被一个叫 **Blackstone** 的融资方**前置抽走一层**(最高 $7.5 亿销售里程碑 + royalty)[mat-de0507]。流感获批 ≠ 流感赚钱。

**小结**:呼吸道基本盘的真实结构是"COVID 存量(缓慢下滑)+ 流感(薄利被抽成)+ 2027 欧洲回补(份额未知)+ RSV≈0",而不是笼统的"三产品放量"。

## §9 进入公司本身(三):现金、债务与跑道——命门从"生死"降为"稀释"

一家每年烧几十亿、没利润的公司,最要命的问题是:**钱够烧到 INT 兑现吗?**

### 9.1 账面数字

截至 2026-06-30[mat-f2d0a8]:
- 现金+投资 **$69.1 亿**;
- 但 7 月付掉了 **$9.5 亿**诉讼和解款(LNP 专利,付给 Arbutus/Genevant);
- 扣掉 $6 亿债务后,**真实可动用净现金约 $53.6 亿**;
- 每年经营性现金消耗约 **$27 亿**(剔除一次性项)。

### 9.2 两个此前被忽略的"暗雷"

本研究从财报附注里挖出两条市场很少提的东西:

**① 一条 $13 亿的尾部**[mat-f2d0a8]:上面那笔 $9.5 亿和解还有个上诉环节,视结果 Moderna **可能再付最高 $13 亿,且至今未做任何财务计提**。等于净现金 $53.6 亿上方挂着一个可能 -24% 的尾部。

**② 债务是高息、有抵押的私募信贷**[mat-f2d0a8]:那 $6 亿债务不是普通银行贷款,而是向 **Ares Capital(私募信贷)**借的,利率 **9.2%**、**一级抵押权覆盖几乎全部资产**。一家账上有几十亿现金的公司,去借 9.2% 的抵押债——这是信用市场对它定价偏紧的硬信号。而且债务契约里写着"当 30 天平均市值 > $50 亿时免测最低现金要求"[mat-f2d0a8]——**等于把股价写进了债务条款**,是个反身性放大器。

### 9.3 命门的降级

上一轮研究曾把"现金跑道 vs 兑现赛跑"列为**核心命门**(会不会没钱撑到 INT 兑现)。本轮**降级**:因为 8/19 暴涨到 $155 打开了股权增发窗口——以 $155 增发 5% 股本能融约 $30 亿,稀释成本远低于 $63 时。所以"没钱"不再是可信的翻盘机制,它从"**存亡问题**"变成"**稀释幅度问题**"(估值算术)。但要注意:**2027 年内几乎必然需要一次股权再融资**,只是暴涨让稀释以更高价发生(对老股东更有利)。这条现在归入风险项 + K4/K5 观测,不再是命门。

### 9.4 管理层的激励(为什么他们不怕稀释)

一个理解资本配置的关键背景:CEO Bancel 的薪酬结构是**凸性的**——2025 年(营收 -40%、亏 $28 亿、股价低位的一年)他仍拿了 $1,993 万,**奖金按目标的 170% 支付**[mat-2f4635];2025 年 3 月授予的期权行权价才 **$30.96**(现价 $154.90,内在价值约 $4,425 万)。而且他的薪酬**跟盈利完全脱钩**——2022 年赚 $84 亿的年份 $1,936 万,2025 亏损年 $1,993 万,几乎一样[mat-2f068d]。含义:**管理层的财富主要来自期权凸性,不是既有股份价值,所以他们对"高位增发稀释老股东"的心理成本很低**——这强化了"2026-2027 高位增发"的判断。

## §10 进入公司本身(四):美国政策——一个无法用执行力对冲的折价

Moderna 有一个大药企没有的独特风险:**它 100% 收入来自 mRNA 疫苗,而美国政策环境正在系统性地敌视 mRNA 疫苗。**

### 10.1 美国疫苗从"获批"到"赚钱"的链条

你要先懂这条变现链:**FDA 批准 → ACIP 推荐 → CDC 纳入免疫程序 → 支付方/保险覆盖 → 药房渠道铺货**。光有 FDA 批准不够——真正决定一个疫苗能不能大规模卖出去的,是后面 **ACIP(免疫实践咨询委员会)**的推荐和随之而来的保险覆盖。

### 10.2 链条被打断在哪

2025 年起,RFK Jr. 任 HHS 部长,对 mRNA 疫苗公开敌意[baseline §六]:
- HHS 终止了 BARDA 的全部 **22 个 mRNA 项目、近 $5 亿**[mat 政策类,baseline §六已确认 hhs.gov 一手];
- **ACIP 被整体改组换人**,疫苗推荐路径的可预测性大降;
- 第三方甚至把"美国疫苗态度转变"直接算进了 RSV 品类的下滑预测[mat-d946d7]。

### 10.3 一个重要的区分:政策敌意主要打呼吸道,不太打肿瘤

这是本研究一条容易被市场忽略的细分。**INT 是肿瘤治疗药,走的是 CMS/Part B + 商业保险的报销通道,不经过 ACIP 疫苗推荐机制。** 10-K 自己写明"ACIP 建议不保证覆盖",药品报销由 CMS/商保决定[mat-df9859]。HHS 公告本身也写了"mRNA 技术的其它用途不受影响"。

所以:**HHS/ACIP 的 mRNA 敌意,主要打击呼吸道疫苗分部,对 INT(肿瘤)的直接适用性弱。** 这意味着本研究里的"政策折价"论据**只能按呼吸道分部计权,不能整体折价**——这是一个对看空立场的重要自我约束(否则会高估政策的打击面)。

**但注意另一道门**:INT 虽不受 ACIP 影响,却面临另一个障碍——**个体化产品在美国的 HTA(卫生技术评估)/报销体系里没有既成的定价框架**,历史上 Provenge 就是被"CMS 覆盖时机"拖死的[mat-72c8ae]。所以 INT 即使 2027 年获批,**有意义的收入可能要到 2028-2029 才起量**(制度性时滞),这会压低 rNPV 的现值。

## §11 进入公司本身(五):竞争与并购——为什么这只股票同时是"科学期权"和"并购标的"

### 11.1 个体化癌症疫苗不是 Moderna 独家

市场容易把 8/19 的成功理解成"Moderna 独家验证了一个新品类",**这不对**。**BioNTech + Genentech/罗氏**从 2016 年就在做同样的事——他们的药叫 **autogene cevumeran(BNT122)**[mat-20fec5]。所以这条赛道是"**Moderna+Merck vs BioNTech+罗氏**"两组巨头对垒。

有意思的分野:**BioNTech 直接冲"冷肿瘤"**(结直肠、胰腺),**Moderna 从"热肿瘤"(黑色素瘤)起步**[mat-20fec5]。所以竞争对手的读出会成为 INT"跨癌种外推"的**先行指标**——如果 BioNTech 在胰腺癌成功,整个品类(含 INT 的冷肿瘤扩张)重估;如果失败(至今 4 年未成[mat-8842c2]),市场对 INT 跨癌种的隐含概率就得下调。这对 Moderna 是"免费的信息"。

一个对 Moderna 有利的细节:INTerpath-001 的对照组是 **Keytruda 活性对照**(较难),而 BioNTech 结直肠试验的对照组是"观察等待"(较易出差异)[mat-967429]。所以 INT 这次成功在**方法论上比同类竞品更硬**——统计学门槛更高。

### 11.2 为什么 Merck 可能买断 Moderna

这是理解 Moderna 股价"下有支撑"逻辑的关键背景。Merck 的当家药 **Keytruda**(去年销售逾 **$250 亿**,占 Merck 销售 40%)将在 **2028 年专利到期**[mat-7c2029],之后收入会断崖。Merck 急需新增长曲线,而 INT 正是 Keytruda 的"生命周期延展"最重资产之一(INT 和 Keytruda 联用),Merck 还已经承担了一半成本。

所以市场反复出现"Merck 应该买断 Moderna 的 INT 权益、甚至整体收购"的讨论[mat-17252a]。但要冷静看两点:
- **Merck 自述的收购射程"最高至 $150 亿"**[mat-7c2029],而 Moderna 现市值 $618 亿——**整体收购在 Merck 胃口之外**。现实的并购形态更可能是"买断 INT 的 50% 权益"。
- 而"买断"对 Moderna 股东是**双刃**:一次性变现的价格可能**低于**市场当前对 INT 期权的隐含定价——即"被买断"反而可能坐实看空目标价。
- 且 Merck 有替代方案(皮下剂型 Keytruda、其它联用、$150 亿以内的外部并购)[mat-8ee163],**"必须买 Moderna"并不成立**。

所以并购既是"价值地板"也是"尾部风险",不是单纯的利好。这就是为什么这只股票同时被当作"科学期权"和"并购标的"来交易。

## §12 历史镜鉴:治疗性癌症疫苗商业化,人类只成功过一半

要判断 INT 值多少钱,有一个不能不看的历史样本:**Provenge(Dendreon 公司,2010 年获批的世界第一个治疗性癌症疫苗)**。它的故事是 INT 最贴切的镜鉴——**但要小心哪些能类比、哪些不能**。

**Provenge 的死亡序列**[mat-e9e1b7][mat-fb3ad2]:2010 年获批(前列腺癌)、拿到总生存获益、定价 $9.3 万/疗程 → 但采纳受"高定价 + 保险覆盖不确定"阻滞 → 高生产成本(COGS 一度 **77%**,远超预测的 20-30%[mat-d134d4])吞掉毛利 → 更便利的口服竞品改变护理标准 → 峰值年收入只到 **$3.25 亿**、第 3 年就转跌 → 2014 年**破产**。峰值到破产,历时 4 年半。

**教训(能类比的部分)**:治疗性癌症疫苗的失败**不在临床终点,而在获批之后的四重门**——报销、COGS、给药便利性、竞争。Provenge 拿到了 FDA 首批、拿到了 OS 获益,**依然破产**。"获批"只是第一道门。而且"个体化产品的成本预测系统性乐观"是个反复出现的行为规律(Provenge 的 COGS 是预测的 2-3 倍)。

**必须诚实标注的、不能类比的部分**[mat-a08a45][mat-a9a469]:
- Provenge 是**自体细胞疗法**(要采集患者活细胞、18 小时冷链、体外处理再回输),INT 是 **mRNA 化学制品**(可标准化合成)——工艺可扩展性不同,Provenge 的 COGS 数值不能直接搬;
- Provenge 面对的是**晚期**前列腺癌(价值主张薄,OS 获益仅几个月),INT 是**辅助治疗**(降复发风险 49%,价值主张强得多);
- Provenge 是**独自商业化的小公司**,INT 有 **Merck 出资一半 + 主导商业化**;
- CAR-T(另一类个体化疗法)最贵的一环是病毒载体(约 $10 万/例),**INT 不需要病毒载体**[mat-a9a469]——所以 INT 的 COGS 上限应显著低于 CAR-T。

所以 Provenge 镜鉴的**正确用法**是:警惕"获批后四重门"和"成本预测偏乐观"这两个**行为规律**,而不是照搬它的破产结局或 COGS 数值。
