## 环① 看懂并信得过这家公司（理解闸门 · 三梁）

> 背景（mRNA 是什么、INT 怎么造、公司历史）已在 primer §2-§8 讲透，此处只留**决策相关**的三梁速写。

### 梁一 · 生意与护城河

**这门生意怎么赚钱（一句话）**：Moderna 本质是"一个正在萎缩的呼吸道疫苗现金业务" + "一个可能重估一切的肿瘤期权（INT）",中间靠 COVID 攒下的现金续命。2025 年营收 $19.44 亿、99.6% 来自 COVID 疫苗[mat-fd317b]——**今天仍是单产品公司**。

**护城河判断——正在变化中**：
- mRNA 平台"可编程"是真实的技术护城河（换序列即换适应症），但**LNP 底层专利并不干净**——Moderna 刚为此付 $9.5 亿和解，还有 GSK/Northwestern/CureVac/Sanofi 等一串诉讼在打[mat-f2d0a8]。
- **呼吸道分部没有护城河**：COVID 是与 Pfizer 分份额的成熟市场；mRESVIA 在 RSV 三方竞争中份额约 0.3%[mat-ace761][mat-d946d7]；流感是高度成熟、需让价才能进的市场[mat-10e2e6]。
- **真正的（潜在）护城河在 INT**：全球首个个体化新抗原疗法 P3 成功 + Marlborough 专用产能已在 2025-09 发运患者批次[mat-df9859] + 与 Keytruda 的联用地位。但这条护城河的宽度取决于命门1（能否跨癌种），未定。

**单位经济（最关键一组）**：INT 对 Moderna 的**年净投入仅约 $4 亿**（Merck 出资一半、主导临床）[mat-de0507]——**极高杠杆的期权**（$4 亿/年博数十亿分成流）。但个体化生产的 COGS 是黑箱：历史镜鉴 Provenge 的 COGS 曾达 77%（预测 20-30%）[mat-d134d4]；INT 无病毒载体（比 CAR-T 便宜）[mat-a9a469] 但 9 针/疗程[mat-bc7e01] 抬高单位成本——**净成本方向未定**（命门2）。

### 梁二 · 管理层与资本配置（长期持有的一等公民）

- **谁在掌舵**：CEO Stéphane Bancel，2011 年至今约 15 年，**制造/供应链出身**（前 bioMérieux CEO、Eli Lilly 供应链）[mat-978a59]——不是科学家。这解释了公司对"自建全球产能"的执着（Norwood/Marlborough/英加澳），也解释了为什么在需求崩塌后仍难主动收缩产能（三年 $30 亿存货减值是代价[mat-de0507]）。
- **资本配置记录——喜忧参半**：COVID 巅峰赚约 $206 亿（2021-22），2021-22 回购约 $34 亿；此后转为保现金。但把 COVID 现金大量投入了**后来被砍的管线与过大的产能**（候选药 42→25、CMV P3 失败、诺如 P3 中期未达）。
- **激励是否与小股东对齐——警示**：Bancel 薪酬**与盈利脱钩**（2022 净利 $84 亿年薪 $1,936 万 vs 2025 亏 $28 亿年薪 $1,993 万）[mat-2f068d]；2025 年在营收-40%、股价低位时**奖金仍按目标 170% 支付**[mat-2f4635]；2025-03 期权行权价 $30.96（现价 $154.90）。激励是**凸性的**（期权为主）→ **管理层偏好扩张、对稀释老股东的心理成本低**（喂环⑤/⑥ 的"高位增发"判断）。
- **一句话评**：这是一个**执行力强但资本纪律存疑**的配置者——适合"平台扩张"叙事，不适合"为每股价值精打细算"。托付 3-5 年的信任度：**中等偏低**。

### 梁三 · 多年财务弧线（趋势）

营收 $0.6 亿(2019)→ $184 亿(2022)→ **$19.4 亿(2025)**[mat-d04406][mat-fd317b]；3 年 ROIC 全负（-30%量级）、FCF 三年累计约 -$99 亿[财务库]。这条弧线的定性：**一次性暴利后的塌缩,尚未找到第二基石**——公司**从来没有一个"正常年份"的基准收入**。这直接决定了②必须用 rNPV 而非任何倍数法（见 primer §6）。

**① 闸门结论**：生意能看懂（primer 已建模）；管理层执行力可信、资本纪律存疑；财务弧线是"塌缩+找第二曲线"。**闸门通过,但"信得过管理层为小股东精打细算"这条打折**——这会影响⑥的持有期与稀释假设。

**E[return] = 0.25×(-22%) + 0.45×(-57%) + 0.30×(-72%) = -53%**

**这一环最反直觉、也最有力的结论**：**即使 Bull 情景(跨癌种完全兑现),按利润 50/50 的内在价值口径,公允价也只有 ~$120,仍低于现价 $154.90(-22%)。** 换句话说,现价 $154.90 隐含的跨癌种价值(~$459 亿),**比我认为"完全兑现"时的价值($260 亿)还高 76%**——市场要么在用销售额口径(而非利润 50/50),要么把 8 项试验之外的更多瘤种也提前计价了。三档全负 → **当前价在我的内在价值框架下,任何情景都高估。**

**为什么仍是减持而非做空**：(1) 我的 SOTP 输入本身可能偏保守(利润率、倍数、瘤种数若更高,Bull 内在价值可上修);(2) 并购是真实的二元上行尾部(即便作价可能低于市场隐含,仍能一次性抬升);(3) 8/19 单日 +177% 的伽马挤压史[mat-6fbd47]。**期望值显著为负 → 减持;尾部与自身口径不确定性 → 不做空。**

### 4.4 我的判断 + 信心度

**判断：卖出/减持(强度 2-3/10)。信心度:中。** 凭什么下"中"而非"高"：W2(口径)是 10-K 直接证伪的**硬点**、相对估值(②)是硬证据、且"即使 Bull 也 -22%"这一结论在我的口径内很硬;但**决定 delta 的 W1(跨癌种概率,我 30% vs 市场 70%+)本质是 2027 前不可证的概率判断**,而疗效已 de-risk 使我无法更激进;且我的 SOTP 输入(利润率/倍数)本身有不确定性、P3 具体 HR 是结构性空窗(K1,已 waive)——**信息与口径都不完备,故减持而非重仓做空。EV -53% 是"我的口径下"的数,不是"市场必然回落 53%"的预测——两者区别见 6.2。**

## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

### 5.1 已知风险 + 盲点风险

- **已知风险**：① NSCLC(INTerpath-002)读出成功 → 跨癌种外推被证,我的 Base/Bear 崩;**注意此时市场很可能用销售额口径把股价推到 $220-260(远超我的内在 Bull $120)——这是做空会被挤压的核心原因,也是"减持不做空"的直接依据**;② Merck 溢价买断 → 一次性重估;③ P3 HR 披露强于 P2b → 黑色素瘤价值上修。
- **盲点风险**：① INT 若在**中间瘤种(RCC/膀胱)**先读出且阳性,会在 NSCLC 之前就部分证伪 W1——我可能低估了"部分外推"的概率;② mRNA-4359 等**全资肿瘤资产**(不与 Merck 分成[mat-df9859])被市场重新发现 → 额外期权;③ 皮下 Keytruda + INT 捆绑[mat-7c2029] 使 Merck 战略依赖度高于我的假设。

### 5.2 kill 触发条件（可观测,喂 sidecar）

- **翻多 kill(交易层)**：INTerpath-002(NSCLC 辅助)主要终点达标且 HR ≤0.65 → 跨癌种从期权变基本情形 → **平仓看空/减持**。触发时**市场价**大概率冲 $220-260(销售额口径+外推),**内在 Bull 价值**约 $120——两者差就是"市场溢价",但交易上不与已兑现的动量对抗,故平仓。
- **加速看空**：任一冷/中间瘤种(RCC/膀胱)读出**失败**,或 ESMO 2026 披露 P3 RFS HR >0.65 / DMFS 与 RFS 背离 → 下修至 $45-60(注意**不是**回到读出前的 $63——黑色素瘤已成功构成实质地板)。
- **口径 kill**：若后续披露 Merck 合作有"某些例外"使 Moderna 实得显著高于利润 50/50 → W2 部分回退,上修黑色素瘤分部。

### 5.3 历史失败镜鉴（≥2,每个标失败模式+峰谷+预警+是否已现）

1. **Provenge / Dendreon（现金流断裂型）**[mat-e9e1b7][mat-fb3ad2][mat-d134d4]：世界首个治疗性癌症疫苗,拿到 FDA 批准 + OS 获益,**仍破产**。失败模式=获批后四重门(报销时机/COGS 77%/给药复杂/口服竞品)。峰谷:$57.67→$0.24(-99.6%,4.5年)。最早预警:COGS 远超预测 + 峰值收入仅 $3.25 亿第 3 年转跌。**现在是否已现**：INT 的 COGS 未披露(不能排除)、给药 9 针复杂(已现)、报销框架缺失(已现[mat-72c8ae])——**部分已现**。教训:个体化癌症治疗"获批≠赚钱",且成本预测系统性乐观。⚠️ **不可直接类比的部分**：INT 是辅助治疗(价值主张强)、有 Merck 分担、mRNA 无病毒载体——破产结局不可照搬,但"四重门"结构完全可类比。
2. **平台首胜后翻倍再均值回归（估值透支型）**[mat-c31355]：CAR-T(2017)、基因治疗(2019-21)、mRNA 自身(2021 Moderna $497→$25,-95%)。失败模式=单点验证被外推成平台整体验证,估值透支未读出适应症。峰谷:Moderna 2021 顶到 2026 低点 -95%。预警:市值隐含的适应症数 >> 已读出适应症数。**现在是否已现**：$455 亿期权隐含把 8 项未读出试验按高概率计价——**已现**。
3. **诺如/CMV 管线内部证伪（叙事打折型）**：CMV P3 失败、诺如 P3 中期未达早期成功[mat-f2d0a8]——**同一平台的其它 P3 已在失败**,提示"平台可复制"叙事本身有裂缝。

### 5.4 signpost（未来 3-12 月验证/证伪事件 → 喂 sidecar）

ESMO 2026(~10月,P3 HR)｜INTerpath-002 NSCLC 读出｜首个冷/中间瘤种读出｜竞品 BNT122 结直肠/胰腺读出｜Q3/Q4 现金 vs 指引｜是否高位增发｜Merck 买断信号｜2027 欧洲订单。

## 环⑥ 在什么价/仓位/时点做什么（行动）

### 6.1 买入框（锚在②的 SOTP）

- **强力买入区 $34-47**（SOTP Bear $34 ~ 回归锚 $47）：只有在这个价,即使跨癌种全灭,黑色素瘤+现金+呼吸道残值也构成安全边际。
- **可建仓区 $47-75**（回归锚上沿 ~ SOTP Base $66 上沿）：需对跨癌种给正概率才买,试探档。
- **观望区 $75-110**（SOTP Base 上方 ~ 接近 Bull 内在价值 $117）：不追,已持仓持底仓。
- **减持区 $110-176**：**当前 $154.90 在此**（隐含把跨癌种按 70%+ 概率、且用销售额口径计,不接受）。
- **$176.66(52 周高)上方 = 强制减仓区**,清到底仓。
- **注**：即使 Bull 内在价值 $117-120 也在"观望区"上沿,说明当前价无任何情景支撑建多头仓。

### 6.2 仓位框架

- **position_tier = 试探(观望为主)**：理由——EV=-53%(我的 SOTP 口径)强烈指向减持,但终局 delta 吃 W1(2027 前不可证的概率判断)+ P3 HR 结构性空窗 + 我 SOTP 输入本身有上行不确定性(利润率/倍数若更高则 Bull 内在价值上修)。**EV -53% 是"内在价值 vs 现价"的差,不是"市场必然在某时间内回落 53%"的预测**——市场可能长期用销售额口径维持溢价,所以是"减持既有仓 + 不建新多头 + 不做空",而非"重仓押回落"。信息与口径完备度不支持"标准/重仓"级方向下注。
- **initial_max_pct = null**（不给伪精确;当前价不建多头仓;已持仓者按 6.1 在 $140-176 分批减,$176.66 上方清到底仓）。
- **不做空**：借券成本 + NSCLC 读出 + 并购双向尾部 + 8/19 单日 +177% 的伽马挤压史[mat-6fbd47]。纪律是**减持,不是做空**。

### 6.3 时间维度

- **持有期**（对少数愿持有的底仓）：跟到 INTerpath-002 读出为止(最可能 2026-2027),那是命门1 的总开关。
- **下一 catalyst**：ESMO 2026(~10月)的 P3 HR——若强于 P2b,Base 目标上修;弱于则加速看空。
- **"到 X 未发生 Y 怎么办"**：若 2027 年内 NSCLC 未读出且现金跌破指引又高位增发 → 稀释坐实,维持看空。

### 6.4 什么会让我改主意

- **上修**：INTerpath-002 达标 HR ≤0.65 / Merck 溢价买断 / P3 HR 强于 P2b（对应 5.2 翻多 kill）。
- **下修**：冷肿瘤读出失败 / ESMO HR 令人失望 / 呼吸道续崩（对应 5.2 加速看空）。

**中等偏高**：SEC 一手财报 + 官方临床稿 + 竞品/镜鉴/政策多源齐全;双轴 gap 全绿。**残留缺口**：P3 具体 HR（结构性空窗,已 waive）、INT 实际 COGS（公开无源）、50/50 的"某些例外"条款（需协议原件）——三者都是**方向不改、幅度待定**的缺口,已在 thesis 数据缺口章标注。
