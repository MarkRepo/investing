## 核心数据点与事实

1. **[UroToday/ESMO 2025] INTerpath-011（NCT06833073）设计**：随机、多队列、开放标签 P2，**高危非肌层浸润性膀胱癌（NMIBC）**；队列 A **约 278 例** 1:1 随机至膀胱内灌注 BCG（50mg，诱导 q1w×6 周，维持 q1w×3 周于第 13/25/49/73 周）± **intismeran 1mg IM q3w×9 剂**；队列 B（探索性，约 30 例）为 intismeran 单药。
2. **[UroToday] 入组定义**：队列 A 为 BCG 初治高危 NMIBC（HG Ta、T1 和/或 CIS）；队列 B 为 BCG 初治或 BCG 暴露的 CIS±乳头状肿瘤患者，且不适合或拒绝膀胱内灌注治疗。BCG 初治定义为未用过 BCG 或距复发 >2 年用过。
3. **[UroToday] 疗效评估**：尿细胞学由**盲法独立中心评审** + 膀胱镜。→ 终点设计规范，但**开放标签**（非双盲）。
4. **[UroToday] 关键结构性事实**：这是 INT program 里**唯一有"单药队列"的试验**（队列 B，约 30 例，探索性）→ 是**观测 INT 单药活性**（脱离 PD-1 抑制剂协同）的唯一公开窗口，对判断"INT 本身贡献多少 vs 只是 pembro 增效剂"至关重要。

## 叙事主线

因为**INTerpath-011 在 NMIBC 里把 INT 与标准 BCG 联用、并额外设了一个约 30 例的单药探索队列** → 所以它是 program 内**唯一能分离"INT 自身活性"与"检查点抑制剂协同"的试验** → 对投资意味着这条读出（膀胱癌，BCG 背景而非 PD-1 背景）是判断**跨免疫微环境外推**（命门1）的高信息量事件，权重应高于又一个 PD-1 联合试验。

## 反常识/分歧点

- 市场把 INT 一律理解为"pembrolizumab 的增效剂"；INTerpath-011 队列 B（单药）与 BCG 联用设计表明 Merck/Moderna 自己也在测试**不依赖 PD-1 通路**的场景。
