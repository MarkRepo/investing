## 核心数据点与事实

1. **[Finerva（数据源 YCharts）] BioTech & Genomics 板块 EV/Revenue 中位数时间序列**：2020Q4 峰值 **15.19x** → 2021-2022 持续回落 → 2023-2024 稳定在 **4.5-6.5x**（2024Q4 为 6.2x）→ 2025 年进一步压缩，**2025Q2 低至 3.8x** → **2026Q1 中位数 4.4x**。
2. **对照计算（我的计算）**：Moderna 当前 EV ≈ 市值 $618.5 亿 − 净现金约 $53.6 亿 ≈ **$565 亿**；TTM 收入约 **$22.3 亿**（FY2025 $19.44 亿 + H1 2026 同比增量 $2.84 亿）→ **EV/Revenue ≈ 25.3x**。
3. **相对水位**：25.3x ÷ 4.4x ≈ **5.7 倍于板块中位数**；即便对标 2020Q4 泡沫顶点的 15.19x，**Moderna 当前倍数仍高出 67%**。
4. **含义**：以收入为分母的任何倍数法都无法解释当前市值 → **市场定价的 100% 是"未来的 INT 收入"**，当前收入实质上被赋值为零甚至负（因其亏损）。这与我选择 rNPV/分部相加、明确弃用 P/E 与 P/S 的方法论判断一致，并为下行情形提供一个**独立的回归锚**：若 INT 叙事失效，估值向 4-6x EV/Revenue 回归意味着 EV 约 **$90-134 亿**（对应股价约 **$36-47**，按 3.99 亿股 + 净现金）。

## 叙事主线

因为**板块 EV/Revenue 中位数在 2026Q1 仅 4.4x（且 2025 年一度压到 3.8x），而 Moderna 当前为 25.3x** → 所以当前定价完全脱离了收入基准，其全部合理性寄托于 INT 的未来现金流 → 对投资意味着环②应给出两个下行锚：**(a) 倍数回归锚 $36-47**（INT 叙事完全失效）；**(b) rNPV 分部锚**（INT 按概率加权 + 呼吸道地板 + 净现金）。二者的差距本身就是"期权价值"的市场定价，**这是我环②反推隐含预期的技术路径**。

## 反常识/分歧点

- **市场用"平台公司不看当期收入"来豁免估值纪律；板块数据表明"生物科技/基因组学"整体的中位倍数也只有 4.4x** —— 即"平台溢价"并不是板块常态，Moderna 的 25x 是**个股特有的事件溢价**，不是行业属性。
