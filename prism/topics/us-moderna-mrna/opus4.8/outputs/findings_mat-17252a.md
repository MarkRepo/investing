## 核心数据点与事实

1. **[BioSpace] 一封公开提议（投资者致 Merck 的邮件，经 BioSpace 报道）主张 Merck 应买断 Moderna 在 INT 组合疗法中的一半权益**，理由是 Keytruda 2028 失去独占后的收入缺口需要该组合来补。
2. **[同上] 提议方对 Moderna 侧的估算**："出售其在该组合中的一半权益，其规模很可能**足以让这家生物科技公司的市值一夜翻倍**，同时仍留下大量管线项目维持未来业务。"→ **注意时点**：该文成稿于 Keytruda 2023 年销售 / 2024Q1 数据的语境下，当时 MRNA 市值约 $400 亿量级；"翻倍"对应的绝对金额约 $400 亿 —— **在今天 $618 亿市值下这个倍数已不适用**，但它给出了一个第三方对"INT 一半权益"的价值感（数百亿美元级）。
3. **[同上] Keytruda 的体量与悬崖**：2023 年销售逾 **$250 亿**（原文误写为 $25 million，按上下文与 mat-7c2029 应为 $25 billion），占 Merck 当年销售约 **40%**，同比 +19%；2028 年失去独占后**第一年可能下滑 19%**（Pharmaceutical Today 口径）。
4. **[同上] 时间紧迫性论据**："组合疗法越接近上市、Merck 越接近专利悬崖，这笔交易就会越贵" → **对 Moderna 股东的含义：谈判筹码随 P3 成功而大幅增强**，8/19 之后 Merck 的买断成本已经跳升。

## 叙事主线

因为**Keytruda（占 Merck 销售 40%、年逾 $250 亿）在 2028 年面临专利悬崖，而 INT 是其最重要的生命周期延展资产之一，且 Merck 已承担一半成本** → 所以存在一条清晰的战略交易路径（Merck 买断 Moderna 的 INT 一半权益，或整体收购）→ 对投资意味着这是**看空 thesis 的最大尾部风险**：即便我判断 $154.90 透支了跨瘤种期权，一个战略买家的出价可以在任何时点把这个"透支"变成"兑现"。**它同时也是一条价值地板**：Moderna 的 INT 权益有一个非市场化的、由 Merck 的悬崖压力定价的买方。
