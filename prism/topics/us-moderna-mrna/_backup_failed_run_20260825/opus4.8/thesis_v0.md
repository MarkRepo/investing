## 一、核心 thesis（终局：买/卖/持有 + EV + 目标价/介入纪律）

**近端看空 / 减持（strength 3/10，0=完全看空 10=all-in）。**

一句话：INT 黑色素瘤 P3 首胜（2026-08-19）兑现了肿瘤期权、股价从 ~\$63 翻倍至 ~\$139-151[mat-647d42]，但**已证实价值（辅助黑色素瘤）仅支撑共识目标 ~\$85-95[mat-add981]，当前价透支了尚未验证的"冷肿瘤外推"**——在 ESMO（10月）披露 HR[mat-a92932] 与首个冷肿瘤读出（RCC，~2026末）de-risk 之前，估值先行。

**终局落点**：
- **卖/减持** at ~\$139-151；**目标价近端 \$85-100**（共识锚，均值回归 + 后浪退潮）。
- **介入纪律**：不在此价追多；等两个 de-risk 事件再重估——① ESMO HR（K1）；② 首个冷肿瘤读出（K2）。若 ESMO RFS HR ≤0.55 且 OS 有获益趋势 → 上修至 \$150+；若冷肿瘤失败/HR>0.7 → 下修回 \$60-70（读出前价 + 薄黑色素瘤溢价）。

## 二、支持理由（看空当前估值）

1. **共识隐含下行**：19 家投行 P3 后共识目标 ~\$85-95.67，低于现价 ~\$139-151，~\$17B 估值缺口[mat-647d42][mat-add981]。BofA/Jefferies 最高 \$170 但均为中性评级；JPM 卖出 \$77。
2. **已证实价值有限**：JPM 测算"仅黑色素瘤 ~+3% 估值"（85% 成功概率已 pre-modeled）[mat-add981]；即翻倍主要由"平台外扩预期 + 散户情绪（癌症疫苗预防 vs 辅助治疗认知偏差）"驱动，而非新增确定现金流。
3. **核心价值驱动未验证**：Wolfe 的 \$9.2B 峰值销售依赖 4 适应症（黑色素瘤/RCC/MIBC/NSCLC）[mat-add981]，其中冷肿瘤（NSCLC/胰腺）能否外推是最大问号，且 P3 HR/p 值要等 ESMO（10月）才披露[mat-a92932]。
4. **基本面仍深亏 + 断崖未止**：FY2025 营收 \$1.94B(-40%)、净亏 \$2.8B[mat-447084]；2026Q2 营收仅 \$145M、净亏 \$782M[mat-647d42]；呼吸道基（COVID/RSV）仍在缩，mRESVIA 2025Q1 销售大幅低于预期[mat-cc1aef]。
5. **多个管线接连受挫**：CMV 停研、诺如中期未达早期成功、流感 mRNA-1010 曾遭 FDA RTF[mat-8eeb5d]——"呼吸道特许经营补断崖"叙事兑现打折。

## 三、最大反方观点（诚实列，非稻草人）

1. **平台首次验证的重估是结构性的**：全球首个个体化新抗原/mRNA 肿瘤疗法 P3 首胜，若外推成立则打开整个 onco 管线，\$9.2B 峰值销售可能仍低估平台。翻倍或只是起点。
2. **ESMO 可能强于预期**："读出早于预期"暗示中期即达显著，数据强度可能可观[mat-a92932]；若 HR ≤0.5、OS 早现获益，共识目标会集体上修。
3. **现金跑道够撑到兑现**：2026 末现金 \$4.7-5.2B、2028 才需盈亏平衡[mat-8eeb5d]，不存在近端被迫增发稀释的强制卖点；有时间等 RCC/NSCLC 读出。
4. **呼吸道仍有正催化**：流感 mRNA-1010 美国 PDUFA 2026-08-05、组合 mRNA-1083 已获 EU 批准[mat-8eeb5d]，若获批为第 5 产品、组合放量，呼吸道基企稳。

## 四、会改变看法的事件 / Killer Questions（可观测、可证伪）

- **K1｜ESMO 2026（10/26-27）披露 INTerpath-001 的 HR / OS 趋势**：RFS HR ≤0.55 且 OS 有获益趋势 → 上修；HR >0.7 或 OS 无信号 → 下修。（可观测：ESMO 具体数值[mat-a92932]）
- **K2｜首个"冷肿瘤"读出达标与否**：RCC（辅助，~2026末）或 NSCLC（INTerpath-013 P2）主终点是否阳性——当前估值的核心赌注。（可观测：试验 topline）
- **K3｜流感 mRNA-1010 美国 PDUFA（2026-08-05）是否获批 + 组合 mRNA-1083 美国再申是否被 FDA 受理**：呼吸道能否补 COVID 断崖。（可观测：FDA 决定[mat-8eeb5d]）
- **K4｜2026-2027 现金消耗是否守住指引**（年末 2026 \$4.7-5.2B、2028 盈亏平衡）：若季度烧钱超指引或增发/举债稀释 → 跑道命门恶化。（可观测：季报现金 vs 指引[mat-8eeb5d]）
