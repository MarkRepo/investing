# Decomposition v0 — PDD Holdings（命门拆解 · 驱动收料）

> 冷启动断点：训练知识 + baseline（含 §六 prescan 校准）+ thesis_v0。薄拆解不做 LLM critic，仅置信度 tag + 机械自检。深度重拆留 04。
> B 轴 = 命门拆解（喂 case 决策环）+ primer 入门目标（喂 primer），两者共住本文件。

## 一、命门 1-3（thesis 翻盘点）

- **命门1 — 利润下行的"性质"：主动投入期 vs 增长见顶？**（置信度：**中**）
  - 净利润 FY2025 -12%、Q1'26 -15%（`[mat-a3b032]`/`[mat-641651]`）。若是管理层主动投入生态/供应链（利润可恢复弹性）→ 深度价值成立；若是增长见顶+竞争挤压（利润持续下台阶）→ 价值陷阱。**财报上两者难分**——这是整个 thesis 成败的总开关。对应 K1/K5。
  - → 需砸料：take-rate 拆解、销售费用/履约成本结构、国内 vs Temu 利润归因、管理层投入项目 ROI 线索。

- **命门2 — Temu 在监管新常态下是"增长期权"还是"持续亏损拖累"？**（置信度：**低** ⚠️ 优先砸料）
  - de minimis 终止后美国日活 -58%（`[mat-8231b1]`），半托管/本地履约重构单位经济（`[mat-2e4344]`/`[mat-37c676]`）。公司**不单独披露 Temu 财务** → 盈利路径/减亏信号是最大黑箱。对应 K2/K3。
  - → 需砸料：第三方 Temu GMV/MAU 估算、半托管 take-rate、非美市场（欧洲/拉美）扩张数据、监管时间线。

- **命门3 — 资本配置是否转向系统性股东回报？**（置信度：**低/uncertain** ⚠️ 优先砸料）
  - 巨额现金 + buyback ratio 0.12 信号待核（`[mat-f8c99f]`）。PDD 历史零分红/零回购、治理保守。若 FY2026 首次系统性回购/分红 = re-rating 开关（K4 触发加仓）；不确定性极高。对应 K4。
  - → 需砸料：历次财报回购授权/执行、管理层资本配置表态、现金/等价物余额与用途。

## 二、每环 B 靶点（A 合同地板之上的命门特化补充）

- **环① 理解闸门（三梁：钱怎么来/管理层/张力）**：B靶点 = ①国内 vs Temu 收入与利润归因拆解（命门1）；②管理层资本配置史 + 黄峥治理文化对披露/回报的影响（命门3，对应 hard 类 `mgmt-capital-alloc`）。
- **环② 定价锚（估值）**：B靶点 = ①当前 forward PE/PS/EV-EBIT + 市场隐含增长率与 Temu 估值占比（命门1/2）；②卖方/买方一致预期锚（hard 类 `consensus`，分析师公允价 ~$110-118 待落实区间与分歧点）。
- **环③ WMBT（这个价需要什么为真）**：B靶点 = 拆出"市场当前价隐含的利润率/增速假设"，对照命门1的利润见底判断（What-Must-Be-True 咬命门1）。
- **环④ 下注（edge 收口）**：B靶点 = 把"我 vs 市场已定价数"的 delta 落在命门1（利润弹性）+ 命门2（Temu 期权价值）两条 driver 上。
- **环⑤ 证伪机制**：B靶点 = ①历史镜鉴（hard 类 `historical-mirror`——增长股利润见顶后的价值陷阱案例，如早期阿里/eBay/Wish 出海失败）；②命门2 Temu 持续亏损的早期预警指标。
- **环⑥ 行动**：B靶点 = 把 K1-K5 翻成可监控的加仓/减仓触发器（命门验证时点 → 仓位映射）。

## 三、primer 入门目标 v0（种子 · 喂 primer · 非定稿）

门外人为投资读完本 topic 应能做到（标置信度/缺口 tag）：

1. 用一句话说清 PDD 的两个引擎（国内拼多多 + Temu）各自怎么赚钱/烧钱（高）
2. 解释"全托管 vs 半托管"模式差异及其对单位经济的影响（中，需收背景料）
3. 说清 de minimis 是什么、为何终止、对 Temu 的具体冲击链条（高，已有 prescan 料）
4. 看懂 PDD 财报关键行：营收结构（在线营销 vs 交易服务）、净利率趋势（高）
5. 解释拼多多"低价心智 + 农产品 + 拼团"护城河及其被对标的程度（中）
6. 说出国内电商竞争格局：拼多多 vs 阿里 vs 京东 vs 抖音的相对位（中，需收份额料）
7. 理解 VIE 架构 + 中概 PCAOB/退市折价为何压估值（中）
8. 解释为何 PDD 是"高增长(曾) + 低 PE"——多空在争什么（深度价值 vs 价值陷阱）（高）
9. 说清黄峥/联席 CEO 治理文化对信息披露与资本配置的影响（中，需收 mgmt 料）
10. 看懂 EU DSA / UFLPA / 各国监管对跨境电商的约束逻辑（中，部分已有料）
11. 用估值原型框架（成熟现金流 vs 高增长）给 PDD 选对估值模型（中，喂环②）
12. 说出 3 个会改变 PDD 投资判断的可观测信号（K# 通俗版）（高）
