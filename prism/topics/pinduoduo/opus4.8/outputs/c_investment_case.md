## 环③ 这个价需要什么为真？（What-Must-Be-True）

要让 $86 是"合理价"（而非错杀），以下假设须**同时**为真（按对定价杠杆排序）：

1. **【国内利润持续下台阶】** 净利润不是单年回调，而是结构性下行（连续多季降幅不收窄、且营业利润也转弱）——对应命门 1 的空头侧。**当前证据：弱**（Q1'26 营业利润 +22%、营业利润率升至 18.4%、营销仅 +1.2%；净利 -15% 经逐行拆解几乎全因线下项 [mat-98af66]——见环④逐行证伪）。
2. **【Temu 价值 ≈ 0 或负】** Temu 在 de minimis 后无法走通单位经济、长期烧钱拖累集团。**当前证据：中（本轮升级）**——后 de-minimis GMV-20~30%、US MAU-46% [mat-f5c8be/ec51dd/71d11f] 支持"收缩"；但集团合并口径 Q1'26 营业利润仍 +22%，说明 Temu 拖累**正被国内强势吸收**（见环④反证）。
3. **【现金永不回报 + 折价永久】** 零回购零分红持续 + 中概/治理折价不收敛。**当前证据：中-强**（历史零回报 + 治理锁死 + 1/4 现金受限支持；但 VIE 占比降至 13.1%、HFCA 风险缓解是反向 [mat-413cbf]）。
4. **【国内份额系统性流失】** 在阿里/抖音夹击下份额持续掉。**当前证据：弱/数据缺失**（一手无第三方份额料；在线营销 +2.5% 近熄火是间接担忧信号，K5 待补）。

**缝合**：4 条里第 3 条证据最实、第 2 条本轮升到"中"、第 1/4 条一手证据仍偏弱——**市场的悲观定价建立在"难分/部分不可证"的假设上**，这是 edge 的来源；但 edge 比 v1 略薄（Temu 不再贡献正期权）。

## 环④ 我信哪边，凭什么？（下注 + EV 加总）

### 核心分歧一句话（锚回环②的数）
〔图例：各档为「概率 / 相对现价回报」〕
**市场在价里写的是"国内 ~5–6x 衰退 + Temu = 0"；我判断国内不是衰退而是高质量减速（营业利润 +22%、ROIC 18%），Temu 则确是收缩中的拖累、但被国内吸收。** delta 主要踩在 **driver A**：
- **driver A（国内利润性质）— 本轮一手逐行证实，反方致命一击被证伪**：
  - 反方致命一击：「营业利润+22% 同时营销仅+1.2%，对靠补贴维持低价的平台不自洽——补贴必是被重分类出营业利润线，+22% 是会计幻觉」。
  - **逐行反驳 [mat-98af66]**：营业利润口径**本就包含营业成本（COGS）**——补贴/履约/带宽/支付费都落 COGS。事实是 **COGS +15%（>收入+11%）、毛利率压缩 1.5pct 至 55.8%**：补贴/履约成本压力**真实存在且如实进了营业利润线**，没有被藏。营业利润 +22% 的来源是：毛利 +8.2% × 营销费用 held-flat(+1.2%) 的**经营杠杆**（销售营销是最大单项 opex，占收入约 32%）。即"营业利润+22%"是真经营改善，**不是腾挪**。
  - **保留的残核（诚实）**：① 毛利率压缩 1.5pct = 低价补贴在 COGS 端的真实代价，若加速则经营杠杆会反噬；② 营销零增长撑住利润的另一面——**若是以丢份额为代价（在线营销收入仅 +2.5%），则不可持续**（K5 数据缺失，列环⑤盯）。
  - 结论：**我更乐观，且本轮证据从"单季疑点"升为"逐行证实"**——这是强化项。
- **driver B（Temu）— 从"免费期权"降级为"模糊拖累"**：v1 当它免费 upside skew；本轮 web 料显示后 de-minimis Temu 主动收缩（全托管腰斩、GMV-20~30%、US MAU-46%、半托管广告弱 [mat-f5c8be/ec51dd/71d11f]）。**反证反方"Temu 亏损掩盖国内、故 4x 是假象"**：集团合并 Q1'26 营业利润仍 +22%、毛利率仅压 1.5pct——Temu 拖累已被国内强势覆盖，国内 ex-Temu 只会更赚钱（4x 若有偏差是偏**低估**国内）。**处理：上行不计入（不再给正期权）、下行只当国内的从属拖累**——driver B 在 EV 两侧都不再是主下注理由。

### 已知风险 + 盲点风险
- **已知**：国内价格战无终局（阿里/抖音持续掠夺）→ take-rate/毛利率被压（Q1'26 毛利率已 -1.5pct 是早期读数）；Temu 监管未见顶（de minimis 全球 2025-08-29 落地后欧盟扩限/各国执法仍推进 [mat-71d11f]）。
- **盲点**：① **国内份额是否在以"营销零增长"换取**——营业利润 +22% 若实为"少花获客费、默许份额流失"换来，则不可持续（K5 一手缺失，最大盲点）；② **Q1'26"其他损益/投资损失"构成不明**（-RMB20 亿，YoY 逆转 -53 亿 [mat-98af66]），若是经常性减值则净利质量更差、driver A 的"会计波动"解释打折；③ Temu 收缩若从"减亏式收缩"变"失血式收缩"（半托管也走不通），则从次要拖累升为主拖累。

### 历史失败镜鉴（≥2 · 本轮 Wish 升为一手）
1. **Wish / ContextLogic（跨境低价直邮鼻祖）〔本轮一手化〕**：收入 $2.5B(2020)→$571M(2022, **-73%**)、2022 亏损扩至 $288M，2024 以 **$173M 售予 Qoo10** 近清算 [mat-2efcec][mat-89ceb2]。失败模式=低价直邮在**履约时延/不可靠 + 假货致信任崩 + 复购下滑**下单位经济击穿，法国 2021 下架、Temu/Shein 抢走低价份额与营销 [mat-e53070]。最早预警=履约投诉+退货率上升+复购下滑。**对位本 case**：Temu 后 de-minimis 的 US MAU-46%、净值评分下滑 [mat-f5c8be] 是同类早期信号 → **盯 Temu 留存/复购**，这是 driver B 下行的真实路径。
2. **阿里 2021–2024（中概价值陷阱）〔训练知识〕**：低 PE 有**制度性原因（监管+治理+增长见顶）不收敛**，"便宜很久"；峰谷 **−70%+**、多年不反弹。教训=**中概低 PE ≠ 安全边际**，需催化才收敛 → 直接命中本 case 横盘价值陷阱情形（27%），也是本轮上调该档权重的依据。
3. **（双向镜鉴）Meta 2022→2023〔训练知识〕**：利润首降时市场杀估值，但若是**主动投入**则可强反转（一年翻倍）。教训=利润性质判对了赔率极佳 → 支撑 driver A 的下注逻辑（本轮 driver A 已一手证实，此镜鉴权重提升）。

### Kill 触发（可观测）
- **K1-kill（盯 driver A 真命门 = 营业利润，非净利）**：连续两季**营业利润同比转负、或增速跌破个位数**（剔除线下投资/汇兑项）→ driver A 证伪、确认主业失速/价值陷阱，下调强度。**新增辅助阈值**：若营业利润维持增长但**毛利率连续两季再压 >1pct/季 或 在线营销收入转负**（份额流失实锤）→ 同样触发 driver A 残核 #1，降档。（净利润同比降幅仅作辅助参考——含线下项波动，不作主 kill。）
- **K2-kill**：可靠第三方显示 Temu 整体 GMV 持续下滑**且半托管单位经济也走不通/亏损扩大** → 从次要拖累升为主拖累。
- **K3-kill**：新增重大监管打击（欧盟扩大限制 / 美国进一步关税合规壁垒）。

### Signpost（3–12 月）
- 下一季报（~2026-08）：营业利润是否延续两位数增长、**毛利率是否企稳**（验 driver A 残核）、在线营销收入是否回正（验份额）、净利降幅是否收窄。
- 是否首次**系统性回购/分红**公告（命门3 re-rate 开关）。
- Temu 第三方 GMV/MAU/留存月度数据 + 半托管单位经济（补黑箱、验 driver B 是减亏式还是失血式收缩）。
- Q1'26"其他损益"构成披露（电话会/年报）——验净利质量。

### 什么会让我改主意
- **上修**：首次系统性回购/分红（→ 强度 7+，升档）；连续两季营业利润企稳 + 毛利率企稳 + 在线营销回正（命门1 + 份额双确认多）；Temu 出现可信减亏（半托管单位经济跑通）。
