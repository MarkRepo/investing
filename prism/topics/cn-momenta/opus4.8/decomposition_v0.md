# decomposition_v0 — Momenta 魔门塔

> 薄拆解（基于 thesis_v0 + K# + baseline §六 prescan 校准）。v0 不做 critic，只置信度 tag + 机械自检。深度版留 04。

## 一、命门 1-3（机理/兑现路径上方向错了就翻盘）

- **命门1 = 软件授权高毛利的可持续性**（置信度：**中**）
  机理：71.6% 毛利率是"卖算法"而非"卖硬件"的体现。若智驾平权价格战 + 客户压价使毛利结构性下行（跌破 ~65%），则"SaaS 式经营杠杆 → 盈亏平衡 → 高估值"的整条链断裂。决定 K1、直接喂估值。

- **命门2 = 第三方供应商模式 vs 头部客户自研的长期均衡**（置信度：**uncertain**）
  兑现路径：客户既是金主又是潜在竞争者（比亚迪天神之眼/上汽/通用自研）。若头部 OEM 掌握数据后转自研，Momenta 的 TAM 被压到中腰部，增长天花板远低于叙事。短期"两条腿走路"缓冲是真是假，决定 K2/K3。**置信度低 → 01/02 优先砸料。**

- **命门3 = IPO 估值隐含假设能否被业绩兑现路径支撑**（置信度：**中**）
  机理：$9bn/约 650 亿 RMB 招股估值隐含高增速×目标利润率。若实际"增速放缓 + 利润率受命门1压制"，则估值需向下重定价（破发/回调）。决定 K5，是 terminal（目标价/介入）的核心。

## 三、primer 入门目标 v0（理解性/教学性，门外人读完应能做到；非决策性）

1. 说清"第三方智驾供应商" vs "车企自研" vs "华为全栈"三种模式的区别与各自取舍
2. 解释"一个飞轮两条腿"战略：数据飞轮如何运作、两条腿分别指什么
3. 区分 高速NOA / 城市NOA / L2 / L3 / L4 的能力边界与监管含义
4. 说清端到端（end-to-end）大模型架构相对模块化方案的差异
5. 解释为什么"软件授权"模式能有 70%+ 毛利率，及其与硬件 Tier-1 的不同
6. 理解"客户即股东即潜在竞争者"的三重身份张力（为何对供应商既是护城河又是风险）
7. 说清智驾平权（价格下探）对方案商单价与放量的双面影响
8. 区分 Momenta 的量产收入 vs Robotaxi/L4（哪条腿赚钱、哪条烧钱）
9. 解释 Robotaxi 单位经济（cost-per-mile）由哪些成本构成、为何难跑通
10. 理解 IPO 招股/基石投资者/绿鞋/破发 的基本机制（读懂招股结构）
11. 列出评估智驾供应商竞争地位的可观测信号（市占率口径/搭载量/客户数/单月装机）
12. 说清华为"超"地位及车企对华为的"灵魂"忌惮（解释为何中立第三方有生存空间）

> 标缺口需收料：#9 Robotaxi 单位经济（prescan 未深挖，需专项料）；其余训练知识 + 招股书可覆盖。性质全为理解性，无决策性条目（终局决策归 case）。
