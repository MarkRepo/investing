## 环① 看懂并信得过这家公司（理解闸门 · 三梁）

> **决策速写**（背景详见 primer §1/5/6）：Momenta 是中国最大的第三方城市 NOA 算法供应商，靠"NRE 工程费 + 量产按车许可费"赚钱。**钱怎么来 + 哪个张力直接砸估值——只讲这两点。**

### 梁 1：生意与护城河

**一句话生意**：把高阶智驾算法卖给车厂，量产后按车收许可费——这是一门正从"项目制"转向"软件 License"的生意。

**收入拆解（量×价×结构，2025）**[mat-aa82d8]：
- 营收 24.13 亿 RMB，其中**许可收入占比 40.1%**（2023 仅 3.1%）、NRE 占 59.9%。
- 量：累计装机 >73.3 万辆（2026-02），SOP 车型 68 款、累计定点 180 款。
- 价：单车许可费千元级（被价格战从早期数千元压下来）。
- **驱动估值的就是这条**：许可占比每升一个台阶，毛利率就跳一级（17.5%→49%→71.6%），因为 COGS 三年只 +1.6%。

**护城河——类型与方向判断**：
- 类型 = 数据飞轮（量产数据反哺端到端模型）+ 多芯片适配工程能力 + 中立性（不像华为会下场抢车厂生意）+ 客户股东绑定。
- **方向 = 正在变弱**。理由：①只输出上层算法、不掌芯片、无生态，可替换性高 [mat-1f931d]；②头部客户（比亚迪/上汽/通用）在自研，学会即可替换；③份额月度高波动（元戎单月能冲 38% [mat-f997d9]）说明壁垒不深。这是一条"窗口正在关闭"的浅护城河——**这就是直接砸估值的核心张力**。

**单位经济（取最关键的毛利率）**：综合毛利率 71.6%，对照硬件 Tier-1（15-25%）是真高，但对照"纯软件授权"（地平线该档 94.5%）则偏低、暗示含硬件/集成杂质 [mat-320b95]。经调整亏损率已收窄到 -12.6%，逼近平衡。

### 梁 2：管理层与资本配置

- **谁掌舵**：曹旭东（清华→微软亚研→商汤→2016 创立 Momenta）[mat-264896]。技术血统强，战略定力可见——"一个飞轮两条腿"自创业延续至今、多次访谈口径一致 [mat-62846c]；公开给过可证伪预测（"2026 年只剩 3 家"[mat-48a1d3]），属可回测的 track-record 锚点。
- **资本配置记录**：历轮融资约 25 亿美元（C 系列累计破 10 亿）[mat-1f931d]；烧钱纪律改善（经营现金流出 -10.69→-2.81 亿）。IPO 募资用途：**60% 研发（其中 40% 算力+数据存储）、20% L4 车队、10% 量产、10% 营运** [mat-aa82d8]——即把最大一笔押在"算力+数据"飞轮、第二笔押 L4 期权。这是"赌飞轮和期权"而非"补当期量产"的配置，与高增长叙事一致，但也意味着盈利兑现要再等。
- **激励对齐 / 治理**：WVR 双重股权——曹旭东经济权益仅 **14.85%**、投票权 **59.85%** [mat-aa82d8]。**这是治理风险（与环⑤呼应）**：小股东话语权弱，且"客户即股东"结构下，股东车厂的利益与小股东未必一致。
- **一句话评**：技术型创始人、战略稳、烧钱纪律在改善——**值得托付，但 WVR + 客户股东冲突要求对治理保持警觉**，不是无条件信任。

### 2.2 估值原型 → 三模型独立估值

**估值原型**：高 P/S 成长/概念股 + L4 期权成分（未盈利、营收高增、部分价值来自尚未兑现的 Robotaxi 期权）。判断依据：无 PE 可用、增速是核心矛盾、L4 是显性期权。

**选用模型**：
- **模型 F 同业 P/S 横截面**（有地平线/Mobileye/Pony/WeRide 可比 + 私募阶梯，最适合）
- **模型 B 基本盘 + L4 期权拆解**（量产 L2+ 基本盘 + L4 期权显性，契合原型）
- **模型 A 逆向 P/S-增速反推**（反推现价隐含的营收 CAGR，校验可达性）

**模型 F — 同业 P/S 横截面**（折成 HKD 价，offer 295.6 = 25.0x trailing）：
- 主锚 = 地平线 **13.7x**（最贴近的已上市量产可比，软硬一体）；Mobileye 3.5x（成熟态地板）；Pony 27x、WRD 17.6x 均薄营收失真、剔除。
- Momenta 较地平线给增长溢价（+82% vs +58%、纯软件），扣可替换性 + 规模小 + 未上市流动性折价 → 公允 **base ~14-18x**。
- Bull（板块 re-rate + AI 溢价 24-28x，注意 peer 现贴 52w 低、有均值回归可能）：**265-310**；Base（14-18x）：**155-200**；Bear（向 Mobileye/Tier-1 8-12x）：**88-132**。
- ⚠️ 结论：**offer 295.6 已显著高于 base 上沿（200）**，逼近 bull 区间——定价偏满。

**模型 B — 基本盘 + L4 期权拆解**（基本盘倍数随板块下修）：
- 基本盘（量产 L2+）按 ~13-16x forward P/S（跟随 derate 后的软件 Tier-1）× 2026E 营收 → HKD 190-230 等值。
- 当前市值 US$8.9bn − 基本盘 ≈ **US$1.5-2.5bn 为市场隐含的 L4 期权定价**（基本盘倍数降后，残值更多归到 L4 期权——意味市场给 L4 的隐含定价更贵）。
- 我的 L4 NPV 估算：Robotaxi 收入 immaterial + 全行业纯 L4 烧钱史几乎全败 [mat-12eadb]，概率加权 NPV 偏低（US$0.5-1.5bn）→ **L4 现被高估，基本盘+被高估的期权共同撑着 offer**。
- Bull：**280-340**；Base：**190-230**；Bear：**130-170**。

**模型 A — 逆向 P/S-增速反推**：
- 现价隐含 **2025→2028 营收 CAGR 约 38%**（才能降档到 ~10-12x 可持续 P/S）+ 毛利率守 65%+；退出倍数地板实（连当前地平线都才 13.7x），现价兑现要求苛刻。
- 可达性判断：40% 三年 CAGR 在"智驾平权放量"下并非不可能，但叠加单价被压 + 头部客户自研分流，**我判实际更可能 ~30%**（见环④）。
- 折成价：可达增速（~30-35%）对应 Base **200-250**；超预期（>45% 持续 + 板块 re-rate）Bull **300-350**；低于 25% Bear **130-180**。

> **EV 稳健性**：EV 现稳定为负——即便中性档回到持平（+0%）、EV 仍约 −3.5%；要 EV 转正需中性档 +8% 以上（目标价 >300），而那要求板块明显 re-rate（peer 现贴 52w 低，非不可能但非 base case）。**负 EV 不脆——它需要一个偏乐观的板块假设才翻正。**
>
> EV→仓位：负 EV + 信息不足 → **现价连试探档都建议暂缓，等回调进 accumulate 区或财报验证再启动**（见环⑥）。

### 4.4 我的判断 + 信心度

- **判断**：中性偏多的**质地**，但招股价**偏满（EV −6%）**——**现价不参与 IPO；等回调进 accumulate（150-200）或上市后财报验证（毛利守 65% + 客户无切换）再启动试探/主仓**。
- **信心度：中**。质地（龙头 + 高毛利 + 逼近平衡）证据扎实（招股书硬数据），估值偏满经实时 peer 校准后确凿；但终局两处仍偏定性——命门 2（客户自研）uncertain、L4 单位经济数据薄；正式卖方首覆 pre-IPO 无源（已 waive，上市后监控补）。

## 环⑤ 如果错了会怎样、怎么第一时间知道（证伪机制）

### 5.1 已知风险 + 盲点风险

- **已知风险**：①毛利率回落（命门 1）——单价压缩 + 比亚迪系压价；②客户切自研（命门 2）——绑定越深反转损失越大；③破发（命门 3）——一二级价差仅 44%、缓冲薄 + 逆市 [mat-9a58a9]；④WVR 治理——小股东话语权弱、客户股东利益冲突。
- **盲点风险**：①**收入质量**——近 60% 仍是项目制 NRE（不可持续、毛利低）[mat-9a58a9]，"软件化"程度可能被高估；②**毛利率口径杂质**——71.6% 含多少硬件/集成成分未拆分，纯软件成色存疑 [mat-320b95]；③**安全事故黑天鹅**——一次重大智驾事故可击穿整个行业估值（参 Cruise 吊照 [mat-12eadb]）；④**单一客户脉冲**——最大客户比亚迪系 21.6%，若其智驾策略转向，营收波动剧烈。

### 5.2 历史失败镜鉴（≥2，相似剧本怎么崩）

1. **Mobileye**（独立方案商被取代+估值崩）[mat-657deb]：失败模式=**竞争击穿/可替换性**。软硬一体、芯片护城河最深的它，2024 仍净亏 31 亿、市值从 500 亿+ 腰斩到 ~300 亿。**峰谷损失 ~40-60%**。当年最早预警=营收增速放缓 + 大客户流失 + 减值。**现在是否已现？** 部分——Momenta 单价压缩 + 客户自研苗头已现，但营收仍高增、未到减值阶段。教训：**纯算法可替换性高，即便有芯片也难逃商品化压力**——纯软件的 Momenta 风险更高。

2. **Argo / Cruise / Uber ATG**（纯 L4 全败）[mat-12eadb]：失败模式=**现金流断裂 + 主机厂耐心耗尽**。烧 36/100/数十亿，L4 一延期主机厂即瞬间撤资；一次事故清零运营许可（Cruise）。**峰谷损失=归零**。预警=商用目标反复延期 + 主机厂表态转向 L2+。**现在是否已现？** L4 行业普遍未跑通（小马/文远 Robotaxi 收入仍 immaterial [mat-36233b, mat-478b0c]）。教训：**Momenta L4 期权应低权重；股东 OEM（上汽/通用/奔驰）可复刻"瞬间撤资"**。

3. **小马/文远上市破发**（同业估值镜鉴）[mat-690006, mat-986f3c]：失败模式=**薄营收+深亏损+高倍数定价脆弱**。营收 0.9-1.0 亿美元、经调整亏损扩大、上市即破发。教训：**二级市场不为情怀买单，Momenta 同类定价首日破发是 base-case 风险之一。**

> ⚠️ 只想得到成功案例是 red flag——以上全是失败镜鉴，对照检查 Momenta 当前所处位置。

### 5.3 kill 触发 + signpost（喂 sidecar）

**kill 触发条件**（具体、可观测）：
- **K-margin**：上市后首份财报（2026 中报/Q3）混合毛利率**跌破 60%** → 命门 1 破，bear。
- **K-customer**：前五大某客户（尤其比亚迪系/上汽）公开切自研或订单绝对额显著下滑 → 命门 2 破，bear。**A3 是③里最弱的假设（弱/uncertain）、又是④下注的核心 delta 证据，故证伪点必须前置**：首查点拉到 2026 下半年比亚迪 B 平台动向 + 2026 中报客户集中度，不等到 2027（sidecar K-customer check_at 已设 2026-Q4）。
- **K-share**：第三方城市 NOA 份额（中汽协口径）**跌破 50%** → bear。
- **K-valuation（bull entry）**：股价回调进 accumulate（150-200，对应 ~13-17x P/S、贴近已 derate 的地平线 13.7x）且基本面无恶化 → 介入纪律触发、赔率转正。
- **K-bull-upgrade**：毛利率守 65%+ **且** 大客户加单/新增头部定点 → 上修 thesis、可升档。

**signpost**（未来 3-12 月验证事件）：见 sidecar `signposts`——上市首日（破发否）、2026Q3 首份中报（毛利率/许可占比）、比亚迪 B 平台动向、2026Q4 中汽协份额、2027 L4 阿布扎比/慕尼黑商业化。

### 5.4 macro 横切（regime v2，定性）

[macro_stamp 已落 · provisional] 当前体制对本标的**偏逆风**：美 10Y 实际利率 2.2% 高位 = 高久期/pre-profit 成长估值的硬天花板；risk-on 但脆弱 + CAPE 39.4 → 反转时投机标的先被杀、放大破发；恒科逆风 + 智驾被资本冷落 [mat-9a58a9]。薄顺风：人民币企稳 + 外资回流利港股流动性与外资基石认购。**含义**：宏观给的是"破发风险的放大器 + 估值分母的压制"，强化"等回调"的纪律。
