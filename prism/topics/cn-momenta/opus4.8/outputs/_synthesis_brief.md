## K1-K5 v0→v1 强度调整

- **K1（毛利率守 ≥65%）**：v0 中 → v1 **中性偏多但有明确下行机制**。71.6% 毛利率经招股书硬数据验证为真（非媒体质疑的"偏低"），且 COGS 不随收入增长是结构性的；但许可单价压缩 + 比亚迪系压价是真实悬顶。验证点 = 上市后首份财报混合毛利率。
- **K2（客户切自研）**：v0 uncertain → v1 **uncertain，慢性失血确认存在但当期未爆发**。前五大占比 62.6%（逐年降，2023 86.7%）= 客户多元化在改善 vs 单一最大客户（比亚迪系 21.6%）跃升的集中度回升并存。比亚迪 B 平台"短期仍合作"措辞 = 替换路线图风险已具名但未启动。
- **K3（第三方份额守 ≥50%）**：v0 中 → v1 **口径依赖性确认为命门本身**。独立方案商口径 Momenta 64.5%（第一）；但全市场口径车企自研 78.3% 主导、华为(含五界)压制高价带。元戎单月可冲 38% → 份额月度高波动、护城河不深。
- **K4（L4 单位经济）**：v0 边 → v1 **纯期权，证据偏薄（depth 降级）**。招股书 Robotaxi 收入 immaterial、定性无量化；外部 cost-per-mile 仅 Tesla $0.18 目标 snippet（无拆解）；同业 WeRide/Pony 车队规模有数但 cost-per-mile 全缺、调整后净亏反而扩大。按 option value 低权重计价。
- **K5（破发/估值兑现）**：v0 中 → v1 **终局核心、赔率取决于入场点**。三套对标给三种结论（vs Mobileye 显贵 / vs 地平线相当 / vs AI 基座显便宜）；同业 WRD/Pony 首日破发先例；恒科逆风 + NOA 渗透率 2026Q1 环比回落（36%→32%）。
