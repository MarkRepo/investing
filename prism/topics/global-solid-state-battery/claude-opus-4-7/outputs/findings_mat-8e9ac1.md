## 叙事主线

K3 辅料端无独立"全固态专用"SKU——铜铝箔、PVDF、CMC、SBR、SP、NMP 全部沿用液态体系报价。这反映：(1) 全固态电池在辅料/集流体端不需要全新供应链，可复用现有液态体系产能；(2) K3 路线分化（硫化物 vs 氧化物）对辅料的影响主要体现在工艺端（如硫化物需干法工艺替代 NMP 湿法）而非物料端；(3) 这是 SSB 商业化的一个**结构性优势**——一旦电芯/电解质成本下降，辅料供应链已具备 GWh 级承接能力，不会成为产能瓶颈。

特别值得注意：**SMM 一水葡萄糖 + PEG** 出现在全固态其他材料板下，对应硅碳负极的碳源（葡萄糖热解）/ 复合电极的粘结剂（PEG），暗示 SMM 正在为"硅碳负极 + 全固态"的下一代复合方案做报价池准备。

## 反常识/分歧点

1. **国产 PVDF 118000 vs 进口 191000，价差 38%**——国产 PVDF（液态体系主粘结剂）已替代到接近成熟阶段，意味着 SSB 商业化时国产辅料供应链不会构成成本瓶颈。
2. **NMP -150（唯一下跌）vs 全表 0 涨跌**——NMP 是液态体系 PVDF 浆料的标准溶剂。如果 K3 硫化物全固态采用干法电极工艺（无溶剂），NMP 需求将下降，预示干法工艺已开始挤压传统湿法溶剂市场。
3. **4.5μm 极薄铜箔加工费 26000 vs 6μm 主流 20000，溢价 30%**——SSB 端（特别是锂金属负极配套）需要更薄的铜箔以提升能量密度，30% 加工溢价是 K3 在集流体端的可承受改造成本。
4. **本表 12 行无"固态电池专用粘结剂/导电剂"独立 SKU**——再次验证 mat-89797a 和 mat-3e0561 的判断：SSB 产业化 2026-05 时点仍处于"复用液态体系辅料 + 微改电解质 + 微改正负极"阶段，未形成独立物料品类。距离全栈定制化（fully customized BOM）至少还需 2-3 年。
