# 07 决策套件 — 全球固态电池（v0 校准后）

## 1. 一页纸摘要

**研究问题**：在全固态电池产业化（2027–2030）的窗口里，哪些资产真正受益，哪些只是叙事？

- **生意本质**：固态电池是动力电池下一代工艺平台，护城河从"化学体系"转移到"制造工艺 + 设备 + 关键材料"，赢家不在话题度最高的位置。
- **周期定位**：产业资本周期上行（出货 5 GWh→2030E 610 GWh，CAGR 80%+），但情绪周期已处于"叙事高潮"末段，2026–2027 进入"路线分化 + 时间表延期"扰动期，方向向上、节奏震荡，置信度中等。
- **叙事对照**：主流叙事是"全固态 = 电芯厂赢家通吃"，部分认同；我的判断是路线胜负未定（硫化物 vs 氧化物 vs 半固态共存到 2030+），**电芯厂之间会被洗牌，设备 + 材料卖铲人是路线无关的赢家**。
- **隐含预期**：QS/SLDP 隐含 2027 SOP 兑现 + 40 GWh 量产，偏乐观；A 股半固态概念（卫蓝/清陶链）隐含 2030 渗透率 ≥10%，偏乐观；先导/璞泰来当前估值隐含半固态停滞 + 全固态延期，偏悲观——错位在卖铲人。
- **类比**：最像 2014–2018 年的锂电设备 + 隔膜行情（先导从 30 亿涨到 800 亿），教训是"赢家是给所有人卖工具的人，不是押单一路线的电芯"。
- **核心风险**：已知最大风险——液态 LFP 降到 0.2 元/Wh 让固态在乘用车失去经济性（K2）；最大盲点——硫化物干法电极工艺被日韩率先突破，氧化物路线（中国主流）被边缘化（K3）。

| KQ | 翻盘信号（看空转看多 / 看多转看空） | 加仓信号 | 减仓 / Kill 信号 |

## 6. 核心假设清单（What Would Have To Be True）

1. 全固态 2027–2030 进入"小批量上车 → 量产爬坡"，渗透率 2030 至少 5%（GGII 中性口径减半）
2. 半固态 2026–2030 装车放量到 100+ GWh，过渡期至少 5 年（给卖铲人留 5 年订单窗口）
3. 中国氧化物路线不被硫化物路线全面挤出（K3 不发生最坏情形）
4. LFP 电芯报价底部不破 0.25 元/Wh（K2 不发生最坏情形）
5. 头部车厂自研全固态最终仍要外采 80%+ 产能（CATL/LG 制造护城河成立）

任一假设证伪 → 立即重评 Tier 1/2 仓位。
