## 叙事主线

K3 负极替换成本测算：液态高端动力人造石墨 33900 元/吨 ≈ 33.9 元/kg vs mat-3e0561 电池级金属锂 1215000 元/吨 ≈ 1215 元/kg，价差 35.8 倍。全固态电池若锁定锂金属负极路线，单位重量物料成本是石墨的 36 倍。但锂金属理论比容量 3860mAh/g vs 石墨 355mAh/g（10.9 倍），按比容量等效后单 Ah 成本差距约 3.3 倍——这是 K3 锂金属负极路线的真实成本劣势。

K2 硅碳路径侧翼威胁：沉积法硅碳负极（生物基）300000 元/吨 + 1650mAh/g 提供高能量密度（比石墨 4.6 倍），是 SSB 商业化前最强的液态体系竞争者。但其价格是高端石墨的 8.85 倍，决定了硅碳只能作为掺杂（5-15% 比例）使用，对液态电芯成本拉升约 +5-10%——这进一步推迟 K2 阈值 0.2 元/Wh 的兑现，但同时也是液态体系延伸到 300Wh/kg+ 的工程化路径。

## 反常识/分歧点

1. 沉积法硅碳负极树脂基 535000 vs 生物基 300000，价差 78%——生物基（基于生物质碳源）已比树脂基便宜近一半，硅碳量产降本可能比预期快，进一步压缩 SSB 的"高能量密度独占性"。
2. 高端消费石墨 51850 元/吨 ≈ 高端动力石墨 33900 元/吨 的 1.53 倍。消费电子（手机/穿戴）已经在为高 C 倍率支付溢价，若 SSB 切入消费电子赛道，负极端不会构成成本障碍。
3. 石墨化加工费 7600-9700 元/吨 ≈ 高端动力石墨售价 33900 的 22-29%。负极成本中加工费占比已经压缩到极限，K3 锂金属负极若想商业化必须从 BOM 端（金属锂 1215 元/kg）整体下行，而不是工艺降本。
4. 油系针状焦熟焦 8465 元/吨 涨跌 0 vs 石油焦高硫焦 1925 元/吨 -25——上游原料分化加剧，高品质针状焦（负极原料）已脱离石油焦周期，独立定价，对 K2 LFP 进一步降本贡献有限。
