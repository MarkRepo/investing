## 叙事主线

K3 电解质替换成本测算：液态电解液铁锂储能用 26300 元/吨 ≈ 26.3 元/kg。对比 mat-82e36a：氧化物 LATP 98 元/kg 是液态电解液的 3.7 倍，硫化物 LPSC 8000 元/kg 是液态电解液的 304 倍。意味着：(1) 氧化物 LATP 路线的电解质 BOM 涨幅可被电芯成本下行吸收（若液态 LFP 174Ah 持续 0.39 元/Wh，氧化物 SSB 在 0.50-0.55 元/Wh 区间可形成商业化窗口）；(2) 硫化物路线在当前物料价格下不存在任何商业可行性。

K2 液态电解液降本几乎到底：本周几乎所有溶剂 + 主盐 0 涨跌，唯一变化是 EC -300（-4.5%），而六氟磷酸锂反向 +500，电解液端已到达"原料波动 = 加工成本"的反内卷地板价。新一代主盐 LiFSI 149500 元/吨（vs LiPF6 113000，溢价 +32%）开始替代渗透。

## 反常识/分歧点

1. 六氟磷酸锂 +500 vs 碳酸锂 -5000 强反向：六氟主盐价格已与锂盐脱钩，液态电解液端不会再为 K2 的"LFP 跌破 0.2 元/Wh"贡献降本动力。
2. 氧化物 LATP 98 元/kg vs 液态电解液 26 元/kg 价差 3.7 倍，远小于硫化物的 304 倍。LATP 用量约液态电解液 70-80%，对应 BOM 端净增本约 +200%——氧化物半固态对 BOM 的拖累约 2-3x，需用高镍/锂金属负极的能量密度提升来摊薄。
3. 钴酸锂 4.5V+ 电解液 49000 元/吨 ≈ LATP 98 元/kg 的 50%。消费电子高电压液态电解液的物料成本已接近 LATP 半固态，消费电子端可能成为氧化物半固态 SSB 最早落地的细分。
4. FEC 54000 元/吨 0 涨跌——硅基负极 + 液态电解液的能量密度提升路径仍是 SSB 主要液态竞争者，但需配合 mat-cb6399 中沉积法硅碳 300000-535000 元/吨的高成本。
