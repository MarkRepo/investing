# 全球固态电池行业 → 细分 Arena 选拔

> 来源：01_panorama / 02_cycle / 03_narrative / 04_implied / 06_risk / 07_decision_kit + 26 份 findings；训练知识占比 ~30%

## 摘要

固态电池的"行业"叙事过于粗放——市场把"电芯赢家通吃"作为底层假设定价，但 04 隐含预期 + 07 决策套件已得出"卖铲人 + 看空已 price-in 电芯"的两段结论。本 workflow 把行业拆成 **6 个 arena**，按 6 维度评分后分流：

- **深挖档（3 个）**：固态电池设备链、高镍正极出海、固态电解质材料——三者都是"路线无关 + 估值错位 + 卡点清晰"的卖铲人/材料 arena，对应 07 Tier 1 的核心建仓建议。
- **观察档（2 个）**：半固态电芯装车链、CATL H 股折价——前者等月销/事故数据兑现，后者等全固态期权重新定价。
- **淘汰档（1 个）**：美国全固态纯玩家（QS/SLDP/Factorial）——07 已明确看空 7/10，04 校准"已透支"，无独立深挖价值（保留作为短端反向锚点即可）。

> 锂金属负极+硫化锂上游本可成为第 7 个 arena，但 26 份 findings 中独立资料仅 mat-c660fb / mat-71ce1d 涉及，证据厚度不足，本期合并到"固态电解质材料"arena 一同覆盖。

## 各 arena 评分解读

### 1) 固态电池设备链（先导 / 利元亨 / 海目星 / 纳科诺尔 / 联赢 / 宏工）

- 利润池 3：山西证券测 2030 全球固态设备 1079 亿元（单 GWh 设备价值量从液态 1 亿 → 4-5 亿），当前先导锂电设备 94.7 亿/年。来源：mat-938ef9 + mat-8282a6（先导年报）
- 增速 5：单 GWh 价值量 4-5x 跃升 + 出货 5 GWh → 2030E 610 GWh CAGR 80%+。来源：07_decision_kit §1 + mat-938ef9
- 竞争 4：先导（CR1 ≈ 35%）+ 利元亨/海目星/纳科诺尔次梯队，等静压瑞典 Quintus 独占核心壁垒，国产替代窗口未关。来源：04_implied §D + mat-71ce1d
- 估值 4：先导 PE 隐含 25x、固态收入未单独披露被市场打折；07_decision §2 校准"看多 7/10"。来源：04_implied §C
- 周期 5：从 0 到 1 的招标元年（2026-2027），mat-71ce1d 把利元亨列为"2026 批量进入装车测试"

### 2) 高镍正极出海（容百 / 当升 / 巴莫 / 振华）

- 利润池 4：当升 2025 营收 103.7 亿，容百 2025 营收 122.7 亿；高镍 NCM 单吨 22.46 万元 + 全固态 BOM 溢价 +30%。来源：mat-89797a + mat-cf6e43 + mat-994a6e
- 增速 4：全固态正极 20 吨/10 吨级出货 → 千吨 → 万吨级，CAGR 30%+；同时叠加海外基地（当升芬兰 6 万吨 / 容百韩国 7 万吨）。来源：mat-cf6e43 / mat-994a6e
- 竞争 4：四家寡头（容百 / 当升 / 巴莫 / 振华）+ 全固态高镍当前位列"第一供应商"梯队（容百自述）。来源：mat-994a6e
- 估值 4：当升 PE 15-18x、容百 2025 首亏 PE 失真，"卖铲人 + 海外 + 固态期权"三段未被定价。来源：04_implied §G
- 周期 4：2026-2027 海外基地投产 + 全固态正极放量双驱动；但 PFE / LG 化学诉讼是"政策周期"逆风。来源：06_risk 盲点 #1 #2

### 3) 固态电解质 + 锂金属上游（LPSC / LATP / LLZO + 容百硫化物中试 + 当升氯碘复合 + 出光兴产硫化锂 + 赣锋锂金属）

- 利润池 3：LPSC 当前 8000 元/kg（07 K3 触发位 4000 元/kg），出光兴产 2027 千吨级硫化锂——市场总规模 50-200 亿区间。来源：07_decision §4 K3 + mat-c660fb
- 增速 5：从 0 起步，国产替代叠加全固态需求双驱动，CAGR >50%。来源：mat-c660fb + mat-71ce1d
- 竞争 4：日韩（出光兴产 / 三井金属 / Mitsui）+ 中国（容百硫化物中试 2026H2、当升氯碘复合）双轨；硫化锂前驱体工艺是产业链硬卡点。来源：mat-c660fb + mat-f6cc96
- 估值 4：完全没有独立估值锚（嵌入正极/电芯母公司），市场尚未给独立 SKU 定价。来源：07_decision §2 "SMM 至今未出全固态专用正极/负极独立 SKU"
- 周期 5：研发末期 → 中试初期，2026H2 容百硫化物 + 2027 出光千吨双关键时点；五矿明确把硫化锂列为"全产业链硬卡点"。来源：mat-c660fb + mat-f6cc96

### 4) 半固态电芯装车链（卫蓝-蔚来 / 清陶-智己 / 赣锋-赛力斯 / 东风 E70）

- 利润池 3：2025 装车 31.7 GWh +272%、GGII 2030 预测半固态 420 GWh，但单 Wh 利润 vs 液态压缩。来源：07_decision §2 + mat-71ce1d
- 增速 5：装车增速 +272% 是 04 中最高的硬数据；但持续性存疑（07 校准"中性偏空"）。来源：mat-71ce1d
- 竞争 2：卫蓝/清陶/辉能/赣锋锂电/中汽新能 5+ 家同质化卡位，电芯环节难形成定价权。来源：mat-cf6e43（当升客户名单全覆盖证明同质化）
- 估值 2：A 股半固态概念 2030 渗透率 ≥10% 已 price-in，技术总监已松口"大概率 2030 后"。来源：07_decision §3 Tier 3
- 周期 3：处于"装车 → 月销验证"的关键窗口，但五矿明确"半固态溢价 43% 仅换 +15℃，性价比短期不成立"。来源：mat-f6cc96

### 5) CATL H 股折价 + 全固态期权

- 利润池 5：CATL 2024 营收 3620 亿 / 净利 507 亿 / 净现金 ~2000 亿，全产业链最大利润池。来源：mat-bcf00d
- 增速 2：A 股 PE 反推 3 年 CAGR ~15%，H 股折价后 ~10-12%；液态库存 +51%、产能利用率 76% 拖累。来源：04_implied §E + mat-bcf00d
- 竞争 5：全球电池 CR1 ~35%、CATL 一家说了算；凝聚态/麒麟+硫化物 5 GWh 中试线双路线在手。来源：07_decision §3 Tier 2
- 估值 4：A 股 PE 20x 合理偏低，H 股折价 15-20% + 凝聚态/钠电/海外三个二阶段叙事未在 H 股端定价。来源：04_implied §E
- 周期 2：液态体系自身处于产能过剩 + 价格战阶段，全固态期权 0 定价是"安全垫"但缺少近期催化剂。来源：mat-bcf00d

### 6) 美国全固态纯玩家（QS / SLDP / Factorial）

- 利润池 1：QS 0 收入；SLDP 2025 营收 $21.7M、2026Q1 同比 -49%；Factorial 私募暂无公开数据。来源：mat-5b6fbd / mat-5e83ab / mat-9d0d55
- 增速 3：纯叙事股，增速取决于一次 PowerCo / BMW SOP 公告，二元分布。来源：04_implied §A §B
- 竞争 2：与 CATL/丰田/三星 SDI 不在一个量级，期权属性 > 实业属性。来源：07_decision §3 Tier 3
- 估值 1：QS 隐含 2027 准点 + 40 GWh + 25% license 兑现"三连击"，04 明确"已透支"；SLDP 同样"已透支"。来源：04_implied §A §B
- 周期 3：处于"Pre-A 末期"（CATL 20Ah 标定），但路线 + 节奏 + 融资三个失败方向都已被 06 风险章节列出。来源：mat-f6cc96 + 06_risk

## 深挖档（创建 arena topic）

### 1. 固态电池设备链

- **建议 slug**：`global-ssb-equipment`
- **入选理由**：07 决策套件 Tier 1 的两个标的（先导、利元亨）都在这里；单 GWh 设备价值量 4-5x 跃升 + 国产替代窗口未关，且与硫化物/氧化物/聚合物/卤化物路线无关——是 04 拆解中**唯一两端都"被低估"的 arena**。
- **预期关键洞见**：
  - 先导固态收入"叙事温差"何时消除（中报披露口径）
  - 等静压国产化进度（瑞典 Quintus 壁垒 vs 利元亨/海目星集成）
  - 头部车厂自研产线 capex 对设备订单的二阶利好量化（06 盲点 #3）
- **预填 L4 狩猎问题**：
  1. 2026 中报先导/利元亨能否首次单独披露"固态相关设备订单"？若仍归口"锂电池智能装备"，市场对叙事温差的折价应给多少（参考 04 §C 反推 -15-20% PE 收缩）？
  2. 海目星拿下欣界能源 4 亿/2 GWh 氧化物+锂金属订单后，下一笔商业量产订单（first big check 之后）会落在谁家？利元亨 Quintus 联盟在 2026H2 装车测试中能否抢回份额？
  3. 若 K2 触发（LFP 跌破 0.2 元/Wh），设备订单 2027-2028 弹性是否会被压缩 30%+？此时"路线无关"还能否兜底，还是要回到具体客户结构？

### 2. 高镍正极出海（含全固态高镍 + PFE / LG 化学双逆风）

- **建议 slug**：`global-high-nickel-cathode`
- **入选理由**：04_implied §G 明确判定"被低估"——市场按"周期型正极厂"定价，未给"路线无关全产业链覆盖"溢价；但 06 风险章节同时列出 PFE（盲点 #1）+ LG 化学诉讼（盲点 #2）两个尾部风险。**机会和风险都集中、且都未被充分定价**，必须独立深挖。
- **预期关键洞见**：
  - PFE 条款下容百韩国 SPV / 当升芬兰股权架构的实际可执行性
  - LG 化学高镍 IP 战的边界（NCMA / 单晶 / Ni90+ 包覆）
  - 全固态高镍 BOM +30% 溢价池能否在 2027-2028 兑现到正极厂利润表
- **预填 L4 狩猎问题**：
  1. 容百载世能源 7 万吨 SPV 重组 2026 Q3 能否完成？若未完成、订单转移概率给多少？同样架构问题在当升芬兰一期 6 万吨上是否也存在风险？
  2. LG 化学 2026 Q3 前能否拿到对容百的临时禁令？若拿到，是否会在 6 个月内对当升/巴莫提起类似诉讼？"高镍出海"叙事整体应折价多少（06 测算 20-30%）？
  3. 全固态高镍正极 2027-2028 出货从当前 20 吨级 → 千吨级，BOM +30% 溢价能否真正落到利润表（而不是被电芯客户拿走）？

### 3. 固态电解质 + 锂金属上游（硬卡点）

- **建议 slug**：`global-ssb-electrolyte`
- **入选理由**：mat-c660fb / mat-f6cc96 双重把硫化锂前驱体工艺定为"全产业链硬卡点"；07 K3 直接把硫化物 LPSC 价格（8000 → 4000 元/kg）作为路线胜负的关键监控指标。但**市场没有独立估值锚**（嵌入正极/电芯母公司），SMM 至今未出独立 SKU——是最典型的"卡点 + 未定价"组合。
- **预期关键洞见**：
  - 硫化锂从 480 万 → 100 万元/吨的降本路径与时间表
  - 中国（容百/当升）vs 日韩（出光/三井/Mitsui）的硫化物专利墙拆解
  - 锂金属负极（赣锋千吨试产）何时跨过"实验室 → 中试"门槛
- **预填 L4 狩猎问题**：
  1. 出光兴产 2027 千吨级硫化锂能否准点投产？容百硫化物电解质 2026H2 中试线良率首披能否 ≥70%？这两个时点的实际差距给中国厂商留多少窗口？
  2. 硫化物 LPSC 价格从 8000 → 4000 元/kg 需要哪些工艺/规模门槛？谁会先做到？该价位下硫化物相对氧化物的成本优势是否足以颠覆 K3？
  3. 赣锋锂金属负极千吨试产的真实良率和单位经济性如何？若 2026H2-2027H1 仍卡在"实验室级良率"，对"赣锋半固态 + 锂资源 + 全固态期权"三段拼装的影响应如何重新定价（04 §F 已判定"结构性透支"）？

## 观察档（监控档）

### 4. 半固态电芯装车链

- **暂不深挖理由**：05_decision Tier 3 已列入"看空/回避"，且 04 §F 把赣锋（半固态主力）判定为"估值结构性透支"。装车 +272% 是真数据、但月销/事故/性价比三重证伪信号都已被 06 / 07 列出，独立深挖一个看空 arena 在当前节奏下性价比不高——**等数据兑现后再升档**。
- **升档触发条件**：
  1. 蔚来 ET9 + 智己 LS9 + 赛力斯半固态车型 **任一车型月销破 1.5 万辆**且持续 2 个月（07 K4 加仓位 5000、强化位 2 万）
  2. 半固态溢价从 43% 收窄至 ≤20%，同时安全提升（热失控温度提升）≥+30℃（推翻 mat-f6cc96 性价比结论）
  3. SMM 首次出"全固态专用正极/负极独立 SKU"——证明物料端开始有独立锚
- **监控指标**：
  1. 蔚来/智己/赛力斯半固态车型月销月报（2026-Q3 起按月跟踪）
  2. 半固态车型召回/起火事件计数（07 K4 阈值：单车型 ≥3 起 BMS 起火 → 清仓）

### 5. CATL H 股折价 + 全固态期权

- **暂不深挖理由**：07 Tier 2 已列入"中确信、估值合理可逐步建"，且 04 §E 校准为"A 股合理、H 股低估"——结论已经清晰，主要是仓位执行而非深挖问题。CATL 是 industry topic 自带覆盖、不需要独立 arena 重做尽调；但若 2026 Q2 IR 电话会出现叙事拐点，应升档为独立 arena。
- **升档触发条件**：
  1. CATL 2026 Q2 IR 电话会首次披露**全固态时间表 + Capex 数字**（07 §6 假设 #5 验证）
  2. H 股折价从 15-20% 收窄至 ≤8%，意味着全固态期权开始定价 → 需独立深挖凝聚态 / 钠电 / 海外三段叠加
  3. 凝聚态首批交付客户名单公布（07 §5 日历事件 2026-06）
- **监控指标**：
  1. CATL A/H 股折价率（周度）
  2. 凝聚态 / 硫化物中试线良率（季度，目标 ≥70%）

## 淘汰档

### 6. 美国全固态纯玩家（QS / SLDP / Factorial）

- **淘汰理由**：04 §A §B 双双判定"已透支"，07 Tier 3 明确"看空/回避"——估值定价的"PowerCo 准点 + 40 GWh + 25% license"和"BMW + Samsung + SK On 三选一"两个前提，都被资料证据持续打折；BMW 在 SLDP 10-Q 中已完全静默，QS 真实现金 burn 未改善。继续投入研究的 ROI 极低，保留作为"美股叙事股泡沫"短端反向锚点即可。
- **复活条件**：
  1. QS Cobra 工艺公开**工业级良率 >85%**（07 K5 减空仓阈值）
  2. SLDP 2026H2 连续法 75 吨 pilot 投产**单位经济性首披优于内部模型**（04 §B 校准翻盘信号）
  3. PowerCo 实际下单 ≥10 GWh license（非合同上限 40 GWh）
- **保留监控**：QS / SLDP 季报 + DOE 资金动态（季度），破产/被收购事件触发"美国叙事股溢价破裂"二阶传染评估
