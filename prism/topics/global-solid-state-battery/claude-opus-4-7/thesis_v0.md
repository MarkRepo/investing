## 1. 核心 thesis（强度 6/10，分化看法）

**看多固态电池的"卖铲人"（设备 + 关键材料），看空当前已被 price-in 的纯电芯叙事股**。
产业方向几乎不可逆，但赢家不在话题度最高的位置。

---

## 2. 支持理由

1. **半固态已经在跑真实需求**——蔚来 ET7 / 智己 L6 / 赛力斯均已装车，半固态量产 = 全固态产业基础设施在被搭建（设备、材料、工艺验证），无论全固态终局多久到达，这段路径已经在产生订单
2. **卖铲人受益于任意路线胜出**——干法电极设备、硫化锂、锂金属负极、固态电解质粉体等的需求曲线不依赖硫化物 vs 氧化物的胜负，是"路线无关收益者"
3. **纯电芯叙事股估值已透支多次**——QuantumScape 2020-2021 估值泡沫已破裂一次但仍有溢价，卫蓝/清陶概念股在 A 股已涨过一轮，每次量产时间表延期都会有再杀估值的事件驱动
4. **政策资金确定性高**——日本 NEDO 1500 亿日元、中国新型储能政策、欧盟 Battery Alliance 三方都在持续投入，产业资本周期下行风险被熨平
5. **车厂自研难以撼动专业电池厂的制造 know-how**——丰田搞了 20 年仍未量产，这是工程问题不是研发问题，宁德/LG 等龙头的制造护城河在固态时代依然成立

---

## 3. 最大反方观点（必须诚实对待）

1. **液态电池降本速度可能让固态在 2030 前无经济性**——磷酸铁锂电芯报价已破 0.3 元/Wh，若 2027 年再降到 0.2 元/Wh 以下，固态在乘用车场景将失去市场（只剩 eVTOL / 高端消费电子等小众场景），整个产业链估值天花板下移
2. **中国氧化物路线可能在终局败北**——硫化物离子电导率天然占优，日韩集体押注硫化物，如果硫化物率先突破干法电极工艺，中国氧化物路线（卫蓝、清陶、赣锋）的产业链将变成"次优解"被边缘化
3. **车厂自研可能复制特斯拉 4680 故事**——丰田/日产/本田自研全固态若成功，会显著压低 CATL/LG 在固态时代的议价权，叙事会从"电池厂受益"变成"车厂受益"

## 5. 研究中重点验证项（→ workflow 01 路线图主线）

1. **卖铲人订单弹性追踪**：先导智能、利元亨、当升、贝特瑞、璞泰来等公司 2024-2026 固态相关订单/产能/营收占比的真实爬坡曲线（**对应支持理由 #2**）
2. **三家美国玩家的现金跑道**：QS/SLDP/FE 的 cash burn rate × 现有现金 × 后续融资可行性，以及它们的技术里程碑相对原计划的延期程度（**对应反方 #3 验证 + Killer K5**）
3. **日韩硫化物量产真实风险**：丰田 2027 SOP、日产 2028 SOP、三星 SDI 2027 试产——原型车 → 中试线 → SOP 的每个里程碑是否按时（**对应反方 #2 + Killer K1**）
4. **半固态命运的时间窗口**：半固态 2024-2027 装车数据 + 全固态量产时间表 → 推算半固态生命周期（5-7 年 vs 长期共存）；卫蓝/清陶的估值天花板由此决定（**对应支持理由 #1 + Killer K4**）
5. **液态电池降本曲线**：磷酸铁锂、三元每季度电芯报价 + 上游碳酸锂/镍价跟踪 + 头部厂商单 Wh 成本拆解（**对应反方 #1 + Killer K2，这是最容易被忽视的"竞品颠覆"风险**）
