# thesis_v0 — 双林股份 (300100)（继承自父 arena global-roller-screw）

## 1. 核心 thesis（≤120 字）

**双林是行星滚柱丝杠 arena 里"卡位真实 + 定价有安全边际"的首选：全A股唯一"总成路线 + 上游磨床自制（科之鑫 C3-C0）"垂直整合，主业（汽车传动，扣非 +36.6%）撑现金流，PE 仅 30x（全场最低）。赌它在磨床自主（K4）+ 良率兑现（K2）时先受益。** 强度 **3/10**（arena 4 -1；赛道赢家仍不确定、尚未定点，但双林是本 arena 下行保护与定价安全边际最好的一个）。

## 2. 支持理由

1. **垂直整合独特卡位**：2025-01 收购无锡科之鑫，掌握内螺纹磨床（C3-C0）——全 A 股 PRS 玩家中少见的"设备端自制"，若"丝杠终局是磨床"成立则卡位独特 [mat-eecd0e][mat-0f858a]。
2. **主业稳、现金流厚**：2025 营收 54.84 亿（+11.67%）、扣非净利 +36.63%、经营现金流 7.81 亿；机器人重投入由主业输血，不靠讲故事融资 [mat-eecd0e]。
3. **估值安全边际**：PE 30.2x，全 arena 最低（vs 五洲 240x/恒而达 177x/北特 115x），机器人期权几乎"白送"未被充分定价。
4. **总成路线附加值高**：做反向式 PRS + 关节模组总成（非单卖部件），绑定深、附加值高；10 万套量产线 2026-06 投产。

## 3. 最大反方观点

1. **尚未获正式定点**：反向式 PRS、关节模组、微型滚珠丝杠三条线年报均明写"尚未获得正式定点"，仅送样/首批样件（2025-06 交付）[mat-eecd0e]。
2. **2026Q1 急转**：营收 -10.42%、归母净利 -47.01%、经营现金流 -88.19% [mat-6bae75]——主业开局走弱，放大机器人重投入压力。
3. **商誉减值敞口**：科之鑫商誉 1.15 亿测试通过但依赖激进 DCF（营收增速峰值 86.77%、净利率 >29%），是后续减值风险 [mat-fbeb29]。
4. **机器人未贡献利润**：反向式 PRS 2025 仅 1500 套试制，尚在 0→1。

## 4. Killer Questions

- **K1｜头部定点兑现**：双林反向式 PRS/关节模组能否 2026-2027 拿到头部整机（奇瑞/Tesla/优必选）**正式定点**（非样件）？可证伪：至 2027 仍仅送样。*(继承自父 K1)*
- **K2｜良率兑现**：10 万套线 2026-06 投产后 C3/C5 批量良率能否 ≥80%？可证伪：投产后良率 <70%、返工率高。*(继承自父 K2)*
- **K3｜PRS 路线稳定**：所配套整机线性关节是否维持 PRS 方案、不被准直驱/滚珠替代？*(继承自父 K3)*
- **K4｜磨床自制兑现**：科之鑫磨床（C3-C0）能否支撑双林自身量产 + 2026-06 起对外销售（40 台/月）兑现？可证伪：磨床仅自用、对外销售落空。*(继承自父 K4，双林强相关)*
- **K5｜机器人毛利转正**：双林机器人/关节模组业务毛利能否转正并维持 >25%（不重演谐波以价换量）？*(继承自父 K5)*
- **K6｜主业输血可持续（新增·公司专属）**：汽车传动主业现金流能否在 Q1 净利 -47% 后持续支撑机器人重投入 + 消化科之鑫商誉减值敞口？
