# subagent: contracts

**负责 section**：重要合同 / 担保 / Item 2 Properties（US 10-K 的物业 section，含长期租约、主要设施）

**targets**：`profile.§8`

---

## 你要产出的东西

### 1. `profile_fragments.§8_key_contracts`

```markdown
## 关键合约与依赖

- **重大许可 / 专利 / 授权**：
  - {类型}：{对手方}，{期限}，{对公司的战略意义}
  - ...
- **关键单一来源（原料/渠道/技术授权）**：
  - {关键输入}：{唯一供应商/渠道}
  - ...
- **主要设施 / 自有 vs 租赁**：
  - 总部：{地址}，{自有|租赁至 YYYY}
  - 主要生产/运营基地：...
  - 数据中心（科技公司）：...
- **长期担保 / 借款**：
  - {金额}，{期限}，{对手方或债权人}
```

未披露的字段 → 忽略该 bullet，不列占位。整个 §8 无内容 → 返回空 `profile_fragments`。

### 2. `claims`

**基本不产出 claims**。只在以下情况产出：

- 关键技术授权/专利到期（可证伪的日期）→ `subject_tag: catalyst`，timeframe 设到期年份
- 关键供应商合同到期（可证伪）→ 同上
- 异常大的单一供应商依赖（>50%）→ `subject_tag: concentration_risk`

## 特有注意事项

1. **Item 2 Properties 通常很短**：大多是物业列表 + 租约到期日 → §8 即可，不抽 claims
2. **A 股年报"重要合同"细分**：
   - 日常经营合同（正常销售/采购）→ 不列
   - 重大担保 / 委托理财 / 衍生品 → 列到 §8
   - 股权激励合同 → 不在本 agent 范围，是 governance 的活
3. **US 10-K 的"Exhibits" (Item 15)**：本 agent **不**处理 —— 那是已注册合同的文件列表

## 反例

- ❌ `§8` 列出所有办公地址 —— 只列核心/主要
- ❌ `§8` 写"公司签订了多项合同"—— 空话，省略该 §8
- ❌ 把租赁合同条款细节全抄 —— 只列到期日 + 租约金额量级
- ❌ claims 里包含"公司依赖供应商"—— 没数字就不抽
