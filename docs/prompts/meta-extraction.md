# meta.md 抽取 Prompt（公司稳定事实）

从年报/招股书/交易所公司页面抽取**跨年不怎么变**的稳定事实，输出 `meta.md`。
和 `profile-YYYY.md` 区别：meta 是"一次填好，极少更新"的那些字段（上市日期、交易所、实控人结构、业务大类）；profile 是"每年一份"的业务快照。

---

## 流程

1. 贴交易所公司主页 + 年报首页 + 股权结构图（如果有）进 Claude 对话
2. 附上本 prompt
3. Claude 返回 markdown
4. 你核对关键字段（行业分类、实控人、上市日），保存到 `companies/{market}_{ticker}/meta.md`
5. 以后除非发生变更事件（实控人变更、退市重组、改名），否则不更新

---

不要进 meta.md。

【输出格式】只返回 markdown：

---

## 审阅 checklist

- [ ] 行业分类对上 `controlled-vocab`（用于能力圈分流）
- [ ] 实控人持股 %：多方来源核对（年报前十大股东 + 交易所披露）
- [ ] 上市日和交易所：用交易所官网，不信研报转述
- [ ] 财年截止：很多中概是 12-31，但也有 6-30 / 3-31 的，别默认

---

## 反例

- ❌ "2025 年收入 28 亿" 写进 meta.md → 这是当年事实，属 profile-YYYY.md
- ❌ industry_primary="科技" → 粒度过粗，用 controlled-vocab 细分 id
- ❌ 把最近一次分析师电话会里的"战略方向"写进 §1 业务大类 → 那是展望，不是稳定事实
