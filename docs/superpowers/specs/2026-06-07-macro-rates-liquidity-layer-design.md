# 宏观层设计 — 利率 / 流动性 / 汇率（prism 方案 C）

> 状态：已确认架构方向，待用户复审本文档后转实现计划
> 日期：2026-06-07
> 作者：与用户协同 brainstorm 产出

## 1. 背景与动机

prism 现有 topic（白酒、茅台、泡泡玛特、拼多多、富途等）全部是自下而上的个股/行业逻辑。
每个 case 的估值（买入框、DCF、估值矩阵）都隐含一套**贴现率**和**风险背景**假设，
但 prism 里**没有任何模块拥有这套假设**——它们各拍各的、不可见、不一致。

宏观层填的就是这个缺口：把"会移动我持仓价格的少数宏观变量"系统化地研究出来，
并显式地连到每个持仓上。

用户是宏观门外汉，因此本层有**双重目标**：
1. **学习载体**：用大白话把利率/流动性/汇率框架讲透（primer + 活注解）。
2. **专业级集成**：以严谨的因果链结构接入 prism，输出可消费的体制读数与传导决策。

## 2. 确认的范围决策

| 决策点 | 选定 | 理由 |
|--------|------|------|
| 地理起点 | **美国/全球为主线，中国第二块** | 全球利率/流动性的总闸门在美国；中国作平行第二块 |
| 学习载体 | **入门读本 + 活着的注解层** | primer 一次性建词汇表，regime_read 每指标带注解随用随巩固 |
| 集成架构 | **方案 C（混合）** | macro topic 拿到学习+活读数；transmission_map sidecar 给跨 case 联动；不改 case DCF，可平滑升级到强耦合（方案 B） |
| 研究目标边界 | **利率 + 流动性 + 汇率 三目标** | 三个近端目标（最贴近价格）；增长/通胀/政策反应/财政为上游输入；汇率对中国/中概组合不可省 |

### 为什么是这几个目标（地基逻辑）

```
资产价格 = 现金流 / (无风险利率 + 风险溢价)
                       └利率┘      └流动性/风险偏好┘
```

- **利率、流动性**：分母里最贴近价格的两个变量 → 近端研究目标。
- **增长、通胀**：不是并列目标，而是利率/流动性的**上游驱动输入**（央行盯着它们行动）。
- **汇率**：对几乎全为 A股/中概（含 ADR：拼多多、富途）的组合，是钱"流进/流出中国资产"的闸门 → 必须作为第三个目标，而非可选项。

## 3. 核心架构：一条因果链，四层

```
[L1 输入源] → [L2 驱动变量] → [L3 目标·三体制读数] → [L4 传导·决策]
   数据         增长/通胀          利率 / 流动性 / 汇率        每持仓敏感度
              政策反应/财政         (各自小框架+大白话)         → 仓位/久期倾斜
```

链条三段对应用户最关心的三件事：**左半段=输入，中段=传导逻辑，右段=决策**。
prism 里的文件只是这条链的容器；逻辑在前，文件在后。

### L1 + L2 — 输入层：每个驱动变量看什么、从哪来

| 驱动变量 | 美国/全球输入（主线） | 中国输入（第二块） | 数据源 |
|---------|------------------|----------------|--------|
| 增长趋势 | 非农、ISM PMI(制造+服务)、零售、初请、GDPNow | 官方+财新 PMI、工业增加值、社零、固投 | FRED / 统计局·财新 |
| 通胀趋势 | CPI、**核心 PCE**(美联储最看)、时薪、油价、5y5y 通胀预期 | CPI、PPI | FRED / BLS / 统计局 |
| 政策反应函数 | FOMC 点阵图、CME 利率期货(FedWatch)、官员讲话、纪要 | 货币政策执行报告、OMO/MLF 操作 | CME / 美联储 / 央行 |
| 财政供给 | 国债发行计划(QRA)、TGA 余额、赤字 | 专项债发行、财政存款 | 财政部 / 央行 |

> **数据获取现实**：美国数据 FRED 免费 API 几乎全覆盖上述指标，第二期可全自动抓；
> 中国数据较散（统计局/央行/Wind），MVP 先半自动（人工/web 搜索快照）。

### L3 — 目标层：三个体制读数（regime_read 主体）

每个体制 = 输入 → 内部逻辑 → 输出形态 + 大白话注解。

| 目标 | 关键输入 | 内部逻辑 | 输出形态 | 大白话=在判断什么 |
|------|---------|---------|---------|------------------|
| **① 利率体制** | 美：2Y/10Y、10Y 实际利率(TIPS)、期限溢价、政策利率；中：10Y 国债、DR007、LPR | 费雪：名义=实际+通胀预期；短端看央行、长端看预期+期限溢价 | 曲线四形态(牛陡/熊陡/牛平/熊平)+方向 | 钱的**价格**往上还是往下 |
| **② 流动性体制** | 美：净流动性(美联储资产−TGA−RRP)、信用利差(HY/IG OAS)；中：社融同比、M1、M1-M2 剪刀差、信贷脉冲、DR007 | 央行→银行→市场三层；宽货币×宽信用四象限 | 松/紧 + 四象限 | 钱**多不多、愿不愿冒险** |
| **③ 汇率体制** | 中美 10Y 利差、DXY、USDCNY、跨币种基差、北向资金 | 利差→汇率→资本流动套利链 | 人民币升贬压力 + 外资流向 | 钱往**中国流还是往外跑** |

读数顶部给**综合判断 + 强度分（0–10，沿用 prism thesis 惯例）**。

### L4 — 决策层：传导地图 transmission_map

三体制读数 → 四条传导渠道 → 每持仓敏感度标签：

- **四渠道**：贴现率渠道 / 风险偏好渠道 / carry-久期渠道 / 汇率渠道。
- **每持仓标签**：久期(long/short)、利率β、美元暴露、流动性β + 利好/利空体制 + 一句大白话传导链。
- 体制读数变化 → dashboard 顶部 banner 标出"当前体制 X，最暴露持仓 A/B/C"。
- **MVP 不改 case 的 DCF**，只把联动显式摆出来（可观察、不强制）。

`transmission_map.yaml` 示例：

```yaml
holdings:
  cn-popmart:
    duration: long          # 高估值成长 = 长久期 = 对贴现率最敏感
    rate_beta: high         # 利率上行 → 杀估值最狠
    usd_exposure: low       # 收入主要人民币/港元
    liquidity_beta: high    # 风险偏好票，放水受益、收水先跌
    regime_favor: [复苏, 全面宽松]
    regime_hurt:  [滞胀, 全面收紧]
    plain: "高 PE 成长股，利率一升、风险偏好一降，哪怕基本面没变也先挨打"
  pinduoduo:
    usd_exposure: high      # 中概 ADR，美元/中美利差/外资流向直接相关
    # ...
```

## 4. prism 容器映射（方案 C）

| 文件 | 装的是因果链的哪段 |
|------|------------------|
| `prism/topics/global-macro-rates-liquidity/`（新 `type: macro`） | 整条链的家 |
| `outputs/00_primer.md` | 教 L1→L4 整条链（大白话读本，美主线+中国第二节） |
| `outputs/m_regime_read.md` | L3 三体制活读数（每指标带 `这是什么/为什么看/现在说明什么` 三句注解） |
| `outputs/transmission_map.yaml` | L4 决策 sidecar |
| `manifest.yaml` | L1 输入源登记 |
| `topic.yaml` | 命门(decomposition)=当前最不确定的宏观岔口；thesis=三体制综合判断+强度 |

## 5. 分期落地

- **第一期（MVP，本次目标）**
  - 建 macro topic（放开 `type: macro`）
  - 写 `00_primer.md`（整条因果链大白话读本）
  - 出 `m_regime_read.md` v1（指标手动/半自动快照一次，全注解，顶部综合判断+强度）
  - 给现有 ~6 个持仓建 `transmission_map.yaml`
- **第二期**
  - FRED 自动抓美国指标 + 中国半自动
  - 设监控节奏（monitoring tier / cadence）
  - dashboard 加宏观 banner
- **第三期（可选 = 升级方案 B）**
  - 把贴现率假设真正注入 case 的 DCF（单一事实源）

## 7. 非目标（YAGNI）

- 不做宏观预测/择时（方向胜率低）；本层只做**体制识别 + 敏感性映射**。
- MVP 不改任何现有 case 的 DCF。
- 暂不引入"景气/经济周期"第四目标（增长/通胀保持为输入身份）。
- 不做全自动中国数据管道（第二期再评估）。

## 8. 成功标准

- 用户能**看懂** regime_read 里每个指标在说什么（注解达标）。
- 三体制读数能给出一句可执行的综合判断 + 强度。
- transmission_map 能在体制假设变化时，一眼看出哪些现有持仓最暴露。
- 整套结构与 prism 现有 topic/dashboard 机器同构，web 自动反映。
