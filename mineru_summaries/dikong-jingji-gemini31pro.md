# 为什么是现在：政策引爆与三力共振

低空经济不是新概念，但2024年是质变之年。"低空经济"历史性写入政府工作报告，从地方试点跃升为国家战略，标志着空域资源正式从"管控资源"向"生产要素"转型。驱动力是三重叠加：

- **政策解绑**：2024年1月《无人驾驶航空器飞行管理暂行条例》施行，首部无人机专项行政法规落地；深圳立法先行（全国首部低空经济产业促进专项法规），安徽、海南、四川形成各具特色的省级战略。
- **技术成熟**：亿航智能EH216-S在2023年斩获全球首张载人eVTOL型号合格证（TC）及标准适航证（AC），适航壁垒首次被突破；固态电池、5G-A通感一体、AI自主飞行算法三条技术主线同步推进。
- **资本涌入**：峰飞航空、沃兰特、时的科技等在2023-2024年密集完成数亿元级融资；小鹏汇天A轮超5亿美元；地方政府产业基金形成"以投带引"机制。

# 市场规模：从五千亿到两万亿的路线图

**基准年（2023）**：市场规模5,059.5亿元，构成以工业无人机行业应用为主体，通用航空为补充，新兴业态（eVTOL研发、低空物流）贡献少但增速最快。

|------|----------------|----------|-----------|
| 2024E | 6,300 | ~24.5% | 政策元年，无人机物流试点扩大 |

| 2026E | 10,200 | ~30.8% | eVTOL小规模商业运营启动 |

增速在2026年出现加速拐点，核心驱动是eVTOL商业运营从零到有的跃变。2030年突破2万亿，2035年冲击3-5万亿。

# 产业结构：三层市场，三种时态

**行业应用（当前主力，~65%市占）**：农林植保、电力/管线巡检、安防应急、测绘。技术最成熟，商业模式跑通，是当前产业的"稳定器"。CAGR约15%-20%，稳健但不爆炸。

**无人机物流（近期增长极，~20-25%市占）**：三大头部各走差异化路线——
- 顺丰丰翼：中大型无人机"支线+末端"，破解偏远/跨海配送，已在江西赣州、四川成都获商业运营许可，飞行次数超百万次。
- 美团无人机："3公里15分钟"城市即时配送，人机协同覆盖深圳、上海数十条常态化航线，模式已初步验证。
- 京东物流："干线-支线-末端"三级体系，专攻农村最后一公里，陕西、宿迁等地长期试点。

痛点集中在：信号干扰与末端智能空投柜普及不足（场景瓶颈）、法规审批效率（法规瓶颈）、单位运营成本尚未压过人力（成本瓶颈）。CAGR约30%-40%。

**载人UAM/eVTOL（未来蓝海，~2%市占，CAGR>60%）**：市场份额极小但代表产业天花板。技术路线分化：
- **多旋翼**（亿航EH216-S）：已取证可运营，速度100km/h、航程30km，适合短途城市内点对点；
- **复合翼**（峰飞"盛世龙"）：速度200km/h、航程250km，峰飞完成深圳-珠海全球首条跨海跨城eVTOL演示；
- **倾转旋翼/分体飞行汽车**（小鹏汇天）：技术最复杂，性能潜力最大，正推进"陆空一体"商业化。

# 产业链：谁掌握卡脖子，谁拿定价权

**上游（价值占比10-15%，技术壁垒最高）**

核心瓶颈在于三电：
- 电池：主流锂离子260-300Wh/kg，限制eVTOL商业航程。目标>400Wh/kg的半固态/固态电池，宁德时代、孚能科技已布局航空级产品。
- 电机/电控：永磁同步电机国内技术成熟，但航空级高温高振动可靠性验证有缺口。
- 飞控/航电：大疆积累深厚但面向载人eVTOL的高冗余飞控仍需对标最高安全标准；华为、中兴主攻5G-A低空通感一体化。
- 机体材料：碳纤维产能全球领先，但高端航空级复合材料设计制造能力仍有差距，部分关键芯片依赖进口。

**中游（价值占比30-35%，竞争最激烈）**

工业无人机：大疆一超独大（行业版），纵横股份深耕垂直起降固定翼。

eVTOL整机三足鼎立：
1. 创新科技公司（亿航/峰飞/小鹏汇天）：灵活创新、已抢先机，但规模化生产能力待建；
2. 传统航空国家队（中航工业/中国商飞）：适航经验最深、试验设施最全，但决策速度慢；
3. 跨界车企（吉利沃飞长空/广汽）：雄厚资本+整车制造经验，短板在航空器设计与适航。

**下游（价值占比50-60%，跑马圈地）**

运营：物流公司（顺丰/美团/京东）、传统通航公司、制造商自运营（亿航）、未来平台型整合者（类滴滴模式）。

基础设施：
- 起降场（Vertiport）：无统一国标，深圳先行探索，中建/中交央企和特锐德（充电）已入场；
- UTM空管系统：民航局主导顶层设计，腾讯云/华为/航天科技提供技术实现；
- 5G-A通信网络：三大运营商联合华为/中兴多地测试低空覆盖，是超视距飞行的必要前提。

# 区域格局：三圈分工，深圳领跑

- **珠三角**（深圳/广州主导）：全产业链最完整，大疆、亿航、小鹏汇天均在此，政策最进取，2025年目标600条无人机航线、产业增加值1000亿元。
- **长三角**（上海/合肥/杭州）：制造业基础扎实，安徽主打"全域基础设施+制造集聚"，2025年目标培育50家龙头企业、产业规模800亿元。
- **京津冀**：央企国企+科研院所最集中，侧重政府应用（安防/应急/测绘）和高端制造，空域管理技术研究最强。

# 五大结构性挑战与其突破路径

1. **空域协同难**：军民多头管理，审批流程繁琐，需建立国家级数字化UTM"一窗通办"平台。
2. **电池航程瓶颈**：当前260-300Wh/kg限制载人商用航程，需固态电池突破；载人eVTOL可靠性验证需海量飞行数据。
3. **基建标准缺失**：Vertiport无国标，5G-A低空覆盖密度不足，投资回报期长需PPP模式撬动。
4. **商业ROI未证**：eVTOL研发/制造/运营成本叠加导致票价高企，规模效应形成前需政府补贴过渡，多元化收入（货邮+文旅+数据）有待验证。
5. **人才断层**：飞行员/操控员、航空级软硬件工程师、低空管制员三类人才严重短缺，现有培养体系跟不上产业扩张速度。

# 机遇展望：四条主线

- **政策红利持续释放**：未来5-10年空域逐步开放，细化运营法规、财税优惠将陆续落地。
- **技术融合加速**：AI大模型赋能自主飞行与健康管理（PHM），5.5G/6G实现百万级飞行器同时在线协同。
- **"低空+"赋能效应**：低空+物流、+交通、+文旅、+农业、+应急，几乎每个行业均有深度融合空间，是万亿级增量的来源。
- **新基建投资浪潮**：Vertiport、UTM、5G-A、高精度三维地图将形成新型资产类别，拉动巨额投资。

# 战略建议（按主体）

**制造企业**：死磕"适航取证"，这是商业化的唯一入场券；同时在电池/飞控核心技术上构建专利护城河；清晰定位技术路线和目标市场，避免同质化。

**运营服务商**：从非载人场景（物流/巡检）切入，积累飞行数据和安全记录；选择一个核心区域打造可复制的"样板航线"跑通模式；安全记录是取得监管信任的唯一路径。

**投资机构**：长周期视角，关注整机取证进度与核心零部件（尤其是电池和飞控）"隐形冠军"；跟踪深圳/安徽/广州政策高地的区域机会；警惕短期概念炒作，核心看团队的适航执行力与技术护城河深度。
