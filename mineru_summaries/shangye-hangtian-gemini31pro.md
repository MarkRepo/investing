# 核心投资逻辑

本报告的主线极其清晰：**可复用火箭正在把中国商业航天从"演示验证"推向"工程化量产"的历史拐点**，而这一拐点将使发射需求从当前约40次/年暴增至稳态150次/年，倒逼上游发动机材料和箭体加工供应链跨越"项目定制"走向"规模批产"，核心标的将迎来市占率提升与单件价值量双击。

---

# 一、为什么是现在？——两款首飞点燃催化剂

2025年12月，两件事密集发生：

- **朱雀三号**（蓝箭航天，LEO运力21.3t一次性 / 18.3t航区回收 / 12.5t返场回收，液氧甲烷，一级9台TQ-12B发动机，设计复用≥20次）：2025年12月3日首飞成功、入轨，一子级回收试验因异常燃烧失败。
- **长征12甲**（国家队，液氧甲烷，LEO运力≥10t）：2025年12月23日首飞成功、入轨，一子级回收亦未成功，但获得宝贵再入数据。

两款火箭接续发力，共同标志着中国可复用火箭从"公里级跳跃验证"（已完成）跨越到**入轨级工程首飞**的阶段性节点。报告将此定义为"0到1"已经迈出，随后进入密集迭代期。

# 二、SpaceX猎鹰9：降本逻辑的成功原型

报告用猎鹰9的完整轨迹为中国行业校准坐标：

| 关键节点 | 时间 |
|---|---|
| 首飞 | 2010年6月 |
| 首次成功陆地回收 | 2015年12月（尝试约5年） |
| 实现常态化复用 | 2018年（再花约3年） |
| 截至2025年12月23日 | 580次发射，534次着陆，501次复飞 |
| Block 5一子级平均复用次数 | 从2018年1.67次 → 2024年7.33次 |

**降本数据**（马斯克公开披露）：
- 全新猎鹰9发射成本：约5000万美元
- 复用型边际成本：约1500万美元（其中翻新一子级仅25万美元）
- 近地轨道发射成本：约1.8万元/kg；若复用10次以上降至0.5万元/kg（阿里安5G同指标约8.5万元/kg）
- TrendForce预测：一次性火箭报价1.1-1.8亿美元，猎鹰级约6700万美元，完全回收后有望降至**200-500万美元**

核心结论：**成本压缩是激活星座组网"商业闭环"的前置条件**，没有低发射成本，星链规模就无从成立，中国星座亦然。

# 四、产业链：哪三个环节捕获最大价值

发动机+箭体结构合计占火箭一级硬件成本约**77.8%**（二级约58.1%），是复用时直接被回收的核心部件，也是技术壁垒最集中的环节。

### 1. 发动机系统（成本占比35%~45%，壁垒最高）

可复用要求发动机承受数十至数百次极端热循环，逼迫三条技术路线升维：

- **新材料**：高强高导铜合金（推力室内壁）、铌合金、钛合金——需耐高温、抗疲劳、轻量化
- **零部件加工**：金属3D打印取代传统铸锻，解决冷却通道等复杂异形件良率问题；环锻件对接涡轮盘、泵壳等关键部件
- **发动机总装**：重复点火泵阀、推力调节精密度的检测标准大幅提升

国内代表性发动机参数对比（截取重点）：

| 火箭 | 发动机 | 推进剂 | 海平面推力 | 推力调节 | 设计启动次数 |
|---|---|---|---|---|---|
| 猎鹰9 | Merlin 1D+ | 液氧煤油 | 845kN | 40-110% | 3 |
| 朱雀三号 | TQ-12B | 液氧甲烷 | 1000kN | 55-105% | - |
| 天龙三号 | TH-12 | 液氧煤油 | 1090kN | 40-110% | >3 |
| 双曲线三号 | JD-2 | 液氧甲烷 | 834kN | 35-110% | >3 |

### 2. 箭体结构（成本占比约25%~30%）

贮箱（铝合金薄壁结构）、整流罩、级间段均需在轻量化与强度之间取得极端平衡；可复用额外要求整流罩回收和结构件反复受载不失效。工艺路线：铝合金钣金 → 拼焊 → 数控铣削，精密度持续提升。

### 3. 控制系统（GNC是可复用的"大脑"）

垂直着陆的五阶段控制（调姿段 → 动力回飞 → 滑行 → 动力再入 → 着陆下降）须实现米级落点精度，对惯性导航、姿控计算机、传感器的可靠性和重复使用寿命要求远超一次性火箭。

# 五、两阶段受益逻辑

报告给出清晰的时序判断，不同阶段受益环节不同：

| 阶段 | 特征 | 受益环节 |
|---|---|---|
| 早期（复用成功率低） | 火箭报废率高、新箭需求量大 | 发动机+箭体+控制系统全面受益（制造端量增） |
| 成熟期（常态化复用后） | 液体发动机批量回收复用，新制造需求下降 | **箭体结构+控制系统**持续受益（复用带来翻新/检测需求；需求量反而锁定）|

# 七、政策催化：资本市场为商业火箭开绿灯

- 上交所发布**科创板第五套上市标准**商业火箭审核指引，明确将"可复用技术中大型运载火箭载荷首次成功入轨"定为阶段性成果门槛
- 蓝箭、星际荣耀、中科宇航、星河动力、天兵科技已开启IPO进程
- 2025年国家航天局发布《推进商业航天高质量安全发展行动计划（2025-2027年）》，商业航天司正式设立
- 市场规模：2015年3764亿元 → 2024年超2.3万亿元 → 2025年预计突破2.5万亿元

# 八、测算与假设的关键前提

1. 44,816颗星座计划全部推进（含GW、G60、鸿鹄-3及其余较小星座）
2. 卫星寿命5年（参照星链）
3. 以猎鹰9一箭60星为基准运力——若中国可复用火箭实现更高运力（如朱雀三号航区回收18.3t，约等效一箭70-80星），则150次/年或可适当下修，但绝对发射频次仍大幅高于当前水平

---

# 九、风险提示

1. **可复用技术久攻不克**：两款首飞火箭回收均失败，若中国企业无法快速积累数据完成迭代，商业模式的根基（低成本）将难以兑现
2. **星座建设大幅慢于预期**：资金压力、频轨争夺失败、商业模式不成立，均可导致组网推迟或缩减规模
3. **SpaceX价格战**：若SpaceX进一步降价渗透中国商业发射市场（含国际市场挤压），国内火箭公司议价空间被压缩
4. **出口管制升级**：核心金属加工母机、特种合金原料受到更严厉的海外管制，影响供应链自主化进程
